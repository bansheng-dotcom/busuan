## 八、命宫闰月 bug 修复（2026-10-07）

### 根因
`zhiwei.py` 的 `lmonth = lunar.getMonth()` 对**闰月返回负数**（如 1968 闰七月 = -7、1947 闰二月 = -2）。`month_index = lmonth - 1` 直接算成负数，导致**命宫、身宫、左辅、右弼**整盘偏移 2-3 宫。

### 修复
`lmonth = abs(lmonth)`（闰月作本月，紫微传统 + lunar_python 权威日历口径），一并修正左辅右弼的 `lmonth` 用法。

### 反推验证
穷举 1900~2026 全部 **47 个闰月**，逐例对 iztro 反推有效月序，**47/47 均为「闰月作本月」**，确认修法正确。

### 剩余 1 例为 iztro 自身 bug
1968-09-13（闰七月廿一）：lunar_python 权威日历 09-22 才入八月，iztro 的 `by_solar` 却 09-08 就按八月算（早 14 天），属 iztro 闰月日界 bug。zhiwei 遵循权威日历 + 闰月作本月，是正确方。已在 `ziwei_crosscheck.py` 标 `KNOWN_IZTRO_LEAP`。

### 验证
- 回归测试：157 → **163 通过 / 0 失败**（新增闰月 golden 6 项）。
- 紫微对照：核心一致 **104 / 0 待查**（另 3 年界已文档、1 例 iztro 已知日界 bug）。

## 九、P2 断卦后质检 evaluator（2026-10-07）

对标 weizeW/mingli-skills 的「每体系独立评估者（GAN 式对抗验证）」——之前只有排盘前 `precheck` gate，缺排盘后的断语质检。

### 新增 `libs/review.py`
断卦后质检 gate，与 `precheck.py`（排盘前）对称。七项强制检查（规则 ID R-RV-01~07）：
1. **三层分离**（盘面事实/规则推演/现实建议齐全）
2. **三级标注**（有 `[原文]`/`[规则推演]`，前缀匹配兼容 `[规则推演 R-XX-NN]`/`[原文·书名]`）
3. **免责声明**（末尾必附）
4. **应期**（给应期或明说「应期难定」）
5. **趋吉避凶**（趋/避缺一不可）
6. **信号冲突降级**（出现「冲突」须明说降级/仅供参考/不确定）
7. **白话层**（双轨输出须有白话收口 + 今日可行的一小步）

接口：`review.review(断语文本) → {pass, score, passed, checks, issues, verdict}`，`format_review` 格式化输出，CLI `python libs/review.py check --text/--file`。

### 集成
- SKILL.md 第六节后加「断卦后质检 gate」+ 第十四节代码支撑加 `review.py`。
- 回归测试新增 `test_review`（10 项断言）：合规通过/残缺不过/冲突未降级/空文本/缺白话层。
