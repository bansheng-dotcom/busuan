- 只做情绪安慰、生活建议，不给卦象

## 三、起盘脚本（scripts/cast.py，必须先跑）

```bash
python scripts/cast.py meihua-time           # 梅花易数·时间起卦
python scripts/cast.py meihua-num 12 34      # 梅花易数·数字起卦
python scripts/cast.py xiaoliuren            # 小六壬·月日时
python scripts/cast.py liuyao                # 六爻·铜钱摇卦(含纳甲装卦)
python scripts/cast.py bazi 2000 1 1 8 0 0 1 # 八字·年 月 日 时 分 秒 性别(1男0女)
python scripts/cast.py bazi                  # 八字·默认当前时刻
python scripts/cast.py liuren                # 大六壬·当前时刻
python scripts/cast.py qimen                 # 奇门遁甲·当前时刻(置闰法)
python scripts/cast.py taiyi                 # 太乙神数·当前时刻(年计/统宗)
python scripts/cast.py qizheng               # 七政四余·果老星宗(可--time)
python scripts/cast.py qizheng-liunian 1990 寅 2026  # 七政四余·流年大限小限(出生年 命宫地支 流年年份)
python scripts/cast.py fengshui 1990 坐北朝南 男    # 风水·八宅/玄空飞星(出生年 坐向 性别)
python scripts/cast.py zeri 婚嫁             # 择日·建除黄道神煞(可--time，事项可选)
python scripts/cast.py zeri-month 2026-10 婚嫁  # 择日·按月推荐吉日(月份 事项 [数量])
python scripts/cast.py hehun 1990 5 15 1992 8 20  # 八字合婚(男年 月 日 女年 月 日)
python scripts/cast.py bazi-liunian 2000 1 1 1 2026 10 # 八字·流年聚合(出生年 月 日 性别 起始年 年数)
```

- 所有时间起盘方法可加 `--time "YYYY-MM-DD HH:MM"` 指定占时（缺省用当前系统时间）。
- 八字/紫微/七政四余可加 `--lon 经度`（真太阳时校正，东经 120° 为基准）与 `--dst`（1986-91 中国夏令时回拨 1 小时）；出生时刻临近节气会提示「月柱可能跨节」建议双盘对照。
- 八字/紫微可加 `--html` 生成自包含 HTML 命盘（水墨风，可截图分享）。
- 起盘这一步**必须用脚本**，输出本卦/互卦/变卦/动爻/体用/四柱/大运/四课三传/八门九星/太乙落宫等确定性结果。
- **依赖**（`pip install lunar_python ephem cn2an bidict drawsvg`）：
  - 梅花易数/小六壬/六爻：纯内置。
  - 八字：`lunar_python`。
  - 大六壬/奇门/太乙：`scripts/libs/` 内集成的 kentang2017 开源引擎（`engines/qimen`、`engines/taiyi`，MIT）+ `sxtwl.py` 垫片（用 lunar_python 替代寿星历，见 libs/README.md）。
  - 七政四余/风水/择日：纯标准库（`libs/qizheng.py`、`fengshui.py`、`zeri.py`、`liunian.py`，源自 dglijin-oss/chinese-metaphysics-skills，MIT，见 `libs/LICENSE.dglijin-oss.txt`）。
- 太乙 `pan(0, 0)` 用「年计 + 太乙统宗积年」，如需月/日/时计或命盘，改 `pan(ji_style, method)` 参数（ji_style: 0年 1月 2日 3时 4分 5命；method: 0统宗 1金镜 2淘金歌 3太乙局）。

## 七、分层解读要求（强制，每卦每盘都要做到）

解释卦象/课式时，**先讲本义，再落到当前问事**，不能只把卦名当吉凶标签。顺序：

1. **本义**：该卦/课在典籍中的原始语义（卦辞、彖传、课体、格局）。
2. **组合画面**：上下卦（或宫位/四课三传）组合形成的核心画面。
3. **过程关系**：该卦原本描述的过程、关系、张力。
4. **当前对应**：落到用户所问之事。
5. **推断**：明确标注这部分是推断，不是经文。

区分三层：六十四卦卦义 / 八卦单象 / 当前问事应用，不得用「坎=谨慎」「复=重新开始」这类单词替代完整卦义，也不得把八卦单象冒充六十四卦本义。

## 十、输出格式（三层分离 + 四段式）

**三层分离（强制）**：输出必须把「盘面事实」「规则推演」「现实建议」三层分开写，禁止互相混淆、禁止把推演冒充事实或经文。

- **盘面事实**：脚本排出的卦/课/盘/四柱——可复现、可核验。
- **规则推演**：依据断法规则得出的吉凶、格局、生克——须标注是 `[原文]` 还是 `[规则推演]`。
- **现实建议**：落到当前问事的趋避与建议——一律标 `[主观推断]`。

**三级标注（强制，每条断语必标其一）**：
- `[原文]`：直接引自典籍（须注明书名出处）；
- `[规则推演]`：依据断法规则（体用生克、旺衰、格局等）推出的结论；
- `[主观推断]`：落到当前问事的判断与建议。
- 约束：吉凶定性、格局判断必须能回溯到 `[原文]` 或 `[规则推演]`，不得凭空 `[主观推断]`；`[主观推断]` 只能用于「落到问事」与「建议」。

1. **起卦信息**：输入、方法、所用规则（脚本输出）。
2. **排盘结果**：卦象/课式/盘局/四柱，含五行生克标注（= 盘面事实层）。
3. **断语**：引用原文（注明书名，标 `[原文]`）+ 规则推演（标 `[规则推演]`）。
4. **结论**：吉凶要具体落地，不只贴「吉/凶」标签，须说清：
   - **吉凶总断**：一句话定性（大吉/吉/中平/凶/大凶）+ 吉在何处、凶在何处（落到财/感情/事业/健康/时机哪一面）。
   - **趋避**（必给，对应第五节该术「趋避」条目）：趋吉（可乘之机 + 行动建议）与避凶（风险与规避）缺一不可，落到本卦本问。
   - **可乘之机**：卦中有利处 → 宜做什么、把握什么时机或方位。
   - **风险与规避**：不利处 → 点明风险，给出「如何避免」（方位/时辰/人事/心性上的具体调整）。
   - **行动建议**：「应该如何做」→ 给 1–3 条可执行的具体步骤。
   - **应期**（能断则断）：何时应验、何时转机；断不出就明说「应期难定」。
   - **免责声明**（必附，见第十一节）。

| S | 输入可信度 | S3=出生资料+时区+节气+地点确认；S2=单一排盘工具；S1=手打四柱；S0=干支不合法，先核对再分析 |
| A | 原局硬数据 | 四柱、藏干、月令、日主（脚本输出） |
| B | 结构事实 | 合冲刑害「是否存在」（存在≠生效） |
| C | 命理判断 | 「三合是否化」「某神是否得根」等需论证的判断，必须给依据 |
| D | 流年应验 | 用户提供的人生事件，只能作后验证据 |
| E | 模型解释 | 因果解读，属假设，与事实分开呈现 |

铁则：C 不得伪装成 B；E 不得伪装成 A/D；S0 输入先核对再分析。

**规则层级与冲突裁决**（`STRUCTURAL > CORE > SCHOOL > HEURISTIC > SUPPLEMENTAL`）：

| 标签 | 层级 | 示例 | 硬度 |
|---|---|---|---|
| `[STRUCTURAL]` | 结构事实 | 四柱、藏干、合冲刑害、通根透藏 | 最高，不可改 |
| `[CORE]` | 核心理论 | 月令定权、格局、扶抑、病药 | 高 |
| `[SCHOOL]` | 流派理论 | 调候（穷通宝鉴系）、盲派、人元司令 | 中，须标流派 |
| `[HEURISTIC]` | 经验规则 | 岁运并临、墓库冲开、应期范式 | 初始参考 |
| `[SUPPLEMENTAL]` | 辅助符号 | 神煞、空亡 | 主题标签/修正项 |

冲突裁决：跨层高者胜；同层保留竞争假设；跨流派并列呈现 + 标适用条件；证据不足输出「不确定」，禁止语言润色制造假共识。

**拒绝迎合（铁则）**：用户提出的结论、引用的说法、叙述的某年吉凶，**不得作为改变基础判断的依据**，只能触发重新核查。

**能力边界（MingLi-Bench 160 题实测 36.2%，随机线 25%）**：以下类问题八字结构给不出确定答案，一律按「不确定 + 低置信度」输出，禁止装作有把握——
- **精确年份 + 具体生平**（何年结婚 / 父亡年份 / 某年发生何事）；
- **学历**（印星不可靠推断学历，实测 18% 低于随机）；
- **外貌身材**（「五行主形」不可靠，归 `[SUPPLEMENTAL]`，不作主断）。
