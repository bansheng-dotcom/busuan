# H · 信号解读 + 追求阶段系统

> 来源：simp-skill（追爱军师）。读懂心上人信号、判断追求阶段。核心原则：**不要用单一信号下结论，看趋势和密度。**

## 信号分级

### 🟢 绿灯（积极）
- 主动找你说话，话题延伸主动
- 回复速度明显快（秒回/很快回）
- 记住你说过的细节并之后提起
- 主动分享生活，发圈后第一时间通知你
- 认真接你的梗；主动约你或暗示想见面
- 对你的感情状况好奇/在意；发撒娇语气、加语气词；深夜主动找你（22点后）

### 🟡 黄灯（模糊/暧昧）
- 聊得来但很少主动；回复及时但话题不深入
- 偶尔闪现再消失（时冷时热）；对你好但对谁都好
- 见面有互动但单独聊天少；朋友圈点赞不评论
- 接受你的照顾但从不明确表态

### 🔴 红灯（消极）
- 已读不回或回复极慢且敷衍
- 话题永远你在问、你在推；刻意回避见面
- 频繁提其他异性；明确说过「我们做朋友吧」

### 🏁 友谊区
- 当你树洞，倾诉其他感情；让你分析别人是否喜欢 ta
- 叫你「哥/姐/兄弟/闺蜜」；介绍你认识 ta 的其他异性朋友

**判定原则**：三个绿灯 > 一个红灯。但一句明确的「我们只是朋友」覆盖所有绿灯。

## 追求阶段系统

| 阶段 | 目标 | 策略重点 |
|------|------|---------|
| 1 破冰期 | 建立初步印象 | 找共同话题，展示真实有趣的一面，记住细节，稳定在场不轰炸 |
| 2 升温期 | 成为「特别的存在」 | 制造 1v1 机会，生活小事上关心，建立「只有你们知道」的内部梗 |
| 3 暧昧期 | 让对方意识到你不一样 | 偶尔制造距离感，问稍私密的问题加深连接，困难时第一个出现 |
| 4 表白前 | 选时机做万全准备 | 见表白评估清单 |
| 5 表白后 | 成功维系 / 被拒优雅处理 | 见危机处理 |

### 表白前评估清单
- [ ] 对方给出至少 3 个以上绿灯信号
- [ ] 已有相对稳定的 1v1 互动
- [ ] 没有明确的竞争对手干扰
- [ ] 心理状态稳定，不是焦虑中冲动表白
- [ ] 选好了时间地点（尽量当面，不消息表白）

## 信号解读配合（与 g 层联用）

本模块的「绿灯/黄灯/红灯」与 `g_analysis_framework.md` 的「costly signal / cheap talk」互补：
- 绿灯信号要过「costly」检验：她主动为你**调整计划、投入时间**才是真信号，纯嘴上的「你人很好」是 cheap talk
- 判断信号质量时，时间线趋势（越来越快/越来越慢）比单条信号更重要
