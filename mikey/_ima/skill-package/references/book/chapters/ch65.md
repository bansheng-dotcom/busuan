第65章 反面教材。失败案例汇编

本章金句：失败不是框架断裂的终点，失败是框架最强有力的老师。你从成功里学到的远没有从一次漂亮的失败里学到的多。

前面六十四堂课，绝大多数案例都在教你"怎么做能成"。这一章不一样。这一章用 Mike 自己的失败来教你"什么地方最容易断"。

失败不是污点。失败是最好的老师。前提是你有勇气把它摊开来看。

Mike 做了一个大多数导师永远不会做的事情：把自己的失败案例拿出来公开检讨。不是那种"看吧这个学员好傻逼"的检讨。

是他自己。一个已经把妹无数的导师。在临门一脚的时候犯了一个低级错误，把已经到手的姑娘搞丢了。而且是那种"她已经化好妆在打车来我家的路上"的临门一脚。

你可能会想：这种级别的错误，是不是太蠢了？恰恰相反。

正是因为这个错误太低级、太微小、太容易发生在任何一个人身上。它才有最高的教学价值。一个技术失误你可以怪经验不足。

一个判断失误你可以怪信息不够。但一个在"以为一切都稳了"的

瞬间发生的认知断裂？这是每一个高手都曾经踩过的坑。包括Mike。

这一章把三个维度的失败放在一起拆解。第一个是 Mike 自己的公开检讨，整个流程前九步全部正确，死在最后一步的一致性断裂。第二个是被删之后怎么用正确的方式重新吸引回来，以及用错误的方式过度激进而彻底翻车。第三个是把这些失败模式做一次全面的分类归档。每一种都有精确的断裂位置和可操作的焊接方法。

你把这一章看完。以后你自己犯同样的错误时，你不会觉得"我好失败"。你会想起来：Mike 也犯过这个错。他找到断裂点了。他把焊接的方法写出来了。你知道怎么焊了。

Mike的公开检讨。一致性断裂的完整解剖这个案例在 Mike 的直播间里有一个标题：公开处刑。不是因为结果丢人。是因为每一步的操作拆解，提供了一个反面教材能达到的最高教学价值。

先看结果。女生已经在凌晨化好妆，穿好衣服，准备打车来Mike 家。她在电话里说："你把你家位置发给我。"Mike 发了。

她正准备出门。这时候她问了一句几乎所有女生在第一次去男人家之前都会问的话。

"你都没见过我人，万一你不满意怎么办？"

Mike 回的是："怎么会不满意呢？我搭讪认识的，我眼睛又不瞎。"

女生沉默了三秒钟。说了一句话。

"你记错人了吧，哥们。算了算了。"

电话挂了。她把他删了。

一个已经走到收尾门口的外卖案例，在一句话之内彻底崩塌。凌晨一点四十一分。位置已经发过去了。妆化好了。鞋子穿好了。手机屏幕上显示的是她发给 Mike 的最后一条消息。"你把你家位置发我"。然后一切归零。

为什么会崩？不是 Mike 的操作有问题。他前面每一步都是对的。我们来一步步回溯他到底做对了什么。

前九步的完整复盘这个女生是 Mike 八月份在社交软件上滑到的。两个人聊了几句就加了微信。Mike 的开场很简单："嗨，我叫什么什么。"她也说了她的名字。然后 Mike 说："你下班就直接回家吗？"她说"是的。"Mike 直接发了他家的照片。这在软件外卖的语境下是正常的效率操作。他说"我还想约你小酌一下呢。收拾了一天房间。"

她回了她典型的推拉："我比较社恐，没化妆，下班就直接回家了，还要回去喂小猫。"

Mike 这时候做了一个关键动作：他没有继续推进邀约。他接了她的"猫"话题。"我看到你朋友圈的小猫了，确实很可爱。我喜欢小狗。"

为什么接这个话题？因为外卖需要两个核心元素：吸引和安全感。吸引在软件上更多靠展示面已经传递了。安全感需要你在聊天中补充。"我喜欢小狗"这句话的功能，Mike 自己后来解释得非常清楚："喜欢小狗的人能坏到哪里去呢？"不是说服她"我是好人"。是让她的杏仁核自己做出判断。一个小动作。安全感拉了一点点。

然后消息断层了。两个多月没有联系。八月份的内部群出了一些问题，Mike 忙着清理内鬼，把这个女生彻底忘了。

十一月十八号。她发了一张朋友圈。比较清纯、比较可爱的照片。Mike 在刷朋友圈的时候看到这张照片，脑子里想的是："这女生是谁？我不认识她。但她挺好看。我去跟她聊聊。"

注意这个念头。这一刻的一致性断裂的种子已经埋下了。

Mike 没有意识到自己"不认识她"这件事。不是因为她不重要所以忘了。是因为她本来就是从软件加的，没有线下见过，照片只是朋友圈里的一张模糊记忆。但他当时的脑回路是："我好像认识这个人，我想跟她聊。"

他没有在朋友圈下面点赞。没有评论。直接私聊。

"在干嘛？"

她说"在打游戏。"

从三个月死寂到窗口全开这里 Mike 做了一系列教科书级别的操作。如果你只看这一段的聊天记录，你不会想到这个人两个月后会被删。因为这段操作几乎没有废棋。

"打电话。"Mike 直接发了语音。她说"不是啊，我们都不熟。"然后配了一个哭的表情包。

Mike 在直播里问观众："你们觉得这是好反应还是坏反应？"大部分人说是坏反应。Mike 说这是好反应。因为如果她真的反感，她会直接不理你。她打了字。配了表情包。她在解释。"我不熟"加哭的表情 = "我想给你一个理由为什么现在不能，但我没有完全关上门。"这是黄灯。不是红灯。

"所以说要打电话嘛。因为那个文字聊天聊了一辈子都不会很熟。因为文字聊天没什么情绪。"Mike 发了这条语音。她在另一端听到的不只是内容。是声音里的松弛。是没有在等她"批准"的理所当然。

她说"我在打游戏啊。"把他电话挂了。

这是好反应。她在解释自己的行为。她完全可以说"不方便"然后不理他。但她选择告诉他"原因"。给原因 = 在意你的感受= 窗口存在。

Mike 说"好嘛，那你先忙。"他推开了。给她安全感。

二十几分钟后她打完游戏了。她主动发消息："不要像突然诈尸那样好吗？"

Mike 没有道歉。没有说"不好意思太冒昧了"。他把责任推回去。"你不是发了朋友圈吗？我看你发朋友圈，我才联系你的。"

这就是 Mike 一直在直播间里教的"甩锅技术"。甩锅不是为了推卸责任。甩锅是为了在女生试图把不舒适的责任归到你身上时，你把天平拉回来。她说"不要突然诈尸"。潜台词："你的行为让我不舒服了。你的错。"Mike 的回："你发了朋友圈我才联系你

的。"潜台词："你的行为引发了我的行为。不是我的错。"她愣了一下。然后说："哦，我才想起来。"

这个回合极其关键。Mike 没有踩进她的框架。他建立了自己的框架：我来找你，是因为你给了我信号。不是我闲得没事干。

之后是一系列的推拉。她发"不熟"。Mike 说"那你不想认识就算了"。她发"你一直在打游戏"。Mike 说"我每次给你打电话你永远在玩游戏"。她发"不熟"。Mike 旁边的学员在直播弹幕里给出了标准回："是你不想熟吧？"Mike 认可了这个回复的精髓：不是你自己把自己放在低位等女生来"熟"。是你指出来：你不主动找我，你怎么熟？

凌晨十二点。她发了一张她的猫的照片。

"从此刻开始，攻守异形。"Mike 在直播间里说了这句话。

窗口出现了。不是因为她发了一张猫的照片。是因为她在没有收到任何新消息的情况下，主动找话题了。她开始填补沉默。

开始维持这段对话。她从一个"被追者"变成了"关系的维护者"。这是所有窗口识别里最重要的信号：她开始怕你不理她了。

分钟电话。吸引和安全感的双重拉满有了窗口之后，Mike 再次要求打电话。这一次她接了。通话时长：54分钟。

这通电话的内容 Mike 没有完整公开。但他给了关键信息：不是建立吸引。是强化安全感。吸引在前面的文字博弈中已经拿下了。她愿意接这通 54 分钟的电话本身就是吸引力的证明。电话

的作用是弥补文字无法传递的东西。声音、节奏、情绪、真实的"他就在电话另一端呼吸"的感觉。

"我跟你们不一样。你们可能发一条消息要犹豫半天。我从来不会。我一拍脑袋就发。我电话能力太强了。我的每一次电话都是一种小型约会。"Mike 在直播里说了这段话。不是吹嘘。是他的操作逻辑：电话不是用来"聊内容"的。电话是用来让女生感受"跟你在一起是什么感觉"的。

54分钟后。她主动问："你把你家位置发我。"她准备出门了。凌晨。面没见过。纯靠两个月前的社交软件匹配 + 一小时不到的聊天 + 54分钟电话。她就要来他家了。这是外卖方法里接近满分的执行。

一句话。前功尽弃"你都没见过我人。万一你不满意怎么办？"

她问这句话的时候，已经在准备出门了。妆化好了。位置收到了。这句话不是要答案。这句话是在要最后的安全感确认。她在说："我现在在做一件很有风险的事情。我需要你告诉我：这个风险是可管理的。"

Mike 的回答应该是：承认风险存在，但给出一个她能接受的理由。比如"你说得对，我确实没见过你。但聊了这么久我觉得我们挺契合的。万一不满意，你随时可以走。"

但 Mike 的脑子里，他是搭讪认识的这个女生。在搭讪的逻辑里，"没见过"这个问题不存在。他亲眼见过她。所以他脱口而出："我搭讪认识的，怎么会不满意呢？我眼睛又不瞎。"

然后所有东西崩塌了。

女生沉默了三秒。这三秒足够她的大脑完成全部计算：他说他搭讪认识我。我们不是搭讪认识的。我们是社交软件认识的。

他没有见过我。他以为他见过我。他搞混了。他根本不知道我是谁。

"你记错人了吧，哥们。算了算了。"

电话挂了。

一致性断裂。不是因为你说了什么不该说的。是因为你的现实感和她的现实感之间出现了一道裂缝。她从这个裂缝里看到了一个让她不安的真相：你连她是谁都搞不清楚。你的"不满意我眼睛又不瞎"这句话，在她听来不是自信，是糊涂。你不满意又怎样？你根本没见过我。

Mike 自己也说了："一致性断裂是游戏里最恐怖的事情。女生本来在电话里嗲嗲的，结果一瞬间变了一个人。"

复盘：哪里断了。怎么焊Mike 的复盘给出了三条精确的教训。

第一，信息来源要做好标记。如果你同时使用社交软件和线下搭讪两个获客渠道，每个女生加微信之后第一件事。不是聊天。是备注。软件/日期/关键特征。搭讪/日期/关键特征。三秒钟的动作。这案例后来直接导致 Mike 把软件都卸载了。"从那以后再也不玩软件。软件太容易了。没意思。"

第二，一致性断裂最容易发生在你以为最安全的时候。前面的每一步都对了。你觉得稳了。你一放松，说了一句在你自己的

现实感里完全合理的话。但这句话在她的现实感里完全不合理。

框架不是一个人的事情。框架是两个人共同维持的现实感。当你说了一句话让女生意识到"我们不在同一个现实里"，她的信任归零。之前所有的吸引和安全感，在这一瞬间全部作废。

第三，断裂之后怎么处理。Mike 没有放弃。他尝试了挽回。"我没记错人呀。""我压根都不知道你是谁，没见过你。"他甚至说"那你不想见算了。"能做的都做了。但窗口已经关了。她删了他。挽回失败的核心原因：他的挽回方式是继续在"搭讪认识"这个错误事实上兜圈子。他没有直接承认"我搞错了。你是软件加的。我记混了。"如果他一秒钟承认错误，也许还有机会。但他试图用下一个模糊来覆盖第一个断裂。裂缝变成了鸿沟。

"你尽力了，你就没什么好哭的。失败就失败了，总结经验再来就行。每一局都是尽力局。"

这不是鸡汤。这是 Mike 的失败案例能给你上的最后一课：失败之后，精准定位断裂点。把它录入你的操作前检查清单。下次在同样位置，你不会再断。

反思）已经详细展示了被删后重新吸引的全过程。这里结合 Mike的其他直接案例素材，从失败诊断的角度补充几个关键观察。

框架不能降。哪怕在好友验证框里。Mike 在社交软件上加了一个女生。加上微信之后，他发现朋友圈是一条横线。她没有删他。只是把朋友圈对他关掉了。

大多数男人的做法是看到了，假装没看到，继续聊天。Mike的做法是："你加了微信关朋友圈什么意思？"

这句话有几个层次。第一层：我看到了。第二层：我不舒服。第三层：我在问你。在给你解释的机会。但他没有在后面加"我可以理解""没关系"之类的缓冲词。态度是干净的。没有夹着讨好。

女生秒回。解释。转移话题。朋友圈只给熟人看。然后立刻说"你起得也太早了吧"。典型的"把对自己不利的话题摁住，然后聊别的事情"。Mike 也知道她在转移。但他不追着朋友圈打。他接了她的话题："我最近调作息调得非常成功。"

这个回合展示了 Mike 的一种精确判断力：态度要有，但不能追着打。你问了。她解释了。你再追着不放就是小家子气。点到为止。让她知道你不好糊弄。但不让她觉得你是个纠缠的人。

之后几天的聊天是一场漫长的拉锯战。Mike 要约。她说改天。Mike 说"要不你自己说个时间。"这句话比"你什么时候有空"要高一级。前者是"你主动给我方案"。后者是"我求你配合我的时间"。她没回。Mike 说"说话。"依然是高位。依然不追着她跑。

她说"我下班了。"但依然没有回"什么时间"。这是选择性回复。女人最喜欢干的事情。你问她什么时候出来。她回你"我刚下班"。回答了你没问的东西。绕开了你真正要的答案。Mike 的处理方式是：不接她的转移。引用她的上一句话。再问一遍。"你说个时间。"

最后她说了：下周一。达成契约。

但之后的执行出了问题。她临时说今天理疗累了，想改天。

Mike 坚持：我们约好了今天。他用了攻心术。"我们不是约好了今天吗？我明天有事情。"这句话的精妙在于：第一，把"爽约=不守信用"这个道德标签轻轻贴了上去。第二，用"我明天有事情"来表明他的时间是珍贵的。不是随叫随到的。她让步了。说好吧，那就今天。

然后 Mike 犯了一个精度上的错误。

他在这段舒适的博弈中太专注在"推进到见面"这个目标上，忽略了女生的舒适度一直在下降。她说"你这么没有边界感。"然后把他删了。

Mike 发的好友验证消息是："你是不是傻逼？你他妈你时间宝贵，我时间不宝贵吗？你他妈回消息快一点。我给你打电话就是因为我觉得你回消息太慢了。我的时间也很宝贵。我们电话里赶紧说明白就行。"

骂了她一顿。

五分钟之后。好友通过。

"你打文字不行吗？"她的第一句话。不是"你凭什么骂我"。不是"滚"。而是"你打文字不行吗"。这句话的语气是：好吧。算你

狠。通过了。你想说什么？

为什么骂反而有效？Mike 的解释一针见血：因为这个女生这辈子遇到的每一个男人都在舔她。她的边界被所有舔狗扩张到了银河系。你做任何在她边界之外的事情她都觉得你越界了。Mike的骂不是失去理智的报复。是告诉她：我跟你是平等的。你做了一件让我不爽的事。我就直接告诉你我不爽。你不喜欢可以不回复。但她回复了。她没见过这种男人。她好奇。

但这个故事的另一面更值得注意。如果 Mike 在舒适度下降的早期就补了一点安全感，也许根本不会走到"被删"这一步。她被删之前说的那句"你这么没有边界感"其实是一个可以被提前化解的压力预警信号。她不是在攻击 Mike。她是在说"你的态度我感受到了。我很不舒服。"这时候如果 Mike 回的不是"那你直接说干不了不就行了吗"，而是先给她一口氧气。"我不是不尊重你的时间，我是觉得我们文字聊太慢了。"。再坚持时间，她可能不会删他。

这是一个精度的教训：态度和舒适度不是二选一。是你必须同时管理两条线。 一条拉得太紧，另一条就必须放松。两条同时拉紧，就断了。
