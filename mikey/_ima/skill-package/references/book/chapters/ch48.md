# 第48章 外卖执行完整流程

第48章 外卖执行完整流程

本章金句：外卖的核心不是邀约。是让它变成多余。你要做的是把她脑子里那条"要不要去"的弧线拉到最满。

满到她必须买票。

如果你已经读完了第47章。你已经相信了一件事：外卖方法是成立的。想象力制造、便利店思维、前热后冷，这些东西你都理解了。但理解跟做到之间有一道沟。这道沟叫"具体怎么做"。

你打开微信，看着昨天搭讪收来的十几个号，脑子里冒出来的问题是：先给谁发？几点发？发什么？发了之后她不回怎么办？回了之后怎么聊到"她出门打车"这一步？

这章解决的就是这个问题。外卖方法是四段流水线。每一段有每一段的目标、工具和禁止事项。你不需要每段都做到完美。

但你需要知道每段在干什么、什么时候进下一段、什么时候停下来止损。

这四段是：前期钓饵（种下画面）→ 深夜激活（测试可出行性）→ 邀约锁定（敲定时间+获取手机号）→ 她来了之后（不犯错就行）。

四段走完，她从屏幕上的一个微信号变成了坐在你家沙发上的人。她手里可能提着一瓶没喝完的酒，脚边放着她刚从出租车

后备箱拿出来的化妆包。她来了。不是因为你求她来的，是因为她在每一个阶段都做了一个自己的选择。你只是把选项摆在了她面前。

Mike管这个叫"让她自己走进便利店"。门开着，灯亮着，货架上的东西都是真的。本章就是告诉你：门怎么开、灯怎么亮、货架怎么摆。

阶段一：前期钓饵前期钓饵的目标不是在微信上把她聊到上头。是种下一个画面。这个画面不需要很惊艳。"我跟这个男人在一起可能会很有意思"。就够了。因为你种画面的时间窗口没有想象中那么短。Mike在南京白富美案例里，从加微信到女生出现在他家楼下只用了几个小时的JK高中妹用了三天。第47章的Tinder王千里送炮案例：案例用了一个月。时间跨度不一样，但第一段做的事情是一样的：让她知道你是谁，同时在她脑子里留下一个未完的画面。画面种下去之后，她自己会浇水。

第一步：信息交换。搞清楚两件事加到微信之后，前五条消息只做一件事：搞清楚两个基本信息。

第一：她是不是来旅游的。 这是物流判断。Mike在直播20里反复讲了一个被大多数人忽略的操作："我们加到女生的微信，在成都这种旅游城市，我们应该马上判断出这个女生她到底是不是来旅游的。"这个判断直接决定你的时间窗口。如果她明天下午飞

走，你的外卖窗口就是今晚。她如果是本地常住的，窗口可以拉长到几天甚至一周。不搞清楚物流信息，你可能会在跟她聊了三天之后才知道她昨天已经上飞机了。

具体怎么问？Mike在直播20里给了示范。"你是不是来这边旅游的？"一句话。不用绕。不用先聊十分钟再"顺便问一句"。绕弯子的结果是你在她告诉你"明天飞"之前已经投入了大量时间。

这些时间全浪费了。直接问。她的回答决定了你后面几小时是加速还是从容。

Mike对此的补充是："当面没问。她当时在忙自己的事情。但微信上不一样，她有充足时间回答。"

第二：她的基本状态。 哪儿人、做什么、今晚什么安排。这些信息交换不是"查户口"。你在正常社交中认识任何一个人都会做这件事。不做这件事直接越到暧昧或邀约，女生会觉得"这个男的压根不想了解我，就想约我出去"。不要在开局就被她归类为"浮躁的人"。

💬Mike 说："加到女生微信第一件事就是基本信息交换。很多兄弟一加到女生微信第一句话就是'我们一起约杯咖啡'。这很下头。现在太多男人很浮躁，加到女生就想邀约。我要是妹子就觉得你这个男的压根不想了解我，就想直接约我见面。我为什么要跟你出来？我吃饱了撑的，我跟我闺蜜逛街不行吗？"

信息交换还有一个隐蔽功能：筛选。一个回你"嗯""哦""好的"的女生，你不需要花时间走剩下的三段流水线。她被放进"长

期养着"的文件夹。你继续发朋友圈，她可能有一天因为某张照片从红灯变绿灯。一个回你"我明天晚上回南京""最近在忙着搬家""我跟我闺蜜在这边逛街好无聊"的女生。她给你了素材，你可以往下走了。

这里有个细节很多人容易搞混。筛选≠放弃。红灯女不删。

Mike在。"你不需要删掉红灯女生。放在朋友圈里养着。因为她以后会有需求。而且随着你不断自我提升、优化朋友圈、传递更多个性样本，她也许会主动联系你。"他本人在案例里就经历了这种反转：一个之前爱答不理的红灯女，因为他发了一张朋友圈照片，主动私信他、两天后就在他家了。红灯变绿灯的核心机制是时间+朋友圈更新。你不必在红灯身上投入聊天时间，但也不要把她从通讯录里删掉。删掉=关闭了未来的可能性。

第二步：留下一个画面。不是一句调情前期的聊天不需要撩。不需要调情。不需要幽默。需要的是：让你说的话能在她脑子里变成一幅画。Mike的直播20里有一个很经典的例子。女生说"下雨了"。Mike回的不是"注意保暖"或者"下雨天最适合窝在被窝里看电影"。他回的是："我可以叫司机来接你。我们喝酒。"这句话里有画面：一辆车停在她躲雨的地方，她被接到一个温暖的地方，桌上有一杯喝的。她不用思考"我该不该去"。她已经在脑子里看到自己坐进那辆车了。

画面的构成要素只有三个：动作（叫司机来接你）+ 地点暗示（我们喝酒的地方）+ 最小社交压力（喝酒，不是"来我家"）。这三个要素缺一个都不成立。缺动作她就不知道要干嘛。

缺地点暗示她就觉得要去一个未知的地方。不安全感触发。把地

点说得太明确。"来我家喝酒"。她会在这一步就触发ASD。而"我们喝酒"足够模糊，她可以脑补这个场景是酒吧、是你朋友家、是你客厅。她脑补的任何版本都比你说出来的更有说服力。

直播23里Mike给JK高中妹留下了什么画面？"好期待。"就三个字。女生发来她P了两张的照片，Mike回了句"好期待"然后发了一个爱心表情包。他没说"好期待见你"。他没说"好期待看你穿JK的样子"。他说"好期待"。这句话什么都没承诺，但女生的大脑已经开始工作了：他在期待什么？他在期待我发更多照片？他在期待见到我？这些她自己完成的填空，比你任何一句话都有价值。

这里需要拆开来看"画面"的两种递送方式。第一种是直接画面。"我帮你叫车，我们喝酒。"你直接把一个具体的场景植入她的脑子。第二种是引导画面。"好期待。"你只给了半幅画，剩下的半幅她自己填。两种方式适用不同场景。直接画面适用于你已经拿到了足够的窗口。她给你发了私密照、她主动问你在干嘛、她说了"我好无聊"。这时候直接丢一个具体的画面是最有效的。

引导画面适用于窗口还没有完全打开。她不冷但也不热。你不能直接丢"来喝酒"，因为太早了。但你丢"好期待"这种模糊钩子，进可攻退可守：她如果接了就打开窗口，她如果不接你也不丢人。

💬Mike 说："画面感很足。你不需要把生活过得精彩才能聊得精彩。你只需要把你本来就在过的生活生动地形容出来。你形容出来，本质上就是一个很有趣的事情。"（千里送炮案例：案例）

直播20里还有一个更高级的画面植入方式。Mike发给南京白富美的冰箱图和他那句"把厨房改成调酒台"。这张图本身没有任何邀请。但它传递了一个完整的信息包：我家里有酒、我喜欢招待人、我这个人讲究但不装。女生收到这张图之后，不需要Mike再说什么。她自己会想："他家里是这个样子的。""他调酒是什么样子？""我能不能尝一杯？"一张图激发了一连串的脑补。这就是外卖图的价值。它不是一张装饰性的照片，它是一个开放式问题：你想不想来看看？

第三步：停止聊。发朋友圈。等着前期钓饵的最后一件事很多人不做：在信息交换完成、第一个画面种下去之后，停下来。不追消息。不问她今天吃了什么。

不发表情包维持热度。停下来之后去做一件事：发一条朋友圈。

不是精修的自拍。不是"今天打卡了XX网红店"。是一条能让看到的人感觉到"这个人在过自己的生活"的日常碎片。你冰箱里的酒。你在傍晚看到的天空。你收拾到一半的房间。这些东西本身不露脸不炫富，但它们是她脑补你的拼图碎片。Mike管这些叫"外卖图"。他当年住在一个"只有20平的小隔间"里，拿得出手的只有一台冰箱的照片。就这张冰箱图。里面摆了酒。他在无数个外卖案例里用过。

💬Mike 说："这是我唯一拿得出手的电器。没办法，穷人泡妞就要有穷人的方法。不是说穷人泡不到妞。方法对了，你依然能泡到妞。就跟你穷的时候你用特惠快车泡妞，和你富的时候你用豪华车泡妞是一个道理。"

朋友圈的频率控制很重要。一天发三条=你在刷存在感。一个星期不更新=她忘了你。Mike在。不是每天都发，但每周至少有一到两条有内容的东西。"我会继续发我的朋友圈。继续跟别的女生互动。时不时发一些朋友圈钓鱼。你会发现一些红灯可能会因为你朋友圈某些照片直接变成绿灯。"朋友圈是你的24小时营业招牌。你不需要站在门口拉客，但招牌得亮着。

她说你帅、有钱、幽默。这些来自朋友圈的信息无法被证伪。你的朋友圈不是用来"炫耀"的，是用来"给线索"的。线索越私人，她的脑补越深入。

执行完前期钓饵三步之后，你的状态应该是一个"没有追任何人"的状态。你留了线索。你亮着灯。你不需要站在门口拉客。

Mike在直播20里的状态就是一个很好的参照：他发完冰箱图、发完调酒台之后，该干嘛干嘛。他在兰桂坊带学员搭讪。他没有盯着手机等她的回复。因为他当晚不管她来不来，都有其他结果。

这个"不差你一个"的心态不是装出来的，是有底气支撑的。

阶段二：深夜激活前期钓饵完成了两件事：她知道了你是谁，她脑子里有一个关于你的模糊画面。但画面不会自动变成行动。你需要激活。

激活的意思不是"约她出来"。激活的意思是：在她冲动值最高的时间点，用一个低成本的互动去测试她的可出行性。如果她给出了可以出行的信号，进入阶段三。如果她没给，回到阶段一继续种画面，或者是止损。

激活时间：22:00到凌晨2:00Mike在多次直播中反复提到这个窗口。"晚上十点到凌晨两点是女生冲动值最高的时段。白天她是社会人。上班、社交、遵守规则。晚上十点之后，她的社交媒体时间开始，她的情感需求开始占据主导。"（第47章）如果她还在外面。在酒吧、在朋友家、在一个她已经待腻了的饭局上。她的可出行性在这个窗口里达到峰值。

晚上十点之后还有一个结构变化：女生的社交义务减少。白天她跟闺蜜、同事在一起，维持社交人设。十点之后闺蜜回家了、同事散了、场子进入后半段。她可以在凌晨一点打车去一个白天绝对不会去的地址. 白天绑住她的东西松开了。

选择这个时间的另一个原因是：深夜的消息本身就是一种"我在想你"的非语言信号。不需要你真的说"我在想你"。她收到的第一条深夜消息就已经知道了一件事：你在这个时候想到她了。她· · ·

不用任何文字就收到了这个信号。这是深夜激活比白天激活多出来的优势。

激活内容：一条消息。不是一堆消息激活消息只需要一条。这条消息的内容不浪漫。不撩。不应该让她觉得你在约她。它只需要做到一件事：让她回你。

Mike在直播20里的激活消息是典型的正确示范。女生前一天已经跟他聊过，当天他发过去的是一张冰箱图。图发过去之后女生回了一个小猫表情包。Mike接着发了一张调酒台的照片。"我今天今后把厨房改成调酒台。"然后女生开始主动了。"她一会出门。""OK呀。""你到时候来找我。"

你看这一轮激活的节奏：Mike发了图 → 她回了表情包 →Mike追加了一张图（增加了画面的丰富度）→ 她主动说她会出门。他没有说"你在干嘛""你想来找我吗""你今晚有没有空"。他的图替他完成了这三件事。图是"钩子"，钩子放下去之后鱼咬不咬，不取决于你怎么拉线，取决于她饿不饿。

直播23的激活要更直接一些。JK高中妹凌晨给Mike发消息问"你几点睡觉"。Mike回了"我睡醒喽"到第二天早上，然后发"我狂做梦"，想看电影，然后发了一张他收拾干净的房间照片。"我的妈，收拾的这么干净。"女生回了这句话之后，窗口已经完全打开了。

💬Mike 说："收拾房间意味着什么？这个男人爱干净，他有安全感。传递的个性样本。为后来我外卖她到家里提供了一个铺垫。我跟这个妹子聊天，没有废话，一环扣一环。"

激活消息有三种经典范本。范本一：图片钩子。 你正在做什么。你家的某个角落、你刚买的一瓶酒、你在傍晚拍到的天空。

不发文字，只发图。让她主动问"这是哪"或者发一个表情包。她主动的那一刻，她就已经比你多发了一条。比你多发一条=她多投了一次资。范本二：画面描述。 不是"你在干嘛"，而是"我在XXX"。你在看一部老电影。你在整理冰箱。你在试着调一种新的酒但是失败了。这些描述让她的脑子跟你的生活同步运转，而不是让她感觉你在查她的岗。范本三：钩子问题。 "你那天说的那个店叫什么来着？"这个问题给她一个低的回复门槛。她只需要说一个名字。但这个名字一旦说出来，你们的对话就自然而然地续上了。钩子问题的核心是：你问的事是她上次主动告诉你的。这证明你记住了她。她收到了这个信号。

三种范本选一种用。不要混着用。不要发一张图又追问"你在干嘛"。图已经替你问了。多发一条就多一次索求。

判断信号：她主动就是绿灯激活之后你需要做一个判断。只有一个判断标准：她有没有主动。

主动的定义是：她发的内容超出了"回应你"的范围。她主动跟你分享动态（"终于拍完了""我跟我朋友待会出门""好无聊啊这个局"）。她主动问你问题（"你在干嘛""你几点睡""你家在哪个区"）。她给你发了一张你没有要的照片（食物、自拍、她周围的场景）。以上任何一种=绿灯。你可以进入阶段三。

直播20里有一个经典的信号捕捉。Mike发完冰箱图之后，女生说"她一会出门"。然后Mike进一步丢钩子"你到时候来找我"。

女生回了"OK呀"。这个"OK呀"就是绿灯。"OK"是一回事，"OK呀"是另一回事。多了一个"呀"，语气从"知道了"变成了"有点期待"。Mike能捕捉到这个字级别的差异，是因为他在这个游戏里的经验足够深。你不必一开始就这么敏感。但你需要知道一件事：绿不是"她答应来"的时候才亮的。绿在"她开始主动跟你多说话"的时候就亮了。

如果她的回应始终维持在"礼貌回复"层面。你问她答，不回问，不扩展。说明她此刻的可出行性是冰点。不要硬推。回到阶段一，继续种画面。再过几天再测一次。

这里需要讲一个反直觉的认知：深夜不一定要当晚拿下。你激活她的时候她可能真的出不来。她在家人旁边、她手机快没电了、她今天晚上确实有不可推的事情。但如果你在激活中展现了正确的状态。不猴急、不翻脸、不道歉。她对你的印象不是"今晚没约成的男人"，而是"那个深夜跟我聊天让我觉得有意思的男人"。这个印象会在下一次激活时帮你省掉一半的预热工作。

Mike在直播24里有一个很实际的心态建议。"我觉得这个女生能成了，我们就不聊了。如果她不来，没关系。你千万不要去舔、去挽回、去问她为什么不来。你就继续发你的朋友圈，继续

过你的生活。她之后会看到的。"这种心态的本质是：你不是在经营一段一对一的关系。你是在经营一个经常更新货架的便利店。

这个人今天没进店，不代表她明天不进。你要做的不是把她拉回来，是把店里的灯继续亮着。

阶段三：邀约锁定她给了绿灯。你进入了整个外卖流程中最关键的一段。这一段的成败决定了她今天是"你家的访客"还是"微信上的一个聊天记录"。邀约锁定有三个硬指标：时间必须精确、地点必须是你家、手机号必须拿到。

第四段：立规矩。不许割。 这是通电话里最有态度的一刻。"你不能割我。你知道吗？"这句话不是卑微。是边界。Mike不是在求她"一定要来"。他在告诉她：你答应了就得来。在打完电话之后，他在微信上又发了一条："今晚一点三十，不许搁老子。"女生回："知道了。"

这个"知道了"的价值不是她答应了来。她之前就答应了。是她在接受你的规矩。她从来的之前的"我试试看"变成了"我答应了"。从试探变成承诺。打完电话后Mike又追加了一个步骤：在微信上发了一条确认。"今晚一点三十，不许割我哦。"但这句确认里他加了一个"哦"和一个表情包。前面是规矩（"不许割"），后面是台阶（"哦"+表情包）。规矩让她的承诺被锁定。台阶让她在被锁定的时候不觉得被压迫。这个"规矩+台阶"的组合，是Mike框架管理中最高频出现的模式之一。

需要处理复杂反对意见。 她有gay蜜朋友、她不知道几点能溜、她怕尴尬、她担心喝完酒回不去。这些反对意见在文字里需要你花二十分钟打字来逐一化解。电话里只需要两轮对话。因为电话里的每一轮对话都是实时博弈，你可以根据她的语气判断她是真的担心还是在客气、是真的有障碍还是在犹豫。文字做不到这个层级的判断。

不需要打电话的情况：她是一个绿灯。她在微信上直接说"几点？地址发我"。这种时候打电话反而多余。她已经在心里完成了

电话邀约之后的禁忌打完电话锁定了时间和承诺之后，不要继续发文字消息去"确认"。你在电话里已经听到了她的声音、得到了她的承诺。现在再发"一定要来哦"等于自己拆掉自己的框架。你亲手把她刚做出来的承诺重新变成了"你还需要说服她"的未定事项。你在用不安全感换安全感。结果是两个都没了。

电话邀约最大的陷阱就是：你打电话之前怕的是"她不同意"。打完电话之后怕的是"她同意了但可能会鸽"。这两个"怕"的来源是同一个。你没有框架。框架不是对方给你的，是你自己有没有把自己当真。
