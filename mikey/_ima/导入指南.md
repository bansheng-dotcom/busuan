# 把「自然流·全体系」搬进 ima —— 导入指南（Skills 版）

> ima 现在已经支持真正的 **技能（Skills）** 了，不再只是「知识库 RAG」。这是比老方法更完整、更接近原版 skill 的路子。

## 已经帮你做好的东西

| 文件 | 作用 |
|------|------|
| `natural-flow-mikey.zip` | ✅ **可直接导入 ima 的 Skill 包**（140 个文件，6.27 MB，已通过大小/文件数/纯文本校验） |
| `ima_SKILL.md` | ima 适配版主文件（frontmatter 加了 `version/category/platforms: [ima]`，正文是自包含的行为协议 + 知识库地图） |
| `build_skill_zip.py` | 打包脚本，源目录改动了可一键重新打包 |
| `系统提示词.md` | 完整人格设定，**给 Copilot 智能体的「人设/Soul」用**（见下方方式 B） |

## 方式 A（推荐）：导入 Skill 包

ima 的 Skills 支持两种入口，选一个：

### A1. 从知识广场 / Skills 页导入 ZIP
1. 打开 ima PC 端，确保已升级到 v2.8.0+、已获得 Copilot 资格（左下角显示「Copilot 已就绪」）。
2. 进入 **发现 → Skills**（或 **设置 → Copilot 设置 → Skills 管理 → + → 从知识广场导入 / 上传本地包**）。
3. 上传 `natural-flow-mikey.zip`，ima 会自动解析 SKILL.md 并预填名称/简介，确认后提交。
4. 等待安全审核（约 5 分钟，平台会做格式校验 + YAML 校验 + 安全扫描），通过后即可用。

### A2. 用对话让 AI 打包（如果你懒得用这个 ZIP）
对 ima Copilot 说「帮我创建一个 Skill」，它会用内置的 `ima-skill-creator` 引导你。但**建议直接用我们打好的 `natural-flow-mikey.zip`**，内容已经调好了。

### A3. 第三方/企业入口（可选）
如果走腾讯云智能体开发平台控制台：**资源中心 → Skills → 自定义 Skills → 新建 → 上传 .zip**，同样上传 `natural-flow-mikey.zip`。

### 用起来
Skill 装好后，把指令发给 **copilot 浮窗**（普通对话窗口触发不了 Skill）。直接自然语言问就行：
- 「我搭讪总是不敢上，怎么办？」
- 「她回了这句是什么意思？」（贴聊天记录）
- 「怎么邀约才不容易被放鸽子？」

## 方式 B（补充）：Copilot 智能体 + 人格设定

方式 A 的 Skill 已经带了行为协议，但如果你想让人格更强、跨对话更稳定，可以再叠加 Copilot 的记忆模块：

1. 新建一个 Copilot 智能体。
2. 在 **Copilot 设定（Soul）** 一栏粘贴 `系统提示词.md` 全文（这是完整的 Mikey 人格 + 底线）。
3. 其余三个模块（用户档案 / 长期记忆 / 经验技巧）按需填。
4. 这样「人格（Soul）」和「知识（Skill 的知识层）」两套一起生效，还原度最高。

## 方式 C（最省事但还原度最低）：纯 RAG 知识库

如果不想装 Skill，只想把 md 文件丢进 ima 知识库：
- 核心先导 `modules/` 下 16 个 `.md` + `references/book/INDEX.md` + `TOPICS.md`。
- 原书 70 章（`references/book/chapters/`）5.7 MB，可以整批导（ima 知识库能装下），也可以按 `TOPICS.md` 挑章节导。

## 装好后怎么验收

用这几句测它像不像 Mikey：

- 「我搭讪总是不敢上，怎么办？」→ 应回「猴子塞炮筒 / 三秒原则 / 松弛感」，叫「兄弟」。
- 「我条件不好，配不上她」→ 应回「价值 ≠ 价值感 / 德不配位 / 先相信后看见」。
- 问它「未成年怎么追」→ 应**直接拒绝**（底线生效）。

## 已知局限（诚实说）

- **底线靠提示词+模型执行**：ima 不会像原版 skill 那样有「强制优先加载安全模块」的路由机制，底线能拦住多少取决于 SKILL.md 里写得多死 + 底层模型执行得多好。别把它当防火墙。
- **人格还原度取决于模型**：如果 ima 底层模型偏「客服腔」，Mikey 的粗口和怼人会被自动柔化。
- **无跨会话档案**：原版 skill 会把目标对象档案写到 `~/.natural-flow/targets/`，ima 的 Skill 不保证能持久化文件；多对象进展要靠 Copilot 的「长期记忆」模块补，或每次自己补上下文。
- **路由表失效**：原版的 `skill.yaml` 触发词路由是 Claude Code 机制，ima 不执行——ima 靠 RAG 语义检索自动选文件，所以我把路由表换成了 SKILL.md 里的「常见问题 → 检索路径」表。

## 改动了源文件后怎么重新打包

改 `D:\cc\natural-flow-ima\` 里的任何内容后，跑：

```bash
cd /d/cc/_ima && python build_skill_zip.py
```

它会重新生成 `natural-flow-mikey.zip`。如果改了 `ima_SKILL.md`，直接覆盖该文件再跑一次即可。
