# 阶段一：展示面

## 术 · 展示面建设（ch14）

- **展示面 = 简历 = 产品包装 = 个人IP**。「你连一份像样的简历都拿不出来，业务能力再强，人家也不会给你面试机会。」
- **两道防火墙**：① 社交软件（第一道，生死攸关——99%女人只看照片）；② 搭讪后朋友圈（第二道，消除戒备、建立二次吸引）。
- **安全感机制**：女人被搭讪时大脑想的不是「他帅不帅」，是「他是不是威胁」。分开后安全感归零，只能通过朋友圈做「背景调查」。**没有信息=未知=不投资=不回消息**。
- **一致性**：展示面目的是展示「你真实最好的一面」，不是「装有钱人」。跑车照片+碎屏手机=0.3秒被识破=信誉归零。**假展示面比没展示面更致命**（女人社交直觉是50个男人的总和）。
- **inner game 与 out game 兼备**：「男人最吃香的是六边形战士」——内核、穿搭、展示面、聊天、约会、社交直觉，不能某几项是0。
- **外在影响内在**：你穿皱巴巴T恤出门搭讪，内在状态不会好。收拾好看了，推门出去那一刻精神已经不一样了。

## 术 · 朋友圈发布技术手册（ch15）

- **一组不超过一张个人照**：多=暴露短板。女人取你最低的那张作为真实水平。**「在精不在多。」**
- **个人照"不刻意"**：传递「平时就长这样，被抓拍到了」，不是「拍了五小时」。男模风（红酒杯/暗调/POSE）=庸脂俗粉=只吸引低质量女生。高质量女生看生活感。
- **五种内容类型**：旅行（最高价值，资源+时间+不被困）、运动（自律健康）、工作（暗示事业不说明）、美食（品位不是流水账）、宠物（责任感=安全感）。
- **混搭原则**：个人照是点缀不是主力。十条朋友圈个人照不超五六条，否则=「孔雀开屏」。
- **头像用动漫不用本人**：本人照拍不好=自恋+条件不匹配=低价值。动漫头像=「我不需要用脸证明什么」的松弛。头像任务是**不给女人拒绝你的理由**，不是加分。
- **定位少即是多**：照片已说明在哪就不加定位。每个目的地只加一次。
- **第一人称视角**：拍你眼睛看出去的东西（牵狗拍狗和手，不是别人拍你跟狗）。第一人称=「我在体验」，第三人称=「我在展示」。
- **发圈禁忌**：不发人生感悟（爹味重）、不转发文章（借别人的嘴）、不刷屏、不过度修图（美颜=不接纳自己=低自尊）、不抱怨（=没掌控感）、不发深夜鸡汤（=孤独）、不发政治争议。
- **军火库**：预存照片。每次出门拍三张存着，要发时从三十张里从容选，不临时翻相册将就。

## 术 · 审美（ch16）

- **人是无法理解认知以外的东西的**。你觉得帅的照片，女人眼里可能六分。「金锄头谬误」：农民以为皇帝用金锄头锄地。你只看过自己拍的照片，没有坐标系。
- **Instagram 基准线**：先摄入足够多的「好」，才能识别出自己的「不好」。看多了好照片，你相册里不好的照片自己会刺眼。
- **网感 = 不经意**：苹果原相机不做过度机内处理（噪点留着、该暗暗、该柔柔），画面像人眼看到的不是算法算出来的。**氛围大于清晰度**（人类看照片不看像素，看光线情绪环境）。单反太清晰=刻意=孔雀开屏；安卓 AI 增强=看起来被优化过=网感的反面。
- **照片五元素拆解**（逐项自审不靠感觉）：① 光线（有方向感、脸有立体感）；② 角度（相机略高于眼、身体侧身）；③ 背景（像你真的会去的地方，不是酒店大堂）；④ 穿搭（和场景匹配）；⑤ 表情（做自己，不刻意不笑也不刻意笑，不看镜头）。
- **双账号策略**：Game 号（只放筛选过的内容，零污染）+ 私人号（随便发，零约束）。「不是虚伪，是在接受规则的前提下给真实人格留一个不需要被审核的空间。」

## 技术 · 展示面操作

1. **Instagram 图库对比法**：把你照片 P 进网红图库，违和=不合格，严丝合缝=达标。绕开自我评价系统，让第三方当审判官。
2. **照片质感在氛围不在分辨率**：苹果原相机，后期只微调曝光色温，不碰滤镜。「用得越少越像真的。」
3. **帅照 + 价值照组合**：覆盖不同 RAS 的女生。

# 阶段二：资源获取

## 术 · 资源获取三通道（ch17）

- **三通道必须并行**：社交软件（量）、线下搭讪（质）、多人聚会（效率）。单通道容错率是零。
- **社交软件唯一作用 = 加微信**（云搭讪）。不要在软件上聊天、建立感情、给认可。
- **线下搭讪 = 所见即所得**：照片和本人能差两个身位，搭讪先看后行动。
- **多人聚会 = 自带信任背书**：高价值朋友在你开口前把价值垫好了。致命前提：你朋友不能是傻逼（他会掉你价值）。

## 技术 · 资源获取操作

1. **工业化 SOP（Tinder王公式）**：加好友→模糊邀约+「你现在在干嘛」→她回了就约。微信上「在干嘛-分享生活-在干嘛」无限循环。约会时 QWE 循环（提问-给反馈-再提问）。
2. **守株待兔**：确认审美偏好→反向推导这类女生常出没的地方→把自己送过去（买杯咖啡）→等。模特经纪公司楼下、健身房旁轻食店、独立书店咖啡区。
3. **拿到就撤**：搭讪加微信后立刻走，不在原地发展。「趁你的价值还没被磨光之前，保持神秘感。」
4. **先批量后转化**：一天搭十个先攒着，量大就不会对某一个人过度投资。
5. **僚机三原则**：不抢女人、一人带领、物流互助。
6. **融入生活**：「为了搭讪上街消耗时间成本。买瓶水遇到正妹顺手搭，那时你的状态才是最 real 的。」

# 阶段三：网聊

## 术 · 网聊基本认知（ch19）

- **网聊唯一目标 = 见面**。线上每一句话不指向见面就删。「见面不行，线上聊得再花也拿不到结果。你不可能赛博作案。」
- **吸引靠浅沟通不靠表沟通**：文字（表沟通）只能做门票，浅沟通（线下状态）才是比赛。**线上的人格是纸板，线下的人格是一栋楼。**
- **需求感靠分母稀释，不靠意志力忍**：对某女生上头了，起心动念先加三个妹子。注意力稀释后回复节奏自然松弛。「意志力不是可靠策略。」
- **线上不过度暧昧**：暧昧会让她「提前得到你」。线上暧昧浓度越高，见面落差越大。**线上让她好奇但不让她确认**。
- **开黄腔是大忌**：网聊阶段不聊性、不设例外（没吸引时聊性=性骚扰）。三阶段：网聊不聊→约会看吸引（话题自己走到那里）→私密空间直接升级。「你不是在约炮，你是在约会。」
- **二八原则**：80% 消息随便回（会说废话的正常人），20% 关键节点（废测/邀约被推/身份交换）认真回。「跟朋友怎么聊就怎么跟她聊。」

## 术 · 网聊人设（ch18）

- **「在这个网络世界里，你可以成为任何人。」** 不是造假，是换语言框架描述真实身份。
- **人设构建三步**：① 提炼产业级标签（外卖员=物流运输，修图的=IP编导，厨师=餐饮行业）；② 笼统化留白（高级感定调、笼统化留白，让她自己脑补）；③ 人设与朋友圈闭环（每一句话都能在朋友圈找到侧证）。
- **转场技术**：被追问细节时不纠缠不解释，摁住话题切到新频道。「你解释得越多，她越在帮你做备调。」
- **灵活但不混乱**：不同场景切换侧面，核心事实不变。

## 术 · 聊天的底层逻辑（ch21）

- **聊天的目的 = 让对方喜欢你**（不是邀约/升级/情绪价值）。「她喜欢你，你回哈哈都是情绪价值。」
- **话术话题内容不具备吸引力**，浅沟通才是。「你用别人的话术，你在装一个不是你的人。」
- **引导投资 = 核心机制**：让女人自己逆向合理化「我为什么花这么多时间在他身上？因为我喜欢他」。胜过你写一万字小作文。
- **投资类型**：话题、时间、表情包、反撩。
- **投资信号**：她开始问你问题、发无信息量消息（表情包/「好无聊」）、深夜还在聊、跟你讲烦恼。
- **男人的基因是繁衍，女人的基因是筛选**：她的忽冷忽热、废测、总结性回复都是筛选行为。
- **解决核心问题不解决次要问题**：别问「这句话怎么回」，问「我的框架是什么样」。
- **强行为线索三大要素**：高位、引导投资、见面。
- **前提加意图**：「我忙完了，我们约杯东西」=高位；「我都有空，见个面吧」=低位。

## 术 · 垂直聊天法（ch22）

**核心公式：聊她，聊我，聊我们。** 三个维度像齿轮咬在一起转。

| 维度 | 本质 | 操作 | 上限 |
|------|------|------|------|
| **聊她** | 建立参与感+提供跳板 | 「在干嘛」 | 一次最多两次 |
| **聊我** | 传递存在感（不是高价值） | 发当下生活照片 | 胡说八道 |
| **聊我们** | 导向见面不暴露需求感 | 模糊邀约/共同点/角色扮演 | 撑死两次最好一次 |

- **聊她**：她的话只是跳板，踩一脚弹到自己这边。连问五个=查户口=需求感。
- **聊我**：① 一定配图（建「聊天军火库」）；② 胡说八道的松弛（「我在拉屎」传递的不是事实是松弛）；③ 图片和人设匹配。开黄腔是大忌。
- **聊我们**：模糊邀约（「下次一起约个伴」）、共同点连接（「我们吃的东西都一样」）、角色扮演（「像地下党」）。
- **三个比例规则**：聊我们不超三次、聊她不超两三个、一句话不超三回合。**聊得广比聊得深重要一百倍**。
- **三短一长**：70%短+30%长=男神框架。
- **一句逗逼一句正经**：反差让她猜不透。
- **适当撤离**：每聊一两套循环消失一两小时（前提是你真的有事做）。

## 技术 · 网聊操作

1. **具体邀约公式**：时间+地点+人物+「不许放鸽子」。「后天晚上七点，某某酒吧见，一起喝一杯，不许放鸽子。」
2. **网聊三大禁忌**：需求感、过度热情、装逼。
3. **收尾后规则切换**：聊我90%、聊我们10%、聊她0%。
4. **阿尔法毒**：女生不回就永远不发=自我审查。「想发就发，发了不检查。」
5. **平衡法**：上头就加三个妹子稀释需求感。
6. **两改封顶**：每条消息最多改两次，第三次直接发。
7. **清空话术截图**：删掉所有「女生说XX怎么回」的截图。

## 术 · 网聊强行为线索（直播52）

**核心：网聊也有强行为线索——你每发一条消息，不是在建立高位、就是在引导投资、就是在为见面做铺垫，三者二不沾=掉位置。**

- **高位**：一上来低位（表白/夸她/讨好），女生会审视你、装逼、权衡利弊（今晚能见非控你到下周）。「有价值的男人不会来讨好，你一讨好她就认定你没价值，把你当地主家的傻儿子爆金币。」
- **前提 + 意图 = 高位**：「我明天打完球正好没事，可以见一面」>「我明天没事，我们见面吧」。前者有前提条件，位置高。表达意图永远是「前提+意图」，不是光秃秃的意图。
- **散漫性思维（引导投资的核心）**：一棵树→鸟→自由→精神追求→存在主义。女生说「吃蛋炒饭」你只能接「好不好吃」=没散漫性思维。练习：从任何一个词自由联想，直到能拐到「见面/暧昧」。
- **引导投资的四种类型**：话题、情绪、预期、目的。女生问你「你在干嘛」→「刚睡醒，你呢」→「一般睡醒想去喝咖啡，今天挺无聊只有一个人，没事的话一起喝点东西」——**因为是她先问的，所以你引导到见面零需求感**。
- **识别假兴趣**：软件上一上来就热情奔放给兴趣的女生，大概率对所有男人都这样。她给「那我们快结婚吧」这种假兴趣，你别接（「那我们快结婚吧」=扑上去=掉位置），用「可惜我们在深圳，不在拉斯维加斯」推开、筛选，直到筛出真窗口。
- **假定时间限制（网聊版）**：「如果我说我明天就走，你今晚会见吗？」——制造紧迫感，跟搭讪时「我朋友在那边等我」相通。你认真回「我待一年」，她就会想「下个月见也行」。
- **用感性解决逻辑问题**：女生说「下雨不想出门/第一次太快」这种逻辑障碍，用感性升维化解——「我之前在巴黎也陷入一样的纠结，最后还是去了，看到了雨中的落日」。描述画面让她大脑脑补，感性永远胜过逻辑。「生未动，心中已过万重山。」
- **心锚（粉红色的大象）**：植入一个具体意象（断臂维纳斯/戏梦巴黎），含沙射影后撤离，让她自己不断想、自己说服自己。**不捅破窗户纸（捅破=触发ASD）。**
- **你退女生才进（与猫论）**：后撤一步她反而追逐。「一般女生约我这么晚我都会拒绝，明晚见喽」=平衡掉需求感、抬高位置。

## 术 · 绿茶博弈 + 网聊实操（直播28/73/74）

**核心：绿茶 = 骑驴找马、不自信+没安全感，捞感情不捞钱。她给你的是「假窗口」，用顾左右而言他来吊你。应对 = 识别 → 打压(iod) → 冷冻 → 她追逐时垂直收网。**

- **识别绿茶**：邀约时永远不给 yes/no，只说「到时候看/睡醒再说/我怕喝醉控制不住自己/我不知道什么时候有空」。她先跟你聊「过程」最后给你一个 no。「绿茶最大的特点是骑驴找马——她不给你准确答复，只吊着你。」
- **绿茶的心理**：没有安全感+不自信→同时吊三四个男人→她需要的是「男性认同感」。「她允许自己吊别人，但不允许别人吊她——你一吊她，她就破防。」她的假窗口是为了获取认同，不是想见你。
- **打压治绿茶**：「当女生非常不尊重你，一定要给她一巴掌——去治她，别让她一直在高位。」敷衍应对三连：「咋了？」「我不喜欢嗯」「你不用敷衍，你不想聊直接说就行」。「捶一下她马上就老实。」给兴趣只能一点点给（意愿度），给多了她就把你当狗。
- **冷冻 = 冷暴力推开**：「框架不平等之后，冷冻一段时间，别再聊。」你冷淡，绿茶为了获取认同会反过来疯狂给你发消息——「听雨好爽」是诚意度够了才回。
- **绝对统治感（绿茶不配拥有大脑）**：绿茶喜欢耍小聪明，你必须帮她做决定。「她说不喜欢威士忌→『重要吗？』再给它选择『也有其他的』」「她纠结→『我帮你做过选择了，就这里』」。「我没这习惯，那边直接进」（不接她，抬标准）。
- **预判她的送命题**：她问「你多大」「你前任都多大」=想让你让着她。回「零零，你想说什么」堵死她的话头。她问「你没车还是不想接」→「我车在深圳，我也不开车接人，除非对象」——两头都不沾，又抬标准又专一。
- **姐妹军师团**：她突然变脸提要求（让你接她），是她把聊天截图发到闺蜜群、闺蜜撺掇的。看破不说破，怼她的逻辑（「难道我接你你就不晕车了吗」）。

## 术 · 约会结构（ch38）

- **约会 = 四阶段的完整弧线**（无结构=漂流）：
  1. **开场（0-5分钟）**：迎接（站起来+自然触碰）、开场话题（不寒暄，直接「男人对女人」对话）、带领（「这边太吵，跟我走」不是「你想去哪」）。
  2. **男女框架（5-15分钟）**：让她明确接收到「这是约会」。三个武器：眼神（想看哪看哪）、触碰（不解释，「我在咸猪手」）、语调（尾音向下）。**不建立男女框架=舒适太高=朋友区**（「舒适的那个人价值最高」）。
  3. **共振/舒适（15-45分钟）**：传递个性样本，聊自己真正在意的东西。想说就说不想说就不说（沉默不是搞砸）。
  4. **转场收尾（45分钟+）**：判断窗口三信号（停止拒绝+触碰不回避+她开始说「我们」）。
- **转场合理化**：给她台阶（「去看蜡笔小新」「看猫」「听音响」）不是「去我家」。
- **收尾三绿灯法则**：① 她坐得更近了？② 她主动开启新话题？③ 沉默时她填补空白？全绿走，红降级。
- **ABC三个计划**：A=你家、B=她家、C=收号择日再约。只有一个A计划=她拒绝你就脑子空了。
- **收尾禁忌**：不聊「我们是什么关系」（逼她定义=理性重启=ASD涌回）。不问不定义。
- **30/60规则**：前30分钟建安全，后30分钟拉近。参考不是手铐。

## 术 · 舒适感 vs 吸引力（ch37，反直觉真理）

- **舒适感与吸引力成反比**。「老板让你最舒服，但你对老板的鸡巴没有任何兴趣。」你让她舒服=你在用舒适感表达需求=吸引力归零。示弱=掉价=讨好。
- **社交压力 = 吸引力工具**：让她不自在片刻（眼神对视不躲、不接无聊话题、真实意图），她的身体会起反应，而她会把身体反应**错误归因**为「心动」。心跳加速的身体信号和心动的信号一样，理性分不清。
- **施压-减压循环 = 约会中的呼吸感**：压一下松一下（像 CPR、像齿轮里的石头）。一直压=恐惧，一直不压=无聊。**压力制造心跳，释放让心跳被归因为你有魅力。**
- **副歌（赋格）**：她已经被你吸引后给她的台阶。你不赋格她，她配不上你、会觉得一切是假的。
- **不取悦是最大的魅力**：你不需要她喜欢你的那一刻，才真正展现值得被喜欢的部分。

## 术 · 阴阳理论（ch40，两种吸引状态）

- **阴 = 幽灵**：不受外界影响、淡定从容、不以物喜不以己悲。核心操作：**不管她做什么你都不被影响**。优势：老少皆宜、不易犯错（约会约60分钟）。劣势：慢。
- **阳 = 太阳**：高能量、幽默、热情、进攻、侵略性。向外释放能量感染周围。优势：速度快（15-30分钟收尾）。劣势：操作难度高、容错低、不适合小白。
- **阴阳不是性格是策略**：你可以在不同场景选择不同策略。「把妹是纯粹的认知游戏，你永远泡不到认知以外的妞。」
- **阳三条底线**：① 速度不是急（她笑=速度，没笑=急）；② 坦然=框架（「是有意的」不是「不好意思」）；③ 你的能量要大于她的抗拒。
- **阴 ≠ 冷漠**：冷漠=没温度；阴=有温度但不受外界控制。
