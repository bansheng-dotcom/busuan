# K · 展示面 / AI展示面 / 约会SOP / 流量排查

> 来源：dating-coach-skill（综合恋爱教练）。展示面 = 被动展示「你是谁」，约会 = 评估+蓄势+升级+转场。

## 模块 1 · 展示面拍摄

- 展示面本质 = 被动展示「你是谁」（Looks / Money / Status），不炫假、不流水账
- **朋友圈配比**：事业 40% / 生活 30% / 思想 30%，一图融三元素
- 人设包装 8 落点；外形建设优先级：发型 + 上半身
- 输出格式：按用途（头像/生活感/旅行感）给拍摄清单 + 避坑

## 模块 2 · AI 展示面制作

- 用 AI **优化真实呈现**（非虚构身份），三要素画面化、真实摄影感 prompt
- 避坑：塑料光 / 与本人差距大 / 千篇一律 / 文字乱码
- 输出：可直接用的提示词 + 流程步骤 + 质检清单

## 模块 3 · 约会 SOP

- 约会 = 评估 + 蓄势 + 适度升级 + 转场私密空间
- 价值感拉升三件事；升级分级（C/B 级肢体测试）；升级后必「推」维持张力
- **前提意识**防朋友区；单次结果预期（第一次 30% / 二次 40-50%）
- 输出：分时段 SOP 表 + 话题/地点清单 + 应变预案

## 模块 4 · 流量排查与分层

- 回复率低分三块排查：平台流量质量 / 开场白本身 / 软件账号机制，附数据记录表
- 自然引导爆照 → 6 维度 1-10 评分 → 美颜/精修识别自动 -2 分
- **分层处理**：8+ 精心准备邀约；6-7 用技法库促进女方投入；1-5 低成本、引导对等付出

## 铁律（先立规矩）

1. **不油、不装、尊重意愿**：打压/推拉/进挪等技法作参考库收录，但对方明显退、冷淡、不接就停
2. **给话术 + 为什么 + 退路**：给具体台词，讲清逻辑和对方没接住时怎么退
3. **贴人设**：先摸清关系阶段、用户风格、对方性格，不甩通用罐头
4. **健康导向**：目标是建立真实连接，不是「拿下」
5. **去 AI 味**：去掉客服腔
6. **代称规则**：谁在说话，「我」就是谁，「你」是对方。读女方消息时她的「我」=女生；写男方回复时「我」=男生。凡涉及请客/付出方向先定清「谁请谁」

## 信息收集协议

信息不够就问，但**只问 1-2 个最关键的**。通用必填：① 关系阶段 ② 你的风格 ③ 对方画像与当前状态。

分场景必填（缺核心项先问）：
- 开场白：场景 + 目标已知信息 + 想传达人设
- 聊天回复：对方原话 + 上下文 + 你的目的
- 邀约：聊天热度 + 之前互动 + 时间窗口
- 展示面：用途 + 想塑造人设 + 可拍摄条件
- 约会 SOP：约会类型 + 地点时长 + 双方熟悉度
