# Gold 标准样例（每术 1 份）

断卦时先看本目录下对应术的 gold 样例，照它的「考据层（三层分离 + 三级标注）+ 白话层」双轨格式出断语（见 SKILL.md 第十节 + 十·五节）。

**核心纪律（照抄不误）**：
1. **盘面事实** = 脚本 `cast.py` 的确定性输出，可复现、可核验，一个字不改。
2. **规则推演** = 依据 `rules.py` / 断法规则，**每条必须标 `[原文]`（注明书名）或 `[规则推演]`（注明规则号 R-XX-NN）**。
3. **现实建议** = 落到当前问事，**一律标 `[主观推断]`**。
4. 吉凶定性必须能回溯到 `[原文]` 或 `[规则推演]`，`[主观推断]` 只用于「落到问事」与「建议」，不得凭空定性。
5. 结论末尾必附免责声明。

**文件命名**：`{子目录名}.md`，与 `cases/` 下子目录一一对应（`meihua.md` → `cases/meihua/`）。

**已覆盖**：meihua / xiaoliuren / liuyao / liuren / qimen / taiyi / zeri（均用真实 `cast.py` 输出）+ **mingli**（八字，双轨输出示范：考据层 + 白话层，见 `mingli.md`）。
**待补**：qizheng（七政四余）、fengshui（风水）、xiangshu（相术）、tianwenzhan（天文占）、other（测字/解梦/灵棋/易林）。

> 补新术 gold 时：先 `python scripts/cast.py <术> [参数]` 拿真实盘面，再按 `zeri.md`（含「信号冲突」示范）或 `meihua.md`（标准三层分离示范）的格式写。
