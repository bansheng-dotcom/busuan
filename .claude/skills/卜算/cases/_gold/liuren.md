## 断法要点（每宗门一句话）

- **元首**（上克下，一克）：尊卑顺、事从外来，宜静守应事。
- **重审**（下贼上，一贼）：事从内起、须重审详察，主反复。
- **知一**（比用，二课同克取比）：二归一、事有定主，宜专一。
- **涉害**（多克俱比，涉害深浅）：事涉两途、须辨先后深浅，主迟疑。
- **蒿矢**（神遥克干）：外来虚惊、声势大而力薄，宜防不实。
- **弹射**（干遥克神）：己意远射、力有所不及，宜量力而行。
- **昴星**（无克无遥，虎视/冬蛇）：事主幽暗、吉凶未明，宜静观。
- **别责**（四课不备，无克无遥）：事无正主、另觅他途，宜寻替代。
- **八专**（干支同位）：事涉专一、难分主客，宜防专权偏执。
- **伏吟**（月将加时同，天地盘同）：事主停滞、原地盘桓，宜守不宜进。
- **返吟**（天地盘互反）：事主反复、去而复返，宜防翻盘。

### 规则推演（考据层 + 白话两层）
- **课体**：返吟（天地盘上下反覆）主**事反复、动荡、去而复返**；绝嗣课主无根、难续。[原文·《六壬大全》课经，Grep「返吟」「绝嗣」佐证]
  → **术语解读**：「课体」是六壬给整件事定的基调；「返吟」＝天地盘上下翻覆，主事情来回折腾、反复不定；「绝嗣」＝断了根、难续上。
  → **问事解读**：你追钱这件事，会来回拉扯、反复折腾，一时半会儿定不下来。
- **三传**：初传子乘白虎（凶，血伤丧病）、中传亥乘太常（吉）、末传戌乘**玄武**临**财爻**（凶）。[规则推演 R-LR-01] 末传财爻乘玄武，正是「财被玄武盗骗」之象——钱财有失脱、被骗、暗中流失之危。[原文·《六壬指南》玄武主盗骗暗昧失脱]
  → **术语解读**：「三传」是事情的开头、中间、结局三段；「天将」是挂在每段上的神，玄武＝盗骗、暗昧、暗中流失。
  → **问事解读**：最后一段（结局）是「钱被玄武压着」，落到你问的事上——钱有被卷走、被骗、暗中流失的危险。
- **神煞**：命中日德、日禄（吉），主自身尚有转圜余地；但毕法赋「伏吟无丁马」主**不动、难推进**。[规则推演 R-LR-02 / R-LR-03]
  → **术语解读**：日德、日禄＝你自身还有贵人、有底气；「伏吟无丁马」＝原地不动、没有往外冲的劲，事情推不动。
  → **问事解读**：你自己还有腾挪空间，但这事推不动、只能慢慢磨。

### 现实建议（考据层）
- 追钱/生意此课**凶多**：末传财乘玄武，钱有被卷走、被骗、暗中耗散之象。[主观推断]
- 返吟主反复，追讨会来回拉锯、易翻盘难落地。[主观推断]
- 日德日禄护身，宜走正道、留凭证、报警/法律途径固定证据，勿私下纠缠。[主观推断]

### 结论（考据层 + 白话收口）
- 吉凶总断：凶，财被玄武（盗骗）乘，防失财被骗，追讨反复难速成。[规则推演]
- 趋吉：日德日禄临身，守正、留证、走正规渠道是唯一转机。[主观推断]
- 避凶：防玄武——不轻信对方口头承诺、不转账不垫资、不私下和解放弃追索。[主观推断]
