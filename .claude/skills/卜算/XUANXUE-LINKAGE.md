# XUANXUE-LINKAGE · 玄学技能联动接口文档

> 各术法之间的**互补 / 同侧**关系、联动调用顺序、多术融合规则。
> 对标 dglijin-oss/chinese-metaphysics-skills 的 `XUANXUE-LINKAGE.md` 与 laoshifu-mcp 的双法同参。
> 融合判定由 `scripts/libs/rules.py::fusion_mark` / `cross_validate` 落地（一致 / 冲突 / 互补 三态）。

---

## 一、联动总则

1. **单术独立断**：每个术按各自流程起盘 + 断卦，三层分离、三级标注不省。
2. **多术融合**：同一问事多术时，两两比对——同侧比吉凶、互补分维度，**不一致就明说「信号冲突，仅供参考」并降级**，绝不只取有利一术硬下结论。
3. **先问事 → 荐术 → 起盘**：拿不准用哪术时，按 SKILL.md 第四节「选术交互流程」推荐 2-3 个候选。

## 三、互补对（分答不同侧面，勿强行比吉凶）

| 组合 | 分工 | 融合输出 |
|---|---|---|
| 六爻 / 梅花 + 奇门 | 前者断**成败**，后者断**时机方位** | 成败如何 + 何时何方行动 |
| 梅花 + 大六壬 | 前者断**心意**，后者断**应期** | 对方怎么想 + 何时应验 |
| 八字 / 紫微 + 六爻 / 梅花 | 前者断**终身格局**，后者断**一事得失** | 大势顺逆 + 当前一事吉凶 |

`fusion_mark(判甲, 判乙, same_aspect=False)` → 标「互补」，各保留，分维度陈述。

## 四、同侧对（答同一侧面，可直接比吉凶）

| 组合 | 侧面 | 冲突处置 |
|---|---|---|
| 梅花 vs 六爻 vs 小六壬 | 一事吉凶 | 冲突则明说「信号冲突」降级 |
| 八字 vs 紫微 | 终身命理 | 冲突则分述两派、标适用条件 |
| 大六壬 vs 奇门 | 时机 | 冲突则标「仅供参考」 |

`fusion_mark(判甲, 判乙, same_aspect=True)` → 一致更稳 / 冲突降级。

---

## 五、推荐联动顺序（先大局后一事）

1. **终身命理**（八字/紫微/七政四余）先看**大势**：旺衰喜忌、大运流年、格局顺逆。
2. **一事得失**（六爻/梅花/小六壬）再看**当前**：这件事成不成、该不该做。
3. **时机方位**（奇门/大六壬/择日）最后定**何时何方**：哪天做、往哪走、选什么时辰。
4. **交叉验证**：`rules.cross_validate([(维度, 吉凶), ...])` —— 多维一致才定论，吉凶矛盾标「信号冲突」。

> 例：问「该不该跳槽」→ 八字看流年官禄宫喜忌（大势）→ 六爻断这次跳槽成败（一事）→ 奇门定投简历/谈 offer 的方位时机（行动）。

## 六、融合三态与代码

| 函数 | 输入 | 输出 |
|---|---|---|
| `rules.fusion_mark(判甲, 判乙, same_aspect)` | 两术结论 | 一致 / 冲突 / 互补 |
| `rules.cross_validate([(维度, 吉凶), ...])` | 多维结论 | 吉 / 凶 / 中 / 信号冲突 |

- **一致**：两术同断同方向 → 结论加可信度。
- **冲突**：同侧吉凶相反 → 明说分歧 + 降级。
- **互补**：不同侧面 → 分维度陈述，不强行比吉凶。

---

## 七、跨术输出格式（多术互参时）

每术各出「三层分离 + 三级标注」的独立断语，最后加一段**融合小结**：

```
【融合小结】
- 六爻（成败）：吉，用神旺相。[规则推演 R-...]
- 奇门（时机方位）：中，宜选开/休/生门方。[规则推演 R-QM-01]
- 综合：成败可期，但须择吉方吉时行动 —— 互补，无冲突。
```

## 八、诚实边界（不因联动而丢）

- 多术一致 ≠ 保证准，只加可信度；MingLi-Bench 实测上限约 36%（四选一），人类 Top-20 约 53.5%。
- 学历 / 外貌 / 精确年份+具体生平类，一律「不确定+低置信度」，多术交叉也补不出确定性答案。
- 排盘确定性可保证；断卦准确率只保证「可追溯、可后验、可校准」。
