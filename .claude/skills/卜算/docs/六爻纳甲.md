## 输出格式（按功能模块，覆盖六爻全部功能，强制）

> 六爻功能分 **5 个模块**，每个模块各有输出要点；断卦先按问事定位模块，再套对应骨架。每段「考据层 + 白话层」双轨，**缺白话＝不合格**。
> 核心：盘面事实（Det/Sto）永远为真，不确定只活在流派分歧（Und）。断语 = 结论 + 证据 + 置信度（🟢🟡🔴）。

- **模块 A · 核心断卦**（求财/事业/婚姻等问事）：9 段骨架，维度须覆盖——①排盘（本卦变卦表 + 六神 + 五神 + 世应 + 旺衰 + 旬空月破 + 动变 + 伏神 + 特殊卦象 + **旺衰七查表**）；②盘面解读（卦象/动爻/用神/世应/旬空/特殊卦象/六神）；③原文+原文解读；④结论摘要（**吉凶判断矩阵**）；⑤分步解读（用神/原神/忌神/仇神/世应/动变/六冲/六神逐条）；⑥确定性标注；⑦时间节奏（病药法十字诀）；⑧行动建议；⑨风险边界。

**② 盘面解读（这个盘在说什么）**

1. **卦象：乾为天 → 天泽履（本卦六冲）**
   - 术语解读：乾为天六爻皆阳、纯阳刚健；变出天泽履＝行路、践行。且乾为天是六冲卦（《增删卜易》「卦之六冲」），六冲主事散、不稳。
   - 问事解读：起头一股劲儿想成事，但本卦带「六冲」散气，求财最怕冲（冲主散财），埋了「难成」的底子。

2. **用神妻财寅木：衰 + 入日墓（休囚入墓＝凶）**
   - 术语解读：求财以妻财为用神；寅木在戌月「囚」、被月日两土泄气而衰；更关键的是**入日墓**——木墓在未、日辰正是未，用神入日墓。休囚入墓＝被埋葬（《增删卜易》墓库章）。
   - 问事解读：财不但「没劲」（衰），还被「埋进墓里」（入日墓）——这笔财眼下是「被埋住、出不来」的凶象，不是「平」，是「难成」。

3. **原神子孙甲子：真空（生财之源彻底断）**
   - 术语解读：原神＝生用神之神（水生木）；子孙甲子安静、在戌月「死」、受月日双克，旬空——**真空**（安静+休囚+受日月克＝永无用处，无应期）。
   - 问事解读：生你的劲儿不只是「空」，是「真空」——彻底断了，没有出空的应期可等，这笔财眼下无「后续粮草」。

4. **忌神兄弟壬申：旺相能克（得日月双生）**
   - 术语解读：忌神＝克用神之神（金克木）；兄弟申金得月建戌土生、日辰未土生，**旺相**——忌神旺相，能克用神（《增删卜易》元神忌神章）。
   - 问事解读：劫财的兄弟「正得势」（得月日双生），有能力克你的财——不是「暂不劫」，是「能劫且正旺」。

5. **世应比和（世勾陈旺、应玄武暗昧）**
   - 术语解读：世爻父母戌土、应爻父母甲辰，同属土比和；世临勾陈（旺）、应临玄武（暗昧）。世应比和主「势均力敌、成败在己」。
   - 问事解读：你和对方「谁也不压谁」，但对方（应爻玄武）带暗昧——防对方不实、防暗箱。

6. **动爻父母甲辰：退神 + 月破 + 化破 + 玄武**
   - 术语解读：三爻父母辰动化丑，辰→丑退神、辰月破（戌冲辰）、丑化破（未冲丑）、临玄武（盗贼暗昧）。
   - 问事解读：文书/合同这一环「退、破、暗昧」——签约、协议务必留底复核，防暗箱诈骗。

**③ 原文 + 原文解读（每条原文紧跟白话翻译 + 套盘）**

**《增删卜易》**（求财总纲）
> 「占求财若得财星持世，或日月动爻作子孙生合世爻，或官鬼持世财动生之，或父母持世财动克之世，皆许求财之易如摘枝耳。若遇兄弟持世及兄弟爻动于卦中，或世临旬空月破，何异缘木求鱼。」

- 逐句解读：「财星持世」→ 妻财坐世爻；「日月动爻作子孙生合世爻」→ 日月动爻有子孙（原神）来生合世；「皆许求财之易如摘枝」→ 易得之象；「兄弟持世及兄弟爻动、世临旬空月破」→ 缘木求鱼白费劲。
- **套盘**：财星没持世（落二爻）、世爻没临空破，但**原神子孙真空（生财之源断）+ 忌神兄弟旺相（能克）**——比「兄弟持世」更凶的「财弱无源」，落到「难成」。

**《增删卜易》**（墓库）
> 「旺相入库为财库，休囚入墓为埋葬。用神休囚又入墓，如人被埋，诸事难成。」

- 逐句解读：旺相入库＝储藏（中性）；休囚入墓＝被埋葬（凶）。
- **套盘**：用神妻财寅木在戌月「囚」（休囚），又入日墓（木墓未、日辰未）——**休囚入墓，财被埋葬、诸事难成**，这是本盘最重的凶信号。

**《增删卜易》**（旬空）
> 「真空者，安静休囚无生助，受日月克，永无用处；假空者，旺相或得生扶，出空有用。」

- 逐句解读：真空＝安静+休囚+无生助+受日月克，永无用；假空＝旺相或得生扶，出空有用。
- **套盘**：原神子孙甲子，安静、戌月「死」、受月日双克、旬空——**真空**，生财之源永无用、无出空应期，这是「财无源头」的铁证。

**《增删卜易》**（六神类象）
> 「玄武主盗贼、朱雀主口舌；白虎金财，丧仪屠宰之物；青龙水利又兼喜庆；蛇利于出入，勾陈利于农工。」

- 逐句解读：玄武盗贼、朱雀口舌、白虎金财主丧仪屠宰、青龙喜庆、腾蛇出入、勾陈农工。
- **套盘**：用神妻财临白虎（财带血伤风险）、原神子孙临腾蛇（生财之源虚惊）、忌神兄弟临朱雀（劫财带口舌）、应爻临玄武（对方暗昧）——全盘六神「险、虚、口舌、暗昧」，无一吉神护财。

**④ 结论摘要（吉凶判断矩阵）**

**凶（按 mingli phase5 判断矩阵）**。用神妻财寅木休囚（戌月囚）+ 入日墓（被埋）；原神子孙真空（不能生）；忌神兄弟申金旺相得日月双生（能克）——矩阵「用神休囚 + 原神不能生 + 忌神能克 ＝ **凶**」。

**修正因子**：世爻戌土旺相（向吉修正，但世旺救不了「用神入墓+原神真空」）；本卦六冲（向凶修正，散财）；父母持世（向凶修正，主辛劳不聚财）；用神临白虎（向凶修正，财带血伤）。

> 注：`cast.py` 自动评分为「48/100 平」，因其评分未计入「入日墓」「原神真空」「忌神旺相」三深度信号；按 phase3/5 完整断法，应为**凶**——深度判断纠正浅度评分。

**白话**：说人话——这笔财眼下是**凶的，别碰**。财本身被埋进了墓里（用神入日墓）、生财的劲儿彻底断了（原神真空）、劫财的正得势（忌神旺相）——三凶叠加，还赶上六冲散财、白虎带险。不是「等等就行」，是「这个时机根本不行」。

   - 原文：《增删卜易》「休囚入墓，如人被埋，诸事难成」。
   - 置信度：🟢 高（旺衰+入墓是确定性判定）。
   - 术语解读：入日墓＝日辰正是用神的墓库，休囚入墓＝被埋葬；这是比「衰」更重的凶（衰是没劲，入墓是出不来）。
   - 问事解读：财不是「没劲」那么简单，是「被埋住了出不来」，求则难成。

2. **原神真空**（结论：生财之源彻底断）
   - 证据：子孙甲子安静、戌月死、受月日双克、旬空 → 真空（Det）。
   - 原文：《增删卜易》「真空者，安静休囚无生助，受日月克，永无用处」。
   - 置信度：🟢 高。
   - 术语解读：真空＝不只是「暂时空」，是「永无用、无应期」；原神真空＝生财之源彻底断。
   - 问事解读：没有「等出空」这回事——生你的劲儿彻底断了，这笔财没有后续粮草。

3. **忌神旺相能克**（结论：劫财者正得势）
   - 证据：兄弟申金得月建戌土生、日辰未土生 → 旺相（Det）。
   - 原文：《增删卜易》「元神忌神，旺相者有力」。
   - 置信度：🟢 高。
   - 术语解读：忌神旺相＝能克用神；兄弟得日月双生，劫财之力正强。
   - 问事解读：劫财的「兄弟」正得势、有能力克你的财——不是暂不劫，是能劫且正旺。

4. **动爻父母退神+月破+化破临玄武**（结论：文书合同防诈）
   - 证据：三爻父母甲辰动化丁丑，辰→丑退神、辰月破、丑化破，临玄武（Det）。
   - 原文：《增删卜易》进退章、十二神「玄武主盗贼暗昧」。
   - 置信度：🟢 高。
   - 术语解读：父母爻主文书契约；退神+月破+化破=这一环破败；玄武=暗昧诈骗。
   - 问事解读：文书/合同「退、破、暗昧」，签约务必留底复核，防暗箱诈骗。

5. **本卦六冲**（结论：求财遇冲主散）
   - 证据：本卦乾为天是六冲卦（Det）。
   - 原文：《增删卜易》「卦之六冲」。
   - 置信度：🟢 高。
   - 术语解读：六冲主事散、不稳；求财最怕冲（冲主散财）。
   - 问事解读：六冲散财，防铺太开、防多头并进。

**⑥ 确定性标注（✅确定 / ⚠️不确定 / ❌矛盾）**

- ✅ 确定：本卦乾为天→天泽履、动爻三爻、妻财落二爻、子孙旬空、父母辰月破、辰→丑退神、六冲、用神入日墓、原神真空、忌神旺相——全部 Det 可复现。
- ⚠️ 不确定：吉凶「凶」的等级（大凶/凶）、应期——「入墓+真空」判凶是流派共识，但「凶到什么程度」属释义。
- ❌ 矛盾：无（用神入墓 + 原神真空 + 忌神旺相一致指向凶，无信号冲突）。

**⑦ 时间节奏（病药法十字诀）**

- **病**：用神妻财**休囚入日墓**；原神子孙**真空**（无出空应期）；本卦六冲主散。
- **药**：逢**冲墓**之日（未墓逢丑冲，丑日冲开墓库）；或逢**生旺木气**之期（寅卯日）；但原神真空，**无「出空」可等**。
- **应期**（十字诀「衰待旺、墓待破、冲待合」）：用神入墓→**待冲墓**（丑日）；用神衰→**待旺**（寅卯日）；六冲→**冲待合**（合之日）。
- 原文：《增删卜易》应期总论「动待合，静待冲；衰待旺，旺待墓；冲待合，合待冲；空待出，墓待破；伏待引，吟待冲」。

**白话**：什么时候有转机？等「冲开墓库」之日（丑日冲未墓）、或木气旺的日子（寅卯日）；但生财的原神是真空，没有「出空」可等，所以转机「有限、且难」。具体哪一天，应期难定，只能给「丑日冲墓、寅卯日待旺」的方向。
