## 输出格式（确定性骨架 + 盘面解读 + 全段白话，强制）

> 输出契约 **10 段**，每段「考据层 + 白话层」双轨：考据给可查证依据，白话给听得懂的人话。**缺白话＝不合格**。
> 核心：盘面事实（Det/Sto）永远为真，不确定只活在流派分歧（Und）。断语 = claim + evidence + confidence（🟢🟡🔴）。

1. **排盘**：`cast.py liuyao` 装卦表**完整展示**（本卦→变卦、六神/六亲/纳甲/世应/动变/旬空）。摇卦 Sto（seed 可重放），纳甲/世应/用神 Det，吉凶 Und。
2. **盘面解读**：这个盘每行怎么读——六神/六亲/世应/动爻/旬空各代表什么、此盘呈现什么象（白话）。
3. **原文**：引经据典**全文**（书名 + 行号，`classical_search.py --passage-id` 可复核）。
4. **原文解读**：这段经文的白话翻译——它在讲什么规则、怎么套到本盘。
5. **结论摘要**：吉凶总断一句话 + **七级评级**（上上/上吉/中上/中平/中下/下平/下下，对应 0-100 评分档）+ 落到问事哪一面；紧跟白话版（第二人称「你」）。
6. **分步解读**：每条断语 claim + evidence + confidence（🟢🟡🔴），每条配「术语解读 + 问事解读」。
7. **确定性标注**：✅确定（Det/Sto 可复现事实）/ ⚠️不确定（Und 流派分歧 + 释义推断）/ ❌矛盾（信号冲突）；三类都要点到，无矛盾则明说「无」。
8. **时间节奏**：应期（能断则断，断不出明说「应期难定」）；紧跟白话版（按问事解读）。
9. **行动建议**：趋吉（可乘之机 + 行动）+ 避凶（风险 + 规避）+ 白话版 + 今日可行的一小步。
10. **风险边界**：limitation（不得由爻位/用神名推断吉凶、金额、具体日期、人物）+ 「判断停在哪」+ 免责。

- **独立评估者**：`libs/najia.py` 装卦 + `case_search.py` 案例库 + Grep 典籍交叉复核 liuyao MCP 排盘（王虎应体系）；主判与独立判不一致标「信号冲突」并降级。
- **结构化双轨**：`cast.py liuyao ... --json` 出盘面事实层 JSON（`schema=liuyao-panfact-v1`），与散文并存。

### 输出样例（求财 · 乾为天 → 天泽履）

> 盘面为固定测试盘（`--seed 1670639339` 可重放），不是真实用户预测。

**① 排盘（盘面事实）**

- 摇卦 Sto（铜钱随机，seed 可重放）；纳甲/世应/六亲/六神 Det；吉凶 Und（旺衰生克流派）。
- limitation：爻象事实只记录六亲/六神/纳甲/世应/旺衰；不得由用神名或爻位推断吉凶、金额、具体日期或人物身份。

```text
本卦：乾为天 → 变卦：天泽履   动爻：[3]
占时：己未日   月建：戊戌   旬空：子丑
乾宫(金)   世爻：上爻   应爻：三爻

六神   爻位   本卦(六亲 干支)     变卦(六亲 干支)     标
腾蛇   初爻   子孙 甲子          —              空
白虎   二爻   妻财 甲寅          —              
玄武   三爻   父母 甲辰          父母 丁丑         应 动
青龙   四爻   官鬼 壬午          —

```

**② 盘面解读（这个盘在说什么，术语 ↔ 白话逐项对照）**

1. **卦象**：本卦乾为天 → 变卦天泽履
   - 术语：乾为天六爻皆阳、纯阳刚健，主「要强、主动、想成事」；变出天泽履（上乾下兑），履＝行路、践行、如履薄冰。
   - 白话：起头你是一股劲儿想把这笔财拿下；但变出来的卦在提醒你——**脚要踩实、如履薄冰**，别冲过头。

2. **动爻三爻**：父母甲辰 → 父母丁丑（退神 + 月破 + 化破）
   - 术语：父母爻主文书、契约、辛劳、责任；辰土化丑土是**退神**（《增删卜易》进退章「辰→丑」属土退）；辰被月建戌冲＝**月破**，丑被日辰未冲＝**化破**。
   - 白话：这事卡在「文书/手续/辛苦经营」这一环，而且这一环**力量在往回缩、还被月日两头冲破**——等于你最费劲、最指望的那块，眼下是「破的、退的」，撑不起来。

3. **用神妻财甲寅落二爻（衰）**
   - 术语：求财以妻财为用神，财爻在位（求财有对象）；但寅木被月建戌土、日辰未土两重泄气，故衰。
   - 白话：钱本身没劲，像没根的苗，眼下起不来。

4. **世应比和**：世戌土、应辰土
   - 术语：世应比和＝双方同五行、势均力敌、持平（《增删卜易》:1458「世为己，应为人」）。
   - 白话：你和对方/外部**谁也不压谁**，没有助力也没有阻力，成败看你自己。

5. **旬空**：子丑空，初爻子孙甲子临空
   - 术语：旬空＝落空不实；子孙是财的原神（生财之神），它临空＝生财之源也虚着。
   - 白话：连「生你的那股劲儿」都落空了，进一步印证「财难起」。

6. **特殊卦象**：本卦乾为天是**六冲卦**
   - 术语：六冲卦主事散、冲突、不稳（《增删卜易》六冲章，乾为天列十冲之一）；本卦六冲＝起头就带「散」气，求财遇冲本不利成。
   - 白话：这卦一上来就带着「散、不稳」的底子，求财最怕冲（冲主散财），所以更坐实了「眼下难成、宜守」。

一句话：**盘面＝有想法、名分正，但六冲带散、财弱、动处退破、原神落空，眼下成不了，宜守不宜攻。**

**③ 原文**

> 《增删卜易》:8
> 「占求财若得财星持世，或日月动爻作子孙生合世爻，或官鬼持世财动生之，或父母持世财动克之世，皆许求财之易如摘枝耳。若遇兄弟持世及兄弟爻动于卦中，或世临旬空月破，何异缘木求鱼。」

**④ 原文解读（逐句白话翻译）**

- 「占求财若得**财星持世**」→ 求财占卦，如果妻财（财星）正好坐在世爻上；
- 「或日月动爻作**子孙**生合世爻」→ 或者日辰月建、动爻里有子孙（财的原神）来生合世爻；
- 「或**官鬼持世**财动生之，或**父母持世**财动克之世」→ 或者官鬼持世而财爻动来生它、或父母持世而财动克世；
- 「皆许求财之易**如摘枝**耳」→ 以上都是「求财容易得像摘树枝」的吉象；
- 「若遇**兄弟持世**及**兄弟爻动**于卦中」→ 反过来，兄弟（劫财的忌神）持世、或兄弟爻发动；
- 「或世临**旬空月破**」→ 或世爻临旬空、月破；
- 「何异**缘木求鱼**」→ 那就像爬到树上找鱼，白费劲。

**套到本盘**：财星没持世（落二爻）、也不是兄弟持世、世爻没临空破——吉凶两头都不占满，所以既非「易得」也非「求不得」，落在中间「平」。这正是原文没写到的「中间态」，于是靠旺衰往下定：用神衰 → 落到「宜守不宜攻」。

**⑤ 结论摘要**

平（48/100，**中平**）。用神妻财甲寅落二爻、月日皆泄而衰，财弱难起；世应比和、名分正无阻力，不凶只是时机未到，宜守不宜攻。

**白话**：说人话——这件事眼下**既不是大吉也不是大凶，是「时机没到」**。你想求的这笔财，钱本身没劲（财爻衰），但局面是正的、没人坏你事（世应比和），所以别硬上，稳住等时机。

**⑥ 分步解读**

1. **用神衰**（claim：财弱难成）
   - evidence：妻财甲寅木，月建戊戌土、日辰己未土皆被木克而反泄木气，用神衰（Det，《增删卜易》:445「两处克两处生者，须看旺衰」）。
   - confidence：🟢 高（盘面事实直接对应，无流派分歧）。
   - 术语解读：用神＝「你这事对应的那个爻」，求财看妻财；「衰」＝它没力气、被月日泄着，财像没根的苗。
   - 问事解读：这笔财眼下起不来，不是没机会，是时机没到、气不足，硬求反耗自己。

2. **世应比和**（claim：成败在己）
   - evidence：世爻父母戌土、应爻父母辰土，同属土、比和（Det，《增删卜易》:1458「世为己，应为人，大宜生合」）。
   - confidence：🟢 高。
   - 术语解读：世＝你自己，应＝对方/外部；比和＝双方同五行、谁也不压谁，没有外来助力也没有阻力。
   - 问事解读：能不能成，主要看你自己怎么经营，别指望外力推你一把。

**⑦ 确定性标注（✅确定 / ⚠️不确定 / ❌矛盾）**

- ✅ 确定：盘面事实全部可复现——乾为天→天泽履、妻财甲寅落二爻、世应比和、本卦六冲（摇卦 Sto、seed 可重放；纳甲/世应/用神 Det）。
- ⚠️ 不确定：吉凶「平（48/100）」、应期「寅卯日」——旺衰吉凶是 Und 流派分歧，应期是释义推断，非盘面直接给出。
- ❌ 矛盾：无（本盘无信号冲突）。

**⑧ 时间节奏（病药法：病 → 药 → 应期）**

- 病：用神妻财甲寅**休囚无力**（月日两土泄气而衰）；另本卦六冲、初爻原神子孙临空。
- 药：逢**生旺木气**之期——寅、卯日（木当值/木旺），或逢亥、子日（水来生木）。
- 应期：**寅卯日**再动方有转机（衰待旺、休囚逢生旺之期，《增删卜易》应期总论）；当前旬空子丑，财爻不空、无出空之应，以「得生扶」为应。

**白话**：什么时候有转机？等木气被扶起来的日子——**寅日、卯日（木旺的日子）前后**再推；现在到寅卯还有一段，这段先别动钱、别抢跑。

**白话**：现在能做的，是把「该准备的都准备好」——渠道、报价、合同，等寅卯日再出手；不能做的，是**往里砸钱、硬催、抢时间**，尤其别把钱押太久，不然周转不开。
