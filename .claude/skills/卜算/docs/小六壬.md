# 小六壬（快断吉凶）

> 分术法文档。总纲见 `SKILL.md`，多术联动见 `XUANXUE-LINKAGE.md`。

## 起盘

```bash
python scripts/cast.py xiaoliuren            # 小六壬·月日时
```

## 断卦流程

- 脚本起盘得落宫 → 取六宫口诀断语。
- 口诀原文：`txt\[其他] 小六壬.txt`（大安/留连/速喜/赤口/小吉/空亡六宫断）。
- 趋避：
  - 趋吉：落大安（安稳顺遂）、速喜（快而喜、求财婚恋宜速）、小吉（小有喜、出行求财）→ 可速行、宜主动。
  - 避凶：落留连（纠缠拖延、防口舌是非）、赤口（口舌破财、防争斗）、空亡（落空、劳而无功）→ 宜缓守静、忌冲动，防口舌破财落空。
  - 参断：大安属木主不动宜守，留连属水主拖延宜静待，速喜属火主速宜乘热打铁，赤口属金主刑防争执，小吉属木主和宜周旋，空亡属土主空勿强求；落宫再叠时辰断轻重。

## 排盘自检

月→日→时顺数落宫忌跳数；六宫口诀与落宫一致。

## 断卦规则

落大安/速喜/小吉→吉；落留连/赤口/空亡→凶。→ `rules.xiaoliuren(落宫)`。
