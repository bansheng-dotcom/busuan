**③ 三传解读（初传发用 → 中传 → 末传结局）**

1. **初传卯乘天空**（凶，但六亲父母生身）
   - 术语解读：初传=发用=事开头；卯乘**天空**（主虚诈、不实、落空）——开头乘天空，主「事多虚诈、不实、易落空」；卯六亲是父母（生身），又落「丙火沐浴（败）之地」。
   - 问事解读：开头容易「虚」——对方话里有水分、计划悬空，别轻信；虽父母生身（有长辈/文书之力），但天空压着，力使不出。

2. **中传寅乘白虎**（凶，但长生+驿马）
   - 术语解读：中传=中程；寅乘**白虎**（主血伤、压力、威猛），又寅是**日马**（驿马，主动）、是**丙火长生**（日干长生，有生机）——白虎凶将压着「长生+驿马」的吉，过程有压力、奔波、但藏生机。
   - 问事解读：过程有压力、奔波（白虎+驿马），但藏「长生」的生机——熬过压力有转机，别硬顶、稳住。

3. **末传丑乘太常**（吉，但旬空）
   - 术语解读：末传=结局；丑乘**太常**（主衣冠、酒食、礼仪，吉），但丑**旬空**（子丑空）——结局本吉，却落空、难落实。
   - 问事解读：结局表面看着行（太常吉），但丑空亡——「空欢喜」的风险，别把希望押在悬着的承诺上。

**④ 原文 + 原文解读（每条原文紧跟白话翻译 + 套盘）**

**《六壬大全》**（课经）
> 「凡一上克下，余课无克，为元首课。」

- 逐句解读：「一上克下」→ 四课中有一课上神克下神；「余课无克」→ 其余课上下无克；「为元首课」→ 这样的课叫元首。
- **套盘**：本课正是「一上克下、余课无克」，故为元首课——名正言顺、有头绪，求财可正着谋。

**《六壬大全》**（十二天将）
> 「天空主虚诈不实、奴婢欺诈；白虎主道路凶恶、丧病、威猛；太常主衣冠、酒食、礼仪。」

- 逐句解读：天空主虚诈不实；白虎主凶恶血伤；太常主衣冠酒食（吉）。
- **套盘**：本课三传「天空→白虎→太常」——初传天空（虚诈）、中传白虎（压力）、末传太常（吉但空），正好是「开头虚、中间压、结尾空欢喜」的链条。

**《六壬大全》**（类神·求财）
> 「求财以财类神为主，财旺相有气可应，空亡休囚难成。」

- 逐句解读：求财看财类神（日干所克之五行）；财旺相有气则可得，空亡休囚则难成。
- **套盘**：本课求财，财类神是**金**（丙火克金）；但四课上神（辰卯卯寅）和三传（卯寅丑）**皆无金**——财类神**不上课**，主「财不现、难求」；这是本课求财最关键的凶信号。

**《六壬大全》**（毕法赋）
> 「空上逢空事莫追。」（第二句「首尾相见始终宜」注中「空亡」相关）

- 逐句解读：「空上逢空」→ 上神空、又乘天空；「事莫追」→ 此事别再追。
- **套盘**：本课支上神卯乘天空（天空）、末传丑旬空——「天空 + 空亡」并见，主「事莫追、追则落空」，印证「宜缓不宜急」。

**⑤ 结论摘要**

中平偏谨慎（课体元首吉，但类神不上课 + 初传天空 + 末传旬空）。**课体元首名正言顺可谋；但财类神（金）不上课（财不现）、初传乘天空（虚诈落空）、末传太常旬空（结局难落实）**——求财主「财不现、开头虚、结局空」，宜核实不轻信、宜稳不宜冒进。

**白话**：说人话——这事「名分正、能按规矩办」，但**财本身没露面（类神不上课）、开头容易空、结局可能白忙**。别轻信、别预付、别把希望押在悬着的承诺上。

**⑥ 分步解读**

1. **课体元首**（结论：名正言顺、可谋）
   - 证据：四课一上克下、余课无克，九宗门取克发用为元首（Det）。
   - 原文：《六壬大全》「凡一上克下，余课无克，为元首课」。
   - 置信度：🟢 高。
   - 术语解读：元首=九宗门课体，主「事有头绪、名正言顺」；课体定「大方向吉不吉」。
   - 问事解读：这事大方向正、有章法，可以正着来。

2. **财类神不上课**（结论：财不现、难求）
   - 证据：求财看财类神（丙火克金，金类神申酉），四课上神+三传皆无金（Det）。
   - 原文：《六壬大全》「求财以财类神为主，空亡休囚难成」。
   - 置信度：🟡 中（类神不上课主「财不现」是共识，但「是否绝对难成」属释义）。
   - 术语解读：类神=「这事对应的那个神」，求财看财（日干所克）；「不上课」=类神没出现在四课三传，主「事不现、难求」。
   - 问事解读：这笔财眼下「不现、够不着」，不是没有，是时机未到、抓不住，宜等类神出现/得生扶之时。

3. **初传天空**（结论：开头虚、防虚诈）
   - 证据：初传卯乘天空（Det）；天空主虚诈不实。
   - 原文：《六壬大全》「天空主虚诈不实」。
   - 置信度：🟢 高。
   - 术语解读：初传=发用=开头；天空=「落空、假」的凶将，管开头吉凶。
   - 问事解读：开头容易空、有不实的地方，对方话里有水分，别轻信、别预付。

4. **末传太常旬空**（结论：结局难落实）
   - 证据：末传丑乘太常（吉）但丑旬空（Det）。
   - 原文：《六壬大全》「空上逢空事莫追」。
   - 置信度：🟡 中（太常吉 vs 旬空，吉象减力是流派共识，但「减多少」属释义）。
   - 术语解读：末传=结局；太常=衣冠酒食吉将；旬空=落空。吉将落空=「结局看着行、其实难落实」。
   - 问事解读：结局表面能落稳，但留神「落空」，别把希望押在悬着的承诺上。

5. **神煞吉凶同临辰**（结论：吉凶交织）
   - 证据：月德/天喜/天德（吉）+ 月破/天罗（凶）同落辰（Det）。
   - 原文：《六壬大全》神煞章。
   - 置信度：🟡 中（神煞吉凶是辅助，不主吉凶）。
   - 术语解读：神煞辅助断事，不主吉凶；本课吉煞凶煞同临辰，主「事有救（天德月德）也有阻（月破天罗）」。
   - 问事解读：这事「有救也有阻」——不是全无希望（天德月德救），但过程有破损、困阻（月破天罗），要防。

**⑦ 确定性标注（✅确定 / ⚠️不确定 / ❌矛盾）**

- ✅ 确定：四课、三传、天将、课体「贼克元首」、末传丑旬空、财类神不上课——全部 Det 可复现（`--ref` 可复核）。
