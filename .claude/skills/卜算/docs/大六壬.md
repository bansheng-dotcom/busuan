## 输出格式（确定性骨架 + 盘面解读 + 全段白话，强制）

> 输出契约 **10 段**，每段「考据层 + 白话层」双轨：考据给可查证依据，白话给听得懂的人话。**缺白话＝不合格**。
> 核心：盘面事实（Det/Sto）永远为真，不确定只活在流派分歧（Und）。断语 = claim + evidence + confidence（🟢🟡🔴）。

1. **排盘**：`cast.py liuren --time` 的天地盘/四课/三传/天将/神煞**完整展示**。起盘 Sto（--time 可重放），格局/课体/四课 Det，吉凶 Und。
2. **盘面解读**：这个盘每行怎么读——课体/发用/三传/天将/神煞各代表什么（白话，逐关键点，至少 4 项）。
3. **原文**：引经据典**全文**（书名 + 行号，可复核）。
4. **原文解读**：逐句白话翻译 + 套到本盘。
5. **结论摘要**：吉凶总断一句话 + **七级评级**（上上/上吉/中上/中平/中下/下平/下下，对应 0-100）+ 白话版。
6. **分步解读**：每条断语 claim + evidence + confidence（🟢🟡🔴）+ 术语解读 + 问事解读。
7. **确定性标注**：✅确定（Det/Sto 可复现）/ ⚠️不确定（Und 流派分歧 + 释义推断）/ ❌矛盾（信号冲突，无则说「无」）。
8. **时间节奏**：应期（能断则断，断不出明说「应期难定」）+ 白话。
9. **行动建议**：趋吉 + 避凶 + 白话 + 今日可行的一小步。
10. **风险边界**：limitation + 判断停在哪 + 免责。

- 断语 = claim + evidence + confidence，原文在关键判断处引用，不贴 `[原文]`/`[规则推演]` 标签；白话用第二人称「你」。
- 独立评估者：`--ref` 九宗门交叉校验 + `liuren_regress.py` 全量回归 + `case_search.py` 相似课例；主判与回归/原文不一致标「信号冲突」并降级。

### 输出样例（求财 · 贼克元首课 · 三传 天空→白虎→太常）

> 盘面为固定测试盘（`--time "2026-10-09 10:30"` 可重放），不是真实用户预测。

**① 排盘（盘面事实）**

- 起盘 Sto（--time 可重放）；格局/课体/四课/三传/天将/神煞 Det；吉凶 Und（类神取法、旺衰生克属流派）。
- limitation：课象事实只记录格局/四课/三传/天将/神煞；不得由课体名或天将名推断吉凶、金额、具体日期或人物身份。

```text
【大六壬】丙辰日 癸巳时 · 寒露 · 月将辰
格局：贼克（一上克下）→ 元首课

四课（上神 + 下神 / 天将）
  第一课：辰 + 丙（日干）  青龙
  第二课：卯 + 辰         天空
  第三课：卯 + 辰         天空
  第四课：寅 + 卯         白虎

三传（支·干 / 天将 / 六亲）
  初传：卯·乙   天空    父母
  中传：寅·甲   白虎    父母   ← 日马（驿马）
  末传：丑      太常    子孙   ← 旬空（空亡）

神煞命中：月德、天喜、天德（皆辰，吉）｜月破、天罗（皆辰，凶）
```

**② 盘面解读（这个盘在说什么，术语 ↔ 白话逐项对照）**

1. **格局：贼克 → 元首课**
   - 术语：一上克下、余课无克曰元首，为九宗之元、六十四课之首，象天，主「尊制卑、大顺」。
   - 白话：起手就是一副「名分正、可领头」的课，事情本身站得住，不是歪门邪道。

2. **发用卯乘天空（父母）**
   - 术语：初传即「发用」，定事之起因；天空主诈伪、虚而不实、落空。
   - 白话：这件事的**起因是虚的、不实的**——你听来的「好机会」或最初的指望，先别当真。

3. **中传寅乘白虎（父母）+ 日马**
   - 术语：白虎主血伤、威猛、操劳；寅又为驿马（奔波动象）。
   - 白话：中间这段**又忙又冲、还有压力甚至破耗**，要拼，也要防中途起冲突、伤身破财。

4. **末传丑乘太常（子孙）但旬空**
   - 术语：太常主衣冠、酒食、礼仪（吉），但丑临旬空＝吉而落空、填不实。
   - 白话：结局本该「体面、有收获」，但**落了空**，容易「看着好、到手是空」。

5. **三传父母→父母→子孙，财爻（金）不现**
   - 术语：三传发用皆父母（文书、辛劳、名分），末传才见子孙；求财类神「财」不现于三传。
   - 白话：全程都在「文书、辛苦、名分」上打转，**「钱」本身没上场**——这不是一笔快钱。

6. **神煞：辰上吉凶同临（月德/天德/天喜 vs 月破/天罗）**
   - 术语：同一「辰」位既带三吉煞又带两凶煞，吉凶并居。
   - 白话：好的坏的**都压在同一处**，成与败看你怎么接这一下。

一句话：**盘面＝课体正、名分顺，但发用虚诈、中传劳冲、末传空亡、财爻不现——求财虚而不实，利求名/文书正事，不宜硬求快财。**

**③ 原文**

> 《六壬大全》:3517
> 「凡一上克下，余课无克，为元首课，象天。如君克臣，必顺其正，无乱动反常之理。为九宗之元，六十四课之首，故名元首。君占则有伊尹之臣，臣占必遇唐虞之君；常人占之，万事顺利。大哉元首，元亨利贞，首出庶物，万国咸宁，统干之本，乃元吉第一课也。」

> 《六壬指南》:129
> 「○天空，后六戊戌土神也，其神无形无影，由正对天乙至尊即空亡也，由无敢对至尊而虚其位，故曰天空。专主诈伪不实。曰奏书者，言唯执书以奏，则此片时可对至尊也。」

**④ 原文解读（逐句白话翻译 + 套到本盘）**

- 「凡一上克下，余课无克，为元首课」→ 四课里只有一处上克下、再无其他贼克，就叫元首课；
- 「如君克臣，必顺其正，无乱动反常之理」→ 像君管臣，走的是正路，没有反常乱动；
- 「为九宗之元，六十四课之首」→ 它是九个宗门里的第一个、六十四课的头一课；
- 「君占则有伊尹之臣，臣占必遇唐虞之君；常人占之，万事顺利」→ 做臣的遇明君、做君的得贤臣，普通人占则事事顺遂；
- 「天空……专主诈伪不实」→ 天空这一将，专管「假、虚、空、不实」。
- **套到本盘**：本课正是一上克下、余课无克的元首课，所以「名分正、可领头」这一条站得住；但发用卯乘天空，恰把原文「天空专主诈伪不实」压在**发用（起因）**上——于是「万事顺利」被打折成「路正、但起因虚」。

**⑤ 结论摘要**

中平（48/100）。元首课吉、名分正（利求名/文书正事），但求财类神「财」不现、发用天空虚诈、末传太常空亡——**求财虚而不实，宜缓、宜转正事，不宜硬求快财**。

**白话**：说人话——这件事**底子是正的、名分也对，但不是一笔能快速到手的钱**。你最早听到的「机会」虚的成分大，中间还得又忙又扛压力，最后看着能成、却容易落空。想求财，先放一放；想求名、求一份「正经文书上的交代」，反而顺。

**⑥ 分步解读**

1. **求财虚而不实**（claim：求财难得、勿轻信）
   - evidence：三传不见财爻（金），发用卯乘天空（Det，《六壬指南》:129「天空……专主诈伪不实」），末传丑临旬空。
   - confidence：🟢 高（发用天空 + 财爻不现均为盘面事实；「求财不利」是类神取法推得，方向一致）。
   - 术语解读：类神＝「你问的那件事对应的符号」，求财看财爻；「发用」＝定起因的那一传。财不现 + 发用虚诈＝起因假、钱没上场。
   - 问事解读：这笔财眼下**虚、难**，别把宝押在最初听到的消息上。

2. **课体吉、名分正**（claim：正路可走、利文书名声）
   - evidence：格局贼克→元首（Det，《六壬大全》:3517「常人占之，万事顺利」）。
   - confidence：🟢 高（课体是盘面事实，原文直接对应）。
   - 术语解读：元首课＝九宗之首、主顺主正；本课格局正是元首。
   - 问事解读：求财的路虚，但**求名、求一份正式交代（文书/职位/名声）是顺的**，可以往这个方向使力。

3. **中程有压力与波折**（claim：中间要忙、要防冲突破耗）
   - evidence：中传寅乘白虎、又为驿马（Det，《六壬大全》十二天将：白虎主血伤威猛）。
   - confidence：🟡 中（白虎吉凶因课而异，此处仅依天将通义推「劳冲」，非铁断）。
   - 术语解读：中传＝事之中程；白虎＝威猛、血伤、操劳之将；驿马＝奔波动象。
   - 问事解读：推进到一半时**最累、最容易起冲突或破财**，要提前留神。

**⑦ 确定性标注（✅确定 / ⚠️不确定 / ❌矛盾）**

**⑧ 时间节奏（病药法：病 → 药 → 应期）**

- 病：末传丑临旬空（结局落空）、发用天空虚诈、财爻不现于三传。
- 药：待「填实 / 出空」之期——末传丑旬空，逢丑日填实、或逢未日冲空为应。
- 应期：**丑/未日前后**是传统「填空出空」之应；但求财类神不现、发用虚诈，此课求财本身偏空，**具体成日应期难定**，明说「应期难定」。
