## 断卦流程

- 起盘：`cast.py liuren`（脚本已排天地盘、四课、九宗门三传、天将、神煞）。
- **结构化补全**（`libs/liuren_shensha.py` + `libs/liuren_bifa.py`，输出已并入 `cast.py liuren`）：
  - 三传天将吉凶：十二天将（贵人/螣蛇/朱雀/六合/勾陈/青龙/天空/白虎/太常/玄武/太阴/天后）各主何事，初传/中传/末传所乘天将逐位判吉凶。
  - 命中神煞（30 个）：驿马/桃花/华盖/劫煞/灾煞/岁煞（按年支三合局）、日德/日禄/羊刃/天乙贵人（按日干）、月德/天德/天喜/红鸾/皇恩（按月支）、生气/死气/天医/月厌（按月支）、游都/鲁都/五墓（按日干）、岁破/月破（对冲）、天罗/地网（辰戌）、天赦/四废（按季节日干支）、旬空（按日干支）等，命中即标吉凶与落支。
  - 毕法赋 100 句赋文结构化索引（`liuren_bifa.py`，94 条主赋文句 + 吉凶倾向 + 主断方向），按课体格局/神煞关键词关联，命中后**按条名 Grep 原文佐证**（双重保证）。
  - 以上均为结构化判定层 + 出处指针；断卦时仍须 Grep 原文，找不到就明说「依 XX 法推演，非直接引文」。
- **断卦必经步骤 ①检索相似课例**：先跑 `python scripts/libs/case_search.py "占事" 大六壬` 语义检索相似课例，再 Grep `D:\卜算\国学czhengli\txt\案例库\大六壬\`（755 则）按「占事 + 课体」佐证原文（如官讼 Grep「官讼」、宅墓 Grep「宅」、前程 Grep「前程/终身」），看古人同类占事如何断课、断应期，作为断当前课的参照——**不得跳过直接空推**。
- 断：课体、**四课上下生克**（日干日支上神、干支关系、上下贼克）、三传生克、发用末传、类神、年命上神、神煞、毕法赋。
- 毕法赋多句同时命中时：取**与课体/类神最贴切者为主**，余为辅；吉凶相矛盾时明说「信号冲突」降级（参考 liuren-skill 赋文冲突取舍）。
- 测物/射覆：类神落「天将+地支」取象，输出**特征画像**不押物名——跑 `python scripts/cast.py shefu liuren/meihua <信号>`（见 `references/射覆特征画像.md`、`references/现代类象映射.md`）。
- 趋避：
  - 趋吉：三传顺生（初传生中、中生末）、发用类神得力、课体吉（元首/重审/知一/涉害得吉传）→ 可成宜进。
  - 避凶：传中克我、末传脱气、空亡入传、玄武腾蛇并见 → 防小人盗骗口舌，勿轻信勿冒进；见伏吟反吟、闭口课 → 防事难通、防反复。
  - 参断：发用定初因、中传定中程、末传定结局；类神旺相有气可应、空亡休囚难成；年命上神吉则我顺、凶则我阻。

## 输出格式（照八字升级，强制）

> 七条可复用经验见 `references/输出格式升级清单.md`。逐字样例见 `docs/大六壬-OUTPUT-EXAMPLE.md`（一事一占，趋避/应期/一小步/免责照给）。

- **一眼摘要**：`liuren.summary()` 已并入 `cast.py liuren` 输出（日期节气/格局/三传/日马），断卦先看卡再看盘。
- **骨架先行（三层分离 + 四段式）**：②排盘结果〔盘面事实〕③断语〔规则推演〕④结论〔现实建议〕；层标签与 `review.py` 匹配字逐字一致。
- **三级标注**：③每条断语 = `[原文]`（附「六壬大全:行号」「六壬指南:行号」段落 ID，`classical_search.py --passage-id` 原样复核）+ `[规则推演]` + 「术语解读」+「问事解读」。
- **独立评估者**：`--ref` 独立九宗门实现交叉校验（宗门/三传是否存疑，命中存疑课降级）+ `liuren_regress.py` 全量回归（8640 课穷举 + 结构不变量 + 古籍课式对照）+ `case_search.py` 相似课例。主判与回归/原文不一致标「信号冲突」并降级。
- **诚实边界**：④结尾写「判断停在哪」——对方真实意图/精确应验日期不硬断；冷门课体（涉害/八专/昴星/别责）三传须谨慎。
- **结构化双轨**：`cast.py liuren --json` 出盘面事实层 JSON（`schema=liuren-panfact-v1`），与散文并存。
