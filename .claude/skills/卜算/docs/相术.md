> 分术法文档。总纲见 `SKILL.md`，多术联动见 `XUANXUE-LINKAGE.md`。

## 起盘

无排盘，纯文本断法。

## 断卦流程

- 无排盘，纯文本断法：按用户描述/观相要素（五官、三停、骨相、气色、神韵）用 `Grep` 检索原文，分层解读，注明出处。
- 趋避：
  - 趋吉：神完气足、气色明润、五岳丰隆、三停匀称 → 宜进、宜决断、宜任事。
  - 避凶：气色晦暗、神疲气衰、骨相露滞 → 注意身心调养、勿冒险决断、防健康与是非。
  - 参断：先观神后观形，神主一生、色主一时；气色以明润为吉、晦滞为凶；相不独论，形神气色合参，忌以单相断吉凶。
- 参考：`txt\[易藏] 冰鉴.txt`、`柳庄相法.txt`、`太清神鉴.txt`、`神相全编.txt`、`神相铁关刀.txt`、`许负相法.txt`、`公笃相法.txt`、`鬼谷子神奇相法全书.txt`、`玉管照神局.txt`、`月波洞中记.txt`、`人伦大统赋.txt`、`心相篇.txt`。

## 输出格式（照八字升级，强制）

> 七条可复用经验见 `references/输出格式升级清单.md`。逐字样例见 `docs/相术-OUTPUT-EXAMPLE.md`。**无盘纯文本断法，跳过排盘 gate；②盘面事实＝用户提供的观相要素（五官/三停/骨相/气色/神韵）。**

- **骨架先行（三层分离 + 四段式）**：②盘面事实（＝输入）③断语〔规则推演〕④结论〔现实建议〕。
- **三级标注**：③每条 = `[原文]`（附「冰鉴:行号」「神相全编:行号」段落 ID，`classical_search.py --passage-id` 复核）+ `[规则推演]` + 「术语解读」+「问事解读」。
- **诚实边界**：④结尾写「判断停在哪」，不作医学诊断、不单相断吉凶。

## 排盘自检

纯文本，断语必注明出处书名。
