## 断卦流程

- 起盘：`cast.py fengshui 出生年 坐向 性别`（坐向如「坐北朝南」；脚本已算命卦、东西四命、宅型、宅命相配、游年九星、流年飞星、煞气识别、布局建议）。
- 断：命卦与宅命相配、游年九星吉凶方位、玄空飞星旺山旺向/上山下水/双星到向、流年五黄二黑等煞方与化解。
- 趋避：
  - 趋吉：吉方（生气/天医/延年/伏位、流年吉飞星如八白九紫）→ 宜安床、开大门、设书桌财位、常活动。
  - 避凶：凶方（绝命/五鬼/六煞/祸害、流年五黄二黑三煞）→ 少动、忌安床开门，置化解物（铜器、六帝钱、安忍水等）。
  - 参断：命卦与宅命相配定宅运根基；玄空飞星旺山旺向/上山下水/双星到向定宅局吉凶；流年飞星按月变化，逐月趋避。

## 输出格式（确定性骨架 + 盘面解读 + 全段白话，强制）

> 输出契约 **10 段**，每段「考据层 + 白话层」双轨：考据给可查证依据，白话给听得懂的人话。**缺白话＝不合格**。
> 风水堪舆属 C 类（择日/风水），结论不是「吉凶总断」而是「**方位吉凶**」——核心回答「哪个方位吉、哪个方位凶、该把什么放哪」。
> 核心：盘面事实（Det/Sto）永远为真，不确定只活在流派分歧（Und）。断语 = claim + evidence + confidence（🟢🟡🔴）。

1. **排盘**：`cast.py fengshui` 命卦/八宅方位/玄空飞星**完整展示**。命卦/宅型/游年九星/流年飞星 Det（出生年+坐向+性别可重放），九星吉凶轻重 Und。
2. **盘面解读**：这个盘每行怎么读——命卦/宅型/游年九星/流年飞星/煞气各代表什么、此宅呈现什么象（白话）。
3. **原文**：引经据典**全文**（书名 + 行号，`grep -n "关键词"` 可复核）。
4. **原文解读**：这段经文的白话翻译——它在讲什么规则、怎么套到本宅。
5. **结论摘要**：**方位吉凶总断**——哪个方位吉、哪个方位凶 + 七级评级（上上/上吉/中上/中平/中下/下平/下下）；紧跟白话版（第二人称「你」）。
6. **分步解读**：每条断语 claim + evidence + confidence（🟢🟡🔴），每条配「术语解读 + 问事解读」。
7. **确定性标注**：✅确定（Det/Sto 可复现事实）/ ⚠️不确定（Und 流派分歧 + 释义推断）/ ❌矛盾（信号冲突）；三类都要点到，无矛盾则明说「无」。
8. **时间节奏**：方位应期（流年/流月）；断不出精确应期明说「应期难定」。
9. **行动建议**：趋吉 + 避凶 + 白话版 + 今日可行的一小步。
10. **风险边界**：limitation（不得由方位吉凶推断个人吉凶、具体应期、金额）+ 「判断停在哪」+ 免责。

- **结构化双轨**：`cast.py fengshui ... --json` 出盘面事实层 JSON（`schema=fengshui-panfact-v1`）。

**④ 原文解读（逐句白话翻译）**

- 「多攻五姓八宅」→ 当时学人已经流行钻研「八宅」这套方位法；
- 「生气到其位，即修令清洁阔厚，即一家获安荣华富贵」→ 生气（吉星）落在哪个方位，就把那个方位收拾得干净、宽敞、厚实，一家就能安稳富足；
- 「天之福德者，宅之财命也」→ 宅里的「福德吉方」就是这栋宅子的「财运命脉」；
- 「更犯五鬼、绝命、刑祸者，尤不利」→ 反过来，住进五鬼、绝命这类凶方，尤其不利；
- 「先修刑祸，后修福德，即吉」→ 修房顺序要「先处理凶方、再补吉方」才吉，顺序反了就凶；
- 「第一要诀看宅命……命从来处天然定」→ 看宅先看「宅命」（命卦），命卦由出生年天然定死；
- 「第三要诀看生向，坎离震兑针尖上」→ 再看坐向，坎离震兑四正方位要落到正针上才合天心。

**套到本盘**：你「坎命、坎宅、宅命相配」，正合「命从来处天然定」——根基先站对了；游年「生气在东南、绝命在西南」，正合「生气到其位则获安荣、犯绝命尤不利」——所以吉方（东南、正东、正南）要勤修、凶方（西南、东北、西北、正西）要少住少动；流年五黄压正南，属于「方位吉凶随年而变」，须逐年核对、先化凶再补吉。

**⑤ 结论摘要（方位吉凶总断）**

- **宅命**：坎命（东四命）住坎宅（东四宅），宅命相配——根基上吉。
- **吉方**：游年四吉＝生气(东南)、天医(正东)、延年(正南)、伏位(正北)；流年八白(正东)、九紫(东南)为全年财位/喜庆位。
- **凶方**：游年四凶＝绝命(西南)、五鬼(东北)、六煞(西北)、祸害(正西)；流年五黄(正南)、二黑(西北)、三碧(正西)、七赤(西南)。

整体判「**中上（吉中有煞）**」：宅命相配是上吉底子，但流年五黄压正南（延年吉方被大凶压）、二黑压西北（六煞凶方叠凶），须化解五黄、二黑后方可安。

**白话**：说人话——你这房子跟你的命是「配对」的，底子好；东南、正东、正北这些方位是吉位，西南、东北、正西、西北偏凶。但 2026 年有个大煞「五黄」正好压在正南，西北又有「二黑病符」，所以这一年**正南、西北两处要特别当心，先化解再住人**。
