## 断卦流程

- 脚本起盘得本卦/互卦/变卦/动爻/体用。
- **起卦两条路**：先天（时间/数字）`meihua-time` / `meihua-num`；后天（触机）`meihua-guanwu <物数>`（物数占）、`meihua-shengyin <声数>`（声音占）、`meihua-zishu <字数>`（字占）、`meihua-duanfa <物卦> <方位卦>`（端法，见物+方位）。触机起卦后**必合外应断**（见下「三要十应」）。
- **断卦必经步骤 ①检索相似案例**：先跑 `python scripts/libs/case_search.py "占事" 梅花` 语义检索相似案例，再 Grep `D:\卜算\国学czhengli\txt\案例库\梅花\`（占例 14 则）佐证原文，看康节先生如何起卦、体用生克如何落到具体占事，作为断当前卦的参照——**不得跳过直接空推**。
- 断：体用生克（脚本已给，`rules.meihua(体五行,用五行)` R-MH-01）、卦气旺衰、互卦看中段机制、变卦看落点。
- **卦气旺衰（衰旺论）**：体卦宜旺、生体之卦宜旺、克体之卦宜衰——旺：震巽木旺于春、离火旺于夏、乾兑金旺于秋、坎水旺于冬、坤艮土旺于辰戌丑未月；衰则反之。`rules.meihua_wangshuai(体五行, 月支)`（R-MH-04）判旺/相/衰/休；体旺逢生则吉、体衰逢克则凶甚。
- **占断十八类**：按所问之事对应一类取「体=××、用=××」+ 生克快断（天时不分体用全观诸卦；失物以变卦定方位；疾病体宜旺逢生）。`rules.meihua_18lei(类名, 体五行, 用五行)`（R-MH-03），速查 `references/梅花十八类占.md`，断卦按类名 Grep 原文佐证。
- **三要十应（外应触机，后天起卦必查）**：后天起卦后除体用生克外**必须合外应断**——「体用为内、诸应卦为外」，内外相合才准。三要=耳（听声知吉凶）/目（观形知善恶）/心（察理知祸福）；十应=天时/地理/人事/时令/方卦/动物/静物/言语/声音/五色/写字十一类外应，以体卦为主、外应为用；衰旺论/内外论/动静/向背/静占同参。速查见 `references/三要十应速查.md`，断卦按篇名 Grep 原文佐证（双重保证）。
- **以变卦断物（变卦式八则）**：测物/断物除体用外，可取「以变卦断物」八例——泽火革变咸断伤股、地雷复变临断软物、天泽履变乾断铁器、泽火革变噬嗑断土物、雷泽归妹变睽断铁、泽天夬变兑断破磁盘、天水讼变兑断求财空望：变出何卦、变爻属何五行，即以该五行断物类。`rules.meihua_bianyao_shefu(变爻五行)`（R-MH-05）给物类候选（金=铁器金属破磁盘、木=软物文章、土=土物瓦石、火=火类光明、水=水类柔软）。出处《梅花易数·变卦式八则》，断卦 Grep 原文佐证。

## 输出格式（确定性骨架 + 体用卦气解读 + 全段白话，强制）

> 输出契约 **9 段**，每段「考据层 + 白话层」双轨：考据给可查证依据（书名可复核），白话给听得懂的人话（第二人称「你」）。**缺白话＝不合格**。
> 梅花专属骨架：体用生克定吉凶、卦气旺衰定强弱、互卦看中段、变卦看落点、外应合断——这是梅花区别于六爻/六壬的断卦链条。
> 核心：盘面事实（Det/Sto）永远为真，不确定只活在流派分歧（Und）。断语 = 结论 + 证据 + 置信度（🟢🟡🔴）。

1. **排盘**：`cast.py meihua` 全量盘面**表格化展示**（本卦/互卦/变卦表 + 体用 + 动爻 + 卦气旺衰）。起卦 Sto，卦象/体用/动爻 Det，吉凶 Und。
2. **体用生克解读**：体卦/用卦五行生克（体克用/用克体/体生用/用生体/比和）+ 卦气旺衰，术语解读 ↔ 问事解读。
3. **卦象解读**：本卦（现状）+ 互卦（中段）+ 变卦（落点）+ 卦脉，术语解读 ↔ 问事解读。
4. **原文 + 原文解读**：体用生克总诀 + 衰旺论 + 说卦传，每条原文 = 书名 + 全文，紧跟「逐句白话翻译 + 套到本卦」。
5. **结论摘要**：吉凶总断一句话 + 七级评级 + 落到问事哪一面；紧跟白话版。
6. **分步解读**：体用生克/卦气/互卦/变卦逐条，每条 = 结论 + 证据 + 置信度 + 术语解读 + 问事解读。
7. **确定性标注**：✅确定 / ⚠️不确定 / ❌矛盾；三类都点到。
8. **时间节奏**：应期（卦数/动爻/变卦断应期 + 白话）；断不出明说「应期难定」。
9. **行动建议 + 风险边界**：趋吉 + 避凶 + 白话 + 一小步 + limitation + 免责。

- **结构化双轨**：`cast.py meihua ... --json` 出盘面事实层 JSON，与散文并存。

### 输出样例（求财 · 雷泽归妹 → 震为雷 · 用克体）

> 盘面为固定测试盘（`--time "2026-10-09 10:30"` 可重放），不是真实用户预测。

**① 排盘（盘面事实）**

- 起卦 Sto（--time 可重放）；卦象/体用/动爻 Det；吉凶 Und（体用生克流派）。
- limitation：卦象事实只记录本/互/变卦、体用、动爻；不得由卦名或体用生克推断吉凶、金额、具体日期或人物身份。

**本卦 / 互卦 / 变卦**：

| 项 | 卦 | 上下卦 | 五行 |
|---|---|---|---|
| 本卦 | 雷泽归妹 | 震上 兑下 | 木 / 金 |
| 互卦 | 水火既济 | 坎上 离下 | 水 / 火 |
| 变卦 | 震为雷 | 震上 震下 | 木 / 木 |

**体用 + 卦气**：

| 项 | 值 |
|---|---|
| 动爻 | 第 2 爻（兑中爻动） |
| 体卦 | 震（木）—— 你自己 |
| 用卦 | 兑（金）—— 所测之事/财 |
| 体用生克 | 用克体（金克木）→ 凶 |
| 卦气旺衰 | 体卦木，月令酉（秋金旺），木受金克 → 衰，衰而逢克则凶甚 |
| 吉凶评分 | 16/100 → 凶 |
| 应期 | 卦数粗推约 6 日/周/月（参考，非确定） |

**② 体用生克解读**

1. **用克体（金克木）—— 对方/环境压制你**
   - 术语解读：体卦=你自己（主），用卦=所测之事（宾）；体震木、用兑金，金克木，故「用克体」。体用生克口诀「体克用诸事吉，用克体诸事凶」——用克体主「对方/环境压制你、事难成」。
   - 问事解读：求财这事，是「财/对方压着你打」——你处于被动、被克的位置，硬求会吃亏。

2. **卦气衰（木受月令酉金克）—— 体弱逢克，凶上加凶**
   - 术语解读：卦气旺衰看体卦五行 × 月令；体卦震木，月令酉（秋金当令），木被金克，故「衰」。衰旺论「体卦宜旺、克体之卦宜衰」，本卦体衰 + 用克体 = **衰而逢克，凶甚**。
   - 问事解读：你不只是被克，而且是「在弱的月份被克」——天时也不帮你，这卦的凶是「实打实」的，不是虚惊。

**③ 卦象解读（本卦 / 互卦 / 变卦）**

1. **本卦雷泽归妹**——「少女归嫁」，结合之卦但带「凶」
   - 术语解读：归妹（震上兑下）＝长男配少女，主「结合、婚嫁、合作」；但归妹卦辞「征凶，无攸利」——急进有凶、无所利。
   - 问事解读：这事表面是「结合/合作/撮合」的象（归妹），但卦辞明说「急进有凶」——别急着撮合、别急着下注。

2. **互卦水火既济**——中段水火相济，有转机
   - 术语解读：互卦＝本卦二至四爻、三至五爻重组，看「内在机制/中段」；既济（坎上离下）＝水火相济、事已成。但既济卦辞「初吉终乱」——先吉后乱。
   - 问事解读：中间过程看着「水火相济、能成」（既济），但既济是「初吉终乱」——开头顺、后面乱，别被中段的顺迷惑。

3. **变卦震为雷**——落点「动」，但双雷主反复
   - 术语解读：变卦＝动爻变化后的结果，看「落点/结局」；震为雷（震上震下）＝双雷震动、动而有声，但双震主「动而反复、惊动」。
   - 问事解读：结局落在「动」上——事情会有变动、惊动，但双雷是「动而反复」，不是「动而功成」，防反复、防空动。

**④ 原文 + 原文解读（每条原文紧跟白话翻译 + 套盘）**

**《梅花易数》**（体用总诀）
> 「体克用，诸事吉；用克体，诸事凶。体生用，有耗失之患；用生体，有进益之喜。体用比和，则百事顺遂。」

- 逐句解读：「体克用诸事吉」→ 体卦克用卦，事可成、吉；「用克体诸事凶」→ 用卦克体卦，事难成、凶；「体生用有耗失」→ 体生用，泄气、有损失；「用生体有进益」→ 用生体，得助、有收益；「体用比和百事顺遂」→ 体用同五行，顺利。
- **套盘**：本卦体震木、用兑金，**用克体**——正应「用克体诸事凶」，求财主「对方/财压制你、事难成、凶」。

**《梅花易数》**（衰旺论）
> 「体卦宜旺，克体之卦宜衰。体盛则吉，体衰则凶。用克体固不宜，体生用亦非利。」

- 逐句解读：「体卦宜旺、克体之卦宜衰」→ 体卦要旺相、克体的用卦要衰弱才吉；「体盛则吉、体衰则凶」→ 体旺则吉、体衰则凶；「用克体固不宜」→ 用克体本来就不利。
- **套盘**：本卦体震木，月令酉（秋金当令），木被金克、**体衰**；又是**用克体**——「体衰 + 用克体」两凶叠加，正是「衰而逢克，凶甚」。

**《周易》**（归妹卦辞）
> 「归妹，征凶，无攸利。」

- 逐句解读：「征凶」→ 有所行动、有所往则凶；「无攸利」→ 没有什么有利的。
- **套盘**：本卦正是归妹（震上兑下），卦辞明说「征凶无攸利」——急进、主动出击都有凶、无所利，印证「宜守不宜攻、别急着动」。

**⑤ 结论摘要**

凶（16/100，**下平**）。用克体（金克木）对方压制、卦气衰（木受月令酉金克）天时不助，**衰而逢克，凶甚**；互卦既济「初吉终乱」、变卦双雷「动而反复」，求财主「财压制你、时机不利、动则有凶」，宜避、宜缓、宜守。

**白话**：说人话——这事眼下**是凶的，别碰**。财/对方压着你打（用克体），你又在最弱的月份（体衰），还赶上「急进有凶」的卦（归妹）——硬上必吃亏，宜缓、宜守、宜换时机。

**⑥ 分步解读**

1. **用克体**（结论：对方压制、事难成）
   - 证据：体震木、用兑金，金克木（Det）；《梅花易数》「用克体诸事凶」。
   - 置信度：🟢 高（体用生克是确定性判定）。
   - 术语解读：体=你、用=事；用克体=「事/对方克你」，是体用生克里最凶的一档。
   - 问事解读：求财这事，财/对方压着你，你处于被动，硬求必吃瘪。

2. **卦气衰**（结论：天时不助、凶上加凶）
   - 证据：体卦木，月令酉金当令，木受克（Det）；《梅花易数》「体衰则凶」。
   - 置信度：🟢 高。
   - 术语解读：卦气旺衰=体卦五行在当月的旺相休囚；体木逢秋金=衰，衰而逢克则凶甚。
   - 问事解读：你不只是被克，还在「最弱的季节」被克——天时地利都不占，这卦凶得实在。

3. **互卦既济、变卦双雷**（结论：先吉后乱、动而反复）
   - 证据：互卦水火既济（坎上离下）、变卦震为雷（震上震下，Det）。
   - 置信度：🟡 中（互变卦的「先吉后乱」「动而反复」是释义推断）。
   - 术语解读：互卦看中段、变卦看落点；既济=「初吉终乱」、双震=「动而反复」。
   - 问事解读：中间看着能成（既济），但「初吉终乱」；结局落在「动」上，但双雷是「反复动、空动」，不是功成。

**⑦ 确定性标注（✅确定 / ⚠️不确定 / ❌矛盾）**

- ✅ 确定：本卦归妹、互卦既济、变卦震、体震木、用兑金、动爻第2——全部 Det 可复现。
- ⚠️ 不确定：吉凶「16/100 凶」、应期「约 6 日/周/月」——体用生克是流派共识但「凶到什么程度」属释义，应期是卦数粗推。
- ❌ 矛盾：无（体用生克 + 卦气旺衰一致指向「凶」，无信号冲突）。

**⑧ 时间节奏（应期）**

- 应期：卦数粗推约 6 日/周/月（兑金数、震木数合推，参考）；互卦既济「初吉终乱」——若近期有「顺」的迹象，是「先吉」，后续「终乱」要防。
- **白话**：什么时候应验？卦数粗推约 6 个单位（日/周/月），但这是粗推，具体哪天难定；重点是「别在这段时间里硬上」。应期难定，只能给「卦数约 6、宜避此期」的方向。

**⑨ 行动建议 + 风险边界**

**趋吉**：

| 维度 | 建议 |
|---|---|
| 策略 | 用克体 + 体衰 → 宜守、宜缓、宜避，不硬碰 |
| 时机 | 等体卦木得生扶（春木旺、或水来生木）之时再谋 |
| 迂回 | 体生用/用生体之外的「比和」卦象可借——换角度、换方式，不与对方正面冲 |

**避凶**：用克体——对方/环境压制，忌硬碰、忌正面冲突；体衰逢克——天时不助，忌在此时加码投入；归妹「征凶」——忌急着行动、忌主动出击。

- 今日可行的一小步：今天把「这件事最不能碰的那个雷区（对方/硬碰的点）」写下来，明确「未来 6 个单位时间内不动它」。
