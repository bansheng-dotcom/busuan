## 断卦流程

- 脚本起盘得本卦/互卦/变卦/动爻/体用。
- **起卦两条路**：先天（时间/数字）`meihua-time` / `meihua-num`；后天（触机）`meihua-guanwu <物数>`（物数占）、`meihua-shengyin <声数>`（声音占）、`meihua-zishu <字数>`（字占）、`meihua-duanfa <物卦> <方位卦>`（端法，见物+方位）。触机起卦后**必合外应断**（见下「三要十应」）。
- **断卦必经步骤 ①检索相似案例**：先跑 `python scripts/libs/case_search.py "占事" 梅花` 语义检索相似案例，再 Grep `D:\卜算\国学czhengli\txt\案例库\梅花\`（占例 14 则）佐证原文，看康节先生如何起卦、体用生克如何落到具体占事，作为断当前卦的参照——**不得跳过直接空推**。
- 断：体用生克（脚本已给，`rules.meihua(体五行,用五行)` R-MH-01）、卦气旺衰、互卦看中段机制、变卦看落点。
- **卦气旺衰（衰旺论）**：体卦宜旺、生体之卦宜旺、克体之卦宜衰——旺：震巽木旺于春、离火旺于夏、乾兑金旺于秋、坎水旺于冬、坤艮土旺于辰戌丑未月；衰则反之。`rules.meihua_wangshuai(体五行, 月支)`（R-MH-04）判旺/相/衰/休；体旺逢生则吉、体衰逢克则凶甚。
- **占断十八类**：按所问之事对应一类取「体=××、用=××」+ 生克快断（天时不分体用全观诸卦；失物以变卦定方位；疾病体宜旺逢生）。`rules.meihua_18lei(类名, 体五行, 用五行)`（R-MH-03），速查 `references/梅花十八类占.md`，断卦按类名 Grep 原文佐证。
- **三要十应（外应触机，后天起卦必查）**：后天起卦后除体用生克外**必须合外应断**——「体用为内、诸应卦为外」，内外相合才准。三要=耳（听声知吉凶）/目（观形知善恶）/心（察理知祸福）；十应=天时/地理/人事/时令/方卦/动物/静物/言语/声音/五色/写字十一类外应，以体卦为主、外应为用；衰旺论/内外论/动静/向背/静占同参。速查见 `references/三要十应速查.md`，断卦按篇名 Grep 原文佐证（双重保证）。
- **以变卦断物（变卦式八则）**：测物/断物除体用外，可取「以变卦断物」八例——泽火革变咸断伤股、地雷复变临断软物、天泽履变乾断铁器、泽火革变噬嗑断土物、雷泽归妹变睽断铁、泽天夬变兑断破磁盘、天水讼变兑断求财空望：变出何卦、变爻属何五行，即以该五行断物类。`rules.meihua_bianyao_shefu(变爻五行)`（R-MH-05）给物类候选（金=铁器金属破磁盘、木=软物文章、土=土物瓦石、火=火类光明、水=水类柔软）。出处《梅花易数·变卦式八则》，断卦 Grep 原文佐证。

## 输出格式（确定性骨架 + 盘面解读 + 全段白话，强制）

> 输出契约 **10 段**，每段「考据层 + 白话层」双轨：考据给可查证依据，白话给听得懂的人话。**缺白话＝不合格**。
> 核心：盘面事实（Det/Sto）永远为真，不确定只活在流派分歧（Und）。断语 = claim + evidence + confidence（🟢🟡🔴）。

1. **排盘**：`cast.py meihua-time --time` 的本/互/变三卦 + 动爻 + 体用**完整展示**。起盘 Sto（--time 可重放），卦象/体用/动爻 Det，吉凶 Und。
2. **盘面解读**：这个盘每行怎么读——本卦/互卦/变卦/体用生克/卦气旺衰各代表什么（白话，逐关键点，至少 4 项）。
3. **原文**：引经据典**全文**（书名 + 行号，可复核）。
4. **原文解读**：逐句白话翻译 + 套到本盘。
5. **结论摘要**：吉凶总断一句话 + **七级评级**（上上/上吉/中上/中平/中下/下平/下下，对应 0-100）+ 白话版。
6. **分步解读**：每条断语 claim + evidence + confidence（🟢🟡🔴）+ 术语解读 + 问事解读。
7. **确定性标注**：✅确定（Det/Sto 可复现）/ ⚠️不确定（Und 流派分歧 + 释义推断）/ ❌矛盾（信号冲突，无则说「无」）。
8. **时间节奏**：应期（能断则断，断不出明说「应期难定」）+ 白话。
9. **行动建议**：趋吉 + 避凶 + 白话 + 今日可行的一小步。
10. **风险边界**：limitation + 判断停在哪 + 免责。

- 断语 = claim + evidence + confidence，原文在关键判断处引用，不贴 `[原文]`/`[规则推演]` 标签；白话用第二人称「你」。
- 独立评估者：`case_search.py "占事" 梅花` 相似案例 + 案例库 Grep 佐证；体用生克/卦气旺衰由 `rules.py`（R-MH-01~04）结构化判定，主判与案例/原文不一致标「信号冲突」并降级。

### 输出样例（求财 · 雷泽归妹 → 震为雷，用克体）

> 盘面为固定测试盘（`--time "2026-10-09 10:30"` 可重放），不是真实用户预测。

**① 排盘（盘面事实）**

- 起盘 Sto（--time 可重放）；本/互/变三卦、动爻、体用 Det；吉凶 Und（体用生克、卦气旺衰属流派）。
- limitation：卦象事实只记录三卦/动爻/体用/卦气；不得由卦名或体用推断吉凶、金额、具体日期或人物身份。

```text
【梅花易数】公历 2026-10-09 10:30 · 农历八月廿九 巳时
本卦：雷泽归妹（震上 兑下）
动爻：第 2 爻（下卦兑）
互卦：水火既济（坎上 离下）
变卦：震为雷（震上 震下）
体用：体 = 震（木）  用 = 兑（金）  → 用克体（金克木，凶）

卦气旺衰：体卦木 · 月令酉（金）→ 衰（金克木，衰而逢克则凶甚）
吉凶评分：16/100（凶）
应期（卦数粗推）：约 6 日/周/月（仅供参考）
```

**② 盘面解读（这个盘在说什么，术语 ↔ 白话逐项对照）**

1. **本卦雷泽归妹 → 变卦震为雷**
   - 术语：归妹＝少女嫁长男、名分不正、事有反复；变出震为雷＝震动、惊、再起波澜。
   - 白话：起头这事**「名不正、位不稳」**，像没名分的凑合；走到头还是**一阵震动惊扰**，不是安稳收场。

2. **体用：体震（木）用兑（金）→ 用克体**
   - 术语：体＝你自己（此盘为震木），用＝所问之事/对方（兑金）；金克木＝**用克体，对方/环境压着你打**。
   - 白话：这事是**你被人、被环境压着走**，不是你能做主，而是被动挨着、扛着。

3. **卦气：体卦木，月令酉（金）→ 衰**
   - 术语：木旺于春、秋金当令克木；酉月木休囚受克＝体衰。
   - 白话：你自己眼下**正处在「最没劲」的当口**（秋金克木），衰上加克，凶上加凶。

4. **动爻第 2 爻（兑卦中爻）**
   - 术语：动爻＝事变的引爆点；兑中爻动＝**口舌、破损、缺口**处生变。
   - 白话：坏在**「说话/沟通/一个缺口」**上，多半是话说岔了、或哪个环节破了口。

5. **互卦水火既济**
   - 术语：互卦看中段机制；既济＝「事已定」之象，本吉，但此处夹在「用克体」里。
   - 白话：中间那段表面看着「快成了、要定下来了」，其实**是虚的、撑不住后面那一下**。

一句话：**盘面＝用克体 + 体衰逢克 + 动在口舌缺口，凶上加凶；求财不可为，宜避、宜缓、宜换方位时机。**

**③ 原文**

> 《梅花易数》:573
> 「体用之间，比和则吉，互乃中间之应，变乃末后之期。故用吉变凶者，先吉后凶；用凶变吉者，先凶后吉。体克用，诸事吉；用克体，诸事凶。体生用，有耗失之患；用生体，有进益之喜。体用比和，则百事顺遂。又卦中有生体之卦，看是何卦。」

> 《梅花易数》:572
> 「体盛则吉，体衰则凶。用克体固不宜，体生用亦非利。体党多而体势盛，用党多则体势衰。」

**④ 原文解读（逐句白话翻译 + 套到本盘）**

- 「体克用，诸事吉；用克体，诸事凶」→ 你的「体」克对方的「用」，诸事吉；反过来对方克你，诸事凶；
- 「体生用，有耗失之患；用生体，有进益之喜」→ 你泄气去生对方＝耗自己；对方来生你＝有进益；
- 「体用比和，则百事顺遂」→ 体用同五行＝顺遂；
- 「体盛则吉，体衰则凶」→ 体旺则吉、体弱则凶；
- 「用克体固不宜」→ 对方克你，本来就不好。
- **套到本盘**：本盘体震（木）、用兑（金），金克木正是「用克体，诸事凶」；又逢酉月金旺克木、体衰，落到「体衰则凶」「用克体固不宜」——两条凶诀**同时坐实**，所以是凶上加凶，不是普通小凶。

**⑤ 结论摘要**

下平（16/100，凶）。体震木被用兑金克（用克体）、又逢酉月金旺克木而体衰，**用克体 + 体衰逢克**双凶叠加，动爻在兑中（口舌缺口），求财不可为，宜避宜缓。

**白话**：说人话——这件事**眼下是被人压着打，你自己又处在最弱的当口**，坏点多半在「话没说好 / 某个环节破了口」。求财这事，现在做**容易破财、白费劲**，别硬来，先缓一缓、换个人少的方位或换个时机再说。

**⑥ 分步解读**

1. **用克体，主凶**（claim：对方/环境压制，事不可为）
   - evidence：体震木、用兑金，金克木（Det，《梅花易数》:573「用克体，诸事凶」）。
   - confidence：🟢 高（体用五行生克是盘面事实，原文直接对应）。
   - 术语解读：体用＝「体为己身、用为应事」；金克木＝用克体，事被对方/外部压着。
   - 问事解读：这笔财不是你能拿的，**对方或大环境压着你**，越主动越被动。

2. **体衰逢克，凶甚**（claim：你正处弱势，雪上加霜）
   - evidence：体卦木、月令酉金克木 → 衰（Det，《梅花易数》:572「体衰则凶」「用克体固不宜」）。
   - confidence：🟢 高（月令克体是盘面事实，规则 R-MH-04 判定）。
   - 术语解读：卦气旺衰＝体卦五行随月令的旺相休囚；秋金当令，木休囚受克＝衰。
   - 问事解读：你**此刻实力最弱**，又赶上外部打压，双重不利，别硬扛。

3. **动在口舌缺口**（claim：坏点在沟通/某个破损环节）
   - evidence：动爻第 2 爻在兑卦中爻（Det），兑为口、为缺、为破。
   - confidence：🟡 中（兑象取「口舌/缺口」是象法推演，非唯一，供参考）。
   - 术语解读：动爻＝事变的引爆点；兑象＝口、泽、缺、少女。
   - 问事解读：**说话、合同、某个「缺口」最可能出事**，谈钱前先把话对清楚。

**⑦ 确定性标注（✅确定 / ⚠️不确定 / ❌矛盾）**

- ✅ 确定：盘面事实全部可复现——雷泽归妹→震为雷、动爻第 2 爻、互卦水火既济、体震木用兑金、用克体、酉月体衰（起盘 Sto、--time 可重放；三卦/动爻/体用 Det）。
- ⚠️ 不确定：吉凶「下平 16/100」、应期「约 6 日/周/月」、以及「动爻取口舌缺口」的象义——评分与应期是 Und 流派分歧 + 释义推断，非盘面直接给出。
- ❌ 矛盾：无（用克体、体衰逢克方向一致，无信号冲突）。

**⑧ 时间节奏（病药法：病 → 药 → 应期）**

- 病：体卦木逢酉月金克而衰、用兑金克体——**木被金克，最弱之时**。
- 药：待**木气得生扶**之期——亥、子月（水来生木）、或寅、卯日/月（木旺当值）。
- 应期：卦数粗推约 **6 日/周/月**（《梅花易数》卦数应期，仅粗推）；体衰逢克，眼下不宜动，**具体成日应期难定**。

**白话**：什么时候能缓过来？等**木气被扶起来**的日子——亥、子（水生木）或寅、卯（木旺）前后；卦数粗推是 6 日/周/月这个量级，但**具体哪天别死等**，先避过眼下这段再说。

**⑨ 行动建议**

- 趋吉：避开正面冲突，把求财的「说话/合同/缺口」处先补严——对方是谁、条款是什么，落成白纸黑字；等木气生扶之期（亥子寅卯）或换到东方、木旺之方再谈。
- 避凶：用克体忌硬碰、忌加码、忌抢时机；动爻在兑（口舌缺口）——**勿争辩、勿口头承诺、勿在话头上成交**，防破财、防争执。

**白话**：现在能做的，是**把「话」和「合同」先补严实**，别在口头上答应任何钱的事；不能做的，是**跟人硬顶、往里砸钱、抢着成交**——尤其别为了面子在话头上认下这笔。

- 今日可行的一小步：今天把「这笔财最可能出问题的那个缺口（条款/口头上没讲清的地方）」找出来，写成一条清单，先不谈钱、先补漏洞。

**⑩ 风险边界**

- limitation：以上只到「用克体、体衰逢克、动在口舌缺口，求财不可为、宜避宜缓」；具体金额、具体哪天成败、对方是谁，本卦给不出确定答案，不硬断。
- 判断停在哪：能确定的停在「求财凶、不宜为、宜避缓、等木气生扶」；赚多少、必败与否不在本术信号范围。一事一占，同一问题勿反复起卦。

本/互/变三卦 + 动爻 + 体用齐全；体用生克、卦气随月令。

## 交叉验证

体用生克 / 卦气旺衰 / 互变卦 / 动爻。

## 断卦规则

- 用克体→凶（宜避/缓）；体克用→小吉（费力可成）；体用比和→吉；用生体→吉；体生用→泄气小凶。
- 按问事对应一类（求财体克用有财、官讼体宜旺用宜衰、失物变卦定方位…）→ `rules.meihua_18lei`（R-MH-03）。
- 体卦当令则旺、得月令生则相、受月令克则衰；体旺逢生吉、体衰逢克凶甚 → `rules.meihua_wangshuai`（R-MH-04）。
