- 起盘：`cast.py qizheng`（可 `--time`；脚本已排七政日月金木水火土、四余罗计孛气的黄经落宫、十二宫、庙旺落陷、相位、断语）。流年大限小限：`cast.py qizheng-liunian 出生年 命宫地支 流年年份`。

## 输出格式（确定性骨架 + 盘面解读 + 全段白话，强制）

> 输出契约 **10 段**，每段「考据层 + 白话层」双轨：考据给可查证依据（书名 + 行号，`grep -n` 可复核），白话给听得懂的人话（第二人称「你」）。**缺白话＝不合格**。
> 核心：盘面事实（Det/Sto）永远为真，不确定只活在流派分歧（Und）。断语 = claim + evidence + confidence（🟢🟡🔴）。

1. **排盘**：`cast.py qizheng` 七政四余黄经落宫/十二宫/庙旺落陷/相位**完整展示**。生时/地点 Sto，星曜黄经落宫 Det，庙旺落陷/吉凶 Und。
2. **盘面解读**：这个盘每行怎么读——命宫命度、七政落宫、四余、相位各代表什么、此盘呈现什么象（术语 ↔ 白话逐项对照，至少 4 项）。
3. **原文**：引经据典**全文**（书名 + 行号；主典籍《张果星宗》）。
4. **原文解读**：经文逐句白话翻译——它讲什么规则、怎么套到本盘。
5. **结论摘要**：一句话总断 + **七级评级**（上上/上吉/中上/中平/中下/下平/下下）+ **六维白话概括**（性格/事业/财运/感情/身心/阶段，六句，每句＝结论＋依据半句）。
6. **分步解读**：每条断语 claim + evidence + confidence（🟢🟡🔴），每条配「术语解读 + 问事解读」。
7. **确定性标注**：✅确定（Det/Sto 可复现事实）/ ⚠️不确定（Und 流派分歧 + 释义推断）/ ❌矛盾（信号冲突）；三类都点到，无矛盾明说「无」。
8. **时间节奏**：**大限/流年节奏**（宫限 + 相位流转 + 白话）；应期能断则断，断不出明说「应期难定」。
9. **行动建议**：趋吉（可乘之机 + 行动）+ 避凶（风险 + 规避）+ 白话版 + 今日可行的一小步。
10. **风险边界**：limitation（不得由星曜名/宫位名推断吉凶、金额、具体日期、人物）+「判断停在哪」+ 免责。

- **独立评估者**：主路径为 ephem+Meeus 精算（已从线性近似升级，见 libs/qizheng.py 头注）；暂无第二天文引擎做对抗复核，标记**待做**——断卦结论按相位/庙旺/宫位 Grep 原文佐证，冲突降级。
- **结构化双轨**：`cast.py qizheng ... --json` 出盘面事实层 JSON（`schema=qizheng-panfact-v1`），与散文并存。

**② 盘面解读（这个盘在说什么，术语 ↔ 白话逐项对照）**

1. **命宫午宫（狮子）**
   - 术语：命宫落午＝狮子座，午为太阳入庙之地，主自尊、要强、重面子、有领导欲；命度主看午宫所属之宿。
   - 白话：你骨子里要强、爱面子、想当头，是「明着来、不吃暗亏」的性格。

2. **太阴旺·官禄宫（强宫）**
   - 术语：太阴＝身星（月躔处）、主情志与名望；落官禄宫又逢「旺」，且官禄是强宫——主事业有名望、得贵人助、情感丰富。
   - 白话：你的贵人缘和名声都在「事业」这条线上——做事有人帮、越做越有名，是张「事业体面」的盘。

3. **木星庙·财帛宫（强宫）**
   - 术语：木星＝岁星、第一吉星，落财帛宫且入庙＝财帛得吉星拱照，主财运亨通、宜投资；但同宫有罗睺（四余凶星之一），主财运大起大落、防意外破耗。
   - 白话：你有赚钱的命，尤其适合「靠扩张、增长」的财；但钱来得快也去得快，得防「赚了大钱又一把亏掉」。

4. **金星旺·相貌宫 + 太阳平·相貌宫**
   - 术语：相貌宫得太阳、金星同守（金星还旺），主外貌气质佳、异性缘好、注重仪表。
   - 白话：你长得不差、气质好、招人喜欢，靠「第一印象」能加分。

5. **太阳-太阴六合（吉）与太阴-金星刑（凶）**

**④ 原文解读（逐句白话翻译 + 套到本盘）**

- 「次察身星，即月躔处也」→ 第二步看「身星」，就是太阴（月亮）所在的位置，它主你后天情志、名望与际遇；
- 「以二十八宿为本…十一曜为用」→ 以二十八宿为坐标、日金木火土水月气孛罗计十一曜为用神，逐星看落宫庙旺生克；
- **套到本盘**：你命度在午（狮子）、身星＝太阴落官禄卯宫且旺相——按果老「次察身星」，你后天的名望与际遇落在事业，是「以身星得地」的吉象。

- 「强宫者，谓命宫、官禄、田宅、妻妾、男女、福德、财帛」→ 命宫、官禄、田宅、妻妾、男女、福德、财帛这七宫是「强宫」，星落强宫者力量旺；
- 「财帛次弱…居强宫者旺」→ 其中财帛是「次强」（略弱于命宫），但仍是强宫；星曜落在强宫就「旺」；
- **套到本盘**：你太阴落官禄（强宫）、木星落财帛（强宫），两吉星都落在强宫、又逢旺庙——这是「事业、财运双得地」的根据，也是你此盘「平稳偏吉」的底气。
