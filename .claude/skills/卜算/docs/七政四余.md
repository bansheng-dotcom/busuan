## 输出格式（确定性骨架 + 盘面解读 + 全段白话，强制）

> 输出契约 **10 段**，每段「考据层 + 白话层」双轨：考据给可查证依据（书名 + 行号，`grep -n` 可复核），白话给听得懂的人话（第二人称「你」）。**缺白话＝不合格**。
> 命理类（八字/紫微/七政四余）比一事一占多 3 段——⑤ 星曜体系、⑥ 专项断事六维、⑦ 交叉验证——这是终身命理的深度所在。
> 核心：盘面事实（Det/Sto）永远为真，不确定只活在流派分歧（Und）。断语 = claim + evidence + confidence（🟢🟡🔴）。

1. **排盘**：`cast.py qizheng` 全量盘面**表格化展示**（七政落宫表 + 四余落宫表 + 相位表）。生时 Sto，星曜黄经/落宫/庙旺 Det，吉凶 Und。
2. **盘面解读**：命宫 + 七政落宫强弱（强宫/弱宫）+ 相位，术语解读 ↔ 问事解读逐项对照。
3. **原文 + 原文解读**：每条原文 = 书名 + 全文 + 出处行号，紧跟「逐句白话翻译 + 套到本盘」，原文与解读**配对呈现**。
4. **命主概要**：一句话定性（命宫/强星/弱星/相位/层次）+ 七级评级 + 六维白话概括，精讲。
5. **星曜体系**：七政落宫强弱（强宫/弱宫表）+ 四余落宫 + 相位吉凶，精讲。
6. **专项断事**：六维展开（性格/事业/财运/婚姻/健康/子女），每维 = 结论 + 原文引用 + 术语解读 + 问事解读。
7. **确定性标注**：星曜强弱/相位交叉验证 + 矛盾调和 + ✅/⚠️/❌。
8. **时间节奏**：大限小限 + 关键流年 + 近期建议。
9. **行动建议**：趋吉 + 避凶 + 白话 + 今日可行的一小步。
10. **风险边界**：limitation + 判断停在哪 + 免责。

- **结构化双轨**：`cast.py qizheng ... --json` 出盘面事实层 JSON，与散文并存。

**② 盘面解读（这个盘在说什么）**

1. **命宫午宫（狮子座）**——热情、要强、表现欲
   - 术语解读：命宫＝你的根本、自我；午宫（狮子）主热情、要强、爱表现、领导欲、阳光。
   - 问事解读：你这个人天生「亮」——热情、要强、有表现欲，想做点「拿得出手」的事，但也要注意别太要面子。

2. **太阴旺坐官禄（强宫）**——事业宫坐旺星，贵气
   - 术语解读：太阴＝阴柔、情感、贵人；旺＝有力；官禄＝事业宫，且是「强宫」（《张果星宗》「强宫者，谓命宫、官禄、田宅、妻妾、男女、福德、财帛」）。太阴旺坐强宫＝事业上有贵人、有声望、得力。
   - 问事解读：你事业宫坐着一颗「旺」的月亮——事业是你命里的强项，有贵人提携、有声望，适合「靠人脉、靠声望、靠柔性的本事」往上走。

3. **木星庙坐财帛（强宫）**——财帛宫坐庙星，财运亨通
   - 术语解读：木星＝吉星、扩张、财富；庙＝有力；财帛＝财宫，强宫。木星庙坐财帛＝财运亨通、宜投资、财有源头。
   - 问事解读：你的财帛宫坐着一颗「庙」的木星——天生财运好、有投资理财的头脑，财有「扩张」的势，是命里最亮的一处。

4. **太阳、金星落相貌（弱宫）**——好星落弱宫，打折
   - 术语解读：太阳、金星都是吉星，但落在「相貌」宫（弱宫，《张果星宗》「弱宫者，谓兄弟、奴仆、疾厄、相貌、迁移」），吉星落弱宫＝力量打折、有力使不出。
   - 问事解读：你的太阳（自我）和金星（魅力/享受）都落在「弱宫」，有点「有本事但使不上劲」——才华和魅力要主动找平台，别指望自动发光。

5. **太阴-金星刑（凶相位）**——感情/享受有冲突
   - 术语解读：刑相位＝90° 冲突；太阴（情感）与金星（享乐/感情）相刑，主「感情与享受之间打架」——情感受损、或因情破财。
   - 问事解读：你命里唯一的凶相位是「月亮刑金星」——感情上容易有「要情还是要利」的纠结，或因感情、享受破点财，感情要经营、别贪恋一时之快。

**一句话收口**：**这是「太阴旺官禄、木星庙财帛」的命——事业和财运是双强项，命里最亮；但太阳金星落弱宫、太阴金星相刑，感情享受是短板，需经营。**

**③ 原文 + 原文解读（每条原文紧跟白话翻译 + 套盘）**

**《张果星宗》**
> 「强宫者，谓命宫、官禄、田宅、妻妾、男女、福德、财帛，又云：财帛次弱……居强宫者旺。弱宫者，谓兄弟、奴仆、疾厄、相貌、迁移……临弱宫者衰。」

- 逐句解读：「强宫者……居强宫者旺」→ 命、官禄、田宅、妻妾、男女、福德、财帛是强宫，星落强宫则旺；「弱宫者……临弱宫者衰」→ 兄弟、奴仆、疾厄、相貌、迁移是弱宫，星落弱宫则衰。
- **套盘**：你太阴落官禄（强宫）、木星落财帛（强宫）、水星落福德（强宫）——**吉星落强宫，旺而有成**；太阳金星落相貌（弱宫）、火星落疾厄（弱宫）、土星落兄弟（弱宫）——**平星落弱宫，力量打折**。这一强一弱，正是「事业财旺、自我魅力打折」的盘面依据。

**《张果星宗》**
> 「凡禄主与官禄并详，一宜在七强宫，二宜照命，三喜顺行，四喜庙旺……主大富贵。如在五弱宫，或入四杀位，更行留逆，故为福不纯，主人淹滞不遂。」

- 逐句解读：「禄主宜在七强宫、照命、顺行、庙旺，主大富贵」→ 禄主星落在强宫、照命、顺行、庙旺，则大富大贵；「在五弱宫、入四杀、行留逆，福不纯、淹滞不遂」→ 落在弱宫、入煞、逆行，则福气打折、事业迟滞。
- **套盘**：你的「禄主」（主财富之星，木星为吉禄）正坐财帛强宫、庙旺——**合「禄主在强宫、庙旺」，主财运亨通**；但太阳（命主）落弱宫相貌，故「自我发挥」这一环打折，需借平台、靠外力把命主的力量引出来。

**⑥ 专项断事（六维展开，每维引原文）**

1. **性格**（命宫 + 主星）
   - 结论：热情要强、爱表现、重感情——命宫午狮子主热情，太阴旺主情感丰富。
   - 原文：《张果星宗》「强宫者……居强宫者旺」（命宫主星得地则性情明朗）。
   - 术语解读：午宫（狮子）＝热情、要强、表现欲；太阴＝阴柔、情感。
   - 问事解读：你天生「亮」、要强、想做点拿得出手的事；但也要注意别太要面子、别让感情牵着走。

2. **事业**（官禄宫 + 星曜）
   - 结论：事业宫坐旺星，有贵人、有声望，走柔性/人脉路线顺——太阴旺坐官禄强宫。
   - 原文：《张果星宗》「凡禄主与官禄并详，一宜在七强宫……主大富贵」。
   - 术语解读：官禄＝事业宫；太阴旺＝贵人、声望、柔性力量。
   - 问事解读：你事业靠「人脉、声望、柔性的本事」往上走，体制内、文教、服务、咨询都顺；有贵人提携，别单打独斗。

3. **财运**（财帛宫 + 星曜）
   - 结论：财运亨通、宜投资理财，是命里最亮处——木星庙坐财帛强宫。
   - 原文：《张果星宗》「强宫者……财帛……居强宫者旺」。
   - 术语解读：木星＝吉星、扩张、财富；庙＝有力；财帛强宫＝财有源头。
   - 问事解读：你天生财运好、有投资头脑，财有「扩张」的势——适合理财、投资、做大生意；但罗睺在财帛，防财起落，别贪。

4. **婚姻**（妻妾宫 + 相位）

5. **健康**（疾厄宫 + 星曜）
   - 结论：防血光、炎症、冲动——火星坐疾厄宫，计都同宫主暗疾。
   - 原文：《张果星宗》弱宫论（疾厄为弱宫，火计临之需防）。
   - 术语解读：火星＝血光、炎症、急躁；计都＝暗疾、隐患。
   - 问事解读：你身体重点防「火」——炎症、血光、上火、急躁伤身；计都同宫提示有暗疾要早查。

6. **子女**（男女宫 + 四余）
   - 结论：子女缘有吉气——紫气坐男女宫。
   - 原文：《张果星宗》四余论（紫气为吉余，坐男女主子女缘）。
   - 术语解读：紫气＝吉余、清贵；男女宫＝子女。
   - 问事解读：你子女缘有吉气（紫气坐男女），子女清秀、有出息；但子女宫不在强宫，子女之事顺其自然、别强求。
