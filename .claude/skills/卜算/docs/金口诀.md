# 金口诀（四位速断、来意射覆）

> 分术法文档。总纲见 `SKILL.md`，多术联动见 SKILL.md 第十节。

## 起盘

```bash
python scripts/cast.py jinkoujue [地分/方位]  # 大六壬·金口诀(四位:人元/贵神/将神/地分)
python scripts/cast.py jinkoujue --json      # 金口诀·结构化双轨(散文+盘面事实层JSON)
```

## 断卦流程

- 起盘：`cast.py jinkoujue [地分/方位]`（地分缺省取时支，可传地支或八方位：北子/南午/东卯/西酉/东北丑/东南辰/西南未/西北戌；四位自下而上：地分→将神→贵神→人元）。
- 断：**四位五行生克**（人元干/贵神/将神/地分各属五行）→ **五动爻**（干克方妻动、神克干官动、神克将贼动、将克神财动、方克干鬼动）→ **三动**（方生干父母动、干生方子孙动、干方同兄弟动）→ 干神将方 16 条生克断 → **用爻**（阴阳次第五用）→ 旺相休囚（四季五行）→ 五行聚管（组合断）。`rules.jinkoujue_wudong(人元五行, 贵神五行, 将神五行, 地分五行)`（R-JK-01）给五动爻综合倾向。
- **射覆/测物/来意（射覆门）**：以**用爻**为所测之物——用爻地支取「射覆歌其一」物类（`rules.jinkoujue_shefu_zhilei(支)` R-JK-02）、用爻所临贵神取「射覆歌其二」（`rules.jinkoujue_shefu_guishen(贵神)` R-JK-03）、人元干取十干颜色+支干/五行数目+射物所在（`rules.jinkoujue_shefu_yanse_shumu(人元干,用爻支,用爻五行)` R-JK-04）；**来意**以人元与将神生克断（占来意歌「欲占来意将中看」）。速查 `references/金口诀射覆门速查.md`，断卦 Grep「射覆歌/十干颜色/支干数目/五行数目/射物所在/占来意歌」佐证原文；输出**特征画像不押物名**（`references/射覆特征画像.md`）。
- **失物/寻人（四孟遗失）**：课值四孟（寅申巳亥）为遗失、四仲（子午卯酉）为交易、四季（辰戌丑未）为婚姻出身——`shiwu_xunren.jinkoujue_shiwu(地支)`（R-SW-05）；寻人「上克下寻人在家」`shiwu_xunren.jinkoujue_xunren(生克)`；天马/驿马入课走失难寻、天盗/地煞走失阻隔。速查 `references/失物寻人速查.md`，断卦 Grep「四孟值课为遗失/占人人在家」原文佐证。
- 趋避：
  - 趋吉：四位相生、五动得吉动（官动利求官、财动利求财）、吉神（天乙/青龙/六合/太常/太阴/天后）临身旺相 → 宜进宜主动。
  - 避凶：四位相克（克人元官事、克贵神伤尊长、克将神伤妻财、克地分伤小口）、凶动（贼动防内贼诈、鬼动防灾怪口舌）、凶神（螣蛇/朱雀/勾陈/天空/白虎/玄武）临身 → 宜缓守、防口舌盗骗血伤。
  - 参断：以贵神为主、将神为相（七分灾福在此二神）；人元地分定首尾；用爻定事体（阴事/阳事/方内/方外）。
- 参考：`txt\[易藏] 六壬神课金口诀古本.txt`（入式歌解、十二将神/贵神所属、贵神起例、五子元遁、五动爻诵、三动、五合、三合全身、五行休旺、五行聚管、应期合德、十二将神/贵神所主歌、六十甲子钤、六十四课钤、云霄赋、三才赋）。
- 速查：金口诀四位断法见上；断卦按「五动爻/三动/贵神将神名」Grep 原文佐证。

## 输出格式（确定性骨架 + 四位五动解读 + 全段白话，强制）

> 输出契约 **9 段**，每段「考据层 + 白话层」双轨：考据给可查证依据（书名可复核），白话给听得懂的人话（第二人称「你」）。**缺白话＝不合格**。
> 金口诀专属骨架：四位（人元/贵神/将神/地分）定事体、五动（妻/官/贼/财/鬼）定吉凶、三动（父母/子孙/兄弟）定主事、干神将方生克断细节——这是金口诀区别于六爻/六壬的速断链条。
> 核心：盘面事实（Det/Sto）永远为真，不确定只活在流派分歧（Und）。断语 = 结论 + 证据 + 置信度（🟢🟡🔴）。

> **四层证据来源（强制，防「批得差不多」）**：每课先走四层、层层分开，一条结论只挂一个来源标签，不许把「代码事实」和「我的推演」糊在一句里。
>
> | 层 | 是什么 | 来源 | 标签 |
> |---|---|---|---|
> | ① 代码输出 | 盘面事实（四位/五动三动/生克断），**只列事实、不判断** | `cast.py` | `[代码]` |
> | ② 原文映照 | 课式特征 ↔ 典籍原文的**机械映射**（一行一条，只映射不解读） | Grep 典籍 txt | `[映照]` |
> | ③ 原文推演 | 从原文语义推导「这句落到本课是什么意思」，引原文→白话→套课 | 原文 | `[原文推演]` |
> | ④ 逻辑推演 | 四位/五动三动/生克的综合判断 | 我的推理 | `[逻辑]` |
>
> 纪律：
> 1. **原文映照是机械步骤**：起课后先列「本课可映照的特征 → 各对应哪句原文」，一行一条、只映射不解读。这一步逼每课映照出**不同的原文**，是区分两课的起点。
> 2. **原文推演引原文→白话→套课三步**，不许只贴文言再自由发挥。
> 3. **逻辑推演必须标「这是推演、不是经文」**，与代码事实/原文分开。
> 4. 段骨架映射：①排盘＝代码输出层；④原文＋解读＝映照层＋原文推演层；其余各段「术语解读/问事解读」＝逻辑推演层（须标 `[逻辑]`）。
>
> **三级结论标注 + 回溯约束（与四层互补）**：每条**结论**（非盘面事实）必标其一：
>
> | 标 | 是什么 | 对应四层 |
> |---|---|---|
> | `[原文]` | 直接引自典籍（附书名:行号） | ③ 原文推演 |
> | `[规则推演]` | 依据断法规则（四位生克/五动三动）推出的结论 | ④ 逻辑推演（规则可判定部分） |
> | `[主观推断]` | 落到当前问事的判断与建议 | ④ 逻辑推演（落到问事/建议部分） |
>
> - **回溯约束（硬）**：吉凶定性、四位判断**必须能回溯到 `[原文]` 或 `[规则推演]`**，不得凭空 `[主观推断]`；`[主观推断]` 只能用于「落到问事」与「建议」。
> - **白话文解读（每条结论必附人话）**：`[原文]` 文言、`[规则推演]`、`[主观推断]` 每一条之后，紧跟一句「白话文解读」——第二人称「你」、短句，把术语/断法翻译成人话；只翻译这条结论、不得新增吉凶定性；禁用宿命词。

1. **排盘**：`cast.py jinkoujue` 全量盘面**表格化展示**（四位表 + 五动三动表 + 生克断表）。起课 Sto，四位/五动/生克 Det，吉凶 Und。
2. **四位解读**：人元（干）/贵神/将神/地分各是什么、本盘各主何事，术语解读 ↔ 问事解读。
3. **五动三动解读**：妻动/官动/贼动/财动/鬼动 + 父母动/子孙动/兄弟动，口诀原文 + 白话。
4. **原文 + 原文解读**：五动爻诵 + 干神将方类 + 入式歌，每条原文 = 书名 + 全文，紧跟「逐句白话翻译 + 套到本课」。
5. **结论摘要**：吉凶总断一句话 + 七级评级 + 落到问事哪一面；紧跟白话版。
6. **分步解读**：四位/五动/生克断逐条，每条 = 结论 + 证据 + 置信度 + 术语解读 + 问事解读。
7. **确定性标注**：✅确定 / ⚠️不确定 / ❌矛盾；信号冲突须降级并明说。
8. **时间节奏**：应期（应期合德/旺相休囚断应期 + 白话）；断不出明说「应期难定」。
9. **行动建议 + 风险边界**：趋吉 + 避凶 + 白话 + 一小步 + limitation + 免责。

- **结构化双轨**：`cast.py jinkoujue ... --json` 出盘面事实层 JSON，与散文并存。

**② 四位解读**

1. **人元癸（水）**——外、来客、应事之端
   - 术语解读：人元=天干，主「外、来客、事情的起点」；癸水阴干，主「雨露、阴柔、流动」。
   - 问事解读：求财这事，外在的「人、事」带着「流动、阴柔」的性子（癸水），不是硬邦邦的，但也不够实。

2. **贵神天空（土，凶）**——虚诈、落空
   - 术语解读：贵神=十二贵神之一，主「天乙贵人所辖」；天空主「虚诈、惊恐、落空、奴婢走失」，是凶神。
   - 问事解读：你求财这事，「中间人/贵神」带着「虚诈、落空」的凶性——对方或中间环节有不实、会落空，要防。

3. **将神天罡（辰，土）**——事体、用事之主
   - 术语解读：将神=月将，主「事体、用事之主」；天罡（辰）主「刚猛、争斗、变动」。
   - 问事解读：这件事的「主体」是「天罡」——有变动、有争斗、要动，不是稳坐钓鱼台的事。

4. **地分巳（火）**——内、自身、本位
   - 术语解读：地分=地支，主「内、自身、本位」；巳火阴支，主「温暖、急躁」。
   - 问事解读：你自己这边是「火」——有点急、有点热，但火被上头的土泄、被干的癸水克，你自己的劲也不足。

**③ 五动三动解读（口诀原文 + 白话）**

1. **妻动（干克方）**
   - 口诀：《六壬神课金口诀》「妻动于妻妾；官财防损折；占人人在家；访人人不悦；外边来索取；卑下有口舌；论物多翻正；下旁或有缺。」
   - 白话：「妻动」主妻妾、钱财之事，但「官财防损折」——求官求财防损失折损；「外边来索取」——外面有人来要钱/要东西；「卑下有口舌」——底下有口舌是非。

2. **官动（神克干）**
   - 口诀：《六壬神课金口诀》「官动利求官；相逢禄位迁；常人公府事；有官望财难；合得官中物；休从外处干；得财防暗损；问病在喉咽。」
   - 白话：「官动」利求官升迁，但「有官望财难」——有官职的人求财难；「得财防暗损」——得财要防暗中损失；「问病在喉咽」——病在喉咙。

3. **贼动（神克将）**——本课未命中

   - 白话：「贼动」主内贼、家贼难防、内里有奸诈；防被亲近人算计、防失窃。

4. **财动（将克神）**——本课未命中

5. **鬼动（方克干）**——本课未命中

**④ 原文 + 原文解读（每条原文紧跟白话翻译 + 套盘）**

**《六壬神课金口诀》**（五动爻诵·妻动）
> 「妻动于妻妾；官财防损折；占人人在家；访人人不悦；外边来索取；卑下有口舌；论物多翻正；下旁或有缺。」

- 逐句解读：「妻动于妻妾」→ 妻动主妻妾之事；「官财防损折」→ 求官求财要防损失折损；「外边来索取」→ 外边有人来索取；「卑下有口舌」→ 下属/底下有口舌是非。
- **套盘**：本课干克方（癸水克巳火）成**妻动**，正应「官财防损折」——求财防损失折损，主「财有损、防口舌」。

**《六壬神课金口诀》**（干神将方类·将克干）
> 「将克干：喜事重重，求财必得、求名必遂、科举上榜、宜远行。」

- 逐句解读：「将克干」→ 将神克人元；「求财必得」→ 求财必然能得到；「求名必遂」→ 求名必能遂愿。
- **套盘**：本课将神天罡（土）克人元癸（水），成「将克干」，正应「求财必得」——这条是求财的吉断。

**《六壬神课金口诀》**（入式歌解）
> 「四位有克，内有刑克忧患缠：克人元主官事、克贵神伤尊长、克将神伤妻财、克地分伤小口。」

- 逐句解读：「四位有克，忧患缠」→ 四位之间有克，主有忧患缠绕；「克人元主官事」→ 克人元主官非；「克将神伤妻财」→ 克将神主伤妻财。
- **套盘**：本课四位有克（干克方、神克干、将克干），主「内有刑克忧患缠」——财、官、口舌之象交织，正是「求财防损折」的课。

**⑤ 结论摘要**

中平偏谨慎（信号冲突：妻动「官财防损折」vs 将克干「求财必得」）。**五动里「妻动」主「官财防损折、外边来索取、卑下口舌」，凶；但「将克干」又主「求财必得」，吉**——两信号相冲突，须降级：此财「可得但有损折、防口舌、防落空」（贵神天空主虚诈落空），宜小步核实、忌贪大。

**白话**：说人话——这卦求财「信号打架」：一边说「求财必得」，一边说「官财防损折、外边来索取」。合起来看：**财可能有一点，但带着损折、口舌、落空**（贵神天空是虚诈落空的凶神），别贪大、别轻信中间人。

**⑥ 分步解读**

1. **妻动（干克方）**（结论：官财防损折）
   - 证据：人元癸水克地分巳火，成妻动（Det）；《六壬神课金口诀》「妻动…官财防损折」。
   - 置信度：🟢 高（五动是确定性判定）。
   - 术语解读：妻动=干克方，主妻妾、钱财、口舌；「官财防损折」=求官求财防损失。
   - 问事解读：求财这事，有「损折」的风险——不是纯赚，是赚了也可能折损、或有口舌。

2. **将克干**（结论：求财必得）
   - 证据：将神天罡（土）克人元癸（水），成将克干（Det）；《六壬神课金口诀》「将克干…求财必得」。
   - 置信度：🟢 高。
   - 术语解读：将克干=将神克人元，是干神将方生克里的吉断，主「喜事、求财必得」。
   - 问事解读：这条是「求财必得」的吉象——财有机会得，不是完全无望。

3. **贵神天空（凶）**（结论：防虚诈落空）
   - 证据：贵神天空（土，凶）（Det）；十二贵神「天空主虚诈、惊恐、落空」。
   - 置信度：🟢 高。
   - 术语解读：贵神=中间人/天乙所辖；天空=虚诈落空的凶神，主「不实、落空」。
   - 问事解读：中间环节/对方有「虚诈、落空」的凶性——别轻信、别预付，防白忙。

4. **信号冲突降级**（结论：可得但有损、防落空）
   - 证据：妻动「官财防损折」（凶）vs 将克干「求财必得」（吉）——两信号相冲突。
   - 置信度：🟡 中（冲突调和是释义，非盘面给定）。
   - 术语解读：五动与干神将方生克两条线索吉凶相反，按「信号冲突」降级——不取有利一维硬断。
   - 问事解读：合起来——财「可能有一点」，但「带着损折、口舌、落空」，别贪大、宜小步核实。

**⑦ 确定性标注（✅确定 / ⚠️不确定 / ❌矛盾）**

- ✅ 确定：四位（人元癸/贵神天空/将神天罡/地分巳）、五动（妻动+官动）、将克干——全部 Det 可复现。
- ⚠️ 不确定：吉凶「中平偏谨慎」、应期——五动吉凶是流派共识但「轻重」属释义，应期难定。
- ❌ 矛盾：**妻动「官财防损折」vs 将克干「求财必得」信号冲突**——已降级调和为「可得但有损、防落空」，不取有利一维硬下结论。

**⑧ 时间节奏（应期）**

- 应期：金口诀应期看「应期合德」与旺相休囚；本课四季「木囚 火休 土旺 金相 水死」——土旺（贵神天空、将神天罡皆土），主「当下土旺、事在近期」，但天空主落空，应期「近而不实」。
- **白话**：什么时候应验？土旺主「近期有动」，但天空主「落空」——近期可能有「财」的动静，但易落空。具体哪天，应期难定，只能给「近期有动、防落空」的方向。

**⑨ 行动建议 + 风险边界**

**趋吉**：

| 维度 | 建议 |
|---|---|
| 路线 | 借「将克干求财必得」的吉象，小步试、小单核实，别一把梭 |
| 核实 | 贵神天空主虚诈——把中间人/对方的底细、报价、合同逐项核实 |
| 迂回 | 方生将「地载」主家人和合、喜庆——借正路、借靠谱的人脉，别走歪门 |

**避凶**：妻动「官财防损折」——防损折、防口舌，落袋为安；贵神天空——防虚诈落空，勿轻信勿预付；四位有克「忧患缠」——防官事、伤妻财、伤小口。

**白话**：现在能做的，是「小步试、逐项核实」，把中间人的底细、报价、合同查清楚（防天空虚诈）；不能做的，是贪大、轻信、预付、一把梭。记住：这课「可得但有损、防落空」，落袋为安比贪多强。
