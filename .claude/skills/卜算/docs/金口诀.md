## 断卦流程

- 起盘：`cast.py jinkoujue [地分/方位]`（地分缺省取时支，可传地支或八方位：北子/南午/东卯/西酉/东北丑/东南辰/西南未/西北戌；四位自下而上：地分→将神→贵神→人元）。
- 断：**四位五行生克**（人元干/贵神/将神/地分各属五行）→ **五动爻**（干克方妻动、神克干官动、神克将贼动、将克神财动、方克干鬼动）→ **三动**（方生干父母动、干生方子孙动、干方同兄弟动）→ 干神将方 16 条生克断 → **用爻**（阴阳次第五用）→ 旺相休囚（四季五行）→ 五行聚管（组合断）。`rules.jinkoujue_wudong(人元五行, 贵神五行, 将神五行, 地分五行)`（R-JK-01）给五动爻综合倾向。
- **射覆/测物/来意（射覆门）**：以**用爻**为所测之物——用爻地支取「射覆歌其一」物类（`rules.jinkoujue_shefu_zhilei(支)` R-JK-02）、用爻所临贵神取「射覆歌其二」（`rules.jinkoujue_shefu_guishen(贵神)` R-JK-03）、人元干取十干颜色+支干/五行数目+射物所在（`rules.jinkoujue_shefu_yanse_shumu(人元干,用爻支,用爻五行)` R-JK-04）；**来意**以人元与将神生克断（占来意歌「欲占来意将中看」）。速查 `references/金口诀射覆门速查.md`，断卦 Grep「射覆歌/十干颜色/支干数目/五行数目/射物所在/占来意歌」佐证原文；输出**特征画像不押物名**（`references/射覆特征画像.md`）。
- **失物/寻人（四孟遗失）**：课值四孟（寅申巳亥）为遗失、四仲（子午卯酉）为交易、四季（辰戌丑未）为婚姻出身——`shiwu_xunren.jinkoujue_shiwu(地支)`（R-SW-05）；寻人「上克下寻人在家」`shiwu_xunren.jinkoujue_xunren(生克)`；天马/驿马入课走失难寻、天盗/地煞走失阻隔。速查 `references/失物寻人速查.md`，断卦 Grep「四孟值课为遗失/占人人在家」原文佐证。
- 趋避：
  - 趋吉：四位相生、五动得吉动（官动利求官、财动利求财）、吉神（天乙/青龙/六合/太常/太阴/天后）临身旺相 → 宜进宜主动。
  - 避凶：四位相克（克人元官事、克贵神伤尊长、克将神伤妻财、克地分伤小口）、凶动（贼动防内贼诈、鬼动防灾怪口舌）、凶神（螣蛇/朱雀/勾陈/天空/白虎/玄武）临身 → 宜缓守、防口舌盗骗血伤。
  - 参断：以贵神为主、将神为相（七分灾福在此二神）；人元地分定首尾；用爻定事体（阴事/阳事/方内/方外）。
- 参考：`txt\[易藏] 六壬神课金口诀古本.txt`（入式歌解、十二将神/贵神所属、贵神起例、五子元遁、五动爻诵、三动、五合、三合全身、五行休旺、五行聚管、应期合德、十二将神/贵神所主歌、六十甲子钤、六十四课钤、云霄赋、三才赋）。

## 输出格式（确定性骨架 + 盘面解读 + 全段白话，强制）

> 输出契约 **10 段**，每段「考据层 + 白话层」双轨：考据给可查证依据，白话给听得懂的人话。**缺白话＝不合格**。
> 核心：盘面事实（Det/Sto）永远为真，不确定只活在流派分歧（Und）。断语 = claim + evidence + confidence（🟢🟡🔴）。

1. **排盘**：`cast.py jinkoujue --time` 的四位（人元/贵神/将神/地分）+ 五动爻 + 生克断**完整展示**。起盘 Sto（--time 可重放），四位/五动/用爻 Det，吉凶 Und。
2. **盘面解读**：这个盘每行怎么读——四位五行/五动爻/生克断/用爻/旺相各代表什么（白话，逐关键点，至少 4 项）。
3. **原文**：引经据典**全文**（书名 + 行号，可复核）。
4. **原文解读**：逐句白话翻译 + 套到本盘。
5. **结论摘要**：吉凶总断一句话 + **七级评级**（上上/上吉/中上/中平/中下/下平/下下，对应 0-100）+ 白话版。
6. **分步解读**：每条断语 claim + evidence + confidence（🟢🟡🔴）+ 术语解读 + 问事解读。
7. **确定性标注**：✅确定（Det/Sto 可复现）/ ⚠️不确定（Und 流派分歧 + 释义推断）/ ❌矛盾（信号冲突，无则说「无」）。
8. **时间节奏**：应期（能断则断，断不出明说「应期难定」）+ 白话。
9. **行动建议**：趋吉 + 避凶 + 白话 + 今日可行的一小步。
10. **风险边界**：limitation + 判断停在哪 + 免责。

- 断语 = claim + evidence + confidence，原文在关键判断处引用，不贴 `[原文]`/`[规则推演]` 标签；白话用第二人称「你」。
- 独立评估者：四位生克/五动爻/用爻由 `rules.jinkoujue_*`（R-JK-01~04）结构化判定，命中后 Grep 原文佐证；五动与生克断矛盾时标「信号冲突」并降级。

### 输出样例（求财 · 人元癸 / 贵神天空 / 将神天罡 / 地分巳）

> 盘面为固定测试盘（`--time "2026-10-09 10:30"` 可重放），不是真实用户预测。

**① 排盘（盘面事实）**

- 起盘 Sto（--time 可重放）；四位/五动爻/生克断/用爻 Det；吉凶 Und（五动与生克断的取舍属流派）。
- limitation：课象事实只记录四位五行、五动爻、生克断、用爻、旺相；不得由神名或动名推断吉凶、金额、具体日期或人物身份。

```text
【金口诀】丙辰日 癸巳时 · 月将天罡（辰）· 昼贵人（亥，顺行）

四位（自下而上：地分→将神→贵神→人元）
  地分：巳（火，阴）
  将神：天罡 辰（土，阳）
  贵神：天空（土，阳，凶）——虚诈、惊恐、落空
  人元：癸（水，阴）

五动爻
  · 妻动（干克方：癸水克巳火）——占主妻妾事；有官求财不利防损折；访人不悦；外来索取
  · 官动（神克干：天空土克癸水）——利求官；常人有公府事

干神将方生克断
  · 将克干（天罡土克癸水）：喜事重重，求财必得，求名必遂，宜远行
  · 方生神（巳火生天空土）：内外和合，人广财丰，求事不隔手
  · 方生将（巳火生天罡土，地载）：家人和合，喜庆富贵，谋望有成

用爻：二阴二阳，以将为用（天罡土）
旺相休囚：木囚 火休 土旺 金相 水死（人元癸水 → 死）
```

**② 盘面解读（这个盘在说什么，术语 ↔ 白话逐项对照）**

1. **四位：人元癸（水）/ 贵神天空（土）/ 将神天罡（土）/ 地分巳（火）**
   - 术语：四位自下而上是地分→将神→贵神→人元，各属一行；此盘土众、火生土、水孤立于上。
   - 白话：盘里**土最多、又得火生**（旺），唯独你这个人元「水」孤立在最上、还是「死」地——**你自己最弱，环境（土）最盛**。

2. **贵神天空（凶）**
   - 术语：天空主虚诈、惊恐、落空、奴婢走失，是凶神。
   - 白话：关键位置上坐的是**「虚、空、骗」**——这事里**有假、有空、有不实**，别照单全收。

3. **五动：妻动 + 官动（两个「克」）**
   - 术语：干克方＝妻动（求财不利防损折），神克干＝官动（利求官、常人有公府事）。
   - 白话：盘上同时有**两个「克」**，一个主「求财不利、要损」，一个主「利当官、不利求财、防官非」——**求财这条路被两头绊着**。

4. **生克断：将克干（求财必得）+ 方生神、方生将（吉）**
   - 术语：将克干＝「喜事重重，求财必得，求名必遂」；方生神、方生将＝内外和合、喜庆富贵。
   - 白话：可是另一边又明说**「求财必得、喜事重重」**——**跟上面「求财不利」直接打架**（见 ⑦ 信号冲突）。

5. **旺相：土旺、水死**
   - 术语：四季土旺；人元癸水死于土旺之季。
   - 白话：你（水）**正处在最弱的时候**，而对方/环境（土）正旺，**强弱分明**。

一句话：**盘面＝环境土旺、你（水）孤立且死，贵神天空带虚诈，求财「不利」与「必得」两说冲突——宜按「财可得但虚、防损折、防虚诈」折中，降级看待。**

**③ 原文**

> 《六壬神课金口诀古本》:417-419
> 「干克方为妻动，歌曰：妻动于妻妾（占事主于妻妾）／官财防损折（有官求财不利，而有损折）／占人人在家（上克下，寻人在家）…」

> 《六壬神课金口诀古本》:484
> 「将克干：喜事重重，求财必得，求名必遂，科举上榜，宜远行。」

> 《六壬神课金口诀古本》:995
> 「大抵天空主虚诈不实之事，亦主斗讼，出僧道。」

**④ 原文解读（逐句白话翻译 + 套到本盘）**

- 「干克方为妻动……官财防损折（有官求财不利，而有损折）」→ 人元克地分叫妻动，主「有官职在身/沾官的人求财不利、还会损折」；
- 「将克干：喜事重重，求财必得，求名必遂」→ 将神克人元＝喜事连着来，求财能得、求名能成；
- 「大抵天空主虚诈不实之事」→ 天空这一神，专管「假、虚、空、骗、不实」。
- **套到本盘**：本盘正是干癸水克方巳火＝**妻动**（求财不利防损折），又是将天罡土克干癸水＝**将克干**（求财必得）——两处原文在「求财」上**自相矛盾**；而贵神恰是**天空**（虚诈不实），说明「求财必得」这一半也要打折：**财不是没有，是虚的、要防损折防骗**。

**⑤ 结论摘要**

中平（52/100）。「妻动求财不利」与「将克干求财必得」两说冲突（信号冲突，降级看待），贵神天空又主虚诈——折中为**财可得、但虚而不实，须防损折、防虚诈、防官非口舌**。

**白话**：说人话——这课**求财的信号是拧着的**：一边说「不利、要损」，一边说「必得」。合起来就是：**钱可能有，但虚、要打折扣，别全信别人画的饼，还要防中途损一笔、防口舌官非**。别把它当「稳稳到手」，当「可能有、但要留一手」。

**⑥ 分步解读**

1. **求财信号冲突，降级**（claim：求财吉凶难定，取折中）
   - evidence：妻动（干克方，求财不利防损折）+ 将克干（求财必得）同时成立（Det，《六壬神课金口诀古本》:417「官财防损折」vs :484「求财必得」）。
   - confidence：🟡 中（两处原文各自明确，但方向相反，属五动与生克断的层次冲突，故降级）。
   - 术语解读：五动爻看「大意」，生克断看「具体」；两者打架时，以「贵神为相、七分灾福在此」折中。
   - 问事解读：求财**不能只按吉断，也不能只按凶断**——结果要看你怎么把「虚」的地方做实。

2. **贵神天空主虚诈**（claim：事有不实，防骗防空）
   - evidence：贵神天空临课（Det，《六壬神课金口诀古本》:995「天空主虚诈不实之事」）。
   - confidence：🟢 高（贵神落天空是盘面事实，原文直接对应）。
   - 术语解读：贵神＝课中定吉凶的「主」，天空＝虚诈、落空、惊恐之凶神。
   - 问事解读：对方或中间环节**有水分**，谈钱先验真假，别信口头承诺。

3. **人元水死、土旺**（claim：你处弱势，环境占上风）
   - evidence：旺相休囚——土旺、水死（Det，《六壬神课金口诀古本》·五行休旺）。
   - confidence：🟢 高（四季旺相是盘面事实）。
   - 术语解读：四季土旺，水死于土旺之季；人元癸水＝「你」落死地。
   - 问事解读：**此刻你议价、推进的底气不足**，别硬争，先借势、先做实。

**⑦ 确定性标注（✅确定 / ⚠️不确定 / ❌矛盾）**

- ✅ 确定：盘面事实全部可复现——四位（人元癸/贵神天空/将神天罡/地分巳）、五动爻（妻动+官动）、生克断（将克干+方生神+方生将）、用爻（以将为用）、旺相（土旺水死）（起盘 Sto、--time 可重放；四位/五动/用爻 Det）。
- ⚠️ 不确定：吉凶「中平 52/100」、应期、以及「五动与生克断孰主孰辅」的取舍——评级与应期是 Und 流派分歧 + 释义推断。
- ❌ 矛盾：有——「妻动求财不利」与「将克干求财必得」**信号冲突**，已按贵神天空主虚诈折中、**降级**为中平看待（信号冲突，仅供参考）。

**⑧ 时间节奏（病药法：病 → 药 → 应期）**

- 病：人元癸水死于土旺之季（你最弱）、贵神天空（虚诈落空）、妻动（求财不利防损折）。
- 药：逢**水气生扶、土气减退**之期——亥、子（水旺）、或土休囚之月。
- 应期：将克干「宜远行、求财必得」主速，但天空主虚、水死主弱，**应期难定**，明说「应期难定」；可留意亥子日（水旺助你）前后是否「把虚做实」。

**白话**：什么时候有准信？这课**快中有虚、弱中有得**，具体日子说不死——先别按「必得」倒计时，等**水旺的日子（亥、子）**看你这边能不能把局面扳回来再说。

**⑨ 行动建议**

- 趋吉：取「将克干求财必得 + 方生将地载喜庆」之吉——把「虚」的部分做实（验对方资质、落书面条款），走**正当程序/远行外拓**（将克干宜远行）反而能成。
- 避凶：贵神天空防虚诈——**勿轻信口头承诺、勿被画饼**；妻动防损折——**勿加码、勿垫资**；官动防公府事——**求财别沾官非、别打擦边球**。

**白话**：能做的，是**把对方说的话一件件落成白纸黑字、走正规程序**，正儿八经地做反而能成；不能做的，是**听信口头打包票、往里垫钱加码、碰官非擦边球**——这课最怕「虚」和「损」。

- 今日可行的一小步：今天把「这笔财里最虚、最没落字据的那一块」挑出来，要求对方补一份书面确认，先不转钱。

**⑩ 风险边界**

- limitation：以上只到「求财信号冲突、天空主虚诈、水死土旺，财可得但虚、防损折防虚诈防官非」；具体金额、具体哪天到账、对方是谁，本课给不出确定答案，不硬断。
- 判断停在哪：能确定的停在「财虚、须防损折防骗、宜走正规程序」；赚多少、必得与否不在本术信号范围。

## 交叉验证

四位生克 / 五动爻 / 用爻 / 旺相。
