## 断卦流程

- 起盘：`cast.py bazi 年 月 日 时 分 秒 性别`（脚本已排四柱、十神、五行、纳音、大运〔起运规则透明化：年干阴阳+性别定顺逆、数至最近「节」按 3 天=1 年折算、独立交叉校验〕、日主长生、旬空、神煞 31 个〔按 7 类分组〕、地支刑冲合害〔六合/六冲/三合/半三合/三刑/六害/相破〕；可加 `--lon`/`--dst`/`--zishi same|next`〔晚子时 23:00-24:00 换日口径，默认 00:00 换日并提示流派分歧〕）。
- **断命主线（八字断语固定走这条，勿跳步）**：
  1. **起盘**：脚本已排四柱 + 藏干十神矩阵 + 地势 + 四柱空亡 + 纳音 + 命宫胎元 + 交运时间 + 大运（详见「起盘」节）。
  2. **核心格局当头**：一句话点题（如「建禄格·比劫重重·食伤生财」），再展开论证——不得一上来就「破格有救」四个字。
  3. **十神逐干动态**：逐柱讲透干/支十神如何互动（如「年干乙木偏印生身、月干壬水正官合日主化木→官星贪合入印，贵气化为学问名分」）。
  4. **日柱原文诗**：Grep《三命通会》「六X日诗」引日柱断语（如丁丑「丑中金库禄荣丰」、六丁日用庚辛为财壬为官癸为偏官喜西北金水），落到「一生与财/权打交道」。
  5. **身强/身弱喜忌**：扶抑——身强喜克泄耗（官杀/食伤/财），身弱喜生扶（印/比劫）。
  6. **调候用神**：《穷通宝鉴》按月取（如五月丁火喜壬癸润泽、庚金发水源）。
  7. **用神·喜神·忌神分开写（禁「喜忌并称」）**：用神＝对治全局核心矛盾那一位（通常一个五行）；喜神＝生用神之神/次喜；忌神＝坏用神之神；三者各自单独点名 + 单独理由 + 落到具体干支。
  8. **大运断语**：逐运干支十神 + 引动的合冲刑害，落到「这十年如何」（如己卯运＝食神泄秀生财 + 卯木枭神夺食、亥卯未木局）。
  9. **流年断语**：当年干支十神 + 合冲刑害 + 评分，落到「今年如何」（用 `bazi-liunian` 的真实数据，勿心算流年）。
  10. **病药框架**：`bingyao(旺衰, 格局, 喜, 忌)` → 「病在X、药为Y」（如「病在伤官旺泄身，药为印星生身制伤」），已并入 `mingli_analysis` 输出「【病药框架】」。
  11. **对抗判别器**：`python scripts/libs/adversarial.py 年 月 日 时 分 秒 性别` 独立「旺相休囚死」重推 vs 主路径，找旺衰/格局/喜忌分歧——有分歧标「信号冲突」降级。
- **确定性骨架（盘面事实 + 断语分离）**：盘面事实 = `cast.py` 脚本输出，带「确定性 Det/Sto/Und」标注 + `limitation`（不得由盘面推断吉凶/日期/人物）；断语另起，不与事实混。
- **旺衰量化 + 格局成破 + 合化**（`bazi` 已并入，`libs/bazi_liunian.py`）：①旺衰量化得分（得令40+得地30+得势15+得生15，根气按本气/中气/余气分权，>55强/45-55中和/<45弱——避免布尔法把「中气比劫根」当强根，如戊土在子月仅午中气己土应判弱）；②格局成破救应（`tiaohou.ding_ge` 定格 + `GE_JU_JIU_YING` 表：正官格逢伤官→破格、有印→破格有救）；③干支合化条件判断（五合/六合/三合化神得令/透干/有本气根→成化，否则合而不化）。规则 `R-BZ-08~09`。
- **流年/流月深度**（`bazi-liunian`/`liuyue`，`libs/bazi_liunian.py`）：在「干支+生肖+纳音+五行生克」之上补——①流年/流月干支与原局四柱及大运的合冲刑害叠合（`xingchong.zhi_relation`/`gan_relation`）；②岁运并临（流年干支==大运干支）、天克地冲（干克日干/大运干且支冲日支/大运支）；③犯太岁（值/冲/刑/害/破年支）；④喜忌判定（旺衰四维综合→扶抑喜忌，得令一维冲突时标「信号冲突降级」）；⑤吉凶评分（10~90 透明加权）。规则 `R-BZ-02~07`；断语按「岁运并临/天克地冲/犯太岁」Grep《三命通会》《渊海子平》《子平真诠评注》原文佐证。
- **合婚**（`hehun [男时 女时]`，`libs/hehun.py`）：六维——生肖、日主五行、夫妻宫、纳音（原有）+ 双方四柱全盘比对（年/月/日/时逐柱干支合冲刑害，时柱缺省降级）+ 用神喜忌互补（旺衰→喜忌五行→看对方日主补还是冲）；返回结构化 dict。时柱未知标「三柱比对、时柱降级」。断语按「合婚/纳音/六冲/相刑」Grep 原文佐证。
- **三类有信号断法细化**（MingLi-Bench 实测：健康 52.9%、事业 40%、财运 38.5%，均显著高于随机 25% 与「猜众数答案」29.1%；学业 18.2%、性格 28.6%、外貌 33.3% 为无信号，不作主断）：
  - **健康**：五行应脏腑——木主肝胆、火主心小肠、土主脾胃、金主肺大肠、水主肾膀胱；某五行过旺或过弱，对应脏腑易病；日主旺相抗病力强、休囚易病；官杀克身无制主病灾、印星护身主安康。`[原文]`《三命通会》论疾病：「凡水土木相逢于无气之处主蛊气肠胀吐逆之疾；金水火相逢于无气之地主痢疾…」——只断「哪方面健康需注意」的方向，**慎断具体病名、具体年份**。
  - **事业**：官杀＝职位/管理/体制，印星＝文职/专业/幕后，食伤＝才艺/技术/自由职业，财星＝经商/财务，比劫＝合伙/竞争/体力；官印相生利仕途、食伤生财利经商、身强任杀利掌权。给「适合的方向」，标「倾向」，不作「必然某职业」铁断。
  - **财运**：身强能任财→财运顺、可担财；财多身弱→「富屋贫人」、财来财去守不住；食伤生财→靠技术/才艺变现；比劫夺财→防破财、合伙分利。给「财运模式」方向，慎断「某年赚/破多少」的精确数额。
- 趋避：
  - 趋吉：大运流年行喜用神之地（扶抑/调候/通关得宜）乘势进取；岁运合会成吉局有贵人助。

## 输出格式（确定性骨架 + 盘面解读 + 全段白话，强制）

> 输出契约 **10 段**，每段「考据层 + 白话层」双轨：考据给可查证依据（书名 + 行号，`grep -n` 可复核），白话给听得懂的人话（第二人称「你」）。**缺白话＝不合格**。
> 核心：盘面事实（Det/Sto）永远为真，不确定只活在流派分歧（Und）。断语 = claim + evidence + confidence（🟢🟡🔴）。

1. **排盘**：`cast.py bazi` 四柱 + 十神 + 藏干 + 纳音 + 大运**完整展示**（含神煞、刑冲合害、起运/交运）。生时/性别 Sto，四柱/十神/大运 Det，吉凶/喜忌 Und。
2. **盘面解读**：这个盘每行怎么读——四柱、十神、藏干、大运各代表什么、此盘呈现什么象（术语 ↔ 白话逐项对照，至少 4 项）。
3. **原文**：引经据典**全文**（书名 + 行号；主典籍《三命通会》《穷通宝鉴》《子平真诠评注》）。
4. **原文解读**：经文逐句白话翻译——它讲什么规则、怎么套到本盘。
5. **结论摘要**：一句话总断 + **七级评级**（上上/上吉/中上/中平/中下/下平/下下，对应 0-100）+ **六维白话概括**（性格/事业/财运/感情/身心/阶段，六句，每句＝结论＋依据半句）。
6. **分步解读**：每条断语 claim + evidence + confidence（🟢🟡🔴），每条配「术语解读 + 问事解读」。
7. **确定性标注**：✅确定（Det/Sto 可复现事实）/ ⚠️不确定（Und 流派分歧 + 释义推断）/ ❌矛盾（信号冲突）；三类都点到，无矛盾明说「无」。
8. **时间节奏**：**大运/流年节奏**（当前大运 + 关键流年 + 白话）；应期能断则断，断不出明说「应期难定」。
9. **行动建议**：趋吉（可乘之机 + 行动）+ 避凶（风险 + 规避）+ 白话版 + 今日可行的一小步。
10. **风险边界**：limitation（不得由十神名/神煞名推断吉凶、金额、具体日期、人物）+「判断停在哪」+ 免责。

- **独立评估者**：`libs/adversarial.py` 独立重推旺衰 vs 主路径，分歧标「信号冲突」降级。
- **结构化双轨**：`cast.py bazi ... --json` 出盘面事实层 JSON（`schema=bazi-panfact-v1`），与散文并存。

**② 盘面解读（这个盘在说什么，术语 ↔ 白话逐项对照）**

1. **日主戊土（身弱 30 分）**
   - 术语：戊土＝你自己，如高山厚土；生于酉月（金旺）＝土被金泄气，得令不足、根气薄，故判「弱」。
   - 白话：你是块厚土，可惜生在秋天金旺的月份，被「金」抽走了劲——底子要强但眼下气不足，得靠「火」「土」来帮。

2. **月支酉金·伤官透干 → 伤官格**
   - 术语：月支辛金＝伤官（我生之、泄我之秀气），伤官主聪明、才艺、表达欲、不服管；月令定格为「伤官格」。
   - 白话：你的才华、口才、那股「不服就干」的劲儿，是你最大的本钱，也是你最大的漏气口——才华外露但耗自己。

3. **月干丁火正印 → 伤官佩印**
   - 术语：丁火正印生身、同时制住伤官，「伤官佩印」＝用学问/文凭/长辈把才华收住、引成正路（《子平真诠》以「佩印」为伤官格之救）。
   - 白话：好在有个「印」罩着你——读书、学历、长辈贵人，能把你的才华引上正途，不至于横冲直撞。

4. **时干甲木七杀 + 时支寅木（坐长生）**
   - 术语：甲木七杀克身、主压力/挑战/责任/竞争；寅木是七杀的根、又带驿马，杀旺根深。
   - 白话：你这辈子「压力源」很清晰——总有人在逼你、总有竞争和责任压着；但你身弱，硬扛会累。

5. **日支子水正财（妻星）**
   - 术语：日支＝夫妻宫，藏癸水正财＝妻星坐守；但水为忌神，财为忌＝「财来财去、守不住大财」。
   - 白话：婚姻宫有正财坐守，异性缘不缺；可水是你的忌神，钱和感情都偏「现实、流动」，难攒大钱、感情得经营。

一句话：**盘面＝才华外露、靠印收住的「伤官佩印」格，身弱需火土帮扶；忌木水金，财为忌、压力大，是块「要靠贵人托、不能硬扛」的厚土。**

**③ 原文**

> 《穷通宝鉴》:616
> 「八月戊土，金泄身寒，赖丙照暖，喜水滋润，先丙後癸，不必木疏。」

> 《子平真诠评注》:130
> 「伤官喜佩印以制伏，生财以化伤。」

> 《三命通会》:110
> 「戊子巳丑水中之火，又曰神龙之火，遇水方贵，为六气之君火也。五行要论云：戊子含精神辉光全实之气，作四时保生之福，入贵格则为大人君子，器宇含弘，富贵终吉。」

**④ 原文解读（逐句白话翻译 + 套到本盘）**

- 「八月戊土，金泄身寒」→ 八月（酉月）的戊土，被当令的旺金泄气、身子发凉发虚；
- 「赖丙照暖，喜水滋润」→ 要靠丙火来照暖（补阳气），也喜一点癸水滋润（财来养身）；
- 「先丙後癸，不必木疏」→ 取用顺序：先丙火、后癸水，不需要甲木来疏土（土此时不板结）。
- **套到本盘**：你正是八月戊土，喜丙火照暖——原局月干是丁火（非丙）却无丙透、调候略欠，好在日主弱时「火」本就是喜神，方向一致；「不必木疏」也印证了你时干甲木七杀非所用、反而克身，是压力而非助力。
