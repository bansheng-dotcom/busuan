### 三吉门落宫

- `[原文]`《烟波钓叟歌》：「如得开休生三吉门，又合上下盘三奇是也。」（烟波钓叟歌句解:117）
- `[规则推演]` 本盘三吉门开(乾)、休(坎)、生(艮)分别落西北/正北/东北，此三方此时为吉方，宜向此三方行事、出行、布局。
- **术语解读**：奇门八门里「开、休、生」是三吉门，落在哪个方位，那个方位此刻就吉利、宜动。
- **问事解读**：你要行动/出行/谈事，优先选西北、正北、东北这三个方向，比别的方位顺。

### 五不遇时（凶）

- `[原文]`《奇门遁甲秘笈大全》：「五不遇时龙不精，号为日月损光明，时干来尅日干上。」（奇门遁甲秘笈大全:89）
- `[规则推演]` 时干癸（水）克日干丙（火）→ **五不遇时**，主诸事不顺、百事不宜，此时宜静不宜动。
- **术语解读**：五不遇时是奇门里最忌的时辰之一——"时干克日干"就是"这个时辰克你"，像逆风走路。
- **问事解读**：这个时辰本身不吉，重要的事别赶这个点办，改个时辰更稳妥。

### 值符值使

- `[原文]`《奇门遁甲秘笈大全》：「加丙为青龙返首，动作大吉，若逢迫、墓、击、刑，吉事成凶。」（奇门遁甲秘笈大全:397，论格局与迫墓击刑）
- `[规则推演]` 值符天柱落巽、值使惊门落兑——值使惊门属凶门，落兑宫无吉格成局；又值五不遇时，整体格局偏静守，不宜冒进。
- **术语解读**：值符是"当前掌权的主星"、值使是"当前掌权的门"；值使落凶门（惊），说明这盘的主调偏"不宜大动"。
- **问事解读**：这盘整体信号是"先别动、先别谈"，尤其重要决策缓一缓；要动也只在三吉门方位、且避开五不遇时。
