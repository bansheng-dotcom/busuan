## 断卦流程

- 起盘：`cast.py zhiwei 年 月 日 时 性别`（公历输入；脚本已排命宫身宫、五行局、十二宫、十四主星、辅星、四化、大限、小限〔命宫起男顺女逆·12年一轮〕、命宫三方四正、空宫标记）。
- **四化飞星**（`zhiwei.py`，输出已并入 `cast.py zhiwei`）：禄权科忌四化星各飞落哪个宫（地支 + 宫名），如「禄入夫妻宫(太阳亥)」，断四化飞星派核心（化禄入财帛/夫妻主财婚喜，化忌入命/财帛/夫妻/疾厄主对应之失）。四化星含辅星（文昌科/文曲忌/右弼科/左辅科）已计入飞星，命盘辅星同步标注四化。
- **宫干四化（飞星派/北派）**（`zhiwei.py`，输出已并入）：十二宫各自天干起四化飞入星曜所在宫（如「命宫(己)禄武曲→子女」）。后世流派、《全书》以生年四化为主，本层只作盘面事实，断法标 [规则推演]。
- **飞星四化全景**（`zhiwei.feixing_panorama`，输出已并入）：在宫干四化基础上检测**循环忌**（两宫互忌）、**自化忌**（化忌飞入本宫，自耗自缚）、**忌冲**（忌飞入对宫冲命/身宫）——断法标 [规则推演]，忌冲命宫主身心/运势受压。
- **格局判定**（`libs/ziwei_geju.py`，输出已并入）：18 格局结构化规则（15吉/1变动/2凶，含落宫/破格/原文出处），命中即出断语+出处；`rules.ziwei_geju_resolve`（R-ZW-01）聚合冲突裁决。断卦按格局名 Grep 原文佐证。
- **断语知识包**（`libs/ziwei_knowledge.py`）：十四主星断语 + 十二宫主事 + 四化含义（附《全书》原文）；`lookup(星/宫/四化/格局)` 精确查、`search(词,k)` 模糊查、`--json` 导出喂 RAG。`case_search.py "词" 紫微` 先出知识包再出案例库。
- **运限**（`libs/ziwei_horoscope.py`，引擎 py-iztro，输出已并入 `cast.py zhiwei`）：流年/流月/流日/流时四层运限的命宫地支、干支、四化（禄权科忌星）、流曜（流禄流羊流陀流昌流曲流魁流钺流喜流鸾流马等）。断流年吉凶 = 流年命宫三方四正 + 流年四化飞入何宫 + 流曜冲照，与生年盘叠看。
- **流年化忌叠冲扫描**（`libs/ziwei_liunian.py`，`cast.py zhiwei-liunian 年 月 日 时 性别 流年`）：把生年/大限/流年三化忌 + 六煞（羊陀火铃空劫）冲照叠加成十二宫压力热力表，找出该年重点受压宫位（防对应事项之失）。化忌断诀有原文「诸星化忌不宜逢」，叠冲热力为 [规则推演]。
- **验前事校验**（`libs/ziwei_yanqian.py`，`cast.py zhiwei-yanqian 年 月 日 时 性别 "年:事,年:事"`）：用已知人生事件（婚/子/升/财/破财/病/灾）回验命盘——吉事看流年化禄/化科飞入对应宫、凶事看化忌飞入、太岁/小限落宫为引动；命中率高→命盘可信，命中率≈随机→提示复核年界/时辰/命宫。校验逻辑 [规则推演]。
- 断：命宫身宫、三方四正、主星庙旺落陷、四化（化禄权科忌）、六吉（左右昌曲魁钺）六煞（羊陀火铃空劫）、格局（如紫微七杀、武曲贪狼、命宫空宫借对宫等）。飞星与运限断法出处《紫微斗数全书》，断卦按「化禄/化忌、流年命宫」等 Grep 原文佐证。
- 注意（案例库教训）：**夫妻宫太阳化忌 ≠ 单身/不婚**，只主「迟婚、婚姻多波折」（太阳失辉是波折象，非绝婚象）；判断婚姻忌用单一化忌直接断「不婚」。
- 十二宫逆时针排布（命宫→兄弟→夫妻→子女→财帛→疾厄→迁移→交友→官禄→田宅→福德→父母）已由 `libs/ziwei_crosscheck.py` 对照 iztro 校验锁定，勿改方向。
- 年界（对照 iztro 金标准校验）：年干/年支以**立春**为界（`getYearGanByLiChun`，对齐 iztro，字段级 parity）；「正月初一」为另一流派口径。出生在立春↔春节之间者，两口径年干不同，四化、五行局随之不同——本技能遵循立春，与 iztro 一致。
- 闰月（对照 iztro fixLeap=true）：闰月**十五日（含）前作本月，十六日起作下月**（iztro「前半个月算上个月，后半个月算下个月」）；纯 `abs(月)` 作本月是旧口径，已修正。
- **金标准校验**（`libs/ziwei_crosscheck.py`，`python ziwei_crosscheck.py [--n 1000]`）：对照 py-iztro 逐字段 parity——命宫支/身宫支/五行局/紫微天府支/每宫主星/生年四化/大限/核心辅星（硬字段，须全一致）+ 亮度（软，流派差异不判错）。实测硬字段 parity 100%；余差仅「农历日历数据差异」（lunar_python 与 iztro JS 朔日计算，远未来日期差一天，非算法错误，已单列）。
- 亮度（对照 iztro 校验）：庙旺利陷各家亮度表有分歧，`zhiwei.py` 用自写表，与 iztro 等软件可能有亮度档次差异（如天机在丑，本表「旺」、iztro「陷」），断「庙旺有力/落陷无力」按流派差异处理，不作绝对。
- 趋避：
  - 趋吉：化禄（财禄）、化权（掌权）、化科（名望）与六吉（左右昌曲魁钺）拱照之宫 → 可发力、宜进取。
  - 避凶：化忌、煞星（羊陀火铃空劫）冲照之宫 → 防对应事项（命宫忌防身心、财帛忌防破财、夫妻忌防婚变、疾厄忌防病），宜补不宜硬来。
  - 参断：命宫身宫三方四正定主格；主星庙旺有力吉、落陷无力；流年大限宫化忌煞聚处，为趋吉避凶重点。
- 参考：`txt\[术数] 紫微斗数全书.txt`（罗洪先本，十四主星系统，繁体，三卷）为主；`txt\[术数] 紫微斗数.txt`（万历续道藏本，十八星古法）为辅。
- 速查：`references/ziwei_basics.md`（十四主星庙旺落陷表/四化表/十二宫/六吉六煞）；`libs/ziwei_geju.py`（格局规则）、`libs/ziwei_knowledge.py`（断语知识包）。

## 输出格式（确定性骨架 + 盘面解读 + 全段白话，强制）

> 输出契约 **10 段**，每段「考据层 + 白话层」双轨：考据给可查证依据（书名 + 行号，`grep -n` 可复核），白话给听得懂的人话（第二人称「你」）。**缺白话＝不合格**。
> 核心：盘面事实（Det/Sto）永远为真，不确定只活在流派分歧（Und）。断语 = claim + evidence + confidence（🟢🟡🔴）。

1. **排盘**：`cast.py zhiwei` 命宫/身宫/五行局/十二宫主星辅星/四化/大限**完整展示**。生时/性别 Sto，宫位/星曜/四化 Det，亮度/吉凶 Und。
2. **盘面解读**：这个盘每行怎么读——命宫、身宫、四化、三方四正、格局各代表什么、此盘呈现什么象（术语 ↔ 白话逐项对照，至少 4 项）。
3. **原文**：引经据典**全文**（书名 + 行号；主典籍《紫微斗数全书》）。
4. **原文解读**：经文逐句白话翻译——它讲什么规则、怎么套到本盘。
5. **结论摘要**：一句话总断 + **七级评级**（上上/上吉/中上/中平/中下/下平/下下）+ **六维白话概括**（性格/事业/财运/感情/身心/阶段，六句，每句＝结论＋依据半句）。
6. **分步解读**：每条断语 claim + evidence + confidence（🟢🟡🔴），每条配「术语解读 + 问事解读」。
7. **确定性标注**：✅确定（Det/Sto 可复现事实）/ ⚠️不确定（Und 流派分歧 + 释义推断）/ ❌矛盾（信号冲突）；三类都点到，无矛盾明说「无」。
8. **时间节奏**：**大限/流年节奏**（当前大限 + 关键流年 + 白话）；应期能断则断，断不出明说「应期难定」。
9. **行动建议**：趋吉（可乘之机 + 行动）+ 避凶（风险 + 规避）+ 白话版 + 今日可行的一小步。
10. **风险边界**：limitation（不得由星曜名/宫位名推断吉凶、金额、具体日期、人物）+「判断停在哪」+ 免责。

- **独立评估者**：`ziwei_crosscheck.py` 已对 iztro 做排盘 parity（金标准校验）；断卦按「化禄/化忌、流年命宫」Grep 原文佐证，主判与独立判不一致标「信号冲突」降级。
- **结构化双轨**：`cast.py zhiwei ... --json` 出盘面事实层 JSON（`schema=ziwei-panfact-v1`），与散文并存。

**② 盘面解读（这个盘在说什么，术语 ↔ 白话逐项对照）**

1. **命宫空宫（乙未空）**
   - 术语：命宫无主星＝「命无正曜」，本宫力量不显，须借对宫（迁移宫武曲贪狼）来论——命主靠「出外、闯荡、求财」来立身，而非守着本命不动。
   - 白话：你不是个「安分坐等」的人，你的命要「走出去」才活——借来的武曲贪狼，让你骨子里要强、敢拼、爱求财求胜。

2. **身宫天府·官禄宫**
   - 术语：身宫＝后天立身之所、中年后发力处；天府＝南斗财库、稳重掌财；身宫坐官禄宫＝一生以事业为重、靠职分/管理/掌财立身。
   - 白话：你后半辈子是「事业型」的——越往后越靠「手里管着的资源、职位、财权」站住脚，做人稳重、重安全感。

3. **四化：太阳化权 + 巨门化禄（同入疾厄宫，巨日同宫）**
   - 术语：太阳化权＝发光掌权、要出头做主；巨门化禄＝口才、食禄、以言立身；两者同宫成「巨日同宫」格局，主食禄驰名、声名在外。
   - 白话：你有一张「能吃开口饭」的嘴和一股「想当家做主」的劲——靠表达、专业、名望吃饭，越说越出名。

4. **文昌化忌入父母宫**
   - 术语：文昌主文书、学历、契约；化忌入父母宫＝文书/学历/长辈/契约这条线有波折（如学历中断、文书纠纷、与长辈关系需经营）。
   - 白话：你在「文凭、合同、长辈」这些事上容易有坎——要么学历路上有波折，要么签合同、和长辈打交道要格外小心。

5. **格局：府相朝垣**
   - 术语：天府、天相拱照命垣＝「府相朝垣」，主财禄丰厚、富贵荣显（《全书》女命赋「府相朝垣命必荣」）。
   - 白话：这是张「有财有禄」的底牌——只要走正路，你是有家底、能聚财的命。

一句话：**盘面＝命宫空要靠「走出去」立身、身宫天府坐官禄主掌财掌权、巨日同宫主口才扬名、府相朝垣主财禄丰厚；是「越往后越稳、靠本事和资源吃饭」的格局，唯文昌化忌让文书/长辈线要多用心。**

**③ 原文**

> 《紫微斗数全书》:144
> 「命無正曜，夭折孤貧。吉有凶星，美玉瑕玷。」

> 《紫微斗数全书》:49
> 「天府屬土，南斗主令第一星也。為財帛之主宰，在斗司福權之宿，會吉皆為富貴之基，定作文昌之論。」

> 《紫微斗数全书》:146
> 「府相朝垣命必榮。」

**④ 原文解读（逐句白话翻译 + 套到本盘）**

- 「命無正曜，夭折孤貧」→ 命宫没有主星，旧注多作「根基单薄、孤独贫弱」解，但这是「最凶」的极言，实际命无正曜只主「本宫不显、须借对宫」，不必然夭折孤贫；
- 「吉有凶星，美玉瑕玷」→ 就算吉星也会带凶星，像美玉上也有瑕疵，是提醒「别只看吉、要兼看凶」；
- **套到本盘**：你命宫乙未空、正是「命无正曜」，但借对宫武曲贪狼为用、又有府相朝垣托底，所以不能照「孤贫」断——这句要读成「你的命不在本宫发力，要借迁移（往外闯）才活」，而不是判你命薄。

- 「天府屬土…為財帛之主宰…會吉皆為富貴之基」→ 天府是南斗首星、财库之主，管财帛田宅，会到吉星就是富贵根基；
- **套到本盘**：你身宫正是天府坐官禄宫，又得左辅、天相拱照，等于「财库坐到了事业位、还有贵星扶」，是你「越老越有家底、靠职分掌财」的根据。

- 「府相朝垣命必榮」→ 天府天相拱照命宫的人，命必荣显（富贵）；
- **套到本盘**：你天相守财帛、天府守官禄，命宫三方四正得府相拱照，正是「府相朝垣」，主一生财禄荣显、不缺衣禄。

**⑤ 结论摘要**

中上（75/100，**中上**）。命宫空借武曲贪狼、身宫天府坐官禄、巨日同宫、府相朝垣——靠「往外闯 + 掌财掌权 + 口才扬名」立身，财禄丰厚、越老越稳；唯文昌化忌入父母、夫妻宫紫微七杀加火星，文书/学历与感情两条线要多用心经营。

**六维白话概括**（每句＝结论＋依据半句）：
- **性格**：外柔内刚、重实际、有冲劲又有稳重的一面，想当家做主——命宫借武曲贪狼主敢拼求胜，身宫天府主稳重掌财。
- **事业**：事业心极重，宜管理/财务/实业/专业路线，越老越有权有财——身宫天府坐官禄、府相朝垣主财禄。
