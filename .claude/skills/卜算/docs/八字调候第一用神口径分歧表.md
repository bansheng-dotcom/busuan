# 八字调候「第一用神」口径分歧表（13 处 + 3 处未明）

> 关联：[tiaohou_regression.py](../tests/tiaohou_regression.py) 的全量 120 格第一用神对拍。
> 性质：**口径分歧，不是数据错**。TIAO_HOU（借自 yueyuan-bazi，综合《穷通宝鉴》《栏江网》多版本）的「第一用神」优先级与单一《穷通宝鉴》原文的「第一用神」表述不完全一致，源于四类口径分歧。本表逐处记录原文依据与分歧原因，供人工复核；**不拿原文硬改 TIAO_HOU**（多版本综合，单一原文对不上是常态）。

## 三、口径分歧四类归纳

1. **月令用神 vs 实际用神**（最本质）：丁寅、丁巳——「甲木当权」是月令母，「姑用庚金劈甲」才是实际引丁用神。原文首句常点「实际用神」，TIAO_HOU 首字点「月令用神」。
2. **总论 vs 具体**：己申（三秋总论「癸先丙後」vs 七月「丙温土」）、乙未（「柱多金水」条件 vs 无条件）。
3. **多版本矛盾**：甲戌最典型——同一《穷通宝鉴》内「四季甲木总不外庚」与「九月端用丁癸」两句互斥，TIAO_HOU 取「甲庚」。
4. **注释与数据不一致（疑似 bug）**：辛亥——TIAO_HOU 注释「先壬後丙」但数据 `["丙","壬"]`，用神集合无误、仅首用神优先级存疑。

## 四、结论与纪律

- 13 处差异 = 「第一用神」优先级的口径分歧，**用神集合（天干列表）基本一致**（除甲戌「甲庚」vs「丁癸」是真正集合分歧，系多版本矛盾）。
- 按项目纪律「发现不是改库依据」：本表只记录 + 供人工复核，**不改 TIAO_HOU 数据**。唯一可议的是辛亥——若确认是数据 bug（非多版本口径），可将 `["丙","壬"]` 调为 `["壬","丙"]` 以对齐注释与原文，但这需人工拍板，不擅自改。
- 对拍测试（[tiaohou_regression.py](../tests/tiaohou_regression.py)）据此表生成，差异「不判错」、仅报告，作为「TIAO_HOU 与《穷通宝鉴》单本原文的提炼差异」的常驻证据。
