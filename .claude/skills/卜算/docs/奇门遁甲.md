## 输出格式（确定性骨架 + 盘面解读 + 全段白话，强制）

> 输出契约 **10 段**，每段「考据层 + 白话层」双轨：考据给可查证依据，白话给听得懂的人话。**缺白话＝不合格**。
> 核心：盘面事实（Det/Sto）永远为真，不确定只活在流派分歧（Und）。断语 = claim + evidence + confidence（🟢🟡🔴）。

1. **排盘**：`cast.py qimen --time` 的局/干支/值符值使/八门/九星/暗干**完整展示**。起盘 Sto（--time 可重放），局/值符值使/八门九星 Det，吉凶 Und。
2. **盘面解读**：这个盘每行怎么读——局/值符/值使/八门/九星/门星吉凶/旬空各代表什么（白话，逐关键点，至少 4 项）。
3. **原文**：引经据典**全文**（书名 + 行号，可复核）。
4. **原文解读**：逐句白话翻译 + 套到本盘。
5. **结论摘要**：吉凶总断一句话 + **七级评级**（上上/上吉/中上/中平/中下/下平/下下，对应 0-100）+ 白话版。
6. **分步解读**：每条断语 claim + evidence + confidence（🟢🟡🔴）+ 术语解读 + 问事解读。
7. **确定性标注**：✅确定（Det/Sto 可复现）/ ⚠️不确定（Und 流派分歧 + 释义推断）/ ❌矛盾（信号冲突，无则说「无」）。
8. **时间节奏**：应期（能断则断，断不出明说「应期难定」）+ 白话。
9. **行动建议**：趋吉 + 避凶 + 白话 + 今日可行的一小步。
10. **风险边界**：limitation + 判断停在哪 + 免责。

- 断语 = claim + evidence + confidence，原文在关键判断处引用，不贴 `[原文]`/`[规则推演]` 标签；白话用第二人称「你」。
- 独立评估者：`qimen_regress.py` 全量回归 + `rules.qimen_*` 结构化规则（十干克应/门迫/击刑）逐条带出处，命中后 Grep 原文佐证；主判与回归/原文不一致标「信号冲突」并降级。

### 输出样例（出行择方 · 阴遁九局 · 值符天柱落巽 值使惊门落兑）

> 盘面为固定测试盘（`--time "2026-10-09 10:30"` 可重放），不是真实用户预测。

**① 排盘（盘面事实）**

- 起盘 Sto（--time 可重放）；局/值符值使/八门/九星/暗干 Det；吉凶 Und（格局生克属流派）。
- limitation：盘面事实只记录局、干支、值符值使、八门、九星、暗干、旬空；不得由门星名推断吉凶、金额、具体日期或人物身份。

```text
【奇门遁甲】2026-10-09 10:30 · 置闰 · 阴遁九局中元 · 寒露
干支：丙午年 戊戌月 丙辰日 癸巳时
旬空：日空 子丑 ｜ 时空 午未

值符值使
  值符天干：甲申（庚）  值符星宫：天柱 → 巽宫
  值使门宫：惊门 → 兑宫

八门（宫 → 门）
  兑·惊  坤·死  离·景  巽·杜  震·伤  艮·生  坎·休  乾·开

九星（宫 → 星）
  巽·柱  震·芮·禽（天芮+天禽同宫）  艮·英  坎·辅
  乾·冲  兑·任  坤·蓬  离·心

暗干：巽乙 离辛 坤己 震戊 中丙 兑癸 艮壬 坎庚 乾丁

```

**② 盘面解读（这个盘在说什么，术语 ↔ 白话逐项对照）**

1. **阴遁九局中元 · 寒露**
   - 术语：寒露节入阴遁，九局中元；阴遁逆布六仪、顺飞三奇。
   - 白话：眼下是**寒露后的阴遁**，气机偏「收、藏、内敛」，不是大张旗鼓的时节。

2. **值符天柱（凶星）落巽宫**
   - 术语：值符＝本盘主星、掌全局；天柱＝破军凶星（主破坏、口舌、刑伤）；落巽＝东南。
   - 白话：**盘的主星是颗凶星**，还压在东南（巽）——这盘**大方向偏凶**，东南方尤其别去硬闯。

3. **值使惊门（凶门）落兑宫**
   - 术语：值使＝值事之门、定当下所行；惊门＝凶门（主惊恐、口舌、官司）；落兑＝西。
   - 白话：**当下「所行之门」也是凶门**（惊），还落在正西（兑）——**往西动、或眼下就动，容易惹口舌惊扰**。

4. **三吉门：生门（艮/东北）、休门（坎/北）、开门（乾/西北）**
   - 术语：八门里开、休、生三吉门；此盘分落艮（东北）、坎（北）、乾（西北）。
   - 白话：**好门都在北边和西北、东北**——要动，往这三方挑，别往西、东南、东。

5. **天芮·天禽同宫（震/东）**
   - 术语：天芮＝病符凶星，天禽寄宫随天芮；同宫于震（东）。
   - 白话：**东方也带凶星（病符）**，正东这个方位同样要避开。

一句话：**盘面＝值符天柱凶、值使惊门凶，主星主门皆凶，本时正行不宜；但三吉门（开休生）在艮坎乾，择吉方吉时另起可转——宜择方、宜改时，不宜依本盘硬动。**

**③ 原文**

> 《奇门遁甲秘笈大全》:129
> 「八门若遇开休生，诸事逢之皆称情，伤宜捕猎终须获，杜好邀遮及隐形，…」

> 《奇门遁甲统宗》:19
> 「奇门选择最重衰旺休囚，如开门本吉，但其性属金，如临土宫、金位及季夏三秋，所谓得时得地，时之最吉者也；如在春夏而临于木火，则金气大衰，岂得为吉。凡八门皆然，三奇亦然。」

**④ 原文解读（逐句白话翻译 + 套到本盘）**

- 「八门若遇开休生，诸事逢之皆称情」→ 行动若碰到开门、休门、生门这三个吉门，诸事都顺、都称心；
- 「伤宜捕猎终须获，杜好邀遮及隐形」→ 伤门宜捕猎追获、杜门宜拦阻藏匿，皆非「行正事」之门；
- 「奇门选择最重衰旺休囚，如开门本吉……临土宫、金位及季夏三秋，得时得地，时之最吉者也」→ 选时择方最看门星的旺衰休囚；开门本吉，但得「当令、得地」才真吉，失时失地则不吉。
- **套到本盘**：本盘值使惊门、值符天柱皆凶，不在「开休生」之列，故**依本时正行不利**；但三吉门（生、休、开）分落艮、坎、乾——恰应「诸事逢之皆称情」，**改向吉门之方、另择当令之时**才是本盘的正解。

**⑤ 结论摘要**

中平（55/100）。值符天柱（凶星）落巽、值使惊门（凶门）落兑，主星主门皆凶，本时正行不宜；但三吉门（开休生）在艮坎乾，**择吉方（北/东北/西北）吉时另起可转**——宜改向、宜改时，不宜硬动。

**白话**：说人话——这盘**主门主星都偏凶**，尤其西、东南、东三个方向别去，眼下也别急着动。但**北边、东北、西北这三方是吉的**——真要做，就**换到这三方、挑个吉时**再动，别按现在这个时点硬冲。

**⑥ 分步解读**

1. **值符值使皆凶**（claim：本时本盘不宜正行）
   - evidence：值符天柱（凶星）落巽、值使惊门（凶门）落兑（Det，九星/八门落宫是盘面事实）。
   - confidence：🟢 高（值符值使落宫是盘面事实，天柱/惊门属凶星凶门为定说）。
   - 术语解读：值符＝掌全局之主星，值使＝定当下所行之门；天柱破军、惊门主惊恐口舌，皆凶。
   - 问事解读：**按当下这个时点、这个方向直接动，容易惹口舌、惊扰、破耗**，先别急。

2. **三吉门可择**（claim：改向吉门之方，事可转顺）
   - evidence：生门落艮（东北）、休门落坎（北）、开门落乾（西北）（Det，《奇门遁甲秘笈大全》:129「八门若遇开休生，诸事逢之皆称情」）。
   - confidence：🟢 高（门落宫是盘面事实，三吉门为定说）。
   - 术语解读：八门吉凶以开、休、生为三吉门；此盘三吉门分落艮、坎、乾。
   - 问事解读：**要出行/办事，优先选北（休）、西北（开）、东北（生）**这三个方向。

3. **天芮病符占震（东）**（claim：东方带凶星，避开）
   - evidence：震宫「芮·禽」，天芮病符凶星与天禽同宫于震（Det，《奇门遁甲秘笈大全》·九星）。
   - confidence：🟢 高（星落宫是盘面事实；「天芮为病符凶星」为定说）。
   - 术语解读：天芮＝病符凶星，主疾病、困厄；天禽寄宫随天芮同宫。
   - 问事解读：**正东方向也带凶**，跟西、东南一起列为避开之方。

**⑦ 确定性标注（✅确定 / ⚠️不确定 / ❌矛盾）**

- ✅ 确定：盘面事实全部可复现——阴遁九局中元、丙午戊戌丙辰癸巳、值符天柱落巽、值使惊门落兑、八门（生艮休坎开乾…）、九星（震芮·禽同宫…）、三吉门艮坎乾、旬空子丑/午未（起盘 Sto、--time 可重放；局/值符值使/门星 Det）。
- ⚠️ 不确定：吉凶「中平 55/100」、应期、以及「值符值使凶 vs 三吉门可择」的权衡——评级与应期是 Und 流派分歧 + 释义推断。
- ❌ 矛盾：无（「主星主门凶」与「三吉门可择」是「本时正行不利、改向改时则吉」的层次区分，无信号冲突）。

**⑧ 时间节奏（病药法：病 → 药 → 应期）**

- 病：值符天柱、值使惊门皆凶，本时正行不利；旬空 日子丑、时午未（本时所涉空亡，事易落空）。
- 药：**另择吉时**——五阳时、或值符值使相生之时；并改向三吉门（生艮/休坎/开乾）之方。
- 应期：奇门以「择时择方」为用，本身无固定「某日必成」之应；本盘**应期难定**，明说「应期难定」——重点在「何时动、往哪动」而非「哪天成」。

**白话**：什么时候动？奇门看的是「**在哪个时点、往哪个方向动**」，不硬断「哪天成」。这盘当下时点偏凶、还带空亡，**别赶现在**，挑个吉时、改往北/东北/西北再说。

**⑨ 行动建议**

- 趋吉：出行/办事**改向三吉门之方**——北（休门）、西北（开门）、东北（生门），并**另择吉时**（五阳时、符使相生之时）再动，可把凶盘的「正行不利」转成「择吉可成」。
- 避凶：**避开值使惊门（兑/西）、值符天柱（巽/东南）、天芮病符（震/东）**三方；本时（癸巳时，时临空亡）**勿正行、勿签约、勿远行**，防口舌惊扰。

**白话**：能做的，是**把出门/办事的方向和时间改一改**——往北、东北、西北走，挑个吉时再动；不能做的，是**往西、东南、东去，以及趁现在这个时点急着拍板、急着出门**。

- 今日可行的一小步：今天把「要出门办的事」和「约的时间」过一遍，把方向从西/东南/东改到北/东北/西北，把时间错开当下这个空亡时点，先改这一处。
