## 输出格式（确定性骨架 + 用神落宫七层解读 + 全段白话，强制）

> 输出契约 **9 段**，每段「考据层 + 白话层」双轨：考据给可查证依据（书名可复核），白话给听得懂的人话（第二人称「你」）。**缺白话＝不合格**。
> 奇门专属骨架：**用神落宫 → 盘外格局（一票否决）→ 大环境 → 值符值使 → 竖看用神七层 → 横看生克 → 综合 → 应期**——这是奇门区别于其他术法的断局链条（参考 qimen-dunjia 九步 SOP）。
> 核心：盘面事实（Det/Sto）永远为真，不确定只活在流派分歧（Und）。断语 = 结论 + 证据 + 置信度（🟢🟡🔴）。

1. **排盘**：`cast.py qimen` 全量盘面**九宫表格化展示**（九宫格：八门/九星/八神/三奇六仪/暗干 + 值符值使 + 用神落宫）。起局 Sto，定局/排盘/门星神 Det，吉凶 Und。
2. **盘外格局**：一票否决检查（五不遇时/六仪击刑/三奇入墓/门迫）+ 日时关系 + 伏吟反吟。
3. **大环境**：月令旺衰 + 伏吟反吟 + 内外盘（近快/远慢）。
4. **值符值使**：值符星（大方向/大势）+ 值使门（具体执行/结局）。
5. **竖看用神落宫（七层）**：天地盘干（格局）→ 八门 → 九星 → 八神 → 四害（空亡/入墓/击刑/门迫）→ 九宫象意 → 三奇，逐层判吉凶。
6. **横看生克**：日干宫 vs 时干宫 vs 用神宫，他生我/我生他/他克我/我克他/比和。
7. **原文 + 原文解读**：十干克应格局 + 八门九星八神 + 秘笈大全，每条原文 = 书名 + 全文，紧跟「逐句白话翻译 + 套到本局」。
8. **综合判断 + 确定性标注**：吉凶定性（吉因素 vs 凶因素汇总）+ 事象充实 + 应期 + ✅/⚠️/❌。
9. **行动建议 + 风险边界**：趋吉 + 避凶 + 白话 + 一小步 + limitation + 免责。

- **独立评估者**：`qimen_regress.py` 全量回归自检（1080 局 + 结构不变量 + 古籍对照），存疑标「信号冲突」降级。
- **结构化双轨**：`cast.py qimen ... --json` 出盘面事实层 JSON，与散文并存。

**④ 值符值使**

2. **值使惊门落兑**（执行/结局带凶）
   - 术语解读：值使门=具体执行、事情最终结果；惊门属凶门（主惊恐、口舌、官非），落兑宫（金，比和）——执行/结局带「惊、口舌、官非」。

**⑦ 原文 + 原文解读**

**《奇门遁甲秘笈大全》**（八门）
> 「生门属土，居艮宫……主生发、财利、田宅，宜见贵、求财。」

- 逐句解读：生门属土、居艮，主「生发、财利、田宅」，见贵求财宜。
- **套盘**：本局用神生门落艮宫（得位），主「求财宜、有财利」——是求财的吉门，但落宫天英（凶星）拉低吉度。

**《奇门遁甲秘笈大全》**（九星）
> 「天英属火，居离宫……主文明、但失令则主口舌、火灾、血光。」

- 逐句解读：天英属火，主文明，但失令主口舌、火灾、血光。
- **套盘**：本局天英落艮宫（艮土，火生土，泄火），**失令**——生门宫见天英失令，主「求财过程防口舌、急躁、火气」。

**《奇门遁甲秘笈大全》**（五不遇时）
> 「五不遇时者，时干克日干也，百事不宜，谋事不成，只宜静守。」

- 逐句解读：时干克日干为五不遇时，百事不宜、谋事不成，只宜静守。
- **套盘**：本局时干癸克日干丙，**五不遇时命中**——求财「谋事不成、只宜静守」，这是本局最重的凶信号，须降级。

**⑧ 综合判断 + 确定性标注**

**吉凶定性**（吉因素 vs 凶因素汇总）：

| 来源 | 吉因素 | 凶因素 |
|---|---|---|
| 盘外格局 | — | 五不遇时（时克日，硬凶） |
| 值符值使 | — | 值符天柱（凶星）、值使惊门（凶门） |
| 用神落宫 | 生门（吉门）落艮得位 | 天英（凶星）落艮失令 |
| 横看 | 日干 vs 用神比和 | 时干泄用神 |

- **结论：中平偏凶**（五不遇时 + 值符凶星 + 值使凶门 压过 生门吉门）。求财主「门吉星凶、大局带凶，只宜静守、不宜急进」，防口舌、防破败。
- **事象充实**：生门艮宫（土）——求财宜「稳、不动产、田宅、土属性行业」，不宜投机、不宜急攻；值使惊门——过程防口舌官非；天柱——防破败毁伤。

**确定性标注**：

- ✅ 确定：阴遁九局、值符天柱落巽、值使惊门落兑、生门艮宫、五不遇时——全部 Det 可复现（`qimen_regress.py` 回归校验）。
- ⚠️ 不确定：吉凶「中平偏凶」、应期——门星神吉凶是流派共识但「轻重」属释义，应期难定。
- ❌ 矛盾：生门（吉门）vs 天英（凶星）同宫——不矛盾，门星各论：门吉定「财利可求」、星凶定「过程有扰」，合起来「可求但有扰、防口舌」。

**⑨ 时间节奏 + 行动建议 + 风险边界**

**应期**：内外盘一内一外 → 「远+慢」，事缓；五不遇时 → 只宜静守、不宜急攻；生门艮宫数（土数五、八）→ 应期粗推近期 5/8 个单位，参考。

**趋吉**：

| 维度 | 建议 |
|---|---|
| 方向 | 向吉门（生艮/休坎/开乾）之方求财，尤利「东北、北、西北」 |
| 行业 | 生门艮土——宜「稳、田宅、不动产、土属性行业」，不宜投机 |
| 时机 | 五不遇时只宜静守——避开此日此时，另选吉时（符使相生之时）再动 |

**避凶**：五不遇时（时克日）——谋事不成、只宜静守，忌急攻；值使惊门——防口舌、官非、惊恐；值符天柱——防破败、毁伤；天英失令——防急躁、火气、口舌。

**白话**：现在能做的，是「静守、稳着来」，求财走「稳、田宅、土属性」的正路（生门艮土），别投机、别急攻；不能做的，是「五不遇时」里硬上、碰口舌官非、碰破败的事。记住：这局「门吉星凶、大局带凶」，守比攻强。

- 今日可行的一小步：今天把「这笔财最可能引发口舌/破败的那个环节」写下来，明确「五不遇时（此时此日）不动它、另择吉时」。

**风险边界**：以上只到「五不遇时、值符天柱值使惊门、生门落艮门吉星凶」；具体金额、对方真实意图、精确应验日期，本局给不出确定答案，不硬断。

### 输出样例（模块 B · 十干克应 81 格局）

### 输出样例（模块 C · 三奇（入墓/得使）+ 玉女守门）

> 三奇 = 乙丙丁；入墓 = 硬否决，得使/守门 = 加分。本盘按九宫排布实测：

| 检查 | 规则 | 本盘结论 | 白话 |
|---|---|---|---|
| 三奇入墓 | 乙墓坤二、丙墓乾六、丁墓艮八 | 乙落巽4、丙落中5、丁落乾6——**均不入墓**（无否决） | 「入墓」＝吉干掉进"墓"里被埋死，是硬否决。本盘乙丙丁三个都没进墓，这一关过了 |
| 三奇得使 | 天盘三奇临地盘值使门宫 | 值使惊门落兑7、兑7暗干癸（非乙丙丁）——**不得使** | 「得使」＝三奇搭上值使门、如虎添翼。本盘值使门宫没有三奇，没这份加分 |
| 玉女守门 | 值使门临地盘丁奇宫 | 值使惊门落兑7、丁落乾6——**不守门** | 「守门」＝丁奇守在值使门，利婚嫁求财。本盘丁不在值使门宫，没这份吉 |

> **白话**：三奇这块「无功无过」——没入墓（不否决），但也没得使、没守门（不加分）。这局吉不起来，主要就靠生门那一门顶着。

### 输出样例（模块 D · 六仪击刑 + 伏吟反吟 + 内外盘）

| 检查 | 规则 | 本盘结论 | 白话 |

| 六仪击刑 | 六仪（戊己庚辛壬癸）落进"刑"的宫位就是击刑 | **戊落震3（子卯刑）、己落坤2（戌未刑）、辛落离9（午午自刑）——三处击刑，凶** | 「击刑」＝仪干踩进"互相刑克"的宫位，主官司、刑伤、破损，是硬凶格。本盘**戊、己、辛三个都踩中**（戊在震宫犯子卯刑、己在坤宫犯戌未刑、辛在离宫犯午午自刑），等于三处"地雷"同时爆——凶 |
