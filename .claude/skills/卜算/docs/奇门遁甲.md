## 断卦流程

- 起盘：`cast.py qimen`（脚本已定局、排地盘三奇六仪、天盘九星、八门、八神、**暗干/飞干**）。
- 断：用神落宫、宫位生克、门星神仪格局（青龙返首、飞鸟跌穴等吉；太白入荧、荧入太白等凶）；**并查三奇六仪、门迫、击刑、五不遇时、奇仪入墓等凶格**。注意：脚本「芮·禽」处为天芮+天禽同宫（天禽寄宫随天芮），天芮属凶星不可漏断。
- **断卦必经步骤 ①检索相似条文**：先跑 `python scripts/libs/case_search.py "占事" 奇门` 语义检索，再 Grep `D:\卜算\国学czhengli\txt\案例库\奇门\`（116 则：108 分类占断 + 8 门克应）按「占X」佐证原文，先定用神（某星/某门/某干）再查格局生克——**不得跳过直接空推**（奇门古典无日期占验案例，本库为占断条文库，见该库 README）。
- **结构化规则**（`rules.qimen_*`，R-QM-01~11）：八门/九星/八神吉凶、门迫（门克宫）、**十干克应 81 格局**（`libs/qimen_keying.py`，9 天盘干 × 9 地盘干全表，甲遁于戊）、五不遇时（时干克日干）、**六仪击刑**（R-QM-07）、**奇仪入墓**（R-QM-08）、**三奇得使**（R-QM-09）、**玉女守门**（R-QM-10）、**暗干/飞干**（R-QM-11，`libs/qimen_angan.py` 完整算法：值使加时干、阳顺阴逆飞九宫）。每条带典籍出处书名（《奇门遁甲秘笈大全》·十干克应/六仪击刑/奇门占事、《烟波钓叟歌》），命中后**按出处 Grep 原文佐证**——结构化判定层给方向与出处指针，原文检索层给 `[原文]` 依据，两层并存。
- 趋避：
  - 趋吉：用神落宫得吉门（开休生）、吉星（天心天任天辅天禽天冲）、吉神（值符太阴六合九地九天）生助可动；向吉门吉星之方、选吉时（五阳时/符使相生）行动。
  - 避凶：避凶门（死惊伤）、凶格（太白入荧、荧入太白、青龙逃走、白虎猖狂、朱雀入江、腾蛇夭矫等）与凶方，不选凶时；五不遇时、时干入墓、门迫宫百事不宜，改期。
  - 参断：用神宫生克定顺逆（宫生用/用宫相生吉，宫克用/用克宫凶）；门星神仪组合辨格局——青龙返首、飞鸟跌穴、玉女守门宜进，凶格宜避。
- 参考：`txt\[易藏] 奇门遁甲统宗.txt`、`奇门遁甲秘笈大全.txt`、`烟波钓叟歌句解.txt`、`奇门遁甲阴阳遁十八局.txt`、`日家奇门.txt`、`奇门宝鉴御定.txt`、`奇门法窍.txt`、`奇门旨归.txt`、`遁甲演义.txt`、`遁甲符应经.txt`；`txt\[道藏] 秘藏通玄变化六阴洞微遁甲真经.txt`、`黄庭遁甲缘身经.txt`。
- 速查：`references/qimen_geju.md`（十干克应吉凶格局/八门九星八神/五不遇时门迫）、`references/奇门分类占断速查.md`（求财/婚姻/出行/失物/词讼/疾病/考试/官禄/盗贼/远信等用神取法，先定用神再查格局）。
- 案例库：`D:\卜算\国学czhengli\txt\案例库\奇门\` 116 则占断条文（《秘笈大全》奇门占事 108 类 + 八门克应 8 门，`cases/extract_qimen_cases.py` 提取），断卦 Grep 佐证。
- **全量回归自检**：`python scripts/libs/qimen_regress.py`（`libs/qimen_regress.py`）三层体检——①穷举 18 局 × 60 甲子时 = 1080 局，报参考崩溃/排布错/局值符值使分布；②结构不变量（独立参考重写标准转盘法，逐字比对引擎的地盘六仪/值符值使/八门/九星/八神）；③古籍局式对照（gold 样例阴遁九局硬校验 +《秘笈大全》榖雨例软标记）。
- **已知引擎边界（已修复，诚实标注修复史）**：值符加时干法在「时干=甲」的旬首时（甲戌/甲申/甲午/甲辰/甲寅）原有一处 bug——引擎把值符落在「旬首六仪宫」而非标准「戊宫」（甲遁戊），导致值符星落宫、九星、八神整体偏移。**已修复**（`config.zhifu_n_zhishi` 与 `kinqimen.pan_sky` 各一处 `[PATCH]`，见 `qimen_regress.py` 回归 1464/1464 全吻合）。若历史版本/外部 kinqimen 出现「旬首时值符星宫 = 旬首宫」的盘，仍按此降级：以地盘/八门/值使为准。**刻家奇门**（`pan_minute`，未上 cast.py 输出）同款修复：`zhifu_n_zhishi_ke` 值符星宫(甲遁戊)+值使门宫(改值使表)、`kinqimen.pan_sky_minute` 甲遁戊+无分支兜底退地盘，`pan_minute` 已 0 崩溃（刻家另存值符表/地盘用局不一致的结构性问题，排盘未独立验证，仅供研究不参与断卦）。

## 排盘自检

定局（置闰/拆补）、地盘三奇六仪、天盘九星、八门八神；用神落宫。

## 交叉验证

用神落宫 / 门星神 / 格局 / 时令旺衰。

## 断卦规则

用神宫得吉门吉星吉神→吉；门迫/击刑/五不遇时/奇仪入墓→凶（改期避方）。
