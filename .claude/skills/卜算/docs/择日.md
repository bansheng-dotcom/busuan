# 择日（建除黄道、神煞宜忌）

> 分术法文档。总纲见 `SKILL.md`，多术联动见 `XUANXUE-LINKAGE.md`。

## 起盘

```bash
python scripts/cast.py zeri 婚嫁             # 择日·建除黄道神煞(可--time，事项可选)
python scripts/cast.py zeri-month 2026-10 婚嫁  # 择日·按月推荐吉日(月份 事项 [数量])
python scripts/cast.py zeri 婚嫁 --json      # 择日·结构化双轨(散文+盘面事实层JSON)
```

## 断卦流程

- 起盘：`cast.py zeri 事项`（事项：婚嫁/开业/动土/出行/搬家/考试/求医/祭祀；可 `--time` 指定查询日；脚本已算建除十二神、黄道黑道、二十八宿、神煞、宜忌、十二时辰吉凶、综合评分）。按月推荐吉日：`cast.py zeri-month 2026-10 婚嫁`。
- **老黄历补全**（`libs/almanac.py`，输出已并入 `cast.py zeri`）：彭祖百忌（日干/日支）、每日值神（十二值神精确起法）、协纪辨方书吉神/凶煞全表、吉神方位（喜神/财神/福神/阳贵/阴贵）、胎神占方、日冲日煞、每日宜忌。每字段附出处指针（《钦定协纪辨方书》《御定星历考原》），断卦时按字段名 Grep 原文佐证（双重保证）。
- 断：建除黄道吉凶、吉神凶煞、宜忌、冲煞（冲生肖/煞方位）、日课四柱配合、分类择日（婚嫁忌三娘煞杨公忌，动土忌土府，安葬重天赦成日等）。
- 趋避：
  - 趋吉：择成日/开日、天德月德天赦三合六合黄道日时 → 宜办事、签约、婚嫁、开业。
  - 避凶：避破日、杨公忌、四离四绝、月破岁破、冲主人生肖之日 → 改期；动土避土府土禁，安葬避重丧。
  - 参断：建除十二神按事择日（成开宜婚嫁开业、除宜扫除求医、平宜修补、执宜种植）；日课四柱与主人生肖五行合参；吉神凶煞叠加权衡。
- 参考：`txt\[易藏] 钦定协纪辨方书.txt`、`御定星历考原.txt`（另有繁体本 `[术数] 欽定協紀辨方書.txt`、`[术数] 御定星歷考原.txt`）；`txt\[道藏] 儒门崇理折衷堪舆完孝录.txt`、`洞玄灵宝道士受三洞经箓法箓择日历.txt`、`许真君玉匣记.txt`、`六十甲子本命元辰历.txt`。

## 输出格式（确定性骨架 + 盘面解读 + 全段白话，强制）

> 输出契约 **10 段**，每段「考据层 + 白话层」双轨：考据给可查证依据，白话给听得懂的人话。**缺白话＝不合格**。
> 择日属 C 类（择日/风水），结论不是「吉凶总断」而是「**宜忌总断**」——核心回答「今天宜做什么、忌做什么」。
> 核心：盘面事实（Det/Sto）永远为真，不确定只活在流派分歧（Und）。断语 = claim + evidence + confidence（🟢🟡🔴）。

1. **排盘**：`cast.py zeri` 建除/黄道/值神/彭祖忌/吉神方位**完整展示**。建除/黄道/值神/彭祖忌 Det（--time 可重放），综合评分/吉凶 Und。
2. **盘面解读**：这个盘每行怎么读——建除/黄道/值神/彭祖忌/吉神方位各代表什么、此日呈现什么象（白话）。
3. **原文**：引经据典**全文**（书名 + 行号，`grep -n "关键词"` 可复核）。
4. **原文解读**：这段经文的白话翻译——它在讲什么规则、怎么套到本日。
5. **结论摘要**：**宜忌总断**——今日宜做什么、忌做什么 + 七级评级（上上/上吉/中上/中平/中下/下平/下下）；紧跟白话版（第二人称「你」）。
6. **分步解读**：每条断语 claim + evidence + confidence（🟢🟡🔴），每条配「术语解读 + 问事解读」。
7. **确定性标注**：✅确定（Det/Sto 可复现事实）/ ⚠️不确定（Und 流派分歧 + 释义推断）/ ❌矛盾（信号冲突）；三类都要点到，无矛盾则明说「无」。
8. **时间节奏**：当日宜忌 + 吉时 + 后续吉日；断不出后续明说「应期难定」。
9. **行动建议**：趋吉 + 避凶 + 白话版 + 今日可行的一小步。
10. **风险边界**：limitation（不得由神煞名推断吉凶、具体成败、人物）+ 「判断停在哪」+ 免责。

- **结构化双轨**：`cast.py zeri ... --json` 出盘面事实层 JSON（`schema=zeri-panfact-v1`）。

### 输出样例（婚嫁 · 2026年10月9日 丙辰日）

> 盘面为固定测试盘（`--time "2026-10-09"` 可重放），不是真实用户预测。

**① 排盘（盘面事实）**

- 建除/黄道/值神/彭祖忌/吉神方位 Det（--time 可重放）；综合评分 90/100 是脚本加权算法，Und。
- limitation：盘面只记录「某日建何神、值何星、冲何肖」；不得由神煞名推断必成必败、具体结果或人物。

```text
日期：2026年10月9日 · 干支：丙辰
建除：执（吉）   黄道：金匮（大吉）   二十八宿：毕（吉）
综合评分：90/100   等级：大吉

【老黄历补全】《钦定协纪辨方书》 / 《御定星历考原》
农历：二〇二六年八月廿九
值神：青龙（吉）
彭祖百忌：丙不修灶必见灾殃；辰不哭泣必主重丧
吉神：天德、月德、母仓、益后、解神、青龙
凶煞：月破、大耗、四击、九空、往亡
吉神方位：喜神西南  财神西南  福神西北  阳贵正西  阴贵西北
胎神：厨灶栖  外正东
冲煞：冲(庚戌)狗  煞南
宜：祭祀、解除、破屋、坏垣、馀事勿取
忌：诸事不宜

【十二时辰】吉时：丑、卯、巳、未、酉、亥
【推荐时辰】（婚嫁）1. 巳时 09:00-11:00   2. 未时 13:00-15:00   3. 丑时 01:00-03:00
```

**② 盘面解读（这个盘在说什么，术语 ↔ 白话逐项对照）**

1. **干支丙辰**：丙（天干，火）坐辰（地支，土，属龙）。
   - 术语：日柱为当日干支，择日先看日干日支，再看其所值神煞。
   - 白话：这一天轮到「丙辰」值日，是丙火配辰土的日子。

2. **建除执**：建除十二神（建除满平定执破危成收开闭）轮到此日为「执」。
   - 术语：执日属黄道（《协纪辨方书》口诀「除危定执成开为吉」），主「守成、稳固」；但《选择宗镜》另说「执为死符、小耗」，带小凶。
   - 白话：单看建除，这日算「黄道吉日」，适合把事办稳、定下来；但别家又给执日扣了「小耗」的帽子，所以是「吉里带点杂音」。

3. **黄道金匮（大吉）**：黄道六神之一。
   - 术语：黄道六神（青龙、明堂、金匮、天德、玉堂、司命）皆吉神，「所值之日皆宜兴众务」；金匮＝藏宝之库，主钱财、收纳。
   - 白话：今天轮到黄道里的「金匮」当值，是六个吉神之一，办事、纳财、成礼都沾光。

4. **值神青龙（吉）**：每日值神（十二值神）之首。
   - 术语：青龙为十二值神里最吉的一位，主贵人、喜庆、升迁。
   - 白话：今日「值日的神」是青龙，属大吉的当值星。

5. **彭祖百忌**：丙不修灶、辰不哭泣。
   - 术语：彭祖百忌按日干、日支各有一条禁忌；丙日不动灶（修灶犯火），辰日不哭泣（主重丧）。
   - 白话：今天是丙辰日，老一辈的说法——「丙日别修灶、辰日别哭丧」，图个口彩、避个忌讳。

6. **吉神 vs 凶煞并存**：吉神天德、月德、母仓、益后、解神、青龙一大把；凶煞却也挂着月破、大耗、四击、九空、往亡。
   - 术语：天德月德是「三合旺气、上吉之日」，婚嫁首选；月破是「月建之冲、气绝之地」，大凶。
   - 白话：这盘是**两副面孔**——一面吉星开会，一面凶煞扎堆，不能只看一面就下结论。

7. **冲煞**：冲(庚戌)狗、煞南。
   - 术语：辰日冲戌，故冲属狗之人；煞方在南方。
   - 白话：属狗的人今天被日子冲着，宜避主事；南方是煞气所在，今天少往南动。

一句话：**盘面＝吉神凶煞同台，黄道金匮青龙天德月德是「吉」的一面，月破大耗诸事不宜是「凶」的一面，须两面对照、取吉避凶，不能只看评分。**

**③ 原文**

> 《钦定协纪辨方书》:1892
> 「考原曰：按月建十二神，除危定执成开为吉，建破平收满闭为凶。历书所谓『建满平收黑，除危定执黄，成开皆可用，闭破不相当』者也。」

> 《钦定协纪辨方书》:3528
> 「神枢经曰：青龙、明堂、金匮、天德、玉堂、司命，皆月内天黄道之神也，所值之日皆宜兴众务，不避太岁将军月刑，一切凶恶自然避之。」

> 《钦定协纪辨方书》:16114
> 「甲不开仓、乙不栽植、丙不修灶、丁不剃头……辰不哭泣、巳不遠行……亥不嫁娶。」

**④ 原文解读（逐句白话翻译）**

- 「除危定执成开为吉，建破平收满闭为凶」→ 十二建除神里，除、危、定、执、成、开六个算吉，建、破、平、收、满、闭六个算凶；
- 「建满平收黑，除危定执黄」→ 这就是黄历上那套口诀：建/满/平/收是「黑道」（凶），除/危/定/执是「黄道」（吉）；
- 「成开皆可用，闭破不相当」→ 成日、开日都能用，闭日、破日最不吉利。
- 「青龙、明堂、金匮、天德、玉堂、司命皆天黄道之神，所值之日皆宜兴众务」→ 这六个是「天黄道」吉神，轮到它们值日的日子，适合操办各种正事，凶神恶煞也会自动避开；
- 「丙不修灶」「辰不哭泣」→ 丙日不宜动灶（修灶），辰日不宜哭泣（怕招重丧）。

**套到本盘**：丙辰日落在「执」——正是口诀里的「除危定执黄」那个「执」，属黄道吉日；当值黄道神又是「金匮」（六黄道吉神之一）、值神「青龙」，所以建除黄道这一层判「大吉（90 分）」。但盘面神煞层同时出现「月破、大耗、忌诸事不宜」，与「执日黄道吉」打架——这正是《协纪辨方书》反复强调的「吉神凶煞叠加权衡」：**单看建除是吉，叠上神煞就未必，须逐神核对、避凶取吉。**

**⑤ 结论摘要（宜忌总断）**

**宜**：祭祀、解除、婚嫁（取天德月德 + 黄道金匮 + 值神青龙，脚本评分 90/100 大吉）。**忌**：诸事不宜（神煞层见月破、大耗、冲狗煞南），动土修造、大操大办、属狗者主事皆不宜。

两法信号冲突，**整体降级**判「**中上（吉中带煞）**」：日是好日，但带月破的尾巴，**婚嫁可办、须避冲取吉时**。

**白话**：说人话——翻黄历，今天吉星确实多（天德、月德、青龙、金匮全是吉的），光看建除黄道给到 90 分「大吉」；可再往神煞那栏一瞧，又挂着「月破、大耗、诸事不宜」，两套算法打架了。所以结论不能拍胸脯说「大吉大利」，只能说：**想办婚嫁可以借吉神吉时办，但别贪大、别动土，属狗的人今天尤其要避开主事。**

**⑥ 分步解读**

1. **建除执日属黄道吉**（claim：执日为可办事的黄道日）
   - evidence：丙辰日建除落「执」，口诀「除危定执黄」《协纪辨方书》:1892。
   - confidence：🟡 中（考原判执为吉，但《选择宗镜》谓「执为死符、小耗」带凶，执日吉凶本身有流派分歧）。
   - 术语解读：建除十二神是「以月建顺行十二辰」排出的日神；「执」取「守成」义，列黄道六吉之一。
   - 问事解读：婚嫁是「定下来、守成」的事，取执日本身不算冲，名分上是顺的。

2. **黄道金匮当值，宜兴众务**（claim：金匮值日利办事纳财）
   - evidence：黄道「金匮（大吉）」《协纪辨方书》:3528「所值之日皆宜兴众务」。
   - confidence：🟢 高（盘面直接给出，金匮为六黄道吉神无分歧）。
   - 术语解读：金匮是黄道十二神里主「宝库、收纳、钱财」的吉神。
   - 问事解读：婚嫁礼金、聘礼、开席这类「收纳」之事，借金匮当值顺水推舟。

3. **值神青龙，主喜庆贵人**（claim：青龙值日利喜庆）
   - evidence：值神「青龙（吉）」，青龙为十二值神之首《协纪辨方书》:3528。
   - confidence：🟢 高。
   - 术语解读：青龙主贵人、喜庆、升迁，是每日值神里最吉的一位。
   - 问事解读：婚嫁要的就是喜庆、得人助，青龙值日正合。

4. **天德月德，婚嫁上吉**（claim：天德月德为婚嫁首选吉神）
   - evidence：吉神「天德、月德」《协纪辨方书》:4683「天德月德乃月建三合旺气……皆上吉之日」。
   - confidence：🟢 高。
   - 术语解读：天德、月德是「三合旺气」所生的大吉神，能解诸凶，婚嫁取之最稳。
   - 问事解读：今天天德月德同时到，是婚嫁日里很难得的「双德临日」。

5. **彭祖百忌：丙不修灶、辰不哭泣**（claim：丙辰日有两项生活禁忌）
   - evidence：盘面「彭祖百忌」《协纪辨方书》:16114「丙不修灶……辰不哭泣」。
   - confidence：🟢 高（口诀固定，无流派分歧）。
   - 术语解读：彭祖百忌按日干、日支各配一条「当日别做什么」的老例，是民俗层面的避讳。
   - 问事解读：婚嫁当天避开「修灶动火」这类事即可，与婚礼本身无大冲。

6. **冲狗、煞南**（claim：属狗者此日受冲，南方为煞方）
   - evidence：盘面「冲煞：冲(庚戌)狗 煞南」。
   - confidence：🟢 高。
   - 术语解读：辰与戌冲，故冲属狗之人；「煞南」指该日煞气在南方。
   - 问事解读：属狗的新人/主婚人此日宜避正位主事；婚房、车队、宴席尽量不压南方煞位。

**⑦ 确定性标注（✅确定 / ⚠️不确定 / ❌矛盾）**

- ✅ 确定：干支丙辰、建除执、黄道金匮、值神青龙、彭祖百忌、吉神方位、冲(庚戌)狗煞南——全是脚本确定性输出，`--time "2026-10-09"` 可重放（Det）。
- ⚠️ 不确定：执日吉凶（考原吉 vs 选择宗镜凶）、「综合评分 90 分」是脚本加权算法，非经典直接给出（Und）。
- ❌ 矛盾（信号冲突）：建除黄道层判「大吉 90 分」，神煞层却见「月破、大耗、忌诸事不宜」——两层信号冲突，**已降级**为「中上」，并提示避冲、避煞。

**⑧ 时间节奏（当日吉时 + 后续吉日）**

- 当日吉时：巳时（09:00-11:00）、未时（13:00-15:00）、丑时（01:00-03:00）；婚嫁推荐首选**巳时**（脚本「推荐时辰」第一位）。
- 后续吉日：单日盘面只断当日，往后吉日需 `cast.py zeri-month 2026-10 婚嫁` 按月另排——**应期难定（本盘不推后续）**。

**白话**：今天要办事就抢「巳时、未时」这两个吉时，尤其巳时最好；往后哪几天还适合，得另起一个月度吉日盘才能排，这个单日盘给不出。

**⑨ 行动建议**

- 趋吉：婚嫁拜堂、签约、开席定在**巳时（09:00-11:00）**，借天德月德 + 金匮 + 青龙的当值顺位推进；求财纳礼、定聘可放同日。
- 避凶：神煞见月破、大耗、诸事不宜——当日**不动土、不修灶、不大操大办**；属狗者避主位、避主事；南方煞位少压（婚房、车队勿正冲南方）。

**白话**：今天能做的，是把正事排进巳时、顺着吉神办；不能做的，是**动土修灶、铺张摆阔**，属狗的人别抢主位，车子房间别冲南方。

- 今日可行的一小步：把婚嫁要办的核心环节（拜堂/签约/开席）核对一遍，**统一挪到巳时**，并确认属狗的关键人物不在主位。
