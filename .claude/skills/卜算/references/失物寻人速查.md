# 失物·寻人·寻宠 速查（小六壬 / 六爻纳甲 / 金口诀）

> 原则：失物寻人同样「降分辨率给候选」——方位/远近/能否寻回/是否被盗分维输出，不铁口直断「必在某处/某日找回」。
> 规则函数：`libs/shiwu_xunren.py`（`xiaoliuren_shiwu` R-SW-01、`liuyao_shiwu_fangwei` R-SW-02、`liuyao_shiwu_cangchu` R-SW-03、`liuyao_shiwu_duan` R-SW-04、`jinkoujue_shiwu/xunren` R-SW-05）；CLI `python scripts/cast.py shiwu <术> <信号>`。

## 一、小六壬失物（六宫口诀自带方位）

出处：《小六壬》六宫口诀（`txt\[其他] 小六壬.txt`）。

| 落宫 | 失物方位 | 远近 | 能否寻回 |
|---|---|---|---|
| 大安（木·东） | 东方 | 去不远（原处附近） | 易寻 |
| 留连（水） | 南方 | 已移动、拖延 | 难寻（急寻方明） |
| 速喜（火·南） | 西南（申未午） | 已出、需打听 | 可寻（逢人打听） |
| 赤口（金·西） | 西方 | 需急寻 | 难寻（口舌） |
| 小吉（木·六合） | 西南（坤方） | 未远、路上 | 可寻（阴人报喜） |
| 空亡（土） | — | 已失 | 寻不见 |

> 口诀原文：大安「失物去不远」、留连「失物南方去急寻方心明」、速喜「失物申未午逢人要打听」、赤口「失物急去寻」、小吉「失物在坤方」、空亡「失物寻不见」。

## 二、六爻失物（火珠林·占失物/逃亡/贼盗）

出处：《火珠林》（`txt\[易藏] 火珠林.txt` 第 248-290 行）。

### 用神
- **失物看财爻**（妻财）；失文书牌号看父母爻；六畜、小儿、宠物看子孙爻。
- 官鬼为贼、子孙为捕捉（公安）、兄弟为众、父母为衣服文书。

### 能否寻回
| 财爻状态 | 断 |
|---|---|
| 旺相不空不动 | 可见可寻 |
| 空 / 动 | 物已出屋，难寻 |
| 无气 / 休囚 | 不可见 |
| 伏藏 | 按所伏爻之宫寻，较难 |
| 在内卦（安静旺相） | 物未出家，在家中原处 |
| 在外卦 | 物已出外、转移 |

### 是否被盗
- 六爻无鬼、鬼安静 → **非贼偷，自失**。
- 官鬼动 / 财化鬼 → **被盗**（财化鬼妇人为贼、子化鬼小儿/出家偷、兄化鬼相识为盗）。
- 鬼克世 → 蓦然见贼赃；鬼刑世 → 贼再来防再失；鬼爻空 → 贼难觅、寻不见。
- 子孙旺 → 贼可获（应子孙旺日）；子孙空/无气 → 贼难获。

### 方位与藏处
- **卦宫方位**（世宫为方、应宫为所）：乾西北、坤西南、震东、巽东南、坎北、离南、艮东北、兑西。
- **财爻入墓藏处**（五行）：金→丑（东北）、水→辰（东南）、土→辰（东南）、木→未（西南）、火→戌（西北）。
- 用神出现以旺为方、伏藏以生为方；内卦近、外卦远。

### 应期
- 子孙旺日（贼获）、用神生旺之日、合住之期；断不出明说「应期难定」。

## 三、金口诀失物（四孟遗失 / 四仲交易）

出处：《六壬神课金口诀古本》（`txt\[易藏] 六壬神课金口诀古本.txt`）。

| 课值 | 事类 |
|---|---|
| 四孟（寅申巳亥） | **遗失 / 失物**（「四孟值课为遗失」） |
| 四仲（子午卯酉） | 交易 / 行人（「四仲来人问交易」） |
| 四季（辰戌丑未） | 婚姻 / 出身（「四季非问婚姻而问出身」） |

- **寻人在家**：上克下主「寻人在家」（「占人人在家」）。
- **走失难寻**：天马 / 驿马入课「走失难寻、逃亡远去」；天盗 / 地煞入课「走失阻隔不利」。

## 输出模板（失物寻人专用，叠加四段式之上）

```
🔍 失物寻人画像
  方位  🟢/🟡/🔴 东/南/西/北/…（六爻卦宫 / 小六壬落宫 / 金口诀地分）
  远近  …（在家未出 / 已出 / 远）
  能否寻回  …（易寻 / 难寻 / 寻不见，+ 概率档）
  是否被盗  …（自失 / 被盗 + 贼方向）
  状态  …（完好 / 受损 / 被藏）
  应期  …（子孙旺日 / 用神生旺日 / 应期难定）
趋吉：往 X 方寻 / 找 X 人打听 / 原处找
避凶：防 X / 勿久等勿投重注
诚实边界：方位为八卦/落宫粗指，非精确坐标；具体何日找回、是否必在某处不作铁断。
```

> 兜底：此模板是「降分辨率 + 给候选」的落地，方位/远近/能否/被盗分维、各标置信度，避免「铁口直断某处某日」翻车。

## 与四段式的关系（强制：画像＝叠加非替代）

> **画像不是完整输出，是「断语卡片」**——嵌入四段式②③，外层四段式 + 三级标注 + 趋避 + 应期 + 一小步 + 免责 + 白话层照旧。**只贴画像不套四段式 = 不合格**（review.py 仅 1/7）。金样例如下（小六壬寻物，实测 review.py 7/7 通过）：

```
① 起卦信息：小六壬·月日时起课，落宫大安。问事：寻物（钥匙丢了）。

## ② 排盘结果〔盘面事实〕
落宫 大安（属木、青龙、东方）。
🔍 失物寻人画像（降分辨率，不铁口直断）

## ③ 断语〔规则推演〕
- [原文]《小六壬》大安口诀「大安事事昌，求谋在东方，失物去不远，宅舍保安康」。
  · 术语解读：大安属木主静主安、方位东方，故「失物去不远」——东西没跑远，还在原处附近。
  · 问事解读：落到你丢的钥匙——大概率没丢到外面，还在家/原处附近，往东边或常放处找。
- [规则推演] 大安主「静止、心安」，不主移动偷盗（R-SW-01）。
  · 术语解读：落大安 = 安稳未动，非被盗移动之象。
  · 问事解读：应是「自己随手放、忘了」，不是被偷。

## ④ 结论〔现实建议〕
[主观推断] 吉凶总断：中平偏吉，失物去不远、易寻。
应期：短则今日，长则一五七之数（大安主一、五、七）。
趋吉：往家东方位/常放处找，先查抽屉、床头、玄关。
避凶：勿乱翻乱动扩大范围，先冷静回想最后放置处。
今日可行的一小步：先看进门后常放钥匙的位置（玄关/桌面/口袋），10 分钟内查一遍。
```
