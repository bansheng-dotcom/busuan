# 八卦万物类象（卦应）速查

> 出处：《梅花易数》卷三「断占总诀篇之四·卦应」引《说卦传》取象；另见「近取诸身 / 远取诸物」。
> 用法：测物/射覆/观物起卦时，取「物象→卦」「卦→物象」双向查——这是射覆特征画像（`射覆特征画像.md`）与测物取象的**上游数据**。
> 铁则：本表是取象速查，**不得把八卦单象冒充六十四卦本义**；断卦仍须 Grep《梅花易数》原文佐证。取象发散是体系天性，测物先降分辨率（五行/形态/用途），不押单一物名。

## 四、观物 / 测物取象要诀

1. **物象→卦**（观物起卦、端法用）：水→坎、火→离、金→乾兑、木→震巽、土→坤艮；圆→乾、缺→兑、方→坤、柔→巽、仰→震、覆→艮。
2. **卦→物象**（测物/射覆）：先定五行（金木水火土），再取形态（圆/方/长/缺/中空），后落用途——降分辨率，不押单一物名。
3. 现代映射见 `现代类象映射.md`（古象 + 现代象双查）。
