# 射覆 / 测物 · 特征画像法（借鉴 henrryjoke/shefu）

> 原则：**「AI 是画师不是鉴定师——刻画特征，命名权交给玩家。」**
> 射覆 / 测物 / 测动态，一律输出「特征画像」，**不押具体物名**。这是「降分辨率 + 给候选」的落地形态，直接根治「猜具体物」翻车（番茄酱教训：金口诀「用爻天罡辰＋贵神天乙」推成「金属圆物铜镜」，漏掉「地分酉＝四仲＝吃物」，实为番茄酱·红·糊状·调味 → 全错。见 `金口诀射覆门速查.md` 用法要点 0）。
> 理论根基：《正易心法》五原则（§一）；工程实现：`scripts/libs/judge/shefu_portrait.py`（信号→类象库→画像）+ `data/类象库.json`（4 类节点、可回填知识库）。

## 〇、核心定位与命中率基线（先读这条，治「AI 独自锁答案」）

> 借鉴 henrryjoke/shefu v0.3.0 的五轮实战复盘：**射覆具体物品仅约 1/5 完全命中**。根因是**卦象信息量有限（约 8 维约束 vs 物品约 20 维特征）**——靠盘面「铁口猜中」先天做不到。
>
> **所以正确模式是「AI 给约束 + 用户帮聚焦」的联合推断，不是「AI 独自猜」**：
> 1. AI 出「物性约束画像 + 置信度分级 + 候选集（3–5 个，不锁单一）」；
> 2. 按置信度决定下一步：**[高]→直接给候选请用户揭晓 / [中]→辨识问答（二分法，≤2 轮）/ [低]→请用户给一个模糊提示**；
> 3. 靠「辨识问答」补卦象给不出的缺口维度（材质/结构/功能/颜色/大小）。
>
> **禁止锚定上一个答案的信号组合**（三连错教训：打火机→锚点火、番茄酱→锚红液体、指甲刀→又锚红液体）。每次射覆独立。

## 一、理论根基（正易心法五原则）

> 出自麻衣道者《正易心法》42 章·陈抟注。这五条不是背诵口诀，是「画像法」为什么这样设计的理由：

1. **爻位即气位**——阳爻在哪里，阳气就在哪里；阴爻在哪里，阴气就在哪里。**不看标签，看位置。**
2. **八卦是八种功能态**——八卦不是名词，是德性：乾健、坤顺、震动、巽入、坎陷、离丽、艮止、兑悦。从卦画结构直接读，不从卦名读。
3. **观不是推**——先静观卦画/课式结构（六爻阴阳怎么排列、气就怎么走），再语境翻译；不是逻辑推导。
4. **同构容纳**——同一气脉可落于多个维度（自然/人身/器物/人伦），**一脉多现**。
5. **合于自然者为正**——每个取象必须能回溯到结构验证，方向不可逆：**结构 → 自然 → 语境**，不能从语境倒推。

> 落到射覆：**先把「气态」画出来（画像），再让玩家对着画像去认物（命名）**——所以「画像 ≠ 点名」，AI 负责刻画特征、把命名权交给玩家。

## 二、信号源与类象库（4 类 × 维度）

`data/类象库.json` 分 **4 类节点**，每节点两层：顶层「五行」+「dimensions」字典。画像引擎 `shefu_portrait.py` 把术法信号（天将名/八卦名/地支/天干）映射到对应节点，按 `confidence × 权重` 聚合出画像。四类节点维度分布（实测 `类象库.json`）：

| 类 | 节点数 | 维度 |
|---|---|---|
| 天将 | 12（贵人/螣蛇/朱雀/六合/勾陈/青龙/天空/白虎/太常/玄武/太阴/天后） | 五行·功能·形态·性质·材质·结构·颜色 |
| 八卦 | 8（乾坤震巽坎离艮兑） | 人物·功能·动物·形态·性质·数目·方位·材质·结构·静物·颜色 |
| 地支 | 12（子丑寅卯辰巳午未申酉戌亥） | 五行·形状·数目·方位·物类·颜色 |
| 天干 | 10（甲乙丙丁戊己庚辛壬癸） | 五行·方位·物类·颜色 |

- **核心六维**（天将/八卦共有的物性维度）：材质 / 形态 / 功能 / 结构 / 颜色 / 性质。
- **术法扩展维度**（地支/天干/八卦独有）：五行 / 形状 / 数目 / 方位 / 物类 / 人物 / 动物 / 静物。
- **合并全集 14 维**：五行 / 功能 / 形态 / 性质 / 材质 / 结构 / 颜色 / 人物 / 动物 / 数目 / 方位 / 静物 / 形状 / 物类。
- 注：**「尺寸」不在类象库直接映射**——由「形态/物类/数目」联合推断，标 [中]/[低]，不作独立维度。

## 四、置信度三档

- [高]（confidence ≥ 0.7）：多信号一致，或本卦/用卦主象直接给出。
- [中]（0.4–0.7）：单一信号，或需互卦/变卦/月建补充。
- [低]（< 0.4）：无映射记录，标「需类象库 / 信号无映射」。

  数目  [高] 5
  方位  [高] 西北 / [高] 东南
  材质  [中] 金属/首饰/细腻 / [中] 塑料/电子件外壳
  物类  [高] 狗 / [高] 谷瓦类
  颜色  [高] 白/银 / [高] 黄
💡 候选参考：金属/首饰/细腻 + 细/美/圆 + 美容/私密/阴柔 + 狗（候选类别，非点名）

> **白话**：`命中信号 X/Y` = 你给的信号里，有 X 个在类象库找到了映射、共 Y 个（没映射的就不出、或出 [低]）；每维取 top2 候选，[高][中][低] 是「这候选有多稳」。`💡 候选参考` 只是引擎把「材质+形态+功能+物类」的 top 值拼成的**原始提示**，不是答案——真正的候选物由 §六「落处合成」组合组装得出，不是点名。

## 六、落处合成（零件清单法，强制）

> **画像只是「零件清单」，不是答案。** 出完特征画像后，必须做「落处合成」：把画像里的 [高]/[中] 信号当「零件」，交叉组装成 3–5 个候选物再交付。**跳过这步只贴画像 = 不合格**（与「画像=叠加非替代」同级强制）。

### 6.1 求同 / 求异并重（防「多票求同」丢决定性信号）

- **求同定材质**：三术/多信号都出现的（如「金属」）→ 定**材质**，稳。
- **求异定功能/身份**：只有一两个信号独有的（如「火」）→ 往往是**功能/身份**的关键，**不许因「非三术共识」丢弃**，必须显式列出。
- 反例（打火机教训）：只做「多票求同」→ 得到「金属」（对材质）却丢掉「火」（对身份），永远合不出「打火机」。

### 6.2 五行信号多面（火 = 红 + 热 + 点火，别塞单桶）

- 一个五行信号**同时**映射多个面：**火 = 红（颜色）+ 热（性质）+ 点火/燃烧/照明（功能）**；水 = 黑（颜色）+ 冷（性质）+ 液体（材质）。
- 落处合成时，每个五行信号的**所有面都要列出**，再和其他信号组合，不许只取一面。
- 反例（番茄酱教训）：把「火」只读成「点火」→ 漏掉「火=红」，错过「红 + 糊状液体 = 番茄酱」。
- 反例（打火机教训）：把「火」只读成「红」→ 漏掉「火=点火」，错过「火 + 中空 + 金属 = 打火机」。
- 关键：火既可能是「红」（番茄酱），也可能是「点火」（打火机）——**靠「火」与其它信号的组合区分，不靠把「火」塞进单一桶**。

### 6.3 零件清单法（组合枚举候选物）

出完画像后，按下面模板显式组装，不许只列单维 top 值：

```
【零件清单】把 [高]/[中] 信号逐条抄出：
  材质：金属
  结构：中空 / 内虚
  五行/功能：火（点火/燃烧）
  材质：液体
  形态：圆 / 小件 / 手持

【组合组装】「什么小物件 = 金属壳 + 会点火 + 内有液体 + 中空 + 手持？」
  → 打火机 / 煤油打火机 / 油灯 / 防风打火机 …

【候选物】3–5 个，按「零件命中数 × 置信度」排序，不点名。
```

- **颜色 × 材质 是高频组合（先看它）**：红 + 液体 = 酱料/红酒/颜料；白 + 金属 = 银器；黑 + 液体 = 墨/酱油；黄 + 糊状 = 酱。颜色和材质两维组合，往往比单看功能更能锁定物类。
- **材质 × 结构 也是高频组合**：金属/甲胄/刀兵 + 开口/刃 = 指甲刀/剪刀/小刀/钳子。别只盯颜色×材质，结构（开口/中空/铰链）常常是工具类物件的关键。
- **不许锚定上一个答案的组合**：每次射覆独立，盘给的是一大票信号、答案只命中其一子集。必须枚举**全部候选组合**给排名、明确标「不确定」，不锁单一答案（三连错教训：打火机→锚点火、番茄酱→锚红液体、指甲刀→又锚红液体）。

### 6.4 诚实标「无信号」

- 某维度无可靠映射（如「功能」盘里没给「点火」）→ 明说「功能无直接信号，只能从材质/结构/五行推」，**不许硬套一个错的功能**（打火机教训：把太阴「阴柔/私密」这个**性质**硬读成「美容」功能）。

## 八、三阶段交互 + 置信度分级（决定下一步）

> 借鉴 shefu v0.3.0：交互从「渐进精化」收敛为**三阶段**，且**置信度决定下一步动作**。

| 阶段 | 动作 | 置信度分级决定 |
|---|---|---|
| **S1 第一印象** | 卦脉直读 → 画像 + 置信度分级 + 候选集（3–5 个，不锁单一） | **[高]** → 直接给候选，请用户揭晓；**[中]** → 进 S2 辨识问答；**[低]** → 请用户给一个模糊提示 |
| **S2 辨识问答** | 按「卦象给不出的缺口维度」提**二分法**问题（≤2 轮，每次只问一个维度） | 用户回答 → 排除一批候选 → 决定是否第二问 |
| **S3 揭晓与复盘** | 命中/偏移/遗漏各维度 → 回填类象库 + 画像 | 命中 +0.05 / 遗漏 +0.02 / 错误 −0.10（**递进调整，禁止单例大改**） |

**S2 辨识问题库**（二分法、排除逻辑，十大品类模板）：见 `references/辨识问题库.md`。原则：**只问卦象给不出的维度；每次只问一个维度；二选一/对比式；最多两轮。**

- 示例（候选为金属工具时）：Q1「是两片对称张合的，还是一根整体式的？」→ 张合=指甲刀/剪刀/钳子；整体=刀/螺丝刀/锤子。
- 紧急回退（品类不明时按优先级问）：大小 → 重量 → 材质软硬 → 用途。

**S3 回填**：`python scripts/libs/shefu_portrait.py update '{"命中":[...],"遗漏":[...],"错误":[...]}'`——**递进调整**（命中 +0.05、遗漏 +0.02、错误 −0.10），不做「对着一个答案把某信号拉满」的单例 hack。

## 九、与输出契约的关系（强制：画像＝叠加非替代）

> **画像不是完整输出，是「断语卡片」**——必须嵌入输出契约②③，外层输出契约 + 三级标注 + 趋避 + 应期 + 一小步 + 免责 + 白话层照旧。**只贴画像不套输出契约 = 不合格**（review.py 仅 1/7）。金样例如下（实测 review.py 7/7 通过）：

  · 问事解读：落到你测的东西——大概率中空带壳、与「电/亮/屏幕」相关，颜色偏红或银白。

## 十、铁律

- 不判断吉凶、不替玩家命名。
- 禁用：一定、必然、大吉、宜、忌、应该。
- 鼓励：可能、或许、呈现…态势。
- 结束语：「以上是根据卦象展开的特征画像，并非确定性结论。」
- 出完画像必须走 §六「落处合成」组装候选物再交付，只贴画像不组装 = 不合格。
