# 射覆 / 测物 · 特征画像法（借鉴 henrryjoke/shefu）

> 原则：**「AI 是画师不是鉴定师——刻画特征，命名权交给玩家。」**
> 射覆 / 测物 / 测动态，一律输出「特征画像」，**不押具体物名、不组装候选物**。这是「降分辨率 + 命名权交玩家」的落地形态，直接根治「猜具体物」翻车（番茄酱教训：金口诀「用爻天罡辰＋贵神天乙」推成「金属圆物铜镜」，漏掉「地分酉＝四仲＝吃物」，实为番茄酱·红·糊状·调味 → 全错。见 `金口诀射覆门速查.md` 用法要点 0）。
> 理论根基：《正易心法》五原则（§一）；工程实现：`scripts/libs/judge/shefu_portrait.py`（信号→类象库→画像）+ `data/类象库.json`（4 类节点、可回填知识库）。

## 〇、核心定位与命中率基线（先读这条，治「AI 独自锁答案」）

> 借鉴 henrryjoke/shefu v0.3.0 的五轮实战复盘：**射覆具体物品仅约 1/5 完全命中**。根因是**卦象信息量有限（约 8 维约束 vs 物品约 20 维特征）**——靠盘面「铁口猜中」先天做不到。
>
> **所以正确模式是「AI 给约束 + 用户帮聚焦」的联合推断，不是「AI 独自猜」**：
> 1. AI 出「物性约束画像」（多面象按维度完整并列）+ 置信度分级；**不组装候选物**——组装候选是「AI 独自猜」的制度化，正是三轮翻车（耳机仓/打火机/卡包）的共同根源；
> 2. 按置信度决定下一步：**[高]→画像已聚焦，请用户直接揭晓 / [中]→辨识问答（二分法，≤2 轮）/ [低]→请用户给一个模糊提示**；
> 3. 靠「辨识问答」补卦象给不出的缺口维度（材质/结构/功能/颜色/大小）。
>
> **禁止锚定上一个答案的信号组合**（三连错教训：打火机→锚点火、番茄酱→锚红液体、指甲刀→又锚红液体）。每次射覆独立。

## 一、理论根基（正易心法五原则）

> 出自麻衣道者《正易心法》42 章·陈抟注。这五条不是背诵口诀，是「画像法」为什么这样设计的理由：

1. **爻位即气位**——阳爻在哪里，阳气就在哪里；阴爻在哪里，阴气就在哪里。**不看标签，看位置。**
2. **八卦是八种功能态**——八卦不是名词，是德性：乾健、坤顺、震动、巽入、坎陷、离丽、艮止、兑悦。从卦画结构直接读，不从卦名读。
3. **观不是推**——先静观卦画/课式结构（六爻阴阳怎么排列、气就怎么走），再语境翻译；不是逻辑推导。
4. **同构容纳**——同一气脉可落于多个维度（自然/人身/器物/人伦），**一脉多现**。
5. **合于自然者为正**——每个取象必须能回溯到结构验证，方向不可逆：**结构 → 自然 → 语境**，不能从语境倒推。

> 落到射覆：**先把「气态」画出来（画像），再让玩家对着画像去认物（命名）**——所以「画像 ≠ 点名」，AI 负责刻画特征、把命名权交给玩家。

## 二、信号源与类象库（4 类 × 维度）

`data/类象库.json` 分 **4 类节点**，每节点两层：顶层「五行」+「dimensions」字典。画像引擎 `shefu_portrait.py` 把术法信号（天将名/八卦名/地支/天干）映射到对应节点，按 `confidence × 权重` 聚合出画像。四类节点维度分布（实测 `类象库.json`）：

| 类 | 节点数 | 维度 |
|---|---|---|
| 天将 | 12（贵人/螣蛇/朱雀/六合/勾陈/青龙/天空/白虎/太常/玄武/太阴/天后） | 五行·功能·形态·性质·材质·结构·颜色 |
| 八卦 | 8（乾坤震巽坎离艮兑） | 人物·功能·动物·形态·性质·数目·方位·材质·结构·静物·颜色 |
| 地支 | 12（子丑寅卯辰巳午未申酉戌亥） | 五行·形状·数目·方位·物类·颜色 |
| 天干 | 10（甲乙丙丁戊己庚辛壬癸） | 五行·方位·物类·颜色 |

- **核心六维**（天将/八卦共有的物性维度）：材质 / 形态 / 功能 / 结构 / 颜色 / 性质。
- **术法扩展维度**（地支/天干/八卦独有）：五行 / 形状 / 数目 / 方位 / 物类 / 人物 / 动物 / 静物。
- **合并全集 14 维**：五行 / 功能 / 形态 / 性质 / 材质 / 结构 / 颜色 / 人物 / 动物 / 数目 / 方位 / 静物 / 形状 / 物类。
- 注：**「尺寸」不在类象库直接映射**——由「形态/物类/数目」联合推断，标 [中]/[低]，不作独立维度。

## 四、置信度三档

- [高]（confidence ≥ 0.7）：多信号一致，或本卦/用卦主象直接给出。
- [中]（0.4–0.7）：单一信号，或需互卦/变卦/月建补充。
- [低]（< 0.4）：无映射记录，标「需类象库 / 信号无映射」。

  形态  [高] 细/美/圆

  性质  [高] 阴柔/细腻/私密
  数目  [高] 5
  方位  [高] 西北 / [高] 东南
  材质  [中] 金属/首饰/细腻 / [中] 塑料/电子件外壳

> **白话**：`命中信号 X/Y` = 你给的信号里，有 X 个在类象库找到了映射、共 Y 个（没映射的就不出、或出 [低]）；每维取 top2 候选，[高][中][低] 是「这候选有多稳」。`💡 候选参考` 只是引擎把「材质+形态+功能+物类」的 top 值拼成的**原始提示**，不是答案。**射覆到此为止，不组装候选物**——多面象并列交给玩家去对，命名权在玩家。

## 六、多面并列（画像的正确展开——并列，不组装）

> **画像就是最终产出，不组装候选物。** 出完特征画像后，交付的是「多面象按维度完整并列」——每个信号的所有面都列出来，不许挑一个锁死、不许组装成候选物。**组装候选物是「AI 独自猜」的制度化，正是三轮翻车（耳机仓/打火机/卡包）的共同根源**：取象并列是准的，一进入「组装候选」就锁死方向、全错。

### 6.1 纯并列、零收敛（不求和、不数票、不总结共识）

- **不求和、不总结「共识」**：多信号原样并列列出即可，**不做「三术共识」这类收敛小结**——「求同」＝数票＝挑主导＝锁方向，是翻车根源（眼镜布教训：字面数「红/赤」3 票压过「黄」2 票，漏掉「黄＝土旺/用爻/发用」当令信号，答案正是黄）。
- **每个信号的多面全列**：一个信号同时有多面（如「己」＝绛红〔十干颜色〕＋黄〔五行土色〕），两面都列，不许取一面丢一面。
- 反例（打火机教训）：只做「求同」→ 得到「金属」却丢掉「火」，漏掉关键面。

### 6.2 五行信号多面（火 = 红 + 热 + 点火，别塞单桶）

- 一个五行信号**同时**映射多个面：**火 = 红（颜色）+ 热（性质）+ 点火/燃烧/照明（功能）**；水 = 黑（颜色）+ 冷（性质）+ 液体（材质）。
- 并列时，每个五行信号的**所有面都要列出**，不许只取一面。
- 反例（番茄酱教训）：把「火」只读成「点火」→ 漏掉「火=红」。
- 反例（打火机教训）：把「火」只读成「红」→ 漏掉「火=点火」。
- 关键：火既可能是「红」（番茄酱），也可能是「点火」（打火机）——**两面都并列列出，靠玩家/交互去对，不靠模型选**。

### 6.3 诚实标「无信号」

- 某维度无可靠映射（如「功能」盘里没给「点火」）→ 明说「功能无直接信号，只能从材质/结构/五行推」，**不许硬套一个错的功能**。

### 6.4 盲区显式化（缺X ≠ 非X）

> 2026-10-18 指甲刀教训（铁指甲刀 + 蓝色塑料壳）：三术盘面全没起出「兑」——梅花本卦天地否(乾坤)、金口诀四位(壬水/天空土/辰土/午火)五行无金、六壬发用亥水。而指甲刀的核心类象（金刃/缺器/塑料壳/开合）恰恰全在「兑」卦。根因不是类象库缺（兑早已录全），而是**盘面起不出对应卦象时的先天信息缺口**。

**「缺X ≠ 非X」铁律**：盘面缺某五行/某卦，**只能**推出「本盘对该类物件分辨力低（无该类信号可依）」，**绝不能**推出「物件非该类」——起盘采样有限，缺＝没起出，不是不存在。本轮金口诀四位无金、梅花六观无兑，实物却是铁指甲刀，正是这条的铁证。

**画像引擎「盲区」维度**（`shefu_portrait.py::blind_spots`）：每副画像除「盘面给了什么」，另列「盘面给不出什么」——
- **五行盲区**：盘面信号五行并集 vs 金木水火土，缺者标「缺金→对金属/刀剪/利器分辨力低」等。
- **卦盲区**（梅花六观）：六观卦并集 vs 八卦全集，缺者标「缺兑→缺「金刃/缺器/刀剪/带口工具」类象」等。

作用：把「缺」从被忽略的空白变成**显式降级提示**，逼断卦者**去走辨识交互补维度**，而不是顺着盘面现有的错信号往下推。

## 八、三阶段交互 + 置信度分级（决定下一步）

> 借鉴 shefu v0.3.0：交互从「渐进精化」收敛为**三阶段**，且**置信度决定下一步动作**。

| 阶段 | 动作 | 置信度分级决定 |
|---|---|---|
| **S1 第一印象** | 卦脉直读 → 画像（多面象并列） + 置信度分级 | **[高]** → 画像已聚焦，请用户直接揭晓；**[中]** → 进 S2 辨识问答；**[低]** → 请用户给一个模糊提示 |
| **S2 辨识问答** | 按「卦象给不出的缺口维度」提**二分法**问题（≤2 轮，每次只问一个维度） | 用户回答 → 排除一批象/方向 → 决定是否第二问 |
| **S3 揭晓与复盘** | 命中/偏移/遗漏各维度 → 回填类象库 + 画像 | 命中 +0.05 / 遗漏 +0.02 / 错误 −0.10（**递进调整，禁止单例大改**） |

**S2 辨识问题库**（二分法、排除逻辑，十大品类模板）：见 `references/辨识问题库.md`。原则：**只问卦象给不出的维度；每次只问一个维度；二选一/对比式；最多两轮。**

- 示例（候选为金属工具时）：Q1「是两片对称张合的，还是一根整体式的？」→ 张合=指甲刀/剪刀/钳子；整体=刀/螺丝刀/锤子。
- 紧急回退（品类不明时按优先级问）：大小 → 重量 → 材质软硬 → 用途。

**S3 回填**：`python scripts/libs/judge/shefu_portrait.py update '{"命中":[...],"遗漏":[...],"错误":[...]}'`——**递进调整**（命中 +0.05、遗漏 +0.02、错误 −0.10），不做「对着一个答案把某信号拉满」的单例 hack。

**复盘红线（禁据答案反推改规则/代码，2026-10-14 耳机仓 + 打火机教训）**：
- 用户揭晓的答案是**后验事实，不是改规则/类象库/代码的依据**。禁止「拿答案回头在盘面/类象库里挑能对上答案的信号，再反向改 confidence、改断法规则」——这是以答案为中心的逆向工程，会污染规则。
- 复盘只做一件事：**定位真正的问题**——是「流程缺陷」（跳用爻）、「方法缺陷」（求同淹没求异 / 单锁一面），还是「信息根本不足」（盘面 8 维 vs 物品 20 维的先天歧义）。
- **改规则的检验标准**：改出的规则必须是「不知道答案时、断卦现场也能预先判定」的；凡是「只有知道答案后才晓得该怎么取」的，一律不是规则、是反推，**禁写**。
- 允许回填类象库的，只有「与答案无关的客观类象扩展」（某神某支确有某物类象、此前缺录），不许「按答案把某象 confidence 拉高/拉低」。

## 九、与输出契约的关系（强制：画像＝叠加非替代）

> **画像不是完整输出，是「断语卡片」**——必须嵌入输出契约②③，外层输出契约 + 三级标注 + 趋避 + 应期 + 一小步 + 免责 + 白话层照旧。**只贴画像不套输出契约 = 不合格**（review.py 仅 1/7）。金样例如下（实测 review.py 7/7 通过）：

## ③ 断语
- [原文]《说卦传》离为火、为电、为目、为雉；兑为泽、为口、为毁折。
