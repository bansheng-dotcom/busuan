# 现代类象映射（射覆 / 测物 / 测动态 速查）

> 古籍万物类象是「农业时代」的取象（火=炉、文书、雉），现代占卜要补「现代映射层」，收窄类象发散。
> 用法：取象时「古象 + 现代象」双查，命中率更高。古象标出处，现代映射为 `[规则推演]` 增补。

## 〇、射覆 / 测物的诚实边界与策略

- **先认清**：测「具体是什么物 / 具体什么动作」是**低信号题**——一个神将几十个类象，事前无法确定取哪个，所以「精确命中某物」命中率天然低，**没有一条规则能让它百发百中**（2026-10-08「番茄酱」教训：事后挑「朱雀=赤色」是倒推答案，事前同样可挑「朱雀=文书」，都合理但只有一个中）。
- **唯一稳健的提准法＝降分辨率**：把「具体物」降到「**类别 / 属性**」——五行、颜色、软硬、食物/钱/工具、糊状/液体、在家/在外、静/忙。类别级命中率远高于具体物。
- **给候选不给答案**：输出「方向 + 候选排序」，不押单一答案。
- **靠后验积累**：几十上百个后验才配提炼统计规律，**2 个案例只能当个例，不配定规则**。
- **类象带 confidence + 后验回填**（借鉴 shefu）：每条类象标置信度（🟢高/🟡中/🔴低），每轮复盘后——命中信号 confidence↑、错误信号 confidence↓，靠几十个后验把类象权重校准出来；具体画像法见 `射覆特征画像.md`。

## 三、射覆 / 测物 通用口诀

1. **动者为用，用卦定本质**（金属/木/水/火/土）。
2. **体卦定属性**（中空、带电、颜色、软硬）。
3. **互卦定内里**（装什么、含什么）。
4. **变卦定用途/动态**（咬合、发声、夹住）。
5. **降分辨率**：先断「五行 + 形态 + 用途」三大类，别直接猜「具体某物」。
6. **记外应**：起卦瞬间的环境/直觉，是射覆最灵的外应，别只盯盘面。

## 四、诚实边界

- 类象发散是体系天性：一个「兑金」能对应几十种金属物。
- 射覆/测具体动作命中率有限，优化目标是「明显高于随机」，不是「百发百中」。
- 最有效的提准手段：**降分辨率（占方向不占动作）＋ 现代映射 ＋ 后验校准**。
