# 梅花卦脉取象（结构 → 德性 → 落处 推导法）

> 借鉴 shefu 项目（正易心法 + 说卦传卦脉解读）。核心：**八卦取象不靠查表，靠「结构→德性→落处」推导**。
> 用法：梅花测物/射覆/观物起卦时，遇到 `类象库.json` 没有的场景，用卦脉推导新类象；断卦先看德性、再落处。
> 与 `八卦取象速查.md` 互补：速查表是「查得快」，本文是「推得全」。取象发散是体系天性，测物先降分辨率（五行/形态/用途），不押单一物名。

## 一、八卦 = 八种功能态（不是八个名词）

| 卦 | 结构 | 德性 | 一句话卦脉 |
|---|---|---|---|
| 乾 ☰ | 三阳纯奇 | **健** | 纯阳自健，自我驱动，无始无终 |
| 坤 ☷ | 三阴纯偶 | **顺** | 纯阴自顺，承载一切，暗流遍体 |
| 震 ☳ | 一阳在下 | **动** | 阳气压至最深处，必暴起冲破 |
| 巽 ☴ | 一阴在下 | **入** | 阴气从根渗入，无孔不入 |
| 坎 ☵ | 一阳在中 | **陷** | 阳气陷于阴中，进退两难 |
| 离 ☲ | 一阴在中 | **丽** | 阴附于阳体，因阳而明 |
| 艮 ☶ | 一阳在上 | **止** | 阳气走到顶，力尽而止定 |
| 兑 ☱ | 一阴在上 | **悦** | 阴气到顶溢出，润泽散布 |

## 二、卦脉推导通式

```
卦画结构（几阳几阴、在什么位置）
  → 德性（健/顺/动/入/陷/丽/止/悦，一字）
  → 功能态（一句话：气在做什么）
  → 落处（气在这个领域表现为 X：自然/人伦/动物/植物/物用/人体/性状/颜色）
```

**例（乾）**：三阳纯奇 → 健（纯阳自健）→ 落「玉」（纯阳凝为至坚至纯之质）、「马」（健行千里）、「圜」（健行无始无终，轨迹为圆）。

**为什么这比查表全**：查表只能查到表里有的；推导法从「结构」这一个根出发，任何新场景都能照见「为什么」，不会自相矛盾。断卦时每条类象都能回答「为什么是这个象」，不是「口诀说它是」。

## 四、卦脉流动（六爻内阴阳进退）

> B3 教「从初爻到上爻，气怎么走」。与体用生克互补：体用看「谁生谁克」，卦脉看「气往哪流」。

1. **阴阳进退四模式**：阳进（阳爻集中下＝上升期）、阳退（阳集中上＝衰退期）、阴进（阴从根渗入＝隐患滋生）、阴退（阴集中上、阳从底破＝新机萌动）。
2. **消息卦定位**：数阳爻个数（0~6），对照十二消息卦（复→临→泰→大壮→夬→乾 为阳长，姤→遁→否→观→剥→坤 为阴长），定位本卦在阴阳大周期哪一段。
3. **中爻造化（互体）**：二至五爻为「造化区」，互体 = 藏在卦腹部的脏腑。本卦表面态势 vs 互体内部造化——**一致＝表里如一；不一致＝祸福倚伏**（表面一套，内部一套）。

## 五、五观分析（梅花断卦可扩展，本/互/变之外加三观）

| 观 | 看什么 | 问什么 |
|---|---|---|
| 立极（本卦直读） | 上下卦功能态 + 阴阳分布 + 月建加权 | 这团气是什么、力度如何 |
| 观一 变卦 | 动爻推动后流向何处 | 按此态势下去会变成什么 |
| 观二 互卦 | 二至五爻重组的内在因果 | 什么内因导致当前局面 |
| 观三 错卦 | 六爻全反的对立面 | 反面映出本卦什么特征 |
| 观四 综卦 | 上下颠倒的立场 | 换位置看是什么面貌 |
| 观五 复卦 | 上复/下复的变化态 | 条件反转后的可能态 |

**会合参证**：多窗口印证＝🟢 高置信；窗口矛盾＝🟡 中置信、标注矛盾（这是信息不是错误）；窗口沉默（静卦无变）＝🔴 标注缺位。

## 六、射覆落处维度（测物输出用）

> 射覆是「画师不是鉴定师」——评的是特征刻画精度，不是命名准确率。

| 维度 | 输出 | 分级 |
|---|---|---|
| 用途/品类 | 干什么用的 | ★★★ |
| 形态/材质 | 圆方长短、金木水火 | ★★ |
| 颜色/尺寸 | 深浅大小 | ★ |

每维度输出：**特征描述 + 卦象依据 + 置信度 🟢🟡🔴**。命中维度记 confidence +0.05，错误维度 -0.10（反馈闭环）。

## 七、铁则

- **先德性、后落处**：先读「健/顺/动/入/陷/丽/止/悦」是什么功能态，再落到具体类象；不许跳过德性直接贴物名。
- **不得把八卦单象冒充六十四卦本义**：单卦德性 ≠ 重卦卦义，断卦仍 Grep《梅花易数》原文佐证。
- **降分辨率**：测物先定五行、再形态、后用途，不押单一物名。
