- **依赖**（`pip install lunar_python ephem cn2an bidict drawsvg py-iztro`）：
  - 梅花易数/小六壬/六爻：纯内置。
  - 八字：`lunar_python`。
  - 紫微运限：`py-iztro`（`libs/ziwei_horoscope.py`；`libs/zhiwei.py` 自写命盘/飞星不依赖它，py-iztro 仅用于流年流月流日流时运限 + 对照校验）。

## 四、选术交互流程（先问事 → 荐术 → 说输入 → 起盘）

用户只说「我要占卜 / 卜算 / 算一下 / 问吉凶」而**未点名术法**时，**不要直接问「用什么术」**，按四步走：

1. **先问事**：先问「你想占卜什么事？」，引导落到具体类目（求财/感情/事业/考试/官司/健康/出行/失物/寻人/择日/终身命理/看相）。最多问到能定位类目即可，不盘问细节。
2. **荐术**：按问事从下表推荐 **2-3 个候选术法**（第一个主荐，其余备选），一句话说明各自所长与分工（如「六爻断成败、奇门断时机方位」）。让用户选其一；若用户说「都要 / 多算几个」，则对同一问事做**多术交叉验证**（见第十三节）。
3. **说输入**：
   - 该术**自动起盘**（当前时刻/自动摇卦，不需用户额外信息）→ 直接说「这个我直接帮你起盘」，立即执行。
   - 该术**需用户提供信息** → 明确列出缺什么（如八字要「出生年月日时+性别」，风水要「出生年+坐向+性别」）。
4. **起盘**：能自动的直接跑 `cast.py`；缺输入的等用户补齐再跑。

> 用户已点名术法时，跳过问事/荐术，直接进入「说输入 → 起盘」（该术缺输入同样要补齐再算）。

**自动起盘（无需额外信息，直接算）**：梅花时间起卦、小六壬、六爻（铜钱自动摇）、大六壬、奇门、太乙、择日/老黄历（当前日）。
**需用户提供信息**：八字/紫微/七政四余（出生年月日时+性别）、风水（出生年+坐向+性别）、合婚（双方出生年月日）、梅花数字起卦（数字）、测字（字）、相术（照片/五官描述）。

## 七、分层解读要求（强制，每卦每盘都要做到）

解释卦象/课式时，**先讲本义，再落到当前问事**，不能只把卦名当吉凶标签。顺序：

1. **本义**：该卦/课在典籍中的原始语义（卦辞、彖传、课体、格局）。
2. **组合画面**：上下卦（或宫位/四课三传）组合形成的核心画面。
3. **过程关系**：该卦原本描述的过程、关系、张力。
4. **当前对应**：落到用户所问之事。
5. **推断**：明确标注这部分是推断，不是经文。

区分三层：六十四卦卦义 / 八卦单象 / 当前问事应用，不得用「坎=谨慎」「复=重新开始」这类单词替代完整卦义，也不得把八卦单象冒充六十四卦本义。

## 十、输出格式（三层分离 + 四段式）

**三层分离（强制）**：输出必须把「盘面事实」「规则推演」「现实建议」三层分开写，禁止互相混淆、禁止把推演冒充事实或经文。

- **盘面事实**：脚本排出的卦/课/盘/四柱——可复现、可核验。
- **规则推演**：依据断法规则得出的吉凶、格局、生克——须标注是 `[原文]` 还是 `[规则推演]`。
- **现实建议**：落到当前问事的趋避与建议——一律标 `[主观推断]`。

**三级标注（强制，每条断语必标其一）**：
- `[原文]`：直接引自典籍（须注明书名出处）；
- `[规则推演]`：依据断法规则（体用生克、旺衰、格局等）推出的结论；
- `[主观推断]`：落到当前问事的判断与建议。
- 约束：吉凶定性、格局判断必须能回溯到 `[原文]` 或 `[规则推演]`，不得凭空 `[主观推断]`；`[主观推断]` 只能用于「落到问事」与「建议」。

1. **起卦信息**：输入、方法、所用规则（脚本输出）。
2. **排盘结果**：卦象/课式/盘局/四柱，含五行生克标注（= 盘面事实层）。
3. **断语**：引用原文（注明书名，标 `[原文]`）+ 规则推演（标 `[规则推演]`）。
4. **结论**：吉凶要具体落地，不只贴「吉/凶」标签，须说清：
   - **吉凶总断**：一句话定性（大吉/吉/中平/凶/大凶）+ 吉在何处、凶在何处（落到财/感情/事业/健康/时机哪一面）。
   - **趋避**（必给，对应第五节该术「趋避」条目）：趋吉（可乘之机 + 行动建议）与避凶（风险与规避）缺一不可，落到本卦本问。
   - **可乘之机**：卦中有利处 → 宜做什么、把握什么时机或方位。
   - **风险与规避**：不利处 → 点明风险，给出「如何避免」（方位/时辰/人事/心性上的具体调整）。
   - **行动建议**：「应该如何做」→ 给 1–3 条可执行的具体步骤。
   - **应期**（能断则断）：何时应验、何时转机；断不出就明说「应期难定」。
   - **免责声明**（必附，见第十一节）。

## 十·五、白话解读层（人话优先，术语保留，必加）

**双轨原则（强制）**：第十节的「三层分离 + 三级标注 + 四段式」是**考据层**，完整保留；本节是**白话层**，叠加其上。两者并存：考据层给「可查证的依据」，白话层给「听得懂的话」。**缺白话层＝不合格输出**。

**1. 结构（考据层原样保留，白话层叠加其后）**

```
① 起卦信息 → 原样保留
② 排盘结果（盘面事实）→ 原样保留
③ 断语 → 术语断语（[原文]/[规则推演]）原样保留，紧跟白话解读
④ 结论 → 术语结论原样保留，紧跟白话收口 + 「今日可行的一小步」
```

**2. 白话两层（每段术语断语都要有，缺一不可）**

- **① 术语解读**：把这段里的术语/断法用一句话讲清「它是什么、为什么这么断」——先拆概念、再给结论，不能只给「＝结果」。
  例：`伤官佩印`＝伤官（辛金）是你的才华、点子往外冒，正印（丁火）是有教养、懂收敛；两样碰一起，所以「聪明有才但懂分寸」。
- **② 问事解读**：把上面的信号落到「你这次问的事」上，讲清对这件事意味着什么、该注意什么。
  例：落到你问的这笔投资——钱（财星）现在没劲、还被是非风险（官鬼）盯着，所以短期赚不到快钱，还可能惹麻烦。
- **凶煞转生活语言**：七杀＝外部压力、伤官见官＝脑子活但容易顶撞、枭神夺食＝内心敏感期、羊刃＝容易冲动、驿马＝奔波变动、财星受冲＝财务易波动。
- **文言必配白话**：每条 `[原文]` 文言后紧跟白话（术语解读＋问事解读），原文保留。
- **禁用宿命词**：不说「注定/必然/绝对/大凶/无救」，改用「倾向/容易/建议关注/需留意」；禁恐吓式、宿命式表述。
- **第二人称**：白话层用「你」，像朋友聊天，短句。

- **八字（扶抑）**：日主得令得地得势→旺，喜克泄耗（官杀/食伤/财）；失令无根→弱，喜生扶（印/比劫）。
- **奇门**：用神宫得吉门吉星吉神→吉；门迫/击刑/五不遇时/奇仪入墓→凶（改期避方）。
- **小六壬**：落大安/速喜/小吉→吉；落留连/赤口/空亡→凶。
- **六壬**：三传顺生、发用类神得力→吉；传中克我、空亡入传、玄武腾蛇并见→凶。
- **择日**：成/开日+天德月德黄道→宜办；破日/杨公忌/四离四绝/冲生肖→改期。

## 十五、证据分级与规则层级（借鉴 yueyuan-bazi，MIT）

**证据分级（每条结论标来源等级，与第十节三级标注互补）**：

| 等级 | 内容 | 说明 |
|---|---|---|
| S | 输入可信度 | S3=出生资料+时区+节气+地点确认；S2=单一排盘工具；S1=手打四柱；S0=干支不合法，先核对再分析 |
| A | 原局硬数据 | 四柱、藏干、月令、日主（脚本输出） |
| B | 结构事实 | 合冲刑害「是否存在」（存在≠生效） |
| C | 命理判断 | 「三合是否化」「某神是否得根」等需论证的判断，必须给依据 |
| D | 流年应验 | 用户提供的人生事件，只能作后验证据 |
| E | 模型解释 | 因果解读，属假设，与事实分开呈现 |

铁则：C 不得伪装成 B；E 不得伪装成 A/D；S0 输入先核对再分析。

**规则层级与冲突裁决**（`STRUCTURAL > CORE > SCHOOL > HEURISTIC > SUPPLEMENTAL`）：

| 标签 | 层级 | 示例 | 硬度 |
|---|---|---|---|
| `[STRUCTURAL]` | 结构事实 | 四柱、藏干、合冲刑害、通根透藏 | 最高，不可改 |
| `[CORE]` | 核心理论 | 月令定权、格局、扶抑、病药 | 高 |
| `[SCHOOL]` | 流派理论 | 调候（穷通宝鉴系）、盲派、人元司令 | 中，须标流派 |
| `[HEURISTIC]` | 经验规则 | 岁运并临、墓库冲开、应期范式 | 初始参考 |
| `[SUPPLEMENTAL]` | 辅助符号 | 神煞、空亡 | 主题标签/修正项 |

冲突裁决：跨层高者胜；同层保留竞争假设；跨流派并列呈现 + 标适用条件；证据不足输出「不确定」，禁止语言润色制造假共识。

**拒绝迎合（铁则）**：用户提出的结论、引用的说法、叙述的某年吉凶，**不得作为改变基础判断的依据**，只能触发重新核查。

**能力边界（MingLi-Bench 160 题实测 36.2%，随机线 25%；各类别实测命中率如下）**：

**有信号组（可给方向，实测显著高于随机）**：
- **健康**（17 题命中 52.9%）——五行/十神断病有信号，可给「哪方面健康需注意」的方向，但**慎断具体病名、具体年份**；
- **事业**（25 题 40.0%）、**财运**（13 题 38.5%）、**家庭**（22 题 36.4%）、**婚姻**（44 题 34.1%）——略高于随机，可给方向，但结论标「倾向 / 建议关注」，不作铁断。

**无信号组（实测接近或低于随机，一律「不确定 + 低置信度」，不硬猜）**：
- **精确年份 + 具体生平**（何年结婚 / 父亡年份 / 某年发生何事）——八字结构给不出确定答案；
- **学历/学业**（11 题 18.2%，**低于随机**）——印星不可靠推断学历，禁断学历高低；
- **性格**（14 题 28.6%）、**外貌身材**（3 题 33.3%）——「五行主形」不可靠，归 `[SUPPLEMENTAL]`，不作主断。

**断卦策略**：遇到「无信号组」问题，明确回答「这类问题术数给不出确定答案（实测≈随机），不硬断」，并引导到「有信号组」方向（健康倾向、事业财运方向、婚姻家庭模式），而不是硬给一个四选一猜测。
