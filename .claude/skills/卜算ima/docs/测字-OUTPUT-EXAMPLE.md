## ③ 断语〔规则推演〕

- `[原文]`《测字秘牒》：「何以谓之装头？盖其所问之事与所写之字……我则添笔于上而出之。」（测字秘牒:14，测字十法·装头）
- `[规则推演]` 字同、事不同、断不同——先定所测之事，再拆字取义（装头/接脚/穿心/破解/添笔等十法）+ 心易六法取义 + 取格大法定吉凶。
- **术语解读**：测字是"拆字形、取字义、谐字音"来断事；同一个字，问的事不同，断法就不同。
- **问事解读**：先说你问什么，我才能按这件事拆这个字（如「临」问病，取音可断「临丧」）。

## ④ 结论〔现实建议〕

- `[主观推断]` **吉凶总断**：视拆得吉凶形而定——拆得吉字吉形顺势行，凶字凶形止缓改期。
- **应期**：转注定音以应事，应期难定。
- **趋吉**：拆得吉字吉形（装头见首、会意吉象、谐声吉音）时顺势而行。
- **避凶**：拆得凶字凶形（破解散、谐声凶音、五行相克）时止、缓、改期；一事一测勿反复。
- **今日可行的一小步**：今天先想清楚要测的**具体一件事**，再把字报来，一事一测。
- **判断停在哪**：测字只给「字象吉凶」方向；具体结果、精确应验不硬断。
