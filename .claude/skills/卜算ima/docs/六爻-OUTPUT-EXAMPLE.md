### 用神：妻财伏而不现

- `[原文]`《增删卜易》：「占妻妾病者，以财爻为用神，财爻旺相或临日月……治之即愈。」（增删卜易:25，财爻为用神）
- `[规则推演]` 求财以妻财为用神；本卦妻财不上卦，伏三爻（飞神兄弟己亥克之），用神衰（我生月建、我生日辰）——财爻不现又衰，主**财上无根、求财艰难**。
- **术语解读**：用神就是"你这事对应的那个爻"，求财看妻财；"伏"是它没露在卦面、藏在别爻底下，还压在克它的兄弟爻下，等于"财被压着出不来"。
- **问事解读**：这笔财眼下难到手，是"有想法没落地、钱被别的事占着"的象，不宜硬求。

### 世应与忌神动克

- `[原文]`《增删卜易》：「凡学卜者……先学装卦，知道动变及卦之六冲……看熟用神章中占何人占何事以何爻为用神。」（增删卜易:6，装卦动变）
- `[规则推演]` 世应关系「应克世」（凶，对方克我压力大）；五爻兄弟（忌神）动克用神财爻——忌神动克用神，防破财、合伙分利之失。
- **术语解读**：应克世＝对方/外部压着你打；兄弟是"劫财"的忌神，它一动就克财，等于有人分你的钱、或破财。
- **问事解读**：这卦提醒你——这单子/这笔财，容易被竞争对手或合伙方压一头，还可能破财，先别投入。

### 应期

- `[原文]`《增删卜易》：「各门类应期总注章。」（增删卜易:65，应期总注）
- `[规则推演]` 用神伏藏待出伏、旬空待出空、冲待合合待冲——本卦财爻伏藏且衰，**出伏/得生扶之日方有转机**，当前旬空子丑，待出空之月日再议。
- **术语解读**：应期就是"什么时候应验/什么时候转机"；财伏着，要等它"出来"或"被生扶"的日子才有机会。
- **问事解读**：短期内不宜动，等出伏、出空、得月建日辰生扶之时再考虑，别抢这一时。
