# 太乙神数（国运大局、主客胜负）

> 分术法文档。总纲见 `SKILL.md`，多术联动见 `XUANXUE-LINKAGE.md`。

## 起盘

```bash
python scripts/cast.py taiyi                 # 太乙神数·当前时刻(年计/统宗)
python scripts/cast.py taiyi --ji 0-5 --method 0-3 --game --full  # 太乙·计式×积年法+运筹博弈+全字段
python scripts/cast.py taiyi --json          # 太乙·结构化双轨(散文+盘面事实层JSON)
```

默认「年计 + 太乙统宗积年」；可用 `--ji`（0年 1月 2日 3时 4分 5命）`--method`（0统宗 1金镜 2淘金歌 3太乙局）切 24 种盘，`--game` 加运筹博弈，`--full` 出全字段。已知引擎边界：命法(5)、日计×太乙局(2,3) 有 bug 已被 cast.py 拦截；时/分计×非统宗 可能死循环。

## 断卦流程

- 起盘：`cast.py taiyi [--ji 0-5] [--method 0-3] [--game] [--full]`（脚本已算太乙积年、行宫、计神文昌始击、主客五将、三才五福、八门九星、二十八宿、五运六气、军事占断、格局、古籍卷次推演等 100+ 字段，分门别类打印；`--full` 出全 JSON）。
- 断：太乙落宫旺衰、主客胜负、格局（掩迫关囚击格对）；**先套规则函数**（勿心算）——`rules.taiyi_suan(算数)`（R-TY-01 算数吉凶）、`rules.taiyi_zhuke(主算,客算)`（R-TY-02 主客胜负）、`rules.taiyi_geju(断语)`（R-TY-03 掩迫关囚击格对凶格）、`rules.taiyi_luogong_wangshuai(旺衰)`（R-TY-04 落宫旺衰），再 search_txt.py 原文佐证。
- 趋避：
  - 趋吉：主客算和、客算胜主则宜先发制人；太乙落宫旺相、文昌始击得地 → 可进、可主动。
  - 避凶：遇掩（主将掩蔽）、迫（太乙迫宫）、关囚、击格对等凶格 → 避正面硬碰，改守势、换方向、待时机。
  - 参断：主算客算定谁利主谁利客；计神、文昌、始击三方定吉凶方位；太乙行宫与岁计统宗积年合参，大事重主客胜负。
- 交叉验证：主客算 / 格局 / 落宫旺衰 三维一致才定论（`rules.cross_validate`），不一致明说「信号冲突」降级。
- **案例检索（诚实说明）**：太乙**无古籍占验案例**（典籍均为算法/格局/口诀书，无「断案」类记录），`case_search.py "占事" 太乙` 会如实返回空——断卦不以「相似案例」为据，改以规则函数（R-TY-01~04）+ 速查表 + 典籍原文佐证；现代占验案例靠 `cases/taiyi/`（`manage.py new`）沉淀后验，缺案例时照实说明。
- 参考：`txt\[易藏] 太乙金镜式经.txt`、`太乙秘书.txt`、`太乙淘金歌.txt`、`太乙局.txt`、`太乙人道命法.txt`；`txt\[道藏] 黄帝太乙八门入式秘诀.txt` 等。
- 速查：`references/太乙速查.md`（主客算吉凶/主客胜负/掩迫关囚击格对/落宫旺衰/三才五福/起盘 CLI），断卦按格局名/算数断语 search_txt.py 原文佐证。
- **全量回归自检**：`python scripts/libs/taiyi_regress.py`（`libs/taiyi_regress.py`）三层体检——①穷举体检（计式×积年法 × 时间序列，报崩溃/结构错/落宫分布）；②结构不变量（局式数∈1-72、落宫∈1-16、主客算范围、计神文昌始击合法宫位、八门八宫旺衰 8 宫齐全）；③积年独立重算（lunar_python 独立算农历年，校验年计 4 积年法：统宗/太乙局 10153917、金镜 1936557、淘金歌 10154193）。
- **已知引擎边界（诚实标注，kinliuren 2019 旧代码）**：①命法(ji_style=5) pan 抛 TypeError，上游未完成，`cast.py` 已拦截；②日计×太乙局(2,3) TypeError；③时/分计×非统宗 可能死循环。④【已修复】每年大雪~小寒约 30 天 `pan()` 崩溃（sxtwl 垫片冬至年界错配），2026-10-08 已修，穷举 0 崩溃。

## 输出格式（照八字升级，强制）

> 七条可复用经验见 `references/输出格式升级清单.md`。逐字样例见 `docs/太乙神数-OUTPUT-EXAMPLE.md`（主客胜负）。

- **一眼摘要**：`taiyi.summary()` 已并入 `cast.py taiyi` 输出（局式/太乙落宫/主客算/胜负），断卦先看卡再看盘。
- **骨架先行（三层分离 + 四段式）**：②排盘结果〔盘面事实〕③断语〔规则推演〕④结论〔现实建议〕。
- **三级标注**：③每条 = `[原文]`（附「太乙金镜式经:行号」段落 ID，`classical_search.py --passage-id` 复核）+ `[规则推演]` + 「术语解读」+「问事解读」。
- **诚实边界**：④结尾写「判断停在哪」，具体成败不硬断；太乙无古籍占验案例，不以「相似案例」为据。
- **结构化双轨**：`cast.py taiyi --json` 出 JSON（`schema=taiyi-panfact-v1`）。
