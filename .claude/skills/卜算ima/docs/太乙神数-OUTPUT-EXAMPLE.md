## ③ 断语〔规则推演〕

- `[原文]`《太乙金镜式经》：「推多少以占胜负……客以少筭临多，主人胜也。」（太乙金镜式经:3，主客算胜负）
- `[规则推演]` 客算 3 少、主算 16 多，客以少算临多 → **主人胜**，利主不利客；宜守正、据主场，不宜先发。
- **术语解读**：太乙用"主算/客算"比大小定胜负——主算是守方力量、客算是攻方力量；客以少临多，就是"攻方吃亏、守方得利"。
- **问事解读**：你若是"主"（守方/主场/已有地盘的一方），此局利你；若想"先发制人"当客方，则不利。

## ④ 结论〔现实建议〕

- `[主观推断]` **吉凶总断**：利主不利客。主算得势，宜守成、据主场、后发制人。
- **应期**：主客胜负之局，待局式流转（岁计更替）再定新势；当前以守为主。
- **趋吉**：据主场、守正、巩固已有优势；主算三才足数，基础扎实可进取。
- **避凶**：忌先发制人、忌当客方冒进；客算纯阳虚薄，勿轻敌冒进。
