# 风水堪舆（八宅命卦、玄空飞星）

> 分术法文档。总纲见 `SKILL.md`，多术联动见 `XUANXUE-LINKAGE.md`。

## 起盘

```bash
python scripts/cast.py fengshui 1990 坐北朝南 男    # 风水·八宅/玄空飞星(出生年 坐向 性别)
python scripts/cast.py fengshui 1990 坐北朝南 男 --json  # 风水·结构化双轨(散文+盘面事实层JSON)
```

## 断卦流程

- 起盘：`cast.py fengshui 出生年 坐向 性别`（坐向如「坐北朝南」；脚本已算命卦、东西四命、宅型、宅命相配、游年九星、流年飞星、煞气识别、布局建议）。
- 断：命卦与宅命相配、游年九星吉凶方位、玄空飞星旺山旺向/上山下水/双星到向、流年五黄二黑等煞方与化解。
- 趋避：
  - 趋吉：吉方（生气/天医/延年/伏位、流年吉飞星如八白九紫）→ 宜安床、开大门、设书桌财位、常活动。
  - 避凶：凶方（绝命/五鬼/六煞/祸害、流年五黄二黑三煞）→ 少动、忌安床开门，置化解物（铜器、六帝钱、安忍水等）。
  - 参断：命卦与宅命相配定宅运根基；玄空飞星旺山旺向/上山下水/双星到向定宅局吉凶；流年飞星按月变化，逐月趋避。
- 参考：`txt\[易藏] 葬书.txt`、`撼龙经.txt`、`青囊奥语.txt`、`青囊序.txt`、`天玉经.txt`、`催官篇.txt`、`入地眼全书.txt`、`地理辨正.txt`、`人子须知.txt`、`宅经.txt`、`阳宅指南.txt`、`宅法举隅.txt`；`txt\[道藏] 黄帝宅经.txt`、`金锁玉关.txt`。

## 输出格式（照八字升级，强制）

> 七条可复用经验见 `references/输出格式升级清单.md`。逐字样例见 `docs/风水堪舆-OUTPUT-EXAMPLE.md`。

- **一眼摘要**：`fengshui.summary()` 已并入 `cast.py fengshui` 输出（命卦/东西命），断卦先看卡再看盘。
- **骨架先行（三层分离 + 四段式）**：②排盘结果〔盘面事实〕③断语〔规则推演〕④结论〔现实建议〕。
- **三级标注**：③每条 = `[原文]`（附出处书名（《宅经》），`search` 检索原文复核）+ `[规则推演]` + 「术语解读」+「问事解读」。
- **诚实边界**：④结尾写「判断停在哪」；风水不作医学/投资依据，不引申个人吉凶。
- **结构化双轨**：`cast.py fengshui ... --json` 出 JSON（`schema=fengshui-panfact-v1`）。

- **白话层（双轨，缺一不可）**：每条断语后叠「术语解读」（讲清术语是什么、为什么这么断）＋「问事解读」（落到问的事）；结尾给「今日可行的一小步」（24 小时内可做的具体动作）。
- **免责声明（必附）**：④末尾固定附「> 以上内容属传统术数文化研习，仅供娱乐与文化参考，不构成医疗、法律、投资、婚姻等任何专业决策依据」。
- **应期**：能断则断，断不出明说「应期难定」。
- **趋吉避凶**：④结论必给「趋吉（可乘之机＋行动）＋避凶（风险＋规避）」，缺一不可。

## 排盘自检

命卦（性别+年份）→宅型（坐向）→飞星排盘（运星/山星/向星）。
