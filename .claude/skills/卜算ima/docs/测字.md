# 测字（拆字取义、十法六法）

> 分术法文档。总纲见 `SKILL.md`，多术联动见 `XUANXUE-LINKAGE.md`。

## 起盘

无排盘，纯文本断法。

## 断卦流程

- 无排盘，纯文本断法：用户报字/写字，按《测字秘牒》三层断——①测字十法拆字形（装头/接脚/穿心/包笼/破解/添笔/减笔/对关/摘字/观梅）；②心易六法取义（象形/会意/假借/谐声/指事/转注）；③取格大法定吉凶（先五行生克、次六神动静，相生安静取吉格）。
- **先问所测何事**：字同、事不同、断不同。
- 趋避：
  - 趋吉：拆得吉字吉形（装头见首、会意吉象、谐声吉音、五行相生）→ 顺势而行。
  - 避凶：拆得凶字凶形（破解散、谐声凶音、五行相克、六神动）→ 止、缓、改期；一事一测勿反复。
  - 参断：有物之字观梅/相字随机应变；无物之字审来意 + 字到时上下左右远近之影响，否则拆字；转注定音以应事（「临」字问病读去声断「临丧」）。
- 参考：`txt\[易藏] 测字秘牒.txt`（清·程省，测字十法/心易六法/取格大法/双句格/散格/杂占赋/至理测法）；`txt\[易藏] 梅花易数卷四五相字术.txt`（六神笔法/五行体格式/谢石测字，据《梅花易数》卷四五传世文本整理）。
- 速查：`references/相字术速查.md`（测字十法/心易六法/取格大法），断卦仍按篇名 search 原文佐证。

## 输出格式（照八字升级，强制）

> 七条可复用经验见 `references/输出格式升级清单.md`。逐字样例见 `docs/测字-OUTPUT-EXAMPLE.md`。**无盘纯文本断法，跳过排盘 gate；②盘面事实＝用户所报之字+所测之事。**

- **骨架先行（三层分离 + 四段式）**：②盘面事实（＝输入）③断语〔规则推演〕④结论〔现实建议〕。
- **三级标注**：③每条 = `[原文]`（附出处书名（《测字秘牒》），`search` 检索原文复核）+ `[规则推演]` + 「术语解读」+「问事解读」。
- **诚实边界**：④结尾写「判断停在哪」，具体结果不硬断；先问所测何事再断，一事一测勿反复。
- **白话层（双轨，缺一不可）**：每条断语后叠「术语解读」（讲清术语是什么、为什么这么断）＋「问事解读」（落到问的事）；结尾给「今日可行的一小步」（24 小时内可做的具体动作）。
- **免责声明（必附）**：④末尾固定附「> 以上内容属传统术数文化研习，仅供娱乐与文化参考，不构成医疗、法律、投资、婚姻等任何专业决策依据」。
- **应期**：能断则断，断不出明说「应期难定」。
- **趋吉避凶**：④结论必给「趋吉（可乘之机＋行动）＋避凶（风险＋规避）」，缺一不可。
