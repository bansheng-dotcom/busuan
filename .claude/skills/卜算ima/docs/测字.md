# 测字（拆字取义、十法六法）

> 分术法文档。总纲见 `SKILL.md`，多术联动见 `XUANXUE-LINKAGE.md`。

## 起盘

无排盘，纯文本断法。

## 断卦流程

- 无排盘，纯文本断法：用户报字/写字，按《测字秘牒》三层断——①测字十法拆字形（装头/接脚/穿心/包笼/破解/添笔/减笔/对关/摘字/观梅）；②心易六法取义（象形/会意/假借/谐声/指事/转注）；③取格大法定吉凶（先五行生克、次六神动静，相生安静取吉格）。
- **先问所测何事**：字同、事不同、断不同。
- 趋避：
  - 趋吉：拆得吉字吉形（装头见首、会意吉象、谐声吉音、五行相生）→ 顺势而行。
  - 避凶：拆得凶字凶形（破解散、谐声凶音、五行相克、六神动）→ 止、缓、改期；一事一测勿反复。
  - 参断：有物之字观梅/相字随机应变；无物之字审来意 + 字到时上下左右远近之影响，否则拆字；转注定音以应事（「临」字问病读去声断「临丧」）。

- 速查：`references/相字术速查.md`（测字十法/心易六法/取格大法），断卦仍按篇名 search_txt.py 原文佐证。
