# 八字命理（一生格局、大运流年）

> 分术法文档。总纲见 `SKILL.md`，多术联动见 SKILL.md 第十节。

## 起盘

```bash
python scripts/cast.py bazi 2000 1 1 8 0 0 1 # 八字·年 月 日 时 分 秒 性别(1男0女)
python scripts/cast.py bazi                  # 八字·默认当前时刻
python scripts/cast.py hehun 1990 5 15 1992 8 20  # 八字合婚(男年 月 日 女年 月 日 [男时 女时])
python scripts/cast.py bazi-liunian 2000 1 1 1 2026 10 # 八字·流年深度(出生年 月 日 性别 起始年 年数; 合冲刑害+岁运+喜忌+评分)
python scripts/cast.py liuyue 2000 1 1 1 2026              # 八字·流月深度(出生年 月 日 性别 流年; 同上)
python scripts/cast.py bazi 2000 1 1 8 0 0 1 --json        # 八字·结构化双轨(散文 + 盘面事实层 JSON)
python scripts/cast.py bazi 2000 1 1 1 --range "03:00-05:00"  # 八字·时间不确定逐分钟枚举
```

## 断卦流程

- 起盘：`cast.py bazi 年 月 日 时 分 秒 性别`（脚本已排四柱、十神、五行、纳音、大运〔起运规则透明化：年干阴阳+性别定顺逆、数至最近「节」按 3 天=1 年折算、独立交叉校验〕、日主长生、旬空、神煞 31 个〔按 7 类分组〕、地支刑冲合害〔六合/六冲/三合/半三合/三刑/六害/相破〕；可加 `--lon`/`--dst`/`--zishi same|next`〔晚子时 23:00-24:00 换日口径，默认 00:00 换日并提示流派分歧〕）。
- **断命主线（八字断语固定走这条，勿跳步）**：
  1. **起盘**：脚本已排四柱 + 藏干十神矩阵 + 地势 + 四柱空亡 + 纳音 + 命宫胎元 + 交运时间 + 大运（详见「起盘」节）。
  2. **核心格局当头**：一句话点题（如「建禄格·比劫重重·食伤生财」），再展开论证——不得一上来就「破格有救」四个字。
  3. **十神逐干动态**：逐柱讲透干/支十神如何互动（如「年干乙木偏印生身、月干壬水正官合日主化木→官星贪合入印，贵气化为学问名分」）。
  4. **日柱原文诗**：Grep《三命通会》「六X日诗」引日柱断语（如丁丑「丑中金库禄荣丰」、六丁日用庚辛为财壬为官癸为偏官喜西北金水），落到「一生与财/权打交道」。
  5. **身强/身弱喜忌**：扶抑——身强喜克泄耗（官杀/食伤/财），身弱喜生扶（印/比劫）。
  6. **调候用神**：《穷通宝鉴》按月取（如五月丁火喜壬癸润泽、庚金发水源）。
  7. **用神·喜神·忌神分开写（禁「喜忌并称」）**：用神＝对治全局核心矛盾那一位（通常一个五行）；喜神＝生用神之神/次喜；忌神＝坏用神之神；三者各自单独点名 + 单独理由 + 落到具体干支。
  8. **大运断语**：逐运干支十神 + 引动的合冲刑害，落到「这十年如何」（如己卯运＝食神泄秀生财 + 卯木枭神夺食、亥卯未木局）。
  9. **流年断语**：当年干支十神 + 合冲刑害 + 评分，落到「今年如何」（用 `bazi-liunian` 的真实数据，勿心算流年）。
  10. **病药框架**：`bingyao(旺衰, 格局, 喜, 忌)` → 「病在X、药为Y」（如「病在伤官旺泄身，药为印星生身制伤」），已并入 `mingli_analysis` 输出「【病药框架】」。
  11. **对抗判别器**：`python scripts/libs/judge/adversarial.py 年 月 日 时 分 秒 性别` 独立「旺相休囚死」重推 vs 主路径，找旺衰/格局/喜忌分歧——有分歧标「信号冲突」降级。
- **确定性骨架（盘面事实 + 断语分离）**：盘面事实 = `cast.py` 脚本输出，带「确定性 Det/Sto/Und」标注 + `limitation`（不得由盘面推断吉凶/日期/人物）；断语另起，不与事实混。
- **旺衰量化 + 格局成破 + 合化**（`bazi` 已并入，`libs/pan/bazi_liunian.py`）：①旺衰量化得分（得令40+得地30+得势15+得生15，根气按本气/中气/余气分权，>55强/45-55中和/<45弱——避免布尔法把「中气比劫根」当强根，如戊土在子月仅午中气己土应判弱）；②格局成破救应（`tiaohou.ding_ge` 定格 + `GE_JU_JIU_YING` 表：正官格逢伤官→破格、有印→破格有救）；③干支合化条件判断（五合/六合/三合化神得令/透干/有本气根→成化，否则合而不化）。规则 `R-BZ-08~09`。
- **流年/流月深度**（`bazi-liunian`/`liuyue`，`libs/pan/bazi_liunian.py`）：在「干支+生肖+纳音+五行生克」之上补——①流年/流月干支与原局四柱及大运的合冲刑害叠合（`xingchong.zhi_relation`/`gan_relation`）；②岁运并临（流年干支==大运干支）、天克地冲（干克日干/大运干且支冲日支/大运支）；③犯太岁（值/冲/刑/害/破年支）；④喜忌判定（旺衰四维综合→扶抑喜忌，得令一维冲突时标「信号冲突降级」）；⑤吉凶评分（10~90 透明加权）。规则 `R-BZ-02~07`；断语按「岁运并临/天克地冲/犯太岁」Grep《三命通会》《渊海子平》《子平真诠评注》原文佐证。
- **合婚**（`hehun [男时 女时]`，`libs/pan/hehun.py`）：六维——生肖、日主五行、夫妻宫、纳音（原有）+ 双方四柱全盘比对（年/月/日/时逐柱干支合冲刑害，时柱缺省降级）+ 用神喜忌互补（旺衰→喜忌五行→看对方日主补还是冲）；返回结构化 dict。时柱未知标「三柱比对、时柱降级」。断语按「合婚/纳音/六冲/相刑」Grep 原文佐证。
- **三类有信号断法细化**（MingLi-Bench 实测：健康 52.9%、事业 40%、财运 38.5%，均显著高于随机 25% 与「猜众数答案」29.1%；学业 18.2%、性格 28.6%、外貌 33.3% 为无信号，不作主断）：
  - **健康**：五行应脏腑——木主肝胆、火主心小肠、土主脾胃、金主肺大肠、水主肾膀胱；某五行过旺或过弱，对应脏腑易病；日主旺相抗病力强、休囚易病；官杀克身无制主病灾、印星护身主安康。`[原文]`《三命通会》论疾病：「凡水土木相逢于无气之处主蛊气肠胀吐逆之疾；金水火相逢于无气之地主痢疾…」——只断「哪方面健康需注意」的方向，**慎断具体病名、具体年份**。
  - **事业**：官杀＝职位/管理/体制，印星＝文职/专业/幕后，食伤＝才艺/技术/自由职业，财星＝经商/财务，比劫＝合伙/竞争/体力；官印相生利仕途、食伤生财利经商、身强任杀利掌权。给「适合的方向」，标「倾向」，不作「必然某职业」铁断。
  - **财运**：身强能任财→财运顺、可担财；财多身弱→「富屋贫人」、财来财去守不住；食伤生财→靠技术/才艺变现；比劫夺财→防破财、合伙分利。给「财运模式」方向，慎断「某年赚/破多少」的精确数额。
- 趋避：
  - 趋吉：大运流年行喜用神之地（扶抑/调候/通关得宜）乘势进取；岁运合会成吉局有贵人助。
  - 避凶：忌神当值或岁运刑冲日主/用神 → 防对应年限之失（冲日主防变动破耗、刑冲用神防破财失业、冲夫妻宫防婚变、冲官杀防官非）；犯太岁、岁运并临、三刑四冲重者缓守、大事改期。
  - 参断：按五行十神避重就轻——忌金避金属行业/西行，忌水避水险，忌官杀避争讼竞争，忌比劫防破财合伙，忌财星防贪财失义。
- 参考：`txt\[易藏] 三命通会.txt`、`渊海子平.txt`、`滴天髓阐微.txt`、`穷通宝鉴.txt`、`子平真诠评注.txt`、`神峰通考.txt`、`千里命稿.txt`、`五行大义.txt`、`五行精纪.txt`、`命理探源.txt`、`李虚中命书.txt`、`珞琭子赋注.txt`。

- **白话层（双轨，缺一不可）**：每条断语后叠「术语解读」（讲清术语是什么、为什么这么断）＋「问事解读」（落到问的事）；结尾给「今日可行的一小步」（24 小时内可做的具体动作）。
- **免责声明（必附）**：④末尾固定附「> 以上内容属传统术数文化研习，仅供娱乐与文化参考，不构成医疗、法律、投资、婚姻等任何专业决策依据」。
- **六维白话概括（终身命理必做）**：白话层六句收口——性格/事业/财运/感情/身心/阶段，每句＝结论＋依据半句。
- **应期**：能断则断，断不出明说「应期难定」。
- **趋吉避凶**：④结论必给「趋吉（可乘之机＋行动）＋避凶（风险＋规避）」，缺一不可。

## 输出格式（确定性骨架 + 盘面解读 + 全段白话，强制）

> 输出契约 **10 段**，每段「考据层 + 白话层」双轨：考据给可查证依据（书名 + 行号，`grep -n` 可复核），白话给听得懂的人话（第二人称「你」）。**缺白话＝不合格**。
> 命理类（八字/紫微/七政四余）比一事一占多 3 段——⑤ 用神体系、⑥ 专项断事六维、⑦ 四维交叉验证——这是终身命理的深度所在。
> 核心：盘面事实（Det/Sto）永远为真，不确定只活在流派分歧（Und）。断语 = claim + evidence + confidence（🟢🟡🔴）。

> **四层证据来源（强制，防「批得差不多」）**：每副盘先走四层、层层分开，一条结论只挂一个来源标签，不许把「代码事实」和「我的推演」糊在一句里。
>
> | 层 | 是什么 | 来源 | 标签 |
> |---|---|---|---|
> | ① 代码输出 | 盘面事实（四柱/十神/藏干/大运/神煞/刑冲合害），**只列事实、不判断** | `cast.py` | `[代码]` |
> | ② 原文映照 | 盘面特征 ↔ 典籍原文的**机械映射**（这特征对应哪本书哪句，一行一条，只映射不解读） | Grep 典籍 txt | `[映照]` |
> | ③ 原文推演 | 从原文语义推导「这句落到本盘是什么意思」，引原文→逐句白话→套盘 | 原文 | `[原文推演]` |
> | ④ 逻辑推演 | 十神生克/旺衰喜忌/大运流年的综合判断 | 我的推理 | `[逻辑]` |
>
> 纪律：
> 1. **原文映照是机械步骤**：起盘后先列「本盘可映照的特征 → 各对应哪句原文」，一行一条、只映射不解读。这一步逼每副盘映照出**不同的原文**，是区分两个盘的起点（日主/格局/调候不同，映照的原文必不同）。
> 2. **原文推演引原文→白话→套盘三步**，不许只贴文言再自由发挥。
> 3. **逻辑推演必须标「这是推演、不是经文」**，与代码事实/原文分开呈现。
> 4. 现有 10 段映射：①排盘＝代码输出层；③原文＋解读＝映照层＋原文推演层；其余各段「术语解读/问事解读」＝逻辑推演层（须标 `[逻辑]`）。

> **三级结论标注 + 回溯约束（与四层互补）**：四层管「内容从哪来」，三级管「结论是什么类型」，每条**结论**（非盘面事实）必标其一：
>
> | 标 | 是什么 | 对应四层 |
> |---|---|---|
> | `[原文]` | 直接引自典籍（附书名:行号） | ③ 原文推演 |
> | `[规则推演]` | 依据断法规则（旺衰/格局/调候/病药/十神组合）推出的结论 | ④ 逻辑推演（规则可判定部分） |
> | `[主观推断]` | 落到当前问事的判断与建议 | ④ 逻辑推演（落到问事/建议部分） |
>
> - **回溯约束（硬）**：吉凶定性、格局判断**必须能回溯到 `[原文]` 或 `[规则推演]`**，不得凭空 `[主观推断]`；`[主观推断]` 只能用于「落到问事」与「建议」。
> - **白话文解读（每条结论必附人话）**：`[原文]` 文言、`[规则推演]`、`[主观推断]` 每一条之后，紧跟一句「白话文解读」——第二人称「你」、短句，把术语/断法翻译成人话（「它是什么 → 对你意味着什么 → 该怎么做」）；只翻译这条结论、不得新增吉凶定性；禁用「注定/必然/绝对/大凶」等宿命词。

1. **排盘**：`cast.py bazi` 全量盘面**表格化展示**（四柱表 + 神煞 7 类表 + 刑冲合害表 + 旺衰量化表 + 格局/调候/喜忌/评分/病药表）。生时/性别 Sto，四柱/十神/大运 Det，吉凶/喜忌 Und。
2. **盘面解读**：日主性质（十干体性）+ 月令 + 旺衰 + 格局 + 调候，术语解读 ↔ 问事解读逐项对照。
3. **原文 + 原文解读**：每条原文 = 书名 + 全文 + 出处行号，紧跟「逐句白话翻译 + 套到本盘」，原文与解读**配对呈现**。
4. **命主概要**：一句话定性（日主/格局/旺衰/用神/喜忌/病药/层次）+ 七级评级 + 六维白话概括，精讲。
5. **用神体系**：用神五法（表格）+ 五神（表格）+ 病药评级 + 六大十神组合 + 格局三关，精讲。
6. **专项断事**：六维展开（性格/事业/财运/婚姻/健康/子女），每维 = 结论 + 原文引用 + 术语解读 + 问事解读。
7. **确定性标注**：四维交叉验证（表格）+ 矛盾调和 + ✅/⚠️/❌。
8. **时间节奏**：大运 8 步十二长生（表格）+ 人生四阶段 + 关键流年。
9. **行动建议**：趋吉（方位/颜色/行业/数字/吉祥物/食物七件套表格）+ 避凶 + 白话 + 今日可行的一小步。
10. **风险边界**：limitation + 判断停在哪 + 免责。

- **独立评估者**：`libs/judge/adversarial.py` 独立重推旺衰 vs 主路径，分歧标「信号冲突」降级。
- **结构化双轨**：`cast.py bazi ... --json` 出盘面事实层 JSON（`schema=bazi-panfact-v1`），与散文并存。

**③ 原文 + 原文解读（每条原文紧跟白话翻译 + 套盘）**

**《滴天髓阐微》**
> 「戊土固重，既中且正。静翕动辟，万物司命。水润物生，火燥物病。若在艮坤，怕冲宜静。」

- 逐句解读：「戊土固重，既中且正」→ 戊土是厚重端正的阳土，中正可靠；「水润物生，火燥物病」→ 水润它则万物生、火太燥则成焦土；「若在艮坤，怕冲宜静」→ 坐寅（艮）坐申（坤）的戊土怕冲、宜静守。
- **套盘**：你日主戊土正合「固重中正」之性——为人厚重、中正、靠得住。但生于酉月（秋金当令），正是「秋则多泄、体薄怕冲」之时：土被金泄、根气薄，故判**身弱（30 分）**。这带来两个后果：一是「需火暖水润」——火＝印星生身（你的底气来源）、水少量＝润局；二是「怕冲宜静」——你命带寅巳申三刑（不全）、酉子相破，地支本就不静，更要守静、忌再逢冲。**落到生活：稳重是你的底色，但别硬扛、别在冲刑的年份轻举妄动。**

**《子平真诠评注》**
> 「有伤官佩印者，印能制伤，所以为贵，反要伤官旺，身稍弱，始为秀气。」

- 逐句解读：「伤官佩印，印能制伤，所以为贵」→ 伤官配印，用印收住伤官，反成贵格；「反要伤官旺，身稍弱，始为秀气」→ 条件是伤官要旺、身要稍弱，才是「秀气」。
- **套盘**：你月令酉金伤官当令、年干辛金再透，**伤官极旺**（泄身之秀气足）；日主 30 分**身稍弱**——正合「伤官旺、身稍弱」两个条件，是标准「伤官佩印」秀气格局。**这意味着：你的才华是「成格局」的，不是散漫的聪明；只要配上「印」（学历、专业、贵人），才华就能变现为贵气。反过来，若丢了「印」（不读书、不靠专业），伤官就成了「孤傲泄身」，聪明反被聪明误。**

**《三命通会》**
> 「【六戊日诗曰】子坐财乡亦是祥（子中癸旺，自坐财乡）……柱中有用或无用，月令如何要忖量。」

   - 原文：《渊海子平》「伤官之人，多负才傲物，常以他人不如己。」
   - 术语解读：伤官旺主才华外露、傲气、不服管；身弱主底气不足、易内耗。
   - 问事解读：你聪明、要强、有主意，但心里容易没底、想得多；外表稳重（土），骨子里有股不安分的劲儿（伤官）。

2. **事业**（官杀＝职位、印＝文职专业、食伤＝才艺）

   - 原文：《子平真诠评注》「伤官佩印，印能制伤，所以为贵」。
   - 术语解读：伤官佩印＝用学问文凭收住才华；杀印相生＝压力被印化成权柄。
   - 问事解读：教师、技术专家、研究、幕后策划都行；别去硬扛管理和纯拼体力的岗。

3. **财运**（财星喜忌＋财库＋食伤生财链）
   - 结论：正财为忌、身弱难任财、无财库 → 过手财、守不住大财，理财要「分篮求稳」。
   - 原文：《渊海子平》「财多身弱，正为富屋贫人。」
   - 术语解读：财为忌＝钱越多越耗你；身弱难任财＝担不住大财；无财库（水财库在辰、命无辰）＝难蓄财。
   - 问事解读：钱「够花但难攒」，适合稳定收入，忌投机、忌大额杠杆；钱到手容易散。

4. **婚姻**（配偶星＋夫妻宫＋星宫同参）

   - 原文：《渊海子平》「财多身弱，妻反胜夫。」（身弱财旺，配偶偏强势）
   - 术语解读：男命以正财为妻，子水正财坐日支（夫妻宫）＝妻星坐守；桃花在酉＝异性缘旺；酉子相破＝感情有磕碰；妻星在日支＝晚婚倾向。
   - 问事解读：你异性缘不差，但配偶偏「现实、强势、流动」，感情要用心经营、防小磕碰；不必急着早婚。

5. **健康**（五行应脏腑＋十神＋宫位）

   - 原文：《三命通会》「戊巳见甲乙寅夘多者，内主脾胃不和、翻胃隔食、气噎蛊胀、泄防黄肿。」
   - 术语解读：土弱→脾胃弱；木旺→肝胆旺、压力；水为忌→肾膀胱；七杀克身无制→神经紧张。
   - 问事解读：重点养脾胃（规律饮食）、疏肝胆（别憋气）、放松神经（别过度焦虑）；忌熬夜、忌长期高压。

6. **子女**（食伤＝子女星＋时柱子女宫）
   - 结论：子女聪明独立、可能有点叛逆，宜「用理解收住」——食伤（金）为子女星、伤官旺，时柱甲寅七杀坐子女宫。
   - 原文：《渊海子平》「时带伤官，子息无传。」（时柱伤官重者子女缘需经营，非绝对）
   - 术语解读：子女星＝食伤（金），伤官旺→子女聪明、有主见；时柱甲寅（七杀坐子女宫）→子女宫为杀，需印化。
   - 问事解读：子女聪明、独立、可能有点叛逆（伤官旺）；你身弱，跟子女的关系要「用理解收住」（印化），别硬管。
