# 天文占（星象灾异、天人感应）

> 分术法文档。总纲见 `SKILL.md`，多术联动见 `XUANXUE-LINKAGE.md`。

## 起盘

无排盘，纯文本断法。

## 断卦流程

- 无排盘，纯文本断法：就星象、灾异、天人感应之问，检索占辞原文解读；侧重史料与占辞，不作现代天文预报。
- **断卦必经步骤 ①检索相似案例**：先用 `search` 检索知识库天文占案例（120 则），按「天象」佐证原文（如彗孛 search「彗/孛」、日食 search「日食」、天鸣 search「天鸣」），看同类天象在历史上应于何事，作为断当前占的参照——**不得跳过直接空推**。
- 趋避：
  - 趋吉：星象吉应（五星顺行、星应得位）→ 顺势而为、顺应大势。
  - 避凶：凶象（五星失次、彗孛犯斗、日食月食）→ 修省、防变，属大势警示，不轻断个人吉凶。
  - 参断：以史料占辞为本（开元占经、乙巳占），星应分国分域分事；重天人感应，不作现代天文预报，不引申为个人命理。
- 参考：`txt\[易藏] 开元占经.txt`、`唐开元占经.txt`、`乙巳占.txt`、`灵台秘苑.txt`、`马王堆汉墓帛书五星占.txt`；`txt\[道藏] 灵台经.txt`、`通占大象历星经.txt`、`秤星灵台秘要经.txt`、`素问入式运气论奥.txt`、`太上洞真五星秘授经.txt`、`太上洞神五星诸宿日月混常经.txt`、`太上飞步五星经.txt`。
- 案例库：天文占 120 则历史天文占验（《开元占经》，`extract_tianwen_cases.py` 提取），断卦可参照。

## 输出格式（照八字升级，强制）

> 七条可复用经验见 `references/输出格式升级清单.md`。逐字样例见 `docs/天文占-OUTPUT-EXAMPLE.md`。**无盘纯文本断法，跳过排盘 gate；②盘面事实＝用户所问天象/灾异。**

- **骨架先行（三层分离 + 四段式）**：②盘面事实（＝天象）③断语〔规则推演〕④结论〔现实建议〕。
- **三级标注**：③每条 = `[原文]`（附出处书名（《开元占经》《乙巳占》），`search` 检索原文复核）+ `[规则推演]` + 「术语解读」+「问事解读」。
- **诚实边界**：④结尾写「判断停在哪」，不作现代天文预报、不引申个人命理。

- **白话层（双轨，缺一不可）**：每条断语后叠「术语解读」（讲清术语是什么、为什么这么断）＋「问事解读」（落到问的事）；结尾给「今日可行的一小步」（24 小时内可做的具体动作）。
- **免责声明（必附）**：④末尾固定附「> 以上内容属传统术数文化研习，仅供娱乐与文化参考，不构成医疗、法律、投资、婚姻等任何专业决策依据」。
- **应期**：能断则断，断不出明说「应期难定」。
- **趋吉避凶**：④结论必给「趋吉（可乘之机＋行动）＋避凶（风险＋规避）」，缺一不可。

## 排盘自检

纯文本，断语必注明出处书名。
