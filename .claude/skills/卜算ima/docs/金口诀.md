# 金口诀（四位速断、来意射覆）

> 分术法文档。总纲见 `SKILL.md`，多术联动见 `XUANXUE-LINKAGE.md`。

## 起盘

```bash
python scripts/cast.py jinkoujue [地分/方位]  # 大六壬·金口诀(四位:人元/贵神/将神/地分)
python scripts/cast.py jinkoujue --json      # 金口诀·结构化双轨(散文+盘面事实层JSON)
```

## 断卦流程

- 起盘：`cast.py jinkoujue [地分/方位]`（地分缺省取时支，可传地支或八方位：北子/南午/东卯/西酉/东北丑/东南辰/西南未/西北戌；四位自下而上：地分→将神→贵神→人元）。
- 断：**四位五行生克**（人元干/贵神/将神/地分各属五行）→ **五动爻**（干克方妻动、神克干官动、神克将贼动、将克神财动、方克干鬼动）→ **三动**（方生干父母动、干生方子孙动、干方同兄弟动）→ 干神将方 16 条生克断 → **用爻**（阴阳次第五用）→ 旺相休囚（四季五行）→ 五行聚管（组合断）。`rules.jinkoujue_wudong(人元五行, 贵神五行, 将神五行, 地分五行)`（R-JK-01）给五动爻综合倾向。
- **射覆/测物/来意（射覆门）**：以**用爻**为所测之物——用爻地支取「射覆歌其一」物类（`rules.jinkoujue_shefu_zhilei(支)` R-JK-02）、用爻所临贵神取「射覆歌其二」（`rules.jinkoujue_shefu_guishen(贵神)` R-JK-03）、人元干取十干颜色+支干/五行数目+射物所在（`rules.jinkoujue_shefu_yanse_shumu(人元干,用爻支,用爻五行)` R-JK-04）；**来意**以人元与将神生克断（占来意歌「欲占来意将中看」）。速查 `references/金口诀射覆门速查.md`，断卦 search「射覆歌/十干颜色/支干数目/五行数目/射物所在/占来意歌」佐证原文；输出**特征画像不押物名**（`references/射覆特征画像.md`）。
- **失物/寻人（四孟遗失）**：课值四孟（寅申巳亥）为遗失、四仲（子午卯酉）为交易、四季（辰戌丑未）为婚姻出身——`shiwu_xunren.jinkoujue_shiwu(地支)`（R-SW-05）；寻人「上克下寻人在家」`shiwu_xunren.jinkoujue_xunren(生克)`；天马/驿马入课走失难寻、天盗/地煞走失阻隔。速查 `references/失物寻人速查.md`，断卦 search「四孟值课为遗失/占人人在家」原文佐证。
- 趋避：
  - 趋吉：四位相生、五动得吉动（官动利求官、财动利求财）、吉神（天乙/青龙/六合/太常/太阴/天后）临身旺相 → 宜进宜主动。
  - 避凶：四位相克（克人元官事、克贵神伤尊长、克将神伤妻财、克地分伤小口）、凶动（贼动防内贼诈、鬼动防灾怪口舌）、凶神（螣蛇/朱雀/勾陈/天空/白虎/玄武）临身 → 宜缓守、防口舌盗骗血伤。
  - 参断：以贵神为主、将神为相（七分灾福在此二神）；人元地分定首尾；用爻定事体（阴事/阳事/方内/方外）。
- 参考：`txt\[易藏] 六壬神课金口诀古本.txt`（入式歌解、十二将神/贵神所属、贵神起例、五子元遁、五动爻诵、三动、五合、三合全身、五行休旺、五行聚管、应期合德、十二将神/贵神所主歌、六十甲子钤、六十四课钤、云霄赋、三才赋）。
- 速查：金口诀四位断法见上；断卦按「五动爻/三动/贵神将神名」search 原文佐证。

## 输出格式（照八字升级，强制）

> 七条可复用经验见 `references/输出格式升级清单.md`。逐字样例见 `docs/金口诀-OUTPUT-EXAMPLE.md`（四位速断）。

- **一眼摘要**：`jinkoujue.summary()` 已并入 `cast.py jinkoujue` 输出（日时干支/四位/用爻），断卦先看卡再看盘。
- **骨架先行（三层分离 + 四段式）**：②排盘结果〔盘面事实〕③断语〔规则推演〕④结论〔现实建议〕。
- **三级标注**：③每条 = `[原文]`（附出处书名（《六壬神课金口诀古本》），`search` 检索原文复核）+ `[规则推演]` + 「术语解读」+「问事解读」。
- **诚实边界**：④结尾写「判断停在哪」，具体何事何人不硬断。
- **结构化双轨**：`cast.py jinkoujue --json` 出 JSON（`schema=jinkoujue-panfact-v1`）。

- **白话层（双轨，缺一不可）**：每条断语后叠「术语解读」（讲清术语是什么、为什么这么断）＋「问事解读」（落到问的事）；结尾给「今日可行的一小步」（24 小时内可做的具体动作）。
- **免责声明（必附）**：④末尾固定附「> 以上内容属传统术数文化研习，仅供娱乐与文化参考，不构成医疗、法律、投资、婚姻等任何专业决策依据」。
- **应期**：能断则断，断不出明说「应期难定」。
- **趋吉避凶**：④结论必给「趋吉（可乘之机＋行动）＋避凶（风险＋规避）」，缺一不可。

## 排盘自检

四位（人元/贵神/将神/地分）齐全；五动爻三动、用爻、旺相休囚对应。

## 交叉验证

四位生克 / 五动爻 / 用爻 / 旺相。
