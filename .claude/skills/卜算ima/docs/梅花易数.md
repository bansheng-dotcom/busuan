# 梅花易数（体用生克、灵活）

> 分术法文档。总纲见 `SKILL.md`，多术联动见 `XUANXUE-LINKAGE.md`。

## 起盘

```bash
python scripts/cast.py meihua-time           # 梅花易数·时间起卦
python scripts/cast.py meihua-num 12 34      # 梅花易数·数字起卦
python scripts/cast.py meihua-guanwu 12      # 梅花易数·物数占(后天触机)
python scripts/cast.py meihua-shengyin 8     # 梅花易数·声音占(后天触机)

python scripts/cast.py meihua-duanfa 坎 南    # 梅花易数·端法后天起卦(物+方位)
```

## 断卦流程

- 脚本起盘得本卦/互卦/变卦/动爻/体用。
- **起卦两条路**：先天（时间/数字）`meihua-time` / `meihua-num`；后天（触机）`meihua-guanwu <物数>`（物数占）、`meihua-shengyin <声数>`（声音占）、`meihua-zishu <字数>`（字占）、`meihua-duanfa <物卦> <方位卦>`（端法，见物+方位）。触机起卦后**必合外应断**（见下「三要十应」）。
- **断卦必经步骤 ①检索相似案例**：先跑 `python scripts/libs/case_search.py "占事" 梅花` 语义检索相似案例，再 search_txt.py `D:\卜算\国学czhengli\txt\案例库\梅花\`（占例 14 则）佐证原文，看康节先生如何起卦、体用生克如何落到具体占事，作为断当前卦的参照——**不得跳过直接空推**。
- 断：体用生克（脚本已给，`rules.meihua(体五行,用五行)` R-MH-01）、卦气旺衰、互卦看中段机制、变卦看落点。
- **卦气旺衰（衰旺论）**：体卦宜旺、生体之卦宜旺、克体之卦宜衰——旺：震巽木旺于春、离火旺于夏、乾兑金旺于秋、坎水旺于冬、坤艮土旺于辰戌丑未月；衰则反之。`rules.meihua_wangshuai(体五行, 月支)`（R-MH-04）判旺/相/衰/休；体旺逢生则吉、体衰逢克则凶甚。
- **占断十八类**：按所问之事对应一类取「体=××、用=××」+ 生克快断（天时不分体用全观诸卦；失物以变卦定方位；疾病体宜旺逢生）。`rules.meihua_18lei(类名, 体五行, 用五行)`（R-MH-03），速查 `references/梅花十八类占.md`，断卦按类名 search_txt.py 原文佐证。
- **三要十应（外应触机，后天起卦必查）**：后天起卦后除体用生克外**必须合外应断**——「体用为内、诸应卦为外」，内外相合才准。三要=耳（听声知吉凶）/目（观形知善恶）/心（察理知祸福）；十应=天时/地理/人事/时令/方卦/动物/静物/言语/声音/五色/写字十一类外应，以体卦为主、外应为用；衰旺论/内外论/动静/向背/静占同参。速查见 `references/三要十应速查.md`，断卦按篇名 search_txt.py 原文佐证（双重保证）。
- **以变卦断物（变卦式八则）**：测物/断物除体用外，可取「以变卦断物」八例——泽火革变咸断伤股、地雷复变临断软物、天泽履变乾断铁器、泽火革变噬嗑断土物、雷泽归妹变睽断铁、泽天夬变兑断破磁盘、天水讼变兑断求财空望：变出何卦、变爻属何五行，即以该五行断物类。出处《梅花易数·变卦式八则》，断卦 search_txt.py 原文佐证。
- 测物/寻物可再取 `rules.meihua_probability(体五行, 用五行)` 量化成概率档（极高/较高/中等/较低/很低，R-MH-02）；射覆/测物一律出「特征画像」不押物名（见 `references/射覆特征画像.md`）。
- 趋避：
  - 趋吉：用生体相生，事有助力宜进；体克用可为但费劲，宜坚持；体用比和同心可成。
  - 避凶：用克体是对方/环境压制，忌硬碰，换时机/方位/方式再动；体生用是泄气，付出多回报少，勿投入过大。
  - 参断：体卦当令得月建生扶则吉象可进；体卦休囚受克则凶象加重宜守；互卦生变卦、变卦生体，后程可转好。

## 排盘自检

本/互/变三卦 + 动爻 + 体用齐全；体用生克、卦气随月令。

## 交叉验证

体用生克 / 卦气旺衰 / 互变卦 / 动爻。

## 断卦规则

- 用克体→凶（宜避/缓）；体克用→小吉（费力可成）；体用比和→吉；用生体→吉；体生用→泄气小凶。
- 按问事对应一类（求财体克用有财、官讼体宜旺用宜衰、失物变卦定方位…）→ `rules.meihua_18lei`（R-MH-03）。
- 体卦当令则旺、得月令生则相、受月令克则衰；体旺逢生吉、体衰逢克凶甚 → `rules.meihua_wangshuai`（R-MH-04）。
