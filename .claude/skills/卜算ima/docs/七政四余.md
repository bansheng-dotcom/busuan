## 断卦流程

- 起盘：`cast.py qizheng`（可 `--time`；脚本已排七政日月金木水火土、四余罗计孛气的黄经落宫、十二宫、庙旺落陷、相位、断语）。流年大限小限：`cast.py qizheng-liunian 出生年 命宫地支 流年年份`。
- 断：命宫命度、星曜落宫庙旺落陷、星曜相位（合/拱/六合为吉，刑/冲为凶）、大限小限流年。
- 趋避：
  - 趋吉：吉星（日月木金）庙旺拱照、吉相位（拱/六合）→ 宜进、宜乘势。
  - 避凶：凶星刑冲、罗睺计都月孛紫气犯宫 → 防对应宫位之失（财帛/官禄/夫妻等），静待凶相位流转、不硬来。
  - 参断：命宫命度定根基，星曜落宫庙旺落陷定强弱；相位组合（吉相位叠加/凶相位叠加）定顺逆；大限小限流年定应期。
- 参考：`txt\[易藏] 张果星宗.txt`、`星学大成.txt`、`星命总括.txt`、`星命溯源.txt`、`演禽通纂.txt`、`禽星易见.txt`、`兰台妙选.txt`、`神机妙算一掌经.txt`；`txt\[术数] 七政推步.txt`、`天步真原.txt`。

## 输出格式（照八字升级，强制）

> 七条可复用经验见 `references/输出格式升级清单.md`。逐字样例见 `docs/七政四余-OUTPUT-EXAMPLE.md`。

- **一眼摘要**：`qizheng.summary()` 已并入 `cast.py qizheng` 输出（命宫/七政庙旺落宫/四余/相位吉凶概览），断卦先看卡再看盘。
- **骨架先行（三层分离 + 四段式）**：②排盘结果〔盘面事实〕③断语〔规则推演〕④结论〔现实建议〕；层标签与 `review.py` 匹配字逐字一致。
- **三级标注**：③每条断语 = `[原文]`（附出处书名（《星学大成》《张果星宗》），`search` 检索原文复核）+ `[规则推演]` + 「术语解读」+「问事解读」。
- **独立评估者**：主路径为 ephem+Meeus 精算（已从线性近似升级，见 libs/qizheng.py 头注）；暂无第二天文引擎做对抗复核，标记**待做**——断卦结论按相位/庙旺/宫位 search 原文佐证，冲突降级。
- **诚实边界**：④结尾写「判断停在哪」——精确年份+具体生平不硬猜（MingLi-Bench 无信号组），几本书相反时并列呈现不按条数投票。
- **结构化双轨**：`cast.py qizheng ... --json` 出盘面事实层 JSON（`schema=qizheng-panfact-v1`），与散文并存。

- **白话层（双轨，缺一不可）**：每条断语后叠「术语解读」（讲清术语是什么、为什么这么断）＋「问事解读」（落到问的事）；结尾给「今日可行的一小步」（24 小时内可做的具体动作）。
- **免责声明（必附）**：④末尾固定附「> 以上内容属传统术数文化研习，仅供娱乐与文化参考，不构成医疗、法律、投资、婚姻等任何专业决策依据」。
- **六维白话概括（终身命理必做）**：白话层六句收口——性格/事业/财运/感情/身心/阶段，每句＝结论＋依据半句。
- **应期**：能断则断，断不出明说「应期难定」。
- **趋吉避凶**：④结论必给「趋吉（可乘之机＋行动）＋避凶（风险＋规避）」，缺一不可。
