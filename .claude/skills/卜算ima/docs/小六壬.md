## 断卦流程

- 脚本起盘得落宫 → 取六宫口诀断语。
- 口诀原文：`txt\[其他] 小六壬.txt`（大安/留连/速喜/赤口/小吉/空亡六宫断）。
- **失物/寻物/寻宠**：落宫自带失物方位——`shiwu_xunren.xiaoliuren_shiwu(落宫)`（R-SW-01）给方位/远近/能否寻回（大安东、留连南、速喜申未午、赤口西、小吉坤方、空亡寻不见）。速查 `references/失物寻人速查.md`，断卦 search 六宫口诀原文佐证；输出方位/远近/能否分维、不铁口直断某处某日。
- 趋避：
  - 趋吉：落大安（安稳顺遂）、速喜（快而喜、求财婚恋宜速）、小吉（小有喜、出行求财）→ 可速行、宜主动。
  - 避凶：落留连（纠缠拖延、防口舌是非）、赤口（口舌破财、防争斗）、空亡（落空、劳而无功）→ 宜缓守静、忌冲动，防口舌破财落空。
  - 参断：大安属木主不动宜守，留连属水主拖延宜静待，速喜属火主速宜乘热打铁，赤口属金主刑防争执，小吉属木主和宜周旋，空亡属土主空勿强求；落宫再叠时辰断轻重。

## 输出格式（照八字升级，强制）

> 七条可复用经验见 `references/输出格式升级清单.md`。逐字样例见 `docs/小六壬-OUTPUT-EXAMPLE.md`（一事一占）。

- **一眼摘要**：`xiaoliuren.summary()` 已并入 `cast.py xiaoliuren` 输出（落宫/吉凶），断卦先看卡再取口诀。
- **骨架先行（三层分离 + 四段式）**：②排盘结果〔盘面事实〕③断语〔规则推演〕④结论〔现实建议〕。
- **三级标注**：③每条 = `[原文]`（附出处书名（《小六壬》），`search` 检索原文复核）+ `[规则推演]` + 「术语解读」+「问事解读」。
- **诚实边界**：④结尾写「判断停在哪」，具体何时转好不硬断；一事一占勿反复。
- **结构化双轨**：`cast.py xiaoliuren --json` 出 JSON（`schema=xiaoliuren-panfact-v1`）。

- **白话层（双轨，缺一不可）**：每条断语后叠「术语解读」（讲清术语是什么、为什么这么断）＋「问事解读」（落到问的事）；结尾给「今日可行的一小步」（24 小时内可做的具体动作）。
- **免责声明（必附）**：④末尾固定附「> 以上内容属传统术数文化研习，仅供娱乐与文化参考，不构成医疗、法律、投资、婚姻等任何专业决策依据」。
- **应期**：能断则断，断不出明说「应期难定」。
- **趋吉避凶**：④结论必给「趋吉（可乘之机＋行动）＋避凶（风险＋规避）」，缺一不可。

## 排盘自检

月→日→时顺数落宫忌跳数；六宫口诀与落宫一致。

## 断卦规则

落大安/速喜/小吉→吉；落留连/赤口/空亡→凶。→ `rules.xiaoliuren(落宫)`。
