## ③ 断语〔规则推演〕

> 每条：[原文]（附段落 ID，`classical_search.py --passage-id` 可复核）→ [规则推演] → 术语解读 + 问事解读。

### 身命与太阴

- `[原文]`《星学大成》：「天之禀赋实根原身命二宫，人之操持亦凭赖阴阳二宿……日生重太阳，夜生重太阴。」（星学大成:1053）
- `[规则推演]` 太阴（身主）落官禄宫、得「旺」，又夜生（寅时近卯），太阴为重——主情感丰富、得贵人助、晚运/名声有根基。
- **术语解读**：七政里太阴就是月亮，古人夜生以月亮为重；「旺」是星曜在该宫最得力的状态。太阴旺落官禄，等于"名声事业有根基、且能得人缘助力"。
- **问事解读**：你这盘有"靠人缘、靠名声往上走"的底子，情感细腻、能得贵人，但也要防太阴带来的情绪起伏。

### 木星庙照财帛

- `[原文]`《星学大成》：「凡福财星宜照福德为上身命次之……喜在庙旺兼行顺段为福。」（星学大成:139）
- `[规则推演]` 木星（福财之星）落财帛宫、得「庙」（木星在未为庙），正应「福财星喜在庙旺」——主财运亨通、宜投资、财禄有根基。
- **术语解读**：木星是吉星里的"财星/福星"，「庙」是它最舒服的宫位。木星庙落财帛，就是"钱上有福气、正财能积累"。
- **问事解读**：你的财运偏"正财、慢慢积累"型，适合稳健投资、靠专业或实业生财，不宜投机快钱。

### 相位：吉凶相当

- `[原文]`《张果星宗》：「居强宫者旺。」（张果星宗:138，论强宫）
- `[规则推演]` 太阳-太阴六合（吉，和谐有利）；太阴-金星相刑（凶，冲突需谨慎）——吉相 1、凶相 1，综合「吉凶相当，平稳发展」。
- **术语解读**：六合是两星 60° 的和谐夹角（顺），刑是 90° 的冲突夹角（卡）；这盘一顺一卡，所以是"平稳但有坎"。
- **问事解读**：整体平稳，但感情/审美/钱财这块（太阴金星的刑）容易有纠结和反复，宜顺不宜硬顶。
