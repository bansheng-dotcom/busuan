# 六爻纳甲（用神细分、六亲世应）

> 分术法文档。总纲见 `SKILL.md`，多术联动见 `XUANXUE-LINKAGE.md`。

## 起盘

```bash
python scripts/cast.py liuyao [问事]          # 六爻·铜钱摇卦(含纳甲装卦+用神分析+断卦分析)
python scripts/cast.py liuyao 求财 --json      # 六爻·结构化双轨(散文+盘面事实层JSON)
```

`[问事]` 可选（求财/事业/官/官司/考学/文书/子女/兄弟/合作/婚姻/出行 等，缺省「通用」看世爻）。自动摇卦后输出：爻画+装卦表 + 【用神分析】（问事→用神→落爻→旺衰）+ 【断卦分析】（世应关系 + 吉凶评分 0-100）+ 【趋吉避凶】；用神不现自动取伏神。

## 断卦流程

**主断走 `liuyao` MCP（王虎应体系）**：六爻主断优先调用 liuyao MCP（zhishengyk/liuyao）——
- 排盘 `build_chart`：爻值按初爻→上爻 0老阴/1少阳/2少阴/3老阳，给起卦时间或历史月支+日干支；直接展示返回的 `display.markdown`（六神/伏神/本变卦/动爻/世应/旬空/月建日辰），**不自己重排纳甲**。
- 检索 `search_knowledge(query, kind=rule/case, method=all/lifa/xiangfa, topic/subtopic, limit)` 理法/象法/案例 RAG；`get_topics` 看事项分类、`get_outline` 浏览书籍、`get_source(evidence_id)` 回查原文、`inspect_chart` 条件核查。
- 断卦内核：按 `references/六爻断卦内核.md`（八步流程 + 十条禁令 + 取用/爻状态/应期细则）执行，不许跳步、不许先结论后证据。
- **MCP 未连接时**：说明需启用六爻服务，不声称已检索王虎应资料，回退下方内置流程。

**内置辅助（交叉验证 + 离线回退）**：
- `cast.py liuyao` 自动摇卦 + `libs/najia.py` 装卦（纳甲/世应/六亲/六神/旬空/伏神/月破/日冲/化进退）复核 MCP 排盘。
- `search` 检索《增删卜易》《卜筮正宗》《易冒》《易隐》《火珠林》《黄金策》《断易天机》《卜筮全书》交叉佐证；`search` 检索 381 则古籍案例参照。
- 象法 `python scripts/libs/liuyao_xiangfa.py 六神/六亲 <名>` 补 liuyao 偏理法的短板（测物/测动态）。
- **失物/寻人/寻宠**：失物看财爻、官鬼为贼、子孙为捕捉（宠物/六畜看子孙）；`shiwu_xunren.liuyao_shiwu_duan(财爻状态,官鬼状态,子孙状态,卦宫)`（R-SW-04）断能否寻回/远近/是否被盗/应期，`liuyao_shiwu_fangwei(卦宫)` 定方位、`liuyao_shiwu_cangchu(财爻五行)` 定入墓藏处。速查 `references/失物寻人速查.md`，断卦 search `火珠林`「失物看财、官鬼为贼、子孙为捕」原文佐证。
- 理法知识包 `cast.py liuyao-knowledge <用神/旺衰/应期/六神/世应/生克>` 或 `python scripts/libs/liuyao_knowledge.py <词>`：27 条结构化断语 + 原文出处（王虎应体系），**MCP 未连接时离线 RAG 回退**，断卦按出处 search 原文佐证（双重保证）。
- 趋避：用神旺相得生扶宜进、忌神动克用神防对应六亲之失（官鬼防官非、妻财防破财、父母防文书长辈、兄弟防破耗、子孙防伤病）；用神旬空待出空、月破当月缓；腾蛇虚惊/玄武盗骗/白虎血伤各按所临防；动爻生用吉克用凶、冲待合合待冲为应期。
- 速查：`references/liuyao_yongshen.md`（用神/六亲/六神）、`references/六爻断卦内核.md`（八步/取用/爻状态/应期/禁令）。

## 输出格式（照八字升级，强制）

> 七条可复用经验见 `references/输出格式升级清单.md`。逐字样例见 `docs/六爻-OUTPUT-EXAMPLE.md`（一事一占，无六维概括，趋避/应期/一小步/免责照给）。

- **一眼摘要**：`liuyao.summary()` 已并入 `cast.py liuyao` 输出（本卦→变卦/问事用神/世应/评分吉凶），断卦先看卡再看盘。
- **骨架先行（三层分离 + 四段式）**：②排盘结果〔盘面事实〕③断语〔规则推演〕④结论〔现实建议〕；层标签与 `review.py` 匹配字逐字一致。
- **三级标注**：③每条断语 = `[原文]`（附出处书名（《增删卜易》《卜筮正宗》），`search` 检索原文复核）+ `[规则推演]` + 「术语解读」+「问事解读」。
- **独立评估者**：`libs/najia.py` 装卦 + `search` 案例库 + search 典籍，交叉复核 liuyao MCP 排盘（王虎应体系）；主判与独立判不一致标「信号冲突」并降级。
- **诚实边界**：④结尾写「判断停在哪」——具体金额/具体日期/对方是谁不硬断；一事一占，同一问题不反复占。
- **结构化双轨**：`cast.py liuyao ... --json` 出盘面事实层 JSON（`schema=liuyao-panfact-v1`），与散文并存。

- **白话层（双轨，缺一不可）**：每条断语后叠「术语解读」（讲清术语是什么、为什么这么断）＋「问事解读」（落到问的事）；结尾给「今日可行的一小步」（24 小时内可做的具体动作）。
- **免责声明（必附）**：④末尾固定附「> 以上内容属传统术数文化研习，仅供娱乐与文化参考，不构成医疗、法律、投资、婚姻等任何专业决策依据」。
- **应期**：能断则断，断不出明说「应期难定」。
- **趋吉避凶**：④结论必给「趋吉（可乘之机＋行动）＋避凶（风险＋规避）」，缺一不可。

## 排盘自检

纳甲干支→世应→六亲→六神四步齐全；用神取对（财=妻财等）；月建日辰旺衰、动变生克。

## 交叉验证

用神旺衰 / 原神忌神 / 动变生克 / 月建日辰。

## 断卦规则

用神旺相且原神生→吉；忌神动克用神→凶；用神旬空→事虚待时；用神月破→当月不利。
