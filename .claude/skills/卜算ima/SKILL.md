# 卜算（术数占卜）技能

确定性起盘 + 典籍断卦。**起盘用脚本算（不许心算），断卦用 txt 原文（不许杜撰）**。

> 本文档是**总纲**：路由 + 选术流程 + 共享输出/质检/证据规范。各术法的起盘命令、断卦流程、趋避、参考书、自检、规则详见 [`docs/`](docs/) 下对应分术法文档；多术联动见 [`XUANXUE-LINKAGE.md`](XUANXUE-LINKAGE.md)。

## 一、路由契约

### 触发（任一）
- 用户表达占卜意图：算卦、起卦、占一下、卜一卦、问吉凶、排盘、择日、测字、解梦、看风水、看相
- 只说「我要占卜/卜算/算一下」而**未说问什么事、未点名术法**：同样触发，按第三节「选术交互流程」先问事→荐术→说输入→起盘，**不要直接问「用什么术」**
- 点名某术：梅花易数 / 六爻 / 金钱卦 / 小六壬 / 大六壬 / 金口诀 / 奇门遁甲 / 太乙 / 八字 / 四柱 / 命理 / 周易 / 紫微斗数 / 七政四余 / 果老星宗 / 星命 / 风水 / 堪舆 / 玄空飞星 / 八宅 / 相术 / 看相 / 天文占
- 给出卦例要求解读、复盘、教学

### 排除（不触发，交给通用问答）
- 纯历史考据、流派介绍、书单科普（非实际占卜）
- 只做情绪安慰、生活建议，不给卦象
- 要求医学诊断、法律/投资决策代办（见免责）

## 三、选术交互流程（先问事 → 荐术 → 说输入 → 起盘）

用户只说「我要占卜 / 卜算 / 算一下 / 问吉凶」而**未点名术法**时，**不要直接问「用什么术」**，按四步走：

1. **先问事**：先问「你想占卜什么事？」，引导落到具体类目。可占类目远不止日常几类，**完整类目与每类的推荐术法见本节末「按问事推荐」表**——涵盖：求财 / 感情 / 事业 / 考试 / 官司 / 健康 / 出行 / 失物·寻人 / 择日 / 终身命理 / 合婚 / 风水 / 看相 / 测字 / 射覆 / 解梦 / 国运大事 等。最多问到能定位类目即可，不盘问细节。
2. **荐术**：按问事从下表推荐 **2-3 个候选术法**（第一个主荐，其余备选），一句话说明各自所长与分工（如「六爻断成败、奇门断时机方位」）。让用户选其一；若用户说「都要 / 多算几个」，则对同一问事做**多术交叉验证**（见第十节 + `XUANXUE-LINKAGE.md`）。
3. **说输入**：
   - 该术**自动起盘**（当前时刻/自动摇卦，不需用户额外信息）→ 直接说「这个我直接帮你起盘」，立即执行。
   - 该术**需用户提供信息** → 明确列出缺什么（如八字要「出生年月日时+性别」，风水要「出生年+坐向+性别」）。
4. **起盘**：能自动的直接跑 `cast.py`；缺输入的等用户补齐再跑。**具体命令见对应 `docs/` 分术文档「起盘」节**。

> 用户已点名术法时，跳过问事/荐术，直接进入「说输入 → 起盘」（该术缺输入同样要补齐再算）。

**自动起盘（无需额外信息，直接算）**：梅花时间起卦、小六壬、六爻（铜钱自动摇）、大六壬、金口诀、奇门、太乙、择日/老黄历（当前日）。
**需用户提供信息**：八字/紫微/七政四余（出生年月日时+性别）、风水（出生年+坐向+性别）、合婚（双方出生年月日）、梅花数字起卦（数字）、测字（字）、相术（照片/五官描述）。

## 五、起盘与依赖（scripts/cast.py，必须先跑）

- 起盘这一步**必须用脚本**，输出本卦/互卦/变卦/动爻/体用/四柱/大运/四课三传/八门九星/太乙落宫等确定性结果。
- **依赖**（`pip install lunar_python ephem cn2an bidict drawsvg py-iztro`）：
  - 梅花易数/小六壬/六爻：纯内置。
  - 八字：`lunar_python`。
  - 紫微运限：`py-iztro`（`libs/ziwei_horoscope.py`；`libs/zhiwei.py` 自写命盘/飞星不依赖它，py-iztro 仅用于流年流月流日流时运限 + 对照校验）。
  - 大六壬/奇门/太乙：`scripts/libs/` 内集成的 kentang2017 开源引擎（`engines/qimen`、`engines/taiyi`，MIT）+ `sxtwl.py` 垫片（用 lunar_python 替代寿星历，见 libs/README.md）。
  - 七政四余/风水/择日/神煞/刑冲合害：纯标准库（`libs/qizheng.py`、`fengshui.py`、`zeri.py`、`liunian.py`、`shensha.py`、`xingchong.py`，源自 dglijin-oss/chinese-metaphysics-skills，MIT，见 `libs/LICENSE.dglijin-oss.txt`）。
- 通用 flag：
  - 所有时间起盘方法可加 `--time "YYYY-MM-DD HH:MM"` 指定占时（缺省用当前系统时间）。
  - 八字/紫微/七政四余可加 `--lon 经度`（真太阳时校正，东经 120° 为基准）与 `--dst`（1986-91 中国夏令时回拨 1 小时）；出生时刻临近节气会提示「月柱可能跨节」建议双盘对照。
  - 八字可加 `--zishi same|next`：出生在晚子时（23:00-24:00）时选「子时换日」口径（`same`=00:00 换日主流默认，`next`=晚子时换日推进次日），无论哪种都会打印流派分歧提示。
  - `--html` 生成自包含 HTML 可视化（水墨风，可截图分享）：八字命盘、紫微命盘、六爻卦图、梅花三卦图、奇门九宫格、大六壬四课三传图、太乙神数盘图、`bazi-liunian` 流年趋势曲线。可视化是「叠加」不是「替代」——文字断语（考据层＋白话两层）永远是主体，图只辅助「看得懂盘面」。
  - `--ref`（仅大六壬）：排盘后加一道**独立九宗门实现交叉校验**（`libs/liuren_regress.py::cross_check_ref`，含涉害深浅独立重算），对比引擎与独立实现的宗门/三传，不一致即标「宗门/三传存疑」，提示按《六壬大全》原文复核——涉害/比用/返吟/八专边界易误判，命中存疑课时断卦须降级。
- 各术具体起盘命令见 `docs/` 对应文档「起盘」节。

## 六、输出规范（强制）

### 分层解读要求（每卦每盘都要做到）

解释卦象/课式时，**先讲本义，再落到当前问事**，不能只把卦名当吉凶标签。顺序：

1. **本义**：该卦/课在典籍中的原始语义（卦辞、彖传、课体、格局）。
2. **组合画面**：上下卦（或宫位/四课三传）组合形成的核心画面。
3. **过程关系**：该卦原本描述的过程、关系、张力。
4. **当前对应**：落到用户所问之事。
5. **推断**：明确标注这部分是推断，不是经文。

区分三层：六十四卦卦义 / 八卦单象 / 当前问事应用，不得用「坎=谨慎」「复=重新开始」这类单词替代完整卦义，也不得把八卦单象冒充六十四卦本义。

### 现实角色映射（体用/用神对应谁）

结构体用先定（动为用、静为体），再按领域映射现实角色：

- 感情「对方怎么看我」：体=问卦者，用=对方及反应。
- 感情「要不要主动」：体=问卦者，用=行动后的关系反馈（别把用直接当对方内心）。
- 工作「能否跳槽」：体=本人及现状，用=目标岗位/公司。
- 考试面试：体=本人准备发挥，用=考试/面试机制。
- 健康：体=本人及恢复力，用=病情/治疗；只谈卦象承受阻滞，不作医学诊断。
- **现代场景化扩展**（工作/生活/生意/交友/出行/股市/家宅/厂房/办公/商铺/婚恋 11 类，含体用角色 + 五生克落点 + 取象要点）：见 `references/梅花现代场景.md`。
- 六爻用神：测财=妻财、测官=官鬼、测文书父母=父母、测子女=子孙、测兄弟=兄弟、测自身=世爻。

### 背景补充规则

- 字段齐全、角色清楚时先给方向性初断，不盘问。
- 仅当同一卦存在两个以上会改变主断的解释时，才问背景；**最多问 2 个**区分度最高的问题，并说明用于区分哪两种解释。
- 信息不足时**分阶段收集**（借鉴 yijing-find-lost-item）：
  - **阶段一（必填）**：问事对象/身份/时间——缺则问，最多一次；
  - **阶段二（可选）**：环境/背景细节——仅当影响主断才问，最多 2 个二选一；
  - **阶段三（起卦信息）**：数字起卦等——能自动起盘就不问；
  - 用户不愿补 → **标注「部分信息基于推测」继续断**，不停等。
- 不因缺背景就停止解卦；缺的背景只影响例证/强弱/时间精度。

### 输出格式（三层分离 + 四段式）

**三层分离（强制）**：输出必须把「盘面事实」「规则推演」「现实建议」三层分开写，禁止互相混淆、禁止把推演冒充事实或经文。

- **盘面事实**：脚本排出的卦/课/盘/四柱——可复现、可核验。
- **规则推演**：依据断法规则得出的吉凶、格局、生克——须标注是 `[原文]` 还是 `[规则推演]`。
- **现实建议**：落到当前问事的趋避与建议——一律标 `[主观推断]`。

**三级标注（强制，每条断语必标其一）**：
- `[原文]`：直接引自典籍（须注明书名出处）；
- `[规则推演]`：依据断法规则（体用生克、旺衰、格局等）推出的结论；
- `[主观推断]`：落到当前问事的判断与建议。
- 约束：吉凶定性、格局判断必须能回溯到 `[原文]` 或 `[规则推演]`，不得凭空 `[主观推断]`；`[主观推断]` 只能用于「落到问事」与「建议」。

1. **起卦信息**：输入、方法、所用规则（脚本输出）。
2. **排盘结果**：卦象/课式/盘局/四柱，含五行生克标注（= 盘面事实层）。
3. **断语**：引用原文（注明书名，标 `[原文]`）+ 规则推演（标 `[规则推演]`）。
4. **结论**：吉凶要具体落地，不只贴「吉/凶」标签，须说清：
   - **吉凶总断**：一句话定性（大吉/吉/中平/凶/大凶）+ 吉在何处、凶在何处（落到财/感情/事业/健康/时机哪一面）。
   - **趋避**（必给，对应该术 `docs/` 文档「断卦流程·趋避」条目）：趋吉（可乘之机 + 行动建议）与避凶（风险与规避）缺一不可，落到本卦本问。
   - **可乘之机**：卦中有利处 → 宜做什么、把握什么时机或方位。
   - **风险与规避**：不利处 → 点明风险，给出「如何避免」（方位/时辰/人事/心性上的具体调整）。
   - **行动建议**：「应该如何做」→ 给 1–3 条可执行的具体步骤。
   - **应期**（能断则断）：何时应验、何时转机；断不出就明说「应期难定」。
   - **免责声明**（必附，见「免责声明」）。

### 白话解读层（人话优先，术语保留，必加）

**双轨原则（强制）**：上文的「三层分离 + 三级标注 + 四段式」是**考据层**，完整保留；本节是**白话层**，叠加其上。两者并存：考据层给「可查证的依据」，白话层给「听得懂的话」。**缺白话层＝不合格输出**。

**1. 结构（考据层原样保留，白话层叠加其后）**

```
① 起卦信息 → 原样保留
② 排盘结果（盘面事实）→ 原样保留
③ 断语 → 术语断语（[原文]/[规则推演]）原样保留，紧跟白话解读
④ 结论 → 术语结论原样保留，紧跟白话收口 + 「今日可行的一小步」
```

**2. 白话两层（每段术语断语都要有，缺一不可）**

- **① 术语解读**：把这段里的术语/断法用一句话讲清「它是什么、为什么这么断」——先拆概念、再给结论，不能只给「＝结果」。
  例：`伤官佩印`＝伤官（辛金）是你的才华、点子往外冒，正印（丁火）是有教养、懂收敛；两样碰一起，所以「聪明有才但懂分寸」。
- **② 问事解读**：把上面的信号落到「你这次问的事」上，讲清对这件事意味着什么、该注意什么。
  例：落到你问的这笔投资——钱（财星）现在没劲、还被是非风险（官鬼）盯着，所以短期赚不到快钱，还可能惹麻烦。
- **凶煞转生活语言**：七杀＝外部压力、伤官见官＝脑子活但容易顶撞、枭神夺食＝内心敏感期、羊刃＝容易冲动、驿马＝奔波变动、财星受冲＝财务易波动。
- **文言必配白话**：每条 `[原文]` 文言后紧跟白话（术语解读＋问事解读），原文保留。
- **禁用宿命词**：不说「注定/必然/绝对/大凶/无救」，改用「倾向/容易/建议关注/需留意」；禁恐吓式、宿命式表述。
- **第二人称**：白话层用「你」，像朋友聊天，短句。

**3. 六维度白话概括（终身命理类必做：八字/紫微/七政四余）**

考据层给全大运流年后，白话层六句话收口，每句＝结论一句＋依据半句：

| 维度 | 句式 |
|---|---|
| 性格 | 你是个……的人 |
| 事业 | 适合……，宜…… |
| 财运 | 钱对你……，宜…… |
| 感情 | 感情上…… |
| 身心 | 身体/情绪上注意…… |
| 阶段 | 当前这几年……，之后…… |

**4. 今日可行的一小步（结尾必给）**

每条结论末尾固定：`今日可行的一小步：`＋**一个 24 小时内能完成的具体动作**（落到本卦本问，忌「宜守正」「顺其自然」空话）。一事一占给 1 条，终身命理给 1 条当前最该做的。

**5. 底线不丢（强制）**

- 白话层**只翻译/收口考据层结论**，不得凭空新增吉凶定性；定性仍回溯 `[原文]`/`[规则推演]`。
- 免责声明仍附末尾；白话转译拿不准时宁可不译，不编「人话」曲解盘面。

### 免责声明（每次占卜结论末尾必附）

> 以上内容属传统术数文化研习，仅供娱乐与文化参考，不构成医疗、法律、投资、婚姻等任何专业决策依据。重大事项请咨询相应专业人士、理性判断。

### 常见提醒

- 一事一占、心诚则灵；同一问题不宜反复占。
- 断卦重「象数理」，结合具体问题灵活取用，忌死搬口诀。
- 三式与八字排盘步骤繁多，务必逐步核对、引书求证，不可跳步臆断。

## 七、质量 gate（排盘自检 + 断后质检，强制）

每术起盘后、断卦前，按对应 `docs/` 文档「排盘自检」节自查，防「漏排、错排、跳步」。**这是硬性 gate：任一必查项缺失或存疑，即停下补齐，不得跳过直接断卦。**（相术/天文占/测字/其他为无盘纯文本断法，跳过排盘 gate。）

> gate 可用 `libs/precheck.py` 校验：`precheck.check(术名, 已具备字段集合)` 返回是否通过、缺哪些项。

**降级处置（借鉴 yueyuan 30 秒校验）**：缺字段不硬断，按以下降级并明说——
- 时辰未知 → 年月日三柱，标注「时柱未知，涉及子女/晚年/时柱应期结论降级」；
- 性别未知 → 中性分析、不排大运，标注「补性别后补运」；
- 大运缺失 → 标注「大运缺失」，能排则补；
- 四柱干支不合法 → 先请用户核对，不强行分析。

**断卦后质检（与排盘前 gate 对称，强制）**：断语写完后、交付前，用 `libs/review.py` 自查七项，任一不过即退回补，不得直接交付——
- 三层分离（盘面事实/规则推演/现实建议齐全）
- 三级标注（有 `[原文]` 或 `[规则推演]`，`[主观推断]` 不凭空定性）
- 免责声明（末尾必附）
- 应期（给应期，或明说「应期难定」）
- 趋吉避凶（趋/避缺一不可）
- 信号冲突降级（出现「冲突」须明说降级/仅供参考/不确定）
- 白话层（双轨输出须有白话收口 + 今日可行的一小步）
规则 ID R-RV-01~07。调用：`review.review(断语文本) → {pass, score, issues}`，未过按 `issues` 逐条补齐。

## 九、证据分级与规则层级（借鉴 yueyuan-bazi，MIT）

**证据分级（每条结论标来源等级，与「输出规范」三级标注互补）**：

| 等级 | 内容 | 说明 |
|---|---|---|
| S | 输入可信度 | S3=出生资料+时区+节气+地点确认；S2=单一排盘工具；S1=手打四柱；S0=干支不合法，先核对再分析 |
| A | 原局硬数据 | 四柱、藏干、月令、日主（脚本输出） |
| B | 结构事实 | 合冲刑害「是否存在」（存在≠生效） |
| C | 命理判断 | 「三合是否化」「某神是否得根」等需论证的判断，必须给依据 |
| D | 流年应验 | 用户提供的人生事件，只能作后验证据 |
| E | 模型解释 | 因果解读，属假设，与事实分开呈现 |

铁则：C 不得伪装成 B；E 不得伪装成 A/D；S0 输入先核对再分析。

**规则层级与冲突裁决**（`STRUCTURAL > CORE > SCHOOL > HEURISTIC > SUPPLEMENTAL`）：

| 标签 | 层级 | 示例 | 硬度 |
|---|---|---|---|
| `[STRUCTURAL]` | 结构事实 | 四柱、藏干、合冲刑害、通根透藏 | 最高，不可改 |
| `[CORE]` | 核心理论 | 月令定权、格局、扶抑、病药 | 高 |
| `[SCHOOL]` | 流派理论 | 调候（穷通宝鉴系）、盲派、人元司令 | 中，须标流派 |
| `[HEURISTIC]` | 经验规则 | 岁运并临、墓库冲开、应期范式 | 初始参考 |
| `[SUPPLEMENTAL]` | 辅助符号 | 神煞、空亡 | 主题标签/修正项 |

冲突裁决：跨层高者胜；同层保留竞争假设；跨流派并列呈现 + 标适用条件；证据不足输出「不确定」，禁止语言润色制造假共识。

**拒绝迎合（铁则）**：用户提出的结论、引用的说法、叙述的某年吉凶，**不得作为改变基础判断的依据**，只能触发重新核查。

**能力边界（MingLi-Bench 160 题实测 36.2%，随机线 25%；各类别实测命中率如下）**：此数字可用 `python scripts/cast.py mingli-eval`（`libs/mingli_eval.py`）本地复现——解析案例库「八字紫微」benchmark 表，实时算分品类/总体命中率 + 随机基线(25%) + 众数基线。

**有信号组（可给方向，实测显著高于随机）**：
- **健康**（17 题命中 52.9%）——五行/十神断病有信号，可给「哪方面健康需注意」的方向，但**慎断具体病名、具体年份**；
- **事业**（25 题 40.0%）、**财运**（13 题 38.5%）、**家庭**（22 题 36.4%）、**婚姻**（44 题 34.1%）——略高于随机，可给方向，但结论标「倾向 / 建议关注」，不作铁断。

**无信号组（实测接近或低于随机，一律「不确定 + 低置信度」，不硬猜）**：
- **精确年份 + 具体生平**（何年结婚 / 父亡年份 / 某年发生何事）——八字结构给不出确定答案；
- **学历/学业**（11 题 18.2%，**低于随机**）——印星不可靠推断学历，禁断学历高低；
- **性格**（14 题 28.6%）、**外貌身材**（3 题 33.3%）——「五行主形」不可靠，归 `[SUPPLEMENTAL]`，不作主断。

**断卦策略**：遇到「无信号组」问题，明确回答「这类问题术数给不出确定答案（实测≈随机），不硬断」，并引导到「有信号组」方向（健康倾向、事业财运方向、婚姻家庭模式），而不是硬给一个四选一猜测。

## 十、交叉验证总则（单术多维 + 多术互参，强制）

> 多术联动接口见 `XUANXUE-LINKAGE.md`（按问事功能分组：主术 + 辅术 + 融合输出）。

每术断卦时，多维度结论须互相印证；**不一致就明说「信号冲突，仅供参考」并降级**，不得只取有利一维硬下结论。各术的交叉验证维度见对应 `docs/` 文档「交叉验证」节。

### 多术互参（同一问事，多术交叉验证）

用户对同一问事选多个术法（或说「都要 / 多算几个」）时，逐术独立起盘断卦后做交叉验证：

1. **各术独立断**：每个术按各自流程起盘 + 断卦，各自给吉凶结论（吉/凶/中），三层分离、三级标注不省。
2. **两两三态标记**：用 `rules.fusion_mark(判甲, 判乙, same_aspect)` 两两比对——
   - `same_aspect=True`（两术断同一侧面，如梅花 vs 六爻都断一事成败）→ 一致则结论更稳；冲突则明说「信号冲突」并降级。
   - `same_aspect=False`（两术答不同侧面）→ 标「互补」，各保留，不强行比吉凶。
3. **综合结论**：一致多 → 结论加可信度；冲突 → 明说分歧 + 降级，绝不只取有利一术硬下结论；互补 → 分维度陈述（成败如何 + 时机方位如何）。
4. **常见互补对**（分答不同侧面，勿强行比吉凶）：六爻/梅花断成败 + 奇门断时机方位；梅花断心意 + 大六壬断应期；八字/紫微断终身格局 + 六爻/梅花断一事得失。
5. **常见同侧对**（可直接比吉凶）：梅花 vs 六爻 vs 小六壬（一事吉凶）；八字 vs 紫微（终身命理）；大六壬 vs 奇门（时机）。
