## 二、六亲生克（宫五行为我）

| 六亲 | 关系 | 生克方向 |
|---|---|---|
| 父母 | 生我 | 爻生宫 |
| 子孙 | 我生 | 宫生爻 |
| 官鬼 | 克我 | 爻克宫 |
| 妻财 | 我克 | 宫克爻 |
| 兄弟 | 比和 | 五行同 |

- **原神**：生用神者（如妻财之原神为子孙）。**忌神**：克用神者（如妻财之忌神为兄弟）。
- 断卦口诀：**用神旺相 + 原神发动生之 → 吉；忌神发动克用神 → 凶。**

> 出处：《增删卜易》「原神忌神章」。六亲生克已由 `scripts/libs/najia.py::liuqin` 落地，`tests` 锁定。

## 四、旺衰与应期（月建日辰定旺衰）

- **旺相**：用神得月建日辰生扶、临旺地 → 可成宜进。
- **休囚**：用神受月破日克、临衰地 → 难成宜缓。
- **旬空**：用神旬空 → 事虚、待出空；**月破**：用神月破 → 当月不利。
- **应期**：冲待合、合待冲；空待出空、破待补合；动爻临值之日、静爻逢值逢冲之时。

> 出处：《增删卜易》「月建日辰章」「旬空月破章」。旺衰四维（得令/得地/得势/得助）见 `docs/六爻纳甲.md`「排盘自检」。
