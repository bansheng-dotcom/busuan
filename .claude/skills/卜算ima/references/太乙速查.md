# 太乙神数速查

> 太乙是三式之首（与奇门、六壬并称），专推算天时国运、主客胜负、兵阵灾异。起盘 `cast.py taiyi`，断卦接 `rules.py` 的 R-TY-01~04 + 典籍 search_txt.py + 案例库。速查表只给方向，断卦仍须按关键词 search_txt.py 典籍 txt 原文佐证（双重保证）。

## 一、起盘 CLI

```bash
python scripts/cast.py taiyi                              # 默认 年计/太乙统宗
python scripts/cast.py taiyi --ji 1                       # 月计
python scripts/cast.py taiyi --ji 2 --method 1            # 日计 × 太乙金镜
python scripts/cast.py taiyi --method 2                   # 年计 × 淘金歌
python scripts/cast.py taiyi --game                       # 附加运筹博弈(Nash+线性规划)
python scripts/cast.py taiyi --full                       # 全字段 JSON
python scripts/cast.py taiyi --time "2026-10-07 10:00"    # 指定占时
```

| 参数 | 取值 | 含义 |
|---|---|---|
| `--ji` | 0年 1月 2日 3时 4分 5命 | 计式（命法=5 上游引擎未完成，暂拒） |
| `--method` | 0统宗 1金镜 2淘金歌 3太乙局 | 积年法 |
| `--game` | — | 附加运筹博弈分析 |
| `--full` | — | 输出完整 JSON（100+ 字段） |

**已知引擎边界（诚实标注，上游 kintaiyi 2019 旧代码）**：命法(5) 抛 TypeError；日计×太乙局(2,3) TypeError；时/分计×非统宗 可能死循环。这些组合 `cast.py` 已拦截或提示降级。

## 三、主客算吉凶（R-TY-01）

断语关键词分吉凶，出处《太乙淘金歌·求主客算》：

| 断语关键词 | 判 | 含义 |
|---|---|---|
| 三才足數、上和、下和、長和、太和 | 吉 | 天地人三才齐备、上下和 |
| 無天 / 無地 / 無人 | 凶 | 缺天/地/人，算数有缺 |
| 純陽 / 純陰 / 雜陽 / 雜陰 / 重陽 / 重陰 | 凶 | 阴阳偏极 |

调用：`rules.taiyi_suan(主算) → {judgment, evidence:"R-TY-01"}`。吉凶并存标「信号冲突」降级。

## 四、主客胜负（R-TY-02）

出处《太乙金镜式经·推多少以占胜负》：

| 主算 vs 客算 | 判 | 结论 |
|---|---|---|
| 主吉 客凶 | 吉 | 主方有利、客方不利，宜守不宜攻、宜后发不宜先发 |
| 主凶 客吉 | 凶 | 客方有利、主方不利，宜先发制人、抢先布局 |
| 双吉 | 吉 | 主客两利，可进可攻 |
| 双凶 | 凶 | 两不利，宜缓守静待 |

## 五、格局凶格（R-TY-03）

出处《太乙秘书》《太乙局》《太乙金镜式经》。犯以下格局主凶：

| 格局 | 含义（《太乙秘书》） |
|---|---|
| 掩 | 始击临太乙宫，阴盛阳衰、君弱臣强，谋事受制 |
| 迫 | 太乙迫宫，被动受压 |
| 關 | 关门不通 |
| 囚 | 下犯上 |
| 擊 | 始击（文昌）受冲 |
| 格 | 相格相犯 |
| 對 | 冲对 |

调用：`rules.taiyi_geju(文昌或断语) → {judgment, evidence:"R-TY-03"}`。文昌带「始擊掩」即犯掩格（凶）。

## 八、断卦流程

1. **起盘**：`cast.py taiyi [--ji] [--method] [--game]`，得盘面事实（第二节分组）。
2. **套规则**（勿心算）：`rules.taiyi_suan/zhuke/geju/luogong_wangshuai` 给 R-TY-01~04 吉凶。
3. **search_txt.py 原文佐证**：按关键词（主客算/掩/迫/关/囚/击/格/对/三才足数/五福/君基）搜 `txt\[易藏] 太乙金镜式经.txt`、`太乙秘书.txt`、`太乙淘金歌.txt`、`太乙局.txt`，注明出处。
4. **交叉验证**：主客算 vs 格局 vs 落宫旺衰，`rules.cross_validate([...])` 不一致即「信号冲突」降级。
5. **断语三层分离**：盘面事实 / 规则推演（[原文]+[规则推演]）/ 现实建议（[主观推断]）。
