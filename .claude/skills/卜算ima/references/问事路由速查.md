# 问事路由速查（问事 → 推荐术法）

> 来源：SKILL.md「三、选术交互流程」。用户未点名术法时，按问事从本表选术（主荐在前，备选互补）。
> 本表只做**路由**；选定理法后的起盘/断卦/质检，仍按各术 `docs/` 文档 + search_txt.py 典籍 txt 原文佐证执行。

| 事类 | 可占事项 | 主荐术法 | 备选 / 互补术法 |
|---|---|---|---|
| 求财 | 财运、投资、生意、合伙、借贷、讨债、中奖 | 六爻（妻财用神断成败） | 小六壬（快断）、梅花（体用）、八字（终身财运模式） |
| 感情 | 姻缘、对方心意、要不要主动、分手复合、桃花、第三者 | 大六壬（对方心意/应期） | 梅花（心意动向）、六爻（婚姻成败）、紫微（夫妻宫） |
| 事业 | 跳槽、晋升、创业、合作、求职、调动、辞职 | 六爻（官鬼用神断成败） | 梅花（体用）、奇门（时机方位）、八字（事业方向） |
| 考试 | 升学、考编、考证、面试、答辩 | 六爻（父母用神） | 梅花（体用）、小六壬（快断） |
| 官司 | 诉讼、纠纷、是非、仲裁 | 六爻（官鬼用神） | 奇门（主客胜负） |
| 健康 | 疾病吉凶、养生方向、康复 | 六爻（世爻旺衰） | 梅花（体用）；只断方向，不作医学诊断 |
| 出行 | 远行、搬家、移民、出差、远嫁 | 奇门（方位时机） | 小六壬（快断）、大六壬（应期） |
| 失物·寻人 | 寻物、寻人、寻宠、寻车 | 六爻（子孙用神） | 金口诀（射覆寻物）、小六壬（快断） |
| 择日 | 婚嫁、开业、动土、搬家、签约、出行吉日 | 择日（建除黄道神煞） | 老黄历（当前日宜忌） |
| 终身命理 | 八字/紫微/七政四余看一生格局、大运流年 | 八字（格局旺衰）/ 紫微（十二宫四化） | 七政四余（星命）、紫微流年（zhiwei-liunian） |
| 合婚 | 双方八字/星命匹配、婚配吉凶 | 八字合婚（hehun） | 七政四余、紫微 |
| 风水 | 阳宅坐向、流年方位、选房、办公室布局 | 风水堪舆（八宅命卦/玄空飞星） | — |
| 看相 | 面相、手相、骨相、识人用人 | 相术（五官神气色） | — |
| 测字 | 报字测事、测字问吉凶 | 测字（十法六法） | — |
| 射覆 | 猜物、来意、藏物 | 金口诀（四位射覆） | 梅花物数占/字占 |
| 解梦 | 梦境占、梦兆 | 其他（解梦） | 梅花 |
| 国运/大事 | 大格局、主客胜负、博弈、星象灾异 | 太乙神数（主客） | 天文占（星象） |

> 拿不准或大事 → 两术互参（交叉验证，见 SKILL.md 第十节 + `XUANXUE-LINKAGE.md`）。
