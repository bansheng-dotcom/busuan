# 三要十应（外应触机）速查

> 出处：《梅花易数》卷二「体用生克篇之三/四」——三要灵应篇序、三要灵应篇、十应奥论、十应目论、复明天时/地理/人事/时令/方卦/动物/静物/言语/声音/五色/写字之应、遗论、体用、体用论、衰旺论、内外论、动静、向背、静占。
> 用法：梅花**后天起卦**（观物/声音/字数/端法）后，除体用生克外，**必须合外应断**——「体用为内，诸应卦为外」，内外相合才准（见「内外论」）。
> 铁则：本表是结构化判定层 + 出处指针，断卦仍须按篇名 search《梅花易数》原文佐证；缺原文就明说「依三要十应法推演，非直接引文」。

## 一、三要（耳 · 目 · 心）

| 要 | 通道 | 断什么 |
|---|---|---|
| 耳 | 听声音 | 知吉凶——闻声几数、辨物声（金木水火土之声）、察悲喜（笑语吉、悲泣凶） |
| 目 | 见形色 | 知善恶——观物形（圆者事成、缺者事败）、察气色 |
| 心 | 察其理 | 知祸福——静虑诚存，一念所在即为外应 |

- 口诀（原文）：「占决之际，寂闻澄虑，静观万物，而听其音知吉凶，见其形知善恶，察其理知祸福。」
- 总纲（原文）：三要运耳目心三者之虚灵，应于事物；耳之聪、目之明，吾心实总乎聪明。

## 二、十应（十一类外应）

### 总纲（十应奥论 / 十应目论）

- 十应固出于三要而妙乎三要：三要「见吉兆终吉、逢凶谶不免凶」是常理，十应能破常理——**金银对震巽体反不吉（金克木），兵刃对坎体反不凶（金生水）**。
- 十应以**体卦为主、诸用卦（外应）为用**，内分外体：
  - 内卦不吉而外卦吉 → 可解其不吉；内卦吉而外卦凶 → 反破其吉。
  - 内外全吉 → 断然吉；全凶 → 断然凶；内吉外凶 / 内凶外吉 → 详理再断，勿胶柱鼓瑟。

### 十一类外应

| 外应 | 现象举例 | 断法（体卦为主） |
|---|---|---|
| 天时 | 晴明=乾之时、日中=离、雨雪=坎、雷风=震巽 | 乾兑为体比和吉、坎为体逢生大吉、震巽为体见克不吉… |
| 地理 | 茂树秀竹=震地、江湖河池=坎地、窑灶=离地、岩穴=艮地 | 离与震巽为体吉、坤艮为体凶（震地）；震巽坎为体吉、离为体不吉（坎地）… |
| 人事 | 老人=乾、老妇=坤、少男=艮、少女=兑；官吏商贾孩童吏卒 | 论卦象者按五行生克比和；不论者随其吉凶为兆 |
| 时令 | 寅卯月木旺、巳午火旺、申酉金旺、亥子水旺、辰戌丑未土旺 | 生体卦气宜值旺气，克体卦气宜乘衰 |
| 方卦 | 离南、坎北、震东、兑西、巽东南、乾西北、艮东北、坤西南 | 看来占人所在方位，用卦参详；宜在本卦之方/用卦生之方，不宜受克方 |
| 动物 | 乾马坤牛震龙巽鸡坎豕离雉艮狗兑羊；乌鸦报灾、鹊报喜、雁主书信、蛇防毒 | 论卦象以体详；不论者按鸦灾鹊喜蛇毒 |
| 静物 | 水=坎、火=离、金气=乾兑、土气=坤艮；笔砚主文书、袍笏主官职、枷锁防官灾 | 物圆者事成、器缺者事败；审是何物定何事 |
| 言语 | 说迁选求名、论江湖主出行、言争讼主官司、言喜庆利婚姻 | 闻吉语吉、闻凶语凶；喧集难决则定人少处辨其绪 |
| 声音 | 雷=震、风=巽、雨=坎、钟铃金声=乾兑、鼓拍木声=震巽 | 欢笑有喜、悲愁有忧、怒号争喧；鸦灾鹊喜雁远信 |
| 五色 | 青碧绿=木、红紫赤=火、白=金、黑=水、黄=土 | 外应五行详于内卦，体用生克比和定吉凶 |
| 写字 | 淡中浓墨=淬、点画误书=鬼笔、涕泪=丧服 | 鬼笔防窃盗、涕泪防丧服忧惊 |

## 三、配套断法（与三要十应同章，必合参）

- **衰旺论**：体卦宜旺；生体之卦气亦宜旺，克体之卦气宜衰；体衰逢克凶甚，体衰而有生体则稍解。
- **内外论**：体用为内、诸应卦为外，必合内外断——金银宝器三要以为吉，若震巽为体则金克木反不吉；兵刃三要以为凶，若坎为体则金生水反不凶。
- **动静**：不动不占、不因事不占；占卜之际察群物之事，物动而凶者兆卦之凶、物动而吉者兆卦之吉；坐应迟、行应速、走愈速、卧愈迟。
- **向背**：外应相向而来→吉凶将至，相背而去→吉凶已过（鸦报灾，鸦飞来灾将至，鸦飞去灾已过）。
- **静占**：静室无所闻见→不论外卦，只以年月日时五行衰旺 + 体用断。

## 四、后天起卦（触机）命令

| 起卦法 | 命令 | 输入 | 出处 |
|---|---|---|---|
| 物数占 | `cast.py meihua-guanwu <物数>` | 见可数之物，报其数 | 卷一·物数占例 |
| 声音占 | `cast.py meihua-shengyin <声数>` | 闻声几数 | 卷一·声音占例 |
| 字占 | `cast.py meihua-zishu <字数>` | 所见字数（一字/二字有专门规则，见下） | 卷一·字占 |
| 端法 | `cast.py meihua-duanfa <物卦> <方位卦>` | 见某物 + 方位（南离北坎东震西兑…） | 卷一·物卦起例 |

- 端法物卦可填卦名（乾兑离震巽坎艮坤）、数字（1-8）、五行（金木水火土）、方位（南/北/东南…）；方位亦可用方位名。
- 一字占：草书不可取，楷书取左右笔画，左为阳画右为阴画，居左几数上卦、居右几数下卦。二字占：一字上卦、一字下卦（详见原文「一字占至十一字占」）。
