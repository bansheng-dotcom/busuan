## ① shefu：射覆「特征画像」法（★★★ 最优先）

**设计**：AI 不猜物名，而是产出「特征画像」——6 个维度（材质/形态/功能/结构/颜色/尺寸），每个标置信度 🟢高/🟡中/🔴低。命名权交给玩家。
- 例：`材质🟢硬质含金属 / 形态🟢框状 / 功能🟡可开合 / 颜色🟡银白` —— 而不是「这是一把剪刀」。
- 口诀：**「AI 是画师不是鉴定师——刻画特征，命名权交给玩家。」**

**借鉴到咱们**：
- 大六壬/梅花射覆时，不再输出「钱 / 番茄酱」这种具体猜名，改为**特征画像**：把「干上神天将 + 地支」映射成 6 维度，各标置信度。
- 这正好落实了「降分辨率 + 给候选」——直接根治 2026-10-08「番茄酱」翻车（该输出「红色、糊状、食用」而不是「钱」）。

## ② shefu：类象库结构化 + 后验回填 confidence（★★★）

**设计**：`类象库.json` 结构 `卦.维度[{value, confidence, source, validations}]`，每条类象带**置信度 + 出处 + 验证次数**；每轮射覆复盘后 `update_kb.py` 自动更新：命中信号 confidence↑、错误信号 confidence↓。

**借鉴到咱们**：
- 把 `references/现代类象映射.md` 从「平面表」升级成「结构化类象库（带 confidence + source）」。
- 后验回填从「记命中/未命中」升级成「**回填到类象的 confidence**」——命中↑、错误↓，靠几十个后验把类象权重校准出来（这正是「后验积累」的可执行形态）。

## ③ liuren-skill：占验反馈系统 + 相似课体推荐 + 赋文冲突取舍（★★★）

**设计**：①占验反馈系统（记录占问结果与实际情况、准确度统计、经验积累）；②课经案例库 200+（分类检索 + **相似课体推荐** + 历史验证反馈）；③毕法赋组合断语（多赋文同时适用时的**优先级与冲突取舍规则**）。

**借鉴到咱们**：
- 反馈系统 ↔ 咱们的 `cases/manage.py` + `feedback.py`（已有，可补「准确度统计」）。
- 相似课体推荐 ↔ 咱们的 `search`（已有语义检索，可补「按课体/卦名相似推荐」维度）。
- 赋文冲突取舍 ↔ 咱们的 `liuren_bifa.py`（已有结构化索引，可补「多赋文命中时的优先级/冲突裁决规则」）。

## ④ yijing：体用→概率风险等级表（★★）

**设计**：把体用生克直接映射成寻回概率档：

| 五行关系 | 概率 | 说明 |
|---|---|---|
| 用生体 | 极高 | 失物主动来寻 |
| 比和 | 较高 | 在常放处 |
| 体克用 | 中等 | 费力可寻 |
| 用克体 | 较低 | 较难 |
| 体生用 | 很低 | 可能已损 |

**借鉴到咱们**：梅花/六爻的「体用生克 → 吉凶」已有 if-then 规则（rules.py），可**补一档「概率/力度」量化**，把「小吉/凶」落到「极高/较高/中等/较低/很低」，让结论更可操作。

## ⑤ yijing：分阶段信息收集 + 信息不足降级（★★）

**设计**：寻物分 4 阶段收集（物品→时间位置→环境→起卦数字），信息不足时**分阶段追问**；用户不愿补就**标注「部分信息基于推测」继续推**。

**借鉴到咱们**：咱们「背景补充规则」已有「最多问 2 个高区分度问题」，可对齐成「分阶段 + 不愿补则降级标注继续」，避免盘问。

## ⑥ liuyao：理法/象法分开检索（★★）

**设计**：六爻知识分「理法」（旺衰/生克/用神）与「象法」（六神六亲类象），`search_knowledge(method="xiangfa")` 按需检索象法。

**借鉴到咱们**：六爻断卦时，**理法（旺衰）与象法（六神六亲取象）分两路**检索——象法这路正是「测物/测动态」该优先走的（呼应 ①）。

## ⑦ mingyu：术数术语百科（★）

**设计**：`metaphysics-terms.ts` 250+ 术语条目，含辩证解析 + 盘面角色推断。

**借鉴到咱们**：可补一份 `references/术语百科.md`（或并入速查层），断卦时按术语查出处。

## 落地顺序建议

1. **先做 ① 射覆特征画像**——直接根治「猜具体物」翻车，改动小、收益大。
2. **再做 ② 类象库结构化 + confidence 后验回填**——把「后验积累」变成可执行机制。
3. ③④⑤⑥⑦ 按需排后。
