## 1. 求财

- **类神取法**：日干所克之神为财（甲己土、乙庚金、丙辛水、丁壬木、戊癸火）。取财爻在四课三传之位置；青龙、太常为财喜之神。
- **旺衰断**：财爻旺相有气、乘青龙太常、得生 → 财可求；财爻空亡、休囚、乘玄武螣蛇 → 财虚、防骗。
- **吉**：青龙得位、太常临财、三传顺生、水日逢丁财动之。
- **凶**：传财化鬼财休觅、传财太旺反财亏、干乘墓虎（求财遇病丧）、空上乘空事莫追。
- **search 关键词**：`求财` `财` `青龙` `太常` `传财` `财爻`

## 2. 事业 / 前程 / 官禄

- **类神取法**：克日干者为官鬼（主职位）；日禄为俸禄；青龙主升迁、白虎主威权。
- **旺衰断**：官爻旺相、乘青龙贵人、日禄临身 → 宜进取升迁；官爻空亡休囚、乘天空 → 求而不得。
- **吉**：催官使者赴官期、前后引从升迁吉、帘幕贵人高甲第、富贵干支逢禄马、尊崇传内遇三奇。
- **凶**：权摄不正禄临支、课传俱贵转无依、旺禄临身徒妄作。
- **search 关键词**：`前程` `官` `禄` `升迁` `青龙` `白虎` `贵人`

## 3. 婚姻

- **类神取法**：男占以财爻为妻、天后为女；女占以官爻为夫；六合为媒合之神。日干为我、日支为对方/家。
- **旺衰断**：财爻/官爻旺相、乘六合天后、干支上下相合 → 婚易成；落空、乘玄武螣蛇、干支相冲 → 迟成或波折。
- **吉**：后合占婚岂用媒、上下皆合两心齐、万事喜忻三六合、太常乘日之长生。
- **凶**：夫妇芜淫各有私、宾主不投刑在上、彼此猜忌害相随、贵人多见事参差。
- **注意**（案例库教训）：勿以单一化忌/凶断「必不成/单身」，只主迟成与波折。
- **search 关键词**：`婚姻` `婚` `六合` `天后` `财` `官` `合`

## 4. 健康 / 疾病

- **类神取法**：白虎主病、官鬼为病根、天医/子孙为医药。日干为我身，干上神主自身病况。
- **旺衰断**：日干旺相抗病力强；日干休囚、乘墓虎 → 病重。鬼爻旺而克身 → 病实；鬼空无气 → 病轻。
- **吉**：制鬼之位乃良医、日干旺相、子孙乘旺（医药得力）。
- **凶**：干乘墓虎无占病、受虎克神为病证、支乘墓虎有伏尸、病符克宅全家患、鬼临三四讼灾随。
- **慎**：只断「哪方面需注意、轻重缓急」，慎断具体病名与应期（见 SKILL.md 能力边界）。
- **search 关键词**：`病` `虎` `墓` `医` `鬼` `天医`

## 5. 官司 / 官讼

- **类神取法**：勾陈主争讼田土、朱雀主口舌文书、官鬼主官非。日干为我、日支为对方。
- **旺衰断**：我旺他衰、官鬼受制 → 我得理；官鬼旺而克我、勾陈朱雀并见 → 讼不利。
- **吉**：害贵讼直作屈断（贵受克反主讼直）、罡塞鬼户任谋为。
- **凶**：宾主不投刑在上、鬼临三四讼灾随、勾陈克日主勾连、前后逼迫难进退。
- **search 关键词**：`讼` `官讼` `勾陈` `朱雀` `刑` `争`

## 6. 出行

- **类神取法**：驿马/丁马主动、天马主远行；日干为我、三传主行程。干支上神、末传主归期。
- **旺衰断**：驿马发动、三传相生、末传吉 → 出行顺；驿马空亡、传中克我、伏吟反吟 → 阻或反复。
- **吉**：任信丁马须言动、踏脚空亡进用宜。
- **凶**：进茹空亡宜退步、魁度天门关隔定、所谋多拙逢罗网、来去俱空岂动宜。
- **search 关键词**：`出行` `驿马` `丁马` `天马` `三传` `末传`

## 7. 求子 / 孕产

- **类神取法**：日干所生者为子孙；天后主孕产、六合主和合、天喜红鸾主喜。
- **旺衰断**：子孙爻旺相、乘天后六合、天喜红鸾临身 → 易有喜；落空、乘玄武白虎 → 迟或无。
- **吉**：天喜临身主有喜、六合天后主孕育、太阳照武宜擒贼（占产亦主顺）。
- **凶**：干支皆败势倾颓、人宅皆死各衰羸。
- **search 关键词**：`孕` `产` `子孙` `天后` `六合` `天喜` `红鸾`

## 8. 失物 / 寻人

- **类神取法**：财爻为失物、玄武主盗、天空主空亡走失；三传末传主下落、类神落宫主方位。
- **旺衰断**：类神旺相、乘吉将 → 物可寻、人可归；类神空亡、乘天空玄武 → 难寻、防盗失。
- **吉**：类神临生旺、末传生干、神生干兮寻人吉。
- **凶**：玄武入传防盗失、天空入传主走失、空空如也事休追。
- **search 关键词**：`失物` `寻` `盗` `玄武` `天空` `空亡`

## 9. 考试

- **类神取法**：朱雀主文书、帘幕贵人为考官、日干为我。朱雀旺相、帘幕贵人临干或发用 → 高中。
- **旺衰断**：朱雀乘旺、帘幕贵临干、三传顺生 → 名可成；朱雀空亡、白虎临身 → 失利。
- **吉**：帘幕贵人高甲第、尊崇传内遇三奇、太常乘日之长生。
- **凶**：两贵受克难干贵、二贵皆空虚喜期、天空临身主落空。
- **search 关键词**：`考试` `科举` `帘幕贵人` `朱雀` `文书` `甲第`

## 10. 交易 / 合作

- **类神取法**：财爻主利、六合主合、青龙主财喜；日干为我、日支为对方/标的。
- **旺衰断**：六合临身、财爻旺相、干支上下相合 → 成而有利；财爻空亡、干支相冲、玄武入传 → 不成或防诈。
- **吉**：万事喜忻三六合、交车相合交关利、上下皆合两心齐。
- **凶**：合中犯杀蜜中砒、脱上逢脱防虚诈、财爻落空事难成。
- **search 关键词**：`交易` `买卖` `六合` `财` `青龙` `合`

## 11. 通用（不指名问事）

- **取用**：先看课体（元首/重审/知一/涉害/遥克/昴星/别责/八专/伏吟/反吟）定事之体，再看四课上下生克、三传生克、发用末传、日干日支、年命上神、贵人与神煞。
- **旺衰断**：三传顺生、发用类神得力、课体吉 → 可成宜进；传中克我、末传脱气、空亡入传、伏吟反吟闭口 → 阻、反复、难通。
- **吉**：三传递生人举荐、互生俱生凡事益、互旺皆旺坐谋宜。
- **凶**：三传互克众人欺、彼此全伤防两损、空空如也事休追。
- **search 关键词**：按课体名（`元首` `重审` `涉害` 等）+ `三传` `四课` `发用` `类神`
