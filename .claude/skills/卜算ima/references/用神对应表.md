## 一、六爻用神（《火珠林》）

| 问事 | 用神 | 原文 | 出处 |
|---|---|---|---|
| 求官/词讼/问夫/病鬼祟 | 官鬼 | 「占病鬼祟，占失看贼，占求官事，占官词讼，占婚问夫，以上皆看官爻」 | 火珠林:46 |
| 求财/婚姻/买卖 | 妻财 | 「占买卖财，占家事，占婚婢事，占求财事，占婚姻事，以上皆看财爻」 | 火珠林:46 |
| 六畜/小儿/子女 | 子孙 | 「占六畜、小儿，看子孙；失物，看财」「凡占六畜，只以子孙为用」 | 火珠林:251、279 |
| 失物 | 财（失物看财） | 「失物，看财」 | 火珠林:251 |
| 文书/牌号 | 父母 | 「若失文书牌号，当以父母爻取」 | 火珠林:252 |
| 贼/捕捉 | 官鬼为贼、子孙为捕捉 | 「官鬼为贼，子孙为捕捉，兄弟为众，父母为衣服、文书，财为失物」 | 火珠林:281 |

**limitation**：用神定位只是「取哪个爻为分析对象」，**不得由用神名直接推断吉凶**——吉凶须看用神旺衰、月建日辰生克、动变、世应关系，六爻无鬼安静则「非贼偷去，乃自失也」（火珠林:283）。

### 六爻事项分工补充（王虎应口径）

《火珠林》原文是「按六亲分」的粗口径；王虎应《六爻预测自修宝典》《六爻分类占验技法》按**问事细分**，是六爻分类占验的权威口径（见 `D:\术数参考\liuyao\plugins\liuyao-assistant\skills\interpret-liuyao\references\reasoning-kernel.md` 附录一）。二者互补：先按下表定位细分用神，再回《火珠林》六亲原文佐证旺衰生克。

| 问事 | 主用神 | 说明 |
|---|---|---|
| 考学、求职考试、职称评定 | **官鬼＋父母** | 官鬼=名次，父母=成绩与录取通知书 |
| 读书上学（不争名次） | 父母 | 考学才看官，纯求学看父母（文书/学籍） |
| 出国留学 | 父母 | 签证为首要矛盾；官鬼=大使馆 |
| 文书申请类（申请学校、资质） | 父母 | 父母为文书 |
| 失物（财物） | 妻财 | 财物看财 |
| 失物（文件证件类） | 父母 | 证件、牌号、文件类看父母 |
| 失物（宠物/六畜） | 子孙 | 宠物、六畜走失看子孙 |
| 行人、走失、寻人 | **所寻之人的六亲** | 找父看父母、找子看子孙、找财看妻财；用神旺相、生合世爻则回，休囚受制则难 |
| 诉讼、竞争、比赛 | **世应强弱** | 对抗型事项喜我旺彼弱（非单看官鬼） |
| 出行 | 世爻＋父母 | 世爻=本人顺逆，父母=车船工具；出行动而逢合被绊 |

**总原则（王虎应）**：主用神只有一个，承载所问结果；其余六亲各管一个辅助维度（单位、工资、分数、文书……），辅助爻弱不否定主用神，辅助爻旺也不替主用神报成功。取用顺序：一动一静取动、同静取空破异常、再看冲合、再看临世应、再看离世应远近。

## 二、大六壬用神/类神（《六壬大全》）

| 问事 | 用神（天将/类神） | 原文 | 出处 |
|---|---|---|---|
| 求财 | 青龙 | 「求财以青龙为主，要乘旺相气，临旺相乡，与日辰相生，或作三合六合者吉」 | 六壬大全:1872 |
| 婚姻/胎产 | 青龙、六合 | 「占婚姻、胎产同此」「六合喜庆婚姻……青龙应婚姻财寳」 | 六壬大全:1872、2375 |
| 官爵 | 白虎（威权）、太常（印绶） | 「占官爵亦阙要白虎，乃为威权」「占官最喜此将，终始见太常、天驿二马、印绶之卦」 | 六壬大全:1919、1937 |
| 疾病 | 忌白虎 | 「占病切忌白虎贼日，兼虎带杀贼日……皆凶」 | 六壬大全:1920 |
| 行人 | 白虎（定迟速） | 「占行人以虎为准，初传立至，中传在途，末传失约未来」 | 六壬大全:1920 |
| 盗贼 | 玄武 | 「凡占盗贼，须责元武之三传」 | 六壬大全:1960 |
| 文书口舌 | 朱雀 | 「朱雀文书口舌」 | 六壬大全:2375 |
| 官司/争讼 | 勾陈 | 「勾陈主鬬讼勾连」 | 六壬大全:2375 |
| 阴私 | 太阴、天后 | 「天后奸心暗昧，太阴隠晦阴私」 | 六壬大全:2375 |
| 酒食 | 太常 | 「太常有酒食之筵会」 | 六壬大全:2375 |
| 逃亡 | 天空 | 「天空主欺诈之逃亡」 | 六壬大全:2375 |

**十二天将主事总纲**（六壬大全:2375）：
> 「天乙所占官宦……螣蛇为卜惊忧……朱雀文书口舌，六合喜庆婚姻。勾陈主鬬讼勾连，青龙应婚姻财寳。天后奸心暗昧，太阴隠晦阴私。玄武防盗贼之侵凌，太常有酒食之筵会。白虎主死丧之道路，天空主欺诈之逃亡。」

**limitation**：天将/类神定位只是「取哪个天将/类神为分析对象」，**不得由天将名直接定吉凶**——须看其旺相休囚、所临地支、所乘神煞、三传位置（如「求财青龙要乘旺相气临旺相乡」，落闲地则「求财难矣」，六壬大全:1872）。
