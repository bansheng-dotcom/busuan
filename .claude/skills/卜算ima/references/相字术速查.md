# 相字术（测字）速查

> 出处：《测字秘牒》（清·程省）卷一「测字十法」、卷二「心易六法」、卷三「测字取格大法」。
> 用法：用户报字/写字测事时，先按「测字十法」拆字形，再按「心易六法」取义，最后「取格」定吉凶。
> 铁则：本表是结构化判定层 + 出处指针，拆字断语仍须 search_txt.py《测字秘牒》原文佐证；缺原文就明说「依测字法推演，非直接引文」。测字靠触机与师传，「神而明之存乎其人」，不承诺必然。

## 一、测字十法（字形拆解）

| 法 | 操作 | 例（原文） |
|---|---|---|
| 装头 | 添笔于字首，如神龙见首 | 戊→茂、日→春、早→章 |
| 接脚 | 添笔于字脚，如人举足 | 采→悉释番、立→产童、千→秀壬 |
| 穿心 | 字画端正而从中穿入数笔 | 文→吏、月→舟用冉、昌→量 |
| 包笼 | 字全体不动，以笔周围包裹 | 玉→宝、贝→遗测、矢→族 |
| 破解 | 劈破、解拆字之体段 | 行→术衙衍、辛→章、共→莫黄 |
| 添笔 | 添以补不足 | 唯→难、王→玉全旺、才→财 |
| 减笔 | 减以损有余（非事当理正不可用） | 混入摘字法则非 |
| 对关 | 专取头足首尾，关开门闭 | 头尾阖之如门闭、分开如门开（字中第一要义） |
| 摘字 | 摘字中一二笔画以断 | 借旁人言语、万物影响 |
| 观梅 | 不依程式，心镜光明、随物洞照 | 邵子心诀，至精之诀 |

- 十法总纲（原文）：「字从太极出，各具首尾，各有结构。测字之法不离羲画之理……因其所问之事而推之，据吾所触之几而断之。」
- 有物之字观梅/相字随机应变；无物之字审来意 + 字到时上下左右远近之影响，借而用之，否则拆字。

## 二、心易六法（六书取义）

| 法 | 操作 | 例（原文） |
|---|---|---|
| 象形 | 以字象物、以物象字、以字象字、以意象字 | 乙似鱼钩、弓似蛇；烟（因风吹火） |
| 会意 | 合字形之意成象 | 淋=楚汉争锋主口角；霏=长虹截雨主阻隔；蜃=飞龙破蛰主权柄 |
| 假借 | 借四时/人事/事物为用 | 旦借春、千借夏、甲借秋、夕借冬；立逢人借位、遇水借泣 |
| 谐声 | 借同音字取义 | 倒到、秤称、桃逃、梨离、莺（阴）主天阴 |
| 指事 | 因事即断，审情性、察动静、明踪迹 | 内分十法：观人/察色/辨言/辨事/察墨/辨纸/观时/相机/正论勿好奇/言语不可杂 |
| 转注 | 一字多义多音，随机应变 | 为（平/去）、行（蘅/杭/沆/慎）、王（平/旺）、长（场/障/掌/仗） |

## 三、测字取格大法

- 一字之来，用一语判之，谓之取格。
- 法先详**五行生克**，次观**六神动静**；五行相生、六爻安静则取吉格，否则凶格。
- 断语出经入史，字字珠玑，方为不传之秘。

## 三·五、六神主事（测字取象）

> 出处：《测字秘牒》卷三取格实例（六神散见「青龙得水」「朱雀敛翼」「勾陈发动」「白虎脚」「玄武主小人」等）。六神主事与六爻六神一致。

| 六神 | 主事（测字取象） | 实例佐证（《测字秘牒》） |
|---|---|---|
| 青龙 | 喜庆、贵人、得水、升迁、生机 | 「青龙得水」 |
| 朱雀 | 口舌、文书、音信、是非 | 「朱雀敛翼，先有一半，欲告无言」 |
| 勾陈 | 牵连、田土、五鬼、发动 | 「勾陈五鬼」「勾陈发动」 |
| 螣蛇 | 虚惊、缠绕、怪异、梦魇 | 「枭神头、白虎脚、勾陈身、螣蛇尾」（凫字四凶齐犯） |
| 白虎 | 凶伤、血光、孝服、争斗 | 「白虎脚」（凫字断官司不利） |
| 玄武 | 盗骗、暗昧、小人刁唆、私情 | 「玄武主小人刁唆」（公字断合伙分账有小人） |

- 吉凶向：青龙多吉、朱雀主口舌、勾陈主牵连、螣蛇主虚惊、白虎主凶伤、玄武主盗骗——测字时按所问之事对应。

### 古人相字（谢石测字，出处《梅花易数》卷五）

- 谢石测「春」字（原文）：「书一『春』字命相。石奏曰：秦头太重，压日无光。上默然。时秦桧弄权，适忤桧，竟贬之边地。」——拆法：春字上「𡗗」为秦头，下「日」为君象，秦头蔽日主权臣蔽主。出处 `txt\[易藏] 梅花易数卷四五相字术.txt`。
- 古人相字尚有测「因」「串」「也」「酉」「问」「杭」诸例（分合/围困/重叠/加笔/减笔/内外/上下取义），历代字书纪事互见，本库未收文言原文，断时按《测字秘牒》测字十法类推。

## 四、断法要点

1. **先问所测何事**——字同、事不同、断不同（原文「神不变，事不同，断就不同」）。
2. 一字/二字有专门规则：一字看左右笔画阴阳；二字一字上卦、一字下卦（参见 `三要十应速查.md` 第四节的字占命令，或原文「一字占至十一字占」）。
3. 转注定音以应事：如「临」字问病，读去声则断「临丧」不吉；「王」字问求财，读去声则断「旺相」。
4. 测字重触机，忌死搬；一事一测，不反复。
