# 六爻断卦内核（王虎应式 · 推理纪律）

> 本文件是六爻断卦的**推理流程与裁决次序**，不是术语表（术语/用神速查见 `liuyao_yongshen.md`，象法见 `scripts/libs/liuyao_xiangfa.py`）。
> 借鉴 `参考项目/liuyao/`（zhishengyk/liuyao）的 `reasoning-kernel.md`，出处为王虎应《六爻预测自修宝典》《六爻分类占验技法》《卦例说真》及本人答疑主线。
> **机械层已由 `scripts/libs/najia.py` 落地**（tests 锁定）：旬空、伏神、月破、日冲、化进/化退。本文件管「装卦之后怎么断」。

---

## 总纲三句话

1. **卦答所问。** 先把问题锁死，答案只落在被问的维度上；卦里多出的信息是旁白，不许抢答。
2. **主干定吉凶。** 一切围绕用神：看日月与卦中各爻对用神的作用。用神取错，满盘皆错；六神、大象、口诀都是枝叶，不许推翻主干。
3. **状态不是删除键。** 空亡、月破、入墓、合绊是"条件"不是"没有"。每个关键爻分三层记：现在有没有力、象上表达什么、何时兑现。

## 固定流程（八步，不许跳步，不许先有结论再找证据）

### 一、审问
- 把原问拆成维度：事件成败／对象状态／本人得失／原因／应期，各占各的互不顶替。
- 记四个属性：一次性事件还是阶段状态；主问还是兼问；初占还是复占；有无时限。
- 兼问降级处理，不套专测该事的最重断法；复占不多数表决。问题没锁清楚，不进入取用。

### 二、扫盘（只标事实，不下结论）
- 标出：旬空、月破、日冲（暗动/日破候选）、明动爻及本位变爻、伏神位置、明显冲合墓结构（`najia.py` 已机械输出前五类）。
- 取用完成后，与主线无关的异常标记停止跟踪——不给每个凶象都安排戏份。

### 三、取用
- 按事项分工取主用神（分工表见附录一）。主用神承载所问结果；辅助爻弱不否定主用神，辅助爻旺也不替主用神报成功。
- 不凭持世六亲直接断吉凶（"财持世克文书""子孙持世剥官"是辅助信息，不是结论）。
- 用神两现：先取动，再取空破，再看冲合，再看临世应，再看离世应远近，最后爻位六神。
- 用神不现才找伏神；显爻已有主线时，伏神只作补充信息。
- 角色由「爻位＋原问＋盘面」共同确定，不凭象义硬指派。动爻是应爻，先读"对方"再读六亲。

### 四、日月定根
- 月建、日辰对用神的生克冲合分别记录，不折算成分数；太岁、时辰默认不进旺衰。
- 暗动要审定：静爻有气（临月、得生扶、得动爻生、与月合）遇日冲才算暗动；休囚遇冲是日破。

### 五、动爻看趋势
- 动爻是事机，读全链条：谁动（现实角色）→ 化出什么 → 作用于谁。
- 变爻只反馈本位动爻（回头生克、进退、自合），**不跨位作用**。
- 用神自身发动，看本位变爻定变化方向；元神忌神发动，看本位变爻定其力增减。
- 独发先判功能：报应期／说原因性质／以象定吉凶／占此应彼，不先套五行生克硬判。

### 六、审有效作用（每条作用问两句话）
1. **与本题有关吗？** 主体、对象、事项、时间尺度对不上，这条关系出局。
2. **现在真有力吗？** 查制约条件：合绊、空破、入墓、贪合忘生忘克、回头生克、化进退（细则见附录二）。

配套纪律：**分三层看**（有力/象意/何时兑现，互不顶替）；**生克分方向**（他生我 ≠ 我生他）；**链条逐节验**（中间爻有力、每节走得通、终点受得起，链才成立）。

### 七、综合定吉凶：四层查完，落到用神
- 月、日、动爻、本位变爻四层查完，看最终落到用神身上的是什么：得生扶、受克有救→成；受克无制、无根生扶不起→不成。不摆两边掂量，追一条链：克用神的有没有被解掉，生用神的能不能生效。
- 忌神发动先看有没有被制服（被日月除根、被合绊、化退化破）：有制服克落不实；无制服而力大才是真凶。
- 元神是用神之根：用神再旺，元神空伏死绝、飞神克伏、根已断，事亦不成。元神独发是例外（神兆机于动）。
- 世爻必查，但普通世旺世弱不单独投票；世本身是用神、世动、世空破，或事项明看世应时才提高权重。
- 六合六冲、游魂归魂、三刑三合、卦名卦宫等整体信息只修饰过程性质，不单独定成败（见附录三）。
- 定程度：有根、受克有救，优先解释为受损、延迟、反复，不直接拉满到最坏；无根、克多生少、救援失效才断重。

### 八、最后取应期
- 应期线索必须来自主线（决定吉凶的爻和条件），旁支的空破不许拿来报日期。
- 找"当前最卡用神的条件"，问它何时解除或兑现：空待出空冲实，破待实破/合破/出月，合绊待冲开，墓待冲，化进退化待填实，伏神待冲伏/冲飞/逢值。
- 近事优先日时，远事优先月年；多条规律指向同一时间把握才大；没有明确触发条件不强报日期。

## 十条禁令（错题本）

1. 不凭持世六亲断吉凶。
2. 不凭象义硬指派角色——爻位先于六亲扩展义。
3. 不把月破、旬空当否决键。
4. 不用"六冲必散、六合必成"一句话定成败。
5. 不数吉凶象条数投票——看四层作用落到用神身上的结果。
6. 不用应期层信息（破、空、出月）推翻吉凶方向。
7. 变爻不跨位生克；旁爻不生克变爻。
8. 用神不现才找伏神，伏神不与显爻平权。
9. 大象、六神、口诀附和主干，不替代主干下结论。
10. 复占不多数表决，兼问不套专测重法。

### 用神多现的取舍
同六亲两现，按序取"有特殊意义"的那个：一动一静取发动者 → 同静取旬空月破者 → 再看逢冲逢合 → 再看临世临应 → 再看离世应远近 → 地支仍同用爻位/六神/角色消歧。非死排序，一空一破、一动一空可兼看，但要分清各爻承担结果/应期/细节，不双倍计票。

### 用神不现与伏神
- 本卦有相应六亲先取显爻；**用神不现，才到本宫找伏神**（`najia.py` 已自动标出伏神位置与飞神）。
- 伏神作主用后单审：日月旺衰、空破、有无元神、飞神对伏神的生克。飞生伏、伏克飞为有利；伏生飞为泄；飞克伏为不利。
- 飞神空亡、月破或被日月制服，伏神易出（"空下伏神，易于引拔"）；飞神旺相压住，纵旺也待冲飞冲伏才出。

### 生克方向与好处流向
他生我 ≠ 我生他，应生世 ≠ 世生应。求财升迁等事项：用神发动反去生应而不归世，为"无情"，好处流向他人。测自己的事，主用神静临应爻且与世无生合，先问好处是不是落在他人身上。

## 附录二：爻的状态细则

每个关键爻、每条作用都**分三层看**：①现在有没有力 ②象上表达什么 ③何时兑现。只有衰、破、无气、安静、受克叠加才判当前无力。

- **旬空**：空则暂避生克；旬空发动即可起作用，旺相空爻也有力。出空、冲实是兑现条件，不是吉凶反转。
- **月破**：月破爻旺动或得生扶也可有力；月破 ≠ 无效。月破与回头生克并存时，回头生克定吉凶方向，月破管应期。修复：实破（逢值）、合破、出月。
- **入墓**：吉凶的墓主要是日墓、动墓、化墓；月墓通常只取象。入墓是减力受限，不等于失去生克权。冲墓冲出可解。
- **合**：月合通常论合旺（看生合克合）；日合默认合绊；被有效动爻合→合绊候选，原有生克暂停，冲开恢复；本位动爻与变爻合→自合迟滞，只在本位处理。
- **冲**：先分来源（主卦六冲/变卦六冲/月建冲=月破/日辰冲=暗动日破/动爻冲静爻/本位变爻冲=反吟），再分功能（冲散/冲开/冲动/冲破/冲出）。同一地支相冲，来源事项不同结果相反。
- **暗动与日破**：静爻有气（临月、得生扶、得动爻生、与月合）遇日冲→暗动；休囚被月克伤再遇日冲→日破。`najia.py` 标"冲"，暗动/日破据此+旺衰判。
- **化进化退**：旺相动爻化进乘势而进；休囚化进先记趋势待得时；化退而动变皆旺，近事可旺而不退、远事渐退。失物/行人/已分手者，"退"可表回返、"进"反表越走越远。`najia.py` 已标进神/退神。
- **贪合忘生与断链**：连续相生只当候选链逐节验，中间爻被合住链就断，冲开恢复。
- **回头生克与化破化绝**：变爻只对本位动爻回头生克，不跨位。用神化回头克，兼看变爻自身状态。
- **独发**：高信息量结构，先判功能（报应期/说原因/以象定吉凶/占此应彼）。
- **过旺过弱**：过旺需日月共同生扶拱比＋卦内继续增力才成立，再生扶反不利；普通无根、月破、空亡不得直接升级成极弱反断。
- **长生十二宫**：长生沐浴胎养主要"辨意"（性质阶段部位），主吉凶仍以日月、动静生克为骨架。生与墓可同时成立。

## 附录三：大象结构与应期

- **六合六冲**：非全局"合吉冲凶"。主卦/变卦六冲加强反复、分散、不安定；六合变六冲是"合处逢冲"，落点在事情后续（成了之后不稳），不推翻所问之事。事项专门语义：近病逢冲愈、久病逢冲危；跳槽六冲反吉六合牵绊。
- **游魂归魂伏吟反吟**：游魂=不稳向外，归魂=归返；伏吟=停滞痛苦；反吟分爻反吟（本位动变相冲，权重高）与卦反吟（低权重"反复"修饰）。都只附和用神。
- **三刑 / 三合局**：用神生克为重，三刑为轻，只凭三刑不断吉凶。三合先审与用神是否相关，成员需日月/明动/变爻/暗动参与，普通静爻不凑局；成局≠强局，最后判对用神是生克助旺还是只表多人合作之象。
- **隔山化爻**：只用于辨意，不定吉凶。

### 应期取法（先吉凶后应期）

| 主线状态 | 应期线索 |
|---|---|
| 用神安静 | 逢值、逢冲 |
| 用神发动 | 逢值、逢合 |
| 靠元神成事 | 元神逢值逢合，或元神空破解除之时 |
| 被忌神所坏 | 忌神逢值应凶；有救则找忌神被克/冲去/入墓之时 |
| 用神/元忌空 | 出空、冲实 |
| 用神月破 | 实破、合破、出月 |
| 入墓、合绊 | 冲墓、冲用、冲开 |
| 化进、化退 | 逢值、逢合、冲开、填实 |
| 伏神 | 伏神出现、冲伏、冲飞 |
