# 射覆 / 测物 · 特征画像法（借鉴 henrryjoke/shefu）

> 原则：**「AI 是画师不是鉴定师——刻画特征，命名权交给玩家。」**
> 射覆 / 测物 / 测动态，一律输出「特征画像」，**不押具体物名**。这是「降分辨率 + 给候选」的落地形态，直接根治「猜具体物」翻车（2026-10-08 番茄酱教训）。

## 六维度画像

| 维度 | 问什么 | 示例 |
|---|---|---|
| 材质 | 金属/木/水/液体/布/纸/塑料/玉石… | 「糊状 / 液体」 |
| 形态 | 圆/方/长/扁/无定形/双体对称/框状… | 「无固定形状」 |
| 功能 | 食用/书写/照明/计时/装饰/容器/开合… | 「食用 / 调味」 |
| 结构 | 中空/实心/铰链/分层/开合… | 「中空」 |
| 颜色 | 红/白/黑/青/黄/杂色/金银… | 「红色」 |
| 尺寸 | 手持/桌面/大型/微型… | 「手持级」 |

## 置信度三档

- 🟢 高：本卦/用卦主象直接给出，且多信号一致。
- 🟡 中：单一信号，或需互卦/变卦/月建补充。
- 🔴 低：无映射记录，标「需类象库 / 信号无映射」。

## 输出模板

```
🔬 特征画像
  材质 🟢/🟡/🔴 …
  形态 …
  功能 …
  结构 …
  颜色 …
  尺寸 …
💡 候选参考：材质+形态+功能 top 值拼接（候选类别，不点名；`shefu_portrait._fmt` 已自动生成）
结束语：以上是根据卦象展开的特征画像，并非确定性结论。
```

## 与四段式的关系（强制：画像＝叠加非替代）

> **画像不是完整输出，是「断语卡片」**——必须嵌入四段式②③，外层四段式 + 三级标注 + 趋避 + 应期 + 一小步 + 免责 + 白话层照旧。**只贴画像不套四段式 = 不合格**（review.py 仅 1/7）。金样例如下（实测 review.py 7/7 通过）：

```
① 起卦信息：梅花易数·时间起卦，本卦泽火革（离下兑上），动爻初爻，变卦泽山咸。问事：射覆，测对象手中何物。

## ② 排盘结果〔盘面事实〕
本卦泽火革（上兑金、下离火）；互卦天风姤；变卦泽山咸；动爻初爻（离火变艮土）；体卦离火、用卦兑金。
🔬 特征画像（命中信号 2/2）
  颜色 🟢红赤/紫 🟡白/银   材质 🟢干燥/有壳 🟡金属
  形态 🟢中空/丽 🟡带口    功能 🟢火/电/屏幕 🟡电池发热
💡 候选参考：干燥有壳 + 中空 + 火电屏幕（候选类别，非点名）

## ③ 断语〔规则推演〕
- [原文]《说卦传》离为火、为电、为目、为雉；兑为泽、为口、为毁折。
  · 术语解读：离是「外实内虚、中空明丽」火象，兑是「开口、缺」金象；两象合 = 中空有壳、开口、带火光之性。
  · 问事解读：落到你测的东西——大概率中空带壳、与「电/亮/屏幕」相关，颜色偏红或银白。
- [规则推演] 体用离火生兑金（体生用，泄气）；动爻离火变艮土，艮为果蓏、为手（R-MH-05 变卦式八则）。
  · 术语解读：体生用 = 泄气；变爻艮主「手持、壳、止」，故物偏「手持、中空带壳、发光发热」。
  · 问事解读：偏向小型电子配件、打火机、带壳坚果/蛋类，不点名。

## ④ 结论〔现实建议〕
[主观推断] 吉凶总断：射覆即验，无吉凶，只出候选——中空、有壳、开口、带电亮一类。
应期：射覆即验，无应期。
趋吉：往「中空有壳、与火电相关」方向猜，优先小电子/发热发光类。
避凶：勿死咬单一物名；画像非确定结论，猜不中属正常，靠复盘校准。
今日可行的一小步：请对方揭晓，记下命中的维度，回填类象库校准。

```

## 交互：渐进精化（上限 5 轮）

1. 先出画像 v1 → 玩家反馈「对了 / 偏了 / 接近但 XX」。
2. 对 🟡 维度提 1-2 个二选一问题，用互卦 / 变卦 / 月建等未用尽信号源补充。
3. 每轮更新画像，标变化。
4. 揭晓后复盘：命中 / 偏移 / 遗漏各维度 → **自动调用** `python scripts/libs/shefu_portrait.py update '{"命中":[{"类":"天将","名":"朱雀","维度":"颜色","值":"赤/红"}],"错误":[...]}'` 回填类象库 confidence（命中 +0.1、错误 -0.1、validations+1）。

## 铁律

- 不判断吉凶、不替玩家命名。
- 禁用：一定、必然、大吉、宜、忌、应该。
- 鼓励：可能、或许、呈现…态势。
- 结束语：「以上是根据卦象展开的特征画像，并非确定性结论。」
