## 规则推演（考据层 + 白话两层）
- **三吉门方位**：生门在坎（北）、休门在乾（西北）、开门在兑（西）。[规则推演 R-QM-01] 出门办事宜朝北/西北/西三吉门方。
  → **术语解读**：奇门把「门」当吉凶开关，八个门各管一方、各有吉凶；「生门、休门、开门」是三个吉门＝办事顺、有门路的方向。
  → **问事解读**：落到你问的「出门办事」——往北、西北、西三个方向走最顺，事好谈成。
- **凶门**：死门在离（南）、惊门在坤（西南）、伤门在艮（东北），此三方宜避。[规则推演 R-QM-01]
  → **术语解读**：「死门、惊门、伤门」是三个凶门——死门主绝、惊门主惊扰、伤门主伤害，对应南、西南、东北三个方向。
  → **问事解读**：办事别往南、西南、东北去，容易受阻、出岔子。
- **值符值使**：值符天英在艮、值使景门在巽；值使景门主文书/考试/广告。[规则推演 R-QM-03]
  → **术语解读**：值符、值使是本局当值的「主事星」和「主事门」，值使「景门」专管文书、考试、宣传、广告这类事。
  → **问事解读**：如果你这趟是文书、签约、考试、广告类的事，东南方向能借上「景门」的文书之力。
- **天芮·禽同宫**在震——天芮主疾病、天禽主祭祀，天芮凶星不可漏断（SKILL.md 明示）。[规则推演 R-QM-02]
  → **术语解读**：天芮是主疾病的凶星、天禽是主祭祀的中性星，两者同落在震（东）方。
  → **问事解读**：若事涉健康/医疗则加倍留意东边；不是医疗事就别硬往凶上套。

## 现实建议（考据层）
- 办事谈事宜朝**北方（生门）或西北（休门）**，忌朝**南（死门）**。[主观推断]
- 若为文书、签约、考试、广告类事，值使景门在巽（东南），可借景门文书之象。[主观推断]
- 震宫芮·禽同宫，若事涉健康/医疗则加倍留意，非医疗事不硬套凶。[主观推断]

## 结论（考据层 + 白话收口）
- 吉凶总断：中平，看方位取用——北/西北/西利，南/西南/东北宜避。[规则推演]
- 趋吉：行动择北、西北、西三方，选吉时（此局须再核五不遇时/时干入墓）。[主观推断]
- 避凶：忌南（死门）、西南（惊门）、东北（伤门）。[主观推断]
- 应期：奇门重方位时机，主「择时择方」而非固定应期。[主观推断]

**白话收口**：这局不看「成不成」，看「往哪走、什么时候走」。出门办事往北、西北、西三个方向走最顺，别往南、西南、东北三个方向去。文书、签约、考试类的事，东南方向能借上力。

**今日可行的一小步**：把今天要见的人、要去的点，都往北/西北方向约，南边的安排往后推。
