# 装饰素材说明

以下文件位于 `public/assets/decor/`，为本站绘制的同源风格矢量图，用于首页 PC / H5 视觉：

| 文件 | 用途 |
|------|------|
| `yin-yang.svg` | 太极徽标 |
| `bagua-frame.svg` | 后天八卦框 |
| `wuxing.svg` | 五行相生图 |
| `star-map.svg` | 紫微垣星象示意（视觉衬景，非古籍原图扫描件） |
| `paper-noise.svg` | 宣纸噪点纹理 |

说明：外网维基文库 / Wikimedia 素材因网络超时未能稳定拉取，故改为本地矢量，避免版权与加载风险。星象图仅作研习站视觉，不替代卷一原文。
