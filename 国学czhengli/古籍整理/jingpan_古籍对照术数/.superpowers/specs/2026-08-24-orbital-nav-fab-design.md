# 环绕导航浮球（OrbitalNavFab）

日期：2026-08-24  
状态：已批准（对话确认）

## 背景

右下角已有可拖动「頂」按钮。用户希望在同区域再增加一个圆形浮球：可拖动；点击后更多菜单项带动画围成一圈展开，用于快速跳转全站页面。

## 目标

1. 新增始终可见的圆形主球，可拖动，视觉风格对齐「頂」（金边、宣纸底、单字）。
2. 点击展开：全站导航子项以**单圈**环绕主球，带动画「环绕甩出」。
3. 点子项跳转对应路由并收起；点遮罩或再点主球收起。
4. 与「頂」**各自独立**（不合并、不替换、不做自动避让）。

## 非目标

- 不做二级再展开（典籍/工具分组二次环）。
- 不做贴边时的动态扇形避让（子项可能出屏，本次接受）。
- 不做两球磁吸/碰撞系统。
- 不引入第三方 FAB / radial-menu 依赖。
- 不改 `BackToTop.vue` 行为。

## 方案选定

新建独立组件 `OrbitalNavFab.vue`（方案 1），在 `App.vue` 与 `BackToTop` 并列挂载。

## 交互

### 主球

- 始终显示（不依赖滚动阈值）。
- 默认可拖；`sessionStorage` 键建议 `zw-orbital-nav-pos`。
- 默认位置：右下，约在「頂」默认位**上方**一球间距（避免初始重叠）。
- 主球文案：建议「盤」或「菜單」单字（实现时定一个，与站点气质一致优先「盤」）。
- 展开态：主球可轻微旋转或改为「合」态，表示可关闭。

### 拖 vs 点

- 与 `BackToTop` 相同：pointer 移动超过约 4px 视为拖动，松手不触发点击。
- 仅未拖动的 click 切换展开。

### 展开 / 收起

- 展开：半透明全屏遮罩（z-index 低于子球、高于页面内容）；点击遮罩收起。
- 子项按极坐标均分 360°，半径约 72–84px；起始角略偏上，减轻正下方与「頂」抢位。
- 动画（环绕甩出）：各项 stagger delay ≈ 25–35ms；从中心 `scale(0.4)` + `opacity: 0` 移到圆周，带约 ±90° 轻旋；单项过渡约 0.35–0.45s。
- 收起：反向、略快；跳转路由前先收起。
- 拖动主球时若处于展开态：跟随移动子项圆心，或先收起再拖（推荐**拖动开始即收起**，实现更简单）。

## 视觉

- 主球 / 子球：尺寸接近「頂」（主 44px，子约 36px）；`border: 1px solid var(--zw-gold)`；背景 `color-mix` 宣纸+金。
- 当前路由项：可用 `var(--zw-primary)` 或朱砂 `#b42318` 描边强调。
- 夜空主题：复用 `--zw-*`，保证对比度。
- `z-index`：高于页面、与「頂」（70）协调；展开遮罩与菜单建议 ≥ 80，且主球/子球高于遮罩。

## 技术约束

- Vue 3 + `defineComponent` Options-style，与项目一致。
- TypeScript 禁用 `any`。
- 不新增 npm 依赖；动画用 CSS transition / transform。
- `teleport` 到 `body`，与「頂」一致。

## 验收标准

1. 主球可拖，同会话刷新后位置恢复。
2. 点击展开见环绕甩出；再点主球或遮罩收起。
3. 点子项进入正确路由并收起。
4. 拖动不误触跳转；与「頂」可同时存在、互不改对方逻辑。
5. 宣纸 / 夜空两主题可读。
