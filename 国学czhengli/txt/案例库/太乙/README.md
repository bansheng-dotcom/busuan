# 太乙神数 · 案例库说明

> 本目录与六爻/大六壬不同：**太乙无古籍占验案例**（《太乙金镜式经》《太乙秘书》《太乙淘金歌》《太乙局》《太乙人道命法》均为算法、格局、口诀、命法书，无「某日占某事→应验」的断案类记录）。

## 断卦参照（替代案例库的可用依据）

太乙断卦不靠「相似案例」，改靠三样：

1. **规则函数**（`scripts/libs/rules.py` R-TY-01~04）：`taiyi_suan`（算数吉凶）、`taiyi_zhuke`（主客胜负）、`taiyi_geju`（掩迫关囚击格对）、`taiyi_luogong_wangshuai`（落宫旺衰）。
2. **速查表**（`references/太乙速查.md`）：主客算/主客胜负/凶格/落宫旺衰/三才五福，每格标典籍出处。
3. **典籍原文**（Grep 佐证）：`[易藏] 太乙金镜式经.txt`（推多少以占胜负、推三才、推孤单）、`太乙秘书.txt`（掩迫关囚击格对）、`太乙淘金歌.txt`（求主客算）、`太乙局.txt`（击迫）。

## 后验案例

太乙现代占验案例在技能目录 `cases/taiyi/`（用 `cases/manage.py new` 沉淀，后验回填），不随本库上传。`case_search.py` 检索本目录时，太乙无案例会如实返回空，断卦时明说「太乙无古籍占验案例，本断为规则推演+原文佐证」。
