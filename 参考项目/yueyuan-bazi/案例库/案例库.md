# 命理案例库（第 5 步 · 详细版）

> **用途**：LLM 分析时的「参照示例」，让结论有真实依据；**不作训练数据**，单个案例结论不视作普适真理。
> **定位**：本库为**真实命例参照**；`tests/cases/` 为虚构测试盘，二者不得混用（虚构盘不得作为分析依据引用）。
> **状态**：**待核对**——命盘与大运已引擎验证 / 干支自洽验证（2026-08-14）；命理解读与生平细节基于通行本与网络解读整理，**未与古籍原文逐字核对**，使用时应提示来源层级（古籍原文 > 现代名家注本 > 网络解读）。
> **结构**：每例含「命盘 / 命主生平 / 格局判定 / 用神病药 / 大运应验 / 六亲 / 原文出处 / 流派标注」。
> **原则**：只选被多部命理著作反复引用的公认经典命例；大运以原文记载为准（非本引擎重排）；六亲栏仅在有可靠记载时填写。
> **来源层级与八字争议**：命例八字按来源分级——「名家自批 / 著作原文 > 现代名家注本 > 网络解读」；名人命例（如阎锡山、商震）存在出生时辰版本争议，凡有争议处已在案例内显式标注，**不采信网络排盘工具自行推断的版本**。

## 案例 1：阎锡山（七杀格 · 食神制杀 + 杀印相生）

### 命盘
- **八字**：癸未 辛酉 乙酉 丁亥（纯阴八字；⚠ 时柱另有「丁丑」一说，本库取《子平真诠》徐乐吾注「丁亥」版）
- **大运**：庚申(10) 己未(20) 戊午(30) 丁巳(40) 丙辰(50) 乙卯(60) 甲寅(70) 癸丑(80)
- **性别**：男

### 命主生平
阎锡山（1883–1960），山西五台人，晋系军阀首领，民国陆军一级上将，长期割据山西，被称为「山西王」。

### 格局判定（完整推理）
- 乙木生于酉月，辛金七杀当令且透干 → **七杀格**；
- **三重七杀围克**：月柱辛酉 + 日支酉金，年支未土又生金，杀旺身弱至极；
- **制化两端**：时干丁火食神制杀（食神制杀）+ 年干癸水偏印透干、时支亥水化杀生身（杀印相生）；
- 徐乐吾原断「身、煞、食三者均旺，极等之贵」——乙木得亥未之根、丁火秋木盛而有力。

### 用神病药
- **用神**：火（食神制杀，化煞为权）、水（印星化杀生身）
- **病**：七杀过旺、金多木缺；食神丁火坐亥受克、癸水遥隔，制化不均

### 大运应验（逐运）
- **早年庚申运**（杀重身轻）：幼年丧母、生活艰辛、14 岁辍学、投资失败躲债
- **中年南方火运**（己未～丙辰，28–55 岁）：火地强化丁火食神，食神制杀成贵，任山西都督、执掌一方
- **晚年东方木运**（乙卯～甲寅，66 岁后）：木助身抗杀、金木交战加剧，权柄渐失；己丑年（1949）太原解放后随国民政府迁台

### 六亲
幼年丧母（庚申运印证「杀重身轻」）；枭神夺食，家庭助力有限。

### 原文出处
《子平真诠》论杀篇，徐乐吾注引阎造（作「辛金透、丁火刚、秋木盛」三者皆备之例）。现代多家命理分析（suanzhun.net、aizeri.cn 等）详述生平与大运对应。

### 流派标注
- 子平法（格局派）：七杀格、食神制杀 + 杀印相生
- 分歧：有从格论者以乙木极弱、根气尽泄，主张从杀/从势——**流派分歧，并列标注**

## 案例 2：水木从儿格（《滴天髓》顺局篇）

### 命盘
- **八字**：丁卯 壬寅 癸卯 丙辰
- **大运**：辛丑 庚子 己亥 戊戌 丁酉 丙申（起运年龄原文未载）
- **性别**：男

### 格局判定（完整推理）
- 癸水生寅月（孟春），地支寅卯辰会东方一气，四柱无金（印），日主有泄无生 → **水木从儿格**；
- 时干丙火为用（食伤生财，「儿又生儿」）；
- 病在月干壬水（劫财），药在年干丁火（丁壬合化木，反生丙火）——有病有药。

### 用神病药
- **用神**：火（丙火财星）
- **病**：壬水劫财；**药**：丁火合壬化木

### 命主生平与大运应验
- 任铁樵原批：早登科甲，置身翰苑，仕至封疆；申运木火绝地，不禄（卒）。
- 元敏逐运详解：初运辛丑，辛金生身、丙丁回克，幼年多让父母操心；庚子运庚金透而子水化泄；己亥运亥寅化木、己土克水，稍顺；戊戌运戌卯合向火、戊土克壬水，好运；丁酉丙申运丙丁透干喜庆，但西方金地防灾。

### 原文出处
《滴天髓阐微》顺局篇，任铁樵注（guoxue3000 / 元敏滴天髓 513 例全注）。

### 流派标注
- 子平法（从格体系，对应 biange.md 的 FROM 状态）
- 现代元敏注指出此造有「临界八字」之象，随运在正格与从儿格间转换——标注为竞争假设。

## 案例 3：丙火建禄格（《滴天髓》地支篇 · 破格对照）

### 命盘
- **八字**：庚寅 辛巳 丙寅 辛卯
- **大运**：壬午 癸未 甲申 乙酉 丙戌 丁亥
- **性别**：男

### 格局判定（完整推理）
- 丙火生巳月（孟夏）→ **建禄格**；
- 地支两寅一卯、巳火乘权，引出寅中丙火，身旺；天干庚辛财星皆虚浮无根 → 财被比劫夺（群比争财）；
- 建禄格最忌身再旺、喜财官透而有根，此造财星无根、禄刃相逢 → **破格**。

### 用神病药
- **用神**：财星（庚辛金，但虚浮无根，不得力）
- **病**：身旺比劫夺财、财星无根

### 命主生平与大运应验
- 任铁樵原批：初运壬午癸未无根之水，泄金气、助旺火，财之气克泄已尽，祖业虽丰、刑丧早见；甲运刑妻克子、家计萧条；一交申运，天干浮财通根，如枯苗得雨，勃然而兴；乙酉十五年财数倍于祖业，出外经营得财十余万；丙戌运丙子年，得风疾不起（卒）。

### 原文出处
《滴天髓阐微》地支篇，任铁樵注；琴鹤堂国学解析（建禄格破格条件）。

### 流派标注
- 子平法（格局派）；琴鹤堂引《三命通会》论十干禄作补充
- 注意：此例为「破格对照」，用于说明建禄格忌禄刃相逢、喜财官有根——反面教学案例。

## 案例 4：刘澄如命（偏财格 · 财旺生官）

### 命盘
- **八字**：壬戌 己酉 丁丑 甲辰
- **大运**：庚戌(6) 辛亥(16) 壬子(26) 癸丑(36) 甲寅(46) 乙卯(56) 丙辰(66) 丁巳(76)
- **性别**：男

### 命主生平
南浔刘澄如（1862–1934），进士及第，赐花翎三品衔、候补五品京堂，文商两宜、成就非凡。

### 格局判定（完整推理）
- 丁火生酉月，辛金偏财当令，月日丑酉半合财局，年戌时辰食伤生财 → **偏财格**；
- 财旺生官：壬水正官透年干，格神完备；
- 病在月干己土食神损官，药在时干甲木（印）合去己土、去病存官，官印有情 → 成格。

### 用神病药
- **用神**：甲木（印，去己土食神护官）、官星壬水
- **病**：己土食神损官

### 大运应验（逐运）
- **辛亥、壬子运**：官星有力、印得生，学业大成——中秀才、中举、进士及第
- **癸丑运**（36 岁）：土金两旺水浊，偏财旺极崩而入墓——1899 年父去世；七杀杂官，弃官从商
- **甲寅、乙卯运**：印星有力去食神，官印有情，文商两宜、成就非凡
- **丙辰运**（66 岁）：辰戌冲损甲木之根、丙丁入墓，1934 甲戌年两戌冲两辰——去世

### 六亲
1899 年父去世（癸丑运「偏财旺极崩而入墓」）。

### 原文出处
《子平真诠·徐氏评注》（刘澄如命造）；多亮命理分析详解大运与生平对应。

### 流派标注
- 子平法（格局派）；多亮批注强调「格局成败看官印有情，不唯日主旺衰」——对旺衰派有辨正意义。

## 案例 5：范太傅命（正官格 · 正官佩印）

### 命盘
- **八字**：丁丑 壬寅 己巳 丙寅
- **大运**：辛丑 庚子 己亥 戊戌 丁酉 丙申
- **性别**：男

### 格局判定（完整推理）
- 己土生寅月，甲木正官当令 → **正官格**；
- 透丁火（印）、壬水（财）；此造己土身弱，壬水财星耗身又生官助克，故财为忌；妙在**丁壬合**使财去官清，忌神变喜神；
- 丙火透出制伤护官（巳丑拱酉、金气偏旺，巳中庚金伤官，丙丁解之）→ 官清印正、同宫并旺，大贵。

### 用神病药
- **用神**：印星（丙丁火，制伤护官）
- **关键机制**：丁壬合化、财去官清

### 原文出处
《子平真诠》论正官篇（范太傅命）；徐乐吾注「官清印正同宫并旺，大贵奚疑」；现代「正官佩印」辨证文（i.ifeng.com）详解丁壬合化与巳丑合。

### 流派标注
- 子平法（格局派）
- 分歧：有论者认为此造应判「正印格用财破印」（误判辨析已澄清）——作为「格局用神变化」的经典教学案例。

## 案例 6：薛相公命（正官格 · 兼用财印）

### 命盘
- **八字**：甲申 壬申 乙巳 戊寅
- **大运**：癸酉 甲戌 乙亥 丙子 丁丑 戊寅 己卯 庚辰
- **性别**：男

### 命主生平
宰相（「相公」为古代一品官阶称谓）；原文未说明朝代，具体生平无从查证。

### 格局判定（完整推理）
- 乙木生申月，庚金正官本气**未透**，透壬水（印）、戊土（财）→ 用神发生变化：官星用神变为「财印并用」；
- 财印并透，中以日主乙木相隔，水（印）土（财）两不相碍 → **正官格，财印两用，大贵**；
- 徐乐吾注：官印相生、财旺而不破印、官星秉令真神得用；小病在寅申巳三刑，不免刑伤贵气。

### 用神病药
- **用神**：财星戊土（生官）、印星壬水（护官），财印两不相碍、两全其用
- **病**：寅申巳三刑（小病）

### 大运应验
- 徐乐吾注：酉运七煞泄财生印最美，甲运帮身亦吉；乙亥后运北方印地，亥运逢四冲未必无风浪；戊寅运引发冲刑、动了官印财根基、天干财印交战，富贵到头。

### 原文出处
《子平真诠》论正官篇（薛相公命）；徐乐吾注 + 多亮详解 + 道楠释（eeeshu）。

### 流派标注
- 子平法（格局派）：正官格财印两用
- 分歧：有论者主张「正印格用财破印」——已澄清为对《真诠》用神变化的误读，作为「用神变之而善」的经典教学案例。

## 案例 8：商震命（七杀格 · 天地制化两立）

### 命盘
- **八字**：戊子 辛酉 乙未 丙子（⚠ 时柱另有「己卯」一说，本库取《子平真诠》徐乐吾注「丙子」版）
- **大运**：壬戌(6) 癸亥(16) 甲子(26) 乙丑(36) 丙寅(46) 丁卯(56) 戊辰(66) 己巳(76)
- **性别**：男

### 命主生平
商震（1888–1978），浙江绍兴人，国民党二级陆军上将。参加辛亥革命、长城抗战，1935 年授二级上将、任河北省主席，1949 年辞职定居日本，1978 年东京病逝，骨灰安葬北京八宝山。

### 格局判定（完整推理）
- 乙木生酉月，辛金七杀透干 → **七杀格**；
- 年干戊土财生杀，七杀强旺；
- **天地制化两立**：时干丙火伤官合杀（天）、地支两子水印星化杀（地），两不碍 → 成格。

### 用神病药
- **用神**：伤官丙火（合而制杀）+ 印星子水（化杀生身）
- **病**：七杀旺、财生杀

### 大运应验（逐运）
- **初运壬戌**：出生常人之家，幼年家贫
- **癸亥运**：走向革命事业，渐渐发迹
- **甲子运**：大利事业，步入富贵
- **乙丑运**：武贵达将军级别
- **丙寅运**（最好）：1935 年授二级上将、任河北省主席
- **戊辰运**：格局下降，1949 年辞职定居日本

### 六亲
幼年父被仇人所杀、母携儿女改嫁（未中己土偏财弱、被子水害，克父之象）。

### 原文出处
《子平真诠·徐氏评注》（徐乐吾引商造，作「辛金透、丙火刚、秋木盛」例）；多亮详解逐运与生平对应。

### 流派标注
- 子平法（格局派）：七杀格，伤官合杀 + 印化杀，天地制化两立
- 与案例 1（阎锡山）同为七杀格，可对照「伤官合杀」与「食神制杀」之别。

## 案例 9：金状元命（正官格 · 化官为印透财）

### 命盘
- **八字**：乙卯 丁亥 丁未 庚戌
- **大运**：丙戌 乙酉 甲申 癸未 壬午 辛巳 庚辰
- **性别**：男

### 命主生平
状元（金榜题名、大魁天下）。

### 格局判定（完整推理）
- 丁火生亥月，壬水正官当令 → **正官格**；
- 亥卯未三合木局，**官化为印**，乙木透干朝元，身弱转旺；
- 身旺印多，喜财损印——时干庚金财星透出，去印之弊、存官之喜 → **成格，大贵**。

### 用神病药
- **用神**：财星庚金（损印生官）
- **病**：印星过重、身旺

### 大运应验（逐运）
- **早年丙戌运**：伤官生财，家庭富裕、祖荫丰盛
- **乙酉、甲申运**（印运走财地）：财旺破印有力，顺利考上状元、名震全国
- **癸未、壬午官杀运**：官杀印身相生、身旺本忌，中年事业受挫
- **辛巳、庚辰财运**：用神到位、破印有力，终身皆贵

### 原文出处
《子平真诠》论正官篇（金状元命），徐乐吾注；李后启《看李后启算例》详解逐运。

### 流派标注
- 子平法（格局派）
- 与案例 6（薛相公）对比：薛造财官身印均衡、一生平稳；金造官化为印、文采出众，但行运受限更多——同为「化官为印」教学对照。

## 案例 10：韦千里自批造（正财格 · 身弱财旺）【现代名家 · 子平自批】

### 命盘
- **八字**：辛亥 辛卯 庚子 庚辰
- **大运**：庚寅(9) 己丑(19) 戊子(29) 丁亥(39) 丙戌(49) 乙酉(59) 甲申(69) 癸未(79)
- **性别**：男

### 命主生平
韦千里（1911–1988），浙江嘉兴人，民国命理大家，《千里命稿》作者，与袁树珊、徐乐吾并称「民国命理三大家」。1936 年西安事变后为宋美龄占六壬、批蒋介石八字断蒋无性命之忧，由此声名鹊起。

### 格局判定（完整推理）
- 庚金生卯月（仲春），木旺金囚 → **正财格**；
- 地支亥卯合木（财旺）、子辰合水（食伤生财），水木两旺、金无根气（四干庚辛虚浮无申酉禄刃）；
- 韦千里自批：**「徒多比劫而日元无气，非是真强」「身不任财，难免富屋贫人之讥」**——身弱财旺。

### 用神病药
- **用神**：印星土（生身）、比劫帮身；调候喜火（原局无火，一寒儒）
- **病**：财旺身弱、无火（无官杀调候）

### 大运应验（逐运）
- **庚寅运**：少年丧父
- **己丑运**（1929–1938，最好）：己土印生身、伤官配印，写出《千里命稿》、预言西安事变、名利双收
- **戊子、丁亥运**（1939–1958）：随局势奔波，移居香港继续命理业
- **丙戌运**（1959–1968）：香港出版《占卜讲义》等，名声大振
- **乙酉、甲申运**（1969–1988）：申酉用神根气，讲学收入不错，1988 年去世

### 六亲
少年丧父（16 岁左右）。

### 原文出处
《千里命稿·应运篇》韦千里自批造（命理史上极罕见的「大宗师自批造」）。

### 流派标注
- 子平法；韦千里自评「身弱、富屋贫人、格局不高」实为自谦——现代解读者指出其伤官配印、偏印华盖主玄学冷门学问，与命理行业高度适配。

## 案例 12：梁湘润格局休废例（财当令无印）【现代名家 · 禄命法】

### 命盘
- **八字**：癸丑 辛酉 丙子 丙申
- **性别**：男

### 格局判定（梁湘润「格局休废论」）
- 丙火生酉月，财星（辛金）当令，八字**无印（缺木）** → 梁湘润断为**「休废格局」**；
- 休废非凶命，而是「不能按表象论吉凶」——财官印调候俱佳也只作「中品平和命」；
- 常法：癸水正官透干成格，二丙合辛主中年发越、老年平凡，五行缺木（印）。

### 用神病药（梁湘润论式）
- 财当令、日主无根、无印 → 用比劫扶身不足、用羊刃正制于财亦非佳；财格最佳扶身是**印、禄**，此造缺印，故「因财引祸」。

### 原文出处
梁湘润《格局休废论》（86027.cn / 星相法卷）。

### 流派标注
- 梁湘润禄命法：独创「休废格局」「换禄」「拱夹」等实务论式，强调「日主无印 + 财当令 = 因财引祸」，与子平常法视角不同——作为现代禄命派的参照。

## 案例 13：袁树珊自批造（食神制杀生财）【现代名家 · 自批】

### 命盘
- **八字**：辛巳 丁酉 乙巳 戊寅
- **大运**：丙申 乙未 甲午 癸巳 壬辰 辛卯(1931–1940) 庚寅(1941–1950) 己丑(1951–1960)
- **性别**：男

### 命主生平
袁树珊（1881–1962），名阜，晚号江上老人，江苏扬州人，民国命理三大家之一（「南袁北韦中乐吾」），《命理探原》作者。出身医卜世家，曾为政要批命，婉拒吴佩孚、谭延闿之邀。

### 格局判定（完整推理）
- 乙木秋生（酉月），干支金重（四金）→ 身弱；
- **取干火制干金、支火制支金**，四金逢四火，木不畏金 → 食神制杀生财；
- 袁树珊自批：用神似取月干丁火，**实则在命宫甲木午火**；「惜八字缺水，科第难登」。

### 用神病药
- **用神**：火（丁火食神制杀）+ 命宫甲木午火（比劫长生资助）
- **病**：金重木衰、五行缺水

### 大运应验（自述，逐运）
- **七岁丙申运、丁亥年**：巳亥冲、申寅冲，是年八月**先母见背**
- **二十岁前乙未运**：角逐科名、研究医学，终不克如愿
- **二十一岁甲午运**：比劫帮身，学术稍进、名誉渐佳，完姻后连举二男
- **丙午年**：四月**先君弃养**，闰四月次子殇
- **三十一岁癸巳运**：壬子年生三男；癸丑年七月长子殇
- **乙卯冬**：《命理探原》脱稿（自谓日元得禄所致）

### 六亲
七岁母丧、丙午年父丧、两子先后殇（次子、长子）。

### 原文出处
《命理探原·润德堂存稿》袁树珊自批（民国命理三大名著之一，与徐乐吾《子平真诠评注》、韦千里《千里命稿》并称）。

### 流派标注
- 子平法（袁树珊自批）；与案例 10（韦千里自批）同为「大宗师自批造」，可对照两位大师的自评姿态。
