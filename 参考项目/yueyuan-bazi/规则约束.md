# 命理规则约束（给 LLM 的分析约束文本）

> 本文件是「阶段二」的规则约束部分，配合 `mingli_rules.py`（写死的确定性计算）使用。
> 用途：约束 LLM 的分析方向，让输出「有规则可依」，从根上治「照本宣科」。
> 原则：以下是**子平法**的核心判断规则。LLM 在分析八字时，必须**先套这些规则、再给结论**，不得脱离规则自由发挥、不得输出与任何八字都通用的套话。

---

## 一、旺衰综合判断（身强 / 身弱 / 中和）

`mingli_rules.py` 已算出四项硬指标（得令、得地、得生、得助），LLM 按以下权重综合定强弱：

> **确定性粗筛声明**：四项指标为确定性粗筛——「得令」用五行生克法（月支生/同 日主）；「得地」=四支藏干见比劫（未分本气/中气/余气、未计冲克合化空亡削弱）。LLM 须按 SKILL.md 步骤 1 复核根之深浅与根气受损情况后再定论，不得把粗筛结果当最终强弱结论。

**判断优先级（从高到低，定性排序，非数值权重）**：
1. **得令**（月令生扶，优先级最高——「得时不旺，失时不衰」）；
2. **得地**（地支有根，藏干见比劫）；
3. **得生**（有印星生扶）+ **得助**（有比劫帮扶），二者优先级低于得令。

**综合结论规则（粗筛起手式）**：
> **口径声明（v1.8 对齐）**：以下身强/身弱/中和判定为**确定性粗筛起手式**，最终旺衰以 SKILL.md 步骤 1 条件变量框架为准——输出「偏弱 / 中和偏弱 / 中和 / 中和偏强 / 偏强」倾向 + 程度，**禁止强行二选一**；印星成势（透干+得地+合局）时须先过 SKILL.md 步骤 1 两道闸门（日主根气、财官克耗）再定印为用/印为病。

- **身强**：得令，且得地 / 得生 / 得助中至少占一项。
- **身弱**：失令，且无根（不得地）、无生助（不得生亦不得助）。
- **中和**：得令失地、或失令得地得生助者，需结合全局具体权衡，并**明确说明理由**（哪几项强、哪几项弱）。

**禁止**：不得跳过四项指标直接给「身强/身弱」结论；不得出现「此命身强」而不说明得令/得地/得生/得助的逐项依据。

## 二、格局成败救应（《子平真诠》）

格局已由 `mingli_rules.py` 的 `ding_ge()` 定出。LLM 需判断其**成格 / 败格 / 救应**，规则如下：

| 格局 | 成格（喜） | 败格（忌） | 救应 |
|---|---|---|---|
| 正官格 | 财、印相随 | 伤官（伤官见官） | 印星制伤官 |
| 七杀格 | 食神制杀、印化杀 | 财星党杀 | 食神、印星 |
| 正财格 | 食伤生财、身强任财 | 比劫夺财 | 官杀护财 |
| 偏财格 | 同正财格 | 比劫夺财 | 官杀护财 |
| 正印格 | 官杀生印、身弱喜印 | 财坏印 | 比劫制财护印 |
| 偏印格（枭） | 财星制枭、身弱用印 | 食神（枭神夺食） | 财星 |
| 食神格 | 财星（食神生财）、身强 | 偏印（枭夺食） | 财星制枭 |
| 伤官格 | 财星（伤官生财）、印星（伤官配印） | 正官（伤官见官） | 财、印 |
| 建禄格 | 财、官 | 比劫太旺 | 官杀制比劫 |
| 羊刃格 | 七杀（羊刃驾杀）、食伤 | 财星（羊刃夺财） | 七杀 |

**判断要求**：LLM 定出格局后，必须**结合原局实际透出的十神**，判断该格是「成格」「败格」还是「有救应」，并说明依据（哪个字成格 / 哪个字败格 / 哪个字救应）。

**变格衔接（防漏判）**：本表只列正格（八格）+ 建禄/羊刃。若出现变格嫌疑（从势/专旺/化气），按 SKILL.md 步骤 2 与 references/biange.md 的 NORMAL/FROM/ZHUANWANG/HUAGQI 四态状态机裁决——先按 NORMAL 默认、出现嫌疑并列候选、判定后按该状态自己的顺势规则取用，**禁止跨状态套用喜忌**。

**制化自救闸门（v1.8 对齐）**：日主极弱、出现从格嫌疑时，**不直接判从格**——先按 references/biange.md 判据 0 查制化自救（食神制杀/印星化杀/伤官合杀/合绊护身），制化/合绊神透干得地、未被合走克损 → 优先按正格制化处理，不判从格；从格须以「制化机制被破或无可用制化」为前提。

**兼格说明**：`ding_ge()` 只输出主格（月支藏干透干取主，多神同透时取首个透出者）。多神同透时，主格由代码定，兼格由 LLM 按 SKILL.md 步骤 2 补充分辨。

## 三、用神取用原则（三模块综合）

用神取用是分析的核心，需综合三个模块，按以下优先级：

**1. 调候（《穷通宝鉴》，按 SKILL.md 步骤 4 决策树执行）**
- 先查 `mingli_rules.py` 的 `tiao_hou_yongshen()` 得到该日干该月令的调候用神（速查见 references/tiaohou-notes.md，以代码表 TIAO_HOU 为准）；
- 仅当「极端气候（冬月寒极/夏月燥极）」成立时进入 CLIMATE OVERRIDE 状态，调候才获得高于扶抑的决策权，且须依次检查五条例外（①身极弱不从时调候让位 ②从势顺势 ③专旺顺势 ④化气以化神为主 ⑤调候神虚浮无根则调候条件不成立），任一成立即退出该状态；
- 气候不极端 → 普通状态，格局/扶抑为主、调候为辅，通关、病药再其次；
- 禁止把「调候为急」写成无条件公理（仅为调候派立场）。

**2. 旺衰定喜忌（默认方向，须六维复核）**
- **默认方向**：身弱默认喜「印、比劫」（生扶）、忌「财、官杀、食伤」（克泄耗）；身强默认喜「财、官杀、食伤」（克泄耗）、忌「印、比劫」（生扶）。
- **铁则（SKILL.md 步骤 5）**：「身弱≠必喜印比，身强≠必喜财官食伤」——默认方向**必须经六维一致性（扶抑/格局/调候/病药/通关/变格）复核**，冲突时按冲突裁决规则处理，禁止跳过六维直接机械套用。
- **财官反例裁决（v1.8 对齐）**：身弱框架下财官**不一律列忌**——须显式排查三条反例路径（①财旺生官且官能护印；②印重身旺喜财损印；③官杀透而为用），排查通过则财官可为用（详见 SKILL.md 步骤 5 与 references/patterns.md 第八节）；**禁止「身弱→财官一律忌」单线推导**。

**3. 格局定用神**
- 按上文「格局成败救应」表，取该格的「成格用神」（如正官格取财印、七杀格取食神或印）。

**综合裁决规则**：
- 三模块结论一致 → 用神明确，直接采用；
- 三模块冲突（如调候要火、旺衰又忌火）→ 按 SKILL.md 步骤 4 决策树裁决（是否进入 CLIMATE OVERRIDE + 五条例外），并明确说明「当前处于哪种状态、为何该状态生效」，不得无条件「调候优先」；
- 无法定夺 → 输出「用神两难」，**列出各模块的分歧点，提示人工复核**，不得硬给唯一结论。

## 四、输出纪律（治「照本宣科」的硬约束）

1. **每一句论断必须可溯源**：要么来自排盘数据（四柱/十神/大运），要么来自本文档规则，要么来自案例库。**禁止输出无依据的套话**。
2. **先规则后结论**：先写「得令/得地/得生/得助 → 身强身弱 → 格局 → 用神」的推理链，再给结论。
3. **不确定就明说**：命理本无绝对标准（流派林立），凡有分歧或拿不准处，**明示「此处流派有争议，本判断按子平法」**，不得用「必」「定」等绝对措辞。
4. **引用案例**：分析时优先引用「案例库」中相近命例作参照，让结论有「真实依据」支撑。
