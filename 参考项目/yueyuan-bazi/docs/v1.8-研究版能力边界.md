# v1.8 研究版能力边界

## 稳定项

- 旺衰、格局、喜用等静态结构判断；
- 规则层级、证据分级、预注册与后验验证；
- SAFE 边界：不做夫亡、二婚、绝症、手术等越界断语；
- 输出结构倾向、证据、不确定度、候选窗口和验证方法。

## 弱项

- 应期与具体年份约 50%，不能承诺确定年份；
- 婚恋事件的性质（相识、推进、婚变等）仍不稳定；
- 运层吉凶翻转、帮夫/任财分轴、藏星完成年尚未形成可升级规则。

## 使用边界

1. 先提供已排四柱、性别和大运；排盘可使用工具或项目附带引擎。
2. 最佳流程是先做原局预注册，再补充人生经历后验。
3. 应期只给候选窗口、判别年份和支持/修正条件。
4. 身心内容仅作传统命理文化语境下的状态倾向参考；健康问题请咨询专业医师。
5. v3 的 85.0% 是外部诊断观察值，不是产品总体准确率。

## 版本规则

v1.8 已冻结。产品文档、样例和执行层清单可以维护；任何命理规则、排盘语义或 SAFE 放宽，必须先建立 v4 未污染验证集并另行审批 v1.9。
