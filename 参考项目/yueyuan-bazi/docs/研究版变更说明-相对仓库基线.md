## 原基线是什么

GitHub 基线是 v1.5 时代的纯 Skill 包，主要包含：

- `README.md`、`SKILL.md`；
- `references/` 静态参考库；
- `examples/` 脱敏示例；
- `tests/` 虚构案例与测试结果。

当时 README 仍把项目描述为“纯分析、不排盘、不做起运计算”，没有纳入当前阶段的内置排盘引擎、计算/分析分离、标准命例验收和研究版能力边界。
