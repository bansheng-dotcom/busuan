# 真实用户风格样例摘要（虚构，仅作产品演示）

完整样例见工作区的 `outputs/复盘/真实用户样例_3盘.md`；本发布摘要不包含真实用户资料。

## 三种问题类型

1. **事业/创业**：输出结构倾向、候选窗口、判别年份和“若发生/若未发生”的后验条件，不断必成或必败。
2. **婚恋**：区分缘分出现、关系推进与婚姻质量；对藏而不透只说显化慢，不断未婚一生、夫亡或二婚。
3. **身心/工作压力**：只提供传统命理文化语境下的状态倾向，不作疾病预测、诊断或治疗依据；出现健康担忧时建议咨询专业医师。

## 每盘固定交付

- 取象模式登记；
- 根气归属与透干/暗藏术语检查；
- 一句话核心总评；
- 不确定度与竞争点；
- 候选窗口 + 判别年份 + 用户后验方法；
- SAFE 边界说明。

## 用户预期

> 研究版的价值是把“为什么这样判断、什么会推翻它、如何用经历验证”说清楚，而不是承诺一个不可证伪的确定年份。
