# 跃渊 · 专业子平八字分析系统（v1.8 研究版）

> **鱼跃于渊，无咎。** ——《易经·乾卦》
> 作者：無鱼（浅野無鱼）· [GitHub 仓库](https://github.com/qianye-wuyu/yueyuan-bazi)

跃渊是一个**研究型八字分析 Skill**：内置确定性排盘引擎，把出生时间转成四柱盘面，再按正统子平体系（《渊海子平》《子平真诠》《滴天髓》《穷通宝鉴》+ 现代格局派/旺衰调候派/盲派交叉验证）给出带证据、带不确定度、可被经历验证的分析。

它不是"算命的判题程序"，而是**研究程序**：允许不确定、拒绝迎合、结论可用亲身经历后验。

## 二、核心能力

### 1. 内置排盘引擎（计算与推理分离）

`bazi_engine.py`（基于 lunar-python）负责一切确定性计算：

- 四柱、五行、纳音、十神、藏干
- 大运（含起运岁数，sect=2 精确口径）与流年基础
- **空亡**（年/日柱）、**日主十二长生**
- **神煞**：桃花 / 驿马 / 华盖 / 将星（各支）、天乙贵人 / 文昌 / 羊刃（日干）
- **天月二德**

标准命例验收：**6/6 通过**（四柱逐字一致、大运顺逆正确、起运年月天一致，"时"允许 ±1 小时工具精度容差）。

你只需给**出生年月日时 + 性别**，引擎完成排盘；也可以直接给**已排好的四柱 + 大运**（例如排盘 App 的截图/文本），两者可交叉校验。

### 2. 完整分析流程（步骤 0–10）

```
定盘登记 → 旺衰判断 → 格局判定 → 病药定位 → 调候评估
→ 用神六维一致性 → 干支作用与神煞 → 大运流年分层
→ 应期信号链 → 领域分析 → 预注册预测与后验验证
```

- **旺衰**：条件变量框架（得令/得地/得势/透藏/合化/制化），只给"倾向 + 程度"，不做伪量化
- **格局**：《子平真诠》八格 + 建禄/羊刃特殊格 + 从势/专旺/化气独立状态机（含"制化自救"闸门）
- **调候**：穷通宝鉴 120 格，以 `mingli_rules.py` 代码表为基准裁决
- **用神**：扶抑/格局/调候/病药/通关/变格六维交叉，一致则合并、冲突则说明取舍
- **应期**：信号链（前置信号断时段、完成信号断年份），多重独立信号互证，只给"候选窗口 + 判别年份"
- **领域**：婚恋 / 事业 / 财富 / 身心 / 人际 / 六亲家庭 / 学业学历 / 性格，按你所问优先

### 3. 研究程序纪律（最核心的特色）

1. **结论是验证出来的，不是算出来的**——分析先锁定预注册预测，再用你的真实经历做"命中/部分命中/未命中/未知"四态裁决，不反向篡改。
2. **允许不确定，拒绝迎合**——存在路线级分歧时并列两条相反路线并给判别年份；你说了"某年很顺"不会让系统改口。
3. **证据与层级透明**——每条结论标注证据等级（S0–S3 输入可信度 / A–E 推理证据）与规则层级（STRUCTURAL > CORE > SCHOOL > HEURISTIC > SUPPLEMENTAL），流派分歧显式标注、不混用。
4. **SAFE 红线**——不做宿命定级、不做医学诊断、不断夫亡/二婚/绝症等越界断语；身心内容仅作传统命理文化语境下的状态倾向参考。

### 4. 双人群适配 + HTML 交付

- **小白**：白话结论在前（"你的八字能量偏自我成就型"），术语在后（"即身旺喜财官食伤"），可跳过进阶推导。
- **懂行者**：完整推导链、证据等级、流派标注可核对。
- 完整分析默认产出 **HTML 可视化报告**（五行五色、固定模板）；环境不支持时输出等价 Markdown 并如实说明。

## 三、快速开始

### 安装

```bash
# 1. 把仓库复制到 skills 目录（macOS 示例）
cp -R yueyuan-bazi ~/.workbuddy/skills/yueyuan

# 2. 安装排盘引擎依赖（可选，装了才能用内置引擎排盘）
cd yueyuan-bazi && pip install -r requirements.txt
```

### 使用（两种输入方式任选）

```text
方式一（推荐）：提供出生信息，引擎自动排盘
「1990年5月15日 上午10点 男，帮我看看事业」

方式二：提供已排好的盘
「四柱：庚午 辛巳 庚辰 辛巳，男，大运…，分析婚恋」
```

可指定方向：婚恋 / 事业 / 财富 / 身心 / 人际 / 六亲 / 学业 / 性格；需要深度全盘分析时说"深度研盘"。

### 引擎命令行用法

```python
from bazi_engine import paipan
pan = paipan(1990, 5, 15, 10, 1)   # 年, 月, 日, 时(0-23), 性别(1男/0女)
print(pan["四柱"], pan["大运"], pan["起运"], pan["空亡"], pan["十二长生"])
```

## 四、你会收到什么

标准输出结构：

1. **核心总评**（最优判断 + 不确定度 + 主要竞争点，一屏读完）
2. **预期管理提示**（不确定度 ≥ 中时强制附注：如何用亲身经历验证、不必急于要答案）
3. **推导链**（旺衰/格局/病药/调候/用神六维，专业层可核对、小白可跳过）
4. **大运流年与应期**（候选窗口 + 判别年份，不宣称确定年份）
5. **分领域解读**（按你所问优先深化）
6. **HTML 可视化报告**（默认交付物）
7. 提供经历后：**后验验证**（四态裁决 + 收敛重解读）

## 五、能力边界（诚实声明）

### 相对稳定（v3 外部诊断集实测）

- 旺衰、格局、喜用等**静态结构判断**：约 96–100%
- SAFE 红线执行：100%（纪律成绩，不是命中率）

### 弱项（如实告知）

- **应期与具体年份约 50%**——只能给候选窗口和判别条件，不能承诺"某年必发生某事"
- 婚恋事件的性质（相识/推进/婚变）仍不稳定
- 运层吉凶翻转、帮夫/任财分轴等机制尚未形成可升级规则

### 边界

- v3 的 85.0% 是**外部诊断观察值，不是产品总体准确率**，禁止用作宣传
- 不排宿命论、不医学断言、不道德归因（克夫/克妻类表述禁用）
- 结论仅供参考与自我观察，重大决策请以现实依据为准

## 七、方法论内核（懂行者的核对入口）

- **规则分层与冲突裁决**：STRUCTURAL > CORE > SCHOOL > HEURISTIC > SUPPLEMENTAL；极端气候进入 CLIMATE OVERRIDE 特殊状态（调候临时高于扶抑，且须逐条检查退出例外）
- **证据分级**：S 层（输入可信度 S0–S3）+ A–E 层（推理证据）分开标注，禁止把解释伪装成事实
- **预注册 + 后验**：Phase A 独立锁定预测 → Phase B 用经历四态裁决 → 收敛重解读，禁止反向篡改
- **竞争假设**：只有临界盘（从格嫌疑/专旺临界/调候与扶抑相反/关键合化翻转）才并列相反路线，多数盘给单一主判断 + 不确定度（高/中/低）
- **多流派合议**（可选）：子平主框架定调，盲派作平行视角，派别数量 ≠ 证据数量
