# Case 052 · 反吟岁运（岁运与原局相冲）· 岁运

- 类别：岁运（反吟）
- 四柱：甲申 丙寅 甲申 丙寅（乾造）
- 大运：庚寅运（庚甲天克 + 寅申冲）
- 流年：甲申年（与日柱甲申伏吟）
- 设计意图：验证反吟（天克地冲）岁运的剧烈变动

## 预期结论（先给定）
- 原局：甲木日主寅月（比肩当令），申金双冲寅木（两组反吟原局）——身强（月令+禄）
- 大运庚寅：庚金七杀透（庚甲克）+ 寅申冲（反吟）——**天克地冲大运**
- 流年甲申：与日柱甲申伏吟
- 关键点：①反吟主剧烈变动、方向逆转；②庚金七杀克甲——杀运；③申冲寅——禄根被冲（自身/事业变动）
- 喜忌：身强杀运，喜火（食伤制杀）、土（财），忌金水木（杀印比）
- 空亡：甲申日柱，甲申旬空午未——无落空

## 模型输出摘要
- 核心总评：甲木寅月（比肩当令）建禄格，甲坐申（绝地）无根但月令寅禄帮身、丙火食神两透泄秀——身强；**原局两组反吟（寅申冲）**；大运庚寅为**天克地冲大运**（庚甲天克+寅申冲）、流年甲申与日柱**伏吟**。不确定度：中。
- 定盘（S1/A）：乾造，日主甲木，月令寅（甲木比肩当令），藏干申（庚壬戊）寅（甲丙戊）；甲申旬空午未，四支无午未，无落空。
- 旺衰：偏强（[CORE] 寅月木当令为禄 + 寅中甲木本气；甲坐申绝地无根但月令得禄，丙丙食神透泄）。
- 格局：建禄格（甲禄在寅，B 特殊格局）；丙火食神透——食神泄秀。
- 干支作用：**原局两组反吟（寅申冲）**——年日寅冲月时申，主剧烈变动、方向逆转（[HEURISTIC]）；申金为驿马，冲主流动。
- 病药：身强建禄为病（比劫旺）；药=丙火食神泄秀、庚金七杀制身（身强可任杀）。
- 大运流年：**大运庚寅 = 天克地冲**（庚甲天克 + 寅申冲）——七杀运，主剧烈变动；**流年甲申 = 与日柱伏吟**（甲申重现）。申冲寅——**禄根被冲**，主自身/事业变动。
- 岁运喜忌：身强杀运，喜火（食伤制杀）、土（财）；**忌金水木（杀印比）**——庚金七杀坐寅（绝地）无根虚浮，制身无力反引发冲（禄根被冲），此运以凶变论。
- 六维：扶抑（身强需克泄耗）、格局（建禄喜财官食伤）、调候（寅月春温和，非急）、病药（食伤制杀为药）、变格（NORMAL）。一致指向 **喜火（食伤制杀）、土（财），忌金水木（杀印比）**。
- Phase A：最优假设=身强建禄、反吟主变动、大运天克地冲凶变；关键争议=庚金七杀虚浮制身无力；未来高概率主题=庚寅运剧烈变动/禄根被冲、火土岁运制杀得用；推翻条件=火土岁运反逆、金水木岁运反顺。

## 判定
- 结果：**命中**
- 出错模块：无
- 偏差说明：无。两组反吟（原局寅申冲）、天克地冲大运、流年伏吟、禄根被冲、喜忌（喜火土忌金水木）、空亡（无落空）均与预期一致。
