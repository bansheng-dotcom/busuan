# Case 030 · 食神制杀（成格范式）· 普通复杂

- 类别：普通复杂（成格-食神制杀）
- 四柱：戊申 辛酉 甲申 丙寅（乾造）
- 设计意图：验证食神制杀成格判定——食神（丙火）制七杀（庚金藏申）

## 预期结论（先给定）
- 格局：甲木日主酉月（正官当令——辛金正官透月干），地支申申金局（庚金七杀藏）、丙火食神透时干（坐寅长生有根）——**食神制杀**（丙火制申中庚金）？
- 关键争议：①月令辛金正官透 → 正官格？②丙火食神制杀（申中庚金）——食神制杀 vs 正官格的格局竞争；③身弱（酉月失令、甲坐申绝地无根、丙寅帮身）
- 喜忌：身弱食神制杀——喜火（食神）、木（比劫帮身），忌金（官杀）、水（印泄食神？水克火）
- 空亡：甲申日柱，甲申旬空午未——无落空

## 模型输出摘要
- 核心总评：甲木酉月正官当令透月干 → **正官格为主**；丙火食神透时干坐寅（长生）有力，制申中庚金七杀 → **食神制杀为辅**；甲坐申（绝地）失令、官杀成势，仅寅中禄根帮身 → **身弱**；喜水（印化官生身）木（比劫）火（食神制杀），忌金土。不确定度中（格局主从与印之喜忌分歧）。
- 定盘：甲木日主，酉月，申藏庚壬戊、酉藏辛、寅藏甲丙戊；空亡午未无落空（甲申旬空午未）
- 格局竞争（正官格 vs 食神制杀）：月令酉中辛金（正官）当令**透干** → 按《子平真诠》「用神专求月令」取**正官格**；丙火食神制申中庚金（七杀）为辅助结构（丙克庚，不克辛——制杀不碍正官，两结构可并存）
- 旺衰：身弱——酉月官星当令失令、甲坐申（绝地）无本气根（寅中甲木禄根帮身）、申申酉金官杀成势、戊土偏财透泄耗
- 喜忌：身弱正官格 → 喜水（印——化官生身，申中壬水藏支可用）、木（比劫帮身）、火（食神制杀为辅——身弱火泄身，为次选用）；忌金（官杀）、土（财生官）
- 关键分歧（印之喜忌）：正官格身弱喜印（水化官生身）vs 食神制杀忌印（水克丙火食神）——按格局优先（月令正官格）+身弱印为用，取**水印为喜**；食神制杀保留但火为次选
- 调候：酉月秋燥不极端，普通状态，身弱以扶抑为主
- 六维：主六维指向喜水木火、忌金土；病药维度：官杀旺克身为病，药=印（化）食（制）比（帮）
- 岁运：喜水木火运，忌金土运；印旺岁运化官生身为最吉，食神旺岁运制杀亦顺
- Phase A：最优假设=身弱正官格（兼食神制杀）喜水木火忌金土；推翻条件=金土岁运反顺、水木火岁运反逆

## 判定
- 结果：**部分命中**
- 出错模块：格局主从（步骤 2）＋用神取用（步骤 5）——印（水）喜忌分歧
- 偏差说明：格局竞争识别（正官格 vs 食神制杀）、身弱、食神制杀存在——与预期一致 ✓；但印（水）喜忌分歧：预期按「食神制杀」主体取**喜火木忌金水**（忌印泄食神），本分析按「正官格」主体（月令透干取格）+身弱印为用取**喜水木火**（印化官生身）。预期将食神制杀列为主格，本分析判月令正官格为主——流派级分歧（格局派月令优先 vs 以制杀成格范式为主），喜忌差异集中在「水印」一项。
