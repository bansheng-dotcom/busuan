# Case 004 · 化气格（乙庚合化金）· 极端结构

- 类别：极端结构（化气）
- 四柱：乙丑 甲申 庚辰 乙酉（乾造）
- 设计意图：验证化气格（乙庚化金）判定是否成立、化神当令成局的评估

## 盘面分析（定盘登记）
- 日主：庚金（阳金）
- 月令：申月（庚金当权）
- 天干：乙庚乙——月干乙与日主庚合（乙庚合化金），时干乙再合庚（两乙争合）
- 地支：丑申辰酉——申酉金局成势、丑辰土生金（辰酉合、申辰半合水？申辰拱子……需细查）
- 藏干：丑藏己癸辛，申藏庚壬戊，辰藏戊乙癸，酉藏辛
- 空亡：庚辰日柱，庚辰旬空申酉 → 月支申、时支酉均落空亡

## 预期结论（先给定，防确认偏误）
- 化气判定：乙庚合化金——**化神（金）在申月当权得令 + 地支申酉丑辰金土成局 → 化气成立条件强**（但需评估申酉落空亡是否削弱成局、乙木是否无根）
- 乙木根气：丑中乙木余气、辰中乙木余气——乙木有根但弱，且被金克
- 喜忌（若化气成立）：喜金（化神）、土（生金顺），忌火（克金）、木（耗金）、水（泄金）
- 关键点：模型应走 HUAGQI 状态机判定化气，而非普通格局；需评估空亡对化局的影响（[SCHOOL] 分歧）
- 关键争议：乙庚两乙争合是否影响化气纯度

## 模型输出摘要
- 核心总评：庚金申月得禄，乙庚两乙争合，化神（金）当令成局——但**日主庚金申月得禄根 → 违反「日主无强根」→ 化气破格**，退论合而不化（合绊）；普通格局身强，喜火木水忌金土。不确定度中高（空亡碍局 vs 日主得禄破化的流派分歧）。
- 旺衰：化气格以化神论不适用；退论普通后身强（申月得禄+金土局）
- 格局：HUAGQI 六条评估——①乙庚合✓ ②化神当令✓ ③成局✓（但申酉空亡削弱）④**日主庚金申月得禄=有强根 → 破化**✗ → 化气不成立，退论合绊；普通身强
- 调候：申月温和非急
- 病药：无典型病型；比劫旺（申酉金）→ 喜官杀制（火）、财耗（木）
- 六维：一致指向喜火木水、忌金土
- Phase A：化气不成立（日主得禄破化），退论身强喜火木水忌金土；推翻条件=申酉空亡致金局虚、日主根虚 → 化气或可从（空亡流派分歧的关键变量）

## 判定
- 结果：**部分命中**
- 出错模块：格局（化气判定）
- 偏差说明：化气判定方向与预期不同——预期「化气成立条件强（倾向成立）」，模型依据 biange.md 破格条件「日主得强根→破化」判**不成立退论**（庚金申月得禄根）。模型的判断更深一层、且引据破格条件有理有据；但预期聚焦的「申酉空亡削弱成局」被模型用「日主得禄破化」这条更强依据覆盖。属合理的深度分歧，需在测试记录中标注「空亡碍局 vs 日主得禄破化」为流派分歧点，不判模型错误。
