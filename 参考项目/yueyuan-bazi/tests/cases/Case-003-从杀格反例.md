# Case 003 · 从杀格（官杀成势）· 极端结构

- 类别：极端结构（从势/从官杀）
- 四柱：庚申 乙酉 丙申 壬辰（坤造）
- 设计意图：验证从杀格判定是否成立、官杀（金水）成势的取用、日主是否误判身弱不从

## 盘面分析（定盘登记）
- 日主：丙火（阳火）
- 月令：酉月（辛金当权，正财当令——但金可生水官杀）
- 地支：申申酉辰——金局成势（申酉金 + 辰中藏癸水官星）
- 天干：庚壬官杀透两（庚偏财→实际庚为偏财？丙火日主，庚金=偏财，壬水=七杀；乙木=正印，辛金=正财。注意：庚是丙的偏财不是官杀——需重新评估）
- 空亡：丙申日柱，丙申旬空辰巳 → 时支辰落空亡

## ⚠️ 设计复盘（重要）
原设计意图是「从官杀」，但庚金对丙火日主是**偏财**而非官杀。官杀应为壬水（七杀）/癸水（正官）。此盘天干庚乙丙壬——庚偏财、乙正印、壬七杀。印（乙）透出是**从格大忌**（印生身反抗）。此盘设计有误，**不能作为「从杀格」测试用例**——乙木正印透干 + 丙火坐申有微根（申藏庚金非火根……丙火在申为病地无根），但乙木印透即生身反抗，从格不成立。

**处理**：本案例作废/降级为「设计缺陷复盘」案例——验证模型能否识别「印透则从格不成立」。保留此盘，预期改为「不从，身弱印透，喜木火印比」的反向测试。

## 预期结论（修正后）
- 旺衰：弱（酉月失令，金财耗身，仅乙木印生）
- 格局：**非从格**——乙木正印透干生身，从格「生扶（印比）极度微弱或全无」判据不成立（印透有根）
- 喜忌：喜木（印）、火（比劫帮身），忌金（财耗）、水（官杀克）
- 关键点：模型应识别「印透则从格不成立」，不应强行判从——这是测试「从格误判」的防御能力

## 模型输出摘要
- 核心总评：丙火酉月正财当令耗身，庚壬金水财杀透，**乙木正印透干 → 印透即从格不成立**，退论普通格局：身弱，喜木火忌金水。不确定度中。
- 旺衰：偏弱（酉月失令、财耗杀克、丙火坐申无根，仅乙木印生）
- 格局：Root resistance 判据——判据1无本气根通过，但**判据2乙木印透（弱根）→ 生扶有显 → 从格不成立**，正确识别印透阻从；退论普通格局
- 调候：酉月温和非急
- 病药：非官杀混杂（无正官透）；命中**财多身弱**病型（财当令+日主弱），药为印比
- 六维：一致指向喜木火、忌金水
- 岁运：喜木火运帮身任财，忌金水运
- Phase A：身弱喜木火忌金水；推翻条件=金水运反顺

## 判定
- 结果：**命中**
- 出错模块：无
- 偏差说明：无。修正后的预期全部命中——尤其**正确识别「乙木印透则从格不成立」**（判据2防御生效），未强行判从；财多身弱病型命中。此案例验证了从格判据清单对「印透阻从」的防御能力。
