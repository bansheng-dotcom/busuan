# Case 033 · 印多为病（经典病型）· 普通复杂

- 类别：普通复杂（病药-印多为病）
- 四柱：壬辰 壬寅 甲子 癸酉（乾造）
- 设计意图：验证印多为病病型——印星（水）过旺、日主被印滋而无力

## 预期结论（先给定）
- 病型：甲木日主寅月（比肩当令？寅中甲木是甲之比肩——**纠正：寅月甲木当令，比肩**。印星=水。此盘壬癸水印透三（壬年/壬月/癸时）、子辰水局——**印多**）
- 旺衰：印多身强？——甲坐子（沐浴）有根、寅月得令——身强印多 → 印多为病（印为忌）
- 关键点：①水印极旺（壬癸三透+子辰水局）——印多为病命中；②「印多身强 vs 母多灭子」界限——水多木漂？甲坐寅得令有根，未至灭子 → 印多为病（非母多灭子）；③身强印为忌 → 喜火（食伤泄身+制印？火克水）土（财破印）、忌水（印）金（官杀生水）
- 喜忌：喜火土（食伤财），忌水（印）金（官杀生印）
- 空亡：甲子日柱，甲子旬空戌亥——无落空

## 模型输出摘要
- 核心总评：甲木寅月得令，坐子（沐浴）得印、辰中乙木余气根，天干壬癸三透水印 + 子辰半合水局，水印极旺而身强。**印多为病命中**（非母多灭子：甲坐寅得令有根，未至「水多木漂」灭子程度）。身强印为忌。不确定度：低。
- 定盘（S1/A）：乾造，日主甲木，月令寅，藏干寅（甲丙戊）辰（戊乙癸）子（癸）酉（辛）；甲子旬空戌亥，四支无戌亥，无落空。
- 旺衰：偏强（[CORE] 得令寅月 + 坐子印 + 辰中余气根 + 印三透生身；子辰半合水局助印）。综合「身强印多」。
- 格局：月令寅本气甲木（比肩），不透；甲禄在寅 → 建禄格（B 特殊格局）。不以正格论。
- 病药：**印多为病命中**——水印极旺（壬癸三透 + 子辰半合水局）滋身过度，甲木得令有根未被淹，属「印多为病」而非「母多灭子」。药 = 火（食伤泄秀）+ 土（财破印）；药根气：原局火土均不透不显，药力虚，待岁运。
- 调候：寅月春，气候温和，非极端，不触发 CLIMATE OVERRIDE；调候非急。
- 六维：扶抑（身强需泄耗 → 喜火土，金生水助印故忌）、格局（建禄喜财官食伤，忌印比）、调候（非急）、病药（火土为药）、通关（水木顺生无交战）、变格（NORMAL）。一致指向 **喜火土、忌水金**（比肩甲木亦忌——身强忌比劫帮身）。
- 岁运：喜火土岁运（丙丁巳午、戊己辰戌丑未），忌水金岁运（壬癸亥子、庚辛申酉）；水金运印旺更病。
- Phase A：最优假设=印多为病、喜火土忌水金；主要争议=印多为病与母多灭子界限（本盘靠「甲坐寅有根」裁为前者）；未来高概率主题=火土运顺遂、水金运压抑；推翻条件=水金岁运反顺、火土岁运反逆。

## 判定
- 结果：**命中**
- 出错模块：无
- 偏差说明：无。旺衰（身强印多）、病型（印多为病，并正确排除母多灭子）、喜忌（喜火土忌水金）、空亡（无落空）均与预期一致；另补充建禄格命名与「金生水助印故忌金」的论据链。
