# Case 058 · 合处逢冲（解合应事）· 岁运

- 类别：岁运（合处逢冲）
- 四柱：甲戌 甲戌 己卯 庚午（乾造）
- 大运：己酉运（卯酉冲）
- 流年：乙酉年（卯酉冲 + 酉戌害）
- 设计意图：验证合处逢冲的解合应期（原局卯戌合被酉冲破）

## 预期结论（先给定）
- 原局：己土日主戌月（劫财当令？戌中戊土是己之劫财——戌月戊土当令 → 劫财格），卯木七杀（时支？日支卯——己土七杀=卯木）——**卯戌合**（日支卯与月支戌合火）
- 大运己酉：酉冲卯——**合处逢冲（卯戌合被酉冲破=解合）**
- 流年乙酉：乙木七杀透 + 酉冲卯——再冲
- 关键点：①合处逢冲则动（解合应事）——原局卯戌合（七杀合劫财？）被冲破，主变动；②酉戌害（流年酉-月支戌害）；③七杀（卯木）被冲——事业/压力主题被引动
- 喜忌：身弱（戌月劫财帮身、己坐卯被克）七杀旺，喜火（印化杀）、土（比劫），忌木（七杀）、金（食伤泄）
- 空亡：己卯日柱，己卯旬空申酉——无落空

## 模型输出摘要
- 核心总评：己土戌月（戊土劫财当令），己坐卯（七杀）被克、甲甲正官两透、庚金伤官透——**身中和偏弱、官杀混杂 + 伤官见官**；日支卯与月支戌**卯戌合**，大运己酉酉冲卯——**合处逢冲（解合应事）**，流年乙酉再冲 + 酉戌害。不确定度：中。
- 定盘（S1/A）：乾造，日主己土，月令戌（戊土劫财当令），藏干戌（戊辛丁）卯（乙）午（丁己）；己卯旬空申酉，四支无申酉，无落空。
- 旺衰：中和偏弱（[CORE] 戌月劫财当令帮身 + 午中丁火偏印；但己坐卯七杀被克 + 甲甲正官两透克身 + 庚金伤官泄身）。
- 格局：月令戌本气戊土劫财当令，不透 → 劫财不取正格，退以旺衰论（[CORE] 不成格以旺衰喜忌论）。
- 病药：**官杀混杂（甲甲正官两透 + 卯木七杀）** + **伤官见官（庚金伤官 vs 甲木正官）**；甲木官星坐戌（养地，戌中无木）无根虚浮、庚金伤官坐午（沐浴）无根；药=印（火，午中丁火）制伤官化官杀生身、比劫（土）帮身。
- 干支作用：**卯戌合（日支卯七杀 - 月支戌劫财）**——原局有合；大运己酉酉冲卯——**合处逢冲则动（解合应事）**（[HEURISTIC]）；流年乙酉再冲卯 + **酉戌害**（流年酉-月支戌）。
- 岁运分析：**卯木七杀被酉冲**——事业/压力主题被引动，主变动；酉戌害——月支（事业宫）受害；乙木七杀透（坐酉绝地无根）——压力虚透。身弱七杀旺，七杀被冲动主压力、变动主题。
- 六维：扶抑（身弱需印比——火土）、格局（不成正格退旺衰论）、调候（戌月秋燥需水，但水为财生杀——参数级）、病药（印化杀制伤为药）、变格（NORMAL，己坐卯虽被克但有戌午根，不从）。一致指向 **喜火（印化杀）、土（比劫），忌木（七杀）、金（食伤泄）**。
- Phase A：最优假设=官杀混杂+伤官见官、合处逢冲主变动、喜火土忌木金；关键争议=卯戌合解合吉凶、酉戌害；未来高概率主题=乙酉年七杀被冲动压力变动、火土岁运化杀帮身顺；推翻条件=木金岁运反顺、火土岁运反逆。

## 判定
- 结果：**命中**
- 出错模块：无
- 偏差说明：无。卯戌合、合处逢冲（解合应事）、酉戌害、七杀被冲引动事业/压力主题、身弱喜火土忌木金、空亡（无落空）均与预期一致；补充官杀混杂+伤官见官并存的病机描述。
