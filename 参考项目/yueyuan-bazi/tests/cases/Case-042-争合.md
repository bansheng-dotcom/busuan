# Case 042 · 争合（两干争合一干）· 普通复杂

- 类别：普通复杂（干支作用-争合）
- 四柱：甲午 己巳 甲子 己巳（乾造）
- 设计意图：验证争合判定——两己土（正财）争合一甲木日主

## 预期结论（先给定）
- 天干作用：甲木日主，月干己土、时干己土——**两己争合一甲（两正财争合日主）**
- 旺衰：巳月食神当令（巳中丙火是甲之食神），甲坐子（沐浴）得印根，甲午甲子——身中和
- 关键点：①两己争合一甲——财星争合日主（感情/合伙多角象，男命财为妻——两财争合主感情纠葛）；②己土正财坐巳（病地）无根——财虚？；③子午冲（日时冲）——夫妻宫逢冲
- 喜忌：身中和，喜水（印）、木（比劫帮身），忌火土（食伤财）、金（官杀）
- 空亡：甲子日柱，甲子旬空戌亥——无落空

## 模型输出摘要
- 核心总评：甲木日主巳月（食神当令），月干、时干两己土正财——**两己争合一甲（财星争合日主）**；甲坐子（沐浴）得印根，午巳火泄——身中和。不确定度：中。
- 定盘（S1/A）：乾造，日主甲木，月令巳（丙火食神当令），藏干午（丁己）巳（丙庚戊）子（癸）；甲子旬空戌亥，四支无戌亥，无落空。
- 旺衰：中和偏弱（[CORE] 巳月火当令泄木 + 午巳火泄身，甲坐子（子中癸水正印）得印根——身中和）。
- 天干作用：**两己争合一甲**——月干己、时干己（正财）争合日主；甲己合化土需月令土当令（巳月火当令，不合化）→ 合而不化，仅论合绊（C 级判断）。
- 格局：月令巳本气丙火食神当令，不透 → 食神格（[CORE] 月令不透取本气）。
- 病药：财多身弱边缘——两己财透（坐巳，己土通根巳中戊土）有根，甲木身中和，财星两透合身；病=财星合绊日主（男命财为妻，两财争合主感情纠葛/合伙多角象）；药=水（印生身）、木（比劫帮身任财）。子午冲（日支子-年支午冲）——**夫妻宫逢冲**。
- 调候：巳月夏月，气候燥——调候需癸水润局；但原局水仅子中癸水（坐支印根），调候神有根但力弱，未至极燥不触发 CLIMATE OVERRIDE（[SCHOOL] 普通状态）。
- 六维：扶抑（身中和需微扶——水木）、格局（食神格顺用）、调候（夏月需水，与扶抑同向）、病药（财星合绊为病，印比帮身为药）、变格（NORMAL，甲坐子印根不从）。一致指向 **喜水（印）、木（比劫帮身），忌火土（食伤财）、金（官杀）**。
- 岁运：喜水木岁运，忌火土岁运；财星（己土）得根岁运财旺合身——感情/合伙主题引动；子午冲逢岁运引动主夫妻宫变动。
- Phase A：最优假设=争合（两财合身）、喜水木忌火土；关键争议=合化不化、财多身弱程度；未来高概率主题=水木岁运帮身任财顺、火土岁运财多身弱压力；推翻条件=火土岁运反顺、水木岁运反逆。

## 判定
- 结果：**命中**
- 出错模块：无
- 偏差说明：无。两己争合一甲判定、身中和、子午冲（夫妻宫逢冲）、喜忌（喜水木忌火土）、空亡（无落空）均与预期一致；补充「甲己合不化只论合绊」的 C 级判断过程。
