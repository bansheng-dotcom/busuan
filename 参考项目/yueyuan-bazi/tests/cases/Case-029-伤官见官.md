# Case 029 · 伤官见官（经典病型）· 普通复杂

- 类别：普通复杂（病药-伤官见官）
- 四柱：乙巳 丁亥 甲戌 庚午（乾造）
- 设计意图：验证伤官见官病型——伤官（丁火）与正官（庚金）并见

## 预期结论（先给定）
- 病型：甲木日主亥月（偏印当令），丁火伤官透（月干）、庚金七杀透（时干）——**伤官见杀**（非见官——庚为甲之七杀）。设计偏差：庚是七杀非正官。
- 复盘：伤官见官须伤官+正官（辛金）；此盘是伤官+七杀（庚）——伤官制杀？伤官驾杀？须修正预期
- 修正预期：伤官（丁）透 + 七杀（庚）透——身弱（亥月印生身但甲坐戌无根……甲在戌为养地）伤官泄、杀克身，喜水（印化杀制伤？印克伤官+化杀）——杀印相生+印制伤官组合
- 关键点：验证模型能否识别「伤官见官 vs 伤官见杀」的差别（官=正官辛，杀=七杀庚，不可混）
- 空亡：甲戌日柱，甲戌旬空申酉——时支午无……甲戌旬空申酉，无落空

## 模型输出摘要
- 核心总评：**设计意图偏差——「伤官见官」不成立**：甲木日主官杀为金（辛正官/庚七杀），此盘时干庚金为甲之**七杀**（非正官）——伤官（丁）见的是杀而非官，**伤官见官病型不命中**；实际结构为伤官（丁）透+七杀（庚）透，亥月偏印当令，**印制伤官+印化杀生身**为救应，喜水木忌火金土。不确定度中。
- 定盘：甲木日主，亥月，巳藏丙庚戊、亥藏壬甲、戌藏戊辛丁、午藏丁己；空亡申酉——时支午不空（甲戌旬空申酉），无落空
- 十神复核（甲木日主）：官杀=金（庚七杀/辛正官）、印=水（壬偏印/癸正印）、食伤=火（丙食神/丁伤官）——**庚金是七杀，非正官**；设计意图「伤官见官」张冠李戴（须正官辛金）
- 病型核对（patterns.md 二节）：伤官见官须「伤官与正官并见」——此盘伤官（丁）+**七杀**（庚）→ **不命中** ✓；识别为「伤官见杀」结构
- 旺衰：得令（亥月偏印当令生身）+得地（亥中甲木长生本气根）→ 身有根基；丁火伤官透泄、庚金七杀透克（均虚浮无根）→ 中和偏弱
- 救应结构：亥月壬水印当令——**印化杀生身**（庚→壬→甲）+ **印制伤官**（壬克丁），杀印相生与印制伤官并行（预期修正方向一致）
- 喜忌：身弱，喜水（印——化杀生身+制伤官）、木（比劫帮身），忌火（伤官）、金（七杀）、土（财生杀）
- 调候：亥月冬寒偏冷，甲木冬月需丙火暖局——但此盘身弱印旺、调候火神（丙）不透不藏（巳中丙火藏支）、且伤官（丁）已透可微暖 → 调候为辅助，扶抑为主
- 六维：一致指向喜水木、忌火金土
- 岁运：喜水木运，忌火金土运；伤官（丁）透为病，印旺岁运制伤为吉，伤官旺岁运（无印制）主口舌官非
- Phase A：最优假设=中和偏弱、伤官见杀（非见官）喜水木忌火金土；推翻条件=火金土岁运反顺、水木岁运反逆

## 判定
- 结果：**命中**
- 出错模块：无（防御测试——模型正确识别设计错误）
- 偏差说明：无。模型正确识别「伤官见官」设计意图不成立：庚金为甲之七杀（非正官辛金），伤官见的是杀——不命中伤官见官病型；修正方向「印制伤官+印化杀生身、喜水木忌火金土」与预期一致。
