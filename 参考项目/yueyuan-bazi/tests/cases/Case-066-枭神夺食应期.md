- 设计意图：验证枭神夺食病型被岁运引动的应期

## 预期结论（先给定）
- 原局：甲木日主寅月（比肩当令），壬水偏印双透（年/月干）——**枭神（壬水偏印）夺食（丙火食神）**：甲木食神=丙火（时干透）
- 旺衰：寅月木当令、甲坐子（沐浴）得印生——身强（印旺）
- 流年庚申：庚金七杀克甲 + **申冲寅（禄根被冲）** + 申子辰合水局（申子辰——大运戌？需查：流年申+原局子子+？无辰——申子半合水）
- 关键点：①枭神夺食病型（壬水枭神夺丙火食神）——岁运引动时为应期重点；②申冲寅（禄根被冲）——自身变动；③庚金七杀克甲——杀年压力
- 喜忌：身强枭神夺食，喜火（食伤）、土（财破印），忌水（枭印）、金（官杀生印）
- 空亡：甲子日柱，甲子旬空戌亥——无落空

## 模型输出摘要

**步骤0 定盘**：甲木日主，月令寅（寅藏甲木本气，为甲之比肩/临官）；年干壬=偏印、月干壬=偏印、时干丙=食神；地支子寅子寅。空亡：甲子日属甲子旬，空亡戌亥，原局无戌亥、无落空。十二长生：甲在寅为临官、在子为沐浴。

**步骤1 旺衰**：得令（寅月甲木当令）；得地（月支寅、时支寅双禄根，年支子、日支子双印根）；得势（双壬偏印透生身）。不利：丙火食神透泄。综合倾向 **「身强印旺」**——木水成势，印比皆旺。喜火（食伤泄秀）、土（财破印），忌水（枭印）、金（官杀生印）。

**步骤2 格局**：月令寅为甲木临官之地 → **建禄格**（B 类特殊格局，非变格体系）。双壬偏印透、丙火食神透。建禄身强，财官食伤为喜。

**步骤3 病药**：病型检查——**「枭神夺食」命中**（壬水偏印强旺，同性克丙火食神，身旺印为忌）。从重者论：病=枭神夺食（双壬枭神夺丙火食神——才华/表达受制）；药=火（食伤泄秀）、土（财破印）。药根气：**丙火坐寅长生有力**（食神被夺但根未拔——受压制而非灭绝）；土原局无，待岁运。

**步骤4 调候**：甲木寅月春季，气候温和，非极端 → 普通状态，格局扶抑为主，调候辅助。

**步骤5 用神六维**：①扶抑：身强印旺喜食伤财（火土）泄耗；②格局：建禄格身强喜财官食伤；③调候：辅助；④病药：药=火土；⑤通关：木生火生土流通；⑥变格：NORMAL。六维一致 → 喜火（食伤）、土（财），忌水（枭印）、金（官杀生印）。与预期一致。

**步骤6 干支作用**：天干双壬偏印、丙火食神，壬丙无合；地支子子双印、寅寅双禄——**子寅无冲合**、寅寅伏吟（月支-时支同支）。空亡无落空。神煞：驿马——申子辰马在寅，年支子/日支子查 → 驿马在寅（月支寅、时支寅），[SUPPLEMENTAL] 流动主题；桃花（子日→酉）原局无。

**步骤7 大运流年**：
- 大运庚戌：庚金七杀透（忌——生印助枭）、戌土偏财（喜——破印）。
- 流年庚申：**庚金七杀透（忌）** + 申金七杀根；**申冲寅**（流年申冲月支寅、时支寅——双禄根被冲）；**申子半合水局**（流年申+年支子+日支子——无辰不成三合，半合水印局，枭神更旺）。
- 岁运互动：申子半合水助枭神（壬水更旺、夺食加重）；庚金七杀透生印（枭神夺食病加重）；申冲寅伤禄根（自身变动）。

**步骤8 应期**：①**枭神夺食病型被岁运引动**（申子半合水助枭、庚金生印——枭神夺食加重）——表达受阻/才华被压制/思虑过度主题（[HEURISTIC] 病型被引动=应期重点）；②申冲寅（禄根被冲）——自身变动；③庚金七杀透——杀年压力。多层信号互证 → 枭神夺食应期成立：谋事有始难终、表达受阻；但食神丙火坐寅长生根未拔，逢火土年（食伤财）可解。

**步骤9 领域**：事业——枭神夺食主才华被压制、谋事受阻、有始难终；表达/创作——思虑过度、表达不畅；自身——禄根逢冲主变动、状态起伏。

**不确定度**：中（申子半合水对枭神助力的强度、食神根是否被彻底压制约为参数级变量）。
