# Case 084 · 后验调候（冬木火运应吉）· 后验

- 类别：后验（调候-应验）
- 四柱：壬子 壬子 甲子 丙寅（乾造）
- 设计意图：验证冬木调候（CLIMATE OVERRIDE）的后验——火运暖局应吉

## Phase A 预注册（先给定）
- 原局：甲木子月，三子水印+壬透——冬寒极，CLIMATE OVERRIDE，调候丙火为急，喜火木忌水
- 预注册主题：①火运（巳午）暖局应吉；②水运（亥子）寒上加寒应凶

## 用户经历（后验输入）
- 2025 乙巳年：状态回升，有积极进展（乙木比劫+巳火食神暖局）。

## 预期裁决（先给定）
- 2025 乙巳：巳火（调候用神）暖局 + 乙木帮身——**调候火年应吉** → 与「喜火」一致 → **部分命中/命中**（调候主题支持）
- 关键点：①CLIMATE OVERRIDE 下调候火为第一用神；②巳火出现→暖局→顺

## 模型输出摘要

### Phase A（预注册，独立于经历）
- 步骤0：甲木日主，月令子（子藏癸水本气，为甲之正印）；年干壬=偏印、月干壬=偏印、时干丙=食神；地支子子子寅。空亡：甲子日属甲子旬，空亡戌亥，原局无戌亥、无落空。十二长生：甲在子为沐浴、在寅为临官（禄根）。
- 步骤1：失令（子月癸水正印当令，冬水寒而不生木）；得地（时支寅临官禄根、三子印、日支子沐浴）；得势（双壬偏印透、丙火食神透坐寅长生）。综合：满盘水（三子+双壬）+寅木禄根——水寒木冻，倾向 **「身弱（水寒木冻）」**（印旺成势但寒极无火，木气不舒）。喜火（暖局）、木（比劫），忌水（寒印）、金（生水助寒）。
- 步骤2：月令子本气癸水正印 → **正印格**（水印极旺，近「水多木漂」母多灭子形态）。
- 步骤3：病型「母多灭子（水多木漂）」命中（印多至极淹没日主）；病=水印过旺（冬寒）；药=火（暖局+食神泄秀）、土（财制印——但冬月土冻力弱）。药根气：丙火坐寅长生（有力）。
- 步骤4：**甲木子月冬寒极 → CLIMATE OVERRIDE 触发**，调候丙火暖局为第一用神（甲木冬月用丙火——冬木要火暖）。例外检查：①身弱有根（寅禄+丙食透）不从；⑤调候神丙火坐寅长生有根，不触发 → **CLIMATE OVERRIDE 成立**，调候（火）获得特殊决策权，可高于扶抑。喜火木、忌水金。
- 步骤5：六维一致（调候优先）→ **喜火（暖局第一）、木（比劫），忌水（寒印）、金（生水）**。
- 步骤6：天干双壬印、丙食，壬丙无合；地支三子（印重见）、寅木（子寅无刑冲）。空亡无落空。
- 步骤10 Phase A 预注册：
  - 最优假设：冬寒极，CLIMATE OVERRIDE，调候丙火为第一用神；喜火木、忌水金。
  - 主要用神：丙火食神（暖局泄秀）。
  - 关键争议：调候（火）vs 扶抑印多为病（土财制印）——冬月土冻，调候优先。
  - 预注册主题：①**火运（巳午）暖局应吉**——状态回升、事业顺；②水运（亥子）寒上加寒应凶；③土运（辰戌丑未）制印但冬月力弱。
  - 推翻条件：火运反逆或水运反顺 → 本路线被削弱。

### Phase B（后验，读取经历后）
- 用户经历：2025 乙巳年，状态回升，有积极进展。
- 2025 乙巳解析：**巳火食神（调候用神——暖局；巳为丙火禄根，调候神得禄）** + **乙木劫财（喜——帮身）**；乙木坐巳沐浴根弱。巳火暖局——冬木得火暖，寒局得解。
- 四态裁决：**部分命中**——巳火（调候用神）暖局+乙木帮身，与「喜火、火运暖局应吉」预测一致 → 状态回升、积极进展应验；调候主题获单年支持。判「部分命中」而非「命中」：单一年份且乙巳为火木双喜之年，收敛需更多年份（水运反证、火运复现）。
- 阶段性收敛：目前更支持「冬木调候喜火」路线；若补充任一水年（寒上加寒应逆）或火年复现可进一步确认。
- 铁则执行：不反向篡改 Phase A。

### 与预期裁决对照
- 预期：部分命中/命中（调候主题支持）。我判部分命中 → **一致**（在预期接受范围内，取保守档）。

## 判定
- 结果：命中
- 出错模块：无
- 偏差说明：Phase A 独立分析（CLIMATE OVERRIDE、调候丙火为第一用神、喜火木忌水金）与预期一致；Phase B 对 2025 乙巳（巳火暖局+乙木帮身）判部分命中（调候主题单年支持），在预期「部分命中/命中」范围内，一致。
