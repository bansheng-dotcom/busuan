# Case 098 · 后验争合（感情纠葛）· 后验

- 类别：后验（争合-感情）
- 四柱：甲午 己巳 甲子 己巳（乾造）
- 设计意图：验证争合后验——两财争合的感情纠葛

## Phase A 预注册（先给定）
- 原局：甲木日主巳月（食神当令），两己土正财争合一甲——**争合**（感情/合伙多角象），子午冲（夫妻宫逢冲）
- 预注册主题：①两财争合——感情纠葛/多角；②夫妻宫逢冲——婚恋变动

## 用户经历（后验输入）
- 感情经历：曾同时面临两个追求者纠结不定，后分手。

## 预期裁决（先给定）
- 两财争合 + 夫妻宫逢冲 → 感情多角/纠葛与「争合」一致 → **部分命中**（主题命中：多角纠葛；「分手」为宫冲之象）
- 关键点：①两正财争合日主（男命财为妻）→ 多角感情；②子午冲夫妻宫 → 婚恋变动

## 模型输出摘要

### Phase A（预注册，独立于经历）
- 步骤0：甲木日主，月令巳（巳藏丙火本气，为甲之食神）；年干甲=比肩、月干己=正财、时干己=正财；地支午巳子巳。空亡：甲子日属甲子旬，空亡戌亥，原局无戌亥、无落空。十二长生：甲在午为死地、在子为沐浴（子藏癸水印）。
- 步骤1：失令（巳月丙火食神当令泄身）；得地（日支子沐浴藏癸水印、年支午死地、月支/时支巳病地）；得势（甲木比肩帮身）。不利：己土正财双透耗、食伤双泄。倾向 **「身弱（中和偏弱）」**——食伤旺泄+财旺耗，赖子水印星+甲木比肩。喜水（印）、木（比劫），忌火（食伤）、土（财）、金（官杀）。
- 步骤2：月令巳本气丙火食神 → **食神格**。己土正财双透（争合）。
- 步骤3：病型「财多身弱」边缘命中（双财+食伤旺+身弱）。药=水（印制食）、木（比劫帮身）。药根气：子水印星（日支有根）；甲木坐午死地根弱。
- 步骤4：甲木巳月夏燥，调候需癸水润根（夏木非水不荣）——调候方向（喜水）与扶抑（喜印）同向；子水印星有根，调候辅助。
- 步骤5：六维一致 → 喜水（印）、木（比劫），忌火（食伤）、土（财）、金（官杀）。
- 步骤6：天干**两己土正财争合一甲**（年干甲-月干己、年干甲-时干己——[C]级：巳月火当令，甲己合化土不成立，合而不化、合绊论——**争合之象**）；地支**子午冲**（日支子-年支午——**夫妻宫逢冲**）、巳午会火（月支巳-年支午）。空亡无落空。神煞：将星（寅午戌见午，年支午为将星）。
- 步骤10 Phase A 预注册：
  - 最优假设：身弱食神格，**两财争合**（感情/合伙多角之象）+**夫妻宫逢冲（子午冲——婚恋变动）**；喜水木，忌火土金。
  - 主要用神：子水正印（生身）、甲木比肩。
  - 关键争议：争合（两财争一甲——男命妻=财，两财争合主感情多角、选择摇摆）。
  - 预注册主题：①**两财争合——感情纠葛/多角关系**；②**夫妻宫（日支子）逢冲——婚恋变动/波折**；③水木岁运（印比）帮身→感情趋稳。
  - 推翻条件：感情稳定无多角或婚恋平顺 → 争合/宫冲预测需重估。

- 解析：**两个追求者**（两正财争合日主——两异性追求 ✓）；**纠结不定**（争合——选择摇摆 ✓）；**后分手**（子午冲夫妻宫——婚恋变动/分手 ✓）。
