# Case 053 · 天克地冲流年（岁运与原局）· 岁运

- 类别：岁运（天克地冲）
- 四柱：壬午 丙午 丙寅 己丑（乾造）
- 大运：壬子运（壬丙天克 + 子午冲）
- 流年：丙子年（丙壬冲 + 子午冲）
- 设计意图：验证天克地冲流年的最大变量作用

## 预期结论（先给定）
- 原局：丙火日主午月（羊刃当令），午午火局+寅木印生——身极旺（羊刃格）
- 大运壬子：壬丙天克（七杀）+ 子午冲（官杀冲刃）——**天克地冲大运**
- 流年丙子：丙壬冲 + 子午冲——岁运同冲
- 关键点：①羊刃逢冲（子午冲刃）——主剧烈变动、官非/血光提示；②壬水七杀制刃——冲刃+制刃双重；③天克地冲为当年最大变量
- 喜忌：身旺羊刃，喜水（官杀制刃）、金（财），忌木火土（印比食伤）
- 空亡：丙寅日柱，丙寅旬空戌亥——无落空

## 模型输出摘要
- 核心总评：丙火午月（羊刃当令），丙坐寅（长生）、午午火局、丙火比肩透——**身极旺（羊刃格）**；大运壬子为**天克地冲大运**（壬丙天克 + 子午冲刃）、流年丙子岁运同冲（再冲刃）——**羊刃逢冲**，当年最大变量，主剧烈变动、官非/血光提示。不确定度：中。
- 定盘（S1/A）：乾造，日主丙火，月令午（丙火羊刃），藏干午（丁己）寅（甲丙戊）丑（己癸辛）；丙寅旬空戌亥，四支无戌亥，无落空。
- 旺衰：极旺（[CORE] 午月羊刃当令 + 丙坐寅长生根 + 午午火局 + 丙比肩透 + 寅木印生）。
- 格局：**羊刃格**（B 特殊格局）；壬水七杀透年干为制刃之神。
- 病药：刃旺为病；药=壬水七杀制刃（得子水根后制刃有力）、金（财泄）；己土伤官透（坐丑通根）泄秀为辅。原局壬水七杀坐午（胎地）根弱，制刃力微。
- 大运流年：**大运壬子 = 天克地冲**（壬丙天克 + 子午冲刃）；**流年丙子 = 岁运同冲**（丙壬冲 + 子午再冲刃）——天克地冲为当年最大变量；**羊刃逢冲主剧烈变动、官非/血光提示**（[HEURISTIC]）；壬水七杀得子水强根制刃——**冲刃 + 制刃双重**：既有变动凶险之象，亦有七杀制刃成功转权威的可能。
- 岁运喜忌：身旺羊刃，喜水（官杀制刃）、金（财），忌木火土（印比食伤）。
- 六维：扶抑（极旺需抑——水金）、格局（羊刃喜官杀制刃）、调候（午月夏燥需水，壬水制刃兼调候同向）、病药（七杀制刃）、变格（NORMAL）。一致指向 **喜水金，忌木火土**。
- Phase A：最优假设=羊刃格逢冲刃、喜水金忌木火土；关键争议=冲刃凶变 vs 制刃成功之转化；未来高概率主题=壬子运子午冲刃剧烈变动/官非血光提示、水金岁运制刃得用；推翻条件=木火土岁运反顺、水金岁运反逆。
