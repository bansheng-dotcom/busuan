# Case 080 · 后验身心（忌神克用）· 后验

- 类别：后验（身心-状态提示）
- 四柱：己丑 丁丑 庚辰 丙戌（乾造）
- 设计意图：验证身心板块后验——忌神克用时的状态提示（不作医学断语）

## Phase A 预注册（先给定）
- 原局：庚金日主丑月（正印当令），丁火正官透（月干）、丙火七杀透（时干），丑丑辰戌土印局——身强（印旺）
- 最优假设：身强，喜水（食伤泄）木（财），忌火土（官杀印）
- 预注册主题：①官杀（丙丁火）克身 + 三刑（丑戌刑）——身心压力/状态提示；②火土岁运（官杀印）压力增大

## 用户经历（后验输入）
- 2025 乙巳年：感到压力很大、失眠（身心状态差）。

## 预期裁决（先给定）
- 2025 乙巳：乙木正财透 + 巳火七杀（丙火长生）——**忌神（七杀）岁运 + 巳丑拱金？** → 七杀克身 → 压力/失眠与「忌神克用+三刑引动」一致 → **部分命中**（状态主题命中）
- 关键点：①身心板块措辞强制免责声明（传统命理文化语境下的状态倾向，不作医学断语）；②忌神克用为压力应期范式

## 模型输出摘要

### Phase A（预注册，独立于经历）
- 步骤0：庚金日主，月令丑（丑藏己土本气，为庚之正印）；年干己=正印、月干丁=正官、时干丙=七杀；地支丑丑辰戌。空亡：庚辰日属庚辰旬，空亡申酉，原局无申酉、无落空。十二长生：庚坐辰为养地。
- 步骤1：得令（丑月己土正印当令生金）；得地（丑丑辰戌四土印星成势）；得势（己印透、丁官透、丙杀透）。综合倾向 **「身强印旺」**——土印成势，近土多金埋（母多灭子）形态。喜水（食伤泄）、木（财破印）、金（比劫出土），忌火（官杀生印）、土（印）。
- 步骤2：月令丑本气己土正印透月干 → **正印格**。丁火正官透、丙火七杀透——**官杀混杂**（印旺泄官杀，官杀为忌生印）。
- 步骤3：病型「印多为病/母多灭子（土多埋金）」命中（印旺身强印为忌）；「官杀混杂」命中。药=水（食伤泄秀）、木（财破印）。药根气：原局水木俱无，待岁运。
- 步骤4：庚金丑月冬寒，调候丁火炼金；但调候神丁火坐丑无根 → 例外⑤调候降级辅助；身强印旺扶抑为主。
- 步骤5：六维一致 → 喜水木金（食伤财比劫），忌火土（官杀印）。
- 步骤6：地支**丑戌刑**（双丑刑戌）、**辰戌冲**（日支辰-时支戌）——刑冲并见；天干丙丁官杀透、己印透。空亡无落空。神煞：天乙贵人（庚日贵人在丑未，丑为贵人）。
- 步骤10 Phase A 预注册：
  - 最优假设：身强印旺，喜水木金，忌火土。
  - 主要用神：水食伤（泄秀）、木财（破印）。
  - 关键争议：丑戌三刑——身心/官非主题；官杀（火）为忌（生印）。
  - 预注册主题：①**官杀（丙丁）生印——压力/体制束缚；丑戌三刑——身心压力、状态起伏主题**；②火土岁运（官杀印）压力增大；③水木岁运（食伤财）泄秀破印→缓解。
  - 推翻条件：水木岁运反逆或火土岁运反顺 → 本路线被削弱。

### Phase B（后验，读取经历后）
- 用户经历：2025 乙巳年，感到压力很大、失眠（身心状态差）。
- 2025 乙巳解析：乙木正财透（喜——财破印，但乙木坐巳为沐浴、力弱）+ **巳火七杀（忌——丙火七杀之长生根，七杀增旺）**；巳火克庚（七杀克身）、巳火生土（助印为忌）。巳丑无拱（巳酉丑三合缺酉，不作拱局论）。
- 四态裁决：**部分命中**——①「火土岁运压力增大」方向应验：巳火七杀（忌）增旺克身、生印助病——压力/失眠与「忌神克用+官杀引动+三刑」预测一致；②乙木财星（喜）透有缓解之意但根弱（乙坐巳沐浴），不足以扭转压力状态；③身心状态主题（压力、失眠）为当年主象。

- 铁则执行：不反向篡改 Phase A。
