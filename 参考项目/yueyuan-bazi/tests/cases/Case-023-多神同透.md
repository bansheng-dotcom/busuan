# Case 023 · 多神同透（财官印食伤齐透）· 普通复杂

- 类别：普通复杂（多神透出）
- 四柱：甲午 丙寅 戊申 庚申（乾造）
- 设计意图：验证多神同透的格局判定——月令藏干多神透出的取格

## 预期结论（先给定）
- 格局：寅月甲丙戊透——**七杀（甲）、偏印（丙）同透**，按决策链「本气优先」：寅本气甲木（七杀）→ 七杀格为主，印透为辅（杀印相生嫌疑）
- 关键点：①甲丙同透（七杀+偏印——杀印相生成格潜力）；②庚金食神两透（制杀？泄身？）；③戊土坐申（病地）无根——身弱？
- 争议：身弱（戊坐申无根）杀印相生 vs 食神制杀——两种成格路径的竞争
- 喜忌：倾向喜火（印化杀生身），忌金水木（食伤财杀）
- 空亡：戊申日柱，戊申旬空寅卯——月支寅落空亡

## 模型输出摘要
- 核心总评：戊土寅月七杀当令失令，月令本气甲木（七杀）透年干、中气丙火（偏印）透月干——**多神同透**，按决策链本气优先取**七杀格**；日主戊土坐申（病地）无本气根（仅申中戊土余气、午中己土劫财根）→ **中和偏弱**，杀印相生为主线，喜火土忌金水木。不确定度中。
- 定盘：戊土日主，寅月，寅藏甲丙戊、午藏丁己、申藏庚壬戊；空亡寅卯——月支寅落空亡
- 多神同透取格（步骤2决策链）：月令寅藏甲丙戊三干同透（年甲/月丙）→ **本气优先：七杀（甲）格为主**，偏印（丙）为辅 → 杀印相生嫌疑；庚金食神两透（日支申中庚+时干庚）→ 食神制杀为竞争路径
- 旺衰：失令（寅月七杀当令克身）；得地？坐申病地——戊土本气根（辰戌未）全无，仅申中戊土余气+午中己土劫财根+寅中戊土余气（根气弱）；得势？丙火偏印透生身、庚金食神两透泄身 → 综合**中和偏弱**
- 成格路径竞争：身弱杀旺 → 杀印相生（丙火印化杀生身，最合身弱）vs 食神制杀（庚金制甲——但身弱食神泄身、且庚金两透泄身重）→ 倾向杀印相生为主线
- 喜忌：喜火（印化杀生身）、土（比劫帮身），忌金（食伤泄身——虽制杀但泄身重）、水（财生杀）、木（杀攻身）
- 调候：寅月气候温和，非急；身弱以扶抑为主
- 六维：一致指向喜火土、忌金水木
- 岁运：喜火土运，忌金水木运；月支寅落空亡——寅为甲木七杀之本气根，**杀根落空、杀力减**，对身弱为参数级有利
- Phase A：最优假设=中和偏弱七杀格杀印相生喜火土忌金水木；推翻条件=金水木岁运反顺、火土岁运反逆

## 判定
- 结果：**命中**
- 出错模块：无
- 偏差说明：无。七杀格为主（本气优先）、杀印相生嫌疑、身弱喜火忌金水木、寅落空亡减杀——全部与预期一致；「戊坐申无根」细化为本气根全无、余气根尚存，判定仍为中和偏弱，方向一致。
