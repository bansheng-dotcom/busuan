# Case 049 · 空亡（用神落空）· 普通复杂

- 类别：普通复杂（空亡-用神落空）
- 四柱：甲戌 甲戌 丙寅 戊子（乾造）
- 设计意图：验证空亡判定——用神（印星水）落空亡的影响

## 预期结论（先给定）
- 空亡：丙寅日柱，丙寅旬空戌亥——**年支戌、月支戌均落空亡**
- 旺衰：戌月食神当令（戌中戊土是丙之食神），丙坐寅（长生）得印根——身中和
- 关键点：①戌戌伏吟 + 落空亡（食神落空——虚而不实，才华/表达受困？）；②甲木偏印透两（坐戌养地）——印星帮身；③戊土食神透（时干）——食神制杀？无杀
- 喜忌：身中和食神旺，喜木（印制食神）、水（官杀？调候？），忌火土（比劫食伤）、金（财）
- 空亡：丙寅日柱，丙寅旬空戌亥——年支戌、月支戌落空亡

## 模型输出摘要
- 核心总评：丙火戌月（戊土食神当令），丙坐寅（长生）、甲木偏印两透生身——身中和；**丙寅旬空戌亥，年/月支戌均落空亡——食神（戌）落空，虚而不实**，才华表达受困主题；戌戌伏吟。不确定度：中。
- 定盘（S1/A）：乾造，日主丙火，月令戌（戊土食神当令），藏干戌（戊辛丁）寅（甲丙戊）子（癸）；**丙寅旬空戌亥——年支戌、月支戌均落空亡**。
- 旺衰：中和（[CORE] 戌月土当令泄火，但丙坐寅长生根 + 甲木印两透生身——身中和）。
- 格局：月令戌本气戊土食神当令、戊透时干 → 食神格；**食神（戌戌）落空亡**——格神虚而不实。
- 病药：身中和，食神当令泄秀为才华；**病=食神落空（才华/表达虚而不实）**；药=甲木印制食神（印制食神护身）、水（官杀调候润燥）。甲木偏印坐戌（养地，戌中无木）根弱。
- 调候：戌月秋燥——水官杀兼调候（润燥），但未至极燥不触发 CLIMATE OVERRIDE（[SCHOOL] 普通状态）。
- 六维：扶抑（身中和需微扶——木）、格局（食神格顺用）、调候（戌月需水润，与喜水同向）、病药（印制食、食神落空）、变格（NORMAL，丙坐寅长生不从）。一致指向 **喜木（印制食神）、水（官杀兼调候），忌火土（比劫食伤）、金（财耗身）**。
- 岁运：喜木水岁运，忌火土岁运；**空亡应期——大运流年填实（值临戌支）或冲空（辰冲戌）之年为食神出空应期**（[HEURISTIC] 填实/冲空）；戌戌伏吟主反复主题。
- Phase A：最优假设=食神落空、喜木水忌火土；关键争议=食神落空吉凶（虚而不实）、印制食神力度；未来高概率主题=木水岁运顺、火土岁运食伤旺泄；推翻条件=火土岁运反顺、木水岁运反逆。

## 判定
- 结果：**命中**
- 出错模块：无
- 偏差说明：无。食神（戌戌）落空判定、身中和、喜忌（喜木忌火土金）、空亡应期（填实/冲空）均与预期一致；仅注：设计意图所述「用神（印星水）」措辞有误——丙火印星为木（甲木），非水；水为丙火官杀。实际验证对象为「食神落空」，主判断不受影响。
