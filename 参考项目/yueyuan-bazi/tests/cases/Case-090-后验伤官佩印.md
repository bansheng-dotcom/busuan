# Case 090 · 后验伤官佩印（学业成就）· 后验

- 类别：后验（伤官佩印-应验）
- 四柱：丁亥 癸卯 甲午 庚午（乾造）
- 设计意图：验证伤官佩印后验——学业/才学成就

## Phase A 预注册（先给定）
- 原局：甲木日主卯月（劫财当令），丁火伤官透、癸水正印透——**伤官佩印**（身弱伤官旺印为用）
- 预注册主题：①印星（水）岁运学业/资质顺；②伤官（火）岁运才华展露但须印护

## 用户经历（后验输入）
- 2021 辛丑年：学业有成，获奖（辛金正官+丑土财——官星？）。

## 预期裁决（先给定）
- 2021 辛丑：辛金正官透 + 丑土财星——官星引动 + 丑中癸水印星（印库）→ 学业成就与「印星护身+官星成器」相关 → **部分命中**（学业主题支持；机制解释待核）
- 关键点：①伤官佩印主才学；②丑中癸水印星藏——印为用

## 模型输出摘要

### Phase A（预注册，独立于经历）
- 步骤0：甲木日主，月令卯（卯藏乙木本气，为甲之劫财）；年干丁=伤官、月干癸=正印、时干庚=七杀；地支亥卯午午。空亡：甲午日属甲午旬，空亡辰巳，原局无辰巳、无落空。十二长生：**甲在卯为帝旺**、甲在午为死地、甲在亥为长生。
- 步骤1：得令（卯月乙木劫财当令，**甲木帝旺**）；得地（**亥卯半合木局**——年支亥-月支卯，日支午、时支午死地）；得势（癸水正印透坐卯长生有根）。不利：丁火伤官透坐午（丁火临官禄，伤官旺）、庚金七杀透（坐午被火克、根弱）。综合倾向 **「身强（中和偏强）」**——卯月帝旺当令+亥卯木局+印透，木势强；伤官泄秀有力但不扭转旺势。
- **关键判定（与预期分歧）**：身强 → **「伤官佩印」不成立**（patterns.md 铁则：佩印须身弱、印为用；身旺印为忌时佩印不成立，改论「印克伤官」为病）。喜火（伤官泄秀）、土（财）、金（官杀——身强可任），忌水（印克伤官）、木（比劫）。
- 竞争假设：若判身弱（甲坐午死地+伤官禄旺泄身+杀透）——伤官佩印成立、喜水木——与预期同——**路线级竞争**（喜忌方向相反）。
- 步骤2：月令卯本气乙木劫财 → 建禄/劫财格（B 类特殊格局）。丁火伤官透、庚金七杀透。
- 步骤3：病型检查（身强视角）——「印克伤官」为病（癸水印克丁火伤官——身旺印为忌）；「伤官见官」不命中（庚为七杀）。药=火（伤官泄秀——但被印克）、土（财破印）。药根气：丁火坐午禄根（有力）、土原局无。
- 步骤4：甲木卯月春季温和 → 普通状态，调候辅助。
- 步骤5：六维（身强路线）一致 → 喜火（伤官）、土（财）、金（官杀），忌水（印）、木（比劫）。
- 步骤6：天干丁庚无合、癸丁无合；地支亥卯半合木局、午午（伏吟/伤官重见）。空亡无落空。神煞：桃花（寅午戌见卯，日支午/时支午查 → 桃花在卯，月支卯为桃花，但卯为劫财忌神——桃花带忌，[SUPPLEMENTAL] 感情纠葛主题）。
- 步骤10 Phase A 预注册：
  - 最优假设：**身强（中和偏强）**，伤官佩印不成立；喜火土金（伤官财官），忌水木（印比）。
  - 竞争假设：身弱（伤官佩印）喜水木——路线级竞争。
  - 主要用神：丁火伤官（泄秀）、土财。
  - 关键争议：身强 vs 身弱（卯月帝旺+木局+印透 vs 甲坐午死地+伤官禄旺泄身）。
  - 预注册主题：①火土岁运（伤官财）泄秀生财——才华/学业展露；②水岁运（印）克伤官——才华受阻（身强视角）；③金岁运（官杀）——身强可任为喜。
  - 推翻条件：水印岁运反顺（学业顺）→ 身弱伤官佩印获支持；火土岁运反逆同理。

### Phase B（后验，读取经历后）
- 用户经历：2021 辛丑年，学业有成，获奖。
- 2021 辛丑解析：辛金正官透 + 丑土正财；**丑中癸水正印入丑库**（丑藏癸水——印星引动）；丑午害（流年丑害午）。
- 四态裁决：**部分命中**——①「学业有成获奖」为成就/学业主题，两路线均可部分解释：身强路线——辛金官星引动（官星主名望成就）+丑土财星（喜）——官财年为喜、获奖合理；身弱伤官佩印框架——丑中癸水印星引动（印主学业）亦可解释；②本经历对两路线的判别力有限（辛官+丑财+丑中癸印三象并存），单一年不足定论；③机制解释待核，如实标注。
- 诚实边界：我的 Phase A 判身强（喜火土金忌水木），与预期预注册（身弱喜水木）存在**路线级分歧**——本经历「官星成就」略偏身强用官财解释，但不足以翻案；需水年/火土年复现进一步裁决。
- 铁则执行：不反向篡改 Phase A（两条路线均保留，标注经历倾向）。

### 与预期裁决对照
- 预期：部分命中（学业主题支持；机制解释待核）。我判部分命中 → **裁决一致**；但旺衰判断存在路线级分歧（身强 vs 身弱），见判定。

## 判定
- 结果：部分命中（裁决一致，旺衰路线分歧）
- 出错模块：旺衰判断（身强 vs 身弱）
- 偏差说明：①裁决「部分命中」与预期一致（学业成就主题命中、机制待核）；②**路线级分歧**：我独立判**身强**（卯月甲木帝旺+亥卯半合木局+癸印透），故「伤官佩印」不成立（身旺印为忌），喜火土金忌水木；预期判「身弱伤官佩印」喜水木。2021 辛丑（辛官+丑财+丑中癸印三象并存）对两路线判别力有限，单一年不足定论——标注为流派分歧而非判错，裁决保持部分命中。
