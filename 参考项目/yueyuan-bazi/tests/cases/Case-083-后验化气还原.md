# Case 083 · 后验化气（化气还原岁运）· 后验

- 类别：后验（化气-还原）
- 四柱：壬寅 壬寅 丁卯 乙巳（乾造）
- 设计意图：验证化气格还原（助日主根）岁运的后验

## Phase A 预注册（先给定）
- 原局：丁壬合化木嫌疑（寅月木当令、寅卯木局；丁火巳中微根）——化气倾向，喜木水，忌金土
- 预注册主题：①助化神（木水）岁运顺；②助日主根（火土）岁运或「还原」退常格

## 用户经历（后验输入）
- 2024 甲辰年：变化较大，换了方向（甲木印星透——助化神应顺？但用户说变化大、有波折）。

## 预期裁决（先给定）
- 2024 甲辰：甲木（化神木印）透 + 辰土（泄木耗木）——木土混杂 → 化气格逢辰土（忌神）→ 压力/变化与「忌土」一致 → **部分命中**（主题命中：变化；细节待查）
- 关键点：①化气格喜化神五行，辰土（财）耗木为忌；②甲木透本是印星帮化——但辰土破化，矛盾处标注

## 模型输出摘要

### Phase A（预注册，独立于经历）
- 步骤0：丁火日主，月令寅（寅藏甲木本气，为丁之正印）；年干壬=正官、月干壬=正官、时干乙=偏印；地支寅寅卯巳。空亡：丁卯日属丁卯旬，空亡戌亥，原局无戌亥、无落空。十二长生：丁在卯为病地、在巳为帝旺。
- 步骤1：得令（寅月甲木正印当令生火）；得地（时支巳帝旺根、日支卯藏乙木印、年支月支寅）；得势（乙木偏印透生身、双壬正官透克——水生木印）。综合：身强（印旺）之象，但有 **化气格嫌疑**：
  - 化气判据核查：①天干五合——**丁壬合**（双壬争合日主丁）✓；②化神当令——寅月木当令 ✓；③化神得地支成局——寅卯会木局 ✓；④日主无强根——丁火在巳为帝旺之地但**巳藏丙戊庚（无丁火本气）**，日主根为巳中丙火劫财之根（微根、且在时柱距日主远）；⑤化神不受克——原局无强金克木 ✓。
  - 倾向：**化气格成立（丁壬合化木）**——但日主有巳火帝旺之地，判据④存疑 → **路线级竞争假设**：化气（喜木水）vs 常格身强（喜火土）。化气倾向为最优（化神当令成局、日主根弱）。
- 步骤2：若化气成立 → 按 biange.md HUAGQI 状态机；若不成立 → 退正印格（寅月甲木印）。
- 步骤3：变格体系不套用普通病型；化气内病=破化之物（金克木、火泄木、土耗木），药=木水。
- 步骤4：丁火寅月春温和 → 普通状态；化气例外④「以化神为主」，调候让位。
- 步骤5：六维一致（化气路线）→ 喜木水（化神+生源），忌金（克木）、土（耗木）；火（泄木）有争议（[SCHOOL] 泄木可顺亦可破化）。
- 步骤6：天干**双壬争合丁**（争合之象——婚恋/人际多角主题）、乙印透；地支**寅卯会木局**（月支寅-日支卯）、**寅巳相害（穿）**（月支寅-时支巳）。空亡无落空。神煞：驿马（亥卯未马在巳，日支卯查 → 时支巳为驿马）。
- 步骤10 Phase A 预注册：
  - 最优假设：**丁壬合化木倾向成立**（化气格），喜木水，忌金土；火有争议。
  - 竞争假设：化气不成立 → 常格身强（丁火巳帝旺根+印旺），喜火土——两条路线喜忌方向相反（路线级竞争）。
  - 关键争议：丁火巳根之强弱决定化气成否。
  - 预注册主题：①助化神岁运（木水——亥子寅卯壬癸）顺；②**助日主根（火）或耗化神（土）岁运——「还原」退常格或破化，主变化、波折**；③金运（克木）破化主凶。
  - 推翻条件：助化神岁运反逆或土火岁运反顺 → 化气路线被削弱。

### Phase B（后验，读取经历后）
- 用户经历：2024 甲辰年，变化较大，换了方向。
- 2024 甲辰解析：**甲木偏印透（助化神——应顺）** + **辰土伤官（忌——耗木破化）**；**卯辰相害（穿）**（流年辰害日支卯——夫妻宫/自身宫被穿，主变动）；甲木坐辰（辰藏乙木中气根，木有根）。
- 四态裁决：**部分命中**——①「耗化神（土）岁运主变化/波折」主题命中：辰土耗木破化+卯辰穿引动日支——主变化、波折、方向转变；②甲木透（助化神）与辰土破化混杂——「变化较大、换了方向」与「化气逢土耗木破化」预测一致；③细节（是否彻底破化退常格、还原与否）需更多信息，诚实标注。
- 铁则执行：不反向篡改 Phase A；竞争假设（化气 vs 常格）保留，本经历对化气路线「耗土破化主变化」主题形成单年支持。
