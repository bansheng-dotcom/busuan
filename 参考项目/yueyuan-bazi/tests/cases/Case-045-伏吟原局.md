# Case 045 · 伏吟（原局同柱重现）· 普通复杂

- 类别：普通复杂（干支作用-伏吟）
- 四柱：庚申 甲申 庚申 甲申（乾造）
- 设计意图：验证伏吟判定——四柱同干支重见（两庚申、两甲申）

## 预期结论（先给定）
- 干支作用：庚申重见（年日）、甲申重见（月时）——**伏吟**（同柱干支重现，主反复停滞、应旧事）
- 旺衰：申月金当令（比肩——申中庚金是庚之比肩），庚坐申禄根——身极强（两申禄+比肩）
- 关键点：①伏吟重见——反复、停滞、旧事重演主题；②甲木偏财透（坐申绝地无根）——财星虚浮，比肩夺财；③两申冲两寅？无寅……四申金局
- 喜忌：身强比劫旺，喜火（官杀制）、水（食伤泄），忌金土（比印）、木（财被夺但虚）
- 空亡：庚申日柱，庚申旬空子丑——无落空

## 模型输出摘要
- 核心总评：庚金申月（比肩当令），四申金局、庚坐申禄根、比肩透——**身极强**；庚申重见（年日）、甲申重见（月时）——**伏吟**；甲木偏财两透坐申绝地无根，比肩夺财。不确定度：低。
- 定盘（S1/A）：乾造，日主庚金，月令申（庚金比肩当令），藏干申（庚壬戊）；庚申旬空子丑，四支无子丑，无落空。
- 旺衰：极强（[CORE] 申月金当令 + 庚坐申禄根 + 四申金局 + 比肩透；月令与日主同气）。
- 格局：月令申本气庚金比肩当令 → **建禄格**（B 特殊格局，庚禄在申）；比肩当令不以正格论。
- 干支作用：**伏吟**——庚申（年日）重见、甲申（月时）重见，同柱干支重现，主反复、停滞、应旧事（[HEURISTIC]）；四申冲无寅，伏吟力量纯。
- 病药：**比劫夺财命中**——甲木偏财两透坐申（绝地）无根，四申比劫夺财，财星虚浮；病=比劫旺夺财，药=官杀（火，原局无）制比劫、食伤（水，原局无）泄比劫。
- 调候：申月秋、气候温和，非极端，不触发 CLIMATE OVERRIDE；调候非急。
- 六维：扶抑（身强需克泄耗——火水）、格局（建禄喜财官食伤）、调候（非急）、病药（比劫夺财）、变格（NORMAL）。一致指向 **喜火（官杀制）、水（食伤泄），忌金土（比印）、木（财被夺但虚）**。
- 岁运：喜火水岁运，忌金土岁运（比劫更旺）；伏吟岁运加重反复/停滞/旧事主题；比劫旺岁运财更被夺。
- Phase A：最优假设=伏吟、比劫夺财、身强喜火水忌金土木；关键争议=四申金局过旺、财星虚浮；未来高概率主题=火水岁运制泄得用、金土岁运比劫夺财；推翻条件=金土岁运反顺、火水岁运反逆。

## 判定
- 结果：**命中**
- 出错模块：无
- 偏差说明：无。伏吟判定、身极强、比劫夺财病型、喜忌（喜火水忌金土木）、空亡（无落空）均与预期一致。
