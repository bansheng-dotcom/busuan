# Case 034 · 母多灭子（土多埋金）· 普通复杂

- 类别：普通复杂（病药-母多灭子）
- 四柱：戊戌 己未 庚戌 戊寅（乾造）
- 设计意图：验证母多灭子病型——印星（土）过旺至极、日主（金）被淹没

## 预期结论（先给定）
- 病型：庚金日主未月（正印当令？未中己土是庚之正印——未月己土当令 → 印当令），天干戊己土印透三（戊年/己月/戊时）、地支未戌戌土局——**土多埋金（母多灭子）命中**
- 旺衰：印多至极——土多埋金，金被埋而非被生 → 「印多身衰」（母多灭子）
- 关键点：①土极旺（三印透+三土支）——母多灭子（土多埋金）成立，非印多为病（已达灭子极端）；②庚金坐戌（衰地）根弱被埋；③寅木财星（时支）制印？寅中甲木克土——财破印之救应？
- 喜忌：喜木（财破印）、水（食伤泄秀流通），忌火土（印比——火生土、土埋金）、金（比劫？比劫帮身抗印可）
- 空亡：庚戌日柱，庚戌旬空寅卯——时支寅落空亡

## 模型输出摘要
- 核心总评：庚金未月，己土正印当令，天干戊己戊三透印星，地支未戌戌三土支，土势极旺而庚金仅坐戌（衰地）余气根、根弱被埋——**母多灭子（土多埋金）命中**，已达「印多至极」极端，非一般印多为病。不确定度：中。
- 定盘（S1/A）：乾造，日主庚金，月令未（己土正印当令），藏干未（己丁乙）戌（戊辛丁）寅（甲丙戊）；**庚戌旬空寅卯，时支寅落空亡**。
- 旺衰：身衰（[CORE] 土印极旺是生我者但过满成埋，庚坐戌衰地、根仅戌中辛金余气，寅中无金；「印多身衰」——母多灭子，非印旺身强）。综合「土多埋金」。
- 格局：月令未，本气己土正印当令，己透月干 → **正印格**；但印为忌（母多灭子，佩印不成立，patterns.md 先决校验）。
- 病药：**母多灭子（土多埋金）命中**——三印透 + 三土支，土满埋金。药 = 木（财破印）+ 水（食伤泄秀流通）；**药根气不足：寅木财星落空亡（虚而不实），水全无透藏**——救应乏力，命局偏「病重药轻」。
- 调候：未月夏月土燥，调候需壬癸水润；但原局水全无（天干无壬癸、地支寅戌未均不藏水）→ 调候神虚浮无根（例外⑤）→ 降级为辅助参考，不进入 CLIMATE OVERRIDE 主裁。
- 六维：扶抑（身弱需扶，但印已非扶身之药，只能靠比劫帮身抗印）、格局（正印格而印为忌，废格）、调候（虚浮降级）、病药（木水为药）、通关（金土交战需水通关——水兼病药与通关）、变格（NORMAL，庚有戌中余气根、不从）。一致指向 **喜木（财破印）、水（食伤泄秀/通关），忌火土（印比——火生土助埋、土埋金）**；金比劫帮身抗印，中性偏喜（[HEURISTIC] 救应，预期亦存疑）。
- 岁运：喜木水岁运（甲寅、壬癸亥子等），忌火土岁运（丙丁巳午、戊己辰戌丑未）；土金运金被埋更深。
- Phase A：最优假设=母多灭子、喜木水忌火土；关键争议=财星落空亡致药力打折、比劫帮身之喜忌存疑；未来高概率主题=木水运转顺、火土运压抑；推翻条件=木水岁运反逆、火土岁运反顺。

## 判定
- 结果：**命中**
- 出错模块：无
- 偏差说明：无。病型（母多灭子/土多埋金）、旺衰（印多身衰）、喜忌（喜木水忌火土）、空亡（时支寅落空）均与预期一致；补充了「寅木财落空亡致破印救应虚而不实」「调候神虚浮降级」两个细节，属加分项。
