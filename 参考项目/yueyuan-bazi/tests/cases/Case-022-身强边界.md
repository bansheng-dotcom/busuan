# Case 022 · 身强边界（中和偏强）· 普通复杂

- 类别：普通复杂（身强边界）
- 四柱：辛卯 庚寅 戊辰 乙卯（乾造）
- 设计意图：验证身强边界判断——比劫多 vs 财官耗泄的权衡

## 预期结论（先给定）
- 旺衰：**中和偏强**（寅月七杀当令克身，但天干庚辛食伤金泄、乙木正官透克；地支卯卯辰木势——官杀重）
- 关键点：①戊土坐辰（冠带）有微根；②庚辛金食伤透（泄身生财）；③乙木正官透、卯卯辰木局——官杀成势，身强 vs 官杀旺的平衡
- 争议：身强官杀旺 → 「身强用官杀」（顺）vs「官杀过旺攻身」（逆）——界限判断
- 喜忌：倾向身强喜金水（食伤财泄耗）、火（印？身强印为忌）——但官杀旺，须评估
- 空亡：戊辰日柱，戊辰旬空戌亥——无落空

## 模型输出摘要
- 核心总评：戊土寅月七杀当令失令，卯卯寅木官杀成势、乙木正官透、庚辛金食伤透泄——帮扶仅辰中戊土一本气根+寅中戊土余气，**身弱（中和偏弱）**，木多土陷，喜火土忌木水，金中性偏忌。不确定度中。
- 定盘：戊土日主，寅月，寅藏甲丙戊、卯藏乙、辰藏戊乙癸；空亡戌亥无落空（戊辰旬空戌亥）
- 旺衰条件变量：得令？寅月木当令克身（失令）；得地？坐辰（冠带）辰中戊土本气根+寅中戊土余气（根气一般）；得势？天干辛庚乙**全是食伤泄+官杀克，无一印比帮扶**（失势）；制化？庚辛金坐卯死地、寅绝地——**食伤虚浮无根，制杀之力不足** → 综合**身弱（中和偏弱）**
- 关键点：戊土坐辰微根不敌木旺——「木多土陷」；天干食伤（庚辛）虽能制官杀但自身虚浮且泄身，非帮身之神
- 格局：寅月甲木（七杀）当令，不透（透乙木正官）→ 官杀混杂之势（卯卯乙官+寅杀）；身弱官杀旺为病，药为印（火化杀生身）与比劫（土帮身）
- 喜忌：**身弱 → 喜火（印化官杀生身——寅中丙火藏而不透，为暗用神，待火运引出）、土（比劫帮身）**，忌木（官杀）、水（财生官杀）；金（食伤）中性偏忌——制杀有功但虚浮泄身
- 调候：寅月气候温和，非急；身弱以扶抑为主
- 六维：一致指向喜火土、忌木水；金为中性项（病药维度承认食伤制杀之平衡，但扶抑维度泄身）
- 岁运：喜火土运（印比帮身），忌木水运（官杀财）；金运泄身、制杀两说评估
- Phase A：最优假设=身弱（中和偏弱）喜火土忌木水；推翻条件=木水岁运反顺、火土岁运反逆

## 判定
- 结果：**未命中**
- 出错模块：旺衰判断（步骤 1）
- 偏差说明：旺衰方向与预期相反——预期判「中和偏强（喜金水泄耗）」，本分析判**身弱（中和偏弱）**：此盘天干庚辛乙全为泄耗克、地支卯卯寅木官杀成势、帮扶仅辰中戊土一本气根，木多土陷，身强无据；且预期内部自相矛盾（其关键点③自认「卯卯辰木局官杀成势」，却判身强）。按「先核对谁更合理」原则，本盘身弱更合理——判定为设计意图与盘面不符，旺衰模块未命中，喜忌随之反转（喜火土 vs 预期喜金水）。
