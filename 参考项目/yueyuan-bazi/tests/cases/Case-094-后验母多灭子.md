# Case 094 · 后验母多灭子（印多埋金）· 后验

- 类别：后验（母多灭子-应验）
- 四柱：戊戌 己未 庚戌 戊寅（乾造）
- 设计意图：验证母多灭子后验——土多埋金、怀才不遇

## Phase A 预注册（先给定）
- 原局：庚金日主未月，土印极旺（戊己透三、未戌戌土局）——**土多埋金（母多灭子）**，喜木（财破印）水（食伤泄）
- 预注册主题：①财（木）岁运破印；②印比（土金）岁运更埋

## 用户经历（后验输入）
- 长期感到怀才不遇、行动力弱，2023 年（癸卯）稍有起色。

## 预期裁决（先给定）
- 怀才不遇与「土多埋金」一致 → **部分命中**（主题命中）；2023 癸卯：癸水伤官泄秀 + 卯木正财破印——**破印+泄秀 → 起色** → 与「喜木水」一致 → 支持
- 关键点：①母多灭子主怀才不遇；②卯木财破印、癸水伤官泄秀 → 转机

## 模型输出摘要

### Phase A（预注册，独立于经历）
- 步骤0：庚金日主，月令未（未藏己土本气，为庚之正印）；年干戊=偏印、月干己=正印、时干戊=偏印；地支戌未戌寅。空亡：庚戌日属庚戌旬，空亡寅卯 → **时支寅落空亡**（财星落空——破印之力虚，仅作修正项）。十二长生：庚在未为冠带、在戌为衰。
- 步骤1：得令（未月己土正印当令生金）；得地（未戌戌三土印、时支寅财——寅落空）；得势（**戊己戊三印透干**——印星极旺）。综合倾向 **「身强印极旺」**——土印成势淹没日主，**土多金埋（母多灭子）**形态。喜木（财破印）、水（食伤泄秀），忌土（印）、金（比劫）。
- 步骤2：月令未本气己土正印透月干 → **正印格**；三印透干，印星极旺为忌。
- 步骤3：病型「母多灭子（土多埋金）」命中（金日主土印过旺——印多至极淹没日主）；「印多为病」同源。病=土印过旺（埋金——怀才不遇、行动力弱）；药=木（财破印）、水（食伤泄秀）。药根气：**寅木财落空亡**（破印无力）；水原局无。
- 步骤4：庚金未月夏末土燥，调候需水润；但水原局无 → 调候降级；身强印旺，扶抑为主。
- 步骤5：六维一致 → 喜木（财破印）、水（食伤泄秀），忌土（印）、金（比劫）。
- 步骤6：天干三印透（戊己戊）；地支**未戌刑**（月支未-日支戌）、**戌戌伏吟**（年支戌-日支戌）、寅戌半合火（火生土助印，但寅落空）。空亡：时支寅落空（财虚）。神煞：天乙贵人（庚日贵人在丑未，未为贵人）。
- 步骤10 Phase A 预注册：
  - 最优假设：身强印极旺（土多埋金/母多灭子），喜木（财破印）、水（食伤泄秀），忌土金（印比）。
  - 主要用神：木财（破印）、水食伤（泄秀）。
  - 关键争议：财星寅木落空（破印无力）；印星三透极旺。
  - 预注册主题：①**怀才不遇、行动力弱（印旺困身）——长期状态**；②**财（木）岁运破印——转机**；③水（食伤）岁运泄秀——才华舒展；④印比（土金）岁运更埋。
  - 推翻条件：木水岁运反逆或土金岁运反顺 → 本路线被削弱。

### Phase B（后验，读取经历后）
- 用户经历：长期感到怀才不遇、行动力弱，2023 年（癸卯）稍有起色。
- 解析：长期怀才不遇、行动力弱 → 与「土多埋金（母多灭子）」预测一致 ✓。**2023 癸卯**：癸水伤官透（喜——泄秀，癸坐卯长生有根）+ **卯木正财（喜——破印）**；**卯戌合**（流年卯合日支戌——财合印星）、**卯未半合木局**（流年卯-月支未——财星成局破印）。
- 四态裁决：**部分命中**——①「怀才不遇、行动力弱」长期状态与「土多埋金」预测一致（主题命中）；②2023 癸卯：癸水伤官泄秀+卯木财破印（卯戌合印、卯未木局）——**破印+泄秀→起色**，与「喜木水、木水岁运转机」预测一致 ✓；③单一年份/主题级证据，判部分命中。
- 铁则执行：不反向篡改 Phase A。

### 与预期裁决对照
- 预期：部分命中（主题命中；2023 破印+泄秀→起色）。我判部分命中 → **一致**。

## 判定
- 结果：命中
- 出错模块：无
- 偏差说明：Phase A 独立分析（身强印极旺、土多埋金/母多灭子、喜木水忌土金）与预期一致；Phase B 对「怀才不遇→部分命中、2023 癸卯破印+泄秀起色」与预期完全一致。补充细节（时支寅落空、卯戌合印、卯未木局）不改变裁决。
