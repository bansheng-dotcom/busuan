# Case 046 · 反吟（原局相冲）· 普通复杂

- 类别：普通复杂（干支作用-反吟）
- 四柱：庚寅 甲申 庚寅 甲申（乾造）
- 设计意图：验证反吟判定——原局寅申双冲（反吟结构）

## 预期结论（先给定）
- 干支作用：庚寅（年日）vs 甲申（月时）——**两组反吟（寅申冲）**：庚甲天克（庚金克甲木）+ 寅申地冲——天克地冲双现
- 旺衰：申月金当令（比肩），庚坐寅（绝地）无根——但月令申金帮身、天干庚金比肩透两——身强
- 关键点：①两组反吟（天克地冲）——剧烈变动、方向逆转主题；②甲木偏财被庚金克（比肩夺财）；③寅申冲——驿马冲（流动/变动）
- 喜忌：身强比劫旺，喜火（官杀制）、水（食伤泄），忌金土（比印）、木（财被夺）
- 空亡：庚寅日柱，庚寅旬空子丑——无落空

## 模型输出摘要
- 核心总评：庚金申月（比肩当令），庚寅（年日）、甲申（月时）——**两组反吟（寅申冲）**：庚甲天克 + 寅申地冲，**天克地冲双现**；身强比劫旺，甲木偏财两透坐申绝地无根被夺。不确定度：低。
- 定盘（S1/A）：乾造，日主庚金，月令申（庚金比肩当令），藏干寅（甲丙戊）申（庚壬戊）；庚寅旬空子丑，四支无子丑，无落空。
- 旺衰：身强（[CORE] 申月金当令 + 庚金比肩两透 + 两申帮身；庚坐寅绝地无根但整体金势旺）。
- 格局：月令申本气庚金比肩当令 → **建禄格**（庚禄在申）。
- 干支作用：**两组反吟（寅申冲，天克地冲）**——庚寅 vs 甲申：天干庚甲相克、地支寅申相冲，主剧烈变动、方向逆转（[HEURISTIC] 反吟）；寅申冲亦为驿马冲（流动/变动主题）。
- 病药：**比劫夺财命中**——甲木偏财两透坐申（绝地）无根，被庚金比劫克夺；病=比劫夺财，药=官杀（火，原局无）、食伤（水，原局无）。
- 调候：申月秋、气候温和，非极端，不触发 CLIMATE OVERRIDE；调候非急。
- 六维：扶抑（身强需克泄耗——火水）、格局（建禄喜财官食伤）、调候（非急）、病药（比劫夺财）、变格（NORMAL）。一致指向 **喜火（官杀制）、水（食伤泄），忌金土（比印）、木（财被夺）**。
- 岁运：喜火水岁运，忌金土岁运；反吟岁运主剧烈变动、方向逆转；驿马冲引动主流动/变动。
- Phase A：最优假设=反吟（天克地冲）、比劫夺财、身强喜火水忌金土木；关键争议=寅申冲两组力量、反吟凶象；未来高概率主题=火水岁运制泄得用、金土岁运比劫夺财；推翻条件=金土岁运反顺、火水岁运反逆。
