# Case 050 · 身弱从儿边缘（临界盘）· 普通复杂

- 类别：普通复杂（从格边缘-临界盘）
- 四柱：丙午 乙未 己丑 丁卯（乾造）
- 设计意图：验证身弱/从儿临界判定——食伤（火土）旺、日主己土有微根

## 预期结论（先给定）
- 格局：己土日主未月（比肩当令——未中己土是己之比肩），丙丁火印透两（丙正印/丁偏印——**纠正：丙火是己之正印，丁火是己之偏印**），卯木七杀（时支）——身弱印旺？从儿嫌疑？
- 旺衰：未月土当令（比肩）、午未合火（印）、丙丁印透——身中和偏弱（己坐丑有根，丑中己土）——**不从**（有根）
- 关键点：①从儿嫌疑检查（Root resistance 判据）——日主己土坐丑（本气根）→ 判据1根有力未损 → 倾向不从 ✓；②印星（丙丁火）透干——印星帮身更不从；③食伤（午火？午是己之偏印非食伤——己土食伤=金）……设计复盘：此盘火土旺，非食伤旺，从儿（食伤成势）意图不成立
- 复盘修正：本盘实为「印旺身弱」结构（火印多、己土有根）——印多为病？还是身弱用印？——己坐丑有根、未月比肩——身不算弱，火印多 → 印多为病（火炎土燥）
- 喜忌：印多土燥，喜水（财制印润局）、金（食伤泄秀），忌火土（印比）、木（官杀生印）
- 空亡：己丑日柱，己丑旬空午未——年支午、月支未均落空亡

## 模型输出摘要
- 核心总评：己土未月（比肩当令），己坐丑（本气根）有根、丙丁火印两透、午未合火——身中和，**火印多→印多为病（火炎土燥）**；**从儿不成立**（Root resistance：日主己土坐丑本气根有力未损 + 印星透干生扶——判据 1/2 均否决从儿）。不确定度：中。
- 定盘（S1/A）：乾造，日主己土，月令未（己土比肩当令），藏干午（丁己）未（己丁乙）丑（己癸辛）卯（乙）；**己丑旬空午未——年支午、月支未均落空亡**。
- 旺衰：中和（[CORE] 未月比肩当令 + 己坐丑本气根 + 丙丁印生身；卯木七杀克身）。身不算弱。
- 变格检查（biange.md FROM）：**从儿不成立**——己土食伤为金（庚辛申酉），**原局无金，食伤未成势**；且判据 1（己坐丑本气根有力未损）→ 不从；判据 2（丙丁印透干生扶）→ 不从。设计意图「食伤（火土）旺」措辞有误：火为己土之印、土为比劫，非食伤。
- 病药：**印多为病（火炎土燥）命中**——火印多（丙丁透 + 午未合火）、土燥；药=水（财制印润局）、金（食伤泄秀）；原局水金皆无，药虚，待岁运。
- 调候：未月夏月燥——调候需水润；但原局水全无，调候神虚浮无根（例外⑤）→ 降级为辅助参考。
- 六维：扶抑（身中和需流通——水金）、格局（月令比肩不取正格，退以旺衰论）、调候（夏燥需水但原局无水，降级）、病药（印多为病）、变格（NORMAL）。一致指向 **喜水（财制印润局）、金（食伤泄秀），忌火土（印比）、木（官杀生印）**。
- 岁运：喜水金岁运，忌火土岁运（印比助燥）；卯木七杀生火助印（忌神引化）；午未印星落空（[SUPPLEMENTAL] 印多为病落空反减病，参数级）。
- Phase A：最优假设=印多为病（非从儿）、喜水金忌火土木；关键争议=从儿不成立（Root resistance）、印旺身强与否；未来高概率主题=水金岁运制印泄秀顺、火土岁运燥热压抑；推翻条件=火土岁运反顺、水金岁运反逆。

## 判定
- 结果：**命中**
- 出错模块：无
- 偏差说明：无。从儿不成立（Root resistance 判据完整）、印多为病修正、身中和、喜忌（喜水金忌火土木）、空亡（午未落空）均与预期一致；补充设计意图「食伤（火土）旺」措辞有误（己土食伤为金）的标注——预期结论本身已自我修正为印多为病，结论一致。
