# Case 013 · 四库全现（多库）· 极端结构

- 类别：极端结构（多库）
- 四柱：甲辰 己未 戊戌 癸丑（乾造）
- 设计意图：验证多库（辰未戌丑四库全现）的评估——逐个查库性、库中藏干、冲合关系

## 预期结论（先给定）
- 格局：非变格；未月土当令，日主戊土身强（未戌辰丑土势成）
- 旺衰：强（土当令 + 四库土势）
- 关键点：①四库全现，须**逐个查库中所藏十神**（辰藏戊乙癸/未藏己丁乙/戌藏戊辛丁/丑藏己癸辛），不笼统论「库多=财多」；②丑未冲、辰戌冲（两对冲）——须评估冲破对库中藏神的影响；③甲己合（年甲-月己）合化土？未月土当令化神土——可合化，助旺
- 喜忌：身强土旺，喜金（食伤泄）、水（财）、木（官杀制），忌火土（印比）
- 空亡：戊戌日柱，戊戌旬空辰巳——年支辰落空亡

## 模型输出摘要
- 核心总评：戊土未月当令，辰未戌丑四库全现、土势极旺，**身强**（非变格——土专旺嫌疑但身强不致极旺成一方独霸且财官食伤有藏有透，未达专旺纯度，按普通身强论），喜金水木忌火土。不确定度中（甲己合化与两冲开库的C级判断）。
- 定盘：戊土日主，未月；辰藏戊乙癸、未藏己丁乙、戌藏戊辛丁、丑藏己癸辛；空亡辰巳——年支辰落空亡
- 逐库查（以戊日主十神）：辰=比肩（戊）/正官（乙）/正财（癸）；未=劫财（己）/正印（丁）/正官（乙）；戌=比肩（戊）/伤官（辛）/正印（丁）；丑=劫财（己）/正财（癸）/伤官（辛）——**四库皆土库，非「库多=财多」**，财（癸水）仅藏辰丑
- 地支关系：丑未冲、辰戌冲——**两对冲**；[HEURISTIC] 墓库引动须先查库性：库中所藏以土（比劫）为主，冲开土库主土气动荡、比劫夺财象；财（癸）藏辰丑逢冲有「库开财显」之机，但比劫同旺夺财亦重——墓库吉凶两派对立，并列标注，不直接断「冲库发财」
- 甲己合：年甲（七杀）与月己（劫财）相合，未月土当令化神土当权 → [C级] 倾向合化土助旺；但甲木坐辰有乙木余气微根，化不纯，标注「合化程度存疑，无论化与不化，土势皆增」
- 旺衰：强（未月土当令+四库土势+甲己合土助旺），日主戊坐戌（比肩库根）得地
- 喜忌：身强土旺，喜金（食伤泄秀）、水（财——辰丑中癸水）、木（官杀制身），忌火土（印比助旺）
- 调候：未月夏燥，但气候非极端至极、身强土旺以扶抑为主，调候为辅（普通状态，CORE>SCHOOL）
- 六维：一致指向喜金水木、忌火土
- 岁运：喜金水木运，忌火土运；辰戌丑未逢冲逢合之年为库动应期（须按墓库P0修正查库性再断）；辰落空亡须亥子财星填实或冲空之年为财应期提示
- Phase A：最优假设=身强喜金水木忌火土；推翻条件=火土岁运反顺、金水木岁运反逆

## 判定
- 结果：**命中**
- 出错模块：无
- 偏差说明：无。四库逐查（皆土库非财库）、丑未辰戌两冲、甲己合化土助旺、身强喜金水木忌火土、年支辰落空亡——全部与预期一致；墓库冲开按 P0 修正查库性、不直接断发财，符合规则。
