# Case 057 · 空亡填实（岁运填实）· 岁运

- 类别：岁运（空亡-填实）
- 四柱：甲辰 戊辰 丙申 庚寅（乾造）
- 大运：乙亥运（亥为原局空亡支？丙申日柱旬空辰巳——无亥）
- 流年：丙辰年（辰填实）
- 设计意图：验证空亡填实的应期判定（用神落空逢填实）

## 预期结论（先给定）
- 空亡：丙申日柱，丙申旬空辰巳——**年支辰、月支辰均落空亡**
- 原局：丙火日主辰月（食神当令？辰中戊土是丙之食神——辰月戊土当令 → 食神格），甲木偏印透、庚金偏财透（坐寅绝地无根）——身弱食神旺（辰辰土泄）
- 流年丙辰：辰填实——食神（土）落空逢填实 → 出空应期
- 关键点：①填实（值临）为出空应期（[CORE] 主流共识）；②食神填实——才华/表达主题被引动；③辰辰伏吟（原局两辰+流年辰）——反复主题
- 喜忌：身弱食神旺，喜木（印）、火（比劫），忌土金（食伤财）、水（官杀）
- 空亡：丙申日柱，丙申旬空辰巳——年支辰、月支辰落空亡

## 模型输出摘要
- 核心总评：丙火辰月（戊土食神当令），**丙申旬空辰巳——年/月支辰均落空亡（食神落空）**；丙坐申（病地）无根、寅中丙火长生根，甲木印透生身、戊土食神透泄身、庚金财透耗身——身弱食神旺；**流年丙辰辰支填实——食神出空应期**，才华/表达主题被引动。不确定度：中。
- 定盘（S1/A）：乾造，日主丙火，月令辰（戊土食神当令），藏干辰（戊乙癸）申（庚壬戊）寅（甲丙戊）；**丙申旬空辰巳——年支辰、月支辰均落空亡**。
- 旺衰：身弱（[CORE] 辰月土当令泄火 + 丙坐申病地无根 + 戊土食神透泄身 + 庚金财透耗身；仅寅中丙火长生根）。
- 格局：月令辰本气戊土食神当令、戊透月干 → **食神格**；**食神（辰辰）落空亡**——虚而不实。
- 病药：身弱食神旺为病（食神泄身）+ 财虚（庚金偏财坐寅绝地无根）；药=甲木印制食神生身（坐辰衰地、辰中乙木余气根——印有微根）、火比劫帮身。
- 空亡应期（[HEURISTIC]）：**填实（值临）为出空应期——流年丙辰辰支填实，食神出空**，才华/表达主题被引动；原局两辰 + 流年辰 = **辰辰伏吟**——反复主题。
- 调候：辰月春末，气候温和，非极端，不触发 CLIMATE OVERRIDE；调候非急。
- 六维：扶抑（身弱需印比——木火）、格局（食神格顺用）、调候（非急）、病药（印比帮身为药）、变格（NORMAL，丙有寅中长生根不从）。一致指向 **喜木（印）、火（比劫），忌土金（食伤财）、水（官杀）**。
- 岁运：喜木火岁运，忌土金水岁运；乙亥大运乙木正印透生身（亥中甲木余气根）；流年丙辰丙火比劫帮身 + 辰填实引动食神。
- Phase A：最优假设=食神落空、身弱食神旺、喜木火忌土金水；关键争议=食神填实吉凶（才华引动 vs 泄身加重）；未来高概率主题=丙辰年比劫帮身+食神出空才华主题、火木岁运帮身顺；推翻条件=土金水岁运反顺、木火岁运反逆。

## 判定
- 结果：**命中**
- 出错模块：无
- 偏差说明：无。辰辰落空判定、身弱食神旺、填实为出空应期、辰辰伏吟反复主题、喜忌（喜木火忌土金水）均与预期一致。
