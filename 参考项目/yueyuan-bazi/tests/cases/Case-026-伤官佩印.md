# Case 026 · 伤官佩印（成格范式）· 普通复杂

- 类别：普通复杂（成格-伤官佩印）
- 四柱：丁亥 癸卯 甲午 庚午（乾造）
- 设计意图：验证伤官佩印成格判定——身弱伤官旺、印为用

## 预期结论（先给定）
- 格局：甲木日主卯月（劫财当令），丁火伤官透（泄身）、癸水正印透（生身）——**伤官佩印**：身弱（卯月木当令但甲坐午泄、丁庚泄耗）伤官旺，癸水印为用化伤生身
- 先决校验：印星（癸水）喜忌——身弱印为用 → 佩印成立 ✓
- 喜忌：喜水（印）、木（比劫），忌火金土（伤官财官）
- 空亡：甲午日柱，甲午旬空辰巳——无落空

## 模型输出摘要
- 核心总评：甲木卯月劫财当令、亥中甲木长生根，身本不弱，但丁火伤官透泄、庚金七杀透克、两午火泄身 → **中和偏弱**；丁火伤官透为病、癸水正印透为药（制伤生身）→ **伤官佩印成立**（先决校验：身弱印为用，佩印成立 ✓），喜水木忌火金土。不确定度中。
- 定盘：甲木日主，卯月，亥藏壬甲、卯藏乙、午藏丁己；空亡辰巳无落空（甲午旬空辰巳）
- 先决校验（patterns.md 一）：印星（癸水）喜忌——身弱/中和，印为用 → **伤官佩印成立** ✓（非印为忌，不落印多为病/枭神夺食）
- 旺衰：得令（卯月木当令）+得地（亥中甲木长生本气根）→ 身有根基；但甲坐午（死地）、丁庚两透泄克、两午火泄 → 综合**中和偏弱**（预期「身弱伤官旺」方向一致，程度略中性化）
- 格局：伤官格透丁（伤官）——身弱伤官旺，癸水印透制伤生身 → 佩印成格；庚金七杀透（坐午无根虚浮）克力弱，印亦能化杀
- 喜忌：喜水（印——制伤生身）、木（比劫帮身），忌火（伤官）、金（七杀）、土（财——午中己土，财生杀）
- 调候：卯月气候温和，非急；身弱以扶抑为主
- 六维：一致指向喜水木、忌火金土（扶抑/格局/病药同向）
- 岁运：喜水木运，忌火金土运；伤官被制之年（印旺岁运）主学业文贵，伤官旺岁运（无印制）主口舌
- Phase A：最优假设=中和偏弱伤官佩印喜水木忌火金土；推翻条件=火金土岁运反顺、水木岁运反逆

## 判定
- 结果：**命中**
- 出错模块：无
- 偏差说明：无。伤官佩印成立（身弱伤官旺、印为用、先决校验通过）、喜水木忌火金土——全部与预期一致；旺衰按中和偏弱略中性化处理，不改变佩印成立与喜忌方向。
