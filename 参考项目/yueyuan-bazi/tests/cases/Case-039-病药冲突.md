# Case 039 · 病药冲突（病药与格局冲突）· 普通复杂

- 类别：普通复杂（病药冲突）
- 四柱：丙午 甲午 庚午 丁丑（乾造）
- 设计意图：验证病药与格局冲突的裁决——官杀（火）为药 vs 官杀克身的冲突

## 预期结论（先给定）
- 格局：庚金日主午月（正官当令——午中丁火是庚之正官），丙丁火官杀透（丙七杀/丁正官）——官杀格
- 旺衰：身弱（午月火旺克身、庚坐午无根，仅丑中辛金余气根）——**官杀攻身**
- 关键点：①官杀极旺（午月当令+丙丁透+三午）身弱——官杀攻身为祸；②病药冲突：从重者论病=官杀无制（杀攻身），药=印（土）化杀生身——但全局火炎土燥，土印被火泄（土生金被火烤）——药根气弱；③调候：夏月燥热，壬癸水润局——水又是官杀之食伤（水克火）？
- 喜忌：身弱杀旺——喜土（印化杀，但炎燥土焦）、金（比劫帮身），忌火（官杀）、木（财生官杀）
- 空亡：庚午日柱，庚午旬空戌亥——无落空

## 模型输出摘要
- 核心总评：庚金午月，丁火正官当令，丙火七杀、丁火正官齐透（**官杀混杂**），三午火局——**官杀攻身，身弱杀旺**；病=官杀无制克身，药=印（土）化杀，但全局火炎土燥、土印根气弱（丑中己土且午丑相害伤根）——**病重药轻**。不确定度：中。
- 定盘（S1/A）：乾造，日主庚金，月令午（丁火正官当令），藏干午（丁己）丑（己癸辛）；庚午旬空戌亥，四支无戌亥，无落空。
- 旺衰：身弱（[CORE] 午月火旺克身 + 三午成势 + 庚坐午无根，仅丑中辛金余气根）——官杀攻身。
- 格局：月令午本气丁火正官当令、丁透时干 → 正官格；丙火七杀透年干 → 官杀混杂。丙坐午（帝旺）杀强、丁坐丑官弱。
- 病药：**官杀攻身为病（从重者论）**；药=印（土）化杀生身——**但土印被火炎烤焦**（丑中己土仅余气、且午丑相害伤根），药根气弱；水食伤制杀亦为药（制官杀护身兼调候），但**原局无水**。病重药轻。
- 调候：午月夏月燥极（三午）——CLIMATE OVERRIDE 检查；调候神（壬癸水）原局虚浮无根（例外⑤）→ 降级为辅助参考；水在此兼「调候 + 食伤制杀」双职，方向与病药一致。
- 六维：扶抑（身弱需印比——土金）、格局（官杀格身弱宜印化杀）、调候（夏燥需水但原局无水，降级）、病药（印土化杀但土焦、水制杀但原局无）、变格（NORMAL，丑中辛金余气根不从）。一致指向 **喜土（印化杀，但炎燥土焦）、金（比劫帮身），忌火（官杀）、木（财生官杀）**；水（食伤制杀兼调候）亦为喜，但原局无水、待岁运。
- 岁运：喜土金水岁运（印比帮身/制杀），忌火木岁运（官杀更旺、财生杀）；火土燥岁运加重病势。
- Phase A：最优假设=官杀攻身、喜土金忌火木；关键争议=印土被烤焦药力不足、水制杀兼调候但原局无；未来高概率主题=土金水岁运转顺、火木岁运官非压力；推翻条件=火木岁运反顺、土金水岁运反逆。

## 判定
- 结果：**命中**
- 出错模块：无
- 偏差说明：无。官杀攻身（身弱杀旺）、病药冲突（印土药焦）、调候（夏燥需水）、喜忌（喜土金忌火木）均与预期一致；补充水食伤制杀兼调候的双职视角与午丑相害伤土根的细节。
