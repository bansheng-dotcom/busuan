# Case 063 · 魁罡逢冲（岁运冲魁罡）· 岁运

- 类别：岁运（特殊格局-魁罡逢冲）
- 四柱：壬辰 壬寅 庚辰 丙戌（乾造）
- 大运：庚戌运（与日支辰？戌辰冲）
- 流年：甲戌年（戌辰冲——魁罡逢冲）
- 设计意图：验证魁罡逢冲的剧烈变动（魁罡冲则发/凶？）

## 预期结论（先给定）
- 魁罡：庚辰日（魁罡日）——辰戌冲（日支辰-流年戌冲）——**魁罡逢冲**
- 原局：庚金日主寅月（偏财当令？寅中甲木是庚之偏财——寅月甲木当令 → 偏财格），壬水食神双透（年/月干），丙火七杀透（时干）——身弱财旺（寅月财耗、庚坐辰养地微根）
- 流年甲戌：戌辰冲（魁罡逢冲）+ 甲木偏财透
- 关键点：①魁罡逢冲主剧烈变动（古有「魁罡冲则发」之说要件是身强；身弱逢冲则凶）——**须按身弱身强区分**；②庚金坐辰（养地）根弱——身弱魁罡逢冲主凶变/变动；③甲木偏财透——财与变动关联
- 喜忌：身弱财旺，喜土（印生身）、金（比劫），忌木（财）、火（官杀）、水（食伤泄）
- 空亡：庚辰日柱，庚辰旬空申酉——无落空

## 模型输出摘要

**步骤0 定盘**：庚金日主，月令寅（寅藏甲木本气，为庚之偏财）；年干壬=食神、月干壬=食神、时干丙=七杀；地支辰辰寅戌。空亡：庚辰日属庚辰旬，空亡申酉，原局无申酉、无落空。十二长生：庚坐辰为养地。**庚辰日为魁罡日**（魁罡四日：庚辰/壬辰/戊戌/庚戌）。

**步骤1 旺衰**：失令（寅月甲木偏财当令耗身）；得地（年支辰、日支辰、时支戌均藏戊土偏印微根，庚坐辰养地）；得势（双壬食神泄身、丙火七杀克身——克泄交加）。综合倾向 **「身弱」**——财旺耗身、食神泄、七杀克，仅赖辰戌土印星微根。喜土（印）、金（比劫），忌木（财）、火（官杀）、水（食伤泄）。

**步骤2 格局**：月令寅本气甲木偏财，甲木不透 → 取本气 **偏财格**。双壬食神透生财、丙火七杀透克身（坐戌有丁火中气根）。偏财格身弱，食神生财、七杀攻身，财旺为病。

**步骤3 病药**：病型检查——「财多身弱」边缘命中（财旺+身弱）；「七杀无制」不命中（壬水食神可制丙火七杀——食神制杀为救应）。从重者论：病=财旺身弱+七杀攻身；药=土（印生身）、金（比劫帮身）。药根气：辰戌印星有根；比劫原局无，待岁运。

**步骤4 调候**：庚金寅月春季，气候温和，非极端 → 普通状态，格局扶抑为主。

**步骤5 用神六维**：①扶抑：身弱喜印比（土金）；②格局：偏财格身弱喜印比任财，食神制杀为救应；③调候：辅助；④病药：药=印比；⑤通关：火生土生金，土为七杀与日主间通关；⑥变格：NORMAL。六维一致 → 喜土（印）、金（比劫），忌木（财）、火（官杀）、水（食伤）。与预期一致。

**步骤6 干支作用**：天干双壬食神泄、丙七杀克，无五合；地支**辰戌冲**（年支辰-时支戌、日支辰-时支戌，双辰冲戌）、**辰辰自刑**（年支辰+日支辰同支重见，[SCHOOL] 仅作自我纠结主题提示）。空亡无落空。神煞：**魁罡**（庚辰日）——辰戌冲为魁罡逢冲；华盖（申子辰见辰，日支辰为华盖，[SUPPLEMENTAL] 孤高主题）。

**步骤7 大运流年**：
- 大运庚戌：庚金比肩透（喜神帮身）、戌土偏印（喜）；**戌辰冲**（大运戌冲日支辰——魁罡逢冲启动）。
- 流年甲戌：甲木偏财透（忌神）、戌土偏印（喜）；**戌辰冲**（流年戌再冲日支辰——魁罡逢冲叠加）；大运戌-流年戌地支伏吟。
- 岁运互动：双戌冲双辰——魁罡逢冲剧烈；庚金比肩帮身（喜）、甲木财透生杀（忌）。

**步骤8 应期**：①魁罡逢冲（戌辰冲，大运流年双重引动）——剧烈变动/大变动主题（[HEURISTIC]：魁罡冲则发须身强为要件，身弱逢冲主凶变/波折）；②十神星动——甲木偏财透（财星引动、财生杀）；③岁运引动——戌戌伏吟。此盘**身弱**，魁罡逢冲主剧烈变动且带波折，但庚金比肩帮身、戌土印星为救应，变动中有支撑。

**步骤9 领域**：事业——魁罡逢冲主大变动（身弱主波折变动、环境剧变）；财富——甲木财透（忌）生杀，防因财招压/破费；自身——魁罡日性格刚直果决，逢冲之年主人生大节点。

**不确定度**：中（魁罡冲身弱凶变与帮身救应的强度对比为参数级变量）。

## 判定
- 结果：命中
- 出错模块：无
- 偏差说明：主线（魁罡逢冲剧烈变动、身弱须按身强身强区分、喜土金忌木火水）与预期完全一致；补充了「辰辰自刑」「双辰冲戌」「华盖」等结构细节，不改变主结论。
