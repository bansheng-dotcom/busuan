# Case 068 · 流年冲月柱（事业环境变动）· 岁运

- 类别：岁运（宫位-冲月柱）
- 四柱：癸卯 丙辰 丙申 戊子（乾造）
- 大运：戊午运（午与原局？）
- 流年：庚戌年（戌冲辰——冲月柱）
- 设计意图：验证流年冲月柱主事业环境变动

## 预期结论（先给定）
- 原局：丙火日主辰月（食神当令？辰中戊土是丙之食神——辰月戊土当令 → 食神格），癸水正官透（年干）、戊土食神透（时干）——身弱（辰月泄、丙坐申病地无根）
- 流年庚戌：**戌冲辰（冲月柱）**——事业环境/父母宫变动 + 庚金偏财透
- 关键点：①流年冲月柱关事业环境（[HEURISTIC] 应期范式）；②戌辰冲（墓库冲）——先查库性；③庚金偏财透（坐戌养地）——财运变动关联
- 喜忌：身弱食神旺，喜木（印）、火（比劫），忌土金（食伤财）、水（官杀）
- 空亡：丙申日柱，丙申旬空辰巳——月支辰落空亡

## 模型输出摘要

**步骤0 定盘**：丙火日主，月令辰（辰藏戊土本气，为丙之食神）；年干癸=正官、月干丙=比肩、时干戊=食神；地支卯辰申子。空亡：丙申日属丙申旬，空亡辰巳 → **月支辰落空亡**（食神月令落空，食神虚；空亡不参与旺衰计算，仅作修正项）。十二长生：丙坐申为病地。

**步骤1 旺衰**：失令（辰月戊土食神当令泄身）；得地（年支卯藏乙木正印根、日支申病地、时支子胎地）；得势（月干丙火比肩帮身）。不利：癸水正官克、时干戊土食神泄。综合倾向 **「偏弱」**——食神泄、官克，赖卯木印星+月干比肩支撑。喜木（印）、火（比劫），忌土（食伤）、金（财）、水（官杀）。

**步骤2 格局**：月令辰本气戊土食神，戊土透时干 → **食神格**。癸水正官透年干、丙火比肩透月干。食神格身弱，食旺泄身为患。

**步骤3 病药**：病型检查——「伤官见官」不命中（戊土为食神非伤官，丙火伤官为己土）；余不命中。从重者论：病=食神旺泄身+正官克身（身弱）；药=木（印制食生身）、火（比劫帮身）。药根气：卯木正印年支有根；丙火比肩月干透。

**步骤4 调候**：丙火辰月春末，气候温和，非极端 → 普通状态，格局扶抑为主，调候辅助。

**步骤5 用神六维**：①扶抑：偏弱喜印比（木火）；②格局：食神格身弱喜印比；③调候：辅助；④病药：药=木火；⑤通关：水生木生火，木为通关；⑥变格：NORMAL。六维一致 → 喜木（印）、火（比劫），忌土（食伤）、金（财）、水（官杀）。与预期一致。

**步骤6 干支作用**：天干**戊癸合**（时干戊食神合年干癸正官——[C]级：辰月土当令，戊癸合化火须火当令不成立，合而不化、合绊论——食神被合减泄、官被合减克，两害暂缓）；地支**辰申半合水**（月支辰-日支申）、**申子半合水**（日支申-时支子——两处半合水官杀局）、**卯辰相害（穿）**（年支卯-月支辰，[v1.5] 相害=相穿，同一关系非两种）。空亡：月支辰落空（食神虚）。神煞：桃花——亥卯未见子，年支卯查 → 桃花在子（时支子），[SUPPLEMENTAL] 异性缘主题。

**步骤7 大运流年**：
- 大运戊午：戊土食神透（忌——泄身）、午火比劫（喜帮身）；大运戊与年干癸再合（食神合官）。
- 流年庚戌：**庚金偏财透（忌——财耗身，坐戌养地有根）** + 戌土食神（忌）；**戌冲辰**（流年戌冲月支辰——冲月柱）。
- 岁运互动：**戌辰冲冲月柱**（事业环境/父母宫变动，[HEURISTIC] 应期范式）；庚金偏财透（财星引动）；戌土食神泄身（身弱逢食财——负担）。

**步骤8 应期**：①宫位动——流年戌冲月支辰（冲月柱关事业环境/父母宫，主岗位/公司/环境变动）；②十神星动——庚金偏财透（财星引动）；③墓库冲——戌辰冲（先查库性：辰戌均藏戊土食神——冲库引动食伤，主变动/表达类）。三层信号互证 → 事业环境变动+财务变动主题；身弱逢食财，变动中防为财所累、身心透支。

**步骤9 领域**：事业——冲月柱主事业环境变动（岗位/团队/公司层面）；财富——庚金财透但身弱财耗，防为财所累；家庭——冲月柱亦涉父母宫，防长辈健康/家庭事务波动。

**不确定度**：中（身弱程度、戊癸合绊对官食的制衡效果为参数级变量）。
