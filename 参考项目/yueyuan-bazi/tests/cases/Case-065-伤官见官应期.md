# Case 065 · 伤官见官应期（岁运引动）· 岁运

- 类别：岁运（病型应期）
- 四柱：乙巳 丁亥 甲子 庚午（乾造）
- 大运：戊子运（子水印星）
- 流年：庚午年（庚甲七杀克 + 午子冲）
- 设计意图：验证伤官见官/官非应期（岁运引动病型）

## 预期结论（先给定）
- 原局：甲木日主亥月（偏印当令），丁火伤官透（月干）、庚金七杀透（时干）——**伤官+七杀**（非伤官见正官——庚为七杀）
- 大运戊子：戊土偏财透（耗身）、子水印星（生身）
- 流年庚午：庚金七杀克身 + 午子冲（流年午-大运子冲）
- 关键点：①伤官（丁）遇七杀（庚）——伤官驾杀/伤官制杀主题；②庚金七杀克甲——杀年压力；③子午冲（大运流年互冲）——变动引动，伤官见官类官非/口舌主题提示
- 喜忌：身弱（亥月水印生身但甲坐子沐浴有根——中和），喜火（伤官泄）、土（财），忌金（七杀）、水（印泄伤官）
- 空亡：甲子日柱，甲子旬空戌亥——无落空

## 模型输出摘要

**步骤0 定盘**：甲木日主，月令亥（亥藏壬水本气，为甲之偏印）；年干乙=劫财、月干丁=伤官、时干庚=七杀；地支巳亥子午。空亡：甲子日属甲子旬，空亡戌亥 → **月支亥落空亡**（偏印月令落空，印星虚——空亡不参与旺衰计算，[SCHOOL] 分歧派别主张计入，此处仅作修正项标注）。十二长生：甲木在亥为长生。

**步骤1 旺衰**：得令（亥月壬水偏印当令生木，甲木长生在亥）；得地（日支子沐浴藏癸水印、时支午死地、年支巳病地）；得势（年干乙木劫财帮身）。不利：丁火伤官泄、庚金七杀克。综合倾向 **「中和偏弱」**——印星当令生身有力，但月令亥落空打折扣、伤官七杀泄克。喜火（伤官制杀泄秀）、土（财制印）、木（比劫），忌金（七杀）、水（印克伤官）。

**步骤2 格局**：月令亥本气壬水偏印，壬不透 → 取本气 **偏印格**。丁火伤官透月干、庚金七杀透时干。偏印格，伤官七杀并现——**伤官驾杀（伤官制杀）之象**（注意：庚为七杀非正官，此非「伤官见官」病型；[patterns.md] 伤官见官特指伤官与正官并见）。

**步骤3 病药**：病型检查——「伤官见官」不命中（庚为七杀非正官）；「印多为病」边缘（亥水印旺克丁火伤官，印克伤官为病）。从重者论：病=七杀攻身+印克伤官（伤官才华受制）；药=火（伤官制杀泄秀）、土（财制印通关）。药根气：丁火坐亥无根（弱）；土原局无。

**步骤4 调候**：甲木亥月冬寒 → CLIMATE OVERRIDE 倾向；调候甲木冬月用丙火暖局、丁火辅助（表：冬木要火暖）。例外检查：⑤调候神虚浮无根——**丙火原局无、丁火坐亥无根** → 例外⑤成立，调候条件不成立、降级为辅助参考。但调候方向（喜火）与扶抑方向（喜火制杀泄秀）**一致**，无路线冲突——火统一为用神。

**步骤5 用神六维**：①扶抑：中和偏弱，伤官泄秀可用，喜火土木；②格局：偏印格伤官制杀为救应，喜火；③调候：冬木喜火暖（辅助，与扶抑同向）；④病药：药=火（伤官制杀）、土（财制印）；⑤通关：木生火生土流通；⑥变格：NORMAL。六维一致 → 喜火（伤官）、土（财），忌金（七杀）、水（印）。与预期一致。

**步骤6 干支作用**：天干**乙庚合**（年干乙劫财合时干庚七杀——合杀减攻身之力，[C]级合绊）；地支**亥子半会水局**（月支亥-日支子，印局）、**巳午半会火局**（年支巳-时支午）、**子午冲**（日支子-时支午——夫妻宫/自身宫逢冲）。空亡：月支亥落空（偏印虚）。神煞：桃花以年支巳查 → 巳酉丑桃花在午，时支午为桃花（[SUPPLEMENTAL] 异性缘主题）。

**步骤7 大运流年**：
- 大运戊子：戊土偏财透（喜——财制印）、子水偏印（忌）；大运子与日支子伏吟。
- 流年庚午：**庚金七杀透（克身，与乙庚合之庚同字——杀星重现）** + 午火伤官（喜）；**子午冲**（流年午冲日支子、大运子）。
- 岁运互动：子午冲（冲日支自身/婚姻宫+冲大运）；庚金七杀克甲（杀年压力）；午火伤官旺（伤官制杀有制化）。乙庚合杀被流年庚透所破？——庚再透，合杀之力减弱，杀攻身复现。

**步骤8 应期**：①十神星动——庚金七杀透干克身（杀年压力）；②宫位动——子午冲引动日支（自身/婚姻宫）；③岁运引动——大运子与流年午冲。三层独立信号互证 → 主变动+压力+口舌主题。伤官（丁火）逢午而旺制庚杀——**伤官驾杀**，主以才华应对压力，但杀克身+冲宫，变动剧烈、易有口舌/官非类纠纷（[HEURISTIC] 病型被岁运引动=应期重点）。

**步骤9 领域**：事业——伤官制杀，变动中有机会但口舌多、易与上级/规则冲突；婚恋——子午冲引动日支夫妻宫，防感情变动；身心——杀克+子午冲，压力大、易烦躁（传统命理文化语境下的状态倾向，仅作文化解释与自我观察参考，不作疾病预测、诊断或治疗依据）。

**不确定度**：中（月令落空对旺衰的影响、乙庚合杀是否被破为参数级变量）。
