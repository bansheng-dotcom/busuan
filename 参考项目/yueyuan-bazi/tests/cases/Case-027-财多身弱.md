# Case 027 · 财多身弱（经典病型）· 普通复杂

- 类别：普通复杂（病药-财多身弱）
- 四柱：戊申 庚申 壬申 丙午（乾造）
- 设计意图：验证财多身弱病型——财星（金）当令成势、日主无根

## 预期结论（先给定）
- 病型：壬水日主申月（印当令？申中庚金是壬之偏印——**纠正：申月庚金当令，庚金是壬水偏印**，非财。壬水财=火，官杀=土。此盘戊土七杀透、丙火偏财透——财杀旺，庚金偏印生身）
- 修正预期：此盘非财多身弱——是**杀旺（戊土申月长生）印（庚）化杀生身**结构。设计复盘。
- 复盘后预期：身弱（壬坐申长生有根？壬水长生在申——坐申得长生根，不算弱）……设计意图与盘面不符。降级为「官杀旺+印化」测试：戊土七杀透坐申长生（杀有根）、庚金印透化杀生身 → 杀印相生（身弱杀旺印有力 → 贵格）
- 关键点：验证模型能否识别设计意图偏差并正确判定杀印相生
- 空亡：壬申日柱，壬申旬空戌亥——无落空

## 模型输出摘要
- 核心总评：**设计意图偏差——「财多身弱」不成立**：壬水日主财星为火（丙偏财/丁正财），此盘申月庚金当令——庚为壬之**偏印**（非财），天干戊（七杀）、庚（偏印）、丙（偏财）；三申金印星极旺生身、壬坐申（长生）有根 → **身强印旺**（非财多身弱），喜火木土（财食官），忌金水（印比）。不确定度中。
- 定盘：壬水日主，申月，申藏庚壬戊、午藏丁己；空亡戌亥无落空（壬申旬空戌亥）
- 十神复核（壬水日主）：财=火（丙偏财/丁正财）、官杀=土（戊七杀/己正官）、印=金（庚偏印/辛正印）——**申月庚金是偏印，非财**；设计意图「财多身弱」张冠李戴
- 旺衰：得令（申月金印当令生身）+得地（三申金局、壬坐申长生本气根）+得势（庚金偏印透）→ **身强印旺**；克泄耗仅丙火偏财坐午（帝旺）透、戊土七杀坐申（病地微根）、午中丁火
- 病型核对（patterns.md）：财多身弱须「财星当令成势+日主无根或弱」——此盘财星（火）不当令、仅午中丁火+丙透，不「多」；日主身强 → **不命中** ✓
- 格局：申月庚金偏印当令透 → 偏印格；印旺身强，**印为忌**，喜财（丙火——坐午帝旺有力破印）、官杀（戊土制身）、食伤（木泄秀）
- 关键分歧（预期修正方向「身弱杀旺印有力→杀印相生」）：杀印相生范式须**身弱**杀旺印有力（patterns.md 三）；此盘**身强印旺**，按「身强杀旺则不宜印化、印反为忌」，应直接用财破印、官杀制身——预期「身弱杀印相生」不成立，本分析判身强印旺用财
- 喜忌：喜火（财破印——丙坐午帝旺有力）、木（食伤泄秀）、土（官杀制身），忌金（印）、水（比劫）
- 调候：申月秋燥不极端，普通状态，格局为主
- 六维：一致指向身强印旺喜火木土、忌金水
- 岁运：喜火木土运，忌金水运（印比助旺更甚）；丙火财星坐午帝旺为原局唯一有力去病之神
- Phase A：最优假设=身强印旺喜火木土忌金水；推翻条件=金水岁运反顺、火木土岁运反逆

## 判定
- 结果：**部分命中**
- 出错模块：旺衰判断（步骤 1）＋格局取用（步骤 5）——与预期「修正方向」分歧
- 偏差说明：设计意图偏差（财多身弱）识别一致 ✓；但预期复盘修正方向为「身弱杀旺印有力→杀印相生」，本分析独立判 **身强印旺**（三申金印当令+壬坐申长生，身强明确）——按 patterns.md「身强杀旺不宜印化、印反为忌」，喜财破印（丙坐午帝旺）而非喜印比。预期修正方向与盘面实际旺衰不符，此处以独立分析为准。
