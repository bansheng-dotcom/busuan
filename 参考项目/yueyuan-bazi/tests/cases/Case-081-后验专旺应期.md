# Case 081 · 后验专旺（曲直格岁运）· 后验

- 类别：后验（专旺-岁运应验）
- 四柱：甲寅 甲寅 甲寅 甲子（乾造）
- 设计意图：验证专旺格岁运后验——顺旺势岁运应吉

## Phase A 预注册（先给定）
- 原局：甲木日主寅月，三寅比肩+子水印星——**曲直格（木专旺）**，喜水木忌金土，火有争议
- 预注册主题：①水木岁运（亥子寅卯）顺；②金运（申酉官杀）破格压力

## 用户经历（后验输入）
- 2023 癸卯年：事业顺遂，颇有成就（癸水印星+卯木比劫，水木年）。

## 预期裁决（先给定）
- 2023 癸卯：癸水印星 + 卯木比劫——**顺专旺势** → 与「喜水木」一致 → **命中**（顺旺势年应吉）
- 关键点：①专旺格喜印比，水木岁运顺；②子水落空亡不影响主判断

## 模型输出摘要

### Phase A（预注册，独立于经历）
- 步骤0：甲木日主，月令寅（寅藏甲木本气，为甲之比肩）；年干甲=比肩、月干甲=比肩、时干甲=比肩；地支寅寅寅子。空亡：甲寅日属甲寅旬，空亡子丑 → **时支子落空亡**（印星落空，仅作修正项，不影响专旺主判断）。十二长生：甲在寅为临官。
- 步骤1：得令（寅月甲木当令）；得地（三寅临官禄根、时支子印）；得势（三甲比肩透）。克泄耗（金土火）**全无**，唯子水印星为生扶。综合：**曲直格（木专旺）成立**——检查纯度：地支三寅一子（子为印星同类相生不破专旺），无异类有根，纯度极高；按 biange.md ZHUANWANG 状态机取用。
- 步骤2：月令寅为甲木临官，本有建禄之象，但满盘木势、克泄耗全无 → 判 **专旺曲直格**（变格体系，优先于建禄格）。
- 步骤3：变格体系不套用普通病型（patterns.md 五）；专旺内势纯无病；若论病=破格之物（金土火），药=助旺木水。原局无破格之物。
- 步骤4：甲木寅月春季温和，非极端气候 → 普通状态；专旺例外③「以顺势为主」，调候让位。
- 步骤5：六维一致 → 喜水木（印比），忌金（官杀最忌）、土（财次之）；**火（食伤）有泄秀与破格两说（[SCHOOL] 分歧，按是否得根伤旺势评估）**。
- 步骤6：天干三甲比肩、无五合；地支三寅（比肩重见，非自刑）、子水。空亡：时支子落空（印星虚，不参与旺衰）。神煞：驿马（申子辰马在寅，年支子查 → 寅为驿马，三寅皆驿马）。
- 步骤10 Phase A 预注册：
  - 最优假设：曲直格（木专旺），喜水木，忌金土；火有争议（泄秀/破格两说）。
  - 主要用神：水印、木比劫。
  - 关键争议：火（食伤）喜忌的流派分歧；子水印落空。
  - 预注册主题：①**水木岁运（亥子寅卯）顺旺势——事业顺遂**；②金运（申酉官杀）破格压力；③土运（辰戌丑未财星）次之。
  - 推翻条件：水木岁运反逆或金土岁运反顺 → 本路线被削弱。

### Phase B（后验，读取经历后）
- 用户经历：2023 癸卯年，事业顺遂，颇有成就。
- 2023 癸卯解析：**癸水正印透（喜——印星生木）** + **卯木劫财（喜——比劫帮身）**——水木年，顺专旺势。
- 四态裁决：**命中**——癸卯水木岁运顺旺势，与「喜水木」预测一致；事业顺遂成就应验。
- 铁则执行：不反向篡改 Phase A；子水落空不影响主判断。

### 与预期裁决对照
- 预期：命中（顺旺势年应吉）。我判命中 → **一致**。

## 判定
- 结果：命中
- 出错模块：无
- 偏差说明：Phase A 独立分析（曲直格成立、喜水木忌金土、火有争议）与预期一致；Phase B 对 2023 癸卯（癸印+卯比帮身顺旺势）判命中，与预期完全一致。
