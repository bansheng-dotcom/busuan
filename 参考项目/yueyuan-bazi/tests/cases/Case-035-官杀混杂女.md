# Case 035 · 官杀混杂（女命婚恋）· 普通复杂

- 类别：普通复杂（官杀混杂-女命）
- 四柱：戊戌 癸亥 丙午 壬辰（坤造）
- 设计意图：验证女命官杀混杂的婚恋判断——正官七杀并透

## 预期结论（先给定）
- 官杀混杂：丙火日主，癸水（正官）月透、壬水（七杀）时透——**官杀混杂成立（女命夫星杂）**
- 旺衰：亥月水当令（官杀旺），丙火坐午（帝旺）得根——身不算弱（有根）
- 关键点：①女命官杀混杂主婚姻多波折（夫星不止一个）；②去留判断——壬坐辰（墓）无力、癸坐亥（帝旺）有力 → 留官去杀倾向；③午戌半合火（帮身）？
- 喜忌：身中和，官杀旺——喜木（印化杀生身）、火（比劫帮身抗官杀），忌水（官杀）、金（财生官杀）
- 空亡：丙午日柱，丙午旬空寅卯——无落空

## 模型输出摘要
- 核心总评：坤造丙火亥月，壬水七杀当令，癸水正官透月干、壬水七杀透时干——**官杀混杂成立（女命夫星杂）**；丙坐午（帝旺）有强根，身不算弱（中和偏弱）。不确定度：中。
- 定盘（S1/A）：坤造，日主丙火，月令亥（壬水七杀当令），藏干戌（戊辛丁）亥（壬甲）午（丁己）辰（戊乙癸）；丙午旬空寅卯，四支无寅卯，无落空。
- 旺衰：中和偏弱（[CORE] 亥月水当令克身，但丙坐午帝旺根强、午戌半合火帮身，辰中无火）——有根不算弱。
- 格局：月令亥，本气壬水七杀当令、壬透时干 → **七杀格**；癸水正官月干并透 → 官杀混杂。
- 病药：**官杀混杂命中（女命夫星杂）**——去留判断：癸坐亥（禄地/有力）、壬坐辰（墓/无力）→ **留官去杀倾向**；药 = 木（印化杀生身，亥中甲木藏支）+ 火（比劫帮身抗官杀）。
- 调候：亥月冬月偏寒，丙火日主调候需暖；但原局午火帝旺自暖，且调候方向（木火暖身）与扶抑（身弱喜印比）**同向**——非冲突，普通状态。
- 六维：扶抑（身中和偏弱需印比）、格局（七杀格宜印化杀）、调候（木火同向）、病药（去杀留官 + 印化）、通关（金水无交战）、变格（NORMAL，丙坐午强根不从）。一致指向 **喜木（印化杀）、火（比劫帮身），忌水（官杀）、金（财生官杀）**。
- 岁运：喜木火岁运，忌水金岁运（水金运官杀更旺克身）；木运化杀生身为吉。
- Phase A：最优假设=官杀混杂留官去杀、喜木火忌水金；关键争议=去留方向（癸壬力量对比）与食神戊土制杀之助；未来高概率主题=婚恋多波折、需印比岁运帮身；推翻条件=水金岁运反顺、木火岁运反逆。

## 判定
- 结果：**命中**
- 出错模块：无
- 偏差说明：无。官杀混杂（癸官壬杀并透）、旺衰（有根身不算弱）、去留（留官去杀）、喜忌（喜木火忌水金）、空亡（无落空）均与预期一致。补充：戊土食神坐戌通根，兼有食神制杀留官之助（辅助项，不改主判断）。
