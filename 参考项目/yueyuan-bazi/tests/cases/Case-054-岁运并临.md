# Case 054 · 岁运并临（流年与大运同干支）· 岁运

- 类别：岁运（岁运并临）
- 四柱：庚戌 己卯 甲寅 丙寅（乾造）
- 大运：丙寅运（寅木为日主禄根）
- 流年：丙寅年（岁运并临——流年=大运=丙寅）
- 设计意图：验证岁运并临的信号强化（非加倍）

## 预期结论（先给定）
- 原局：甲木日主卯月（劫财当令），寅木禄根（日时双寅）——身强
- 大运丙寅：丙火食神透 + 寅木禄根
- 流年丙寅：**岁运并临**（流年=大运=丙寅）
- 关键点：①岁运并临=同一岁运信号重复出现、主题被强化，**非必凶、不作加倍量化**（[HEURISTIC] 规则）；②丙火食神透（泄秀）——身强食神泄秀为喜；③寅木禄根被引动
- 喜忌：身强喜火（食伤泄）、土（财）、金（官杀），忌水木（印比）
- 空亡：甲寅日柱，甲寅旬空子丑——无落空

## 模型输出摘要
- 核心总评：甲木卯月（劫财当令，甲羊刃在卯）——**羊刃格**，甲坐寅禄根（日时双寅）身强；庚金七杀透制刃、丙火食神透泄秀、己土正财透耗身；**大运丙寅、流年丙寅——岁运并临**（流年=大运），丙火食神泄秀主题被强化。不确定度：低。
- 定盘（S1/A）：乾造，日主甲木，月令卯（乙木劫财当令），藏干戌（戊辛丁）卯（乙）寅（甲丙戊）；甲寅旬空子丑，四支无子丑，无落空。
- 旺衰：偏强（[CORE] 卯月劫财当令为羊刃 + 甲坐寅禄根双现；庚己丙透耗泄）。
- 格局：**羊刃格**（甲羊刃在卯，B 特殊格局）；庚金七杀透年干制刃（坐戌，庚在戌为衰、戌中辛金余气根——七杀有微根制刃）。
- 病药：刃旺为病；药=丙火食神泄秀（身强泄秀为喜）、己土正财耗身、庚金七杀制刃。
- 大运流年：**大运丙寅、流年丙寅 = 岁运并临**——同一岁运信号重复出现、主题被强化，**非必凶、不作加倍量化**（[HEURISTIC]）；丙火食神透泄秀为**喜用被强化**（才华/输出主题）；寅木禄根被引动（比劫主题并存）。
- 岁运喜忌：身强羊刃，喜火（食伤泄）、土（财）、金（官杀制刃），忌水木（印比）。
- 六维：扶抑（身强需克泄耗）、格局（羊刃喜官杀制刃）、调候（卯月春温和，非急）、病药（食伤泄秀+七杀制刃为药）、变格（NORMAL）。一致指向 **喜火土金，忌水木（印比）**。
- Phase A：最优假设=羊刃格身强、喜火土金忌水木；关键争议=岁运并临吉凶（喜用食神被强化→偏吉）；未来高概率主题=丙寅岁运食神泄秀才华发挥、禄根引动竞争并存；推翻条件=水木岁运反顺、火土金岁运反逆。
