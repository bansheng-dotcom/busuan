# Case 089 · 后验枭神夺食（才华受阻）· 后验

- 类别：后验（枭神夺食-应验）
- 四柱：壬子 壬寅 甲子 丙寅（乾造）
- 设计意图：验证枭神夺食后验——才华/表达受阻

## Phase A 预注册（先给定）
- 原局：甲木日主寅月，壬水偏印双透、丙火食神透（时干）——**枭神夺食病型**（壬水枭神夺丙火食神），身强
- 预注册主题：①印星（水）岁运表达受阻/思虑重；②食伤（火）岁运才华释放

## 用户经历（后验输入）
- 2020 庚子年：想写的东西写不出来，工作汇报受阻（庚金七杀+子水枭印）。

## 预期裁决（先给定）
- 2020 庚子：庚金七杀透 + 子水枭神（夺食）——**枭神夺食被引动** → 表达受阻与病型一致 → **命中**（枭神夺食主题）
- 关键点：①枭神夺食=才华被压制主题；②岁运引动病型为应期

## 模型输出摘要

### Phase A（预注册，独立于经历）
- 步骤0：甲木日主，月令寅（寅藏甲木本气，为甲之比肩/临官）；年干壬=偏印、月干壬=偏印、时干丙=食神；地支子寅子寅。空亡：甲子日属甲子旬，空亡戌亥，原局无戌亥、无落空。十二长生：甲在寅为临官。
- 步骤1：得令（寅月甲木当令）；得地（月支寅、时支寅双禄根、年支子、日支子双印）；得势（双壬偏印透）。综合倾向 **「身强印旺」**——木水成势。喜火（食伤泄秀）、土（财破印），忌水（枭印）、金（官杀生印）。
- 步骤2：月令寅为甲木临官 → **建禄格**（B 类特殊格局）。双壬偏印透、丙火食神透。
- 步骤3：病型「枭神夺食」命中（壬水偏印强旺同性克丙火食神，身旺印为忌）。病=枭神夺食（表达/才华受制）；药=火（食伤泄秀）、土（财破印）。药根气：**丙火坐寅长生有力**（食神被夺但根未拔）。
- 步骤4：甲木寅月春季温和 → 普通状态，调候辅助。
- 步骤5：六维一致 → 喜火（食伤）、土（财），忌水（枭印）、金（官杀生印）。
- 步骤6：天干双壬印、丙食，壬丙无合；地支子子双印、寅寅双禄（子寅无冲合、寅寅伏吟）。空亡无落空。神煞：驿马（申子辰马在寅，日支子查 → 寅为驿马）。
- 步骤10 Phase A 预注册：
  - 最优假设：身强印旺（建禄），**枭神夺食病型**（壬水枭神夺丙火食神）；喜火土，忌水金。
  - 主要用神：丙火食神（泄秀，但被夺）、土财。
  - 关键争议：枭神夺食——表达/才华受制主题；食神根未拔（可被救）。
  - 预注册主题：①**印星（水）岁运表达受阻/思虑重（枭神夺食加重）**；②食伤（火）岁运才华释放；③金运（官杀）生印助枭。
  - 推翻条件：水印岁运反顺或火食岁运反逆 → 病型预测被削弱。

### Phase B（后验，读取经历后）
- 用户经历：2020 庚子年，想写的东西写不出来，工作汇报受阻。
- 2020 庚子解析：**庚金七杀透（生印助枭）** + **子水偏印（枭神——印旺夺食）**；子子伏吟（流年子与原局双子——印星重见）。
- 四态裁决：**命中**——庚金七杀生印+子水枭神旺 → **枭神夺食被引动**（印旺夺食神）——表达受阻、写作不顺、汇报受阻，与「枭神夺食主才华被压制」病型预测完全一致。
- 铁则执行：不反向篡改 Phase A。
