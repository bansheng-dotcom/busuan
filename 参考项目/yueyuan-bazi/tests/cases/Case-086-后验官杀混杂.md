## 模型输出摘要

### Phase A（预注册，独立于经历）
- 步骤0：丙火日主，月令亥（亥藏壬水本气，为丙之七杀）；年干戊=食神、月干癸=正官、时干壬=七杀；地支戌亥午辰（坤造）。空亡：丙午日属丙午旬，空亡寅卯，原局无寅卯、无落空。十二长生：丙在午为帝旺。
- 步骤1：失令（亥月壬水七杀当令克火）；得地（日支午帝旺根、年支戌火库藏丁火、时支辰）；得势（戊土食神透、癸水正官透、壬水七杀透——克泄并至）。综合倾向 **「身中和」**——坐午帝旺、戌火库，官杀双透克身但身有根。喜木（印化杀）、火（比劫），忌水（官杀）、金（财生杀）；土（食神）制杀为救应。
- 步骤2：月令亥本气壬水七杀透时干 → **七杀格**；癸水正官透月干 → **官杀混杂（女命夫星杂）**。
- 步骤3：病型「官杀混杂」命中（女命夫星混杂主婚恋波折）。**去留分析**：壬七杀坐辰（辰为壬水墓库，根弱无力）、癸正官坐亥（亥藏壬甲，癸水临官得禄根、有力）→ **留官去杀**（留有力者癸官、去无力者壬杀）；戊土食神坐戌（本气根）有力制壬杀——食神制杀留官为救应。
- 步骤4：丙火亥月冬寒 → CLIMATE OVERRIDE 倾向；丙火冬月调候取壬水映辉+甲木生火。但本局官杀（壬癸）已旺，调候壬水与「官杀为忌」冲突；调候以**甲木（印）生火暖局**为要点（与扶抑喜木同向）。例外权衡：身中和非极弱，官杀旺——判调候辅助、扶抑为主（喜木火）。
- 步骤5：六维一致 → 喜木（印化杀）、火（比劫），忌水（官杀）、金（财生杀）；土（食神）制杀为救应。
- 步骤6：天干**戊癸合**（食神合正官——[C]级：亥月火不当令，合而不化、合绊论；与「食神制杀留官」两机制并存，以力量论留官去杀）；地支**午戌半合火**（日支午-年支戌）、**辰戌冲**（年支戌-时支辰）。空亡无落空。神煞：将星（寅午戌见午，日支午为将星）。
- 步骤10 Phase A 预注册：
  - 最优假设：身中和，官杀混杂（女命夫星杂），**去留留官去杀**（癸官坐亥有力、壬杀坐辰无力；戊食神制杀留官）；喜木火，忌水金。
  - 主要用神：木印（化杀）、火比劫。
  - 关键争议：去留方向（戊癸合绊官 vs 食神制杀留官）；调候壬水与官杀为忌的冲突。
  - 预注册主题：①**官杀混杂——女命婚姻多波折、感情选择摇摆**；②木火岁运（印比）化杀帮身→感情/事业趋稳；③水金岁运（官杀财）→感情压力。
  - 推翻条件：木火岁运反逆或水金岁运反顺 → 本路线被削弱。

### Phase B（后验，读取经历后）
- 用户经历：感情经历——恋爱多次均不顺，2021 年才稳定。
- 解析：恋爱多次不顺 → 与「官杀混杂主婚恋波折」预测一致 ✓。2021 辛丑：辛金正财透（忌——财生杀）+丑土伤官（丙火伤官=己土，丑藏己土；丑中癸水正官入库——**官星收束**）；**丑午害（穿）**（流年丑害日支午——夫妻宫被穿）。
