# Case 051 · 伏吟岁运（岁运与原局同柱）· 岁运

- 类别：岁运（伏吟）
- 四柱：丁亥 辛亥 甲寅 丙寅（乾造）
- 大运：甲寅运（与日柱甲寅伏吟）
- 流年：甲寅年（岁运并临 + 与日柱伏吟）
- 设计意图：验证伏吟 + 岁运并临双重引动

## 预期结论（先给定）
- 原局：甲木日主亥月（偏印当令），寅木禄根（日时双寅）——身强（印生+禄根）
- 大运甲寅：与日柱甲寅**伏吟**，且寅木为禄——禄神伏吟
- 流年甲寅：岁运并临（流年=大运），且与日柱伏吟——**三重伏吟**
- 关键点：①伏吟主反复停滞、应旧事；②岁运并临=信号强化非加倍；③禄神伏吟——身强更旺，喜克泄耗（火土金）
- 喜忌：身强喜火土金，忌水木（印比）
- 空亡：甲寅日柱，甲寅旬空子丑——无落空

## 模型输出摘要
- 核心总评：甲木亥月（偏印当令），甲坐寅禄根（日时双寅）、亥中甲木余气根——身强（印生+禄根）；大运甲寅与日柱**伏吟**、流年甲寅**岁运并临**且再伏吟——**三重伏吟**，寅木禄神伏吟。不确定度：低。
- 定盘（S1/A）：乾造，日主甲木，月令亥（壬水偏印当令），藏干亥（壬甲）寅（甲丙戊）；甲寅旬空子丑，四支无子丑，无落空。
- 旺衰：偏强（[CORE] 亥月印当令生身 + 甲坐寅禄根双现 + 亥中甲木余气）。
- 格局：月令亥本气壬水偏印当令，不透 → 偏印格；身强印为忌（印旺生身）。
- 病药：身强印旺为病；药=火（丁丙食伤泄秀）、土（财，原局无）、金（辛金正官，坐亥无根虚浮）。丁火伤官、丙火食神透干泄秀——身强食伤泄秀为喜。
- 大运流年：**大运甲寅 = 日柱甲寅伏吟**（禄神伏吟）；**流年甲寅 = 岁运并临 + 与日柱伏吟**——三重伏吟。伏吟主反复停滞、应旧事（[HEURISTIC]）；岁运并临=同一岁运信号重复出现、主题被强化（非必凶、不作加倍量化）。
- 岁运喜忌：**身强忌水木（印比）**——甲寅岁运为忌神（比肩禄旺），伏吟加重忌神信号，主反复、停滞、竞争、破财主题（比劫夺财倾向）；丙丁食伤泄秀仍在，泄秀主题并行。
- 六维：扶抑（身强需克泄耗——火土金）、格局（偏印格身强印忌）、调候（亥月冬寒需火暖，丙丁火透为调候兼泄秀，同向）、病药（食伤泄秀为药）、变格（NORMAL）。一致指向 **喜火土金，忌水木（印比）**。
- Phase A：最优假设=身强忌印比、喜火土金；关键争议=伏吟岁运吉凶（忌神被强化主反复停滞）；未来高概率主题=甲寅岁运反复/竞争/破财主题强化、火岁运泄秀得用；推翻条件=火土金岁运反逆、水木岁运反顺。

## 判定
- 结果：**命中**
- 出错模块：无
- 偏差说明：无。伏吟判定（日柱伏吟）、岁运并临、三重伏吟、身强、喜忌（喜火土金忌水木）、空亡（无落空）均与预期一致；补充「身强忌比肩，甲寅忌神岁运伏吟加重主题」的吉凶方向细化。
