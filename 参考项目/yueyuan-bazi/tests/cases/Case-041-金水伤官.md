# Case 041 · 金水伤官喜见官（经典例外）· 普通复杂

- 类别：普通复杂（伤官见官例外）
- 四柱：辛巳 庚子 庚子 癸未（乾造）
- 设计意图：验证「金水伤官喜见官」例外——冬金水伤官、官星（火）调候

## 预期结论（先给定）
- 病型检查：庚金日主子月（伤官当令——子中癸水是庚之伤官），癸水伤官透（时干）——**金水伤官**
- 关键点：①子月冬寒 → CLIMATE OVERRIDE 触发；②金水伤官喜见官——官星（火）调候：午未火（未中丁火）为调候神，但未透、巳中丙火是庚之七杀（巳中丙火）——调候神（火）藏支有根；③调候与伤官见官的例外衔接：金水伤官见火官星不为祸反为喜（调候优先）
- 喜忌：冬金水伤官，喜火（官杀调候）、木（财？伤官生财），忌水（伤官泄身过重）、金（比劫？帮身任伤官可）
- 空亡：庚子日柱，庚子旬空辰巳——年支巳落空亡

## 模型输出摘要
- 核心总评：庚金日主子月，癸水伤官当令透时干——**金水伤官**；子月冬寒触发 CLIMATE OVERRIDE，调候为急，火（官星）为调候神；**金水伤官喜见官**——伤官见火官星不为祸反为喜（调候优先例外）。不确定度：中。
- 定盘（S1/A）：乾造，日主庚金，月令子（癸水伤官当令），藏干巳（丙庚戊）子（癸）未（己丁乙）；**庚子旬空辰巳——年支巳落空亡**。
- 旺衰：身弱（[CORE] 子月水当令泄身 + 庚坐子死地无根 + 年支巳中庚金长生根但巳落空亡减力；天干辛庚比劫透帮身）。
- 格局：月令子本气癸水伤官当令、癸透时干 → **伤官格**（金水伤官）。
- 病药：金水伤官，冬月水旺伤官泄身过重为病；药=火（官星调候暖局，未中丁火、巳中丙火藏支有根——巳虽空、未中丁火在）、土（印制伤官生身）、木（财，伤官生财助调候）。
- 调候：**子月冬寒 → CLIMATE OVERRIDE 触发**；金水伤官喜见官——火为第一用神（暖局解冻，伤官见官不为祸反为喜，与 patterns.md「伤官见官」例外条款衔接）；调候神火藏支有根（未中丁火）→ 调候条件成立，**调候优先于扶抑**。
- 六维：扶抑（身弱需印比——土金）、格局（伤官格）、调候（CLIMATE OVERRIDE 内火为急）、病药（火暖局+土制伤生身）、变格（NORMAL，庚有巳中长生根，不从）。一致指向 **喜火（官杀调候，第一用神）、木（财生官助调候）、土（印生身制伤），忌水（伤官泄身过重）**；金比劫帮身任伤官，中性偏喜。
- 岁运：喜火木土岁运，忌水岁运（伤官更旺泄身）；火官星得根岁运调候得力。
- Phase A：最优假设=金水伤官喜见官、喜火木土忌水；关键争议=身弱伤官泄与调候火制身之权衡、巳空亡减调候根；未来高概率主题=火木岁运顺、水岁运寒湿泄身；推翻条件=水岁运反顺、火岁运反逆。

## 判定
- 结果：**命中**
- 出错模块：无
- 偏差说明：无。金水伤官判定、CLIMATE OVERRIDE 触发、喜见官（火调候）不为祸反为喜、喜忌（喜火忌水）、空亡（巳落空）均与预期一致；补充未中丁火不空故调候神仍有根的细节。
