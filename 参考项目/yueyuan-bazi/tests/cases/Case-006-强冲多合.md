# Case 006 · 强冲多合（地支复杂）· 极端结构

- 类别：极端结构（强冲 / 多合）
- 四柱：丁丑 壬寅 壬寅 丁未（乾造）
- 设计意图：验证地支多合强冲（寅丑暗合、丁壬合、寅未暗合、丑未冲）的复杂作用评估——「合处逢冲」「多合争合」

## 盘面分析（定盘登记）
- 日主：壬水（阳水）
- 月令：寅月（甲木当权，食神当令）
- 地支：丑寅寅未——两寅木（食神）成势、丑土官星、未土官星（丑未冲）
- 天干：丁壬丁——月干丁与日主壬合（丁壬合木）、时干丁再合壬（两丁争合）
- 藏干：丑藏己癸辛，寅藏甲丙戊，未藏己丁乙
- 空亡：壬寅日柱，壬寅旬空辰巳 → 无落空

## 预期结论（先给定，防确认偏误）
- 地支作用：①寅丑暗合（月日支与年支）；②寅未暗合（月日支与时支）；③丑未冲（年支与时支）——**「合处逢冲」「多合争合」结构**
- 天干作用：两丁争合壬——**争合**（夫星/官星争合日主，感情多角象）
- 格局：寅月食神当令（丁火伤官透？丁为伤官）——伤官格？需评估
- 旺衰：壬水寅月泄气（食神泄身），坐寅无根，仅丑中癸水余气根——偏弱
- 关键点：模型应识别「两丁争合一壬」的争合结构 + 「丑未冲破合」的合处逢冲——这是应期与感情分析的关键
- 争议点：丁壬合化木？寅月木当令，化神（木）当令——但两丁争合，化气纯度受影响

## 模型输出摘要
- 核心总评：壬水寅月食神当令泄身，两丁火伤官透干**争合**日主（两丁争合一壬），丑寅寅未多合+丑未冲（合处逢冲）；身弱，喜金水忌木火。不确定度中。
- 旺衰：偏弱（寅月食神泄、两丁伤官透泄，丑中癸水余气根微）
- 格局：非变格；月令寅木本气甲木（食神）不透、中气余气不透 → 取本气为格，食神格身弱
- 干支作用：①天干两丁争合一壬（争合结构，感情/合作多角象）；丁壬合化——寅月木当令化神木，但两丁争合难专，[C级] 倾向合而不化；②地支寅丑暗合、寅未暗合、丑未冲——「合处逢冲」交战，两寅食神成势
- 病药：非典型伤官见官（官未透）；身弱食伤旺为病，药为印比
- 六维：一致指向喜金水、忌木火
- 岁运：喜金水运，忌木火运；丑未冲引动年时宫（祖业/子女）为应期提示
- Phase A：身弱喜金水忌木火；主题①两丁争合主感情多角 ②丑未冲主变动；推翻条件=木火运反顺

## 判定
- 结果：**命中**
- 出错模块：无
- 偏差说明：无。全部预期项命中（两丁争合一壬识别/丑未冲破合=合处逢冲/寅丑寅未暗合/身弱喜金水/感情多角主题/丁壬合化受争合影响的 C 级评估）。
