# Case 032 · 羊刃驾杀（特殊格局）· 普通复杂

- 类别：普通复杂（特殊格局-羊刃驾杀）
- 四柱：戊午 戊午 丁巳 壬寅（乾造）
- 设计意图：验证羊刃格判定——丁火午月羊刃、七杀（壬水）制刃

## 预期结论（先给定）
- 格局：丁火日主午月（羊刃——午为丁之羊刃），壬水七杀透时干（坐寅长生有根）——**羊刃驾杀**（杀有力制刃）
- 旺衰：极旺（午月羊刃当令 + 午午巳火局 + 戊土伤官透泄）
- 关键点：①羊刃格属 B 特殊格局，不入变格顺势逻辑；②壬水七杀坐寅（长生）有力制刃 → 羊刃驾杀成立；③戊土伤官两透（泄秀？制杀？）
- 喜忌：羊刃驾杀——喜水（官杀制刃）、土（食伤泄刃），忌火（比劫帮刃）、木（印生刃）
- 空亡：丁巳日柱，丁巳旬空子丑——无落空

## 模型输出摘要
- 核心总评：丁火午月**羊刃当令**、坐巳（帝旺）、午午巳火局成势，戊土伤官两透泄身 → **极旺**，羊刃格（B 特殊格局，不入变格顺势逻辑）；壬水七杀透时干但**坐寅（病地）无根虚浮**（壬水长生在申、非寅；寅藏甲丙戊无壬水）→ **杀无力制刃，羊刃驾杀不成立（或杀力不足）**，倾向刃旺无制、靠戊土伤官两透泄刃；喜水土忌火木。不确定度中高。
- 定盘：丁火日主，午月，午藏丁己、巳藏丙庚戊、寅藏甲丙戊；空亡子丑无落空（丁巳旬空子丑）
- 格局：午月丁火羊刃 → 羊刃格（[CORE] B 特殊格局，不进入 biange 变格顺势逻辑）
- 旺衰：极旺——午月羊刃当令（得令）、丁坐巳（帝旺）得地、午午巳火局成势、寅中甲木丙火印比生扶；戊土伤官两透泄身（火生土泄）
- 羊刃驾杀核对（patterns.md 三）：羊刃格+七杀有力制刃 → 权威格；**杀无力制刃 → 刃旺无制而凶暴**——壬水七杀坐寅：壬水长生在申（非寅），壬坐寅为**病地**、寅藏甲丙戊无壬水 → **壬水虚浮无根，制刃无力** → **羊刃驾杀不成立**（预期「坐寅长生有根」有误——寅非壬水长生地）
- 实际救应：戊土伤官两透（坐午帝旺、戊在午为帝旺）有力——**伤官泄刃**（间接削刃）为原局主要平衡机制；巳中庚金（正财）藏支耗刃为辅
- 喜忌：喜水（官杀制刃——原局壬水无根，须待水运得根）、土（食伤泄刃——戊土两透有力）、金（财耗刃），忌火（比劫帮刃）、木（印生刃）
- 调候：午月夏燥，但身极旺羊刃以扶抑制化为主，调候为辅助
- 六维：一致指向喜水土金、忌火木；格局维度：羊刃格刃旺无制（病）→ 药=食伤泄（现成）+官杀制（待运）
- 岁运：喜水运（七杀得根制刃——最得力）、土金运（泄耗刃气），忌火运（帮刃）、木运（生刃助凶）；水运为制刃关键
- Phase A：最优假设=羊刃格刃旺无制（七杀虚浮）喜水土忌火木；推翻条件=火木岁运反顺、水土岁运反逆；判别关键=壬水七杀岁运得根是否成驾杀

## 判定
- 结果：**部分命中**
- 出错模块：关键点评估（七杀力量判断，步骤 2/6）
- 偏差说明：羊刃格、极旺、戊土伤官两透、喜水土忌火木——与预期一致 ✓；但「壬水七杀坐寅（长生）有根、杀有力制刃、羊刃驾杀成立」未命中——壬水长生在申非寅、壬坐寅为病地、寅藏甲丙戊无壬水，七杀虚浮无根，制刃无力，应判「刃旺无制（伤官泄刃为实际救应）」而非驾杀成立。喜忌方向不受影响（喜水土忌火木）。
