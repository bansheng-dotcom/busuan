# Case 018 · 从格破格（印透）· 极端结构

- 类别：极端结构（从格破格）
- 四柱：壬午 丁未 癸巳 庚申（乾造）
- 设计意图：验证从格破格判定——财官成势但印（庚金）透干阻从

## 预期结论（先给定）
- 格局：**从格嫌疑（财官火土成势）但庚金正印透干有根（申中庚金本气根）→ 从格不成立**，退论普通
- 关键点：按 Root resistance 判据2「印星透干有根 → 生扶有力 → 倾向不从」——庚金印透 + 申中庚金根 → 不从 ✓
- 退论后：癸水日主午月财旺、未月土官杀、丁火偏财透、壬水劫财帮身（壬在午为胎）——身弱财官旺，喜金水（印比帮身），忌火土（财官）
- 空亡：癸巳日柱，癸巳旬空午未——年支午、月支未均落空亡

## 模型输出摘要
- 核心总评：癸水午月财（火）当令、未月土官杀、丁火偏财透，财官火土成势（从格嫌疑），但庚金正印**透干坐申（申中庚金本气根）**→ 生扶有力 → **从格不成立，退论普通身弱财官旺**，喜金水忌火土。不确定度中。
- 定盘：癸水日主，午月，午藏丁己、未藏己丁乙、巳藏丙庚戊、申藏庚壬戊；空亡午未——年支午、月支未均落空
- 从格判据核对（biange.md FROM）：判据1日主本气根——癸水本气根（亥子丑辰）全无，巳为癸之胎地无癸 → 无根；但**判据2印星（庚金）透干有根（申中庚金本气）→ 「生扶有力」→ 倾向不从** ✓（从格裁决规则：判据2命中即倾向不从）
- 退论旺衰：身弱财官旺——癸水坐巳（胎地）无本气根，午月财当令、未土官杀、丁火偏财透泄耗交加；但庚金正印坐申（临官）有力生身、壬水劫财透干帮身（坐午胎地力弱）
- 喜忌：身弱财官旺，喜金（印生身）、水（比劫帮身），忌火（财）、土（官杀）
- 调候：午月夏燥，但身极弱不从时调候让位（CLIMATE OVERRIDE 例外①）→ 以保身扶抑为先；庚印生身为第一要务
- 六维：一致指向喜金水、忌火土
- 岁运：喜金水运（印比帮身任财），忌火土运（财官旺身愈弱）；午未落空使财官之压力减——财官落空反减轻身弱负担（[HEURISTIC] 忌神落空反减凶），为参数级有利修正
- Phase A：最优假设=身弱财官旺喜金水忌火土；推翻条件=火土岁运反顺、金水岁运反逆

## 判定
- 结果：**命中**
- 出错模块：无
- 偏差说明：无。核心判定命中：从格不成立（庚印透干有根→生扶有力→倾向不从），退论身弱财官旺、喜金水忌火土一致；午未落空对财官压力的减轻（忌神落空减凶）已按辅助修正并入。
