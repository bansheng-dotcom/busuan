# Case 005 · 极端寒暖（冬木无水·调候冲突）· 极端结构

- 类别：极端结构（极端寒暖 + 调候）
- 四柱：壬子 壬子 甲子 丙寅（乾造）
- 设计意图：验证极端气候（冬月寒极）下 CLIMATE OVERRIDE 触发、调候与扶抑/格局冲突的裁决

## 盘面分析（定盘登记）
- 日主：甲木（阳木）
- 月令：子月（壬水当权，冬月寒极）
- 地支：子子子寅——三子水（印星）成势 + 寅木禄根
- 天干：壬壬丙——两壬水（偏印）透 + 丙火（食神）透
- 藏干：子藏癸，寅藏甲丙戊
- 空亡：甲子日柱，甲子旬空戌亥 → 无落空

## 预期结论（先给定，防确认偏误）
- 气候：**冬月寒极（三子水 + 壬透）→ 触发 CLIMATE OVERRIDE**
- 调候需求：甲木冬月需丙火暖局（丙火已透，为调候用神）——**丙火透干，调候神有根（寅中丙火本气），调候条件成立**
- 五条例外检查：①身极弱不从？——甲木坐寅禄根、得水印生，身不算极弱，①不成立；②③④变格？——从势/专旺/化气不成立；⑤调候神虚浮？——丙火透干有根，⑤不成立 → **CLIMATE OVERRIDE 生效，调候（丙火暖局）优先**
- 喜忌：喜火（调候丙火 + 食神）、木（比劫帮身），忌水（印星过旺，寒水灭木——水多木漂风险）
- 关键点：模型应识别「水旺木漂」风险（印多为病）+ 调候优先于扶抑——此盘是调候（喜火）与扶抑（身旺印多本应喜克泄耗……但冬木寒，火既是调候也是泄秀，取火为用）的微妙平衡
- 争议点：身强（印多）按扶抑应喜财官（土金）泄耗，但冬木寒极调候为急——CLIMATE OVERRIDE 下调候胜出，取火

## 模型输出摘要
- 核心总评：甲木子月冬寒极（三子水+壬透），丙火食神透干坐寅有根 → **CLIMATE OVERRIDE 触发，调候（丙火暖局）优先**；身非极弱、非变格、调候神有根，五条例外全不成立；喜火木忌水。不确定度中（调候与扶抑的张力）。
- 旺衰：偏强（子月水当令、三子印星生身、甲坐寅禄）——「寒强」非「暖强」
- 格局：非变格，普通格局印旺身强
- 调候：CLIMATE OVERRIDE 触发 ✓；甲木子月专项丙火暖局命中；五条例外逐条检查全部不成立 → 状态生效，调候优先 ✓
- 病药：命中「印多为病」（冬水印旺寒水灭木，水多木漂方向），药取火暖兼泄
- 六维：收敛喜火（调候第一）、木，忌水（寒印）、金土（生水助寒/耗木）——正确处理「调候与扶抑冲突时 CLIMATE OVERRIDE 胜出，不以土金为用」
- 岁运：喜火运暖局，忌水运寒上加寒、金运生水助寒
- Phase A：调候为急取火喜火木忌水；推翻条件=水运反顺火运反逆

## 判定
- 结果：**命中**
- 出错模块：无
- 偏差说明：无。全部预期项命中（CLIMATE OVERRIDE 触发/五条例外全查且不成立/调候取火/喜火木忌水/水多木漂印多为病识别/调候与扶抑张力正确以调候胜出）。此案例验证了 CLIMATE OVERRIDE 状态机的完整闭环。
