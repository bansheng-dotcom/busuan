# Case 060 · 天克地冲（伏吟反吟互见）· 岁运

- 类别：岁运（天克地冲-应期）
- 四柱：庚戌 乙酉 甲午 丙寅（乾造）
- 大运：甲午运（与日柱甲午伏吟）
- 流年：庚午年（庚甲天克 + 午午伏吟）
- 设计意图：验证天克地冲+伏吟叠加的应期断法

## 预期结论（先给定）
- 原局：甲木日主酉月（正官当令——酉中辛金是甲之正官 → 正官格），庚金七杀透（年干）、丙火食神透（时干）——身弱（酉月金克、甲坐午泄）
- 大运甲午：与日柱甲午**伏吟**
- 流年庚午：庚甲天克（七杀克身）+ 午午伏吟（与原局午伏吟）——**天克地冲？庚克甲为天克，午午非冲为伏吟**——天克+伏吟叠加
- 关键点：①庚金七杀克身（天克）——杀年压力；②午午伏吟（日支+流年）——反复/婚姻宫引动；③伏吟反吟叠加——剧烈变动主题
- 喜忌：身弱官杀旺，喜水（印化杀）、木（比劫），忌金（官杀）、火（食伤泄身生财）
- 空亡：甲午日柱，甲午旬空辰巳——无落空

## 模型输出摘要

**步骤0 定盘**：甲木日主，月令酉（酉藏辛金本气，为甲之正官）；年干庚=七杀、月干乙=劫财、时干丙=食神；地支戌午寅。空亡：甲午日属甲午旬，空亡辰巳，原局无辰巳、无落空。十二长生：甲坐午为死地。

**步骤1 旺衰**：失令（酉月辛金当令克木）；得地（时支寅为甲木临官禄根；日支午死地；年支戌无木根）；得势（月干乙木劫财帮身，但乙坐酉被克）。综合倾向「偏弱」——金旺克木、午火泄身，赖时支寅木禄根支撑。喜木（比劫）、水（印），忌金（官杀）、火（食伤泄身）、土（财生杀）。

**步骤2 格局**：月令酉本气辛金为正官，辛不透（庚七杀透年干）→ 取本气 **正官格**。庚金七杀透与辛金正官同源 → **官杀混杂**。丙火食神透时干坐寅长生有力 → 食神制杀之象；但身弱，食神泄身为负担。格局偏险。

**步骤3 病药**：病型检查——「官杀混杂」命中（正官辛+七杀庚同现）。从重者论：病=官杀混杂攻身（身弱）；药=印星（水）化杀、比劫（木）帮身；丙火食神制杀亦为药但身弱泄气。药原局无水，待岁运。

**步骤4 调候**：甲木酉月，秋季气候温和，非极端 → 普通状态，格局扶抑为主。

**步骤5 用神六维**：①扶抑：偏弱喜印比（水木）；②格局：官杀混杂需去留/制化，印化杀为佳；③调候：辅助；④病药：药=水印化杀、木比劫帮身；⑤通关：水为金木交战之通关；⑥变格：NORMAL。六维一致 → 喜水（印）、木（比劫），忌金（官杀）、火（食伤泄）、土（财生杀）。与预期一致。

**步骤6 干支作用**：天干庚乙合（劫财合杀——乙木合庚金七杀，减杀攻身之力，[C]级合绊）；地支**寅午戌三合火局**（年戌-日午-时寅，食伤成局，泄身极重——虽酉月火非当令不化，但火局之势强）、午戌半合、寅午半合。空亡无落空。

**步骤7 大运流年**：
- 大运甲午：与日柱甲午**伏吟**（伏吟主反复/停滞，引动自身宫与日主）。
- 流年庚午：**庚甲天克**（流年庚七杀克日主甲）+ **午午伏吟**（流年午-日支午，叠加大运午成三午）。
- 岁运互动：天克（庚克甲）+ 伏吟（午午）叠加 = 当年最大变量；三午食神泄身至极、引动日支（自身/婚姻宫）；庚金七杀克身。

**步骤8 应期**：①十神星动——庚金七杀透干克身（杀年压力）；②原局结构响应——午午伏吟（日支+流年）；③岁运引动——三午引动寅午戌火局泄身。三层独立信号互证成立 → 主自身/婚姻宫剧烈变动+压力主题。伏吟主反复停滞、天克主剧烈变动——叠加应「变动激烈但有反复」。

**步骤9 领域**：事业——身弱杀攻+食伤泄，压力大、变动多；自身/婚姻——午午伏吟引动日支，主自身状态起伏、婚姻宫动荡；身心——身弱杀克食伤泄，防身心透支（仅文化语境状态提示）。

**不确定度**：中（身弱程度、火局化与不化为参数级变量）。

## 判定
- 结果：命中
- 出错模块：无
- 偏差说明：主线（天克+伏吟叠加、身弱喜水木忌金火、日支引动）与预期一致；补充了预期未提的「庚乙合绊七杀」「寅午戌三合火局」两个结构细节，不改变主结论方向。
