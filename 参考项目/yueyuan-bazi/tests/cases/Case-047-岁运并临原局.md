# Case 047 · 岁运并临（原局结构）· 普通复杂

- 类别：普通复杂（岁运并临结构基础）
- 四柱：壬子 壬子 丙午 戊子（乾造）
- 设计意图：验证岁运并临相关——原局三子冲一午（反吟）的结构基础

## 预期结论（先给定）
- 干支作用：三子水冲一午火（年子/月子/时子 vs 日午）——**子午冲三重（反吟）**，日主丙火坐午被三子围攻
- 旺衰：子月水当令（正官——子中癸水是丙之正官），丙坐午（帝旺）得根但被三子冲——身弱（官杀旺克身）
- 关键点：①三子冲午——日支夫妻宫被重冲（婚姻/自身冲击主题）；②壬水七杀两透（壬子年/月子）——官杀混杂？壬七杀/癸正官（子中）——杀旺；③戊土食神透（制杀？被水耗）
- 喜忌：身弱杀旺，喜木（印化杀）、火（比劫帮身），忌水（官杀）、金（财生杀）
- 空亡：丙午日柱，丙午旬空寅卯——无落空

## 模型输出摘要
- 核心总评：丙火子月（癸水正官当令），三子冲一午（年/月/时子 vs 日午）——**子午冲三重（反吟）**，日主丙火坐午（帝旺）被三子围攻、根受重冲；壬水七杀两透克身——**身弱官杀攻身**。不确定度：中。
- 定盘（S1/A）：乾造，日主丙火，月令子（癸水正官当令），藏干子（癸）午（丁己）；丙午旬空寅卯，四支无寅卯，无落空。
- 旺衰：身弱（[CORE] 子月水当令克身 + 壬壬七杀两透 + 三子冲午，午根受重冲；仅午中丁己帮身）。
- 格局：月令子本气癸水正官当令，不透；壬水七杀两透得令 → 七杀格倾向；**官杀混杂**（癸官当令 + 壬杀两透）。
- 病药：**官杀攻身（身弱杀旺）**；药=印（木，原局无）化杀生身、比劫（火，午根被冲）帮身；戊土食神透（坐子胎地无根）**制杀无力**。
- 调候：子月冬月寒——调候需火暖局；丙午火自暖（日主丙火坐午），且身弱官杀旺，调候让位于扶抑（例外①：身极弱不从时调候让位倾向）。
- 六维：扶抑（身弱需印比——木火）、格局（七杀格宜印化杀）、调候（冬寒需火但扶抑优先）、病药（印化杀为药）、变格（NORMAL，午根虽被冲但日主有根，不从）。一致指向 **喜木（印化杀）、火（比劫帮身），忌水（官杀）、金（财生杀）**。
- 岁运：喜木火岁运，忌水金岁运；**三子冲午为原局结构变量——日支（夫妻宫）被重冲，主婚姻/自身冲击主题**；子午冲逢岁运引动（如子年午年）加重。
- Phase A：最优假设=官杀攻身、喜木火忌水金；关键争议=午根受冲身弱程度、戊土食神制杀无力；未来高概率主题=木火岁运帮身制杀顺、水金岁运官杀攻身；推翻条件=水金岁运反顺、木火岁运反逆。

## 判定
- 结果：**命中**
- 出错模块：无
- 偏差说明：无。三子冲午（反吟）、身弱官杀攻身、官杀混杂、喜忌（喜木火忌水金）、空亡（无落空）、夫妻宫重冲主题均与预期一致；补充戊土食神坐子无根制杀无力的细节。
