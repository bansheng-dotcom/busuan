# Case 062 · 驿马引动（岁运合冲驿马）· 岁运

- 类别：岁运（神煞-驿马）
- 四柱：壬申 丙午 戊寅 乙卯（乾造）
- 大运：庚戌运（戌与寅？寅午戌会火局）
- 流年：壬寅年（寅为驿马？）
- 设计意图：验证驿马引动的流动/异地主题（非硬断）

## 预期结论（先给定）
- 驿马：申子辰马在寅——年支申 → **驿马在寅**（日支寅为驿马）
- 原局：戊土日主午月（正印当令？午中丁火是戊之正印——午月丁火当令 → 正印格），壬水偏财透（年干）、乙木正官透（时干）——身强印旺（午月火印+寅木生火）
- 流年壬寅：寅为驿马填实/引动——**驿马逢值** → 流动/异地/出行主题提示
- 关键点：①驿马只作主题提示（流动/异地/变动），不改主框架结论；②寅午半合火（日支寅-月支午）——驿马合入印局；③壬水偏财透——财与动有关联
- 喜忌：身强印旺，喜金（食伤泄）、水（财）、木（官杀），忌火土（印比）
- 空亡：戊寅日柱，戊寅旬空申酉——年支申落空亡

## 模型输出摘要

**步骤0 定盘**：戊土日主，月令午（午藏丁火本气，为戊之正印）；年干壬=偏财、月干丙=偏印、时干乙=正官；地支申午寅卯。空亡：戊寅日属戊寅旬，空亡申酉 → **年支申落空亡**。十二长生：戊土在寅为长生。

**步骤1 旺衰**：得令（午月丁火当令生土）；得地（日支寅为长生根；时支卯官星无土根；年支申病地且落空）；得势（月干丙火偏印透生身）。综合倾向 **「身强印旺」**——午月火印当令+丙火透+寅长生根，印比成势；壬水财耗、乙木官克不足以扭转。喜金（食伤泄）、水（财耗），忌火（印）、土（比）；木（官杀）身强可任但生印助病，中性偏忌。

**步骤2 格局**：月令午本气丁火正印不透 → **正印格**。丙火偏印透、乙木正官透、壬水偏财透。印旺格，印多为病之象。

**步骤3 病药**：病型检查——「印多为病」命中（印旺身强，印为忌）。从重者论：病=印星过旺（午火当令+丙透）；药=金（食伤泄秀）、水（财破印）。药根气：壬水坐申有本气根但**申落空亡**（财星根空，力减）；金原局不现，待岁运。

**步骤4 调候**：戊土午月夏月火旺土燥；调候取壬癸水润局，但**壬水坐申落空亡**（调候神根虚）→ 触发例外⑤「调候神虚浮无根」，调候条件不成立、降级为辅助参考；且戊土本喜暖燥，判普通状态，调候不作为主用。

**步骤5 用神六维**：①扶抑：身强喜食伤财（金水）泄耗；②格局：正印格印旺喜食伤泄秀、财破印；③调候：辅助（条件不成立降级）；④病药：药=金水；⑤通关：土生金生水流通；⑥变格：NORMAL。六维基本一致 → 喜金（食伤）、水（财），忌火（印）、土（比），木中性偏忌。与预期喜忌大体一致（木为唯一分歧）。

**步骤6 干支作用**：天干乙木正官透坐卯禄根有力（身强可任）；地支**寅午半合火**（日支寅-月支午）、**寅申冲**（日支寅-年支申）、寅卯半会木（日支寅-时支卯）。空亡：年支申落空（偏财壬水之根空，财星虚）。神煞：驿马两查——以年支申查「申子辰马在寅」→ **日支寅为驿马**；以日支寅查「寅午戌马在申」→ 年支申亦为驿马（但申落空）。[SUPPLEMENTAL] 仅作流动主题标签。

**步骤7 大运流年**：
- 大运庚戌：庚金食神透（喜神）、戌土比肩（忌）；**寅午戌三合火局**（大运戌+日支寅+月支午——火印成局，印更旺、病加重）。
- 流年壬寅：**壬水偏财透（喜神）** + 寅木（藏甲木七杀；驿马）。**寅申冲**（流年寅冲年支申——驿马逢冲）；寅午戌三合火局再引动。
- 岁运互动：驿马（寅）逢值+逢冲——流动/异地/变动主题；壬水财星透（喜）但财根申空；火印局旺（忌）压制行动力。

**步骤8 应期**：①驿马引动（流年寅值驿马 + 寅申冲驿马逢冲）——流动/异地/出行主题（[SUPPLEMENTAL] 仅作主题提示，不改主框架）；②十神星动——壬水偏财透（喜神）；③岁运引动——寅午戌三合火局。主题：变动/流动中带财星机会，但印旺为病，变动受制、行动力被压。

**步骤9 领域**：事业——身强印旺，驿马逢冲主工作变动/异地机遇；财富——壬水财透为喜，但财根申空、戌土比劫有夺财之虑；人际——驿马主题主流动中的人际变化。

**不确定度**：中（财根落空、官星喜忌为参数级变量）。

## 判定
- 结果：命中
- 出错模块：无
- 偏差说明：主线（驿马引动流动主题、身强印旺、喜金水忌火土）与预期一致；补充了预期未提的「寅申冲驿马逢冲」「寅午戌三合火局」「财根申落空亡」等结构细节。唯一参数级分歧：预期喜忌含木（官杀），我判木中性偏忌（身强可任但生印助病），不影响主方向。
