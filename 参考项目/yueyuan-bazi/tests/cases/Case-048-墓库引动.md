# Case 048 · 墓库引动（辰戌冲）· 普通复杂

- 类别：普通复杂（墓库-引动）
- 四柱：丙辰 戊戌 丙辰 庚寅（乾造）
- 设计意图：验证墓库引动判定——辰戌冲对库中所藏十神的影响

## 预期结论（先给定）
- 墓库：辰戌冲（年辰-月戌）——**墓库引动**，须先查库性：辰藏戊乙癸、戌藏戊辛丁
- 旺衰：戌月食神当令（戌中戊土是丙之食神），丙坐辰（冠带）有微根——身中和偏弱
- 关键点：①辰戌冲（P0 修正：先查库中所藏十神、库之喜忌、透藏关系）——辰中癸水（正官）藏、戌中丁火（劫财）藏，冲则库开/动荡？；②丙火食神当令+戊土食神透（月干）——食神格？；③庚金偏财透（坐寅绝地）——财虚
- 喜忌：身弱食神旺，喜木（印制食神？印为用）、火（比劫帮身），忌土金（食伤财）、水（官杀）
- 空亡：丙辰日柱，丙辰旬空子丑——无落空

## 模型输出摘要
- 核心总评：丙火戌月（戊土食神当令），年辰-月戌**辰戌冲——墓库引动**；丙坐辰（冠带）微根、寅中丙火长生根，戊土食神透泄身、庚金偏财坐寅绝地无根——身中和偏弱、食神格。不确定度：中。
- 定盘（S1/A）：乾造，日主丙火，月令戌（戊土食神当令），藏干辰（戊乙癸）戌（戊辛丁）寅（甲丙戊）；丙辰旬空子丑，四支无子丑，无落空。
- 旺衰：中和偏弱（[CORE] 戌月土当令泄火 + 戊土食神透泄身 + 庚金财耗；丙坐辰微根 + 寅中丙火长生根）。
- 格局：月令戌本气戊土食神当令、戊透月干 → **食神格**。
- 墓库（P0 修正）：**辰戌冲为墓库引动——先查库性**：辰藏戊乙癸（癸水正官）、戌藏戊辛丁（辛金正财、丁火劫财）。冲则库开，**藏神显用**——戌中丁火（劫财帮身，喜）与辰中癸水（正官，忌）对冲同显，吉凶交织；丙火日主坐辰（冠带）有根、非以辰为唯一根 → 属「库开释放」倾向；**禁止直接断「逢冲=发财」**（[HEURISTIC] 墓库 P0）。
- 病药：身弱食神旺为病（食神泄身）+ 财虚（庚金偏财坐寅绝地无根）；药=印（木）制食神生身（寅中甲木藏、未透）、火（比劫帮身）。
- 调候：戌月秋、气候温和，非极端，不触发 CLIMATE OVERRIDE；调候非急。
- 六维：扶抑（身弱需印比——木火）、格局（食神格顺用）、调候（非急）、病药（印比帮身为药）、变格（NORMAL，丙坐辰+寅根不从）。一致指向 **喜木（印制食神）、火（比劫帮身），忌土金（食伤财）、水（官杀）**。
- 岁运：喜木火岁运，忌土金水岁运；辰戌冲逢岁运再引动（如戌运辰运）——墓库开合主题；庚金财星虚浮，财主题弱。
- Phase A：最优假设=食神格身弱、喜木火忌土金水；关键争议=辰戌冲库开吉凶（丁火劫财显 vs 癸水正官显）；未来高概率主题=木火岁运帮身顺、土金水岁运泄耗攻身；推翻条件=土金水岁运反顺、木火岁运反逆。

## 判定
- 结果：**命中**
- 出错模块：无
- 偏差说明：无。辰戌冲墓库引动判定、先查库性（辰中癸水、戌中丁火辛金）、库开倾向、身中和偏弱食神格、喜忌（喜木火忌土金水）、空亡（无落空）均与预期一致；补充「库开吉凶交织（丁火劫财 vs 癸水正官对冲）」的细化裁决。
