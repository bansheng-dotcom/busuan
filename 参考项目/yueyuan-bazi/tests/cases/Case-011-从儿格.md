# Case 011 · 从儿格（食伤成势）· 极端结构

- 类别：极端结构（从势-从儿）
- 四柱：乙巳 丙午 乙巳 丙午（乾造）
- 设计意图：验证从儿格判定、食伤（火）成势、日主乙木无根的评估

## 预期结论（先给定）
- 格局：**从儿格成立**——午月火当令（食伤当令）、巳午火局成势、丙火伤官透、乙木日主无根（乙在巳病地、午长生？——乙木长生在午，须评估午是否为乙木之根）
- 关键争议：乙木日主坐巳（病地）无木根，但午为乙木长生——长生是否算「有根」？若算，则从儿有争议（退身弱）；若不算（无本气根），则从儿成立
- 喜忌：喜火土（食伤生财顺），忌水（印——生身反抗）、木（比劫）
- 空亡：乙巳日柱，乙巳旬空寅卯——无落空

## 模型输出摘要
- 核心总评：乙木午月食伤（火）当令，巳午巳午火局成势、丙火伤官透（年时双透），乙木日主无本气根（午为乙之「长生」为虚长生、非通根），且印星（水）全无，**从儿格成立**，喜火土忌水木。不确定度中（长生是否算根的流派分歧）。
- 定盘：乙木日主，午月，巳藏丙庚戊、午藏丁己；空亡寅卯无落空（乙巳旬空寅卯）
- 关键争议（长生算不算根）：乙木「长生在午」是十二长生虚位，非通根——**通根须地支藏干含日主本气**，午藏丁己、巳藏丙庚戊均无乙木 → 乙木无本气根；午之长生位不足以破坏从势纯度 → 从儿成立
- 从格判据核对：判据1无本气根✓；判据2比劫（乙）透干但**无根**（坐巳病地、午长生虚）→ 生扶无显；判据3食伤火成势✓；判据4印星（水）全无✓ → 从儿成立
- 杂气标注：乙木比肩透干而无根，从得假（有杂），岁运逢比劫得根之运有破格风险
- 喜忌：喜火土（食伤生财顺），忌水（印——生身反抗）、木（比劫——帮身反抗）
- 调候：午月夏燥，但从儿（FROM）成立 → CLIMATE OVERRIDE 例外②「从势以顺势为主」，调候让位
- 六维：FROM 从儿喜食伤财（火土）、忌印比（水木），六维一致
- 岁运：喜火土运，忌水（印破格最凶）、木（比劫帮身反抗）运
- Phase A：最优假设=从儿格喜火土忌水木；推翻条件=印比岁运反顺、食伤财岁运反逆；判别关键=乙木比劫岁运得根是否反从

## 判定
- 结果：**命中**
- 出错模块：无
- 偏差说明：无。从儿格成立判定与预期一致（午之长生=虚长生非根、无本气根、印全无），喜火土忌水木一致，空亡核对无误。
