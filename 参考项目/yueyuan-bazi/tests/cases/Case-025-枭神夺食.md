# Case 025 · 枭神夺食（经典病型）· 普通复杂

- 类别：普通复杂（病药-枭神夺食）
- 四柱：癸亥 乙卯 丙申 戊子（乾造）
- 设计意图：验证枭神夺食病型判定——偏印（癸水）夺食神（戊土？丙火日主食神为戊土）

## 预期结论（先给定）
- 病型检查：丙火日主——癸水偏印（壬？丙之偏印为甲木/正印为乙木——**纠正：丙火日主，印星为木**！癸水是丙之正官，非偏印）→ **设计有误，需复盘**：丙火日主印=木（甲偏乙正），食神=土（戊食己伤）。此盘癸水官、乙木正印、戊土食神——无偏印夺食（乙木正印克戊土食神？乙克戊？木克土，乙木克戊土——正印克食神，非枭神夺食）
- 复盘结论：本案例设计意图（枭神夺食）不成立——丙火日主无偏印。**降级为「正印克食神」（印多为病方向）测试**：乙木正印克戊土食神
- 修正预期：印星（乙木）克食神（戊土）——身弱印为用则佩印成立？丙火子月（官当令）身弱，乙木印生身 → 印为用，克食神无碍（佩印）。不命中枭神夺食。
- 关键点：验证模型能否**识别设计错误**（枭神夺食须偏印克食神，正印克食神不算）——防御测试

## 模型输出摘要
- 核心总评：**设计意图偏差——「枭神夺食」不成立**：丙火日主印星为木（甲偏印/乙正印），此盘天干癸乙戊——癸为丙之**正官**（非偏印）、乙为**正印**（非偏印），全盘无甲木偏印 → 无「偏印夺食神」之结构，枭神夺食病型不命中。识别并纠正设计错误。不确定度低。
- 定盘：丙火日主，卯月，卯藏乙、亥藏壬甲、申藏庚壬戊、子藏癸；空亡申酉无落空（丙申旬空辰巳？——丙申日柱，丙申旬空辰巳，无落空）
- 十神复核（丙火日主）：官杀=水（壬七杀/癸正官）、印=木（甲偏印/乙正印）、食伤=土（戊食神/己伤官）——**癸水是正官，非偏印**；偏印为甲木，此盘无甲
- 病型核对（patterns.md 二节）：枭神夺食须「偏印（枭）强旺+食神被克（特指偏印夺食神）」——无偏印（甲木）→ **不命中**；乙木（正印）克戊土（食神）为「正印克食神」，属印护/佩印方向，**不得与枭神夺食混称**（patterns.md 概念澄清）
- 旺衰：卯月正印当令生身、乙木正印透（坐卯禄地有力）、亥中甲木印——印星旺；丙火坐申（病地）无本气火根、癸水正官坐亥（帝旺）透克身 → 印旺身弱倾向
- 喜忌：身弱印为用 → 乙木印生身、克食神（戊）为印护食伤方向（佩印性质），印为用、官（癸）泄之——喜木火（印比帮身），忌水金（官财）
- 调候：卯月气候温和，非急；身弱印旺以扶抑为主
- 六维：一致指向身弱印为用、喜木火忌水金；病型维度：不命中枭神夺食（无偏印）
- 岁运：喜木火运，忌水金运；此盘真正病机为「印旺身弱/印多为病」（卯月印当令+乙透），非枭神夺食
- Phase A：最优假设=印旺身弱、无枭神夺食（设计错误）；推翻条件=若岁运逢甲木偏印强旺夺食则转枭神夺食

## 判定
- 结果：**命中**
- 出错模块：无（防御测试——模型正确识别设计错误）
- 偏差说明：无。模型正确识别「枭神夺食」设计意图不成立：丙火偏印为甲木、此盘无甲；癸水是正官非偏印；乙木正印克戊土食神属佩印/印护方向，与预期复盘结论一致（不命中枭神夺食、降级为正印克食神印护测试）。
