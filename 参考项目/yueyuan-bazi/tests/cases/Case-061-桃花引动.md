# Case 061 · 桃花引动（岁运合冲桃花）· 岁运

- 类别：岁运（神煞-桃花）
- 四柱：辛巳 甲午 己卯 癸酉（乾造）
- 大运：戊戌运（戌与原局卯？卯戌合——桃花合）
- 流年：壬戌年（卯戌合——桃花被合引动）
- 设计意图：验证桃花引动作为婚恋主题提示（非硬断）

- 流年壬戌：卯戌合（日支卯-流年戌合）——**桃花（午）被动？非桃花，但卯戌合引动日支夫妻宫**
- 关键点：①神煞只作主题标签（[SUPPLEMENTAL]）——桃花/夫妻宫引动提示婚恋主题，**不改主框架结论**；②卯戌合引动日支（夫妻宫）——婚恋主题提示；③身弱官星（甲木）透——婚恋与事业关联
- 喜忌：身弱印旺，喜金（食伤泄）、水（财），忌火土（印比）、木（官杀生印）
- 空亡：己卯日柱，己卯旬空申酉——时支酉落空亡

## 模型输出摘要

**步骤0 定盘**：己土日主，月令午（午藏丁火本气，为己之偏印）；年干辛=食神、月干甲=正官、时干癸=偏财；地支巳午卯酉。空亡：己卯日属己卯旬，空亡申酉 → **时支酉落空亡**。十二长生：己土在午为临官、在巳为帝旺。

**步骤1 旺衰**：得令（午月丁火当令生土）；得地（年支巳为帝旺根、月支午为临官，火土同源根气足；日支卯病地）；得势（印星当令）。不利：甲木正官透克、辛金食神泄、癸水财耗。综合倾向 **「身强印旺」**——火土印比成势，克泄耗不足以扭转。喜金（食伤泄秀）、水（财耗），忌火（印）、土（比）、木（官杀生印）。

**步骤2 格局**：月令午本气丁火偏印不透 → **偏印格**。甲木正官透月干（坐午被火泄，官星虚浮力弱）、辛金食神透、癸水偏财透。印旺格，印多为病之象。

**步骤3 病药**：病型检查——「印多为病」命中（印星过旺，日主被印滋而无力作为，印为忌）。从重者论：病=印星过旺（午火当令）；药=金（食伤泄秀）、水（财破印）。药根气：辛金坐巳受火克（根弱）；癸水坐酉得辛金生（根尚可）。

**步骤4 调候**：己土午月夏月，火旺土燥有燥意，但己土本身喜暖；调候取癸水润土（[SCHOOL]），与扶抑一致（身强喜水）。判普通状态，调候为辅助。

**步骤5 用神六维**：①扶抑：身强喜食伤财（金水）泄耗；②格局：偏印格印旺喜食伤泄秀、财破印；③调候：癸水润土辅助；④病药：药=金水；⑤通关：土生金生水，金水流通；⑥变格：NORMAL。六维一致 → 喜金（食伤）、水（财），忌火（印）、土（比）、木（官杀生印）。喜忌与预期一致。

**步骤6 干支作用**：天干**甲己合**（月干甲正官合日主己——[C]级判断：午月火土当令有合化土倾向，但甲坐午受泄，倾向合而不化，官星被合绊、官星力减——婚恋/事业相关）；地支**卯酉冲**（日支卯-时支酉，夫妻宫冲时柱）、巳午半会火局、卯戌合（流年引动）。空亡：时支酉落空——喜神辛金食神之根落空，虚而不实（填实之年为应期）。神煞：桃花以年支巳查 → 巳酉丑桃花在午，**月支午为桃花**；[SUPPLEMENTAL] 只作婚恋主题标签。

**步骤7 大运流年**：
- 大运戊戌：戊土劫财透（身强忌比劫）、戌土。
- 流年壬戌：**壬水正财透（喜神）** + 戌土劫财（忌神比劫）；**卯戌合**（流年戌合日支卯——夫妻宫被引动；卯戌合化火须火当令，戌月火墓不化，以合绊论）。
- 岁运互动：大运戌-流年戌地支伏吟；卯戌合引动日支夫妻宫；壬水财星透干（喜）与戌土劫财（忌）同现——财来但防比劫夺财。

**步骤8 应期**：①岁运引动——卯戌合引动日支夫妻宫；②十神星动——壬水正财透（男命财为妻星）；③神煞——午火桃花（月支）主题。三层独立信号互证 → **婚恋/异性缘主题应期**（[SUPPLEMENTAL] 桃花仅作主题标签，不改主框架）。同时戌土劫财透——防感情/财务竞争。

**步骤9 领域**：婚恋——夫妻宫被合+财星透+桃花，婚恋主题强烈；财富——身强喜财，壬水财透为喜，但戌土劫财有夺财隐患；事业——身强印旺，食伤泄秀为用。

**不确定度**：中（甲己合化与否、卯戌合化与否为参数级变量）。
