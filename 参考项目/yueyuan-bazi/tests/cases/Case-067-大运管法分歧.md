# Case 067 · 大运管法（干支一体 vs 前五后五）· 岁运

- 类别：岁运（大运管法-流派分歧）
- 四柱：戊辰 壬戌 甲子 丙寅（乾造）
- 大运：甲子运（与日柱甲子伏吟）
- 流年：丙寅年（寅木禄根引动）
- 设计意图：验证大运管法分歧标注（前5年后5年 vs 十年一体）

## 预期结论（先给定）
- 原局：甲木日主戌月（偏财当令？戌中戊土是甲之偏财——戌月戊土当令 → 偏财格），壬水偏印透（月干）、丙火食神透（时干）——身弱（戌月财耗、甲坐子沐浴有根）
- 大运甲子：甲木比肩帮身 + 子水印星生身——帮身大运
- 流年丙寅：丙火食神透 + 寅木禄根
- 关键点：①**大运管法分歧标注（[SCHOOL]）**：古法天干管前5年（甲木比肩）、地支管后5年（子水印星）vs 干支一体十年统看——输出时标注分歧；②甲子大运与日柱甲子伏吟；③寅木禄根被引动
- 喜忌：身弱喜水木（印比），忌火土金（食伤财官）
- 空亡：甲子日柱，甲子旬空戌亥——无落空

## 模型输出摘要

**步骤0 定盘**：甲木日主，月令戌（戌藏戊土本气，为甲之偏财）；年干戊=偏财、月干壬=偏印、时干丙=食神；地支辰戌子寅。空亡：甲子日属甲子旬，空亡戌亥 → **月支戌落空亡**（偏财月令落空，财星虚；空亡不参与旺衰计算，仅作修正项）。十二长生：甲在寅为临官、在子为沐浴。

**步骤1 旺衰**：失令（戌月戊土偏财当令耗身）；得地（日支子沐浴藏癸水印、时支寅临官禄根；年支辰无木根）；得势（壬水偏印透生身）。不利：丙火食神泄、戊土财耗。综合倾向 **「中和偏弱」**——财旺但印透有根（壬坐子）、寅木禄根支撑。喜水（印）、木（比劫），忌火（食伤泄）、土（财）、金（官杀）。

**步骤2 格局**：月令戌本气戊土偏财，戊土透年干 → **偏财格**。壬水偏印透、丙火食神透——财格配印（身弱印为用，财印相并须分主次）。

**步骤3 病药**：病型检查——「财多身弱」边缘（财旺+中和偏弱）；其余病型不命中。从重者论：病=财旺身弱（戌月财当令）；药=印（水）生身、比劫（木）帮身。药根气：壬水坐子（子藏癸水）有根；丙火坐寅长生；比劫待岁运。

**步骤4 调候**：甲木戌月秋末，气候温和，非极端 → 普通状态，格局扶抑为主，调候辅助。

**步骤5 用神六维**：①扶抑：中和偏弱喜印比（水木）；②格局：偏财格身弱喜印比帮身任财；③调候：辅助；④病药：药=水木；⑤通关：水生木生火，水为通关；⑥变格：NORMAL。六维一致 → 喜水（印）、木（比劫），忌火（食伤）、土（财）、金（官杀）。与预期一致。

**步骤6 干支作用**：天干戊财、壬印、丙食，无五合；地支**辰戌冲**（年支辰-月支戌——财库冲）、**子辰半合水**（日支子-年支辰——印局）、寅戌半合火（时支寅-月支戌）。空亡：月支戌落空（偏财月令虚）。神煞：驿马——申子辰马在寅，日支子查 → 驿马在寅（时支寅），[SUPPLEMENTAL] 流动主题。

**步骤7 大运流年**：
- 大运甲子：甲木比肩透（喜帮身）、子水偏印（喜生身）；**大运甲子与日柱甲子伏吟**。
- 流年丙寅：丙火食神透（忌——泄身）、寅木比肩（喜——禄根值临引动）。
- 岁运互动：甲子大运帮身（喜）——**大运管法分歧标注（[SCHOOL]）**：古法天干甲木管前5年（比肩帮身）、地支子水管后5年（印星生身）；另有派别主张干支一体十年统看——输出时并列标注，不强行二选一。流年丙寅：寅木禄根帮身（喜）、丙火食神泄（忌）。

**步骤8 应期**：①岁运引动——寅木禄根值临（帮身）；②原局结构响应——大运甲子与日柱甲子伏吟（帮身/自身主题强化）；③十神星动——丙火食神透（泄秀）。主题：身弱逢帮身之运年，大体顺遂；但食神泄身、辰戌财库冲——防财务起伏与变动。

**步骤9 领域**：事业——身弱得印比帮身，为顺遂之年；财富——辰戌冲财库、财星月令落空，防财务变动起伏；自身——日柱伏吟，主自身状态、自我议题反复。

**不确定度**：中（大运管法为流派分歧，干支一体 vs 前五后五对吉凶落点有影响；月支落空对财星的影响为参数级变量）。

## 判定
- 结果：部分命中（主线命中，空亡标注偏差）
- 出错模块：空亡标注
- 偏差说明：①预期称「甲子旬空戌亥——无落空」，事实错误——**月支戌正落空亡**（甲子旬空戌亥），我判月支戌落空（偏财月令虚），预期此点失实；②主线「大运管法分歧标注、甲子伏吟、身弱喜水木」与预期一致。
