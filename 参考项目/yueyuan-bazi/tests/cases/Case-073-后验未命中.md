# Case 073 · 后验未命中（预测与经历矛盾）· 后验

- 类别：后验（未命中）
- 四柱：丙午 甲午 庚午 丁丑（乾造）
- 设计意图：验证 Phase B 未命中裁决——预测喜神岁运反不顺

## Phase A 预注册（先给定）
- 原局：庚金日主午月（正官当令），丙丁火官杀透两（丙七杀/丁正官），午午午火局——身弱杀旺（官杀攻身）
- 最优假设：身弱，喜土（印化杀）金（比劫帮身），忌火（官杀）木（财生杀）
- 预注册主题：①土金岁运（印比）转好；②火木岁运压力大

## 用户经历（后验输入）
- 2026 丙午年：事业突然很顺，升职。

## 预期裁决（先给定）
- 2026 丙午：丙火七杀 + 午火官杀——**忌神年反顺** → 与预测矛盾 → **未命中**（喜忌主线受挑战）
- 关键点：①未命中时**明确指出哪一个假设被削弱**（「身弱喜土金忌火」假设被削弱）；②允许重新评估 C 级判断（如身弱程度、官杀是否为用）——是否实际「身强用官杀」？须说明哪一环被推翻；③A/B 级结构事实不得改动
- 关键争议：可能实际是「官杀有根可用」——庚坐午无根，身弱杀旺按理忌火……但事实反顺 → 重估

## 模型输出摘要

### Phase A（预注册，独立于经历）
- 步骤0：庚金日主，月令午（午藏丁火本气，为庚之正官）；年干丙=七杀、月干甲=偏财、时干丁=正官；地支午午午丑。空亡：庚午日属庚午旬，空亡戌亥，原局无戌亥、无落空。十二长生：庚在午为沐浴（败地）。
- 步骤1：失令（午月丁火正官当令克金）；得地（日支丑藏辛金中气根+己土正印、三午皆沐浴无根）；得势（丙丁官杀双透、甲木偏财透——克泄耗交加，无印比透干）。倾向 **「身弱杀旺（官杀攻身）」**——赖日支丑中辛金微根+己土印星贴身。**从格嫌疑核查**：日主有根（丑中辛金）且未被冲克合空死绝削弱、印星（丑中己土）藏而得午火生（有生源）→ 判据1/2 倾向不从。路线：身弱。
- 步骤2：月令午本气丁火正官透时干 → **正官格**；丙火七杀透年干 → **官杀混杂**。去留分析：丙杀坐午有根力强、丁官坐丑（丑藏己癸辛无丁火）无根力弱 → 去官留杀（[SCHOOL] 以力量为判据，不机械套文武）。
- 步骤3：病型「官杀混杂」「杀旺印弱」命中（七杀旺、印星藏而弱化杀不力）。药=土（印化杀）、金（比劫帮身）。药根气：丑中己土印得午生（有源但藏而不透）；比劫原局无。
- 步骤4：庚金午月夏燥，调候需壬水润泽，但壬水原局无、癸水仅藏丑中——调候神弱；且身弱杀旺，例外①「身极弱不从，调候让位于保身」倾向成立 → 调候降级，扶抑（印比）为急。
- 步骤5：六维一致 → 喜土（印）、金（比劫），忌火（官杀）、木（财生杀）。
- 步骤6：天干丙丁官杀透、甲财透；地支三午重见（**午午自刑**，[SCHOOL] 主题提示）。空亡无落空。
- 步骤10 Phase A 预注册：
  - 最优假设：身弱杀旺（官杀攻身），喜土金（印比），忌火木（官财）。
  - 主要用神：土印（化杀生身）、金比劫（帮身）。
  - 关键争议：从格与否（倾向不从）；官杀去留（倾向去官留杀）。
  - 预注册主题：①土金岁运（印比）化杀帮身→转好；②火木岁运（官杀财）→压力大。
  - 推翻条件：火木岁运反顺（升职/得意）→「身弱忌火木」受挑战，需重估身弱程度或印星化杀之力。

### Phase B（后验，读取经历后）
- 用户经历：2026 丙午年，事业突然很顺，升职。
- 2026 丙午解析：丙火七杀透（原预测为忌）+午火正官（忌）——**忌神年反顺**。
- 四态裁决：**未命中**——「身弱喜土金忌火木（火木年压力大）」预测被削弱（实际官杀旺年反升职）。
- 重估路径（Phase B 允许重估 C 级判断，A/B 级结构事实不动）：原判断哪一环被推翻——**印星化杀之力被低估**。丑中己土正印贴身（日支）、得三午火生（火生土、土生金），实际构成 **「杀印相生」**链条：官杀经印转化而生身，官杀不直接攻身。则丙午年杀旺→生印→印生身，杀印相生反为贵（升职合理）。原预测「官杀纯忌」定性过重。
  - 注意：重估方向为「杀印相生（印化杀）」而非「身强用官杀」——庚金失令坐午、印比不透，身本不强，靠印化非靠身任（此与预期"身强用官杀"的重估方向在机制上不同、但官杀非纯忌的方向一致）。
- 诚实边界：单一年证据不足以下定论；但此经历明确削弱「火木年压力大」的预测，增强「官杀经印转化为贵」的倾向。需更多年份（土金年顺逆）进一步确认。
- 铁则执行：不反向篡改 Phase A（原预测保留，标注被削弱）。

### 与预期裁决对照
- 预期：未命中（喜忌主线受挑战；关键争议：是否实际"身强用官杀"）。我判未命中 → **裁决一致**；重估机制我提出「杀印相生」，预期提出「身强用官杀」，方向相同（官杀非纯忌）、机制表述不同。

## 判定
- 结果：命中（未命中裁决一致；重估机制细节差异）
- 出错模块：重估机制表述（参数级）
- 偏差说明：①裁决「未命中」与预期一致——「身弱喜土金忌火木」被 2026 丙午（官杀旺年反升职）削弱；②重估路径：我判「杀印相生」——丑中己土印贴身得午火生，官杀经印化而生身（庚金失令坐午、印比不透，身本不强靠印化）；预期判「身强用官杀」——方向一致（官杀非纯忌）但机制表述不同，故标注参数级差异而非判错。
