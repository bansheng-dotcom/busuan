# Case 069 · 大运喜忌反转（忌神运应凶）· 岁运

- 类别：岁运（喜忌-忌神运）
- 四柱：丙午 甲午 丁巳 丙午（乾造）
- 大运：癸巳运（癸水七杀？丁火七杀=癸水——杀运）
- 流年：壬辰年（壬水七杀透）
- 设计意图：验证忌神（水官杀）岁运应凶的方向判断

## 预期结论（先给定）
- 原局：丁火日主午月（羊刃当令），午午巳午火局成势、丙火劫财透两、甲木正印透——**炎上格（火专旺）成立**（专旺四条件满足：得令得地得势+克泄耗全无根）
- 大运癸巳：癸水七杀透（火专旺忌水——官杀为专旺最大忌神）
- 流年壬辰：壬水七杀透 + 辰土伤官（泄火破专旺）
- 关键点：①专旺格（炎上）喜木火，忌水（官杀最忌）金（财）土（食伤——泄气破格）；②癸水/壬水七杀透——**破格之运**，主压力/变动/健康主题；③辰土伤官泄火——破格叠加
- 喜忌：专旺喜木火，忌水金土（官杀财食伤）
- 空亡：丁巳日柱，丁巳旬空子丑——无落空

## 模型输出摘要

**步骤0 定盘**：丁火日主，月令午（午藏丁火本气，为丁之比肩；**午为丁火羊刃**）；年干丙=劫财、月干甲=正印、时干丙=劫财；地支午午巳午——火势满盘。空亡：丁巳日属丁巳旬，空亡子丑，原局无子丑、无落空。十二长生：丁火在巳为帝旺。

**步骤1 旺衰**：得令（午月丁火当令）；得地（三午一巳——午为丁火临官/羊刃、巳为帝旺）；得势（丙火劫财双透、甲木正印透生身）。克泄耗（水金土）原局**全无**。综合：**专旺炎上格（火专旺）成立**——检查纯度：地支无异类有根（全午巳火）、天干纯火木，纯度极高；按 biange.md ZHUANWANG 状态机取用。

**步骤2 格局**：月令午为丁火羊刃 → 有羊刃格之象，但火势独旺、克泄耗无根——判 **专旺炎上格**（变格体系 ZHUANWANG，按 biange.md 状态机运行；[CORE]：专旺成立时优先于普通羊刃格）。三午重见自刑（[SCHOOL] 主题提示）。

**步骤3 病药**：变格体系不套用普通病型（patterns.md 五：变格按 biange.md 规则运行）。专旺体系内本局**势纯无病**；若论病=破格之物（水官杀、土食伤、金财），药=助旺之木火。原局无破格之物。

**步骤4 调候**：丁火午月夏燥，调候本需癸水润局，但**变格例外③：专旺以顺势为主，调候退居次位** → 退出 CLIMATE OVERRIDE，专旺顺势为主，调候让位。

**步骤5 用神六维**：①扶抑：丁火极旺需顺势（专旺）；②格局：炎上格喜印比；③调候：让位（专旺例外③）；④病药：专旺内无病；⑤通关：不适用；⑥变格：**ZHUANWANG 炎上 → 喜木火（印比），忌水（官杀最忌）、金（财）、土（食伤泄）**。六维一致 → 喜木火，忌水金土。与预期一致。

**步骤6 干支作用**：天干丙丙劫财、甲印透，无五合；地支三午重见（**午午自刑**，[SCHOOL] 自我纠结主题提示）、巳午会火（日支巳+各午）。空亡无落空。神煞：羊刃（午为丁火羊刃，三午刃重——刃旺，结构性变量于步骤 2 已处理）。

**步骤7 大运流年**：
- 大运癸巳：**癸水七杀透（忌——专旺最大忌神官杀）** + 巳火比劫（喜）；癸水坐巳胎地根弱，但透干即破格信号。
- 流年壬辰：**壬水正官透（忌——官杀类；注意：壬水对丁火为正官非七杀）** + 辰土伤官（忌——泄火破格）。
- 岁运互动：壬癸官杀双透——**破格之运**（专旺最忌官杀）；辰土伤官泄火（破格叠加）；大运巳与流年辰无冲合（辰巳不作合）。岁运非并临（干支均不同）。

**步骤8 应期**：①十神星动——官杀（壬癸水）透干攻破专旺（[biange.md] ZHUANWANG 逆势岁运=忌，**官杀旺岁运为最险之运**）；②辰土伤官泄火——破格叠加；③原局结构响应——三午自刑逢破格引动。多层信号互证 → 破格之运主大压力、变动、健康损耗、官非/权威受挑战类主题。

**步骤9 领域**：事业——破格之运主压力大、事业受阻、防官非口舌；身心——刃旺逢官杀破格，防健康损耗、情绪压力（传统命理文化语境下的状态倾向，仅作文化解释与自我观察参考，不作疾病预测、诊断或治疗依据）；财富——忌神财（金）虽未现，但破格之运主整体下行压力。

**不确定度**：中（官杀透干对专旺的破坏程度、癸水根弱是否减轻破格力为参数级变量）。
