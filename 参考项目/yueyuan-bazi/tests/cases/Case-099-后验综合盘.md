# Case 099 · 后验综合盘（多主题互证）· 后验

- 类别：后验（综合-多主题）
- 四柱：壬子 壬寅 甲子 丙寅（乾造）
- 设计意图：验证综合盘后验——枭神夺食+身强的多主题裁决

## Phase A 预注册（先给定）
- 原局：甲木日主寅月（比肩当令），壬水偏印双透、丙火食神透——枭神夺食病型，身强印旺
- 预注册主题：①水（枭印）岁运表达受阻；②火（食伤）岁运才华释放；③土（财）岁运破印

## 用户经历（后验输入）
- 2021 辛丑年：事业低迷（辛金正官+丑土财——土财破印？但低迷）。
- 2023 癸卯年：创作顺利，作品受好评（癸水印+卯木比劫——水年应受阻但创作顺？）。

## 预期裁决（先给定）
- 2021 辛丑：辛金正官透 + 丑土财星——身强官星为用？但低迷 → **部分命中/未知**（官星克身反阻——身强官杀可致压力）
- 2023 癸卯：癸水枭印 + 卯木比劫——**水年按理枭神夺食应受阻，但创作顺** → 与预测矛盾 → **未命中**（「枭神夺食忌水」假设受挑战）——须诚实标注：可能食神（丙火）得卯木生？或枭神夺食判定需重估
- 关键点：①多主题案例——部分命中+未命中并存；②未命中时指出假设被削弱并允许重估 C 级判断

## 模型输出摘要

### Phase A（预注册，独立于经历）
- 步骤0：甲木日主，月令寅（寅藏甲木本气，为甲之比肩/临官）；年干壬=偏印、月干壬=偏印、时干丙=食神；地支子寅子寅。空亡：甲子日属甲子旬，空亡戌亥，原局无戌亥、无落空。十二长生：甲在寅为临官。
- 步骤1：得令（寅月甲木当令）；得地（双寅禄根、双子印根）；得势（双壬偏印透）。综合倾向 **「身强印旺」**——木水成势。喜火（食伤泄秀）、土（财破印），忌水（枭印）、金（官杀生印）。
- 步骤2：月令寅为甲木临官 → **建禄格**。双壬偏印透、丙火食神透（坐寅长生）。
- 步骤3：病型「枭神夺食」命中（壬水偏印旺同性克丙火食神，身旺印为忌）。药=火（食伤泄秀）、土（财破印）。药根气：丙火坐寅长生（食神根旺，被夺但根未拔）。
- 步骤4：甲木寅月春季温和 → 普通状态，调候辅助。
- 步骤5：六维一致 → 喜火（食伤）、土（财），忌水（枭印）、金（官杀生印）。
- 步骤6：天干双壬印、丙食；地支子子双印、寅寅双禄（子寅无冲合）。空亡无落空。神煞：驿马（申子辰马在寅，日支子查 → 寅为驿马）。
- 步骤10 Phase A 预注册：
  - 最优假设：身强印旺（建禄），枭神夺食病型；喜火土，忌水金。
  - 主要用神：丙火食神（泄秀）、土财。
  - 关键争议：枭神夺食——表达/才华受制主题；食神根旺（可被救）。
  - 预注册主题：①**水（枭印）岁运表达受阻**；②**火（食伤）岁运才华释放**；③**土（财）岁运破印**。
  - 推翻条件：水印岁运反顺或火土岁运反逆 → 病型预测被削弱。

### Phase B（后验，读取经历后）
- 用户经历：2021 辛丑年事业低迷；2023 癸卯年创作顺利、作品受好评。
- **2021 辛丑**：辛金正官透（忌——官杀生印助枭）+ 丑土正财（理论上喜——财破印）。但**丑为湿土**（藏癸水辛金己土——印比之库）：丑土生金助印比、丑中癸水为枭神之根——**财星破印之力弱，反助印枭**。→ 辛官生印助枭、丑土湿性助印 → 枭神夺食加重 → 事业低迷（才华受制）。裁决：**部分命中**——「水枭引动表达/事业受阻」主题部分印证（事业低迷）；但预测「土（财）岁运破印应吉」未验——**丑土湿性藏水金、破印力弱的参数级修正**，诚实标注。
- **2023 癸卯**：癸水正印透（忌——理论应夺食受阻）+ 卯木劫财（喜——比劫帮身）；**寅卯会木**（流年卯+原局双寅——比劫局，木旺**生丙火食神**）——食神丙火得寅卯木生而**旺**。→ 身强食伤旺反而泄秀 → 创作顺利、作品受好评。裁决：**未命中**——「水印岁运表达受阻」预测与"创作顺利"矛盾，**「枭神夺食忌水」假设被削弱**；机制修正（C 级重估）：食神丙火坐寅长生根旺、逢卯木会局得生——未被夺死，木旺生火反泄秀；原判断对「夺」之力度定性过重。诚实标注：此经历削弱枭神夺食忌水预测，不强行自圆。
- 总结：多主题案例——2021 部分命中（+参数级修正：丑土破印力弱）+2023 未命中（枭神夺食忌水受挑战）。A/B 级结构事实（四柱、合局）不改动。
- 铁则执行：不反向篡改 Phase A；明确指出被削弱的假设（枭神夺食忌水）。

### 与预期裁决对照
- 预期：2021 部分命中/未知（官星克身反阻）；2023 未命中（枭神夺食忌水假设受挑战，须诚实标注）。我判 2021 部分命中、2023 未命中 → **一致**。

## 判定
- 结果：命中
- 出错模块：无
- 偏差说明：Phase A 与预期一致（建禄身强、枭神夺食、喜火土忌水金）；Phase B 多主题裁决与预期一致——2021 部分命中（丑土湿性破印力弱之参数级修正）、2023 未命中（癸卯寅卯会木生丙火，创作顺，削弱枭神夺食忌水假设），诚实标注不强行解释。
