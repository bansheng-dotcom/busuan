# Case 016 · 化气格（丙辛合化水）· 极端结构

- 类别：极端结构（化气-丙辛合水）
- 四柱：丙申 辛卯 辛巳 丙申（乾造）
- 设计意图：验证化气格（丙辛合水）判定——化神当令、合化与比劫透干的冲突

## 预期结论（先给定）
- 化气判定：丙辛合（年丙-月辛、时丙-日辛，**两组丙辛合**）✓；化神水——**卯月木当令，化神水不当令 → 化气不成立**（须化神当令）
- 关键点：①化神（水）在卯月不当令（木当令）→ 按 biange.md HUAGQI 成化条件②「化神当令」不满足 → 化气不成立，退论合而不化（合绊）；②辛金日主坐巳（长生）、月令卯（财）——身弱财旺
- 退论后：辛金卯月财星当令，丙火正官透，日主辛坐巳长生有根 → 身弱财官旺，喜金（比劫帮身）、土（印生身），忌木火（财官）
- 空亡：辛巳日柱，辛巳旬空申酉——年支申、时支申均落空亡

## 模型输出摘要
- 核心总评：丙辛合（年丙-月辛、时丙-日辛，**两组丙辛合**）✓，但化神水在卯月**不当令**（木当令）→ 化气不成立，退论合而不化（合绊）；辛金卯月财星当令、两丙正官透，日主坐巳（巳中庚金劫财根）+两申金根但**申落空亡**——身弱财官旺，喜金土忌木火。不确定度中。
- 定盘：辛金日主，卯月，巳藏丙庚戊、申藏庚壬戊、卯藏乙；空亡申酉——年支申、时支申均落空
- 化气判据核对（biange.md HUAGQI）：①丙辛合✓；②**化神水在卯月不当令（木当令，水死地）✗ → 化气不成立**（成化条件2否决）→ 退论「合而不化」（合绊，C级判断）
- 长生表述修正：辛金长生在子、帝旺在申；辛坐巳为**死地**（非长生）；但巳中藏庚金为辛之劫财根、两申藏庚金本气根——金根实际有力，但两申落空亡（辛巳旬空申酉）→ **金根虚化、帮身力减**（[HEURISTIC] 空亡虚而不实；[SCHOOL] 有派计入旺衰，此处按主题提示+削弱根力处理）
- 旺衰：卯月财当令耗身 + 两丙官星克身（被辛合绊，克力减）→ 身弱财旺（金根落空，帮扶不足）
- 格局：正财格（卯月乙木当令透否？乙不透——取本气财格）；合绊结构：官星丙火贪合，主贵气/约束被稀释，事业压力主题
- 喜忌：身弱财官旺，喜金（比劫帮身）、土（印生身），忌木（财）、火（官杀克身）
- 调候：卯月气候温和，非急；身弱财旺以扶抑为主，调候为辅
- 六维：一致指向喜金土、忌木火
- 岁运：喜金土运（印比帮身任财），忌木火运（财官旺身愈弱）；申落空亡，逢申运（填实）或寅运（冲空）为根气应期提示
- Phase A：最优假设=身弱财官旺喜金土忌木火；推翻条件=木火岁运反顺、金土岁运反逆

## 判定
- 结果：**命中**
- 出错模块：无
- 偏差说明：无。核心预期命中：化神水卯月不当令→化气不成立→退论合绊；退论后身弱财官旺、喜金土忌木火一致。细节修正（非预期偏差）：「辛坐巳（长生）」按十二长生辛在巳为死地，其根实为巳中庚金劫财根；两申落空亡使金根虚化——已并入分析，不改变主判。
