# Case 043 · 妒合（一干合两干）· 普通复杂

- 类别：普通复杂（干支作用-妒合）
- 四柱：辛未 庚寅 丙午 辛卯（乾造）
- 设计意图：验证妒合判定——辛金（正财）合一丙火日主，另一辛金再合

## 预期结论（先给定）
- 天干作用：丙火日主，年干辛、时干辛——**两辛争合一丙（妒合）**：一丙合两辛，配偶星（正财）妒合日主
- 旺衰：寅月木当令（印星——寅中甲木是丙之偏印），丙坐午（帝旺）得根——身强
- 关键点：①妒合 vs 争合——妒合是一干被两干合（丙被两辛合），争合是两干争合一干，术语区分；②两辛正财争合日主——感情纠葛、合伙多角；③寅午半合火（印比助身）
- 喜忌：身强印比旺，喜金（财）、水（官杀），忌木火（印比）
- 空亡：丙午日柱，丙午旬空寅卯——月支寅落空亡

## 模型输出摘要
- 核心总评：丙火日主寅月（偏印当令），年干、时干两辛金正财——**一丙合两辛为妒合**；丙坐午（帝旺）、寅午半合火、卯木印生——身强；财星妒合日主。不确定度：中。
- 定盘（S1/A）：乾造，日主丙火，月令寅（甲木偏印当令），藏干未（己丁乙）寅（甲丙戊）午（丁己）卯（乙）；**丙午旬空寅卯——月支寅、时支卯均落空亡**（预期仅列寅，卯亦空）。
- 旺衰：偏强（[CORE] 寅月印当令生火 + 丙坐午帝旺 + 寅午半合火 + 卯木印生；未中丁火余气）。
- 天干作用：**两辛争合一丙（妒合）**——年干辛、时干辛（正财）合日主；丙辛合水需月令水当令（寅月木当令，不合化）→ 合而不化，仅论合绊（C 级判断）。
- 格局：月令寅本气甲木偏印当令，不透 → 偏印格；**身强印为忌**（寅卯印落空亡——印星虚，减忌）。
- 病药：身强印比旺为病；药=财（辛金，两透坐未有根——未中己土生辛金）、官杀（水，原局无）、食伤（土，未中己土）。病=身强无制，药=财星耗身泄秀。
- 调候：寅月春，气候温和，非极端，不触发 CLIMATE OVERRIDE；调候非急。
- 六维：扶抑（身强需克泄耗——金水）、格局（偏印格身强印为忌）、调候（非急）、病药（财星为药）、变格（NORMAL，丙坐午强根不从）。一致指向 **喜金（财）、水（官杀），忌木火（印比）**。
- 岁运：喜金水岁运，忌木火岁运；财星两透合身（妒合）主感情纠葛/合伙多角主题；寅午半合火助身——印比旺岁运身更强无制。
- Phase A：最优假设=妒合（两辛合一丙）、身强喜金水忌木火；关键争议=合化不化、寅卯印空减忌；未来高概率主题=金水岁运财官得用、木火岁运印比旺压抑；推翻条件=木火岁运反顺、金水岁运反逆。
