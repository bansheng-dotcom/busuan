# Case 002 · 从财格（财旺身弱从财）· 极端结构

- 类别：极端结构（从势/从财）
- 四柱：戊午 丙辰 甲午 己巳（乾造）
- 设计意图：验证从财格判定是否成立、日主是否误判为身弱不从、财星成势的细分取用

## 盘面分析（定盘登记）
- 日主：甲木（阳木）
- 月令：辰月（戊土当权，财星当令）
- 地支：午午巳辰——午火食伤成势、辰土财库、巳火食伤
- 天干：戊己土财透两（戊偏财/己正财）、丙火食神透
- 藏干：午藏丁己，巳藏丙戊庚，辰藏戊乙癸
- 空亡：甲午旬空辰巳 → 时支巳、月支辰均落空亡（以日柱甲午查，甲午旬空辰巳）
- 印比（水木）无根无透——日主甲木仅得辰中乙木余气微根，且辰落空亡

## 预期结论（先给定，防确认偏误）
- 旺衰：极弱（财星当令 + 食伤泄 + 印比全无）
- 格局：**从财格成立**——财星（土）当令成势 + 食伤（火）生财 + 日主无有力之根（辰中乙木余气根落空亡、遭火土夹攻，按 Root resistance 判据「根被削弱」→ 不从的抵抗能力不足）
- 喜忌：喜土（财）、火（食伤生财顺），忌水（印——生身反抗）、木（比劫——夺财）
- 调候：夏月（辰巳午）燥热——但变格（FROM）成立，按 biange.md 例外②「从势以顺势为主，调候退居次位」
- 变格联动：判定为 FROM（从财）后，步骤 5 第 6 维取从财规则：喜克泄耗（土财火伤），忌生扶（水木）
- 关键点：不得误判为「身弱喜水木印比」——那会完全反掉；须正确识别辰中乙木根落空亡 + 火土成势

## 模型输出摘要
- 核心总评：甲木辰月财星当令，戊己土财透两、丙火食神透，午午巳火土成势，印比全无 → **从财格成立**，喜土火忌水木。不确定度中（从格边缘但倾向从）。
- 旺衰：极弱（财当令耗身、食伤泄身、印比无根无透）
- 格局：Root resistance 四判据全过（辰中乙木余气根落空亡+火土夹攻→根被削弱；印比无显；财食成势；生扶微弱）→ 倾向从财；并列「身弱 vs 从财」但主判从财
- 调候：辰巳午近夏燥热，但 FROM 例外②顺势为主，调候退居次位
- 病药：从格不论病型；势已成无病
- 六维：一致指向喜土火、忌水木
- 岁运：喜土火运顺，忌水（印生身反抗）木（比劫夺财），水木岁运为破格之险
- Phase A：从财喜土火忌水木；推翻条件=水木运反顺则重检
