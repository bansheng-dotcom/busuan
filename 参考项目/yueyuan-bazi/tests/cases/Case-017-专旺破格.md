# Case 017 · 专旺破格（官杀有根）· 极端结构

- 类别：极端结构（专旺破格）
- 四柱：庚寅 庚寅 甲寅 壬申（乾造）
- 设计意图：验证专旺破格判定——木专旺嫌疑但官杀（金）有根则破

## 预期结论（先给定）
- 格局：**木旺成势（三寅）但官杀（庚金）透干有根（申中庚金本气根）→ 专旺破格**，退论普通身旺
- 关键点：按 biange.md 专旺「若官杀有根有力则专旺多不能成立（官杀为专旺最大破格）」+ 破格条件「天干官杀透出而地支有根 → 专旺破，退论普通身旺」——庚金两透 + 申中庚金本气根 → 破格 ✓
- 退论后：身旺（寅月木当令+三寅），喜火（食伤泄）、土（财耗）、水（印生？身旺印为忌）——喜火土，忌金（官杀克身反成压力？身旺喜官杀制——须评估：身旺官杀有力反而成格可用）
- 关键争议：身旺见官杀——是「身旺用官杀」还是「官杀攻身」？取决于身旺程度与官杀力量平衡
- 空亡：甲寅日柱，甲寅旬空子丑——无落空

## 模型输出摘要
- 核心总评：甲木寅月当令，三寅木成势（木专旺嫌疑），但庚金七杀**两透干**且时支申中庚金本气根 → 官杀有根有力 → **专旺破格，退论普通身旺**，喜火土忌水金。不确定度中（身旺用官杀 vs 官杀通关生印之争）。
- 定盘：甲木日主，寅月，寅藏甲丙戊、申藏庚壬戊；空亡子丑无落空（甲寅旬空子丑）
- 破格判定（biange.md 专旺）：专旺成立前置「若官杀有根有力则专旺多不能成立」+ 破格条件「天干官杀透出而地支有根 → 专旺破」——庚金年干月干双透、时支申中庚金本气根 → **破格成立**，退论普通身旺 ✓
- 旺衰：身旺（寅月木当令+三寅成势+壬水印透生身）
- 关键争议（身旺用官杀 vs 官杀攻身）：表面「身旺喜官杀制」可立，但深入查制化：①庚金坐寅（绝地）两透，本身力弱；②**申寅相冲**——时支申金根被三寅木冲破，官杀根受创；③庚金生壬水印、壬水再生甲木身——**官杀→印→身通关，官杀不仅制不了身、反助身势**（杀印相生结构在身旺时助旺）；④申中庚金又被坐申之壬水泄气 → 官杀实际「制身无力、生印助身」→ **金非可用之官杀，忌之**
- 喜忌：身旺，喜火（食伤泄秀、火制金解通关）、土（财耗身），忌水（印助身）、金（官杀通关生印助身、根受冲制身无力）
- 调候：寅月气候温和，非急；身旺以扶抑为主
- 六维：一致指向喜火土、忌水金（扶抑/病药/格局同向）
- 岁运：喜火土运，忌金运（官杀虽能制身但通关生印、且原局根被冲破，金运先助水印凶）、水运（印助身）；火运（食伤制金）为最得力用神运
- Phase A：最优假设=身旺喜火土忌水金；推翻条件=火土岁运反逆、水金岁运反顺

## 判定
- 结果：**命中**
- 出错模块：无
- 偏差说明：无。核心判定命中：专旺破格（庚金透干+申中庚金本气根→官杀有根）→ 退论普通身旺。喜忌上预期犹豫「身旺喜官杀制 vs 官杀攻身」，本分析进一步明确：此盘官杀经「官杀→印→身」通关助身、且申根被寅冲破，制身无力 → 判忌金（与预期「喜火土、忌金水」方向一致，细化程度超出预期）。
