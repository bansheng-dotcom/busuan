# Case 031 · 杀印相生（成格范式）· 普通复杂

- 类别：普通复杂（成格-杀印相生）
- 四柱：戊午 壬戌 甲辰 乙丑（乾造）
- 设计意图：验证杀印相生成格判定——七杀（戊土）旺、印（壬水）化杀生身

## 预期结论（先给定）
- 格局：甲木日主戌月（偏财当令？戌中戊土是甲之偏财——**纠正：戌月戊土当令，戊为甲之偏财**，非杀。甲木七杀=庚金。此盘戊土偏财透、壬水偏印透——财格配印？设计复盘）
- 复盘：杀印相生须七杀（庚）旺 + 印化。此盘戊土（偏财）非杀 → 设计意图偏差。降级为「财格配印」测试：戌月财当令、戊土偏财透、壬水印透化财生身（财格佩印——身弱财旺喜印）
- 修正预期：身弱（戌月财耗、甲坐辰养地微根）财旺，壬水印透化财生身 → 财格配印（印为用），喜水（印）木（比劫），忌火土（食伤财）
- 关键点：验证模型能否识别「杀印相生 vs 财格配印」的差别（杀=庚金，财=戊土，不可混）
- 空亡：甲辰日柱，甲辰旬空寅卯——无落空

## 模型输出摘要
- 核心总评：**设计意图偏差——「杀印相生」不成立**：甲木日主七杀为庚金，此盘戌月戊土当令透年干——戊为甲之**偏财**（非杀）；壬水偏印透月干 → 实为**财格配印**（戌月偏财格、财旺身弱、印化财生身），喜水木忌火土。不确定度中。
- 定盘：甲木日主，戌月，午藏丁己、戌藏戊辛丁、辰藏戊乙癸、丑藏己癸辛；空亡寅卯无落空（甲辰旬空寅卯）
- 十神复核（甲木日主）：财=土（戊偏财/己正财）、官杀=金（庚七杀/辛正官）、印=水（壬偏印/癸正印）——**戌月戊土是偏财，非杀**；甲木七杀（庚金）全盘无 → 设计意图「杀印相生」张冠李戴
- 病型/格局核对：杀印相生范式须七杀（庚）旺+印化——此盘无庚金 → 不成立 ✓；实为**偏财格配印**（戌月戊土偏财当令透年干，财旺身弱，壬水印透化财生身）
- 旺衰：身弱财旺——戌月偏财当令耗身、午戌丑土财成势、戊土偏财坐午（帝旺）透有力；甲木坐辰（衰地）仅辰中乙木微根、壬水偏印坐戌（冠带虚位）无根、乙木劫财坐丑虚浮
- 喜忌：身弱财旺 → 喜水（印——化财生身，壬水虽虚浮仍为救应主神）、木（比劫帮身任财——乙木透），忌火（食伤生财）、土（财——财旺身弱担不起）；金（官杀生印，中性偏顺）
- 调候：戌月秋燥不极端，普通状态，身弱以扶抑为主
- 六维：一致指向喜水木、忌火土
- 岁运：喜水木运（印比帮身任财），忌火土运（食伤财旺身愈弱）；金运生印可顺
- Phase A：最优假设=身弱财旺、偏财格配印喜水木忌火土；推翻条件=火土岁运反顺、水木岁运反逆

## 判定
- 结果：**命中**
- 出错模块：无（防御测试——模型正确识别设计错误）
- 偏差说明：无。模型正确识别「杀印相生」设计意图不成立：戊土为甲之偏财（非七杀庚金），实为财格配印（戌月偏财格、身弱财旺喜印），修正方向与预期一致（喜水木忌火土）。
