# Case 024 · 官杀混杂（男命）· 普通复杂

- 类别：普通复杂（官杀混杂）
- 四柱：壬申 壬子 丁卯 癸卯（乾造）
- 设计意图：验证官杀混杂判定（男命）——正官七杀并透的去留

## 预期结论（先给定）
- 官杀混杂：丁火日主，壬水（正官）年透、癸水（七杀）时透——**官杀混杂成立**
- 旺衰：子月水当令（官杀旺），丁火坐卯（沐浴）有微根、壬癸水克身——身弱
- 关键点：①去留判断——留有力者去无力者：壬坐申长生、癸坐卯（沐浴无根）→ 壬水有力、癸水无力 → 去杀留官倾向；②印星（乙木藏卯）化杀生身？③女命官杀混杂主婚姻波折，男命主事业压力
- 喜忌：身弱官杀旺，喜木（印化杀生身）、火（比劫帮身），忌水（官杀）、金（财生官杀）
- 空亡：丁卯日柱，丁卯旬空戌亥——无落空

## 模型输出摘要
- 核心总评：丁火子月官杀当令旺，壬水正官两透（年/月干）、癸水七杀透时干——**官杀混杂成立**；丁火坐卯（病地）无本气根、仅卯中乙木偏印生身 → **身弱官杀旺**；去留：壬坐申（长生）有力、癸坐卯无本气根无力 → **去杀留官**；喜木火忌水金。不确定度中。
- 定盘：丁火日主，子月，申藏庚壬戊、子藏癸、卯藏乙；空亡戌亥无落空（丁卯旬空戌亥）
- 官杀混杂核对：壬（正官）年月两透 + 癸（七杀）时透 → 官杀混杂成立 ✓；古法「去官留杀为武、去杀留官为文」须以力量为判据
- 去留裁决：壬水正官坐申（壬长生在申，申中壬水本气根）→ **有力**；癸水七杀坐卯——癸长生在卯（虚长生，卯藏乙木无癸本气）→ **无力** → **去杀留官**（留有力者、去无力者）✓
- 旺衰：身弱——子月官杀当令旺克身、丁火无本气根（午未戌全无）、帮扶仅卯中乙木印星两处、无丙丁比劫透
- 调候：子月冬寒，丁火调候本需甲木引丁（庚劈甲引丁）——原局甲木不透不藏、庚金仅申中藏（不透）→ 调候神虚浮，调候降级；且身弱官杀旺「身弱不从时调候让位」→ 以扶抑保身为主
- 喜忌：身弱官杀旺，喜木（印化杀生身——卯中乙木）、火（比劫帮身），忌水（官杀）、金（财生官杀）
- 六维：一致指向喜木火、忌水金
- 岁运：喜木火运，忌水金运；官杀混杂去留已定（去杀留官），七杀（癸）被去，官星（壬）当权——逢官星受生旺之运主贵，逢七杀根旺之运防官非
- Phase A：最优假设=身弱官杀混杂去杀留官喜木火忌水金；推翻条件=水金岁运反顺、木火岁运反逆

## 判定
- 结果：**命中**
- 出错模块：无
- 偏差说明：无。官杀混杂成立、去杀留官（壬有力癸无力）、身弱官杀旺喜木火忌水金——全部与预期一致。细节修正（非偏差）：预期「癸坐卯（沐浴无根）」——按十二长生癸水长生在卯，卯藏乙木无癸本气，故「无根」判断一致，「沐浴」为长生之误记，不影响去留裁决。
