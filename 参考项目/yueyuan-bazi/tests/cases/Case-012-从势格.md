# Case 012 · 从势格（财官食伤混杂成势）· 极端结构

- 类别：极端结构（从势-从弱）
- 四柱：甲午 丙午 癸巳 己未（乾造）
- 设计意图：验证从势格（从弱）判定——财官食伤混杂成势、无从一神之专

## 预期结论（先给定）
- 格局：**从势格（从弱）成立**——午月火当令（财）、甲木伤官透生财、己土七杀透，财官伤混杂成势、癸水日主无根（癸在巳绝地、午绝、未墓——但未为癸之墓，墓算根否？须评估）
- 关键争议：癸水日主是否无根（巳午无癸根，未中无癸；须确认）
- 喜忌：喜火土木（顺势克泄耗），忌金水（印比生扶反抗）
- 空亡：癸巳日柱，癸巳旬空午未——月支午、时支未均落空亡（成势之火土落空，须评估对从势的影响）

## 模型输出摘要
- 核心总评：癸水午月财（火）当令，甲木伤官透、丙火正财透、己土七杀透，财官伤混杂成势，癸水日主无本气根（巳胎地无癸、午未无癸——未为木库非癸水库），印比全无，**从势格（从弱）成立**，喜火土木忌金水。不确定度中（空亡削弱成势之力度）。
- 定盘：癸水日主，午月，巳藏丙庚戊、午藏丁己、未藏己丁乙；空亡午未——月支午、时支未均落空
- 关键争议（墓算不算根）：未中藏己丁乙无癸水，且癸水之墓库在辰非未 → 未对癸水既非根亦非库；巳为癸之胎地、午为绝地，均无本气根 → 日主确实无根 ✓
- 从格判据核对：判据1无本气根✓；判据2印比（金水）全不透✓；判据3财官伤（火土木）成势✓；判据4生扶（金水）全无✓ → 从势（从弱）成立
- 空亡影响（参数级）：午（财）未（杀）落空——成势之火土落空、势力打折；但甲丙己透干，**透干不受地支空亡之限**，伤官财杀透出仍有力量 → 从势成立不变，仅「势」之强度打折
- 喜忌：喜火土木（顺势克泄耗），忌金水（印比生扶反抗）
- 调候：午月夏燥，但 FROM 从势成立 → CLIMATE OVERRIDE 例外②「从势以顺势为主」，调候让位
- 六维：FROM 从势喜克泄耗（火土木）、忌生扶（金水），六维一致
- 岁运：喜火土木运，忌金运（印生身反抗）、水运（比劫帮身反抗）——印比运为破格之运须防
- Phase A：最优假设=从势格喜火土木忌金水；推翻条件=金水岁运反顺、火土木岁运反逆

## 判定
- 结果：**命中**
- 出错模块：无
- 偏差说明：无。从势格成立判定与预期一致（癸无本气根/未非癸之墓库/财官伤成势/印比全无），喜火土木忌金水一致；空亡对从势的削弱已按参数级处理（透干之财官伤不受空亡限），与预期一致。
