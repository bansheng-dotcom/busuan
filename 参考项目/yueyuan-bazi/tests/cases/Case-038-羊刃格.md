# Case 038 · 羊刃格（特殊格局）· 普通复杂

- 类别：普通复杂（特殊格局-羊刃）
- 四柱：戊午 戊午 己未 丁卯（乾造）
- 设计意图：验证羊刃格判定——己土午月羊刃、无制

## 预期结论（先给定）
- 格局：己土日主午月（羊刃——午为己之羊刃），戊土劫财透两、丁火偏印透，午午未火土局——**羊刃格（刃旺无制）**
- 旺衰：极旺（午月羊刃 + 午午未火土 + 戊劫财透）
- 关键点：①羊刃格属 B 特殊格局；②刃旺无制（无七杀制、无食伤泄）——刃旺无制病型命中 → 主刚暴/破财/争斗倾向；③卯木七杀（时支）被午火泄——制刃无力
- 喜忌：刃旺无制——喜水（官杀制刃，但原局无水）、金（食伤泄刃），忌火土（印比帮刃）、木（印生刃？卯木生火反助）
- 空亡：己未日柱，己未旬空子丑——无落空

## 模型输出摘要
- 核心总评：己土日主午月（午为己之羊刃）——**羊刃格（B 特殊格局）**；戊土劫财两透、丁火偏印透，午午未火土成势，身极旺；卯木七杀坐时支被午火泄，制刃无力——**刃旺无制命中**。不确定度：低。
- 定盘（S1/A）：乾造，日主己土，月令午（羊刃），藏干午（丁己）未（己丁乙）卯（乙）；己未旬空子丑，四支无子丑，无落空。
- 旺衰：极旺（[CORE] 午月羊刃当令 + 午午未火土局 + 戊劫财两透帮身 + 丁印生）。
- 格局：羊刃格（B 特殊格局，不进入变格顺势逻辑）；月令午本气丁火偏印当令。
- 病药：**刃旺无制命中**——无七杀制（卯木七杀坐时支被午火泄、无根透，制刃无力）、无食伤泄（原局无金）。药 = 水（官杀制刃）+ 金（食伤泄刃）；**原局水金全无，病重药无**，须待岁运。
- 调候：午月夏月燥极——触发 CLIMATE OVERRIDE 检查；但调候神（壬癸水）原局虚浮无根（例外⑤）→ 调候条件不成立，降级为辅助参考，回到普通状态（扶抑/格局为主）。
- 六维：扶抑（极旺需抑——水官杀、金食伤）、格局（羊刃喜官杀制刃）、调候（夏燥需水但原局无水，降级）、病药（刃旺无制，药水金皆无）、变格（NORMAL）。一致指向 **喜水（官杀制刃）、金（食伤泄刃），忌火土（印比帮刃）、木（卯木生火反助刃）**。
- 岁运：喜水金岁运（制刃/泄刃），忌火土岁运；**原局无制刃之神，刃旺无制主刚暴、破财、争斗、血光主题，须防火土旺岁运**。
- Phase A：最优假设=羊刃格刃旺无制、喜水金忌火土木；关键争议=卯木七杀制刃无力反助火；未来高概率主题=水金岁运制刃得用、火土岁运刃旺为祸；推翻条件=火土岁运反顺、水金岁运反逆。

## 判定
- 结果：**命中**
- 出错模块：无
- 偏差说明：无。羊刃格判定、刃旺无制病型、喜忌（喜水金忌火土、卯木生火反助）、空亡（无落空）均与预期一致；补充调候因「原局无水」触发例外⑤降级的完整裁决链。
