# Case 015 · 化气格（丁壬合化木）· 极端结构

- 类别：极端结构（化气-丁壬合木）
- 四柱：壬寅 壬寅 丁卯 乙巳（乾造）
- 设计意图：验证化气格（丁壬化木）判定——化神当令成局、日主无强根

## 预期结论（先给定）
- 化气判定：丁壬合（月干壬-日主丁）✓；化神木在寅月当令 ✓；地支两寅一卯木局成势 ✓；日主丁火坐卯（病地，卯藏乙木无火根）、巳中丙火为丁之根（巳藏丙戊庚——丙火是丁之劫财根！）→ **日主有微根（巳中丙），须评估是否破化**（化气要求日主无强根——微根是否算强根？）
- 关键争议：丁火巳中丙火余气根 vs 化气「日主无强根」——微根不破化（化气破格须「强根」）
- 若化气成立：喜木（化神）水（生木），忌金（克木）土（耗木），火（泄木有争议）
- 空亡：丁卯日柱，丁卯旬空戌亥——无落空

## 模型输出摘要
- 核心总评：丁壬合（月干壬-日主丁）✓，化神木在寅月当令✓、地支两寅一卯木局成势✓，丁火无本气根（坐卯病地无丁、巳藏丙庚戊无丁），**化气格（丁壬合木）成立**，喜木水忌金土，火泄木有争议。不确定度中（巳中劫财微根是否破化的 C 级判断）。
- 定盘：丁火日主，寅月，寅藏甲丙戊、卯藏乙、巳藏丙庚戊；空亡戌亥无落空（丁卯旬空戌亥）
- 成化条件逐条核对（biange.md HUAGQI）：①丁壬合✓（月干壬邻日主丁）；②化神木寅月当令✓；③地支寅寅卯木局成势✓；④日主无强根——丁火本气根（午未戌）全无，巳中丙火为**劫财微根**，化气破格须「强根」，微根不破化✓；⑤化神不受克——天干无金克木（庚辛全无）✓；⑥逢龙则化（辰支）无，属锦上添花非硬判据，不启用
- 关键争议（微根 vs 强根）：巳为丁火帝旺之地、藏丙火劫财——但通根看藏干，巳无丁火本气，仅为同气劫财微根；化气要求「日主无强根」为破化门槛，**微根（劫财余气）不构成强根 → 不破化**；且时干乙木（偏印）属化神木之同气，透出助化不碍化
- 喜忌（化后以化神论）：喜木（化神）、水（生木顺），忌金（克木）、土（耗木），火（泄木——[SCHOOL] 有「火泄木可顺」一说，标注争议）
- 调候：寅月气候温和，不触发 CLIMATE OVERRIDE；化气成立 → 例外④「化气以化神为主」，调候让位
- 六维：HUAGQI 喜化神木、忌破化之金土，六维一致
- 岁运：喜水木运（助化），忌金运（克化神——最凶）、土运（耗化神）；火运按泄木两说评估；岁运助丁火强根（午未戌）有「还原退常格」之虞——[SCHOOL] 标注分歧
- Phase A：最优假设=化气格喜木水忌金土；推翻条件=金土岁运反顺、水木岁运反逆；丁火得强根之运是否还原为判别关键

- 出错模块：无
