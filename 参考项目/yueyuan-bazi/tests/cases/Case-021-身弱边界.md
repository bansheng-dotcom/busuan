# Case 021 · 身弱边界（中和偏弱）· 普通复杂

- 类别：普通复杂（身弱边界）
- 四柱：甲子 丙寅 戊午 庚申（乾造）
- 设计意图：验证身弱/身强边界判断——印比帮扶 vs 食伤财泄耗的权衡

## 预期结论（先给定）
- 旺衰：**中和偏弱**（寅月七杀当令克身，甲木七杀透、庚金食神透耗身；丙火偏印坐寅长生帮身、戊土坐午帝旺得根、申中庚金食神）
- 格局：寅月甲木七杀透（甲为戊之七杀）→ 七杀格？或按透出取格
- 关键点：①戊土坐午（帝旺）有强根，不算弱；②丙火印星化杀生身（杀印相生嫌疑）；③庚金食神透（泄身制杀？食神制杀）——身弱食神制杀或杀印相生的组合判断
- 喜忌：身弱有印 → 喜火（印化杀生身）、土（比劫帮身），忌水木（财杀）、金（食伤泄——但食神制杀需保留，张力）
- 空亡：戊午日柱，戊午旬空子丑——年支子落空亡

## 模型输出摘要
- 核心总评：戊土寅月七杀当令失令，甲木七杀透克、庚金食神透泄，但戊土坐午（帝旺）有强根、丙火偏印坐寅（长生）生身 → **中和偏弱**（非明显身弱），杀印相生为格局主线，喜火土忌水木，金有张力。不确定度中。
- 定盘：戊土日主，寅月，寅藏甲丙戊、午藏丁己、申藏庚壬戊、子藏癸；空亡子丑——年支子落空亡
- 旺衰条件变量：得令？寅月甲木七杀当令克身（失令）；得地？坐午帝旺本气根（劫财己土）+寅中戊土余气+申中戊土余气（根气足）；得势？丙火偏印透生身（得势）、庚金食神透泄身（泄气）→ 综合中和偏弱
- 格局：寅月本气甲木（七杀）透 → 七杀格；丙火偏印透 → **杀印相生嫌疑**（身弱印化杀生身）；庚金食神透制杀 → 食神制杀为竞争路径（[CORE] 两路成格范式竞争，须按身弱程度裁定）
- 杀印相生 vs 食神制杀裁决：身弱（中和偏弱），杀印相生「印化杀生身」更稳（印生身扶弱）；食神制杀在身弱时泄身、有张力——倾向杀印相生为主，食神制杀为辅助视角
- 喜忌：身弱有印 → 喜火（印化杀生身）、土（比劫帮身），忌水（财生杀）、木（杀攻身）；金（食伤泄身——但食神制杀有平衡之功，**张力项**：保留食神制杀则金不可尽去）
- 调候：寅月气候温和，非急；身弱以扶抑为主
- 六维：一致指向喜火土、忌水木，金为张力项（病药维度：食神制杀可去病）
- 岁运：喜火土运（印比帮身），忌水木运（财杀）；金运按制杀/泄身两说评估；年支子（正财）落空亡 → 财虚、财主题打折
- Phase A：最优假设=中和偏弱杀印相生喜火土忌水木（金张力）；推翻条件=水木岁运反顺、火土岁运反逆

## 判定
- 结果：**命中**
- 出错模块：无
- 偏差说明：无。中和偏弱、杀印相生主线、喜火土忌水木（金张力）、年支子落空亡——全部与预期一致。
