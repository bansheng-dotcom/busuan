# Case 091 · 后验食神制杀（权威成就）· 后验

- 类别：后验（食神制杀-应验）
- 四柱：戊申 辛酉 甲申 丙寅（乾造）
- 设计意图：验证食神制杀后验——权威/魄力成就

## Phase A 预注册（先给定）
- 原局：甲木日主酉月（正官当令），丙火食神透（坐寅长生）制申中庚金七杀——食神制杀成格嫌疑（身弱），喜火木忌金水
- 预注册主题：①食伤（火）岁运才华展露/权威；②官杀（金水）岁运压力

## 用户经历（后验输入）
- 2023 癸卯年：升任管理岗，事业权威确立（癸水印星+卯木比劫）。

## 预期裁决（先给定）
- 2023 癸卯：癸水正印透（化杀生身）+ 卯木比劫（帮身）——**印化杀+帮身 → 制杀成格更稳** → 升迁与「身弱杀旺印化/比帮」一致 → **部分命中**（事业权威主题支持）
- 关键点：①食神制杀主事业权威；②印比帮身使身弱可任杀 → 升迁

## 模型输出摘要

### Phase A（预注册，独立于经历）
- 步骤0：甲木日主，月令酉（酉藏辛金本气，为甲之正官）；年干戊=偏财、月干辛=正官、时干丙=食神；地支申酉申寅。空亡：甲申日属甲申旬，空亡午未，原局无午未、无落空。十二长生：甲在申为绝地、甲在寅为临官（禄根）。
- 步骤1：失令（酉月辛金正官当令克木）；得地（时支寅临官禄根、日支申绝地、年支申绝地）；得势（丙火食神透坐寅长生）。不利：辛金正官透克、戊土偏财耗、申申酉金旺。综合倾向 **「身弱（偏弱）」**——官杀旺攻身，赖寅木禄根+丙火食神制杀。喜火（食神制杀）、木（比劫），忌金（官杀）、水（印泄食神）。
- 步骤2：月令酉本气辛金正官透月干 → **正官格**；丙火食神透时干制申中庚金七杀——**食神制杀成格嫌疑**（身弱杀旺、食神制杀为贵）。
- 步骤3：病型「七杀无制」不命中（丙火食神制申中庚杀有力）；「官杀混杂」边缘（辛官透+申中庚杀藏）。病=官杀旺攻身（身弱）；药=火（食神制杀）、木（比劫帮身）。药根气：丙火坐寅长生（制杀有力）；寅木禄根。
- 步骤4：甲木酉月秋季温和 → 普通状态，调候辅助。
- 步骤5：六维一致 → 喜火（食神）、木（比劫），忌金（官杀）、水（印泄食神）。
- 步骤6：天干**丙辛合**（食神合正官——[C]级：酉月金当令，丙辛合化水不成立，合而不化、合绊论——食神制杀之力被官合所绊）；地支**申酉会金局**（申申酉——官杀局）、**寅申冲**（时支寅-日支申、时支寅-年支申——禄根被冲）。空亡无落空。神煞：驿马（申子辰马在寅，日支申查 → 时支寅为驿马；寅申冲驿马逢冲）。
- 步骤10 Phase A 预注册：
  - 最优假设：身弱，食神制杀成格嫌疑；喜火木，忌金水。
  - 主要用神：丙火食神（制杀）、寅木比劫。
  - 关键争议：丙辛合绊（食神合官制杀力受绊）；寅申冲（禄根被冲）。
  - 预注册主题：①**食伤（火）岁运才华展露/权威确立**（制杀有力）；②比劫（木）岁运帮身任杀；③官杀（金水）岁运压力（杀攻身）。
  - 推翻条件：火木岁运反逆或金水岁运反顺 → 本路线被削弱。

### Phase B（后验，读取经历后）
- 用户经历：2023 癸卯年，升任管理岗，事业权威确立。
- 2023 癸卯解析：**癸水正印透（忌——印泄食神：癸水克丙火食神，制杀之力被泄；但印亦化杀生身——身弱杀旺的另一救应路径）** + **卯木比劫（喜——帮身，卯为甲木帝旺之地）**；**卯酉冲**（流年卯冲月支酉——冲正官星）。
- 四态裁决：**部分命中**——①「事业权威确立」与食神制杀/官杀格局（权威、魄力）预测方向一致；②机制：卯木比劫帮身（身强可任官杀）+癸水印化杀生身（压力转贵人）+卯酉冲官星动（事业变动/升迁之象）——多重机制协同支持升迁；③单一年、多机制并存，程度与细节待更多信息，判部分命中。
- 铁则执行：不反向篡改 Phase A。

### 与预期裁决对照
- 预期：部分命中（事业权威主题支持）。我判部分命中 → **一致**。

## 判定
- 结果：命中
- 出错模块：无
- 偏差说明：Phase A 独立分析（身弱、食神制杀成格嫌疑、喜火木忌金水、丙辛合绊/寅申冲隐患）与预期一致；Phase B 对 2023 癸卯（卯帮身+癸化杀+卯酉冲官动→升任管理岗）判部分命中，与预期完全一致。
