# Case 076 · 后验夫妻宫（婚恋应期）· 后验

- 类别：后验（婚恋-夫妻宫）
- 四柱：丙子 庚子 丁卯 壬寅（乾造）
- 设计意图：验证婚恋应期后验——配偶星动+夫妻宫动

## Phase A 预注册（先给定）
- 原局：丁火日主子月（七杀当令），壬水正官透（时干）、庚金正财透（月干）——身弱官杀旺（子水官杀+壬透）
- 最优假设：身弱，喜木（印化杀）火（比劫），忌水（官杀）金（财生杀）
- 预注册主题：①卯木夫妻宫（日支）——配偶星（水官）与夫妻宫（卯）的关系；②木火岁运（印比）婚恋趋稳

## 用户经历（后验输入）
- 2023 癸卯年：结婚。

## 预期裁决（先给定）
- 2023 癸卯：癸水七杀（配偶星透）+ 卯木（夫妻宫伏吟/引动）+ 卯为日支本宫——**配偶星动+夫妻宫动双信号互证** → **命中**（婚恋主题）
- 关键点：①双信号（配偶星+夫妻宫）互证；②身弱官杀旺主晚婚/波折——但卯木印星帮身（化杀）为婚期有利信号

## 模型输出摘要

### Phase A（预注册，独立于经历）
- 步骤0：丁火日主，月令子（子藏癸水本气，为丁之七杀）；年干丙=劫财、月干庚=正财、时干壬=正官；地支子子卯寅。空亡：丁卯日属丁卯旬，空亡戌亥，原局无戌亥、无落空。十二长生：丁在卯为病地（卯藏乙木偏印）。
- 步骤1：失令（子月癸水七杀当令克火）；得地（日支卯藏乙木印、时支寅藏甲木正印+丙火劫财——木火印比有根）；得势（年干丙火劫财帮身）。不利：庚金正财耗、壬水正官克、双子官杀。倾向 **「身弱（中和偏弱）」**——赖卯寅木印+丙火帮身。喜木（印化杀）、火（比劫），忌水（官杀）、金（财生杀）。
- 步骤2：月令子本气癸水七杀 → **七杀格**；壬水正官透时干 → **官杀混杂**（壬官+子中癸杀）。庚金正财透月干（财生杀）。
- 步骤3：病型「官杀混杂」「七杀无制」边缘命中（有卯寅印化杀，非完全无制）。药=木（印化杀）、火（比劫帮身）。药根气：卯寅木印有根；丙火帮身。
- 步骤4：丁火子月冬寒 → CLIMATE OVERRIDE 倾向；调候丁火冬月用甲木引丁（冬丁不离庚甲）。例外检查：调候神甲木（时支寅藏甲木本气）有根 → 不触发例外⑤；调候方向（喜木印引丁）与扶抑（喜印比）**同向**，无冲突 → 调候辅助、扶抑为主，统一喜木火。
- 步骤5：六维一致 → 喜木（印）、火（比劫），忌水（官杀）、金（财生杀）。
- 步骤6：天干**丁壬合**（日主丁合时干壬正官——[C]级：子月水当令但化神木不当令，合而不化、合绊论——官星合身，婚恋/官星主题）；地支**子卯刑**（年支子-日支卯、月支子-日支卯——双子刑卯，**无礼之刑刑入夫妻宫**）、**卯寅会木**（日支卯-时支寅，印局）。空亡无落空。神煞：桃花——亥卯未见子，日支卯查 → **桃花在子**（年支子、月支子双桃花）。
- 步骤10 Phase A 预注册：
  - 最优假设：身弱（中和偏弱），喜木火（印比），忌水金（官杀财）。
  - 主要用神：木印（化杀生身）、火比劫。
  - 关键争议：官杀去留（壬官坐寅根弱、癸杀当令有力，倾向印化留杀）。
  - 预注册主题：①木火岁运（印比）化杀帮身→婚恋趋稳、事业转好；②**卯木夫妻宫（日支）**——配偶星（男命财星庚金）与夫妻宫卯的互动，子卯刑为夫妻宫隐患，逢卯年值临/引动为婚恋应期；③水金岁运（官杀财）→压力、感情波折。
  - 推翻条件：木火岁运反逆或水金岁运反顺 → 本路线被削弱。

### Phase B（后验，读取经历后）
- 用户经历：2023 癸卯年，结婚。
- 2023 癸卯解析：**卯木值临日支夫妻宫**（伏吟/本宫引动——夫妻宫应期主信号）；癸水七杀透（官杀星动——子卯刑被引动）；卯木印星帮身（喜——身弱印化杀，婚期有利）。丁壬合（原局官星合身）逢卯（合神之根生旺）——官星合身主题激活。
  - 概念核对：男命配偶星=财星（庚金正财月干）。2023 癸卯年庚金财星**未直接引动**（无财星透/合冲）——「配偶星动」这一层证据弱；主信号为**夫妻宫卯值临引动**（宫位动）。
- 四态裁决：**命中（婚恋主题）**——夫妻宫值临引动（宫位动）为主信号 + 子卯刑引动（原局结构响应）+ 癸水官杀透（十神星动）为佐证，≥2 独立层互证；印星帮身（喜）为有利条件。结婚事件与「夫妻宫逢值临为婚恋应期」预测一致。
- 铁则执行：不反向篡改 Phase A；婚期确准，判「命中」。

### 与预期裁决对照
- 预期：命中（配偶星动+夫妻宫动双信号互证）。我判命中（婚恋主题）→ **裁决一致**；但对"配偶星"归属有概念性修正（见下）。

## 判定
- 结果：部分命中（裁决一致，配偶星概念标注偏差）
- 出错模块：配偶星归属标注（Phase B 解释层）
- 偏差说明：①裁决「命中」与预期一致——2023 癸卯结婚与「夫妻宫卯值临引动+子卯刑+官杀透」应期一致；②概念修正：**男命配偶星为财星（庚金正财），预期将癸水七杀列为"配偶星"属概念偏差**（官杀对男命为子女/事业星）；2023 财星未直接引动，主信号为夫妻宫值临（宫位动）+子卯刑（原局响应），应期仍成立，故裁决不变。
