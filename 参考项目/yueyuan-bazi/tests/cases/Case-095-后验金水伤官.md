# Case 095 · 后验金水伤官（冬金见火）· 后验

- 类别：后验（金水伤官-应验）
- 四柱：辛巳 庚子 庚子 癸未（乾造）
- 设计意图：验证金水伤官喜见官后验——火（官杀）岁运应吉

## Phase A 预注册（先给定）
- 原局：庚金子月金水伤官（癸水伤官透），冬寒需火——**金水伤官喜见官**，喜火（调候）木（财）
- 预注册主题：①火（官杀）岁运暖局应吉；②水（伤官）岁运过寒应滞

## 用户经历（后验输入）
- 2025 乙巳年：事业有起色、状态提升（乙木正财+巳火七杀调候）。

## 预期裁决（先给定）
- 2025 乙巳：巳火（调候用神）+ 乙木财星——**火年暖局** → 与「金水伤官喜火」一致 → **部分命中/命中**（调候主题支持）
- 关键点：①金水伤官喜见官（火）——伤官见官不为祸反为喜（例外）；②巳火调候

## 模型输出摘要

### Phase A（预注册，独立于经历）
- 步骤0：庚金日主，月令子（子藏癸水本气，为庚之伤官）；年干辛=劫财、月干庚=比肩、时干癸=伤官；地支巳子子未。空亡：庚子日属庚子旬，空亡辰巳 → **年支巳落空亡**（调候神火之根落空，力减——仅作修正项）。十二长生：庚在巳为长生、在子为死地。
- 步骤1：失令（子月癸水伤官当令泄身）；得地（年支巳藏庚金长生根、日支子/月支子死地、时支未藏己土印）；得势（庚金比肩透、辛金劫财透帮身）。不利：癸水伤官透、双子伤官旺泄。综合倾向 **「身弱（中和偏弱）金水伤官」**——伤官当令泄身，赖巳中庚根+比劫帮身。冬寒极。
- 步骤2：月令子本气癸水伤官透时干 → **伤官格**（金水伤官）。
- 步骤3：病型「伤官见官」不命中（原局无正官丁火）。病=金寒水冷（冬寒）+伤官泄身；药=火（调候暖局）、木（财）。药根气：巳中丙火（调候神）有根但**巳落空**（力减）；木原局无。
- 步骤4：**庚金子月冬寒极 → CLIMATE OVERRIDE 触发**；庚金冬月调候丁火炼金取暖、丙火为辅（冬金要火炼）。**金水伤官喜见官**（[patterns.md] 例外：金水伤官喜见丙火官星调候——伤官见官不为祸反为喜）。例外检查：调候神巳中丙火有根（落空但藏干仍在）→ 例外⑤不成立（力减标注）→ **CLIMATE OVERRIDE 成立，调候火为第一用神**。
- 步骤5：六维一致（调候优先）→ 喜火（官杀暖局）、木（财），忌水（寒伤官）、金（比劫）。
- 步骤6：天干辛庚比劫、癸伤官，无五合；地支**子未害（穿）**（日支子-时支未）、子子双伤官。空亡：年支巳落空（调候神力减）。神煞：天乙贵人（庚日贵人在丑未，未为贵人）。
- 步骤10 Phase A 预注册：
  - 最优假设：身弱金水伤官，冬寒极 CLIMATE OVERRIDE，金水伤官喜见官——喜火（官杀暖局，第一用神）、木（财），忌水（寒伤官）、金（比劫）。
  - 主要用神：火（丁丙——调候暖局）、木财。
  - 关键争议：调候神巳火落空（力减但根在）。
  - 预注册主题：①**火（巳午）岁运暖局应吉——事业起色、状态提升**；②木（财）岁运顺；③水（亥子）岁运过寒应滞。
  - 推翻条件：火岁运反逆或水岁运反顺 → 本路线被削弱。

### Phase B（后验，读取经历后）
- 用户经历：2025 乙巳年，事业有起色、状态提升。
- 2025 乙巳解析：**乙木正财透（喜——财）** + **巳火七杀（调候用神——暖局；庚金七杀=丙火，巳藏丙火；庚金在巳为长生——长生再现）**；巳火值临（调候神填实/再现）。
- 四态裁决：**部分命中**——巳火（调候用神）暖局+乙木财星透——「火岁运暖局应吉」预测方向一致：事业有起色、状态提升应验；调候主题获单年支持；火木双喜之年，判部分命中（单一年，收敛需更多年份）。
- 阶段性收敛：目前更支持「金水伤官喜见官、调候火为用」路线；若补充任一水年（过寒应滞）或火年复现可进一步确认。
- 铁则执行：不反向篡改 Phase A。

### 与预期裁决对照
- 预期：部分命中/命中（调候主题支持）。我判部分命中 → **一致**（在预期接受范围内，取保守档）。

## 判定
- 结果：命中
- 出错模块：无
- 偏差说明：Phase A 独立分析（金水伤官、CLIMATE OVERRIDE、调候火为第一用神、喜火木忌水金）与预期一致；Phase B 对 2025 乙巳（巳火暖局+乙财）判部分命中，在预期「部分命中/命中」范围内，一致。补充年支巳落空（调候神力减）之细节，不改变裁决。
