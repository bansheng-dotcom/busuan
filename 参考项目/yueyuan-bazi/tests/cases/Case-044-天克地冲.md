# Case 044 · 天克地冲（原局年时）· 普通复杂

- 类别：普通复杂（干支作用-天克地冲）
- 四柱：壬申 丙午 庚寅 丙戌（乾造）
- 设计意图：验证天克地冲判定——原局年柱与日柱天克地冲

## 预期结论（先给定）
- 干支作用：年柱壬申 vs 日柱庚寅——**天克地冲**（壬庚天克？壬水克丙火？——壬与庚不克……壬为阳水、庚为阳金，金生水非克。需重查：壬申 vs 庚寅：天干壬庚（金生水，非克），地支申寅（寅申冲 ✓）——**只有地冲无天克，非天克地冲**。设计偏差。）
- 复盘：真正的天克地冲需天干相克+地支相冲，如「庚寅 vs 甲申」（庚甲克+寅申冲）。此盘年壬申/日庚寅只有寅申冲。修正为「寅申冲+官杀混杂」测试。
- 修正预期：年支申 vs 日支寅冲（驿马冲），月干丙午、时干丙戌——丙火七杀双透（庚之七杀）→ 官杀（七杀）双现；身弱（寅月？丙午月火旺克庚……庚在午月火旺，庚坐寅绝地无根）——七杀攻身
- 喜忌：身弱杀旺，喜土（印化杀）、金（比劫帮身），忌火（七杀）、木（财生杀）
- 空亡：庚寅日柱，庚寅旬空子丑——无落空

## 模型输出摘要
- 核心总评：庚金午月（丁火正官当令），丙火七杀双透（月、时）、壬水食神透年——**身弱官杀攻身**；年柱壬申与日柱庚寅：天干壬庚为金生水（非克），地支申寅相冲——**只有地冲、无天克，非天克地冲**（确认预期设计修正）；寅申冲为驿马冲。不确定度：中。
- 定盘（S1/A）：乾造，日主庚金，月令午（丁火正官当令），藏干申（庚壬戊）午（丁己）寅（甲丙戊）戌（戊辛丁）；庚寅旬空子丑，四支无子丑，无落空。
- 旺衰：身弱（[CORE] 午月火旺克身 + 庚坐寅绝地无根 + 年支申庚禄根被寅冲 + 仅戌中辛金余气根；丙丙七杀双透克身）。
- 格局：月令午本气丁火正官当令，不透；丙火七杀双透得令 → **七杀格**（官杀混杂：丁官当令 + 丙杀透）。
- 病药：**七杀攻身（身弱杀旺）**；药=壬水食神制杀（坐申长生有根，但申被寅冲——药根受冲）、印（戌中戊土藏，化杀生身）、比劫（金帮身）。
- 调候：午月夏月燥——调候需水润；壬水食神透为调候兼制杀（双职），方向与病药一致；未至极燥不触发 CLIMATE OVERRIDE。
- 六维：扶抑（身弱需印比——土金）、格局（七杀格宜印化杀/食制杀）、调候（水润局，与病药同向）、病药（壬水制杀、印化杀）、变格（NORMAL，年支申禄根虽被冲但存在，不从）。一致指向 **喜土（印化杀）、金（比劫帮身）、水（食神制杀），忌火（七杀）、木（财生杀）**。
- 岁运：喜土金水岁运，忌火木岁运；寅申冲（驿马冲）逢岁运引动主流动/变动；七杀旺岁运官非压力。
- Phase A：最优假设=七杀攻身、喜土金水忌火木；关键争议=食神制杀药根受冲（申被寅冲）；未来高概率主题=土金水岁运制杀帮身顺、火木岁运官杀攻身；推翻条件=火木岁运反顺、土金水岁运反逆。

## 判定
- 结果：**命中**
- 出错模块：无
- 偏差说明：无。确认「非天克地冲（仅地冲寅申）」的判断与预期设计修正一致；身弱七杀攻身、喜忌（喜土金忌火木）、空亡（无落空）均命中；补充壬水食神制杀为药及申被寅冲的细节。
