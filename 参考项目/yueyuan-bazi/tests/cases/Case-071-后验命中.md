- 四柱：乙酉 辛巳 癸丑 丙辰（乾造）

## 模型输出摘要

### Phase A（预注册，独立于经历）
- 步骤0：癸水日主，月令巳（丙火正财当令）；年干乙=食神、月干辛=偏印、时干丙=正财；地支酉丑巳辰。空亡：癸丑日属癸丑旬，空亡子亥，原局无子亥、无落空。十二长生：癸坐丑为冠带（丑藏癸水中气根）。
- 步骤1：失令（巳月丙火财当令耗身）；得地（日支丑藏癸水本气中气根、辰藏癸水余气根、月支酉）；得势（辛金偏印透生身）。不利：乙木食神泄、丙火财耗。倾向 **「身弱（中和偏弱）」**。**从格嫌疑核查**：Root resistance——日主有根（丑中癸水、辰中癸水）+印星辛金透干有禄根（坐酉）→ 判据1/2 倾向不从。路线：身弱。
- 步骤2：月令巳本气丙火正财透时干 → **正财格**。辛金偏印透月干——财格配印。
- 步骤3：病型「财多身弱」边缘命中；药=金（印生身）、水（比劫帮身）。药根气：辛坐酉禄根有力。
- 步骤4：癸水巳月夏，调候辛金生水（[SCHOOL] 夏癸要辛金）——与扶抑同向，调候辅助。
- 步骤5：六维一致 → 喜金（印）、水（比劫），忌火（财）、土（官杀）。
- 步骤6：**巳酉丑三合金局**（年巳-月酉-日丑——印局成，生身转有力）；天干**丙辛合**（财印合——[C]级：巳月水不当令，合而不化、合绊论，财印互绊）。空亡无落空。
- 步骤10 Phase A 预注册：
  - 最优假设：身弱（中和偏弱），喜金水（印比），忌火土（财官）；印局（巳酉丑）为关键支撑。
  - 主要用神：辛金偏印、壬癸水比劫。
  - 关键争议：身弱 vs 从财——倾向不从（有根+印透）；但印局使身转有力，参数级边界在「身弱喜印比」与「印旺身转强」之间。
  - 预注册主题：①金水岁运（庚辛申酉、壬癸亥子）印比帮身→事业顺、能任财；②火土岁运（财官）为财所累、财来财去。
  - 推翻条件：火土财官岁运反大顺（尤其食伤生财、财官成势）→「身弱忌火土」被削弱。

### Phase B（后验，读取经历后）
- 用户经历：2023 癸卯年，事业较顺，有升职加薪。
- 2023 癸卯解析：癸水比肩帮身（喜——印比路线）；卯木食神（癸水食神=乙木，卯藏乙木本气）泄秀生财；卯酉冲（流年卯冲月支酉——冲印星禄根）、卯辰相害（穿）。比肩帮身后身可任财，食神生财流通。
- 四态裁决：**部分命中**——①喜水方向（癸水比肩帮身任财）与「身弱喜金水」一致，支持；②「升职加薪」涉官/财主题，单一年单一维度不足以完全验证印比路线；③「事业较顺」之顺与帮身任财相符。
- 阶段性收敛结论：基于此单一年份证据，**目前更支持「喜金水」路线**，喜金水、忌火土；该结论为阶段性倾向。若要进一步确认，补充任一火土年（财官）的顺逆即可——火土年顺则削弱本路线、逆则加强；其他资料无需再翻。
- 铁则执行：不反向篡改 Phase A；单一年不足以定论，故判「部分命中」而非「命中」。
