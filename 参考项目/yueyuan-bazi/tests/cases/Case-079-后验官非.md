# Case 079 · 后验官非（伤官见官应期）· 后验

- 类别：后验（事业-官非口舌）
- 四柱：乙巳 丁亥 甲子 庚午（乾造）
- 设计意图：验证伤官见官类官非后验——岁运引动病型

## Phase A 预注册（先给定）
- 原局：甲木日主亥月（偏印当令），丁火伤官透（月干）、庚金七杀透（时干）——伤官+七杀（伤官驾杀），身中和（亥月印生、甲坐子沐浴）
- 最优假设：中和，喜火（伤官泄）土（财），忌金（七杀）水（印泄伤官）
- 预注册主题：①伤官七杀并现——口舌/官非/工作变动主题；②金水岁运（杀印）压力

## 用户经历（后验输入）
- 2020 庚子年：工作中与人起纠纷，有诉讼口舌。

## 预期裁决（先给定）
- 2020 庚子：庚金七杀透（克身）+ 子水印星（泄伤官——印制伤官）——**七杀引动 + 伤官被泄** → 官非口舌与「伤官见杀/七杀引动」一致 → **命中**（口舌官非主题）
- 关键点：①病型被岁运引动=应期重点（[HEURISTIC]）；②庚金七杀透为当年最大变量

## 模型输出摘要

### Phase A（预注册，独立于经历）
- 步骤0：甲木日主，月令亥（亥藏壬水本气，为甲之偏印）；年干乙=劫财、月干丁=伤官、时干庚=七杀；地支巳亥子午。空亡：甲子日属甲子旬，空亡戌亥 → **月支亥落空亡**（偏印月令落空，仅作修正项）。十二长生：甲在亥为长生。
- 步骤1：得令（亥月壬水偏印当令生木）；得地（日支子沐浴藏癸水印、时支午死地、年支巳病地）；得势（乙木劫财帮身）。不利：丁火伤官泄、庚金七杀克。倾向 **「中和（偏弱）」**——印星当令生身有力但月令落空打折扣。喜火（伤官制杀泄秀）、土（财），忌金（七杀）、水（印泄伤官）。
- 步骤2：月令亥本气壬水偏印 → **偏印格**。丁火伤官透月干、庚金七杀透时干——**伤官驾杀（伤官制杀）之象**（庚为七杀非正官，非「伤官见官」病型）。
- 步骤3：病型「七杀无制」不命中（丁火伤官制庚杀）；「印克伤官」为次病（亥水印泄丁火伤官——表达受制）。药=火（伤官制杀泄秀）、土（财）。药根气：丁火坐亥无根（弱）。
- 步骤4：甲木亥月冬寒，调候丙火暖局；但调候神丁火坐亥无根 → 例外⑤调候降级辅助；调候方向（喜火）与扶抑（喜火）同向。
- 步骤5：六维一致 → 喜火（伤官）、土（财），忌金（七杀）、水（印）。
- 步骤6：天干**乙庚合**（劫财合杀，[C]级合绊）；地支**亥子半合水**（月支亥-日支子）、**巳午半会火**（年支巳-时支午）、**子午冲**（日支子-时支午——夫妻宫逢冲）。空亡：月支亥落空。
- 步骤10 Phase A 预注册：
  - 最优假设：身中和，喜火土（伤官财），忌金水（杀印）。
  - 主要用神：丁火伤官（制杀泄秀）、土财。
  - 关键争议：月令落空、伤官根弱（丁坐亥无根）。
  - 预注册主题：①**伤官七杀并现——口舌/官非/工作变动主题**；②金水岁运（杀印）压力——七杀克身、印制伤官（表达受堵、口舌被动）；③火土岁运（食伤财）顺。
  - 推翻条件：火土岁运反逆或金水岁运反顺 → 本路线被削弱。

### Phase B（后验，读取经历后）
- 用户经历：2020 庚子年，工作中与人起纠纷，有诉讼口舌。
- 2020 庚子解析：**庚金七杀透**（与乙庚合之庚同字——杀星重现攻身）；子水偏印（印泄伤官——丁火伤官被制，表达受堵、口舌缠身）；子午冲（流年子冲时支午——冲伤官星）；子水与日支子伏吟（子子）。
- 四态裁决：**命中**——①庚金七杀透（七杀引动——口舌官非/压力主题）为当年最大变量；②子水印星泄伤官（印制伤官——表达受阻、口舌被动）；③病型（伤官驾杀）被岁运引动=应期重点（[HEURISTIC]）。口舌诉讼与「伤官七杀并现+七杀引动」预测一致。
- 铁则执行：不反向篡改 Phase A。

### 与预期裁决对照
- 预期：命中（七杀引动+伤官被泄——口舌官非与伤官见杀/七杀引动一致）。我判命中 → **一致**。

## 判定
- 结果：命中
- 出错模块：无
- 偏差说明：Phase A 独立分析（伤官驾杀、喜火土忌金水、口舌官非主题）与预期一致；Phase B 对 2020 庚子（庚杀透克身+子水印制伤官+子午冲）判命中，与预期完全一致。概念上确认「伤官驾杀」而非「伤官见官」（庚为七杀）。
