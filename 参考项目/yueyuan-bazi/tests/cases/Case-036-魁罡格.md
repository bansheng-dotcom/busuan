# Case 036 · 魁罡格（特殊格局）· 普通复杂

- 类别：普通复杂（特殊格局-魁罡）
- 四柱：庚辰 丙戌 庚辰 丁丑（乾造）
- 设计意图：验证魁罡格判定——庚辰魁罡日、身强

## 预期结论（先给定）
- 格局：庚辰日（魁罡日——庚辰/庚戌/壬辰/戊戌为魁罡），月令戌土（偏印当令？戌中戊土是庚之偏印——戌月戊土当令 → 印当令），天干丙丁火官杀透（丙七杀/丁正官）
- 旺衰：身强（戌月印生 + 庚坐辰养地有根 + 辰戌土印局）
- 关键点：①魁罡日主刚毅果断，喜身强官杀制（魁罡逢杀主贵）；②丙丁官杀齐透——官杀混杂？去留？③辰戌冲（年时冲）——魁罡逢冲主变动
- 喜忌：身强官杀旺——喜火（官杀制身）、水（食伤制杀？），忌土金（印比）
- 空亡：庚辰日柱，庚辰旬空申酉——无落空

## 模型输出摘要
- 核心总评：庚辰日——**魁罡格成立（B 特殊格局）**；戌月戊土偏印当令生身，庚坐辰（养地）有根、辰戌丑三土印局，身强；天干丙火七杀、丁火正官齐透。不确定度：中。
- 定盘（S1/A）：乾造，日主庚金，月令戌（戊土偏印当令），藏干辰（戊乙癸）戌（戊辛丁）丑（己癸辛）；庚辰旬空申酉，四支无申酉，无落空。
- 旺衰：偏强（[CORE] 戌月印当令生身 + 庚坐辰养地根 + 辰戌丑三土印局）；辰戌丑中皆藏辛金余气，金有根不被埋死。
- 格局：庚辰日 → **魁罡格**（B 特殊格局，不入变格顺势逻辑）；月令戌本气戊土偏印当令但不透，丙丁官杀透干——**官杀齐透（官杀混杂）**；去留：丙坐戌（火墓）根弱、丁坐丑（火墓）根弱，两官杀皆根浅，制身之力有限。
- 病药：魁罡喜身强官杀制（魁罡逢杀主贵）——丙丁官杀为药制身，但**两火坐墓根弱，药力不足**（[CORE]）；土印过旺为病（身强印多）。药 = 火（官杀）+ 水（食伤泄秀制土印）。
- 调候：戌月秋、气候温和，非极端，不触发 CLIMATE OVERRIDE；调候非急。
- 六维：扶抑（身强需抑——火官杀、水食伤泄）、格局（魁罡喜官杀）、调候（非急）、病药（官杀制身为药但根弱）、变格（NORMAL/B 特殊格局，非变格体系）。一致指向 **喜火（官杀制身）、水（食伤泄秀），忌土金（印比）**；注意：水食伤制杀与官杀为用存在内部张力，[SCHOOL] 标注存疑。
- 岁运：喜火水岁运（制身/泄秀），忌土金岁运（印比帮身过旺）；辰戌冲（年时冲）为原局结构变量——魁罡逢冲主变动主题。
- Phase A：最优假设=魁罡格身强、喜火水忌土金；关键争议=丙丁官杀坐墓根弱致制身力弱、官杀混杂去留；未来高概率主题=火水运制身泄秀顺、土金运帮身过旺压抑；推翻条件=土金运反顺、火水运反逆。

## 判定
- 结果：**命中**
- 出错模块：无
- 偏差说明：无。魁罡格判定、身强、喜忌（喜火忌土金）、空亡（无落空）、辰戌冲变动主题均与预期一致；补充丙丁官杀坐墓根弱、制身之力有限的细节（预期未展开，属加深分析）。
