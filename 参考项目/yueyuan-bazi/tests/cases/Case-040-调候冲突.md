# Case 040 · 调候冲突（调候与扶抑冲突）· 普通复杂

- 类别：普通复杂（调候冲突）
- 四柱：壬寅 壬寅 丙午 甲午（乾造）
- 设计意图：验证调候与扶抑冲突的裁决——夏火旺但需水调候

## 预期结论（先给定）
- 气候：午月火旺（丙坐午帝旺、午午火局）——夏月燥热但未至「极端」（寅月木生火、壬水透）→ 普通状态
- 旺衰：身强（午月火当令+坐午帝旺+午午火局+甲木印生）
- 关键点：①调候：丙火夏月需壬癸水润局——**壬水透（年/月干）为调候用神**；②扶抑冲突：身强按扶抑本应喜财官（金水）泄耗——壬水（七杀）既是调候又是官杀（泄耗）——**调候与扶抑同向**（非冲突）；③甲木印透（生火助旺）——身强印为忌？
- 喜忌：身强喜金水（财官泄耗+调候）——壬水七杀调候兼制身，喜水金，忌木火（印比）
- 空亡：丙午日柱，丙午旬空寅卯——年支寅、月支寅均落空亡

## 模型输出摘要
- 核心总评：丙火日主**寅月**（偏印当令），丙坐午帝旺、午午火局、甲木印生——**身强**；壬水七杀两透为用制身兼调候（丙火喜壬水映辉）——**调候与扶抑同向，非冲突**。不确定度：低。
- 定盘（S1/A）：乾造，日主丙火，月令寅（甲木偏印当令），藏干寅（甲丙戊）午（丁己）；**丙午旬空寅卯——年支寅、月支寅均落空亡**。
- 旺衰：偏强（[CORE] 寅月印当令生火 + 丙坐午帝旺 + 午午火局 + 甲木印透生身；寅午半合火助身）。
- 格局：月令寅本气甲木偏印当令、甲透时干 → 偏印格；**身强印为忌**（甲坐午死地无根、寅落空亡——印虚浮）。
- 病药：身强火炎为病（印比成势）；药=壬水七杀（制身泄秀兼调候）+ 金（财泄火）。壬水坐寅（病地）根弱、且寅落空——**药根气弱**。
- 调候：**注意盘面月令实为寅（春），非夏**——春月气候温和，非极端，不触发 CLIMATE OVERRIDE；丙火调候用壬水（映辉），与扶抑（身强喜水制）**同向一致，非冲突**。
- 六维：扶抑（身强需抑——水金克泄耗）、格局（偏印格身强印为忌）、调候（丙用壬水，与扶抑同向）、病药（壬水制身为药但根弱）、变格（NORMAL，丙坐午强根不从）。一致指向 **喜水（壬水七杀调候兼制身）、金（财泄火），忌木火（印比）**。
- 岁运：喜水金岁运，忌木火岁运（印比助火炎）；壬水七杀得根岁运（如申子辰）制身有力。
- Phase A：最优假设=身强偏印格、喜水金忌木火、调候与扶抑同向；关键争议=壬水根弱、寅空亡减印根；未来高概率主题=水金岁运顺、木火岁运火炎压抑；推翻条件=木火岁运反顺、水金岁运反逆。

## 判定
- 结果：**命中**
- 出错模块：定盘/气候措辞（预期偏差）
- 偏差说明：主判断命中（身强、调候与扶抑同向非冲突、喜水金忌木火、寅寅空亡）。偏差：预期结论首行称「午月火旺/夏月燥热」，但盘面月柱为壬寅，**月令实为寅（春）**，非夏——夏月设定不成立；预期随后亦自注「寅月木生火」，内部措辞矛盾。我的分析以盘面寅月为准（春月温和、普通状态），结论一致，仅月令季节措辞与预期文字不同。
