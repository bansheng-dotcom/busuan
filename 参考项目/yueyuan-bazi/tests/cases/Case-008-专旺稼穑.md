# Case 008 · 稼穑格（土专旺）· 极端结构

- 类别：极端结构（专旺-稼穑）
- 四柱：戊戌 己未 戊午 己未（乾造）
- 设计意图：验证专旺格（稼穑）判定、午未合/未戌刑的评估

## 预期结论（先给定）
- 格局：**稼穑格（土专旺）成立**——未月土当令、未戌午土局成势、戊己比劫透
- 旺衰：极旺
- 喜忌：喜火土（印比顺旺势），忌木（官杀最忌）、水（财次之）、金（食伤有争议）
- 关键点：未戌相刑（土刑土）应并入力量评估；午未合火生土助旺
- 空亡：戊午日柱，戊午旬空子丑——无落空

## 模型输出摘要
- 核心总评：戊土未月当令，未未戌午土局成势、戊己比劫全透，克泄耗（木水）无本气根，**稼穑格（土专旺）成立**，喜火土忌木水，金有争议。不确定度低。
- 定盘：戊土日主，未月，未藏己丁乙、戌藏戊辛丁、午藏丁己；空亡子丑无落空（戊午旬空子丑）
- 旺衰：极旺（得令+得地+得势三全）
- 格局：ZHUANWANG 稼穑格（未戌午土势成、异类无本气根——未中乙木官杀仅余气、戌中辛金食伤仅余气、水全无 → 专旺成立，未受杂破）
- 调候：未月夏末燥热，但专旺成立 → CLIMATE OVERRIDE 例外③「专旺以顺势为主」生效，调候让位
- 病药：专旺体系不套用病型，势纯无病
- 六维：一致指向喜火土、忌木水；一级用火（印）、二级用土（比劫）；[SCHOOL] 标注土见金（食伤）「泄秀 vs 泄气」两说
- 干支作用：午未合火生土助旺（年日支午-月时支未）；未戌相刑（土刑土）并入整体力量评估、不单独论吉凶；未未非自刑支
- 岁运：喜火土运顺，忌木运（官杀破格最险）、水运（财耗）；金运按两说评估
- Phase A：最优假设=稼穑格喜火土忌木水；推翻条件=木水岁运反顺、火土岁运反逆

## 判定
