# Case 088 · 后验财多身弱（财旺年反累）· 后验

- 类别：后验（财多身弱-应验）
- 四柱：戊午 丙辰 甲午 己巳（乾造）
- 设计意图：验证财多身弱后验——财旺岁运接不住

## Phase A 预注册（先给定）
- 原局：甲木日主辰月（偏财当令），戊己土财透、丙火食神透——**从财格**（身弱财旺至极，从财）或财多身弱边缘，喜土火忌水木
- 预注册主题：①火土岁运（食伤财）顺势应吉；②水木岁运（印比）破从/帮身反抗

## 用户经历（后验输入）
- 2021 辛丑年：财运机会多但接不住，反而亏损（辛金正官透+丑土正财）。

## 预期裁决（先给定）
- 2021 辛丑：辛金正官 + 丑土正财——财官年 → 若从财应顺……但用户反馈「机会多接不住亏损」→ 与「财多身弱担不起财」一致（若判身弱）→ **部分命中**（财多身弱主题；从格 vs 身弱路线未决）
- 关键点：①此案例为从财 vs 财多身弱的路线裁决测试——经历「财多接不住」支持「身弱难任财」而非纯从财；②如实标注路线分歧

## 模型输出摘要

### Phase A（预注册，独立于经历）
- 步骤0：甲木日主，月令辰（辰藏戊土本气，为甲之偏财）；年干戊=偏财、月干丙=食神、时干己=正财；地支午辰午巳。空亡：甲午日属甲午旬，空亡辰巳 → **月支辰、时支巳均落空亡**（偏财月令落空、食神落空——从势纯度受影响，假从嫌疑）。十二长生：甲在午为死地。
- 步骤1：失令（辰月戊土偏财当令耗身）；得地（午午死地、巳病地——**日主甲木无根**）；得势（戊己土财双透、丙火食神透——满盘财食伤，克泄耗交加）。
- **从格嫌疑核查（Root resistance）**：判据1——日主本气根是否存在？地支午午辰巳无寅卯亥子——**日主无根** ✓；判据2——印比透干？原局无印无比透干——生扶无显 ✓；判据3——克泄耗成势？财食伤满盘 ✓；判据4——生扶极度微弱或全无？印比全无 ✓。
- **倾向：从财格成立**（财星当令成势、食伤生财顺之）；但财星（辰土）月令落空、食神（巳火）落空——从势纯度受损，**假从嫌疑** → 保留竞争假设：财多身弱（若非从，退论身弱则喜印比）。
- 步骤2：月令辰本气戊土偏财透年干 → 偏财格；从财成立按 biange.md FROM 状态机取用。
- 步骤3：变格体系不套用普通病型；从格内病=破格之物（印比水木），药=顺势（土火财食伤）。
- 步骤4：甲木辰月春末温和 → 普通状态；从势例外②「以顺势为主」，调候退居次位。
- 步骤5：六维一致（从财路线）→ **喜土火（财食伤），忌水木（印比）**。
- 步骤6：天干**甲己合**（日主甲合时干己正财——[C]级：辰月土当令，甲己合化土倾向成立，从财顺局更纯）；地支午午巳会火（食伤局生财）。空亡：月支辰、时支巳落空（假从瑕疵）。
- 步骤10 Phase A 预注册：
  - 最优假设：**从财格**（日主无根、印比全无、财食伤成势），喜土火（财食伤），忌水木（印比）。
  - 竞争假设：**财多身弱**（辰巳落空使从势纯度受损，退论身弱则喜水木印比）——**路线级竞争**（喜忌方向相反）。
  - 主要用神：戊己土财、丙火食神。
  - 关键争议：从财 vs 财多身弱（无根→从格倾向强；财食落空→假从）。
  - 预注册主题：①火土岁运（食伤财）顺势应吉（从财路线）；②水木岁运（印比）破从/帮身反抗应凶（从财视角）；③若退财多身弱：火土岁运为财所累、水木岁运反发。
  - 推翻条件：火土岁运反逆（机会多接不住/亏损）→ 从财路线受挑战、财多身弱获支持；水木岁运反顺同理。

### Phase B（后验，读取经历后）
- 用户经历：2021 辛丑年，财运机会多但接不住，反而亏损。
- 2021 辛丑解析：辛金正官透 + 丑土正财（甲木正财=己土，丑藏己土——财星）；**丑午害（穿）**（流年丑害年支午、日支午——食伤宫/自身宫被穿）。
- 四态裁决：**部分命中**——①「财运机会多但接不住亏损」与**财多身弱**路线（财旺年担不起财、为财所累）高度一致；②**从财路线被削弱**（从财预测火土年顺势顺，实际土年亏损）；③单一年不足以下定论——如实标注路线分歧：从财 vs 财多身弱未决，本经历**偏财多身弱**；需水木年（印比）顺逆进一步裁决（财多身弱则水木年反发、从财则水木年破格应凶）。
- 铁则执行：不反向篡改 Phase A（预注册两条路线均保留，标注经历偏向）。

### 与预期裁决对照
- 预期：部分命中（财多身弱主题；从格 vs 身弱路线未决）。我判部分命中 → **一致**。

## 判定
- 结果：命中
- 出错模块：无
- 偏差说明：Phase A 独立分析确认从财 vs 财多身弱路线级竞争（从财为最优、辰巳落空致假从嫌疑），与预期一致；Phase B 对 2021 辛丑（土财年机会多接不住亏损）判部分命中、经历偏财多身弱、从财路线被削弱、如实标注路线未决，与预期完全一致。
