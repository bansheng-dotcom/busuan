# Case 056 · 墓库入墓（用神入墓受制）· 岁运

- 类别：岁运（墓库-入墓）
- 四柱：乙酉 癸未 丁酉 辛亥（乾造）
- 大运：乙丑运（丑为金墓）
- 流年：己丑年（丑年——金入墓）
- 设计意图：验证用神（财星金）入墓受制的判定

## 预期结论（先给定）
- 原局：丁火日主未月（食神当令？未中己土是丁之食神——未月己土当令 → 食神格），酉金财星双透（年酉/日酉——酉中辛金是丁之正财）——身弱财旺（未月泄、酉财耗）
- 大运乙丑：丑为金库——财星（酉金）入墓
- 流年己丑：丑年——财星再入墓
- 关键点：①用神（财星金）死绝无气且逢岁运入库 → **入墓受制**（暂时休伏或受制）——财运受压主题；②丑酉半合金（丑酉合金？丑酉半合）——财星被合入墓；③身弱财旺本身担财不力——入墓加剧
- 喜忌：身弱财旺，喜木火（印比帮身），忌金水（财官）、土（食伤泄身生财）
- 空亡：丁酉日柱，丁酉旬空辰巳——无落空

## 模型输出摘要
- 核心总评：丁火未月（己土食神当令），酉酉财星旺、辛金偏财透、亥水官杀克身——**身弱财旺（财多身弱）**；大运乙丑、流年己丑——**丑为金库，财星（酉金/辛金）入墓受制**，财运受压主题。不确定度：中。
- 定盘（S1/A）：乾造，日主丁火，月令未（己土食神当令），藏干酉（辛）未（己丁乙）亥（壬甲）；丁酉旬空辰巳，四支无辰巳，无落空。
- 旺衰：身弱（[CORE] 未月土当令泄火 + 酉酉财星耗身 + 亥水官杀克身 + 癸水七杀透；丁坐酉虽为长生但酉藏辛金属财、未中丁火余气根弱）。
- 格局：月令未本气己土食神当令，不透 → 食神格；身弱食神泄身生财，财更旺。
- 病药：**财多身弱（身弱财旺）**——丁火身弱担不起旺财；药=印（乙木，坐酉绝地无根——印虚浮）、比劫（火，原局无）。喜印比帮身任财。
- 墓库（P0 修正）：**丑为金库（辛金墓库）——财星（酉金、辛金）逢丑运丑年入墓**；丑酉半合金（财星被合入墓）；入墓受制（用神死绝无气且逢岁运入库）→ 财星休伏/受制，**财运受压主题**；身弱财旺本身担财不力——入墓加剧。
- 调候：未月夏月燥——调候需水润；原局亥水、癸水有根，调候神不虚浮；但未月未至极燥，不触发 CLIMATE OVERRIDE（普通状态）。
- 六维：扶抑（身弱需印比——木火）、格局（食神格顺用）、调候（未月需水，但水为官杀克身——调候与扶抑相抵，参数级）、病药（财多身弱，印比帮身为药）、变格（NORMAL，丁有未中余气根不从）。一致指向 **喜木火（印比帮身），忌金水（财官）、土（食伤泄身生财）**。
- 岁运：喜木火岁运，忌金水土岁运；丑运丑年财入墓——财运受压；乙木印透生身（帮身）但坐酉绝地力弱。
- Phase A：最优假设=财多身弱、喜木火忌金水土；关键争议=财入墓吉凶（财源闭锁 vs 忌神受制）；未来高概率主题=木火岁运帮身任财顺、金土水岁运财旺身弱；推翻条件=金水土岁运反顺、木火岁运反逆。

## 判定
- 结果：**命中**
- 出错模块：无
- 偏差说明：主判断命中（身弱财旺、丑为金库财入墓、丑酉半合金、财运受压主题、喜木火忌金水土、空亡无落空）。注：设计意图「用神（财星金）」措辞可商榷——身弱财旺局中财为忌神（耗身），用神应为印比帮身；但墓库检验对象（财入墓→财运受压）成立，不影响判定。
