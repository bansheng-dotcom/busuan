# Case 075 · 后验反例（经历推翻预测）· 后验

- 类别：后验（反例-路线裁决）
- 四柱：乙酉 辛巳 癸丑 丙辰（乾造）
- 设计意图：验证反例裁决——预测路线被经历削弱（与 Case 071 同盘反例）

## Phase A 预注册（先给定）
- 原局：癸水日主巳月（正财当令），身弱财旺——竞争假设：**路线 A 身弱喜金水（印比）vs 路线 B 从财（顺财势）**
- 最优假设：身弱喜金水（有丑库根，倾向不从）
- 预注册主题：①金水岁运顺；②火土岁运（财官）为财累

## 用户经历（后验输入）
- 2024 甲辰年：财运爆发，大赚一笔（甲木伤官生财 + 辰土官星）。

## 预期裁决（先给定）
- 2024 甲辰：甲木伤官生财 + 辰土正官——**财官岁运反大赚** → 与「身弱喜金水忌火土」矛盾 → **路线 A 被削弱**，路线 B（从财喜火土木）获支持
- 关键点：①明确指出哪一假设被削弱（身弱喜金水）；②四态裁决：未命中/部分命中——财旺年顺支持从财路线；③说明原判断哪一环被推翻（从格与否的 C 级判断可重估）；④须诚实：单一年证据，从财路线「倾向增强」而非定论

## 模型输出摘要

### Phase A（预注册，独立于经历）
- 步骤0：癸水日主，月令巳（丙火正财当令）；年干乙=食神、月干辛=偏印、时干丙=正财；地支酉丑巳辰。空亡：癸丑日属癸丑旬，空亡子亥，原局无子亥、无落空。十二长生：癸坐丑为冠带（丑藏癸水中气根）。
- 步骤1：失令（巳月财当令耗身）；得地（日支丑藏癸水本气中气根、辰藏癸水余气根、月支酉）；得势（辛金偏印透坐酉禄根生身）。不利：乙木食神泄、丙火财耗。倾向 **「身弱财旺」**。
- **路线级竞争核查（关键）**：
  - 路线 A 身弱喜金水：Root resistance 判据——日主有根（丑中癸水、辰中癸水）**未损**（无冲克合空死绝）+ 判据2 印星辛金透干有禄根（坐酉）→ 判据1/2 均倾向不从 → 路线 A 成立。
  - 路线 B 从财：须日主无根或根被削弱 + 印比极度微弱——本盘根未损、印透有禄，**从财不成立**（判据1/2 挡下）。
  - 最优假设：**路线 A 身弱，喜金水（印比），忌火土（财官）**；路线 B 作为竞争假设并列，标注成立条件当前不满足。
- 步骤2：月令巳本气丙火正财透时干 → **正财格**。辛金偏印透月干。
- 步骤3：病型「财多身弱」边缘命中；药=金（印生身）、水（比劫帮身）。
- 步骤4：癸水巳月夏，调候辛金生水（夏癸要辛金）——与扶抑同向。
- 步骤5：六维一致 → 路线 A：喜金水、忌火土。
- 步骤6：**巳酉丑三合金局**（印局）；天干**丙辛合**（财印合绊，[C]级合而不化）。
- 步骤10 Phase A 预注册：
  - 最优假设：身弱喜金水（路线 A），倾向不从；路线 B 从财不成立（当前）。
  - 主要用神：辛金偏印、壬癸水比劫。
  - 关键争议：**身弱 vs 从财**（路线级竞争，喜忌方向相反）。
  - 预注册主题：①金水岁运（印比）顺；②火土岁运（财官）为财累（A 视角）/ 顺势顺（B 视角）。
  - 推翻条件：火土财官岁运反大顺（食伤生财、财官成势）→ 路线 A 被削弱、路线 B 获支持。

### Phase B（后验，读取经历后）
- 用户经历：2024 甲辰年，财运爆发，大赚一笔。
- 2024 甲辰解析：甲木伤官（癸水伤官=甲木）透生财 + 辰土正官（癸水正官=戊土，辰藏戊土）。**伤官生财**（甲木生丙火财）、财星有源；辰土官星。
- 四态裁决：
  - 对路线 A「身弱忌火土、火土年为财累」：**未命中**——火土（财官）年反大赚，与预测矛盾，**路线 A 被明确削弱**。
  - 对路线 B「从财喜火土木」：**部分支持**——财旺年顺，从财方向获单一年支持。
- 重估说明（Phase B 允许重估 C 级）：原判据1/2（根未损+印透）挡下从财——本次经历支持从财方向，但**单一年不足以推翻「有根+印透」的结构性判据**；诚实标注：从财路线「倾向增强」而非定论。原判断被推翻的环节：「身弱忌火土」这一喜忌预测；未改动的环节：A/B 级结构事实（四柱、合局）。
- 诚实边界：单一年证据；需更多年份（金水年顺逆、火土年复现）确认路线收敛。
- 铁则执行：不反向篡改 Phase A 已锁定的原局判断。

### 与预期裁决对照
- 预期：路线 A 被削弱、路线 B（从财）获支持；未命中/部分命中。我判对路线 A 未命中、路线 B 部分支持 → **一致**。

## 判定
- 结果：命中
- 出错模块：无
- 偏差说明：Phase A 独立分析确认路线级竞争（身弱 vs 从财）、路线 A 为最优（根+印透挡下从财），与预期一致；Phase B 对 2024 甲辰（伤官生财财官年反大赚）判路线 A 未命中、路线 B 倾向增强、单一年不足定论，与预期一致。
