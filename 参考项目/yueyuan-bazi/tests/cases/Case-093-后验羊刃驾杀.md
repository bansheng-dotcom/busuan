# Case 093 · 后验羊刃驾杀（竞争权威）· 后验

- 类别：后验（羊刃驾杀-应验）
- 四柱：戊午 戊午 丁巳 壬寅（乾造）
- 设计意图：验证羊刃驾杀后验——竞争性岗位权威

## Phase A 预注册（先给定）
- 原局：丁火午月羊刃、壬水七杀透（坐寅长生）制刃——**羊刃驾杀**，喜水（制刃）土（泄刃）忌火木
- 预注册主题：①官杀（水）岁运权威/竞争胜出；②比劫（火）岁运争斗

## 用户经历（后验输入）
- 2021 辛丑年：竞争激烈的岗位竞争中胜出（辛金偏财+丑土食神泄刃）。

## 预期裁决（先给定）
- 2021 辛丑：辛金偏财透 + 丑土食神（泄刃生财）——**泄刃生财 → 竞争胜出** → 与「羊刃驾杀/刃旺有泄」一致 → **部分命中**（竞争权威主题）
- 关键点：①羊刃驾杀主竞争性岗位权威；②丑土食神泄刃为吉

## 模型输出摘要

### Phase A（预注册，独立于经历）
- 步骤0：丁火日主，月令午（午藏丁火本气，为丁之比肩；**午为丁火羊刃**）；年干戊=伤官、月干戊=伤官、时干壬=**正官**（壬水对丁火为正官，丁火七杀为癸水）；地支午午巳寅。空亡：丁巳日属丁巳旬，空亡子丑，原局无子丑、无落空。十二长生：丁在午为临官（羊刃）、在巳为帝旺。
- 步骤1：得令（午月丁火羊刃当令）；得地（午午巳——羊刃临官+帝旺，火极旺；时支寅印长生生火）；得势（戊土伤官双透泄秀、壬水正官透克）。综合倾向 **「身强（火旺极）」**——羊刃成势、印生火。喜水（官杀制刃）、土（食伤泄刃）、金（财耗），忌火（比劫）、木（印）。
- 步骤2：月令午为丁火羊刃 → **羊刃格**（B 类特殊格局）。壬水正官透时干制刃（羊刃用官制——制刃功能与"驾杀"同，但**壬为正官非七杀**，传统"羊刃驾杀"名不适用于此，按"羊刃用官制刃"表述）；戊土伤官双透泄刃。
- 步骤3：病型「刃旺无制」不命中（壬官制刃+戊伤泄刃，非完全无制）。病=刃旺（火极旺）；药=水（官杀制刃）、土（食伤泄刃）。药根气：壬水坐寅病地根弱（制刃力弱）；**戊土坐午得根**（戊土帝旺在午——伤官泄刃有力）。
- 步骤4：丁火午月夏燥，调候需癸水润局；调候方向（水）与扶抑（喜水制刃）同向，但壬水根弱——调候辅助。
- 步骤5：六维一致 → 喜水（官杀）、土（食伤）、金（财），忌火（比劫）、木（印）。
- 步骤6：天干**丁壬合**（日主合正官——[C]级：午月火当令，合而不化、合绊论——官星合身）；地支午午巳火局、寅午半合火（印生火助刃）。空亡无落空。神煞：羊刃（午）、将星（寅午戌见午）。
- 步骤10 Phase A 预注册：
  - 最优假设：身强（火旺极），羊刃格；喜水（官杀制刃）、土（食伤泄刃）、金（财），忌火木。
  - 主要用神：壬水正官（制刃，根弱）、戊土伤官（泄刃，根足）。
  - 关键争议：壬水为正官非七杀（羊刃用官制刃）；壬根弱、丁壬合绊制刃力有限。
  - 预注册主题：①**官杀（水）岁运权威/竞争胜出（制刃）**；②土（食伤）岁运泄刃生财；③比劫（火）岁运争斗、破财。
  - 推翻条件：水岁运反逆或火岁运反顺 → 本路线被削弱。

### Phase B（后验，读取经历后）
- 用户经历：2021 辛丑年，竞争激烈的岗位竞争中胜出。
- 2021 辛丑解析：**辛金偏财透（喜——财耗身，辛坐丑养地有根）** + **丑土食神（丁火食神=己土，丑藏己土——泄刃生财）**。
- 四态裁决：**部分命中**——①「竞争胜出（权威/竞争主题）」与羊刃格（竞争性岗位、以制刃/泄刃为用）预测方向一致；②机制：主路径为**丑土食神泄刃生财**（身强泄秀生财——竞争胜出得利）+辛金财星透（耗身）——泄刃+财耗为吉；壬水官星制刃路径未直接引动；③单一年、机制细节与预注册主路径（官杀制刃）略不同（实为泄刃路径），判部分命中。
- 铁则执行：不反向篡改 Phase A。

### 与预期裁决对照
- 预期：部分命中（竞争权威主题）。我判部分命中 → **裁决一致**；十神概念与机制细节有偏差（见下）。

## 判定
- 结果：部分命中（裁决一致，十神概念标注偏差）
- 出错模块：十神标注（壬水官/杀归属）
- 偏差说明：①裁决「部分命中」与预期一致（竞争胜出与羊刃格预测方向一致）；②**十神概念修正**：壬水对丁火为**正官**（丁火七杀为癸水），预期标"壬水七杀"有误——故按「羊刃用官制刃」表述而非传统「羊刃驾杀」；③机制细节：2021 主路径为丑土食神泄刃生财，非官星制刃——不改变主题命中，标注参数级差异。
