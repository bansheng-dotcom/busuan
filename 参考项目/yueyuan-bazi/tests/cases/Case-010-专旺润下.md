# Case 010 · 润下格（水专旺）· 极端结构

- 类别：极端结构（专旺-润下）
- 四柱：壬子 癸亥 壬子 癸亥（乾造）
- 设计意图：验证专旺格（润下）判定、亥子重水+子子自刑

## 预期结论（先给定）
- 格局：**润下格（水专旺）成立**——亥月水当令、亥子水局成势、壬癸比劫透
- 旺衰：极旺
- 喜忌：喜金水（印比顺旺势），忌土（官杀最忌）、火（财次之）、木（食伤有争议）
- 关键点：子子自刑应并入力量评估；此盘为冬月寒极——但专旺成立则 CLIMATE OVERRIDE 例外③「专旺以顺势为主」生效
- 空亡：壬子日柱，壬子旬空寅卯——无落空

- 旺衰：极旺（得令+得地+得势三全）
