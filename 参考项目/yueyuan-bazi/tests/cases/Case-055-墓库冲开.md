# Case 055 · 墓库冲开（辰戌冲发财？）· 岁运

## 预期结论（先给定）
- 原局：丙火日主戌月（食神当令），辰戌冲（原局年时与月冲？癸未/丙辰——未辰……需查：年未-日辰，未辰非冲；月戌-日辰，辰戌冲 ✓）——**辰戌冲（月日）**
- 大运戊辰：与原局辰戌冲（再冲）——墓库重冲
- 流年庚辰：与原局辰伏吟 + 辰戌冲
- 关键点：①**墓库 P0 修正**：先查库中所藏十神、库之喜忌、透藏关系——辰藏戊乙癸（癸水正官藏）、戌藏戊辛丁（辛金正财藏）；②冲开=库开释放 vs 破库折根 vs 入墓受制——丙火日主坐辰（冠带）有根，非以辰为唯一根 → 库开倾向；③财星（辛金藏戌）被冲开——财库开？须按藏神喜忌断吉凶，**禁止直接断「逢冲=发财」**
- 喜忌：身中和食神旺，喜木（印）、火（比劫），忌土金（食伤财）、水（官杀）
- 空亡：丙辰日柱，丙辰旬空子丑——无落空

## 模型输出摘要
- 核心总评：丙火戌月（戊土食神当令），**月戌-日辰辰戌冲——墓库引动**；癸壬官杀两透克身、戊土食神透泄身，丙坐辰（冠带）微根、未中丁火帮身——身中和偏弱、食神格；大运戊辰（与原局辰戌再冲）、流年庚辰（与辰伏吟+辰戌冲）——**墓库重冲**。不确定度：中。
- 定盘（S1/A）：乾造，日主丙火，月令戌（戊土食神当令），藏干未（己丁乙）戌（戊辛丁）辰（戊乙癸）子（癸）；**丙辰旬空子丑——时支子落空亡**（预期误作「无落空」）。
- 旺衰：中和偏弱（[CORE] 戌月土当令泄火 + 戊土食神透泄身 + 癸壬官杀两透克身；丙坐辰冠带微根 + 未中丁火印帮身）。
- 格局：月令戌本气戊土食神当令、戊透时干 → **食神格**。
- 墓库（P0 修正）：**辰戌冲为墓库引动——先查库性**：辰藏戊乙癸（癸水正官）、戌藏戊辛丁（辛金正财、丁火劫财）。**丙火日主坐辰（冠带）有根、非以辰为唯一根 → 属「库开释放」倾向**（非破库折根）。**戌为丙火之墓库（火库）**——冲开则戌中丁火（劫财帮身）显、辛金（正财）显、辰中癸水（正官）显，吉凶交织。**禁止直接断「逢冲=发财」**（[HEURISTIC] 墓库 P0）；身弱食神格财为忌，财库开反主财动波折/为财所累。
- 病药：身弱食神旺为病（食神泄身）+ 官杀透克；药=印（木）制食神化官杀生身（未中乙木藏）、火比劫帮身。
- 调候：戌月秋燥，水官杀兼调候（润燥），但未至极燥不触发 CLIMATE OVERRIDE。
- 六维：扶抑（身弱需印比——木火）、格局（食神格顺用）、调候（戌月需水，与忌水相抵——官杀为忌故不取水为用，参数级）、病药（印比帮身为药）、变格（NORMAL）。一致指向 **喜木（印）、火（比劫），忌土金（食伤财）、水（官杀）**。
- 岁运：喜木火岁运，忌土金水岁运；辰戌冲逢岁运再引动——墓库开合主题；庚辰流年财星透——财主题引动但身弱难任。
- Phase A：最优假设=食神格身弱、辰戌冲墓库重冲库开、喜木火忌土金水；关键争议=库开吉凶（丁火劫财 vs 辛金财 vs 癸水官）、子空亡；未来高概率主题=木火岁运帮身顺、土金水岁运泄耗攻身；推翻条件=土金水岁运反顺、木火岁运反逆。
