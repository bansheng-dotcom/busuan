# Case 077 · 后验财库（财库逢冲）· 后验

- 类别：后验（财运-财库）
- 四柱：癸未 己未 庚戌 丁丑（乾造）
- 设计意图：验证财库逢冲的后验——先查库性再断吉凶

## Phase A 预注册（先给定）
- 原局：庚金日主未月（正印当令），未戌丑三库（土印）——身强（印旺+库土），丁火正官透（时干）
- 最优假设：身强印旺，喜火（官杀）木（财）水（食伤），忌土金（印比）
- 预注册主题：①丑未冲/戌未刑——库被引动的吉凶看库中藏神（丑藏辛金劫财、未藏丁火官星）；②火木岁运（官财）顺

## 用户经历（后验输入）
- 2021 辛丑年：破财较大。

## 预期裁决（先给定）
- 2021 辛丑：辛金劫财透 + 丑（与未冲，库中辛金劫财引动）——**劫财透+库冲引动劫财** → 破财与「比劫夺财/劫财引动」一致 → **命中**（财库逢冲须查库性——库中藏劫财，冲则劫财显凶，非「逢冲=发财」）
- 关键点：①墓库 P0：先查库中十神（丑藏辛金=劫财），冲开=劫财显现 → 凶；②印证「禁止直接断逢冲发财」

## 模型输出摘要

### Phase A（预注册，独立于经历）
- 步骤0：庚金日主，月令未（未藏己土本气，为庚之正印）；年干癸=伤官、月干己=正印、时干丁=正官；地支未戌丑。空亡：庚戌日属庚戌旬，空亡寅卯，原局无寅卯、无落空。十二长生：庚在戌为衰地（戌藏戊土印）。
- 步骤1：得令（未月己土正印当令生金）；得地（未戌丑三土库印星——未藏己土、戌藏戊土、丑藏己土，印星成势）；得势（己土正印透、丁火正官透、癸水伤官透）。综合倾向 **「身强印旺」**——土印成势，近「土多金埋（母多灭子）」形态。喜火（官杀制身）、木（财破印）、水（食伤泄秀），忌土金（印比）。
- 步骤2：月令未本气己土正印透月干 → **正印格**。丁火正官透时干、癸水伤官透年干。
- 步骤3：病型检查——**「母多灭子（土多埋金）」命中**（金日主土印过旺）；**「伤官见官」命中**（癸水伤官+丁火正官并见，癸坐未无根克力弱但结构存在）。从重者论：病=印旺身强（土多金埋）为根基之病；药=木（财破印）、水（食伤泄秀）。药根气：木原局无；癸水坐未（未藏乙丁己无癸水）**无根虚浮**（伤官见官之伤官无力）。
- 步骤4：庚金未月夏末土燥，调候需壬癸水润；但调候神癸水坐未无根 → 例外⑤部分成立，调候降级辅助；身强印旺，扶抑为主。
- 步骤5：六维一致 → 喜火（官杀）、木（财）、水（食伤），忌土金（印比）。
- 步骤6：天干癸水伤官克丁火正官（伤官见官）；地支**丑戌未三刑齐备**（月支未-日支戌-时支丑：未戌刑+丑戌刑+**丑未冲**——三刑全彰）、**丑未冲**（时支丑-月支未）。空亡无落空。神煞：天乙贵人（庚日贵人在丑未，未、丑皆为贵人）。
- 步骤10 Phase A 预注册：
  - 最优假设：身强印旺（土多金埋边缘），喜火木水（官财食伤），忌土金（印比）。
  - 主要用神：木财（破印）、水食伤（泄秀）。
  - 关键争议：三库（丑戌未）逢冲刑——库被引动的吉凶须先查库性。
  - 预注册主题：①丑未冲/丑戌未三刑——库被引动，**先查库中藏神**：丑藏辛金劫财、未藏丁火官星、戌藏戊土印星——冲刑引动以库中藏神论（劫财引动→破财/竞争，官星引动→事业，印星引动→印为忌）；②火木岁运（官财）顺——制身破印；③土金岁运（印比）压力/破财。
  - 推翻条件：木火岁运反逆或土金岁运反顺 → 本路线被削弱。

### Phase B（后验，读取经历后）
- 用户经历：2021 辛丑年，破财较大。
- 2021 辛丑解析：**辛金劫财透（忌神——比劫夺财）** + 丑土正印（忌）；**丑未冲**（流年丑冲月支未——冲库）；丑戌未三刑引动（流年丑+原局未戌）。
- 库性先查（P0 修正）：丑库藏辛金劫财、癸水伤官、己土印——**库中劫财（辛金）透干** + 丑未冲开库 → **劫财显现** → 破财（比劫夺财主题）。印证「墓库逢冲须先查库性，禁止直接断逢冲=发财/升职」。
- 四态裁决：**命中**——破财与「劫财透+库冲引动库中劫财（比劫夺财）」预测一致。
- 铁则执行：不反向篡改 Phase A。

### 与预期裁决对照
- 预期：命中（劫财透+库冲引动劫财→破财与比劫夺财一致）。我判命中 → **一致**。

## 判定
- 结果：命中
- 出错模块：无
- 偏差说明：Phase A 独立分析（身强印旺、丑戌未三刑齐、库中藏神劫财/官星/印星）与预期一致；Phase B 对 2021 辛丑（辛金劫财透+丑未冲开库引动库中劫财→破财）判命中，与预期完全一致。补充细节（三刑齐备、伤官见官病型、天乙贵人）不改变裁决。
