# Case 020 · 三会局（寅卯辰木会局）· 极端结构

- 类别：极端结构（多合-三会成势）
- 四柱：庚辰 己卯 甲寅 丙寅（乾造）
- 设计意图：验证三会局（寅卯辰会木）判定、会局与月令的关系

## 预期结论（先给定）
- 三会：寅卯辰三会木局——卯月木当令 ✓ → **木会局成势**
- 旺衰：日主甲木——寅卯辰会木局生扶、甲坐寅禄根——**身强（会局+得令+禄根）**
- 关键点：①三会局成势后甲木极旺，专旺嫌疑？——庚金七杀透干有根（辰中无庚……庚在辰为养地，辰藏戊乙癸无庚——庚金虚浮无根）→ 官杀无根，专旺（曲直）嫌疑增大！②丙火食神透两（寅中丙火本气根）——曲直见火「泄秀 vs 泄气」争议；③己土正财透（卯月土死绝）
- 争议：曲直格 vs 普通身旺——庚金七杀透（虽无根）是否破坏专旺纯度？
- 喜忌（若曲直）：喜水木，忌金土，火有争议；（若身旺）：喜火土金泄耗
- 空亡：甲寅日柱，甲寅旬空子丑——无落空

## 模型输出摘要
- 核心总评：寅卯辰三会木局，卯月木当令会局成势，甲木坐寅禄根、得令得地，**木极旺**；庚金七杀透干但**无根**（庚坐辰，辰藏戊乙癸无庚）→ 不构成专旺破格项，**曲直格（木专旺）倾向成立**，喜水木忌金土，火有争议。不确定度中高（路线级竞争：曲直 vs 普通身旺）。
- 定盘：甲木日主，卯月，寅藏甲丙戊、卯藏乙、辰藏戊乙癸；空亡子丑无落空（甲寅旬空子丑）
- 三会局判定：寅卯辰三会木局，卯月木当令 ✓ → 会局成势，木气一方独旺（[CORE] 三会力量较强，辰在会局中归木）
- 旺衰：身强（得令+三会木局+坐寅禄根+辰中乙木余气）——木势极旺近专旺
- 专旺纯度核查（biange.md）：①官杀（庚金）透干但**无根**（辰中无庚）→ 官杀无力，「专旺破格须官杀有根有力」不满足 ✓；②异类有根：寅中丙火（食神，本气根）、辰中戊土（财）——**三会局成化下辰土归木、寅中丙火为食神之根** → 丙火食神有根是纯度争议项
- 关键争议（庚金七杀透是否破纯）：按 biange.md 专旺破格「天干官杀透出而地支有根」——庚金**地支无根**，不构成破格；但丙火食神有根+己土财透为「杂气」——[SCHOOL] 曲直见火「泄秀为佳 vs 泄气破格」两说
- 路线级竞争：曲直格（木极旺+官杀无根）vs 普通身旺（食伤财透出有杂）——按 biange.md 裁决顺序，官杀无根是专旺最大破格项不成立，倾向曲直成立；预测差异=金运（官杀得根）反逆则支持曲直、火土运顺反逆可辨
- 喜忌（若曲直）：喜水（印）、木（比劫顺旺势），忌金（官杀）、土（财），火（食伤——泄秀/泄气两说，按「是否伤及旺势纯度」评估）
- 调候：卯月气候温和，非急；专旺（ZHUANWANG）顺势为主
- 六维：ZHUANWANG 曲直喜印比、忌财官（金土），食伤（火）为争议项
- 岁运：喜水木运，忌金运（官杀最险）、土运（财耗）；火运按两说
- Phase A：最优假设=曲直格喜水木忌金土（火争议）；推翻条件=金土岁运反顺、水木岁运反逆；判别关键=庚金岁运得根是否反格

## 判定
- 结果：**命中**
- 出错模块：无
- 偏差说明：无。三会木局成势、身强近专旺、庚金七杀透干无根→不破专旺（曲直格倾向成立）、丙火食神有根为泄秀/泄气争议项——全部与预期一致；已按路线级竞争模板标注曲直 vs 普通身旺及判别条件。
