# Case 028 · 比劫夺财（经典病型）· 普通复杂

- 类别：普通复杂（病药-比劫夺财）
- 四柱：丙申 丙申 丁酉 甲辰（乾造）
- 设计意图：验证比劫夺财病型——比劫（丙丁火）旺、财星（金）不透

## 预期结论（先给定）
- 病型：丁火日主申月（正财当令），天干丙丙火比劫透两、甲木正印透，地支申申酉金财星成势但**不透**——比劫（丙火）旺 + 财星不透 → **比劫夺财命中**（比肩分财/劫财夺财）
- 旺衰：申月财当令，丁火坐酉（病地）无根、丙火比劫坐申（病地）——身弱财旺，比劫帮身任财？还是比劫夺财？
- 争议：身弱财旺喜比劫帮身任财 vs 比劫夺财——身弱任财 vs 比劫夺财的界限（关键测试点：身弱时比劫是帮身任财还是夺财）
- 喜忌：倾向喜木火（印比帮身），忌金（财）、水（官杀）
- 空亡：丁酉日柱，丁酉旬空辰巳——时支辰落空亡

## 模型输出摘要
- 核心总评：丁火申月正财当令，申申酉三金财星成势但不透，丁火坐酉（虚长生）无本气根、丙丙劫财透但坐申病地**无根不旺**、甲木正印微根 → **身弱财旺**；此盘比劫帮身任财为「药」，**比劫夺财病型不命中**（比劫无根不旺），更贴切「财多身弱」，喜木火忌金水。不确定度中。
- 定盘：丁火日主，申月，申藏庚壬戊、酉藏辛、辰藏戊乙癸；空亡辰巳——时支辰落空亡
- 病型核对（patterns.md 二节）：比劫夺财须「比劫旺+财星弱/不透，或财星虽透但比劫势众」——此盘丙丙比劫虽透但**坐申病地无根**（不得令不得地）、财星申申酉金**当令成势**（非弱）→ **不命中比劫夺财** ✓
- 旺衰：身弱财旺——申月正财当令耗身、三金成势，丁火无本气根（午未戌全无，酉为虚长生）、帮扶仅丙丙虚透+甲木印微根（辰中乙木）
- 病机重判：**财多身弱**（财星当令成势+日主弱）——财旺身弱担不起财；比劫（丙火）帮身任财是**药非病**（身弱任财方向，非夺财）
- 关键争议（身弱任财 vs 比劫夺财界限）：裁决依据=比劫是否有力——丙丙劫财坐申病地无根，比劫虚浮无力，无法「夺」财，反为帮身之药 → 倾向财多身弱（比劫任财）
- 喜忌：身弱财旺 → 喜木（印生身）、火（比劫帮身任财），忌金（财——财旺身弱担不起）、水（官杀克身）
- 调候：申月秋燥不极端，普通状态，身弱以扶抑为主
- 六维：一致指向喜木火、忌金水；病型维度：不命中比劫夺财
- 岁运：喜木火运（印比帮身任财），忌金水运（财官旺身愈弱）；时支辰落空亡——辰中乙木印落空，印星助力打折，[HEURISTIC] 用神落空减力提示
- Phase A：最优假设=身弱财旺（财多身弱）喜木火忌金水；推翻条件=金水岁运反顺、木火岁运反逆

## 判定
- 结果：**部分命中**
- 出错模块：病药定位（步骤 3）——病型命名分歧
- 偏差说明：喜忌方向一致（喜木火印比、忌金水）✓；但病型命名分歧：预期「比劫夺财命中」，本分析判 **不命中比劫夺财**——丙丙比劫坐申病地无根不旺，不构成「比劫旺夺财」，身弱财旺下比劫是帮身任财之药；本盘更贴切「财多身弱」。预期已自标「身弱任财 vs 比劫夺财界限」为争议点，此处按力量判据（比劫无根）取「财多身弱/比劫任财」。
