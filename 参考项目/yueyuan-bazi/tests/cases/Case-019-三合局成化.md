# Case 019 · 三合局成化（申子辰水局）· 极端结构

- 类别：极端结构（多合-三合成化）
- 四柱：丙子 庚子 甲申 壬辰（乾造）
- 设计意图：验证三合局（申子辰合水）成化判定、水局对旺衰的影响

## 预期结论（先给定）
- 三合：申子辰三合水局——子月水当令，申子辰全 → **水局成化**（[C] 级判断，须月令化神当权——子月水当令 ✓）
- 旺衰：日主甲木——申子辰水局生木，甲木得水生，但甲在申（绝地）无根、辰中乙木余气根——身弱而印旺（水多木漂倾向）
- 关键点：①三合水局成化后旺衰重算（水极旺生木）；②甲木被水局生但自身无强根——「水多木漂」风险（印多为病/母多灭子之木漂）；③丙火食神透（子月火绝）虚浮
- 喜忌：身弱印旺（水多木漂），喜火（食伤泄水+暖局）、土（财制水），忌水（印）、金（官杀生水）
- 空亡：甲申日柱，甲申旬空午未——无落空

## 模型输出摘要
- 核心总评：申子辰三合水局，子月水当令化神当权 → **水局成化**（[C]级），水极旺生身；甲木日主坐申（绝地）无本气根、仅辰中乙木余气根 → **身弱印旺（水多木漂）**，喜火土忌水金。不确定度中。
- 定盘：甲木日主，子月，子藏癸、申藏庚壬戊、辰藏戊乙癸；空亡午未无落空（甲申旬空午未）
- 三合成化判定（[C]级）：申子辰三合水局，子月水当令化神当权 ✓ → 水局成化，旺衰重算——印星（水）极旺
- 旺衰：日主甲木——得令？子月水当令（印）生身；但甲坐申（绝地）、辰中乙木余气根（弱）→ 印旺身弱
- 病机核对：**印多为病/母多灭子（水多木漂）**——水（印）过旺生木而木无强根，水多木漂、漂泊无根（patterns.md 五行特定），病在印旺
- 关键点：丙火食神透年干——子月丙火**绝地虚浮无根**；冬月调候本需丙火暖局（冬木要火暖），但丙火虚浮 → 调候神无根（例外⑤方向），不过丙火作为「食伤泄水」的扶抑用神地位仍存
- 喜忌：身弱印旺（水多木漂），喜火（食伤泄水+暖局）、土（财制水），忌水（印）、金（官杀生水助印）
- 调候：子月寒极触发 CLIMATE OVERRIDE，但调候神丙火虚浮无根、且身弱扶抑为先 → 调候降级为辅助，扶抑（泄水制水）为主
- 六维：一致指向喜火土、忌水金（扶抑/病药/调候同向）
- 岁运：喜火土运，忌金运（官杀生水）、水运（印旺木漂更甚）；火运兼暖局与泄水双功
- Phase A：最优假设=身弱印旺（水多木漂）喜火土忌水金；推翻条件=水金岁运反顺、火土岁运反逆
