# Case 085 · 后验病药（药神岁运应吉）· 后验

- 类别：后验（病药-应验）
- 四柱：丙午 甲午 庚午 丁丑（乾造）
- 设计意图：验证病药论后验——药神（印土）岁运应吉

## Phase A 预注册（先给定）
- 原局：庚金午月官杀旺身弱（同 Case 039/073），病=官杀无制，药=印（土）化杀生身
- 预注册主题：①土金岁运（印比）化杀帮身应吉；②火木岁运（官杀财）压力

## 用户经历（后验输入）
- 2024 甲辰年：得贵人帮助，事业转顺（甲木财透？辰土印库——土印为药）。

## 预期裁决（先给定）
- 2024 甲辰：辰土（正印）化杀生身——**药神岁运** → 转顺与「药=印」一致 → **部分命中**（药神应验主题；甲木财透增加复杂）
- 关键点：①病药论：药神岁运应吉；②辰土印星为药 → 支持「喜土印」

## 模型输出摘要

### Phase A（预注册，独立于经历）
- 步骤0：庚金日主，月令午（午藏丁火本气，为庚之正官）；年干丙=七杀、月干甲=偏财、时干丁=正官；地支午午午丑。空亡：庚午日属庚午旬，空亡戌亥，原局无戌亥、无落空。十二长生：庚在午为沐浴（败地）。
- 步骤1：失令（午月丁火正官当令克金）；得地（日支丑藏辛金中气根+己土正印、三午沐浴无根）；得势（丙丁官杀双透、甲木偏财透）。倾向 **「身弱杀旺（官杀攻身）」**——赖丑中辛金微根+己土印贴身。
- 步骤2：月令午本气丁火正官透时干 → **正官格**；丙火七杀透年干 → **官杀混杂**。
- 步骤3：病型「官杀混杂」「杀旺印弱」命中（七杀旺、印星藏而弱）。**病=官杀无制（杀旺）**；**药=印（土）化杀生身**（丑中己土正印贴身，且得午火生——杀印相生链条，药有源）、金（比劫帮身）。药根气：丑中己土印贴身得生（有力但藏而不透）。
- 步骤4：庚金午月夏燥，调候需壬水润；但调候神水原局无（癸水仅藏丑中）→ 调候降级；身弱杀旺，扶抑（印比）为急。
- 步骤5：六维一致 → 喜土（印化杀）、金（比劫），忌火（官杀）、木（财生杀）。
- 步骤6：天干丙丁官杀透、甲财透；地支三午（午午自刑主题）、丑（己印辛金癸水）。空亡无落空。
- 步骤10 Phase A 预注册：
  - 最优假设：身弱杀旺，**病=官杀无制，药=印（土）化杀生身**；喜土金，忌火木。
  - 主要用神：丑中己土正印（化杀生身）。
  - 关键争议：印星藏而不透、化杀之力有限；杀印相生链条（午生丑、丑生庚）为关键机制。
  - 预注册主题：①**土金岁运（印比）化杀帮身应吉**；②火木岁运（官杀财）压力。
  - 推翻条件：火木岁运反顺 → 药神（印）路线受挑战（官杀非纯忌、或印化杀为贵）。

### Phase B（后验，读取经历后）
- 用户经历：2024 甲辰年，得贵人帮助，事业转顺。
- 2024 甲辰解析：**辰土正印（药——化杀生身；辰为湿土印星、庚金印库）** + **甲木偏财透（忌——财生杀，甲坐辰有乙木中气根）**。辰土引动丑中己土印星（土库相连）——药神化杀生身。
- 四态裁决：**部分命中**——①「药神（土印）岁运应吉」主题命中：辰土印星化杀生身 → 贵人帮助、事业转顺，与「药=印」预测一致；②甲木财透（忌）生杀增加复杂——非纯粹吉运，贵人帮助与财生杀之压力并存；③「事业转顺」方向与药神应验相符，细节（顺的程度）待更多信息。
- 阶段性收敛：此经历支持「喜土印（药神）」方向；「忌火木」仍需反向印证（火木年顺逆）。
- 铁则执行：不反向篡改 Phase A。

### 与预期裁决对照
- 预期：部分命中（药神应验主题；甲木财透增加复杂）。我判部分命中 → **一致**。

## 判定
- 结果：命中
- 出错模块：无
- 偏差说明：Phase A 独立分析（病=官杀无制、药=印化杀、喜土金忌火木）与预期一致；Phase B 对 2024 甲辰（辰土印星药神化杀生身+甲财透复杂化）判部分命中，与预期完全一致。
