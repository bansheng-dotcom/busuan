# Case 097 · 后验建禄（身强用财官）· 后验

- 类别：后验（建禄-应验）
- 四柱：庚子 己丑 庚申 乙酉（乾造）
- 设计意图：验证建禄格后验——身强用财官

## Phase A 预注册（先给定）
- 原局：庚金日主丑月（正印当令），坐申禄根、乙木正财透——**建禄日**身强，喜火（官杀）木（财）水（食伤）
- 预注册主题：①财官（木火）岁运顺；②印比（土金）岁运竞争/阻滞

## 用户经历（后验输入）
- 2024 甲辰年：财运提升，收入增加（甲木偏财+辰土印星——财透印藏）。

## 预期裁决（先给定）
- 2024 甲辰：甲木偏财透（财星用神）——**身强用财 → 财运提升** → 与「喜财」一致 → **部分命中**（财运主题支持）
- 关键点：①建禄身强喜财官食伤；②甲木财星透干为用

## 模型输出摘要

### Phase A（预注册，独立于经历）
- 步骤0：庚金日主，月令丑（丑藏己土本气，为庚之正印）；年干庚=比肩、月干己=正印、时干乙=正财；地支子丑申酉。空亡：庚申日属庚申旬，空亡子丑 → **年支子、月支丑均落空亡**（正印月令落空，仅作修正项）。十二长生：庚在申为临官（**禄根**）。
- 步骤1：得令（丑月己土正印当令生金）；得地（日支申临官禄根、申酉会金局、时支酉）；得势（庚金比肩透、己土正印透）。综合倾向 **「身强」**——金土成势，庚坐申禄根（建禄日）。喜火（官杀制身）、木（财耗）、水（食伤泄），忌土金（印比）。
- 步骤2：月令丑本气己土正印透月干 → **正印格**；庚金比肩透年干、乙木正财透时干（乙坐酉绝地，财根弱）。
- 步骤3：病型「印多为病」边缘命中（印旺身强，印为忌）。药=火（官杀）、木（财破印）、水（食伤泄秀）。药根气：乙木坐酉（绝地）根弱；火原局无。
- 步骤4：庚金丑月冬寒，调候丁火炼金；但调候神火全无 → 例外⑤调候降级；身强印旺扶抑为主。
- 步骤5：六维一致 → 喜火（官杀）、木（财）、水（食伤），忌土金（印比）。
- 步骤6：天干**庚乙合**（比肩合财——[C]级合绊，财被合分之象）；地支**子丑合**（[C]级：丑月土当令合化土倾向）、**申酉会金局**（日支申-时支酉）。空亡：年支子、月支丑落空。神煞：羊刃（酉为庚之羊刃）。
- 步骤10 Phase A 预注册：
  - 最优假设：身强（正印格印旺、庚坐申禄根建禄日），喜火木水（官财食伤），忌土金（印比）。
  - 主要用神：木财、火官杀。
  - 关键争议：财星根弱（乙坐酉绝）；子丑落空；庚乙合财被绊。
  - 预注册主题：①**财官（木火）岁运顺——财运/事业提升**；②印比（土金）岁运竞争、阻滞。
  - 推翻条件：木火岁运反逆或土金岁运反顺 → 本路线被削弱。

### Phase B（后验，读取经历后）
- 用户经历：2024 甲辰年，财运提升，收入增加。
- 2024 甲辰解析：**甲木偏财透（喜——财星用神，甲坐辰藏乙木中气根有根）** + 辰土偏印（忌——印星）；**辰酉合**（流年辰合日支酉——辰酉合金）；申辰半合水（日支申-流年辰——食伤局）。
- 四态裁决：**部分命中**——①「财星（木）岁运顺」预测方向一致：甲木偏财透干（用神）→财运提升、收入增加应验 ✓；②辰土印星（忌）为混杂因素（财透印藏）；③单一年、财运主题支持，判部分命中。
- 铁则执行：不反向篡改 Phase A。

### 与预期裁决对照
- 预期：部分命中（财运主题支持）。我判部分命中 → **一致**。

## 判定
- 结果：命中
- 出错模块：无
- 偏差说明：Phase A 独立分析（身强正印格、庚坐申禄建禄日、喜火木水忌土金）与预期一致；Phase B 对 2024 甲辰（甲财透用神→财运提升）判部分命中，与预期完全一致。补充细节（庚乙合财、子丑落空、辰酉合）不改变裁决。
