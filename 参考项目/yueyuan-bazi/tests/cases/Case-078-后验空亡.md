# Case 078 · 后验空亡（用神落空应期）· 后验

- 类别：后验（空亡-用神落空）
- 四柱：甲戌 甲戌 丙寅 戊子（乾造）
- 设计意图：验证空亡后验——用神落空逢填实的应验

## Phase A 预注册（先给定）
- 原局：丙火日主戌月（食神当令），甲木偏印透两（年/月干），丙坐寅（长生）得印根——身中和，戌戌食神落空亡（丙寅旬空戌亥）
- 最优假设：身中和食神旺，喜木（印制食神）火（比劫），忌土金（食伤财）水（官杀）
- 预注册主题：①食神（戌土）落空——才华/表达/子嗣主题虚而不实；②填实之年应期

## 模型输出摘要

### Phase A（预注册，独立于经历）
- 步骤0：丙火日主，月令戌（戌藏戊土本气，为丙之食神）；年干甲=偏印、月干甲=偏印、时干戊=食神；地支戌戌寅子。空亡：丙寅日属丙寅旬，空亡戌亥 → **年支戌、月支戌均落空亡**（食神落空）。十二长生：丙在寅为长生（丙坐寅长生根）。
- 步骤1：失令（戌月戊土食神当令泄火）；得地（日支寅长生根藏甲木印+丙火比肩；戌为丙火墓库、年支月支戌）；得势（甲木偏印双透生身、戊土食神透泄）。综合倾向 **「中和」**——食神旺泄气，赖寅木长生根+双甲印生身。喜木（印制食护身）、火（比劫），忌土（食伤）、金（财）、水（官杀）。
- 步骤2：月令戌本气戊土食神透时干 → **食神格**。甲木偏印双透——食神格配印（印为用制食护身）。
- 步骤3：病型检查——「枭神夺食」边缘（甲木偏印克戊土食神；但定义要求"日主身旺印为忌时尤验"，此处身中和、印为用，不判典型病型，仅标注印克食之表达受制主题）。从重者论：病=食神旺泄身（戌月当令+戊透+戌戌）；药=木（印制食生身）、火（比劫帮身）。药根气：甲木坐戌养地（根弱）、寅木长生根（日支有力）。
- 步骤4：丙火戌月秋末，气候温和，非极端 → 普通状态，调候辅助。
- 步骤5：六维一致 → 喜木（印）、火（比劫），忌土（食伤）、金（财）、水（官杀）。
- 步骤6：地支**寅戌半合火**（日支寅-年支戌、日支寅-月支戌）；天干双甲印、戊食，无五合。空亡：**年支戌、月支戌落空**——食神落空，才华/表达/创作主题虚而不实（[SUPPLEMENTAL] 中等力度修正项）。神煞：华盖（寅午戌见戌，日支寅查 → 华盖在戌，落空）。
- 步骤10 Phase A 预注册：
  - 最优假设：身中和食神旺，喜木火（印比），忌土金水（食伤财官）。
  - 主要用神：甲木偏印（制食生身）、火比劫。
  - 关键争议：印克食之枭神夺食象与印为用的张力（表达受制 vs 制食护身）。
  - 预注册主题：①**食神（戌）落空**——才华/表达/创作/子嗣主题虚而不实，逢**填实（戌年值临）或冲空（辰年冲戌）之年为应期**；②木火岁运（印比）帮身制食。
  - 推翻条件：填实之年反逆或木火岁运反逆 → 本路线被削弱。
