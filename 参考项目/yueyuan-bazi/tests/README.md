# yueyuan 测试框架（v1.6 测试阶段）

> 测试目标**不是**「这个盘准不准」，而是「**哪个模块最容易出错**」——用 Case 001–100 定位易错模块后定向修正。

## 一、测试口径

- 统计维度：格局 / 旺衰 / 调候 / 应期 / 盲派 / 后验，各自记录错误率。
- 判定标准：每个案例设「预期结论」（由案例设计时给定，基于设计意图），模型输出与之比对 → 命中 / 部分命中 / 未命中。
- 部分命中定义：喜忌方向正确但细节（如从格细分类型、应期具体年份）有偏差。

## 二、案例分类（总量 100）

| 分类 | 数量 | 覆盖内容 |
|---|---|---|
| 极端结构 | 20 | 从势 / 专旺 / 化气 / 极端寒暖 / 强冲 / 多合 / 多库 |
| 普通复杂 | 30 | 身弱/身强边界 / 多神透出 / 格局成败 / 病药冲突 / 调候冲突 |
| 岁运 | 20 | 伏吟 / 反吟 / 天克地冲 / 岁运并临 / 墓库 / 空亡 |
| 后验 | 30 | 命中 / 部分命中 / 未命中 / 未知 / 反例 |

## 三、案例文件模板

每个案例一个 md，位于 `tests/cases/`，命名 `Case-NNN-分类.md`。

```markdown
# Case 001 · 曲直格（专旺）· 极端结构

- 类别：极端结构（专旺）
- 四柱：甲寅 甲寅 甲寅 甲子（乾造）
- 设计意图：验证专旺格（曲直）判定是否成立、喜忌是否取对

## 预期结论
- 格局：曲直格（木专旺）成立
- 旺衰：极旺
- 喜忌：喜水木，忌金土（火有争议）
- 调候：不适用

## 模型输出摘要
（记录实际输出）

## 判定
- 结果：命中 / 部分命中 / 未命中
- 出错模块：格局 / 旺衰 / 调候 / 应期 / 盲派 / 后验
- 偏差说明：
```

## 四、结果汇总

每个案例判定后，在 `tests/results/` 追加一行记录；每完成 20 个案例做一次错误率汇总。

记录格式（results/SUMMARY.md）：

| Case | 分类 | 结果 | 出错模块 | 备注 |
|---|---|---|---|---|
| 001 | 极端结构 | 命中 | — | |

## 五、测试纪律

1. 案例使用**虚构或脱敏命盘**，禁止用本人/亲友真实命盘（与项目脱敏红线一致）。
2. 每个案例的「预期结论」在**跑之前**给定，不后补——防确认偏误。
3. 判定时若模型输出与预期不符，先核查预期是否合理，再定「未命中」，不轻易改预期。
4. 统计口径始终是「哪个模块最容易出错」，不是「盘准不准」。
