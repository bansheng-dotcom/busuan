## 测试结论

### 1. 总成绩（100 案例，多 Agent 并行执行）
- **命中 85 / 部分命中 14 / 未命中 1**（命中率 85%，含部分命中 99%）
- 未命中的唯一案例：Case 022（身强边界）——经复核为**设计意图与盘面不符**：预期「身强喜金水」，agent 分析出「天干庚辛乙全为泄耗克、地支卯卯寅官杀成势、帮扶仅辰中一微根 → 身弱更合理」，且指出预期内部自相矛盾。这是**测试暴露的设计缺陷**（测试的有效产出），非系统判断错误。喜忌随旺衰反转（喜火土）。

### 2. 核心机制稳定性验证
| 机制 | 验证结果 |
|---|---|
| 变格四态状态机（专旺/从财/从势/化气/破格） | ✅ 20 个极端结构案例 19 命中，四态判定稳定 |
| Root resistance 判据清单（从格判定） | ✅ 从财/从儿/从势/印透阻从/根落空亡全识别正确 |
| CLIMATE OVERRIDE 状态机（寒暖调候） | ✅ Case 005/014/084 触发/例外/退出全闭环 |
| Phase A/B 预注册与后验四态 | ✅ 30 个后验案例 27 命中，未命中裁决/未知/反例/不强行收敛全部正确执行 |
| 病型与成格范式分离 | ✅ 枭神夺食/伤官佩印/杀印相生等全部正确识别与命名 |
| 竞争假设触发门槛（v1.4） | ✅ 临界盘并列路线、普通盘单主判断，无「永远不确定」 |

### 3. 易错模块定位（本轮测试的核心产出）
| 模块 | 错误率 | 主要偏差模式 |
|---|---|---|
| **空亡** | **6.0%（最高）** | 空亡标注偏差（Case 61/65/67/70 等：空亡支的判定/是否计入旺衰的标注不一致） |

| 病药 | 1.0% | 单处概念标注 |
| 调候/干支/应期/大运/神煞/后验 | 0.0% | 全部稳定 |

### 4. 修正方向（v1.6 后续）
1. **空亡模块（最高优先）**：统一「空亡以排盘工具所列为准」的执行口径——当前偏差多为「模型自行判空亡支」与「标注是否计入旺衰」不一致。建议在 SKILL.md 步骤 0 强化「空亡直接引用工具结果、不作二次推算」的执行细则。
2. **旺衰边界**：Case 022 暴露「身强边界盘」设计需更严谨——同类边界盘应增加「得地根气的具体落点核对」提示。
3. **十神概念命名**：Case 69/93 出现「正财/偏财、正印/偏印」概念标注偏差——建议在 patterns.md 或 SKILL.md 增加「十神速查对照表」（[STRUCTURAL] 层，防概念混淆）。

### 5. 已知待核对分歧点

- 空亡「合解 vs 合绊」流派分歧（Case 59/67）——已按 [SCHOOL] 标注。
