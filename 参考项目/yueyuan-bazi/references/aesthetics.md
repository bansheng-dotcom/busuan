# 输出审美规范（内置 Taste Enhancer 审美原则）

> 本文件内置自「Taste Enhancer」审美增强技能，规范 yueyuan 的可视化输出（HTML 报告、图表、卡片等）。属 `[SUPPLEMENTAL]` 输出层规范，不影响命理判断本身。
> 总纲：**减法的勇气 + 对细节的执着 + 对平庸的拒绝**。品味 = 克制。

## 一、视觉设计标准

### 1. 一个焦点
每个输出只有一个视觉焦点。本 skill 的焦点恒为【核心总评 + 路线级竞争假设】——用户第一眼应看到「最优判断 + 不确定度 + 主要竞争点」，而非四柱表或装饰。

### 2. 留白即设计
- 重要结论周围留更多空白；模块之间 ≥ 48px 呼吸空间。
- 单个区块内信息点不超过 3 个；超出即拆分，不堆砌。

### 3. 色彩克制（UI 主题层）
- UI 层（背景、标题、卡片、正文）保持克制：**1 个主色 + 中性色阶**（米白/灰）。
- 主色建议：沉稳东方色（黛青/墨绿，如 `#1e3a34`），用于标题与强调。
- 避免：默认蓝、满屏彩色卡片、大面积渐变。

### 3.5 五行语义色（数据编码层，允许且推荐）
- 五行五色作为**数据编码**使用——颜色编码「是什么（五行身份）」，不是装饰。用于标注天干、地支、藏干、喜忌的五行归属。
- 推荐低饱和东方色值：金 `#b8891e` · 木 `#3e7a4f` · 水 `#2f6d9e` · 火 `#c0392b` · 土 `#9a6a3a`。
- **深色结论卡（Phase A/B/…）统一使用 Phase A 墨绿色 `#1e3a34`**，五行色直接使用上述低饱和版本，保持整体高级、克制。
- **五行色与喜忌是两个正交通道**：颜色只编码五行，喜/忌用符号区分（● 喜用 / ○ 忌神），不得用「红=忌」这类颜色混用。
- 十神是关系而非元素，**不上五行色**，保持中性灰。
- 五色只用于语义字/标签，不作大面积色块装饰。

### 4. 字体节奏
- 标题用衬线（serif）营造书卷气；正文用无衬线（sans）。
- 靠字号、字重、行高变化建立节奏：标题大、正文中、标注小。
- 关键结论加粗，**不整段加粗**。

### 5. 反模式（强制避免）
- 默认蓝 / 满屏卡片网格 / 过度渐变（最多 1 处）/ 全圆角统一 / 图标+文字堆砌。

## 二、文案标准

### 1. 删 AI 味
禁用：此外、综上所述、值得注意的是、强大的/灵活的/优雅的、让我们、接下来、首先…其次…最后。

### 2. 具体优于抽象
「财星当令、身弱需印比」优于「格局复杂、需综合考量」。

### 3. 阶段性收敛结论的措辞（强制，v1.3 分级）
用户提供第一次反馈后，必须给出「进展感」，但**不能让用户感到被催促或被打分**，且**不机械使用「大概率」**（一条人生事件不足以支撑概率陈述）。按证据强度分级：

- **标题（部分命中，单一年/单一维度）**：「基于当前信息，**目前更支持** [X 路线]，喜 [五行]、忌 [五行]。」
- **标题（证据充分，多维互证后）**：「目前 [X 路线] **明显占优**，喜 [五行]、忌 [五行]。」
- **白话翻译层**：可用「大概率偏向 X」，但紧跟「基于有限证据的方向性倾向」标注。
- 禁用：「当前最像的答案」「最可能的结论」「你大概率是 X」等**未分级**的绝对化表述。
- **支持句**：「某年某事，与『某判断』一致。」（平铺直叙，禁用「拿到一分」「领先」等竞赛感词汇）
- **后续引导**：「由于目前提供的经历年份有限，这个判断仍属阶段性倾向。若您想进一步确认，只需再补充……即可；其他资料无需再翻。」（禁用「只差一步」「其余资料你不用再翻」等 push 感表述）
- **诚实边界**：明确标注「部分命中」级，不确定度动态下修。

### 4. 喜用神翻译层（强制，喜忌明确后必做）
喜用神对非专业用户是抽象符号，**必须翻译成人生语言**后才能进入分领域解读：

- 结构：「你的八字能量偏 [X 型：自我成就/依靠/输出]；[喜用五行意象] 是你的助力方向（如事业名望、财富资源、表达才华），[忌神五行意象] 容易带来消耗（如竞争争夺、束缚固执）。」
- 禁用术语堆砌；用意象和场景说话，让完全不懂八字的人也能读懂。
- 翻译完成后才进入分领域重解读，每一条都落到「因为喜 X 忌 Y，所以你的 [领域] **倾向是** [具体形态]」（禁用未分级「大概率是」，同第 3 条）。

### 5. 双人群分层呈现（强制）
本 skill 同时服务小白与懂八字者，两者都必须看着舒服：

- **白话在前、术语在后**：每条关键结论先给一句人话（「你的八字能量偏自我成就型」），术语附后（「即身旺喜财官食伤」），不反过来。
- **通俗区与专业区分区**：翻译层、生活应用、领域解读结论句 = 通俗区（浅色卡/大字号）；推导链（六维、合化判定、流派标注）= 专业区（常规排版 + 小字「进阶内容，小白可跳过」提示）。两者分区呈现，不混排。
- **专业内容可跳过**：推导链模块允许弱化视觉（灰字、折叠感），标注「进阶内容」，不阻挡小白主流程。
- **生活应用**（方位/颜色/环境/职业）在喜忌明确后给出（无路线竞争时第一轮即给），1–2 条，标注民俗文化层（小字灰注），不做恐吓式「忌神绝对避免」。

### 6. 命理特有纪律
- 结论必须带证据等级（A–E）与规则层级标签，但**用弱化视觉呈现**（小号灰字），不喧宾夺主。
- 不确定度只用「高/中/低」文字，**不伪造进度条百分比**。
- 身心板块免责声明必须保留，但置于文末弱化位置。

## 三、结构节奏（HTML 报告固定顺序）

> 落地载体：本节奏已固化为可套用的 HTML 骨架，见 `references/html-template.md`（Design Tokens + 区块固定结构）；产 HTML 时套用该骨架、只替换内容，勿逐盘重写 CSS。

### 第一轮（用户未提供经历时）：
```
核心总评（焦点）
  → 路线级竞争假设（并列展示＝路线摘要卡；完整 Hypothesis 推导在专业区，不全量铺开）
    → 盘基信息（四柱表，供参照）
      → 用神六维一致性
        → 关键变量（合化/合绊等判定）
          → 初步分领域提示（基于原局，不确定度高，语气中立）
            → Phase A 预注册（锁定）
              → 免责声明（文末弱化）
```
> v1.3 补充：**「并列展示」≠「第一屏全部展开」**——第一屏只放路线**摘要卡**（各 3–4 点），完整 Hypothesis（支持证据/反证/预测差异）归入专业区，符合「一个焦点」原则。

> 分支（关键）：**若第一轮喜忌已清晰（无路线级竞争、不确定度 ≤ 中）**，跳过「初步分领域提示」的占位形态，直接按第二轮结构给出：核心总评 → 路线判定（含已排除项）→ **喜用神翻译层 → 五行喜用生活应用 → 基于此方向的领域解读** → 盘基/六维/关键变量（进阶区）→ Phase A → 免责声明。喜忌明确即触发小白内容，不依赖 Phase B。

### 第二轮（用户给过一次反馈后，Phase B 出现时）：
```
核心总评（焦点，不确定度已下修）
  → 路线级竞争假设（带「领先/被削弱」动态标签）
    → 盘基信息（四柱表）
      → Phase B · 阶段性收敛结论（分级措辞：目前更支持/明显占优，深绿卡）
        → 喜用神翻译层（把喜忌翻译成人生语言，小白可懂）
          → 五行喜用生活应用（方位/颜色/环境/职业，民俗文化层，1–2 条）
            → 收敛后分领域重解读（以收敛喜忌为锚，重写事业/财富/婚恋/身心）
              → 待验证缺口（温和引导，其他资料无需再翻）
                → 免责声明（文末弱化）
```
> 关键：**Phase B 收敛结论必须排在分领域解读之前**——用户第一次反馈后，最先看到的是「目前更支持 X」→「这意味着你的人生各领域会如何」，而不是理论推导链。

> 结论先行、竞争假设紧随，符合 SKILL.md 第九章「核心总评先行」与第六章「路线级假设优先」。
