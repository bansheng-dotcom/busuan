# 六亲专库（取象 · 状态 · 应期 · 断语分级）

> 地位：`references/liuqin.md`，[CORE]/[HEURISTIC]/[EVENT]，由 SKILL.md 步骤 9 六亲家庭板块引用；「病型×六亲断语分级表」与 `references/patterns.md`「病型×领域断语上限总表」（第六节）联动，两处口径必须一致。
> 纪律：本库全部规则源自复盘（多命例正反对照），**不含任何具体出生日期、完整四柱、答案字母、届数、命例编号、出题人名**；盘面特征一律以「父星/母星/配偶星/子女星」等抽象代称表述。
> 证据强度：每条规则标注「证据强度：强/中/弱」；**中/弱证据规则保留「待验证」标注，不得静默升格为铁律**。规则层级按 SKILL.md 第三章标签体系合并标注。

## 一、六亲星取象统一口径（R1）｜[CORE]

**财星=父、印星=母（正偏皆可、不分男女）；男命财=妻、官杀=子女；女命官杀=夫、食伤=子女；兄弟=比劫。**

- 适用条件：所有涉及父母/子女/配偶（含夫妻宫事件）的六亲判断；排盘确定后即套用。
- 判断步骤：
  1. 以日主定位十神：**财星=父、印星=母**——不分男女命、不分正偏（正财偏财皆可代父、正印偏印皆可代母；女命同样以财为父）。
  2. 男命：财=妻、官杀=子女；女命：官杀=夫、食伤=子女。
  3. **正偏分工只作亲疏/属性细分，不作存在性判断**：正印=生母；偏印=养母/继母/隔代养育（祖母、婆婆代养）；男命正财主妻、偏财兼主父（[SCHOOL] 参考，不排斥正财断父）。
  4. 六亲状态一律查「星本身」：透干/藏支/得根/得禄/入墓/逢值，不因正偏改判「有无」。
  5. 兄弟=比劫（男命比肩=兄弟、劫财=姐妹；女命比肩=姐妹、劫财=兄弟；[SCHOOL] 部分流派不分性别统论比劫=兄弟姐妹）。
- 反例边界：女命子女星存在「官杀=子女」流派（样本内食伤、官杀两口径各获命例支持）；男命子女星存在「食伤=子女」流派（[SCHOOL] 分歧，与 SKILL.md 步骤 9 总纲标注对称）——取象两可时标注 [SCHOOL] 分歧并列；**应期方法论（R6）优先于取象选择**。
- 证据强度：**强**（多命例印证：偏财=父、正财=父、正印=母均有复盘命例背书）。

## 二、无星纪律（R2）｜[HEURISTIC]

**六亲星三查（天干/地支本气/藏干）俱无 → 只断「缘薄/聚少离多/自小离开家庭」，禁断「孤儿/无夫/无妻/无子」等存在性否定。**

- 判断步骤：
  1. 三查：天干、地支本气、地支藏干。
  2. 俱无 → 断「与这位亲人缘分薄、沟通少、聚少离多、可能自小离开家庭」。
  3. 有藏干之根（中气/余气）→ 断「星弱而藏」：弱、疏远、被动，不断「无」。
  4. 星藏墓库 = 有星而隐（状态），不是缺位。
  5. 缺位 + 宫位凶象，最高只能升级到「自小分离/缘薄」，**不可升级到「亡故/不存在」**。
- 反例边界：任何人都必然有父/母、有婚缘对象（婚否另论）、有子女（生育另论）。
- 证据强度：**强**。

## 三、证据充分性纪律（R3，v1.7 改写，原「平凡先验」）｜[HEURISTIC]

**重断（外情/早逝/收养/离异/重病/破产级）须 ≥2 独立信号（不同结构层：星动/宫动/岁运引动/原局结构响应）；不足则明说证据不足，输出程度级描述并列出判别条件。**

- 判断步骤：
  1. 每条重断列出 ≥2 个独立信号（不同结构层）；
  2. 信号不足 → **明说「证据不足，暂不能定重级断语」**，输出**程度级**描述（感情不佳、家贫、分居、体弱、缘薄），不输出**状态级**（离异、亡故、收养）；
  3. 给出**判别条件**：后续哪些岁运引动（如配偶星透干被合走之年）可区分重级/程度级，供用户经历后验；
  4. **不预设「取平凡」为默认、不猜测用户状态**——用户自己的经历就是最终校验（结论是验证出来的，不是算出来的）。
- 反例边界：「星伤」级信号齐备的盘不适用本纪律，该断则断；证据充分性纪律 ≠ 一律取中间档（先用 R4/R5 判定信号）。
- 证据强度：**强**。（领域实例：婚姻 R34、财富量级 R40、性格 R44、形象 R48，见 SKILL.md 步骤 9 各板块）

## 四、状态 ≠ 生死（R4）+ 墓库亡故三链（R5）｜[HEURISTIC]

**「弱、藏、墓、绝、虚浮、被泄、受克」是状态，不是死讯；亡故必须升级到「星伤」级，且三链齐备才定应期。**

- 适用条件：六亲星呈「弱、藏、虚浮、病地、被泄、受克、入墓」任一状态时。
- 判断步骤：
  1. **状态分级**（R4）：得禄当令=强健；得根透干=正常偏强；虚浮/病地=体弱多病、关系疏远；藏而不透=缘薄、隐而不显；入墓=休伏、闭藏。由状态断「健/弱/病/离/缘薄」，**禁止直断「亡/送养/仙游」**。
  2. 亡故候选必须升级到「**星伤**」级：六亲星**透干**之年 + 被合走/被克损（伤其星，非伤其宫）。
  3. **亡故三链**（R5）：① 星透干（原局透，或该年岁运透出）——**不透 → 仅「入墓受制」= 休伏/病/隐，不断亡**；② 库被**冲开**（辰戌冲、丑未冲等）；③ 叠加**克损**（被克/被合走/被劫夺）。**三步齐备才断亡故应期；缺一 → 断「状态年」或「关口运」**（该运内有损，不断具体年份）。注：「库被冲开」须按 suijie-shensha.md 墓库三分支裁决——对应「破库折根」（藏神已透干逢冲、天干之根被拔）才计入亡故链；「库开释放」（藏神未透）不计入。
- 反例边界：星伤+库开+宫位动三链齐备时可断亡（复盘命例口径）；「已透之星逢墓」与「藏星入墓」不是同一级信号，前者才可论「透干被收」；星伤未现时，即使宫位被冲、墓库被开，只断「有损/变故/关口」。
- 证据强度：**强**（正反大样本对照）。

## 五、六亲应期：星动为主、宫动为辅（R6）｜[HEURISTIC]

**事件取「星动年」——透干得根=生/婚，被合走/被克损=离/亡；宫动只作辅助确认，单宫动不断年。**

- 判断步骤：
  1. 定位六亲星（R1）。
  2. 在目标大运窗口内逐年检查：星是否透干、是否得根/得禄、是否被合走、是否被克损。
  3. 生/婚 = 星透干得根之年（如子女星透干得根断生、比肩透干得根断弟妹出生）；离/亡 = 星被合走/被克之年。
  4. 宫位动（冲/合/伏吟）只作**辅助确认**——单凭宫动不断具体事件；宫动+星动双信号齐备可信度最高。
- 反例边界：岁运并临、天克地冲等「最烈信号」仍须叠加星伤才断亡（与 R4/R15 一致）。
- 证据强度：**强**。

## 六、家境出身分层（R7）｜[HEURISTIC]

**年柱只断祖辈/祖业，月柱（父母宫）为纲断自生家境；年柱财旺 ≠ 自生家富。**

- 判断步骤：
  1. 父星（财）状态：得禄当令=富基；虚浮受克=贫；入墓=财藏不外露。
  2. 月柱（父母宫）：月令为喜用且宫位无冲克 → 家荫好；**月令为忌神 → 父母无力荫助**（无遗产、须自筹/半工读类境况）。
  3. 年柱只断祖辈/祖业与出生地环境，**不断自生家境**。
  4. 父星与月宫冲突（父星旺但月宫坏 / 父星弱但月宫好）→ 取中档（小康/平凡），不断极端。
- 反例边界：父星得禄极旺 + 月柱无伤双旺才断大富；「年柱财旺/透干」只断祖上殷实。
- 证据强度：**强**。

## 七、防断早：应期年 = 信号链完成年（R8，六亲实例）｜[HEURISTIC]

- 判断步骤：
  1. 先定**大限**：该大运是否为「关口运」（六亲星受制的十年窗口）。
  2. 在关口运内找「**信号链完成年**」：星透 + 被合走/被克 + 库开，同年或紧邻年齐备。
  3. 只有前置信号（墓逢值、伏吟、宫冲）而无后置信号（星伤）→ 只断「该运有损 / 近年有关口」，不断具体年份。
  4. 多个候选年之间，取「星动 + 被伤」之年，不取「库动/宫动」之年（R5/R6）。
- 反例边界：三合一应期年（星透被合走 + 库开同年）当断则断，不因防早而漏断；「**断晚优先**」为样本内启发式（负向大事件应期错题全部断早、无一断晚），**弱证据，待扩展样本验证，不作铁律**。
- 证据强度：**中**（母规则为批2 R12，全领域通用，见 suijie-shensha.md 应期流程速查）。

## 八、离开 ≠ 外情（R9）｜[HEURISTIC]

**聚散（离开家庭）≠ 情变（外情）≠ 关系终止（离异）——三者各自需要独立证据，不可混用。**

- 判断步骤：
  1. 区分三个概念：**离开家庭（聚散）≠ 外情（情变）≠ 离异（关系终止）**。
  2. 断外情：六亲星被合 + 合方性质与异性星相关 + 宫位证据，多重信号齐备；**单凭「某星逢合」不断外情**。
  3. 有冲尚有「他冲/他合」抵销时，变故降级（断「离开」不断「离异」）。
- 证据强度：**强**。

## 九、配偶星条款（R26/R27，R1/R2/R4/R9 的婚姻推广）｜[HEURISTIC]

**取象（R26）**：男命以财星为配偶星（正财=正妻，偏财兼主父与情缘——父缘取象按 R1）；女命以官杀为配偶星（正官=正夫，七杀=偏夫/男友/再嫁之缘）。正偏分工**只用于属性细分，不用于存在性判断**——「无正官只有七杀」不断「无正夫」，「只有偏财」不断「无正妻」。同一财星（男命）被问「妻子」还是「父亲」时按**所问领域**取象，同一事件不作双重归属。

**三态纪律（R27）**：

| 配偶星状态 | 合法断语 | 禁止断语 |
|---|---|---|
| **缺位**（三查俱无） | 姻缘迟、感情被动、聚少离多、晚婚倾向 | 「未婚一生/无婚」（任何人必有婚缘对象，婚否另论） |
| **入墓**（星藏库中或岁运入库） | 感情藏而不显、聚少离多、缘分休伏、关系降温 | 「丧偶/克死配偶」 |
| **被合** | 先断方向：合日主=结合；被他神合走=分离；合而不化=牵绊纠缠 | 单凭「逢合」断外情/第三者 |
| **弱/坐绝/受克/虚浮** | 配偶体弱、缘分淡、感情压力、婚恋被动（程度级） | 「离异/丧偶」（R4 推广：弱藏墓绝是状态不是判决） |

- 反例边界：入墓 + 墓被冲开 + 星伤三链齐备可断丧偶/寿限（R5 推广）；星被合走 + 宫动双信号可断分手/离婚年；「星藏而有根」断「晚成/被动」不断「无」；断「外情/第三者」须合方性质指向异性（比劫/异性星）+ 宫位或桃花证据多重齐备。
- 证据强度：**强**（正反对照 ≥6 例）。

## 十、六亲双星互动断法（R56）｜[HEURISTIC]

**财印双透相合 → 先合后墓，断健在和谐；财克印 → 受克方（母方）受损，按星伤完成度分级。**

- 适用条件：父母双星（财=父、印=母）在岁运出现互动（相合/相克/与父母宫冲合），断父母关系事件（健在与否、离异、一方受损、出事年份）。
- 判断步骤：
  1. **先查合、后查墓**：财印双透相合（或相生无碍）→ 父母健在、关系和谐——「合」优先于「墓」解读。
  2. **财克印**（父星克母星）→ 事件指向**受克方（母方）**受损，按星伤完成度分级（R4/R11 同构）：仅透干相克 → 母病/父母失和（程度级）；克+根伤 → 离异/母重病（中事件）；克+库开三链 → 母亡（大事件）。
  3. 父母宫冲/刑动 → 父母关系变故候选年，但须查「抵销」（他冲/他合）与星伤（R9）；单冲宫不断离异。
  4. **事件标签必须与信号方向一致**：受克方是谁就断谁受损——标签写「父母离异」前先确认克方与受克方各自的宫位状态。
- 反例边界：财透克印只给方向，应期仍走 R5/R8 三链完成年；「财印相合」若印为忌另论（合绊）；合而不化只断牵绊。
- 证据强度：**中**（待验证：事件标签与信号方向的错配为复盘直接证据，样本有限）。

## 十二、病型×六亲断语分级表｜[HEURISTIC]/[EVENT]

- 证据强度：**中**（待验证：本表为复盘归纳框架，各格样本覆盖不均，随新样本修订）。
