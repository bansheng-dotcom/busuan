**用法**：判断日主得令时，先看出生日处于**进入当月节气后的第几天**（分日用事之神为何），再定该神对日主的生克关系。例如：某命生于进入寅月节气（立春）后第 20 天（甲木用事），日主为壬水，则月令甲木（食神）泄身，虽在寅月但不得生扶——「得令」需精确到用事之神，而非笼统「寅月木旺」。

## 二、旺衰判断的条件变量框架（[CORE]）

旺衰判断以**条件变量**组织，**不设固定数值权重**（如"月令占 X%"之类无标定依据的量化禁止使用）：

1. **得令**：月令为最高优先级变量之一，结合分日用事（[SCHOOL] 细化）定月令对日主的生克泄耗。
2. **得地（通根）**：通根的**初始参考**（[CORE]，非最终力量函数，须双维分别评估、不合并排序）：
   - **根之深浅**：本气根最深，其次中气根，再次余气根（此为**定性层级**——传统命理共识，非伪量化数值；可用于排序，但不得赋具体百分比/权重数值）
   - **气量深度（得令/根深）**：月支根（提纲秉令，气量总纲最重）优先于坐支根、时支根、年支根
   - **贴身感应（距离/响应）**：坐支（日支）根离日主最近、感应最直接，优先于月支/时支根、年支根
   - 最终根气力量须再结合：是否遭严重冲克、是否失令、是否受合化影响、是否同类成势。例：本气根+遭冲克+失令 ≠ 必然强于 余气根+得令+透干+同类成势——逐项评估，不机械套排序。
3. **得势**：天干比劫、印星帮扶的数量与透藏质量（透干为表、藏支为里）。
4. **透藏**：用神/忌神透干与藏支的区别。
5. **合化**：三合、三会、六合、五合是否成化（C 级判断），成功则旺衰重算。
6. **制化**：被克被制是否改变原结构力量。

## 三、输出口径

- 禁止二选一：输出「偏弱 / 中和偏弱 / 中和 / 中和偏强 / 偏强」+ 一句话依据（月令分日用事、根气、得势逐项列出）。
- 从格嫌疑触发条件（**v1.3 Root resistance 原则**）：**日主无本气根或无有力之根**——注意「无根」是**强支持证据之一，不是硬门槛**：有根 ≠ 一定不从（根遭冲克/合化/落空亡/处死绝则无力破坏从势纯度）、无根 ≠ 一定从（须查印比是否透干未灭）；关键在于**该根是否具备破坏从势纯度的实际能力**。加上满盘克泄耗交加、势已成 + 生扶极度微弱或全无（印比死绝或遭严重破坏）→ 双轨并列「身弱 vs 从格」，各自列成立条件与后果，不强行二选一；若判从格，按 `references/biange.md` 对应细分（从财/从官杀/从儿/从势）取用。
- [SCHOOL] 视角分歧（并列标注，不强制统一）：
  - 格局派（黄大陆等）：格局重于旺衰，旺衰不必细究，凡成格者以格局论。
  - 旺衰调候派（梁湘润等）：以「禄旺 / 有根 / 无根」三分类，且**阳干根深、阴干根浅**（此条为流派规则，非基础变量，不默认适用于所有盘）。
