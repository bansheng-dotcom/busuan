# 变格体系规则库（v1.3 新增；v1.8 补「制化自救闸门」）

> 地位：`references/biange.md`，[CORE]/[SCHOOL]，由 SKILL.md 步骤 2（格局判定）与步骤 5（用神六维）引用。
> **v1.8 修订（开放分析命理修正）**：FROM 前置条件新增「判据 0 · 制化自救闸门」——极弱日主先查可用制化（食神制杀/印星化杀/伤官合杀/合绊护身），制化神透干得地则优先正格制化不判从格；从格须「制化机制被破或无可用制化」为前提。校准样本（抽象化）：例12（梁湘润休废例，合绊护身→不从）、例13（袁树珊例，食神制杀有根→不从）。
> **核心原则（v1.3 P0 修正）**：从势 / 专旺 / 化气 **不是同一个「顺势翻转器」**——各自是独立状态机，成立条件、顺势方向、逆势方向、破格条件、岁运触发方式各不相同。禁止用「判定变格 → 整体喜忌翻转」的统一函数处理。

---

## 一、四态总览

| 状态 | 含义 | 顺势方向 | 逆势方向 | 触发检查时机 |
|---|---|---|---|---|
| `NORMAL` | 普通格局（正格/特殊格局） | 按扶抑/格局正常取用 | — | 不进入变格逻辑 |
| `FROM` | 从势（日主极弱，顺克泄耗之势） | 喜克泄耗，忌生扶 | 见下各细分 | 日主无根/根无力 + 克泄耗成势 |
| `ZHUANWANG` | 专旺（日主一方独旺，顺旺势） | 喜印比，忌财官食伤 | 忌克泄耗 | 日主极旺成势 + 克泄耗无根受制 |
| `HUAGQI` | 化气（日主合而化，顺化神） | 喜化神五行，不顺日主 | 忌化神受克 | 天干五合 + 化神当令成局 |

> **概念边界（防混层）**：
> - 专旺与从势是**相反两极**：专旺=日主极旺顺势，从势=日主极弱顺势。二者共享「顺势不逆势」的总原则，但喜忌方向相反——所以更不能共用一个翻转器。
> - 化气**独成一体**：既非「日主旺」也非「日主弱」，是「日主被合而化」，喜忌以化神论。
> - 建禄、羊刃**不属于变格体系**（见 SKILL.md 步骤 2 分组：属「特殊格局」），不进入本库的顺势逻辑。

## 二、FROM 从势（日主极弱顺从）

### 成立前置条件（逐条打勾的判据清单，v1.4）

> 目的：把「评估根是否破坏从势纯度」从软性经验判断，固化为可复现的「是/否」检查，降低 LLM 自由裁量与上下文带偏风险。

- **判据 0 · 制化自救闸门（v1.8 新增，[CORE]，最先执行）**：进入从格判定前，**先查「制化自救」**——
  - 制化机制：食神制杀、伤官合杀、印星化杀等制化手段，以及合绊护身（如丙辛合财、合杀留官）等自救手段；
  - 「可用」判据：制化/合绊神是否**透干或得地（有根气）**、是否**未被合走/被克损/根被拔**；
  - **制化/合绊神透干得地、未被破坏 → 「制化自救」成立 → 优先正格制化，不判从格**（从格嫌疑降级）；
  - **制化机制被破或无可用制化（制化神虚浮无根、被合走/克损）→ 判据 0 不通过**，继续后续判据，可升级从格嫌疑。
  - 依据：传统「从格须真」判据（真从=无一救应；假从=有救应则仍从）——对齐袁树珊「用食神制杀不弃正格」、梁湘润「休废用印」经典口径；[SCHOOL] 从格/休废在「无根无印极弱」处存在流派分歧，**需外部权威核对**。
- **判据 1 · 日主本气根是否存在？**
  - 存在 → 记录其状态，以下四类**任一命中即视为「根被削弱」**：遭冲克 / 被合化 / 落空亡 / 处死绝。**「根被削弱」必须有具体落点**（写明被谁冲克、合化成何、空亡何支、处何死绝），禁止仅凭「感觉根弱」就判从。
  - 不存在 → 判据 1 通过（无根）。
- **判据 2 · 印星、比劫是否透干？**
  - 透干 → 查其有无根气、是否被克合；透干且有根 → 记为「生扶有力」。
  - 未透 → 记为「生扶无显」。
- **判据 3 · 克泄耗（财官食伤）是否成势？**
  - 是（占主导，非三五零星）→ 判据 3 通过。
  - 否 → 判据 3 不通过。
- **判据 4 · 生扶（印比）是否「极度微弱或全无」？**
  - 是（印比死绝 / 遭严重破坏 / 透而无根被克合）→ 判据 4 通过。
  - 否 → 判据 4 不通过。

**裁决规则**：
- **判据 0「制化自救」成立 → 倾向不从（正格制化）**，即便判据 1/3/4 指向从格（例12 合绊护身、例13 食神制杀即属此类，均判不从）。
- 判据 0 不通过 + 判据 1「根被削弱」（或无根）+ 判据 3 通过 + 判据 4 通过 → **倾向从格**（再按细分类型定从财/从官杀/从儿/从势）。
- 判据 1「根有力未损」或 判据 2「印比透干有根」→ **倾向不从**（普通身弱）。
- 仍不能决断时，才并列「身弱 vs 从格」双轨假设（SKILL.md 第六章路线级模板）。

**校准样本（v1.8，抽象化表述，不写具体命盘）**：
- 例12（梁湘润休废例）：日主极弱无印，但含丙辛合（合绊护身之制化）——判据 0 成立 → 判休废不从、喜木火帮身（梁湘润口径），而非从势喜金水。
- 例13（袁树珊例）：日主极弱，但透丁火食神制杀（食神透干、有根可依）——判据 0 成立 → 判食神制杀正格、用丁火（袁自批口径），而非从杀喜金土。
- 两例均提示：**无根无印日主在有可用制化/合绊护身时，优先正格制化**；此口径与「极弱必从」倾向相反，涉及流派分歧，**需外部权威核对**。

**注意（Root resistance 原则保留）**：有根 ≠ 一定不从（根被削弱仍可从）；无根 ≠ 一定从（须过判据 2/4 查印比）。关键是**该根是否具备破坏从势纯度的实际能力**——已由判据 1 的「被削弱」四类情形操作化；「无根」时以判据 0（制化自救）为第一道闸门。

### 细分（[SCHOOL] 各成条件）
| 类型 | 核心 | 顺势方向（喜） | 逆势方向（忌） | 主要破格条件 |
|---|---|---|---|---|
| **从财** | 财星当令成势，日主顺从财 | 财；食伤生财亦顺 | 比劫（夺财）、印星（生身反抗） | 比劫透干或根气有力；印星透出生身 |
| **从官杀** | 官杀成势，日主顺从官杀 | 官杀；财生官杀亦顺 | 印星（化官杀=泄官杀之势）、比劫 | 印星透干化官杀（官杀被泄）；比劫帮身 |
| **从儿** | 食伤成势，日主顺从食伤 | 食伤；食伤再生财亦顺 | 印星（制食伤）、官杀 | 印星透出制食伤；日主得根 |
| **从势（从弱）** | 财官食伤混杂成势，无从一神之专 | 克泄耗（顺势） | 印比（生扶） | 印比得根透干；势不纯 |

### 岁运触发
- 顺势岁运（喜用五行）→ 顺遂；逆势岁运（忌神五行）→ 凶（破格之运主大凶，须防）。
- 逢印比运：从财/从官杀/从儿分别以「印坏格」「比劫帮身反抗」论凶；从势亦然。
- 命局从得真（势纯无杂）比从得假（有杂但勉强从）更稳，假从更怕逆势岁运。

## 三、ZHUANWANG 专旺（日主一方独旺）

### 成立前置条件
1. 日主得令、得地、得势，一方五行极旺成势。
2. 克泄耗（财官食伤）无根或受制严重——**若官杀有根有力，则专旺多不能成立**（官杀为专旺最大破格）。
3. 全局气势纯粹，从旺顺势。
4. **纯度要求（v1.5 补）**：专旺纯度要求极高，**若地支有一粒异类五行有根，多已破格退论普通身旺**——专旺「易破」，勿轻易判定专旺，先排除异类有根再确认。

### 细分（[SCHOOL]）
| 类型 | 五行 | 顺势方向（喜） | 逆势方向（忌） |
|---|---|---|---|
| 曲直 | 木 | 木（比劫）、水（印） | 金（官杀）最忌、土（财）次之、火（食伤）有泄亦有成器之说 |
| 炎上 | 火 | 火、木 | 水（官杀）最忌、金（财）次之 |
| 稼穑 | 土 | 土、火 | 木（官杀）最忌、水（财）次之 |
| 从革 | 金 | 金、土 | 火（官杀）最忌、木（财）次之 |
| 润下 | 水 | 水、金 | 土（官杀）最忌、火（财）次之 |

> [SCHOOL] 分歧：专旺遇食伤，有「泄秀为佳」与「泄气破格」两说（如曲直见火、炎上见土）——按「是否得根有力、是否伤及旺势纯度」评估，不统一断吉凶。

### 破格条件
- 官杀有根有力（最重）；财星成势；食伤泄气过重伤及日主。
- 天干官杀透出而地支有根 → 专旺破，退论普通身旺。

### 岁运触发
- 印比岁运 → 顺遂（喜）；财官食伤岁运 → 逆（忌），官杀旺岁运为最险之运。
- 专旺格岁运逢「强根官杀」之年，主官非、压力、健康损耗等主题。

## 四、HUAGQI 化气（日主合而化）

### 成化条件（[SCHOOL]，逐条评估）
1. **天干五合**：甲己、乙庚、丙辛、丁壬、戊癸，日主与相邻天干（月干/时干/年干）相合。
2. **化神当令**：化神五行在月令当权得令。
3. **化神得地支成局之助**：月令 + 地支三合/半合/会局向化神。
4. **日主无强根**：日主本气根弱或遭合化（有强根则破化）。
5. **化神不受克**：化神被强克则化不成。
6. 「逢龙则化」（辰支助化）为传统一说，[SCHOOL] 标注——**优先级很低**：化气格成立本就严苛（须化神当令成局 + 日主无强根），辰是否助化属锦上添花，**不作为硬判据**。

### 化后取用
- 化格成立后，**喜忌以化神五行论**，不顺日主本五行：
  - 甲己合化土 → 喜土（火生土亦顺）、忌木（克土）水（耗土）金（泄土，有流派以为金泄土可顺，[SCHOOL]）。
  - 乙庚合化金 → 喜金（土生金亦顺）、忌火（克金）木（耗金）水（泄金）。
  - 丙辛合化水 → 喜水（金生水亦顺）、忌土（克水）火（耗水）木（泄水）。
  - 丁壬合化木 → 喜木（水生木亦顺）、忌金（克木）土（耗木）火（泄木）。
  - 戊癸合化火 → 喜火（木生火亦顺）、忌水（克火）金（耗火）土（泄火）。
- **化气与从势的根本区别**：从势顺「克泄耗之势」（日主被压倒），化气顺「合化之化神」（日主被转化）——机制不同，**不可共享翻转逻辑**。

### 破格条件
- 化神受强克；日主得强根；合而不化（只合不化，退论正常合绊 [C级判断]）。

### 岁运触发
- 助化神之岁运 → 顺；破化神之岁运（克化神、助日主根）→ 凶/反复。
- 化气格逢「助日主本五行之根」的岁运，可能「还原」——从化格退复常格，[SCHOOL] 标注分歧。

## 五、裁决顺序（防误用）

1. 先判 `NORMAL` 是否成立（普通扶抑/格局可用）——**默认状态**，不预设变格。
2. 出现从势/专旺/化气嫌疑时，**先并列列出各候选状态**（如「专旺 vs 普通身旺」「从财 vs 身弱」），各自列成立条件与后果，不默认其一（沿用 SKILL.md 第六章路线级假设模板）。
3. 选定状态后，用**该状态自己的**顺势/逆势/破格规则取用，**禁止跨状态套用喜忌**。
4. 变格被破（如专旺逢强官杀）→ 明确宣告「变格不成立，退论普通格局」，并说明退论后的喜忌变化。

## 六、与用神六维的接口

SKILL.md 步骤 5 第 6 维（变格/外格）取本库结论：
- `NORMAL` → 该维「不适用」，不触发翻转。
- `FROM` → 喜克泄耗、忌生扶（按细分类型微调）。
- `ZHUANWANG` → 喜印比、忌财官食伤（按五行类型微调）。
- `HUAGQI` → 喜化神五行、忌破化之五行（按化神五行论）。
