## 一、大运流年分析顺序（[CORE]/[HEURISTIC]）

1. **三层结构**：原局为体（根基/信息库）→ 大运为纲（十年趋势）→ 流年为目（当年应期）。重要性层级：原局（体）最重，其次大运（纲），再次流年（目）。
2. **分析顺序（≠本体论优先级）**：先定原局格局喜忌 → 再评大运对原局作用 → 最后看流年在大运框架内触发。**流年先与大运作用（岁运互动为第一分析优先级），再作用于原局**。岁运相冲、天克地冲、伏吟为当年最大变量。
3. **流年冲原局各柱**：冲日柱关自身/婚姻，冲月柱关事业环境/父母，冲年柱关祖业/长辈，冲时柱关子女/晚年。**领域提示 ≠ 事件定谳**：宫动只是「该柱领域当年有波动主题」的领域提示；断该领域具体事件（婚/离/变故/生死）必须叠加对应星的**星动完成信号**（配偶星被合走/被冲损等），单宫动不断具体事件。
4. **岁运并临**（流年与大运干支相同）：[HEURISTIC] **同一岁运信号重复出现、主题被强化**，以喜忌定吉凶方向，非必凶；**不作"加倍"式量化**。
5. **大运管法分歧标注**（[SCHOOL]）：古法天干管前 5 年、地支管后 5 年（支力重于干）；另有派别主张干支一体、十年统看。

## 二、应期断法（[HEURISTIC]，强制多重信号互证）

> 铁则：「原局定事、岁运定时」——原局有象（结构具备），岁运引动方应验。**单一信号不足为凭，须 ≥2 个独立信号互证**（如配偶星动 + 夫妻宫动 + 岁运合冲）。
> **「独立」定义（v1.3）**：独立 = 信号来自**不同结构层**——① 十神星动（如官星透干/合动）② 宫位动（如夫妻宫/财帛宫被冲合刑）③ 岁运引动（大运流年与原局的合冲会合）④ 原局结构响应（伏吟/反吟/天克地冲/岁运并临）。取 ≥2 个**不同层**互证；同一层内不同语言描述同一变量不算独立（如「配偶星透 + 财星透」常是同一件事）。

**应期流程速查（三步，先分层后定年）**：
1. **分层（大运层先定性）**：该运对目标领域是关口运（星受制/忌神主导）/主题运/平静运——**关口运只说明「运内该领域有变故」，不说明哪一年、更不说明运内每年都凶**；
2. **信号链（流年层定年）**：前置信号（墓逢值/伏吟/宫冲/星透）只断「时段/关口」；完成信号（星被合走/被克损、库开+星伤、透干得根）之年 = **应期年**；
3. **候选年窗口**：**完成信号年**（星透得根/合身 或 星被合走/被克损）为最强应期年，优先给出；岁运互动年（换运之年）次之；宫动年 / 库动墓逢值年只作**时段/辅助确认**，不能独立定年（待验证：信号强度次序为复盘归纳，样本有限）。

| 引动方式 | 应期含义（提示，非硬断） |
|---|---|
| 合处逢冲 / 冲处逢合 | 原局有合逢冲则动（解合应事）；原局有冲逢合则解（冲解应事） |
| 伏吟（岁运与原局同柱干支重现） | 反复、停滞、应旧事 |
| 反吟（相冲） | 剧烈变动、方向逆转 |
| 天克地冲（岁运干支均与原局某柱相克冲） | 变动最烈之年，主该柱宫位大事——**烈度标签（防误读）**：只定主题与烈度档，**事件类型另查星伤完成度**；禁止把无星伤的年份升级为亡故/牢狱/重疾 |
| 墓库引动（P0 修正） | **先查库中所藏十神、库之喜忌、透藏关系、冲合刑害与岁运承载**，再按以下分支裁决：①**库开释放**——藏神未透干，逢适度冲刑（如辰戌冲、丑未冲）且原局有承载之力 → 库开藏神显用，吉凶看藏神喜忌；②**破库折根**——日主或用神以库藏为唯一根气，逢重冲或合化变质致断根，或藏神已透干、逢冲致天干之根被拔 → 破库坏根，主凶；③**入墓受制**——用神死绝无气且逢岁运入库 → 暂时休伏或受制。**状态年 vs 事件年**：③「入墓受制」=**前置信号（状态年**，只断休伏/受制/关口）；②「破库折根」与「藏神已透干逢冲（根被拔）」=**完成信号（事件年）**——应期取完成信号年，仅有状态年信号不断具体年份。禁止直接断「逢冲＝发财升职」——[SCHOOL] 墓库吉凶两派解读对立，须并列 |
| 填实/冲空 | 空亡地支逢值临（填实）、逢冲（冲空）之年为应期提示 |
| 神煞引动（岁运合冲煞所在支） | 只作主题提示（驿马逢冲提示流动/异地，桃花引动提示婚恋主题），不改主框架结论 |

**按事项（常见范式，须互证；一律先过上方「应期流程速查」三步）**：
- **婚期**（五档排序，R29）：① 配偶星透干**合日主**之年（最标准）> ② 星透得根/得禄 + 夫妻宫动（双信号）> ③ 星透 + 宫动（候选，非首选）> ④ 仅星透（未合身未得根）→ **不断年** > ⑤ 仅宫动/伏吟 → 只断「婚姻领域变化」，不断婚。附：签纸/摆酒可应不同年份分拆（分别取「星合身/合入夫妻宫年」与「食伤透/宫动年」）；双命合婚各命独立断期、以事件反证。
- **离婚/分手**（R30，待验证：离婚应期命例样本少）：离婚 = 配偶星**被合走/被冲损**（星伤完成）+ 夫妻宫动同年；分手 = 配偶星透干**被合走**之年；格局信号（官杀混杂/伤官克官/比劫夺财）只是质量层背景，**不作离期信号**；断丧偶须星伤+库开+根拔三链齐备。
- **事业变动/升迁**：官杀印星引动；伤官见官待印或财通关之年为升迁应期提示。
- **财运**（信号链版，R41，待验证）：得财年 = 财星透干得根（或财库逢冲开且财为喜用）+ 身能任财；破财年 = 财星受损（坐绝被冲/被合走）+ 劫财透干夺财；**单财透/单库动只断状态年**（财来财去），不断得财破财；身弱财旺盘逢帮身大运流年为得财年。
- **身心**（信号链版，R52）：忌神克用、三刑引动、岁运并临带忌、**库动+刑、墓逢值**均为**前置信号**，只断「该时段压力大/有关口」（**库动+刑/墓逢值=状态年，不能单独定年**）；断具体发病年须信号链完成（喜用神/相关星被克损、根拔、库开+星伤）。仅提示状态/压力，**不作医学断语**。
- **学业**（R58，弱证据，**待验证**）：学业顺行年 = 印星透干生身（或印得根通源）+ 学业线路该年无破；学业受阻/中断 = 印弱/受冲 + 食神生财线出现之年（两线并行才可断去向）；方位取象只作辅助不作主证。

## 三、空亡用法（[SUPPLEMENTAL] 辅助修正项 + [SCHOOL] 流派差异）

- 性质：干支配数的余数之「虚」，**非神煞**。主流以日柱查空亡（[SCHOOL] 古法年柱也查：年空重祖业、日空重自身）。**空亡以引擎输出/排盘工具查得结果为准，本模型不手工查空亡**（引擎 `paipan()` 已输出年/日柱空亡；与排盘解耦原则一致，避免记忆查空亡的幻觉风险）。
- 核心规则（[HEURISTIC] 常见范式）：**用神/吉神落空则虚而不实（凶）；忌神/凶煞落空反减凶（吉）**。
- 出空：大运流年**填实（值临）、冲空**为 [CORE] 主流共识；部分流派认为三合六合可解（[SCHOOL] 标注分歧——亦有流派主张逢合反为「合绊」、空而不实）。填实/冲空之年为应期提示。
- 真空：死绝之季落空为「真空」，无用（[SCHOOL] 盲派重"真空/假空"虚实论）。
- **定位**（结构状态输出，防乱用）：
  - 结构状态：空
  - 解释权重：低～中
  - 是否纳入旺衰计算：**否**（[SCHOOL] 分歧：有派别主张计入）
  - 是否进入主用神判断：否
  - 是否用于应期提示：可

## 四、神煞七种速查（[SUPPLEMENTAL]，只作主题标签）

> 原则：《子平真诠·论星辰无关格局》——神煞不操生克成败之权。**神煞只提供主题标签/细节提示，不得对主判断作数值级增强或削弱**（不用"放大/减力"等量化表述）。所附干支为喜用/忌神时，仅调整措辞侧重（喜则正向提示、忌则风险提示），不改变主框架结论。
> 注：**羊刃不入此表**——羊刃是结构性变量（对应羊刃格），在 SKILL.md 步骤 2 处理。
